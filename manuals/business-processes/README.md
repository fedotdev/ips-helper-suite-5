# Экспорты бизнес-процессов IPS

Исходные IWF сохраняются без изменений. Для анализа используйте `/ips-workflow` и локальный
`skills/ips-workflow/scripts/iwf.py` из корня сьюта. Все преобразованные файлы находятся
в `output/business-processes/`; этот каталог исключён из Git.

Команда первой конвертации:

```powershell
python -X utf8 skills/ips-workflow/scripts/iwf.py decode manuals/business-processes
```

Повторная запись того же выходного файла отклоняется. Для повторной обработки одного IWF
задайте новое имя через `--output "повтор/имя.xml"` относительно рабочей папки.

## Независимый эталон

`САТЕ_Согласование_ТД_old.xml` (165 134 байта) соответствует **другому** IWF —
`D:\Техпроцессы IPS\иконки\САТЕ Согласование ТД.iwf` (32 219 байт).
Его неизменённая копия: `skills/ips-workflow/tests/fixtures/SATE-Soglasovanie-TD.iwf`.
Тест сравнивает именно эту пару побайтно, не нормализуя ID, BOM или переводы строк.

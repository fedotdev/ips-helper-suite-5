1 Введение
Autodesk Revit – это программный комплекс для автоматизированного проектирования, реализующий
принцип информационного моделирования зданий (BIM). Комплекс предоставляет возможности З-D
моделирования частей здания и плоского черчения элементов оформления, создания пользовательских
объектов, организации совместной работы над проектом.
Система IPS разработала интегратор с Autodesk Revit. Данное руководство предназначено для описания
работы интегратора с Revir.

2.1 Настройка интегратора
Перед настройкой интегратора с Autodesk Revit следует убедиться, что на клиенте системы IPS загружен

расширения \ Список:
Если модуля расширения Intermech.ADRevit.Integrator.dll в списке нет, то его следует загрузить по пути

2.2 Импорт проектов в систему IPS
Для создания объекта в системе IPS необходимо импортировать проекты Revit, которые расположены на
локальном компьютере пользователя. Для импорта проекта следует:
1. В меню Экспорт\Импорт выбрать команду Импортировать файл.
2. В открывшемся окне следует выбрать необходимый файл.

3. Далее необходимо выбрать, перемещать только выбранный файл в файловое хранилище или составные
файлы тоже.
4. В открывшемся окне следует указать необходимый тип объекта и нажать на кнопку .
Внимание! При импорте одиночных проектов следует выбирать тип объекта Проекты Revit, а если
совместные проекты, то – Совместным проектам Revit.
Примечание: если при импорте совместного проекта был выбран тип объекта Проекты Revit, то система
IPS запретит совместную работу в этом проекте.

2.4 Закладка IPS
На главной панели в приложении Revit находится закладка IPS. Список функциональных кнопок
перечислен ниже:
Открыть карточку объекта – команда, которая позволяет открыть окно Свойства (карточка)
проекта в системе IPS.
Открыть проект – команда, которая позволяет открыть один из проектов, загруженных в систему
IPS, непосредственно из Revit.
Загрузить семейство из IPS – команда, которая позволяет загрузить в проект семейство из системы
IPS.
Добавить файл общих параметров (Добавить ФОП) – команда, которая позволяет загрузить в проект
ФОП из системы IPS.
Добавить связь с проектом Revit – команда, которая позволяет создать связь в Revit между открытым
проект и другим, загруженным в систему IPS, созданная связь между проектами сохраняется в самой системе
IPS.
Добавить связь с САПР – команда, которая позволяет создать связь в Revit между открытым проектом
и документами формата DWG, DGN и DXF, которые загружены в систему IPS, созданная связь между ними
сохраняется в самой системе IPS.
Импорт САПР – команда, которая позволяет импортировать документы формата DWG, DGN и DXF
из системы IPS в Revit. Между проектом Revit и импортированным документом формата DWG, DGN и DXF
связь не создается в системе IPS.
Импорт PDF – команда, которая позволяет импортировать документы формата PDF из системы IPS в
Revit. Между проектом Revit и импортированным документом формата PDF связь не создается в системе IPS.
Информация о плагине – команда, которая позволяет узнать версию плагина.

2.5 Работа команды Загрузить семейство из IPS
Для того, чтобы загрузить семейство в проект Revit необходимо воспользоваться кнопкой Загрузить
семейство из IPS на закладке IPS.
В открывшемся диалоговом окне пользователь имеет возможность выбрать семейство из списка
стандартных библиотеки Revit. для загрузки следует выбрать семейство и нажать кнопку .
Выбранное семейство будет загружено в проект, а так же находится в диспетчере проекта.
Для загрузки созданного или уже существующего семейства в системе IPS необходимо импортировать
файл, а далее объект готов к работе. Подробное описание импорта проектов в систему IPS представлено в п.
2.2.

непосредственно из самой системы. Для этого следует:

2.7 Загрузка связей и импорт документов в проекты Revit
Интегратор с Revit предоставляет возможность добавить связь с проектами, которые загружены в системе
IPS.
2.7.1 Связь с проектами Revit
Для создания связи с проектом Revit следует:
1. На закладке IPS интегратора Revit нажать кнопку Добавить связь с проектом Revit.
2. В открывшемся окне следует выбрать необходимый проект и нажать кнопку .
3. Далее выбрать тип размещения связанного файла.
Руководство по работе интегратора с Autodesk Revit 13

Интегратор с Revit поддерживает три типа размещения файла:
 Совмещение внутренних начал.
 От базовой точки проекта до базовой точки проекта.
 По общим координатам.
Примечание: если модели имеют разные системы координат, то при выборе типа размещения По общим
координатам – размещение будет невозможно и система выдаст сообщение об ошибке. В таком случает
рекомендуется выбрать другой тип размещения файла.
2.7.2 Связь и импорт с САПР
Интегратор с Revit предоставляет возможность добавить связь между проектом с документами формата
DWG, DGN, DXF, которые загружены в системе IPS, или импортировать их из системы IPS в Revit.
Для того, чтобы добавить связь с САПР следует:
1. На закладке IPS интегратора Revit нажать кнопку Добавить связь с САПР.
2. В открывшемся окне следует выбрать необходимый объект\файл и нажать кнопку для
завершения связи файла с проектом Revit.

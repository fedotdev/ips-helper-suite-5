# Проведение изменений через редактор извещений
Инициировать процесс проведения изменений можно непосредственно из редактора извещений (первичный выпуск или выпуск новых версий объектов через ЭИ). Для этого следует:
1\. Вызвать из основного меню редактора **Извещение \ Включить в извещение** или из контекстного меню рабочей области бланка команду **Включить в извещение \ Объекты…** по включению требуемого объекта в ЭИ (ИИ, ПИ, ПР, СЗ).
2\. Далее следует выбрать объекты для включения в ЭИ из списка допустимых.
3\. В появившемся диалоге необходимо выбрать параметры включения в ЭИ. В списке включаемых объектов присутствуют выбранные для включения версии объектов.
В зависимости от выбранной цели включения возможны следующие варианты дальнейших действий системы:
· Выбрана цель **Изменение.** Проверяется значение свойства **Способ модификации объектов** на шаге схемы ЖЦ типа объекта, на котором находится включаемая в ЭИ версия объекта:
ü Если установлено значение **Через рабочую копию объекта** , то выбранные объекты включаются в состав ЭИ с целью **Изменение** типом связи **Изменяется по извещению** с жесткой конкретизацией версии в составе. При включении объектов в состав ЭИ происходит их автоматическое добавление в состав контекста редактирования данного ЭИ, т.е. по аналогии с процессом создания версий объектов с включением в ЭИ по необходимости, подробное описание представлено в п. .
ü Если установлено значение **Выпуском новой версии объекта** , то инициируется выпуск новых версий выбранных объектов, т.е. изначально выбранные объекты выступают в качестве версий-прототипов для вновь создаваемых версий. При этом, если изначально выбранный объект принадлежит информационному набору с синхронным выпуском версий, подробное описание представлено в п. , то осуществляется также синхронное создание версий и для всех связанных объектов.
Вновь создаваемые версии объектов включаются в состав ЭИ с их автоматическим добавлением в состав контекста редактирования этого ЭИ. 
Возможность автоматического включения версий связанных объектов в состав и контекст редактирования ЭИ зависит от значения свойства **Необходимость выпуска извещения** для шага схемы ЖЦ, на котором находится версия-прототип связанного объекта. Действия системы и функциональные возможности по включению создаваемых версий связанных объектов в состав и контекст редактирования ЭИ, а также действия по их скрытию в редакторе **Дерево содержания извещения** , которые описаны в п.п. и .
На рисунке ниже показана настройка значения свойства **Способ модификации объектов** для выбранного шага схемы ЖЦ конструкторских объектов:
· Выбрана цель **Создание**. Объекты включаются в состав ЭИ с целью **Создание** типом связи **Изменяется по извещению** с жесткой конкретизацией версии в составе. При включении объектов в состав ЭИ происходит их автоматическое добавление в состав контекста редактирования данного ЭИ.
· Выбрана цель **Аннулирование**. Объекты включаются в состав ЭИ с целью **Аннулирование** типом связи **Изменяется по извещению** с жесткой конкретизацией версии в составе. При включении объектов в состав ЭИ не происходит их автоматическое добавление в состав контекста редактирования этого ЭИ.

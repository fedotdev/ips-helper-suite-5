# Этапы создания объекта с обязательным включением в ЭИ
Описание процесса создания объекта с обязательным включением в ЭИ осуществляется на примере изделия типа **Деталь** , а также связанных с ними ЭД из родительского типа **Электронная модель детали** и **Чертеж детали** (на примере, ДЭ созданных в 3D CAD NX). Принцип проведения изменений для ДЭ, разработанных в других 3D CAD, аналогичен описываемому.
Для создания объекта с обязательным включением в ЭИ следует:
1\. Запустить процесс создания объекта необходимого типа с заполненной его реквизитной и содержательной частей посредством команд из основного меню, из контекстного меню типа в **Навигаторе** , из контекстного меню существующего объекта того же типа и др.
2\. Для свойства **Необходимость извещения** установить значение **Требовать включение в извещение или запись ЖИ** , чтобы открыть диалог выбора типа инструмента проведения изменений.

3\. При условии, что ранее было выбрано значение **Включить в извещение** , то в открывшемся диалоге с требованием создания нового или выбора существующего ЭИ, в которое будет включен создаваемый объект, следует выбрать один из вариантов: 
· Выбор типа создаваемого ЭИ и запуск его создания.
· Выбор уже имеющего ЭИ.
· Выбор текущего ЭИ, контекст которого активирован на момент создания.

4\. В появившемся диалоге **Параметры включения объектов** уже присутствует создаваемый основной объект в списке включаемых объектов, следует:
· Выбрать создаваемый объект в области **Включаемые объекты.**
· Указать значение цели включения. Например, при создании объекта устанавливается – **Создание**.
· Выбрать следующий шаг ЖЦ, на который будет переведена созданная версия объекта при актуализации ЭИ, подробное описание представлено в п. .

Созданный объект включается в состав ЭИ с целью **Создание** типом связи **Изменяется по извещению** с жесткой конкретизацией версии в составе. При включении создаваемого объекта в состав ЭИ происходит его автоматическое добавление в состав контекста редактирования ЭИ, т.е. создание нового объекта через ЭИ фиксируются в контексте редактирования этого ЭИ.

# Проведение изменений через Журнал изменений
Для того чтобы провести изменения через редактор **Журнала изменений** следует:
1\. Из контекстного меню вызвать команду **Редактировать** для выбранного ЖИ.
2\. В рабочей области бланка ЖИ из контекстного меню вызвать команду **Создать новую запись.**
3\. Из списка допустимых объектов следует выбрать необходимый для его дальнейшего включения в запись ЖИ. Доступен выбор только одного объекта.
4\. В появившемся диалоге необходимо выбрать параметры включения объекта в запись ЖИ.
5\. Далее осуществляется автоматическая проверка значения свойства **Способ модификации объектов** на шаге схемы ЖЦ, на котором находится объект, включаемый в запись ЖИ:
· Если установлено значение **Через рабочую копию объекта** (версия объекта находится на шаге схемы ЖЦ, допускающем ее редактирование), то выбранный объект включаются в состав записи ЖИ с целью **Изменение** типом связи **Изменяется по извещению** с жесткой конкретизацией версии в составе (новая версия не создается, в состав записи ЖИ включается выбранная версия объекта).
При включении версии объекта в состав записи ЖИ происходит его автоматическое добавление в состав контекста редактирования созданной записи ЖИ, т.е. по аналогии с процессом создания версий объектов с включением в ЭИ.
· Если установлено значение **Выпуском новой версии объекта** , то инициируется выпуск новой версии выбранного объекта, т.е. изначально выбранный объект выступает в качестве версии-прототипа для вновь создаваемой версии. При этом, если изначально выбранный объект принадлежит информационному набору с синхронным выпуском версий, то осуществляется также синхронное создание версий для всех связанных объектов.
Вновь создаваемая версия объекта включается в состав записи ЖИ с автоматическим добавлением в состав контекста редактирования этой записи ЖИ. 
Возможность автоматического включения создаваемых версий связанных объектов в состав и контекст редактирования записи ЖИ зависит от значения свойства **Необходимость выпуска извещения** для шага схемы ЖЦ, на котором находится версия-прототип связанного объекта: если установлено предложение или требование выпуска извещения или записи ЖИ, то версии связанных объектов автоматически включаются в состав и контекст редактирования записи ЖИ.

6\. Версия выбранного объекта, включенная в состав созданной записи ЖИ, отображается в рабочей области бланка ЖИ в виде отдельной записи. При синхронном выпуске связанных версий и их автоматическом включении в состав и контекст редактирования записи ЖИ в записи бланка будет присутствовать указание всех версий связанных объектов.
В графе **Изм.** автоматически выводится порядковый номер созданной записи ЖИ в составе текущего ЖИ. 
В графе **Дата записи** автоматически выводится дата создания записи.
В графе **Обозначение документа** автоматически выводится значение атрибута **Обозначение** включенной в запись ЖИ версии объекта, для которой создана эта запись.

# Этапы создания версий объектов через предложение включения в ЭИ
Описание процесса создания версий объектов с предложением включения в ЭИ представлено на примере изделия типа **Сборочная единица** , а также связанных с ними ЭД из родительского типа **Электронная модель сборочной единицы** , **Сборочный чертеж**. и **Спецификация**. Принцип проведения изменений для ДЭ, разработанных в других 3D CAD, аналогичен описываемому.
Последовательность действий:
1\. Следует выбрать версию-прототипа, размещаемою на шаге схемы ЖЦ, для которого установлена необходимость предлагать включение в ЭИ и значение свойства **Способ модификации объектов** не содержит значение **Нельзя модифицировать объект**. В противном случае будет действовать запрет на выпуск новой версии на основании версии-прототипа.
2\. Далее необходимо запустить процесс создания версии объекта через вызов команды **Создать версию** из контекстного меню для выбранной версии-прототипа.
3\. При условии, что для свойства **Необходимость извещения** установлено значение **Предлагать включение в извещение или запись ЖИ** появляется диалог, в котором следует выбрать тип инструмента проведения изменений.
4\. При выборе значения **Включить в извещение** , появится диалог, в котором следует выбрать: создавать новое или выбирать существующее ЭИ, в которое будут включены вновь создаваемые версии объектов:
· Выбор типа создаваемого ЭИ и запуск его создания.
· Выбор имеющего ЭИ.
· Выбор текущего ЭИ, контекст которого активирован на момент создания версий.
При условии что был выбран вариант создания нового ЭИ, пользователю доступны формы с возможностью ввода реквизитной части ЭИ. Описание процесса создания самого ЭИ, заполнение реквизитной части, выбор шаблона и т.д., представлено в главе .
5\. Далее следует выбрать параметры включения в ЭИ. В списке включаемых объектов присутствует версия-прототип основного объекта, версия объекта, на котором инициирована команда выпуска новой версии и включения в ЭИ.
6\. Далее следует выбрать в списке создаваемые и включаемые в ЭИ версии объектов. В случае синхронного выпуска версий, подробное описание представлено в п. , совместно с основным объектом в состав ЭИ включаются и версии связанных объектов.
Версия основного объекта включается в состав без возможности скрытия отображения в рабочей области бланка ЭИ, так как от него инициирован процесс выпуска версии и самого ЭИ. Оставшиеся создаваемые версии связанных объектов изначально включаются в состав ЭИ в скрытом состоянии. При необходимости пользователь имеет возможность отключить скрытие для выбранных версий.
Появление формы с реквизитной частью создаваемой версии основного объекта. Версии связанных объектов создаются в автоматическом режиме.
В редакторе извещений версии основных объектов попадают в рабочую область бланка ЭИ, скрытые версии присутствуют только в редакторе **Дерево содержания извещения**. При необходимости видимость скрытых версий объектов в редакторе **Дерево содержания извещения** можно отключить посредством настройки **Настройка \ Параметры IPS \ Редактор извещений \ Общие настройки \ Показывать скрытые объекты.**
Для перемещения скрытой версии объекта в список основных, следует использовать команду контекстного меню **Показать**. В основной ветке редактора **Дерево содержания извещения** данные версии объектов будут помечены зеленым цветом.

# Реквизитная часть объектов и связей при выпуске объекта через запись ЖИ
При включении версии объекта в состав записи ЖИ (текущей или вновь созданной) осуществляется автоматическое присваивание значений следующим основным атрибутам объекта и его связи с записью ЖИ:
· Атрибут версии объекта **Номер изменения**. Атрибут типа **Строка**. Автоматически присваивается значение по формуле «NЖ», 
где «N» – следующий порядковый номер изменения среди всех версии объекта, а «Ж» – признак, что версия включена в запись ЖИ. 
Например,
Последняя версия объекта имеет значение атрибута **Номер изменения** равное «5», тогда вновь выпущенная через запись ЖИ версия будет иметь значение «6Ж». При этом, следующая версия, выпущенная через ИИ при погашении записи ЖИ, будет иметь значение «6».
· Атрибуты связи версии объекта с ЭИ:
ü **Идентификатор шага ЖЦ, на который будет переведен объект**. Целочисленный атрибут, в который прописывается идентификатор шага схемы ЖЦ, на который будет переведена версия объекта в составе Записи ЖИ ее перевода на шаг ЖЦ **Ожидание погашения посредством ИИ.**
ü **Цель включения объекта**. Целочисленный атрибут, в котором указывается цель включения объекта в состав записи ЖИ. При выпуске версии объекта через запись ЖИ устанавливается значение **Изменение**.
При создании записи ЖИ в составе редактора **Журнала изменений** осуществляется автоматическое присваивание значений следующим атрибутам записи ЖИ:
· **Обозначение**. Строковый атрибут. Значение формируется по формуле «Обозначение.N», где «Обозначение» – значение атрибута **Обозначение** **Журнала изменений** , в составе которого создавалась запись ЖИ, а «N» – порядковый номер создания записи ЖИ в составе редактора **Журнал изменений**.
· **Принадлежит журналу изменений**. Ссылочный атрибут. Содержит ссылку на редактор **Журнал изменений** , в составе которого создавалась запись ЖИ.

# Этапы первичного выпуска ранее созданных объектов через ЭИ
Последовательность действий:
1\. Следует создать требуемые объекты.
2\. Необходимо инициировать включение объектов в состав ЭИ. Включение в ЭИ осуществляется посредством команды контекстного меню **Извещения и контексты \ Выпустить по извещению…** для выбранного объекта или объектов.
На рисунке ниже показан вызов команды по включению объектов в ЭИ с целью первичного выпуска:
3\. В появившемся диалоговом окне следует выбрать необходимые требования создания нового или выбора существующего ЭИ. Возможные варианты:
· Выбор типа создаваемого ЭИ и запуск его создания.
· Выбор имеющего ЭИ.
· Выбор текущего ЭИ, контекст которого активирован на текущий момент.
На рисунке ниже показан диалог создания или выбора имеющегося ЭИ:
4\. В появившемся диалоге следует выбрать параметры включения в ЭИ. По умолчанию установлена цель включения **Создание**.
При необходимости пользователь может указать дополнительные параметры включения: шаг ЖЦ, на который будет выполнен перевод объектов после актуализации ЭИ и необходимость оформления записей отдельными изменениями в бланке ЭИ.
5\. Далее необходимо включить объекты в состав ЭИ с целью **Создание** типом связи **Изменяется по извещению** с жесткой конкретизацией версии в составе. При включении объектов в состав ЭИ происходит их автоматическое добавление в состав контекста редактирования данного ЭИ.

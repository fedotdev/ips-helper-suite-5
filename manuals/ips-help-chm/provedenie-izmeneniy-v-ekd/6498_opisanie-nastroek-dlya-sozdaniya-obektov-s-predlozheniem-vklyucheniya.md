# Описание настроек для создания объектов с предложением включения в ЭИ
Для возможности создания объекта с предложением включения в ЭИ следует:
1\. В настройках первого шага схемы ЖЦ, в контексте типа создаваемого объекта, следует включить опцию необходимости предлагать включение в ЭИ при создании версии, т.е. в свойстве **Необходимость извещения** должно быть установлено одно из значений:
· **Предлагать включение в извещение**.
· **Предлагать включение в извещение или запись ЖИ**.

2\. В настройках редактора извещений необходимо включить опцию **Проверять необходимость включения в извещение при создании объектов.**

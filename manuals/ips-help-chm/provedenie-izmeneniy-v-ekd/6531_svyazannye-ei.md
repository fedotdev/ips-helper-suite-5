# Связанные ЭИ
Процесс проведения изменений подразумевает выпуск большого количества ЭИ. Это может быть, как выпуск нескольких конструкторских ЭИ, так и выпуск конструкторских и технологических ЭИ. Чтобы увязать несколько ЭИ между собой в IPS введено понятие связанного извещения.
Связанные ЭИ имеют одинаковое значение атрибута **Номер взаимосвязанного контекста**. Контексты редактирования каждого из связанных ЭИ объединяются в один взаимосвязанный контекст. Таким образом при выполнении подбора версий в составе изделия, подробное описание представлено в п. , подбираются версии объектов, которые находятся в списке версий объектов основного активного контекста ЭИ и любого из связанных с ним контекстов.
В системе существует несколько способов связывания ЭИ между собой (см. ). 
Далее на примере, описанного в п. , будет описан процесс связывания между собой уже имеющихся ЭИ и применение их взаимосвязанного контекста редактирования при версионном конфигурировании состава головного изделия:
1\. Пользователем из подразделения №1, ответственным за СЕ №1, в результате проведения изменений были выпущены новые версии требуемых объектов через ЭИ №1 (ИИ.02).
2\. Пользователем из подразделения №2, ответственным за СЕ №2, в результате проведения изменений были выпущены новые версии требуемых объектов через ЭИ №2 (ИИ.03).
3\. Активируя тот или иной контекст редактирования ЭИ, можно увидеть состав головной сборочной единицы с учетом изменений только по одному из ЭИ.
4\. Для того, чтобы увидеть изменения сразу по нескольким ЭИ необходимо их связать между собой. Для этого следует выбрать одно из ЭИ и для него вызвать команду **Извещения \ Связать с другим извещением (контекстом)** из контекстного меню.
5\. Далее следует выбрать из списка ЭИ, с которым требуется связать текущее ЭИ.
6\. В результате контексты редактирования связанных ЭИ «суммируются» и имеют одинаковое значение атрибута **Номер взаимосвязанного контекста.**
7\. Активируя контекст редактирования любого из связанных ЭИ, можно увидеть состав головной сборочной единицы с учетом изменений по всем связанным ЭИ.
На рисунке ниже показан пример версионного конфигурирование состава изделия через контекст редактирования связанных ЭИ:
8\. Чтобы найти все ЭИ, связанные с текущим ЭИ, следует вызвать команду контекстного меню **Найти в контексте** для этого ЭИ, вызывающую окно с контекстными выборками. 
9\. Далее отметить в списке выборку **Связанные извещения** , в результате чего в рабочей области окна на закладке **Найденные объекты** отобразятся связанные между собой ЭИ.
Примечание: при необходимости отвязать ЭИ от других извещений, следует вызвать из контекстного меню команду **Извещения и контексты\ Отвязать от другого извещения (контекста)** для выбранного ЭИ.

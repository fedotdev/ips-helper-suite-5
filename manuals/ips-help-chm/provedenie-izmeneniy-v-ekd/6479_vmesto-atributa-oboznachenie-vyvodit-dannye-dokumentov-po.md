# Вместо атрибута Обозначение выводить данные документов по расширенному шаблону. Расширенный шаблон вместо обозначений документов.
Если необходимо выводить в рабочей области бланка ЭИ (также и в **Дереве содержания извещения** редактора) вместо информации об атрибуте **Обозначение** изменяемых объектов, информацию по другим атрибутам объекта, то необходимо активировать указанный режим и выполнить настройку шаблона (формулы вычисления обобщенного параметра для последующего вывода) в соответствующей настройке **Расширенный шаблон вместо обозначений документов.**

# Создание ЭИ с заполнением реквизитной части
Создание ЭИ может быть инициировано различными способами:
1\. Через вызов стандартных команд по созданию нового объекта: 
· Команда **Файл \ Создать…** из основного меню.
· Команда **Создать** из контекстного меню для выбранного типа ЭИ в **Навигаторе.**
· Команда **Создать** из контекстного меню имеющегося ЭИ требуемого типа.
· Команда **Извещения \ Создать связанное извещение** из контекстного меню имеющегося ЭИ, при необходимости создания связанного ЭИ.
2\. В автоматическом режиме при создании версий объектов через выпуск ЭИ (подробное описание представлено в п.п. , , и ).
Создание ЭИ сопровождается появлением формы, в которой пользователь осуществляет заполнение его реквизитной части.
Основные атрибуты реквизитной части ЭИ:
· **Обозначение**. Атрибут типа **Строка**. Заполняется вручную или по классификатору на форме ЭИ.
· **Дата выпуска**. Атрибут типа **Дата**. Указывается дата выпуска ЭИ. Заполняется на форме или в бланке ЭИ;
· **Причина выпуска извещения**. Атрибут типа **Строка** с выбором значения из списка допустимых. Заполняется на форме или в бланке ЭИ.
· **Срок изменения**. Атрибут типа **Дата**. Указывается дата, после наступления которой, ЭИ будет переведено на шаг ЖЦ **Актуализация**. Заполняется на форме или в бланке ЭИ. 
· **Срок окончания изменения**. Атрибут типа **Дата**. Указывается дата, после наступления которой, версии объектов, включенных в ЭИ, будут переведены на шаг ЖЦ **Хранение**. Заполняется на форме или в бланке ЭИ;
· **Серии и даты для извещения**. Специальный атрибут типа **Строка**. Используется для указания применяемости в сериях и датах. Заполняется в бланке ЭИ. Значение передается в версии объектов, включенных в ЭИ.
· **Основание для изменений**. Атрибут типа **Ссылка на версию объекта**. Указывается ссылка на ДЭ, который является основанием для выпуска ЭИ. Заполняется на форме ЭИ.
Перечень атрибутов, а также вид формы (набор элементов управления) для ЭИ при необходимости могут отличаться от имеющихся в поставочной базе данных IPS (настройка).

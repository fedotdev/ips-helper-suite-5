# Описание настроек для создания версий объектов с включением в ЭИ по необходимости
Для возможности создания новых версий объекта с включением в ЭИ по необходимости следует:
1\. В настройках шага схемы ЖЦ в контексте типа объекта, на котором будет находиться версия-прототип, следует выключить необходимость включения в ЭИ, т.е. в свойстве **Необходимость извещения** должно быть установлено значение **Не требовать извещения**. 
Примечание: если объект принадлежит информационному набору с синхронным выпуском версий, то указанное значение **Не требовать извещения** свойства шага схемы ЖЦ должно быть установлено для всех типов объектов, входящих в информационный набор, так как при синхронном выпуске версий выполняется проверка необходимости наличия ЭИ для всех ИО из состава информационного набора.
На рисунке ниже показана настройка отсутствия необходимости включения в ЭИ для шага схемы ЖЦ при выпуске версии объекта:
2\. Для первого шага схемы ЖЦ необходимо выключить запрет на существование более одной версии объекта. При выпуске новой версии объекта, она автоматически попадает на первый шаг схемы ЖЦ и если на первом шаге схемы ЖЦ присутствует другая версии, то создание новой версии будет запрещено. Соответственно, чтобы обеспечить возможность размещения на шаге сразу нескольких версий одного и того же объекта, необходимо отключить указанный запрет.
3\. Для первого шага схемы ЖЦ необходимо выключить запрет на существование более одной контекстной версии объекта. При выпуске новой версии объекта она автоматически попадает на первый шаг схемы ЖЦ. Если версия в последующем будет включаться в ЭИ и на первом шаге схемы ЖЦ будет присутствовать другая версия, выпущенная по другому ЭИ, то создание новой версии будет запрещено. Соответственно, чтобы обеспечить возможность размещения на первом шаге сразу нескольких версий одного и того же объекта, включенных в ЭИ, необходимо отключить указанный запрет.
Примечание: если объект принадлежит информационному набору с синхронным выпуском версий, подробное описание представлено в п. , то для всех типов объектов, входящих в информационный набор, необходимо использовать одну и ту же схему ЖЦ.

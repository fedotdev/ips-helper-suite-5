# Пример №2 Уведомление группы пользователей о вводе деталей через ЭИ
Уведомление группы пользователей о вводе деталей через ЭИ, т.е. уведомлять о создании связи типа **Изменяется по извещению** между ЭИ и объектом типа **Деталь** при условии, что в атрибуте связи **Цель включения объекта** будет установлено значение **Создание.**
Последовательность действий:
1\. Запустить процесс создания ИО типа **Автоматические уведомления**.
2\. Для срабатывания уведомлений следует выбрать тип события **Создание связи.**
3\. На закладке **Условия срабатывания** необходимо ввести значений атрибутов в реквизитной части объекта типа **Автоматические уведомления** , в частности атрибут **Заголовок объекта**.
4\. Далее следует указать тип создаваемой связи, для которой будет срабатывать уведомление: выбор типа связи **Изменяется по извещению.**
5\. На закладке **Условия срабатывания** необходимо выбрать тип объекта, для которого будет срабатывать уведомление: выбор родительского типа ИО **Детали.**
6\. Далее следует добавить формулу для формирования дополнительного условия отбора через атрибут связи **Цель включения объекта.**
7\. На закладке Адресат следует выбрать адресата. В данном случае это выбор группы пользователей.
8\. На закладке **Способ уведомления** необходимо выбрать способ уведомления и формирование текста уведомления с использованием подстановок.
9\. Далее следует подтвердить создание автоматического уведомления.
Пользователям, входящим в установленную группу пользователей, в автоматическом режиме на внутреннюю почту IPS будет приходить уведомление о включении версии объекта из родительского типа **Деталь** в состав ЭИ типом связи **Изменяется по извещению** с целью **Создание.**

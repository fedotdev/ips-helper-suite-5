# Описание настроек для выпуска версий объектов без включения в ЭИ
Для создания новых версий объекта без включения в ЭИ или без предложения выпустить его следует: 
1\. В настройках шага схемы ЖЦ в контексте типа объекта, на котором будет находиться версия-прототип, следует выключить необходимость наличия ЭИ, т.е. в свойстве **Необходимость извещения** необходимо установить значение **Не требовать извещения**. Если объект принадлежит информационному набору с синхронным выпуском версий, подробное описание представлено в п. , то указанное значение свойства шага схемы ЖЦ должно быть установлено для всех типов объектов, входящих в информационный набор, так как при синхронном выпуске версий выполняется проверка необходимости наличия ЭИ для всех ИО из состава информационного набора.

2\. Для первого шага схемы ЖЦ необходимо отключить запрет на существование более одной версии объекта. Выполнение данного условия обусловлено тем, что при выпуске новой версии объекта, она автоматически попадает на первый шаг схемы ЖЦ. Если на первом шаге схемы ЖЦ присутствует другая версия, то создание новой версии будет запрещено. Соответственно, чтобы обеспечить возможность размещения на первом шаге сразу нескольких версий одного и того же объекта, необходимо отключение указанного запрета.
Примечание: если объект принадлежит информационному набору с синхронным выпуском версий, подробное описание представлено в п. , то для всех типов объектов, входящих в информационный набор, необходимо использовать одну и ту же схему ЖЦ.

# Схема ЖЦ для ИО, принадлежащих к родительскому объекту типа Извещение
На рисунке ниже показана схема ЖЦ для ИО, принадлежащих родительскому объекту типа **Извещение:**
Описание шагов ЖЦ и возможных переходов на другие шаги ЖЦ представлено ниже:
| **Шаг** | **Описание** | **Возможный переход (другой шаг)** | **Способ перемещения на другой шаг** |
| --- | --- | --- | --- |
| В разработке | Данный шаг ЖЦ присваивается ЭИ в момент его создания (первый шаг схемы ЖЦ). На данный шаг ЖЦ переводятся также ЭИ при необходимости внесения изменений в процессе согласования. ЭИ, находящиеся на данном шаге, доступны для редактирования. | Согласование и утверждение | Перемещение ЭИ осуществляется автоматически через использование функционала модуля документооборота. Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Удален | Перемещение ЭИ осуществляется автоматически при выполнении команды удаления. Перемещение на данный шаг может осуществляться через использование функционала модуля документооборота или вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Согласование и утверждение | Данный шаг ЖЦ соответствует ЭИ, которые находятся на стадии согласования. ЭИ, находящиеся на данном шаге, не доступны для редактирования (ЭИ подписывается согласующими) | В разработке | Перемещение ЭИ осуществляется автоматически через использование функционала модуля документооборота при необходимости внесения изменений в процессе согласования. Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Ожидание наступления срока изменения | Перемещение ЭИ осуществляется автоматически через использование функционала модуля документооборота после прохождения согласования, но до момента вступления изменений в действие. Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Актуализация | Перемещение ЭИ осуществляется автоматически через использование функционала модуля документооборота или после наступления срока актуализации, указанного в реквизитной части ЭИ (посредством выполнения системного сценария по установленному расписанию в планировщике задач IPS). Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Ожидание наступления срока изменения | Данный шаг ЖЦ соответствует ЭИ, которые прошли стадию согласования, но момент вступления изменений в действие не наступил. ЭИ, находящиеся на данном шаге, не доступны для редактирования (ЭИ согласовано). | Актуализация | Перемещение ЭИ осуществляется автоматически через использование функционала модуля документооборота или после наступления срока актуализации, указанного в реквизитной части ЭИ (посредством выполнения системного сценария по установленному расписанию в планировщике задач IPS). Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Актуализация | Данный шаг ЖЦ соответствует ЭИ, которые прошли стадию согласования и для которых наступил момент вступления изменений в действие. ЭИ, находящиеся на данном шаге, не доступны для редактирования. | Хранение | Перемещение ЭИ осуществляется автоматически через использование функционала модуля документооборота. Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Хранение | Данный шаг ЖЦ соответствует утвержденным ЭИ, утратившим свою актуальность. ЭИ, находящиеся на данном шаге, не доступны для редактирования. | Удален | Перемещение ЭИ осуществляется автоматически при выполнении команды удаления. Перемещение на данный шаг может осуществляться также автоматически через использование функционала модуля документооборота или вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Удален | Данный шаг ЖЦ соответствует удаленным ЭИ. ЭИ, находящиеся на данном шаге, не доступны для редактирования. В системе устанавливается настройка периода нахождения ЭИ на данном шаге, после истечения которого оно будет автоматически удаляться из БД | В разработке | Перемещение на данный шаг осуществляется вручную (спец. команда) при наличии у пользователя соответствующих прав (при ошибочном удалении ЭИ с шага «В разработке»). |
**Внимание!** С учетом ограничений, связанных с автоматизацией процесса проведения изменений (наличие обязательных шагов и связей между шагами схемы ЖЦ), перечень шагов схемы ЖЦ и возможных переходов между ними для ЭИ может быть дополнен или изменен.

# Описание настроек для создания версий объектов через предложение включения в ЭИ
Для возможности создания новых версий объекта через предложение включения в ЭИ следует:
1\. В настройках шага схемы ЖЦ в контексте типа объекта, на котором будет находиться версия-прототип, следует включить опцию необходимости предлагать включение в состав ЭИ при выпуске версии, т.е. в свойстве **Необходимость извещения** должно быть установлено одно из значений:
· **Предлагать включение в извещение**.
· **Предлагать включение в извещение или запись ЖИ.**

Примечание: если объект принадлежит информационному набору с синхронным выпуском версий, подробное описание представлено в п. , то указанное значение свойства шага схемы ЖЦ необходимо установить одинаковым для всех типов объектов, входящих в информационный набор.
2\. Для первого шага схемы ЖЦ необходимо отключить запрет на существование более одной версии объекта. При выпуске новой версии объекта она автоматически попадает на первый шаг схемы ЖЦ. 
Примечание: если создание версии осуществляется не через ЭИ (пользователь получает только предложение о создании ЭИ) и на первом шаге схемы ЖЦ присутствует другая версия, то создание новой версии будет запрещено. Соответственно, чтобы обеспечить возможность размещения на первом шаге сразу нескольких версий одного и того же объекта, необходимо отключение указанного запрета.

3\. Для первого шага схемы ЖЦ следует отключить запрет на существование более одной контекстной версии объекта. При выпуске новой версии объекта она автоматически попадает на первый шаг схемы ЖЦ. 
Примечание: если создание версии осуществляется через ЭИ и на первом шаге схемы ЖЦ присутствует другая версия, выпущенная по другому ЭИ, то создание новой версии будет запрещено. Соответственно, чтобы обеспечить возможность размещения на первом шаге сразу нескольких версий одного и того же объекта, выпущенных через ЭИ, необходимо отключение указанного запрета.
Примечание: если объект принадлежит информационному набору с синхронным выпуском версий, подробное описание представлено в п. , то для всех типов объектов, входящих в информационный набор, необходимо использовать одну и ту же схему ЖЦ.

# Ограничения, связанные с использованием контекстов редактирования ЭИ
**Внимание!** Одна и та же версия объекта может присутствовать в составе только одного контекста редактирования ЭИ.
В составе контекста редактирования ЭИ не может присутствовать несколько версий одного и того же объекта. При этом в состав контекста редактирования ЭИ могут быть добавлены любые версии объектов при условии, что в любом из связанных с ним контекстов нет этих версий или других версий этих объектов. Например, есть цепочка связанных контекстов ЭИ– К1, К2, …, Кn. Есть версии объекта – А1, А2,..., Аm. Допускается добавлять любую из версий А (например, А1) в контексты К, если в любом из контекстов нет другой версии А (например, А2). Указанное ограничение введено с той целью, чтобы при подборе версий в составе не возникло неоднозначной ситуации, когда должны подобраться несколько версий одного объекта.

# Типы извещений
В системе IPS присутствуют следующие системные типы электронных извещений:
· Извещение об изменении (ИИ).
· Предварительное извещение об изменении (ПИ).
· Предложение об изменении (ПР).
· Служебная записка (СЗ).
· Дополнительное извещение об изменении (ДИ).
· Дополнительное предварительное извещение об изменении (ДПИ).
На рисунке ниже представлен список электронных извещений в дереве **Навигатора** :
В составе типов ИИ, ПИ, ПР допускается создание своих пользовательских типов ЭИ. Логика работы вновь введенного пользовательского типа ЭИ будет аналогична родительскому типу. При этом выбор вновь введенного типа ЭИ в процессе выпуска версии объекта будет осуществляться по нажатию кнопки в диалоге выбора типа ЭИ.

Проведение изменений доступно через **Журнала изменений** , который находится по пути **Типы объектов \ Документы \ Журналы изменений**. **Журнал изменений** работает в связке с объектами типа **Записи журнала изменений** , которые находятся по пути **Типы объектов \Контексты редактирования \Записи журнала изменений**. Подробное описание процесса проведения изменений через **Журнал изменений** и **Записи журнала изменений** представлено в главе .

# Погашение записи ЖИ
Для того чтобы погасить запись ЖИ в редакторе **Журнала изменений** следует:
1\. Выпущенная и согласованная запись ЖИ, которая размещена на шаге ЖЦ **Ожидание погашения посредством ИИ** , подробное описание представлено в п. . Включённая в состав записи ЖИ версия объекта размещена на шаге **Выпущен по ПИ** соответствующей схемы ЖЦ, указанный шаг следует применить для версий, выпущенных по ПИ, ПР, СЗ и записи ЖИ.
На рисунке ниже показан пример состава согласованной записи ЖИ:
2\. Из редактора **Журнал изменений** для выбранной записи ЖИ следует вызвать из контекстного меню команду **Погасить извещением…**
3\. В появившемся диалоге необходимо следует указать создавать новый или выбрать существующее ИИ для погашения записи ЖИ.
4\. В появившейся форме ИИ необходимо ввести реквизиты (при выборе варианта создания нового ИИ). Описание процесса создания ЭИ (заполнение реквизитной части, выбор шаблона и т.д.) представлено в главе .
5\. Автоматическое создание новых версий для всех объектов, входящих в состав выбранной записи ЖИ, т.е. версии, входящие в состав записи ЖИ выступают в качестве прототипов для вновь создаваемых.
6\. В содержательной части рабочей области бланка ИИ автоматически создаются записи по изменению для каждой из вновь созданных версий объектов с учетом настройки перечня скрываемых типов, подробное описание представлено в п. .
7\. Вновь созданные версии объектов добавляются в состав и контекст редактирования ИИ. 
У версий объектов из состава ИИ происходит автоматическое присваивание значений следующих атрибутов:
· **Извещение**. Ссылочный атрибут. Содержится ссылка на ИИ, которым погашается запись ЖИ.
· **Номер изменения**. Строковый атрибут. Содержит порядковый номер изменения, который был у версии-прототипа в составе записи ЖИ (доступно ручное изменение значения) без суффикса «Ж». 
Например, версия объекта в составе записи ЖИ имеет значение – «6Ж», вновь созданная версия при погашении записи ЖИ через ИИ будет иметь значение «6».
Атрибуту связи **Цель включения объекта** между ИИ и вновь созданной версии объекта присваивается значение **Изменение**.
8\. У погашаемой записи ЖИ происходит автоматическое присваивание значений следующих атрибутов:
· **Погашено извещением**. Ссылочный атрибут. Содержит ссылку на ИИ, которым погашается запись ЖИ.
· **Шаг жизненного цикла**. Системный атрибут. Содержит идентификатор текущего шага схемы ЖЦ для ИО типа **Записи журнала изменений**. Будет установлено значение **Хранение** т.е. запись ЖИ автоматически переводится на шаг ЖЦ **Хранение** , подробное описание представлено в п. .

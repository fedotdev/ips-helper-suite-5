# Пример №1 Уведомление владельца о том, что ЭИ согласовано и изменения по нему вступили в действие
Уведомление владельца о том, что ЭИ согласовано и изменения по нему вступили в действие, т.е. уведомлять о переводе ЭИ на шаг ЖЦ Актуализация.
Последовательность действий:
1\. Запустить процесса создания ИО типа **Автоматические уведомления** по команде контекстного меню для типа объекта. 
2\. В открывшемся диалоге выбрать типа события **Перемещение на шаг жизненного цикла** для срабатывания уведомления.
3\. Далее следует ввести значения атрибутов в реквизитной части объекта типа **Автоматические уведомления** , в частности атрибут **Заголовок объекта**.
4\. На закладке **Условия срабатывания** необходимо выбрать тип объекта, для которого будет срабатывать уведомление: выбор родительского типа ИО **Извещения**.
5\. Далее следует выбрать шага ЖЦ, перевод на который будет отслеживаться системой.
6\. На закладке **Адресат** необходимо выбрать значение опции для поиска адресата получения автоматического уведомления при наступлении события.
7\. На закладке **Способ уведомления** следует выбрать способа уведомления и формирование текста уведомления с использованием подстановок. Подробное описание возможных подстановок представлено в ».
8\. Для подтверждение создания автоматического уведомления следует нажать кнопку .
При перемещении любого ЭИ, принадлежащего родительскому типу **Извещения** , на шаг ЖЦ **Актуализация** , владельцу ЭИ на внутреннюю почту IPS в автоматическом режиме будет приходить соответствующее сообщение.

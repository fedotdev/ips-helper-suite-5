# Описание настроек для создания объектов с обязательным включением в ЭИ
Для возможности создания объекта только через ЭИ следует:
1\. В настройках первого шага схемы ЖЦ, в контексте типа создаваемого объекта, необходимо включить опцию обязательности включения в ЭИ при выпуске версий, т.е. в свойстве **Необходимость извещения** должно быть установлено одно из следующих значений:
· **Требовать включение в извещение**.
· **Требовать включение в извещение или запись ЖИ**.

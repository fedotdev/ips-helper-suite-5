# Список сокращений
В руководстве по проведению изменений в электронной конструкторской документации применяются следующие сокращения:
| ДИ | Предварительное извещение |
| --- | --- |
| ДПИ | Дополнительное предварительное извещение |
| ДЭ | Электронный документ |
| ЖИ | Журнал изменений |
| ЖЦ | Жизненный цикл |
| ИИ | Извещение об изменении |
| ПИ | Предварительное извещение об изменении |
| ПР | Предложение об изменении |
| СЗ | Служебная записка |
| ЭИ | Электронное извещение |

# Схема ЖЦ для ИО типа Записи журнала изменений
На рисунке ниже показана схема ЖЦ для ИО типа **Записи журнала изменений** :
Описание шагов схемы ЖЦ для ИО типа **Записи журнала изменений** и возможных переходов между ними представлены ниже:
| **Шаг** | **Описание** | **Возможный переход (другой шаг)** | **Способ перемещения на другой шаг** |
| --- | --- | --- | --- |
| Создание объекта | Данный шаг ЖЦ присваивается Записи ЖИ в момент ее создания (первый шаг схемы ЖЦ). Также на данный шаг ЖЦ переводятся Записи ЖИ при необходимости внесения изменений в процессе согласования. Записи ЖИ, находящиеся на данном шаге, доступны для редактирования. | Согласование и утверждение | Перемещение Записи ЖИ осуществляется автоматически через использование функционала модуля документооборота. Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Удален | Перемещение Записи ЖИ осуществляется автоматически при выполнении команды удаления. Перемещение на данный шаг может осуществляться также автоматически через использование функционала модуля документооборота или вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Согласование и утверждение | Данный шаг ЖЦ соответствует Записям ЖИ, которые находятся на стадии согласования. Записи ЖИ, находящиеся на данном шаге, не доступны для редактирования. | Создание объекта | Перемещение Записи ЖИ осуществляется автоматически через использование функционала модуля документооборота при необходимости внесения изменений в процессе согласования. Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Ожидание погашения посредством ИИ | Перемещение Записи ЖИ осуществляется автоматически через использование функционала модуля документооборота после прохождения согласования. Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Ожидание погашения посредством ИИ | Данный шаг ЖЦ соответствует Записям ЖИ, которые прошли стадию согласования. Записи ЖИ, находящиеся на данном шаге, не доступны для редактирования. | Хранение | Перемещение Записи ЖИ осуществляется автоматически через использование функционала модуля документооборота либо после актуализации извещения, которым Запись ЖИ погашается (см. п. ). Перемещение на данный шаг может осуществляться вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Хранение | Данный шаг ЖЦ соответствует утвержденным Записям ЖИ, утратившим свою актуальность (погашены ИИ). Записи ЖИ, находящиеся на данном шаге, не доступны для редактирования. | Удаление объекта | Перемещение Записи ЖИ осуществляется автоматически при выполнении команды удаления. Перемещение на данный шаг может осуществляться также автоматически через использование функционала модуля документооборота или вручную (спец. команда), при наличии у пользователя соответствующих прав. |
| Удаление объекта | Данный шаг ЖЦ соответствует удаленным Записям ЖИ. Записи ЖИ, находящиеся на данном шаге, не доступны для редактирования. В системе устанавливается настройка периода нахождения Записи ЖИ на данном шаге, после истечения которого она будет автоматически удаляться из БД | Создание объекта | Перемещение на данный шаг осуществляется вручную (спец. команда) при наличии у пользователя соответствующих прав (при ошибочном удалении Записи ЖИ с шага «В разработке») |
**Внимание!** С учетом ограничений, связанных с автоматизацией процесса проведения изменений (наличие обязательных шагов и связей между шагами схемы ЖЦ) перечень шагов схемы ЖЦ и возможных переходов между ними для Записи ЖИ может быть дополнен или изменен.

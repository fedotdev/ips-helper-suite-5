# Описание настроек для создания версий объектов только через включение в ЭИ
Для возможности создания новых версий объекта только через включение в ЭИ следует:
1\. В настройках шага схемы ЖЦ в контексте типа объекта, на котором будет находиться версия-прототип, следует включить опцию необходимости включения в ЭИ при выпуске версии, т.е. в свойстве **Необходимость извещения** должно быть установлено одно из значений:
· **Требовать включение в извещение**.
· **Требовать включение в извещение или запись ЖИ**.

2\. Для первого шага схемы ЖЦ необходимо снять запрет на существование более одной контекстной версии объекта. При выпуске новой версии объекта она автоматически попадет на первый шаг схемы ЖЦ. 
Примечание: если создание версии осуществляется через ЭИ и на первом шаге схемы ЖЦ присутствует другая версия, выпущенная по другому ЭИ, то создание новой версии будет запрещено. Соответственно, чтобы обеспечить возможность размещения на первом шаге сразу нескольких версий одного и того же объекта, выпущенных через ЭИ, и необходимо отключить данный запрет.

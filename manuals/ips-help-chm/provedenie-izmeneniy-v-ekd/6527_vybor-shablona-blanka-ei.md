# Выбор шаблона бланка ЭИ
Выбор шаблона для создаваемого ЭИ осуществляется на соответствующем шаге заполнения реквизитной части на форме создаваемого ЭИ. на рисунке ниже показан выбор шаблона бланка для создаваемого ЭИ:
Видимость шаблонов в списке определяется соответствующей настройкой, описание которой представлено в п. .
Шаблоны для ЭИ размещаются по пути **Информационное пространство \ Объекты \ Настройки системы \ Шаблоны документов (бланки) \ Шаблоны извещений**

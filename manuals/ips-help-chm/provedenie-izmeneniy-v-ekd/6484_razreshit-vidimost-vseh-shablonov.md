# Разрешить видимость всех шаблонов
Включенная настройка **Разрешить видимость всех шаблонов** позволяет пользователю видеть полный перечень применяемых шаблонов бланка при создании ЭИ. По умолчанию установлено значение «Нет».
Для управления видимостью шаблонов ЭИ следует: 
1\. В **Конфигураторе базы данных** добавить атрибут **Видимость объекта** к типу объектов **Шаблоны извещений.**
2\. Для имеющихся экземпляров объектов типа **Шаблон извещения** настроить требуемую видимость.

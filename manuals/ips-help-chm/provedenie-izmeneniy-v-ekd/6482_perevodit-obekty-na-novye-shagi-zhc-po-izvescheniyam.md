# Переводить объекты на новые шаги ЖЦ по извещениям
Настройка **Переводить объекты на новые шаги ЖЦ по извещениям** позволяет автоматически перемещать объекты, входящие в состав ЭИ, на шаг ЖЦ указанный в момент их включения в ЭИ (с учетом доступности перехода между шагами ЖЦ в рамках назначенной для объекта схемы ЖЦ). Данная возможность доступна при актуализации ЭИ (подробное описание представлено в п. ).
Примечание: если настройка выключена, то диалог выбора шага ЖЦ не доступен. 
На рисунке ниже показан вариант, где отсутствует возможность выбора шага ЖЦ, на который необходимо переместить объект после актуализации ЭИ:
При выключенной настройки **Переводить объекты на новые шаги ЖЦ по извещениям** перевод объектов в составе ЭИ на требуемый шаг ЖЦ осуществляется вручную, либо автоматизированным способом в рамках согласования по бизнес-процессу.

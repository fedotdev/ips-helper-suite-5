# Принятие предложений по ПР
Для принятия предложений по ПР следует: 
1\. Выпущенное и согласованное ЭИ типа ПР: ПР автоматически размещаются на шаге ЖЦ **Актуализация** , созданные по ПР версии объектов – на шаге **Выпущен по ПИ.**
2\. Далее следует принять предложение по ПР с помощью вызова из контекстного меню одну из команд:
· **Извещения и контексты \ Принять предложения по ПР**.
· **Извещения и контексты \ Принять ПР с копированием содержимого**. При вызове указанной команды в содержательную часть рабочей области бланка ИИ помещается информация из соответствующей содержательной части рабочей области бланка ПР, подробное описание в .
3\. В появившемся диалоге следует выбрать создавать новое ИИ или выбрать существующее ИИ для принятия предложений по ПР.
4\. Появление формы ИИ с возможностью ввода реквизитной части. 
5\. В содержательную часть рабочей области бланка ИИ автоматически прописывается фраза с указанием обозначения ПР, предложения по которому принимаются текущим ИИ, а в редактора извещений версии объектов **Дерево содержания извещения** , созданных ранее по ПР не добавляются.
6\. Версии объектов, входящие в состав ПР, следует добавить в состав ИИ. 
У версий объектов из состава ИИ происходит автоматическое изменение значений следующих атрибутов:
· **Извещение**. Содержится ссылка на ИИ, которым принимается предложение по ПР.
· **Номер изменения**. Содержит следующий порядковый номер изменения (доступно ручное изменение значения).
У ИИ происходит автоматическое изменение значения атрибута **Основание для изменений** , в котором будет указана ссылка на ПР.
7\. Версии объектов из состава ПР не попадают в состав контекста редактирования ИИ. Происходит связывание ИИ и ПР, подробное описание представлено в п. , и соответственно контексты редактирования ИИ и ПР «суммируются», для ИИ и ПР присваивается одинаковое значение атрибуту **Номер взаимосвязанного контекста.**
При переводе ИИ (в рамках процесса согласования) на шаг ЖЦ **Актуализация** , описание представлено в п. , автоматически инициируется событие по переводу ПР на шаг ЖЦ **Хранение**.

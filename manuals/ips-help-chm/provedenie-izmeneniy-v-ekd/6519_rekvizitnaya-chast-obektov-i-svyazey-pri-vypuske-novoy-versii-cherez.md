# Реквизитная часть объектов и связей при выпуске новой версии через ЭИ
При создании новой версии объекта через ЭИ необходимо заполнить следующие основные атрибуты реквизитной части версии объекта и ее связи с ЭИ:
Атрибуты версии объекта:
· **Срок изменения**. Атрибут типа **Дата**. Указывается дата в бланке ЭИ или на форме ЭИ, после наступления которой, ЭИ будет переведено на шаг ЖЦ **Актуализация** , подробное описание представлено в п. .
· **Срок окончания изменения**. Атрибут типа **Дата**. Указывается дата в бланке ЭИ или на форме ЭИ, после наступления которой, версия объекта будет переведена на шаг ЖЦ **Хранение**.
· **Извещение**. Атрибут типа **Ссылка на версию объекта**. Указывается ссылка на ЭИ, в состав которого помещается версия объекта. Заполняется автоматически в момент включения в состав ЭИ.
· **Применяемость в сериях и датах**. Специальный атрибут типа **Строка**. Используется для указания применяемости в сериях и датах. При указании значения в бланке ЭИ, значение передается в объекты, включенные в ЭИ.
· **Номер изменения**. Используется для вывода значения в соответствующее поле бланка ЭИ. Заполняется при изменении через ИИ – следующий порядковый номер, после последнего имеющегося значения среди всех версий объекта. Присваивается только версиям объектов, входящих в основной перечень измененяемых объектов редактора **Дерево содержания извещения.**
Атрибуты связи версии объекта с ЭИ:
· **Идентификатор шага ЖЦ, на который будет переведен объект**. Целочисленный атрибут, в который автоматически прописывается идентификатор шага схемы ЖЦ, на который будет переведена версия объекта в составе ЭИ при его актуализации. Шаг ЖЦ указывается в диалоге параметров включения версии объекта в ЭИ.
· **Цель включения объекта**. Целочисленный атрибут, в котором указывается цель включения объекта в состав ЭИ. При выпуске версии объекта через ЭИ устанавливается значение **Изменение**.
· **Удалять при исключении извещения**. Логический атрибут. Заполняется автоматически при включении объекта в состав ЭИ. Позволяет определить системе необходимо ли удалять версию объекта, включенную в состав извещения, если будет инициирован процесс ее исключения из состава ЭИ.
· **Скрытие**. Признак возможности перевода версии объекта из списка основных в список скрытых или наоборот в редакторе **Дерево содержания извещения**.

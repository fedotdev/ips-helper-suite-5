# Проведение изменения в объектах через выпуск новых версий
В соответствии с ГОСТ 2.504 п. 5.6 все внесенные изменения в объекте: изменения в содержательно или реквизитной частях должны быть проведены путем создания новой версии. Создание новой версии объекта осуществляется на основании другой версии этого объекта (версии-прототипа). 
В момент создания новой версии версия-прототип размещается на одном из имеющихся шагов схемы ЖЦ, закрепленной за типом объекта. Обязательность выпуска новой версии объекта при необходимости внесения изменений обеспечивается посредством выбора значения **Выпуском новой версии объекта** у настройки **Способ модификации объектов** для шага схемы ЖЦ, на котором размещается версия-прототип.

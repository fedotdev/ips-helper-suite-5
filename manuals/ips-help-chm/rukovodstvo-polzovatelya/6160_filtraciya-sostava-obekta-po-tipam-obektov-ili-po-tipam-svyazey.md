# Фильтрация состава объекта по типам объектов или по типам связей
Системой IPS предусмотрена возможность фильтрации состава объекта, с помощью которой пользователь может исключать из состава те типы объектов или те типы связей, которые его не интересуют в данный момент. Это позволяет уменьшить объем выводимых на экран данных, что улучшает восприятие информации и уменьшает затраты времени при ее считывании. Пользователь может создать несколько фильтров и применять их к составам по мере надобности. Эти фильтры сохраняются в последующих сеансах работы. Настройки фильтрации индивидуальны для каждого пользователя, однако системой предусмотрена возможность копирования фильтров с одних клиентских приложений на другие.
**Внимание!** Фильтрация состава осуществляется на все уровни состава объекта.
Общий вид мастера по созданию и редактированию фильтра состава объекта имеет следующий вид:
В окне фильтрации состава расположены:
Дерево со списком фильтров.
· **Имя** – список добавленных в редактор фильтров.
Закладка **Редактор фильтра состава по типам объектов**.
· **Родительские типы объектов** – список добавленных родительских типов объектов.
· **Скрываемые дочерние типы объектов** – список объектов, которые могут являться дочерними по отношению к выбранному родительскому. Отмеченные объекты будут скрыты из состава родительского объекта. 
· **Скрываемые типы связей** – список типов связей, выбрав которые скрываются все объекты с таким типом связи. 
_Примечание: списки**Скрываемые дочерние типы объектов** и **Скрываемые типы связей** дополнено кнопками ____**Отметить все** и ____**Убрать все отметки**._
Закладка **Свойства** – закладка со свойствами выбранного фильтра.
Закладка **Свойства связи**.
 **Добавить**
При использовании кнопки в дереве со списком фильтров, открывается окно **Диалог выбора** , в котором пользователь может выбрать из списка ранее созданные фильтры.
При использовании кнопки на закладке **Редактор фильтра состава по типам объектов** , открывается окно **Выберите объекты** , в котором можно выбрать родительские объекты для дальнейшего создания фильтра.
 **Удалить** – кнопка, которая позволяет удалить выбранный объект.
 **Загрузить из файла** – кнопка, которая позволяет загружать сохраненные фильтры из локального компьютера.
 **Сохранить в файл** – кнопка, которая позволяет сохранить созданный фильтр с настройками на компьютер пользователя.

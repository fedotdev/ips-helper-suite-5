# Сравнить составы
В системе IPS реализована возможность сравнения составов нескольких выбранных объектов. Сравнение составов происходит в специальном окне, в котором можно сравнивать сходство или различия не только в составах объектов, но и в номерах позиций, примечаниях, количествах и др. 
Чтобы вызвать окно сравнения составов, отметьте в списке объекты, составы которых необходимо сравнить, и примените команду **Состав объекта/Сравнить составы** их контекстного меню.
С левой стороны окна отображаются сравниваемые объекты, с правой — панель инструментов и поле, в котором будет отображаться список объектов, сформированный в зависимости от включенного режима отображения. 
Кнопки панели инструментов позволяют включить один из режимов отображения объектов составов: 
· Кнопка **Различия объектов** включает режим отображения объектов, входящих в состав отмеченного объекта (т.е. не входящих в состав остальных сравниваемых объектов);
· Кнопка **Общая часть объектов** включает режим отображения объектов, входящих в состав всех сравниваемых объектов;
· Кнопка **Состав объекта** позволяет увидеть состав отмеченного объекта;
· Кнопка **Развернутый состав объекта** позволяет увидеть развернутый состав отмеченного объекта.
· Кнопка **Настройка типов связей и атрибуты для сравнения**. После нажатия отобразится диалог, где производится настройка типов связей для получения составов, а также выбор сравниваемых атрибутов. Список допустимых сравниваемых атрибутов будет изменятся в зависимости от выбранных типов связей.
Примечание: при развернутом поиске составов сравнение возможно лишь по атрибуту **Количество**. Это связано с тем, что при таком поиске производится группировка списка по версиям объектов с подсчетом количества (если указан атрибут **Количество** в качестве сравниваемого).
Для формирования составов необходимо нажать кнопку **Выполнить запрос**. 
Примечание: выполнять запрос необходимо в следующих случаях:
− при каждом новом открытии окна сравнения составов;
− при смене связи, в контексте которой производится сравнение объектов;
− при включении/выключении режима развернутого состава объектов.
Для простоты восприятия информации, общие части объектов в поле отображаются обычным шрифтом, а отличающиеся части объектов помечаются жирным шрифтом. Если объекты в составе отличаются только определенным атрибутом, то ячейка с соответствующим атрибутом выделяется в списке цветом.
При желании пользователь может просматривать и редактировать информацию по любому из объектов списка на панели с дополнительными видами, вызываемую с помощью кнопки панели инструментов.

# Условный доступ
**Внимание!** Описанный функционал в данном пункте доступен только для пользователя с правами администратора системы IPS.
В системе IPS реализована возможность настройки назначения прав доступа с условиями. Атрибут **Условие проверки прав доступа** предназначен для установки условного доступа. 
Пользователь имеет возможность создать и свой атрибут, тип которого должен быть целочисленным. Данный атрибут может быть вычисляемым и обязан иметь список допустимых значений.
Для настройки списка атрибутов, предназначенных для описания условного доступа и которые могут быть использованы в дополнение к атрибуту **Условие проверки прав доступа** , следует перейти по пути **Настройка \ Параметры IPS \ Система \ Безопасность \ Атрибуты условного доступа**.
С помощью кнопки **Добавить строку** пользователь может добавить в список свой созданный атрибут в дополнение к атрибуту **Условие проверки прав доступа.**
Для корректной работы условного доступа следует назначить атрибут **Условие проверки прав доступа** и\или любой другой дополняющий атрибут, который входит в список атрибутов условного доступа, на тип объекта в **Конфигураторе базы данных**. **Внимание!** Назначение конкретной позиции прав отрабатывает, при условии, что у объекта данный атрибут равен значению, указанному в назначении прав (т.е. указанное право суммируется с остальными правами в случае, если значение атрибута объекта равно соответствующему значению в данном условии).

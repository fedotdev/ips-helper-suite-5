# Комплекты документов
Пользователю доступен параметр **Комплекты документов** , который можно настроить в окне **Параметры IPS**. 
Для корректной генерации комплектов документов необходимо настроить следующие параметры:
· **Отображать окно документа.** Включенный параметр позволяет отображать окно **Обновление комплекта документов,** которое открывается в процессе генерации комплекта документов.
· **Отображать окно вывода.** Включенный параметр позволяет отображать информационное окно **Вывод** из категории **Показать вывод из: Генерация комплектов документов**.
· **Отображать окно трассировки.** Данный параметр позволяет отображать окно трассировки в рабочей области объекта. 
**Внимание!** Параметр**Отображать окно трассировки** имеет приоритет над настройкой **Настройка / Параметры IPS / Система / Экспертная система / Трассировка / Окно трассировки**.
· **Отображать окно с ошибками.** Включенный параметр позволяет отображать окно с ошибками, которые возникают в процессе формирования комплектов документов.

# Функциональная часть редактора
· **Атрибут** – поле с выпадающим списком атрибутов, в котором можно выбрать строковый невычисляемый атрибут. 
· **Найти в значении атрибута** – область со строкой ручного ввода маски поиска, в которой предоставляется возможность ввести сочетание букв или спецсимволов. 
· – кнопка, с помощью которой можно добавить в маску поиска спецсимволы. Подробное описание спецсимволов представлено в п. .
· **Учитывать регистр** – переключатель, который позволяет включить или выключить учёт регистра букв при поиске по маске.
· **Учитывать сходство букв кириллицы и латиницы** – переключатель, который позволяет учитывать схожие по написанию буквы в кириллицы и латиницы (А, М, Т, Н, Р, О, Е, С, Х).
· **Заменить на** – область управления заменами. 
· **Текс** – режим ручного ввода маски замены текста. Допускается вводить как буквы, так и спецсимволы.
· **Спецсимвол** – кнопка, которая позволяет добавить в маску замены следующие макросы:
− **Счетчик [9999:0:1:1]** , где 9999 – разрядность счетчика, 0 – начальное значение, 1 – шаг, 2 – идентификатор счетчика. Счетчик отображается в месте вставки в виде макроса, а присвоение реального номера происходит при применении атрибутов к объектам. Отсчет значений начинается с первого элемента списка, где использован счетчик с учетом сортировки элементов. Номера присваиваются последовательно среди счетчиков с одинаковым идентификатором. Идентификатор счетчика позволяет использовать несколько счетчиков в одном списке объектов.
**Внимание!** Для корректного использования счетчика следует выделить одновременно все необходимые объекты в списке изделий и нажать кнопку или воспользоваться кнопкой .
− **Текущее значение атрибута [N]** – макрос, который заменяет указанный фрагмент атрибута на текущее значение атрибута.
Примечание: нельзя править спецсимвол **Текущее значение атрибута[N]**.
· **Значение атрибута** – поле с выпадающим списком атрибутов, текстовое значение которого будет использовано для дальнейшей замены.
· **Регистр** – поле с выпадающим списком, который позволяет изменять регистр текста, соответствующего маске замены. 
Доступные значения:
− **Без изменения** – введенное значение в поле **Текст** или выбранное значение атрибута из выпадающего списка будет вставлено без изменений.
− **все строчные** – введенное значение в поле **Текст** или выбранное значение атрибута из выпадающего списка будет вставлено строчными буквами.
− **ВСЕ ПРОПИСНЫЕ** – введенное значение в поле **Текст** или выбранное значение атрибута из выпадающего списка будет вставлено прописными буквами.
− **Начинать с прописных** – введенное значение в поле **Текст** или выбранное значение атрибута из выпадающего списка будет вставлено с первой прописной буквы.
· – кнопка, нажатие которой позволяет осуществлять поиск по маске для выбранного атрибута.
· – кнопка, нажатие которой позволяет осуществлять замену фрагмента, указанного в области **Найти в значении атрибута**(совпадающий с маской поиска), на текст, введенный в области **Заменить на.**
· – кнопка, нажатие которой позволяет автоматически заменить все совпадения по маске поиска.
· – кнопка, которая позволяет применить изменение строкового атрибута. 
Примечание: изменение строковых атрибутов осуществляется только после нажатия кнопки . Отмена правок строковых атрибутов недоступна после нажатия кнопки 
· – кнопка, которая позволяет закрыть редактор **Изменение атрибутов**.

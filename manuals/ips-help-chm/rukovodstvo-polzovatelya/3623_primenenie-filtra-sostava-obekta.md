# Применение фильтра состава объекта
На рисунке показан рисунок, где изображены детали и сборочные единицы с МО, а к составу изделия еще не применен фильтр.
Чтобы применить к составу изделия фильтр, следует на панели нажать кнопку **Фильтры составов по типам объектов** и выбрать из списка необходимый фильтр. 
На рисунке ниже изображен состав изделия с применением фильтра:
_Примечание:__если к составу применена фильтрация, то на панели кнопка_ ___подсвечена следующим образом –_ ___.___
Для того чтобы отключить фильтр следует выбрать команду **Отключить фильтрацию** из выпадающего списка. 
**Внимание!** Фильтрация по типу связи работает аналогично.

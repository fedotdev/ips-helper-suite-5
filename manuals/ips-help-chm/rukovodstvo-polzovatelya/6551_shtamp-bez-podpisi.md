# Штамп без подписи
**Внимание!** Администратор системы IPS может самостоятельно написать сценарий для разработки штампа.
Примечание: в данном пункте описан примерный шаблон штампа.
Для создания и настройки штампа без подписи следует:
1\. После вызова команды **Создать** , в открывшемся окне следует на заполнить атрибут **Заголовок объекта** и нажать кнопку .
2\. В рабочей области **Навигатора** появляется новый объект, для работы над настройкой сценария следует открыть **Свойства (Карточка)** этого объекта.
3\. В строке **Тип штампа** следует выбрать без подписи.
4\. В открывшемся редакторе штампов в область **Шаблон штампа** следует добавить сценарий шаблона. Например,
При добавлении типа штампа и сценария в область **Шаблон штампа** автоматически появляются параметры, которые можно настраивать. На рисунке ниже показан пример следующего сценария шаблона без подписи:

· **Изображение штампа** , параметр, который позволяет добавить изображение в штамп.
· **Наименование штампа** , параметр, который позволяет добавить наименование штампа в шаблон штампа.
· **Текущая дата** , параметр, который позволяет добавить текущую дату в шаблон штампа.
При необходимости создания логотипа следует: 
5\. Для этого следует дважды кликнуть мышью по параметру **Изображение штампа** , выбрать необходимый файл, а затем нажать кнопку **ОК**.
6\. Для корректного отображения штампа следует задать допустимые размеры штампа. В области **Размеры (мм)** необходимо установить ширину и высоту шаблона.
Примечание: высоту рамки следует задавать с запасом.
7\. Далее необходимо добавить тип объекта применяемости штампа, для этого следует нажать на кнопку **Добавить тип объекта применяемости**.
8\. В открывшемся окне следует выбрать тип объекта, а затем нажать кнопку .
9\. Для каждого добавленного типа объекта можно настроить свои координаты, для этого следует выбрать тип объекта применяемости и указать координаты в столбце **Координаты**.
10\. В столбце **Страницы** пользователь может указать на какой странице необходимо отображать штамп.

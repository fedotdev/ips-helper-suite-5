# Назначить атрибут
Для настройки параметра, значением которого является атрибут, следует:
1\. На панели инструментов выбрать команду **Назначить атрибут**.
2\. В открывшемся диалоговом окне **Выбор атрибута** указать необходимый атрибут и нажать кнопку .
3\. Выбранному атрибуту следует настроить параметры в параметры импорта атрибута 
После выбора атрибута, в названии столбца отобразится наименование атрибута, а сам столбец меняет цвет фона. В правой части окна **Настройки импорта** , в области для настройки параметров отобразятся сами параметры импорта, которые необходимо будет настроить.
Параметр **Тип значения** позволяет указать, какие данные хранятся в заданном столбце. Данный параметр может иметь одно из двух значений: **Переменный** или **Постоянный**. Тип значения **Переменный** записывает значение атрибута из соответствующего столбца. Тип значения **Постоянный** записывает значение атрибута из значения свойства **Значение атрибута**.
Параметр **Владелец атрибута** позволяет назначить принадлежность атрибута при импорте. Данный параметр может иметь одно из трех значений: **Объект** , **Связь** , **Входимость**. Если выбранный столбец определяет атрибут объекта, то следует выбрать из выпадающего списка значение **Объект**. При условии, что в столбце определяется родительский объект, а соответственно столбцу назначен атрибут родительского объекта, следует выбрать из выпадающего списка значение **Входимость**. Если столбец определяет атрибут связи, то следует выбрать в списке значение **Связь**.
**Внимание!** В перечне импортируемых метаданных может быть только один столбец, определяющий входимость. Атрибуты связи могут импортироваться только в том случае, если указана входимость – иначе невозможно создать связь.
Параметр **Перезаписывать значения** позволяет указать способ модификации атрибута у существующих объектов/связей. Данный параметр может иметь одно из двух значений: **Пропустить** или **Перезаписать**. Если при импорте объект/связь уже существует в системе IPS и требуется обновить значение атрибута, то необходимо выбрать из выпадающего списка значение **Перезаписать**. В случае если с атрибутом ничего делать не нужно следует выбрать значение **Пропустить**.
Параметр **Синхронизировать с Imbase** позволяет включить или выключить режим синхронизации с Imbase. Если ячейка имеет значение, то включенный режим синхронизации позволяет запустить механизм поиска по указанному атрибуту среди индексов Imbase. Обнаруженная в таблице Imbase запись предоставляет возможность создать объект на ее основе, а все остальные атрибуты и тип объекта будут проигнорированы. Если в результате поиска по индексу ничего не найдено, то происходит запись ошибки в перечень ошибок импорта.
Примечание: если значение в ячейке пустое, то создание объекта происходит в обычном режиме.

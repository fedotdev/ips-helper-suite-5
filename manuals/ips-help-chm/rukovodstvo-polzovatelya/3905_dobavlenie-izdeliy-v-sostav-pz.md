# Добавление изделий в состав ПЗ
Кнопка в дереве состава изделий позволяет выбрать дополнительные изделия, которые будут добавлены в состав производственного заказа. Если количество добавляемых изделий не больше семи, для каждого из них будет отображено окно, в котором следует указать количество добавляемого изделия. В остальных случаях количество следует задать вручную, выбрав каждое добавленное изделие, на страничке **Свойства связи**.

# Импорт из Excel в таблицу IMBASE
Система IPS предоставляет возможность импортировать данные из Excel в таблицы IMBASE и обновлять имеющиеся. Для этого следует:
1\. В **Навигаторе** выбрать необходимую таблицу IMBASE в объектах типа **Каталоги и справочники IMBASE.**
2\. Из контекстного меню вызвать команду **Импорт из Excel**. На рисунке ниже показан пример:
3\. В открывшемся окне **Настройки импорта** следует проверить привязку таблицы к головному объекту для импортируемых объектов.
По умолчанию включена флаговая кнопка **При отсутствии совпадений создавать новую запись** , что позволяет не только обновить данные в таблице IMBASE но и создать новые строки.
При необходимости создания копии таблицы следует включить флаговую кнопку **Создать копию таблицы** и заполнить строку **Имя новой таблицы**.
4\. Выбрать кнопку **Открыть файл** и в открывшемся диалоговом окне выбрать необходимый файл MS Excel, а затем нажать кнопку **.**
Содержимое файла отобразится в окне **Настройки импорта**.
5\. На панели инструментов необходимо нажать кнопку **Назначить атрибут.**
6\. В открывшемся окне **Выбор атрибута** следует включить флаговую кнопку **Показать скрытые атрибуты**.
7\. Для корректного импорта данных следует назначить атрибут для сравнения и в свойствах задать условие **Да**. На рисунке ниже показан пример:
**Внимание!** Красным цветом выделен атрибут, который не импортируется, а в окне-подсказке появится сообщение об отказе в импорте. 
8\. Далее следует назначить те атрибуты, значение которых следует обновить или добавить в таблицу IMBASE.
Для завершения импорта необходимо нажат кнопку .

# Удаление версий объектов из контекста
Для удаления версий объектов из контекста редактирования требуется открыть окно с редактором контекста, затем выделить в нем удаляемые версии объектов, и нажать кнопку **Удалить из контекста**.
В появившемся окне требуется подтвердить намерение удалить указанные версии объектов:
После нажатия на кнопку **Да** указанные версии объектов будут удалены из контекста редактирования.
Чтобы внести изменения в контекст редактирования, требуется нажато кнопку **ОК**.

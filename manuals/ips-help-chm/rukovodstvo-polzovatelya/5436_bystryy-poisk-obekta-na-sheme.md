# Быстрый поиск объекта на схеме
Для того, чтобы найти объект на схеме следует нажать кнопку на панели инструментов визуализатора. 
Поиск производится по заголовку объекта. Если объект найден на схеме, то он подсветится в качестве активного элемента. Если объектов с похожими заголовками несколько, повторное нажатие кнопки **Найти** будет выбирать все такие объекты один за одним. Включите переключатель **С учетом регистра** , если нужно искать заголовки объектов именно с указанным регистром букв.

# Сортамент
Ветвь **Сортамент** предназначена для выбора сортамента и вида материала. Средняя панель закладки **Сортамент** содержит список марок материала. В правой панели окна **Типоразмеры** раскрывается таблица размеров выбранного материала. Внизу формируется условное обозначение сортамента.

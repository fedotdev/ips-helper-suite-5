# Удаление объекта из проекта
При необходимости исключить добавленный объект из проекта следует: 
1\. В открытом проекте выбрать из списка объект и открыть панель с дополнительным видом с помощью кнопки .
2\. На открывшейся панели выбрать закладку **Свойства** и нажать кнопку **Все группы атрибутов**.
3\. В поле **Принадлежность проекту** выделить название проекта и нажать клавишу **[Delete]**.
4\. Для сохранения изменений следует нажать кнопку .

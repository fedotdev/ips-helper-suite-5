# Включение в извещение внешнего документа
Редактор извещений позволяет включать в извещение не только объекты базы данных IPS, но и документы, не зарегистрированные в базе данных. Чтобы включить в извещение внешний документ, выполните следующие действия:
· Примените команду **Извещение / Включить внешний документ** главного меню редактора или команду **Включить в извещение / Внешний документ** контекстного меню графы **Содержание изменения**.
· В результате этих действий в бланке извещения появится новая строка, в которую с помощью ввода с клавиатуры можно внести обозначение внешнего документа.

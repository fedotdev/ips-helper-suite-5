# Команда Запустить процесс на основе черновика
При запуске процесса, пользователь имеет возможность на любом шаге сохранить информацию из текущего мастера в отдельный объект типа **Черновики**. Сохраненные объекты отображаются в почте в узле **Черновики**(см. п. ). 
Для сохранения объектов типа **Черновики** следует вызвать мастер запуска процесса (см. п. ), а далее пользователь имеет возможность сохранения информации в зависимости от шагов заполнения информацией процесса:
1\. При нажатии кнопки на первом шаге, где заполнены поля **Название** , **Сообщение** и **Приоритет** , то в папке **Черновики** сохранится процесс только с перечисленными выше полями.
2\. При нажатии кнопки на втором шаге, где пользователь добавляет объект во вкладку **Вложения** – в папке **Черновики** сохраняется информация описанная в п.1. и вложенный объект и т.д..
Примечание: идентификаторы прикрепленных вложений сохраняются в атрибут **Добавленные вложения** объекта типа **Черновик**.
Для того чтобы запустить сохраненный процесс из папки **Черновики** , следует выбрать его из списка и из контекстного меню вызвать команду **Запустить процесс на основе черновика**.
Примечание: ссылка на шаблон процесса, по которому будет запускаться бизнес процесс, сохраняется в атрибуте **Родительский шаблон**.
Примечание: значения переменных с формы мастера запуска процесса сохраняются в атрибуте **Переменные**.

# Удаление атрибутов
В зависимости от настроек конфигуратора, атрибуты типа объектов могут быть обязательными или необязательными. Обязательные атрибуты присутствуют всегда, и пользователь не может их удалить. Необязательные атрибуты могут быть удалены по желанию пользователя. 
Существует несколько способов удаления атрибутов, описание которых представлено ниже.

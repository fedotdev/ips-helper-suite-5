# Формы отчетов
Форма отчетов представляет собой основу документа, в которой заранее определены заголовок отчета, колонки, которые будут отображаться в отчете, шаблон документа и другие параметры. Пользователю достаточно указать форму для какого-либо множества объектов, чтобы на ее основании был сформирован отчет по выбранным объектам.

# Команды вывода штампа
При загруженном модуле расширения **Intermech.Stamp.Client dll** в контекстном меню объекта автоматически добавляются следующие команды: 
Команда **Смотреть со штампом** позволяет открыть аутентичный файл с отображением штампа, но не сохраняет штамп в файле.
Команда **Сохранить со штампом** позволяет сохранить аутентичный файл со штампом. 
**Внимание!** При новом формировании аутентичного файла штамп необходимо сохранять заново.
Для того что применить штамп к документ следует:
1\. Выбрать в дереве **Навигатора** тип объекта, к которому следует применить штамп.
2\. В рабочей области Навигатора выбрать необходимый документ и убедится, что объект имеет аутентичный фал.
Примечание: если объект не имеет аутентичного файла, то его следует сформировать. Подробное описание представлено в п. .
3\. Далее из контекстного меню объекта следует выбрать команду **Аутентичные файлы \** **Смотреть со штампом**.
4\. В открывшемся окне следует выбрать необходимый для применения штамп, а затем указать какие графы выводить для подписи, при условии, что штамп с подписями.
5\. Для перехода к просмотру необходимо нажать кнопку .
Для просмотра откроется аутентичный файл со штампом.
Примечание: при необходимости сохранения аутентичного файла со штампом следует применить команду **Сохранить со штампом**.

# Изменить по маске
Пользователь может изменять значения строковых атрибутов, для это необходимо вызвать команду **Атрибуты \ Изменить по маске**.
Для корректной работы редактора по изменению строковых атрибутов следует предварительно взять на редактирование необходимые объекты. Взятые на изменение объекты подсвечены голубым цветом. 
**Внимание!** Если объект не взят на редактирование, то для него ряд функционала будет недоступен.

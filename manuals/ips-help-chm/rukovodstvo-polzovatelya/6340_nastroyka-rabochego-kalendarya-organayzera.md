# Настройка рабочего календаря органайзера
Настройка **Рабочий календарь** позволяет выбрать необходимый календарь для отображения его в органайзере. По умолчанию назначен стандартный календарь.
**Внимание!** Для корректной работы всех возможностей органайзер, следует устанавливать рабочий календарь пользователя.

# Команда Состав по прототипу
_Примечание: команда**Создать/Состав по прототипу** (далее **Состав по прототипу**) доступна при условии, что загружен модуль расширения **Управление информацией об изделиях PDM**._
Система IPS предоставляет возможность ускоренного процесса создания объектов, используя значения атрибутов и состав уже существующих объектов. Данный процесс реализуем при использовании одной из доступных команд **Создать/По прототипу** (далее **По прототипу**) или **Состав по прототипу**. Команда **По прототипу** позволяет создать только выбранный объект с его составом, не меняя и не копируя входящие в состав объекты, подробное описание работы данной команды представлено в п. . Команда **Состав по прототипу** имеет принципиальную разницу от команды **По прототипу** , она осуществляет прототипирование не только родительского объекта, но и его электронной структуры, что позволяет реализовать групповое изменение строковых атрибутов. Команда **Состав по прототипу** имеет расширенные технические возможности для ускорения процесса создания нового изделия или сборочной единицы, взяв за основу уже готовый объект. 
**Внимание!** Копирование объекта типа СЕ посредством команды **Состав по прототипу** сопровождается копированием состава сборочных единиц, которые присутствуют в объекте, однако следует помнить, что данная возможность не распространяется на копирование конструкторско-технологической документации.

# Ручная выборка
В ручную выборку попадают объекты, которые пользователь самостоятельно выбирает из определенного множества объектов, путем выделения их из списка и помещения в ручную выборку. Состав ручной выборки остается неизменным. Таким образом, пользователь всегда может увидеть отобранные им объекты, открыв ручную выборку. Для ручных выборок пользователь также может задавать условия. В данном случае условия будут применяться только к объектам, находящимся внутри созданной ручной выборки. Чаще всего ручные выборки принадлежат типам объектов, однако свойство ручной выборки может быть задано и контекстной выборке, и выборке-фильтру. В этом случае отбор объектов будет производиться из числа объектов, отобранных вручную для этих выборок.
В процессе использования выборки способ отбора данных в ней можно изменить. Для этого необходимо включить/выключить переключатель **Ручная выборка** в карточке выборки на закладке **Выборка**.

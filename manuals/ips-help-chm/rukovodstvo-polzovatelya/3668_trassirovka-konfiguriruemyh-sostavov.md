# Трассировка конфигурируемых составов
Система IPS имеет возможность генерировать отчет (трассировку) о том, какие объекты в составе были подобраны конфигуратором, а какие объекты были отмечены как ошибочные. Для этих целей используется отдельная закладка, доступная по команде главного меню **Состав/Трассировка конфигурируемого состава:**
Данную закладку можно разместить как поверх окон клиентского приложения, так и пристыковать к любому из них.
Для проверки следует открыть состав в окне **Навигатора** , выбрать в дереве объект, начиная с которого будет выполняться трассировка, а затем нажать кнопку **Выполнить запрос** в указанной закладке. Кнопка изменит свой вид на **Отменить запрос** (позволяет остановить трассировку состава), при этом начнется выполнение задачи по трассировке указанного состава. Задача может выполняться длительное время, в зависимости от сложности трассируемого состава.
После выполнения трассировки данная закладка будет заполнена отчетом:
Переключатели **Ошибки** и **Трассировка** позволяют отфильтровать содержимое отчета. **Трассировка** показывает информацию о тех объектах, которые были успешно подобраны конфигуратором, **Ошибка** – о тех объектах, при подборе которых возникли ошибки.

Для очистки отчета следует нажать кнопку **Очистить трассировку**.

# Добавление атрибутов шаблона
Также пользователь имеет возможность добавить атрибуты шаблона, где в качестве шаблона может выступать одна из существующих таблиц системы. В этом случае, атрибуты, назначенные для выбранной в качестве шаблона таблицы, и их свойства, скопируются в создаваемую таблицу.
Чтобы выбрать атрибуты шаблона, выполните следующие действия:
1\. Нажмите кнопку **Шаблон** , вызывающую диалог выбора.
2\. В появившемся диалоге выберите таблицу, которая будет использоваться в качестве шаблона и нажмите **ОК**.
3\. В появившемся диалоге отображаются все атрибуты, назначенные выбранной в качестве шаблона таблицы. При желании пользователь может отключиться те атрибуты, которые не требуется назначать новой таблице (пользователь не может отключить атрибуты, которые принимают участие в расчетных формулах).
4\. Нажмите **ОК**.

# Настройки редактора ЭСТ
Для того чтобы настроить **Редактор ЭСТ** следует перейти по пути **Параметры IPS \ Система \ Настройки редактора ЭСТ** :
· **Место, куда будут добавлены символы при формировании обозначения ЭСТ.** Данный параметр позволяет установить расположение дополнительно назначенных символов в обозначении ЭСТ. Символы следует вводить в параметре **Символы, которые будут добавлены при формировании обозначения ЭСТ**. Например, при настройках, показанных на рисунке выше обозначение ЭСТ будет равно Т<Обозначение СБЕ>.
· **Разрешать включать в состав большее количество ДСЕ.** Данный параметр позволяет добавлять количество объектов в ЭСТ больше, чем общее количество данных объектов в КЭСИ (см. п. подпункт 6 в алгоритме создания ЭСТ).
· **Символы, которые будут добавлены при формировании обозначения ЭСТ.** В данном параметре указываются символы, которые будут добавлены к обозначению ДСЕ при формировании обозначения ЭСТ. Месторасположение добавляемых символов определяется настройкой **Место, куда будут добавлены символы при формировании ЭСТ**.

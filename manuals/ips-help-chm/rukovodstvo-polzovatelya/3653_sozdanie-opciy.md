# Создание опций
Создать новую опцию можно с помощью команды **Файл / Создать / Новый объект …**. При этом будет отображено окно мастера по созданию новых объектов:
Следует указать название опции (уникальное среди всех объектов данного типа), а также выбрать тип данных значений опции. Остальные поля заполняются по желанию. После нажатия кнопки **Готово** будет создана новая опция.

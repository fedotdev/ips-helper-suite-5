# Прикрепление файла к объекту
Примечание: в данном пункте описана процесс формирования аутентичных файлов для КД.
1\. В дереве состава объекта выделить спецификацию и с помощью контекстного меню вызвать подкоманду **Сформировать** в команде **Аутентичные файлы.**
2\. В открывшемся диалоговом окне следует указать путь в строке поиска, где расположен конвертированный файл, затем его выбрать и с помощью кнопки прикрепить к объекту.

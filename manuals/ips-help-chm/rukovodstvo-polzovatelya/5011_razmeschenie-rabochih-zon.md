# Размещение рабочих зон
По умолчанию рабочие зоны диалога **Настройка допустимых замен** имеют горизонтальное расположение. При необходимости пользователь может изменить положение рабочих зон в диалоге. Для этого необходимо потянуть рабочую зону за ее заголовок в сторону. При этом на экране появится пиктограмма с указателями, предлагающими поместить ее в то или иное место рабочего пространства. 
Совместите удерживаемый указателем мыши заголовок с одним из этих указателей, и рабочая зона закрепится в указанной стороне. Для удобного восприятия информации используйте возможность изменять размеры рабочих зон, регулируя курсором мыши их смежные границы. 
Перетянув с помощью указателя мыши заголовок одной рабочей зоны к другой, они будут отображаться в виде закладок, что позволит существенно увеличить пространство отображаемой информации каждой из рабочих зон.

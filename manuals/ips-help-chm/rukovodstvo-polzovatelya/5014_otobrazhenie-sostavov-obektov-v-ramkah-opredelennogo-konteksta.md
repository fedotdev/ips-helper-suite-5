# Отображение составов объектов в рамках определенного контекста
Чтобы отобразить состав объекта в рамках определенного контекста, необходимо включить специальный режим с помощью команды панели инструментов **Фильтрация состава** , которая вызывает диалог выбора контекста.
С помощью переключателей диалога пользователь может выбрать контекст отображаемого состава, в результате чего, объекты, имеющие другие контексты, будут скрыты из состава объекта. Указанный режим отображения объектов будет являться общим для всех составов, т.е. при переходе к другим составам объектов, пользователь будет видеть только те объекты состава, контексты которых соответствуют указанным в диалоге.

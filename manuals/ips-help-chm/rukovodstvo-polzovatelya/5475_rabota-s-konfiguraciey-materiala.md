# Работа с конфигурацией материала
Раздел **Лакокрасочные материалы** дополнен полем **Конфигурация**. В поле расположены строки с условиями, значения для которых можно выбрать из выпадающего списка. Сконфигурированный материал добавляется не только в список материалов марочника, но и в таблицу IMBASE.
Для управления конфигурацией следует:
1\. Выбрать материал из списка и перейти в поле **Конфигурация**.
2\. Для каждого условия следует выбрать необходимое значение из выпадающего списка.
3\. Для завершения создания конфигурации материала следует нажать кнопку .

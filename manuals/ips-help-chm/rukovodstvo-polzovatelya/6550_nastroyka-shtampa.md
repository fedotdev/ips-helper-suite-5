# Настройка штампа
**Внимание!** Создание и настройка шаблонов штампа доступна только пользователя с правами администратора.
Объекты типа **Штамп** находятся по пути **Навигатор \ Объекты \ Настройки системы \ Штампы документа.**
Для создания объекта типа **Штамп** следует перейти по указанному выше пути и в рабочей области **Навигатора** вызвать из контекстного меню команду **Создать**.
Далее по тексту будут представлены примеры и описания настроек всех возможных типов штампом.

# Настройки автоматической классификации
**Внимание!** Описанная ниже команда доступна только для пользователей с правами администратора.
**Настройки автоматической классификации** – команда, которая позволяет указать ветки конкретных классификаторов для конкретных типов объектов, по которым автоматически следует осуществлять классификацию.
Вид окна **Настройки автоматической классификации** показан ниже на рисунке:
 – кнопка, которая позволяет открыть окно выбора типа объекта или классификатора.
Примечание: в полое **Классификаторы** кнопка доступна только если выбран тип объекта.
 – кнопка, которая позволяет удалить выбранный тип объекта или классификатор.
 – кнопка, которая позволяет выбрать другой классификатор вместо добавленного.
 – кнопка, которая позволяет открыть карточку выбранного объекта.
Для того чтобы настроить автоматическую классификацию следует:
1\. На главной панели системы IPS выбрать меню **Настройка**.
2\. Из выпадающего списка выбрать команду **Настройки автоматической классификации**.
3\. В открывшемся диалоговом окне **Настройка автоматической классификации создаваемых объектов** следует указать типы объектов и папку классификатора.
**Внимание!** Для настройки автоматической классификации следует использовать только **Общие классификаторы**.

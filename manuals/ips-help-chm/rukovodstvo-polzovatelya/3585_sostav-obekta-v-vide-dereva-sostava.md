# Состав объекта в виде дерева состава
Состав любого объекта можно просмотреть в виде иерархического дерева, открыв объект в новом окне. Для этого необходимо отметить объект в списке объектов и применить команду **Открыть в новом окне** его контекстного меню или комбинацию клавиш **[Ctrl+Enter]**.

# Конфигуратор составов объектов
Примечание: данная функциональность будет доступна в том случае, если загружен модуль расширения **Управление информацией об изделиях PDM**.
Система IPS позволяет пользователям гибко управлять составами и комплектациями объектов с помощью Конфигуратора составов. Рассмотрим основные понятия конфигуратора.

# Настройки Цвет и толщина линий для DWG
Пользователь системы IPS может настроить цвет и толщина линий для DWG по своему желанию.
Чтобы осуществить эти настройки, необходимо выполнить ряд действий:
· С помощью пункта главного меню **Настройка / Параметры IPS** вызовите диалог **Параметры**.
· В левой части диалога **Параметры** выберите **Система /_Цвет и толщина линий для DWG_**. 
· В правой части диалога будут установлены цвета которые были использованы при просмотре DWG-файлов за весь сеанс работы системы IPS.
· для нужного цвета можно указать толщину черной линии в миллиметрах.
· Кнопка Изменить цвета на черный переключает кнопку из состояния цветной  на состояние черный в закладке**Просмотр**.

# Список задач
Список задач импорта и экспорта можно просмотреть в навигаторе, выбрав элемент дерева навигации **Задачи синхронизации с IPS Web Portal**. 
В этом окне можно просмотреть свойства задач:
1\. **Тип задачи синхронизации** :
· Импорт обновлений – задача формируется во время запроса обновлений у портала.
· Импорт опубликованных объектов – задача формируется пользователем для импорта каких-либо опубликованных объектов. 
· Публикация – задача формируется пользователем при публикации объекта.
· Публикация информации по процессу – задача формируется автоматически при запуске удаленного подпроцесса или возврата из него.
· Публикация задачи ImProject – задача формируется при запуске задачи ImProject.
2\. **Статус задачи** :
· Успешно выполнена.
· Прервана пользователем.
· Ошибка во время выполнения.
· В работе.
· В ожидании.
· Формируется.
· Применение изменений на узле.
· Применение изменений на портале. 
· Удаление временных данных задачи на портале.
3\. **Процент выполнения**.
4\. **Подробное описание**. Если в результате выполнения задачи произошла ошибка, то статус задачи будет установлен в **Ошибка во время выполнения** , а в атрибуте **Подробное описание** будет находиться информация об ошибке.
5\. **Приоритет**. 
6\. **Порядковый номер**. Автоматически формируется при добавлении задачи в список. Это свойство может быть изменено вручную для сортировки списка до запуска потока, обрабатывающего задачи.
Задачи типа **Импорт обновлений** и **Публикация** могут запускаться вручную, отдельно от всей очереди задач. Для этого необходимо на выбранной задаче выполнить команду контекстного меню **Запустить задачу на выполнение**.
Пользователю доступна команда **Состав задачи** , вызванная из контекстного меню задачи синхронизации с IPS WebPortal, данная команда позволяет отобразить краткую информацию о составе задачи. На рисунке ниже показано окно с информацией о составе задачи.

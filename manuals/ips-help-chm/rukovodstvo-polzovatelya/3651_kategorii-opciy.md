# Категории опций
**Категория опций** – это объект, объединяющий опции в логические группы. Каждая опция принадлежит какой-либо категории. Если для опции не требуется категория, то её следует размещать в системной категории **Нет категории**. Список категорий можно получить, открыв узел **Информационное пространство/Объекты/Объекты конфигуратора составов/Категории опций** в дереве **Навигатора** :

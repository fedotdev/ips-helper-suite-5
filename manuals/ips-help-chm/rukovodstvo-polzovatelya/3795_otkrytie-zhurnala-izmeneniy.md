# Открытие журнала изменений
**Журналы изменений** – это документы, поэтому в дереве объектов Навигатора они находятся по пути **Документы/Журналы изменений**. Для открытия журнала изменений достаточно дважды щелкнуть на нужном журнале или выполнить команду контекстного меню **Редактировать**.
Можно также открыть журнал изменений, находясь на любой его записи, используя команду контекстного меню **Открыть журнал изменений**. Записи **ЖИ** находятся по пути **Контексты редактирования/Записи журнала изменений**.

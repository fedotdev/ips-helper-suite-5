# Создание ТЭСИ
Примечание: данная команда доступна при условии, что загружен модуль расширения **Управление информацией об изделиях PDM** и**Редактор технологической ЭСИ.** Если модуль расширения**Редактор технологической ЭСИ** выключен, то программа будет работать в режиме создания**ТСЕ** (см. п. )**.**
Начиная с IPS6 появилась возможность создавать технологическую электронную структуру изделия (далее ТЭСИ) на основе конструкторской электронной структуры изделия (далее КЭСИ).
Ниже представлены основные отличия ТЭСИ от ТСЕ:
· ТЭСИ и КЭСИ это разные электронные документы, однако ТСЕ с КЭСИ объединены в один объект и переход между ними осуществляется посредством выбора соответствующего контекста состава. 
· С помощью электронной подписи объекты ТЭСИ можно подписывать, а для объектов ТСЕ и КЭСИ не представляется такой возможности.
· Для ТСЕ и КЭСИ нет возможности зафиксировать состав, например, переводом её на шаг ЖЦ, запрещающим редактирование, а для объектов ТЭСИ эта возможность присутствует.
· Для ТСЕ и КЭСИ нет возможности выпуска версии, а для объектов ТЭСИ это доступно.
· Объекты ТЭСИ могут содержать технологические подсборки.
Для создания ТЭСИ следует: 
1\. Открыть сборочную единицу в новом окне, на которую необходимо создать ТЭСИ, и из контекстного меню вызвать команду **Создать** /**ТЭСИ**.
2\. В появившемся диалоговом окне внести необходимые сведения о создаваемом объекте.
По умолчанию ТЭСИ присваивает обозначение КЭСИ с добавлением вначале буквы **«Т»**. Наименование ТЭСИ совпадает с наименованием КЭСИ.
3\. Затем следует нажать кнопку . В результате создается объект ТЭСИ, который включен в состав КЭСИ типом связи **Связь с технологической ЭСИ.**
4\. В открывшемся окне **Редактор ТЭСИ** следует сформировать состав объекта ТЭСИ.
5\. Посредством команды контекстного меню **Добавить в ТЭСИ** или кнопки следует переместить необходимый объекты из КЭСИ в ТЭСИ. 
Примечание: добавить объект в состав ТЭСИ можно с помощью обычного перетаскивания объекта, однако следует помнить, что перетаскивание сработает при определенном положении мыши. На рисунке ниже подробно показано данное положение:

6\. В открывшемся окне **Задание количества…** следует указать количество объектов, добавляемых в ТЭСИ, и нажать кнопку .
Примечание: с помощью кнопки **Все количество** , в ТЭСИ перенесется общее количество объектов.
После добавления объекта в ТЭСИ, значение атрибута **Оставшееся количество** в КЭСИ изменится.
**Внимание!** Следует понимать, что при наличии одного и того же объекта в сборке и подсборке, либо в разных подсборках КЭСИ, система добавляет количество объектов из общего числа объектов в КЭСИ, а не из определенной сборки (подсборки), поэтому объект в КЭСИ остается доступным для добавления во всех подсборках, до тех пор пока оставшееся количество будет более либо равно **1**.
Для возможности добавления количества объектов в ТЭСИ большим, чем общее количество данных объектов в КЭСИ в настройках **Параметры IPS / Система / Настройки редактора ТЭСИ / Разрешать включать в состав ТЭСИ большее количество ДСЕ** должно быть установлено значение – **Да**.
7\. При необходимости исключить выделенный объекта из ТЭСИ следует воспользоваться командой контекстного меню **Удалить из ТЭСИ** либо кнопкой .

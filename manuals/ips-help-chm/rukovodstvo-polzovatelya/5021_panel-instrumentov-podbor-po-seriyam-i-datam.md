# Панель инструментов Подбор по сериям и датам
Панель инструментов содержит следующие элементы управления:
· Поле для выбора головного изделия (с историей ранее выбранных значений).
· Поле для выбора серии (с историей ранее выбранных серий).
· Поле для указания даты (с историей ранее указанных дат).
· Кнопка включения/отключения подбора по сериям/датам.
· Кнопка применения изменённых настроек фильтрации составов.
Указанные настройки являются зависимыми от окон (у каждого окна может быть своя настройка).
Кнопка выбора головного изделия открывает диалоговое окно, в котором можно выбрать головное изделие, в рамках которого будет осуществляться подбор версий изделий по сериям и датам:
Кнопка выбора даты открывает специальное окно, в котором можно выбирать дату, на которую требуется подбирать изделия в составе:
После заполнения требуемыми исходными данными можно включить фильтрацию по сериям/датам нажатием кнопки **Включить подбор по сериям/датам**. Когда кнопка нажата, осуществляется фильтрация составов, отображаемых в данном окне, по сериям/датам. Если одновременно указаны и серия, и дата, то приоритетным является подбор по серии.
Следует обратить внимание на кнопку **Применить** , которая появляется на панели подбора по сериям при включенной фильтрации. Она используется в тех случаях, когда при включенной фильтрации по сериям/датам вносятся изменения в условия фильтрации в текстовых редакторах серии и даты. При выборе элементов из выпадающих списков условия фильтрации изменяются автоматически, нажимать указанную кнопку не требуется.

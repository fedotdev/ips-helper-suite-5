# Работа ссылок
При работе с документацией пользователю предоставлена возможность создавать ссылки на объекты из системы IPS. 
Для добавления ссылки в документ следует:
1\. Взять на редактирование необходимый документ и открыть его.
2\. Установить курсор на место где должна быть ссылка на объект из системы IPS.
3\. Выбрать команду **Вставить гиперссылку**.
4\. В открывшемся диалоговом окне **Гиперссылка** , выбрать меню **Интернет** и в строку **URL:** вставить ссылку [ips://object/-1322852](../../../../../../../../ips:/object/-1322852).
Где, 
· [ips://object/](../../../../../../../../ips:/object/) – это служебная информация, которая неизменна для всех ссылок;
· -1322852 – это идентификатор версии объекта в IPS, который указывает на конкретный объект.
5\. Для завершения создания ссылки необходимо нажать на копку , а затем на кнопку .
6\. Для синхронизации созданной ссылки с системой IPS, документ следует сохранить и перезапустить.

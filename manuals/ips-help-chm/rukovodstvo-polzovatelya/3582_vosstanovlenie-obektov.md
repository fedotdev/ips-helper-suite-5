# Восстановление объектов
Восстановление объектов выполняется с помощью команды контекстного меню **Восстановить**. Команда видна в том случае, если версия объекта находится на уровне продвижения **Удалено**. По этой команде объект будет переведен на шаг ЖЦ, который допускает схема ЖЦ для данного типа объектов. Если в числе допустимых шагов ЖЦ будет находиться первый шаг схемы ЖЦ, то объект будет переведен на него.

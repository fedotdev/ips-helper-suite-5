# Редактор кнопок
Панель инструментов редактора состава позволяет добавлять/изменять/удалять дополнительные кнопки. Для вызова редактора воспользуйтесь кнопкой **Настроить кнопки** либо аналогичной командой контекстного меню панели инструментов.
После вызова команды будет отображено окно редактора кнопок, в котором можно создавать новые кнопки, изменять существующие, перемещать их по списку вверх/вниз, а также удалять:

# Работа с конфигурациями
Назначенные и настроенные параметры импорта можно сохранять в виде конфигураций и использовать при следующем импорте. Конфигурации бывают двух типов:
· **Общие** – это конфигурации, которые могут создавать только пользователи с правами администратора. Общие конфигурации видны всем пользователям.
· **Персональные** – это конфигурации, которые может создать любой пользователь для личного использования при работе с импортом MS Excel. 
**Примечание:** персональные конфигурации видны только их создателям.

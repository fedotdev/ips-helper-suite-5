# Временное скрытие состава объекта
Примечание: данная функциональность будет доступна в том случае, если загружен модуль расширения **Управление информацией об изделиях PDM**.
Объекты базы данных могут иметь очень сложный и громоздкий состав, что затрудняет работу пользователя с ними и замедляет работу системы при считывании информации. Система IPS предоставляет пользователю возможность временно исключать не интересующие его объекты из состава рассматриваемого объекта.

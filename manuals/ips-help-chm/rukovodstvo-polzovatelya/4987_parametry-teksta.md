# Параметры текста
Кнопка позволяет задать жирный шрифт для выделенного текста. Этот текст обрамляется тегами жирного текста **[b]** …**[/b]**. Если текст не был выделен, появятся только теги, между которыми можно будет ввести новый текст. Весь текст, расположенный между открывающим и закрывающим тегами, будет жирным. Аналогично, кнопка задает курсив (теги **[i]** …**[/i]**), кнопка – подчеркивание (теги **[u]** …**[/u]**), а кнопка – перечеркивание (теги **[s]** …**[/s]**). Теги можно удалять, если форматирование текста больше не требуется.
Кнопка позволяет задать цвет текста. При ее нажатии вы сможете выбрать нужный цвет, который будет записан в теге и впоследствии использован для прорисовки текста. Например, красный цвет текста будет определяться тегами **[color:Red]** … **[/color]**. Весь текст, расположенный между тегами, будет красным. Цвет фона текста задается кнопкой . Например, желтый фон текста задается такими тегами: **[background-color:Yellow]** … **[/background-color]**. Выпадающий список справа от этой кнопки позволяет определить размер шрифта: выберите нужный размер в списке, и выделенный текст будет обрамлен соответствующими тегами. Например, для шрифта размером 12 пунктов появятся теги **[font-size:12]** …**[/font-size]**.
Опции форматирования текста можно комбинировать друг с другом – для этого достаточно обеспечить, чтобы теги были вложенными. Например, комбинация **[b][i]** …**[/i][/b]** задает жирный курсив.

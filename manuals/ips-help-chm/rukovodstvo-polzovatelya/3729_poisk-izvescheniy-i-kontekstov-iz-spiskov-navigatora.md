# Поиск извещений и контекстов из списков Навигатора
Выберите в списке **Навигатора** информационный объект (или несколько объектов), откройте вложенные закладки с помощью кнопки и найдите в списке закладок закладку **Извещения и контексты** :
Рассмотрим подробно работу с закладкой **Извещения и контексты**.

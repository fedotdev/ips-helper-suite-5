# Команды Конкретизация / Абстрагирование для головного изделия
Чтобы конкретизировать версии объектов, входящих в состав открытого изделия, следует:
1\. Головное изделие открыть в режиме редактирования.
2\. Из контекстного меню выбрать команду **Конкретизация** , а затем подкоманду **Включить автоконкретизацию состава**.
3\. Система выдаст сообщение о выполненной работе, для завершения конкретизации необходимо нажать кнопку .
Статус мягкой конкретизации будет отображен в колонке **Статусы** , данную колонку можно настроить с помощью команды **Настройки отображения**.
Термин абстрагирование означает удаление у связей конкретизации версий дочерних объектов.
Для отключения автоконкретизации следует выбрать из контекстного меню команду **Абстрагирование** , а затем подкоманду **Выключить автоконкретизацию состава**.
**Внимание!** Подкоманды **Включить автоконкретизацию состава** или **Выключить автоконкретизацию состава** работают только с первым уровнем состава головного изделия.

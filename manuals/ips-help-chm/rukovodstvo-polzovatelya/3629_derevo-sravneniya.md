# Дерево сравнения
**Дерево сравнения** – эта команда системы IPS предназначена для сравнения составов разных версий одного объекта, или двух разных объектов одного типа. Команда запускает механизм сравнения, в котором все изменения в составах сравниваемых объектов будут отмечены соответствующими цветовыми элементами. Команда **Дерево сравнения** позволяет оперативно анализировать составы выбранных объектов. Для получения результата сравнения объектов, необходимо применить правило сравнения составов. Описание процесса создания правила представлено в п. .
Примечание: команда **Дерево сравнения** позволяет сравнить составы таких объектов, как сборочная единица, технологический процесс и т.п.
Для работы с командой **Дерево сравнения** необходимо выделить два объекта и вызвать команду **Состав объекта/Дерево сравнения** (далее **Дерево сравнения**) так, как показано на рисунке ниже:

Окно команды **Дерево сравнения** имеет две рабочие области, в которых находятся сравниваемые объекты и их составы, при необходимости можно включить режим просмотра развернутого состава в виде дерева для каждого объекта. Позиции, в составе которых были созданы изменения, будут отмечены соответствующей иконкой, а сами изменения выделены должным цветом. 
При включении режима отображения панели с атрибутами, под рабочими областями появляются панели со списком атрибутов объектов и их значениями.
**Внимание!** Рабочая область, расположенная слева, по умолчанию отображает состав эталонного объекта. 
Примечание: при сравнении версий одного объекта по умолчанию система IPS считает эталонной версию с меньшим номером или является архивной копией, при условии, что сравниваются архивная и рабочая копии одного объекта. При необходимости, пользователь может поменять местами сравниваемые объекты с помощью нажатия кнопки , расположенной на панели инструментов.

Примечание: в зависимости от типа сравниваемых объектов список правил будет автоматически корректироваться.
**_Группа кнопок, которые позволяют управлять процессом сравнения составов:_**
 – кнопка **Редактировать правило** позволяет изменить параметры выбранного из списка правила сравнения составов.
Примечание: системное правило **Сравнение составов по умолчанию** недоступно для редактирования.
 – кнопка **Новое правило сравнения** позволяет открыть диалоговое окно **Создание нового объекта** и сформировать в нем правило сравнения составов, которое необходимо для запуска процесса сравнения выбранных объектов.
Примечание: расположенные на панели команды **Редактировать правило** и **Новое правило сравнения** доступны пользователю, вошедшему в систему IPS под любой ролью.
 – кнопка **Обновить список правил** позволяет обновить список созданных правил.
 – кнопка **Генерировать отчет** позволяет сформировать отчет с результатами сравнения по шаблону выбранного сценария.
 – кнопка запускает механизм сравнения составов двух объектов.
 – кнопка **Развернутый состав** позволяет отобразить дерево состава сравниваемых объектов.
 – кнопка **Поменять местами сравниваемые объекты** позволяет изменить выбор эталонного объекта.
**_Группа кнопок, которые позволяют управлять списком атрибутов объектов:_**
 – кнопка **Отобразить панели с атрибутами** позволяет открыть панели со списком атрибутов объектов.
 – кнопка **Зачитывать все атрибуты объектов и связей** позволяет расширить список атрибутов на открывшейся панели, включив отображения скрытых и системных атрибутов. 
 – кнопка **Сортировка атрибутов в алфавитном порядке, помеченные цветом атрибуты в начале списка** позволяет автоматически отсортировать список атрибутов в дополнительном окне в алфавитном порядке. Однако измененные атрибуты, значение которых отличны друг от друга, будут находиться в начале списка.
 – кнопка **Сортировка атрибутов в алфавитном порядке** автоматически сортирует список атрибутов в дополнительном окне в алфавитном порядке.

Механизм сравнения зависит от настроенных параметров в правиле сравнения состава. Поэтому очень важно знать и понимать, как работают правила.

# Настройка фильтрации
Например, необходимо создать фильтрацию состава изделия по маршрутам обработки во всех дочерних объектах.
Для корректного использования созданного фильтра следует настроить его по условиям фильтрации, для этого следует:
1\. На закладке **Редактор фильтра состава по типам объектов** в области **Родительские типы объектов** нажать кнопку .
2\. В открывшемся окне **Выберите объекты** следует развернуть **Список объектов** и выбрать те, которые необходимы для работы, а затем нажать на кнопку .
**Внимание!** В составе изделия находятся детали и т.д., поэтому, для того чтобы скрыть из состава все МО следует выбрать их тоже.
3\. В области **Скрываемые дочерние типы объектов** необходимо выбрать объект МО и нажать кнопку .
4\. Для завершения настройки фильтра следует нажать на кнопку .
**Внимание!** Один фильтр может одновременно скрывать несколько дочерних объектов в составе родительского изделия, для этого следует дополнительно выбрать скрываемые дочерние типы объектов.
**Внимание!** Не следует настраивать в одном фильтре одновременно скрытие по типам объектов и по типам связей, применение такого фильтра может привести к не желаемому результату.
Настройка фильтрации по типам связей аналогична настройке фильтрации по типам объектов.

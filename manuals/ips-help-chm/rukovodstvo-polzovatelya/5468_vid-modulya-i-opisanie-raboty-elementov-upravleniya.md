# Вид модуля и описание работы элементов управления
Модуль **Марочник материалов** имеет схожую архитектуру с **Навигатором** , в навигационном окне представлены все разделы марочника, а в рабочей области – основные данные и технические свойства материала. 
Общий вид модуля показан на рисунке ниже: 
В зависимости от выбранного раздела, информационное окно с закладками меняет свое название. Например, в разделе с клеями закладка имеет название **Клеи** и т.п. Рабочая закладка отображает перечень материалов и основные его свойства.
Закладка с основными данными имеет вид окна, разделенного на две области. Справа столбец с перечнем материала из выбранного раздела, а слева – таблица с основными техническими свойствами выбранного материала из раздела.
На закладке имеется панель с элементами управления, которые выполнят ряд команд. Кнопки дублируют значение команд контекстного меню, описание кнопок и команд представлено ниже: 
 **Склеиваемые материалы** – команда, которая позволяет назначить материалы, которые могут быть склеены выбранным клеем.
**Внимание!** Данная команда и кнопка доступны только для раздела **Клеи**.
 **Выбрать среди избранного** и **Добавить в избранное** – команды, которые позволяю сохранить и выбрать частоиспользуемые материалы.
**Внимание!** Для каждого раздела создается отдельный список избранных материалов.
 **Перейти к таблице IMBASE** – команда, с помощью которой осуществляется вызов таблиц **IMBASE** и последующий переход к строке с информацией о материале.
 **Поиск** – команда поиска необходимого материала по указанным параметрам.
 – кнопка сортировки списка материала в столбце по алфавиту. 
В нижней части поля с назначенными свойствами материалу расположены кнопки, предназначенные для коррекции свойств. Вид кнопок показан на рисунке ниже. 
Если материалу не назначены свойства и основные данные, то следует нажать кнопку и в открывшемся диалоговом окне выбрать необходимый объект из списка, который содержат описание свойств клея. Для завершения выбора объекта следует нажать кнопку .

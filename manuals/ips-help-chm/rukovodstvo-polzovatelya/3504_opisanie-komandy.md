# Описание команды
Для вызова команды **Состав по прототипу** следует выделить необходимый объект и с помощью контекстного меню выбрать команду **Создать/Состав по прототипу**.
Вызов команд сопровождается открытием диалогового окна **Состав по прототипу** , в котором поэтапно осуществляется копирование необходимого объекта. Первый этап – это выбор необходимых элементов, которые следует скопировать, для того чтобы создать новые объекты. Второй этап – это замена значений строковых, не вычисляемых атрибутов в списке создаваемых объектов. Обязательным для замены является – атрибут **Обозначение** однако и любой другой строковый атрибут доступен для замены, например, атрибут **Наименование**.
Выбор объектов, необходимых для копирования, осуществляется на закладке **Выбор копируемых объектов**. На рисунке ниже представлен вид диалогового окна с данной закладкой, на которой расположены команды. Все команды закладки служат для управления процессом поиска объектов и дальнейшего их копирования.
Дерево состава прототипируемого объекта отображено в правой части диалогового окна **Состав по прототипу**. Пользователю доступна возможность самостоятельно настроить панель с колонками строковых атрибутов, для отображения значений, по которым будет реализован дальнейший поиск необходимых для копирования объектов. Настройка отображения рабочей области описана в п. данного руководства.
Группа **Копирование элементов** имеет ряд элементов управления, с помощью которых осуществляется поиск и выбор объектов. Описание команд представлено ниже: 
· Строка для поиска объектов в дереве состава по значениям атрибутов, которые отображены на рабочей области.
· Кнопки для поиска и выделения найденных объектов:
− – кнопка, которая выделяет первый или следующий найденный объект по искомой строке.
− – кнопка, которая выделяет все объекты, удовлетворяющие введенному в поисковую строку значению.
· – команда, которая позволяет отметить или снять отметку **Копия** для всех элементов в составе сборочной единицы. 
При условии, что выбран элемент в составе сборочной единицы, то команда позволяет отметить или снять отметку **Копия** для выбранного элемента. 
· – команда, которая позволяет отметить или снять отметку Удалить для всех элементов в составе сборочной единицы или для выбранного элемента.

**Внимание!** Копирование по прототипу не доступно для прочих и стандартных изделий, а также для материалов. 
Для учета исполнений копируемого изделия предусмотрена специальная настройка **Копировать исполнения** , при включении которой в рабочей области редактора добавляется корневой узел **Исполнения**. В состав данного узла входят все исполнения выбранного изделия.
Заключительным этапом копирования изделия по прототипу является изменение значения атрибута **Обозначение** , при необходимости возможны замены любых строковых атрибутов. Данный процесс осуществляется на закладке **Изменения атрибутов** с помощью соответствующих команд.
Примечание: переход на заключительный этап формирование объектов осуществляется с помощью кнопки , расположенной внизу на панели диалогового окна **Состав по прототипу**.
**Внимание!** На данной закладке также доступна настройка отображения рабочей области.
Вид закладки **Изменения атрибутов** представлен на рисунке.
Область **Атрибут** предназначена для выбора строкового атрибута, который в дальнейшем будет изменен. С помощью выпадающего списка пользователю доступны строковые атрибуты, которые отображены на рабочей области со списком прототипируемых объектов.
Область **Найти в значении атрибута** необходима для ручного ввода маски поиска фрагмента атрибута. В строку вводится сочетание букв или спецсимволов, по которым выполняется поиск. Дополнительные команды **Учитывать регистр** и **Учитывать сходство букв кириллицы и латиницы** позволяют применить дополнительные ограничения для поиска необходимого значения.
При установке флажка напротив строки **Учитывать регистр** , включается режим, в котором поиск ведется с учетом регистра введенных букв.
При установке флажка напротив строки **Учитывать сходство букв кириллицы и латиницы** , включается режим поиска для букв имеющих одинаковое написание в кириллице и латинице, так образом поиск осуществляется сразу по обоим алфавитам.
Область **Заменить на** необходима для управления процессом замены найденного фрагмента на заданное, новое значение атрибута. Замена фрагмента осуществляется одним из доступных способов:
1\. Замена исходного значения на произвольное значение реализуется при выборе режима **Текст**. Все найденные фрагменты атрибута, заданные в области **Найти в значении атрибута** , будут заменены на значение введенное в строку ручного ввода.
Строка ручного ввода дополнена кнопкой , которая позволяет добавить в маску замены следующие макросы:
· **Счетчик [9999:0:1:1]** , где 9999 – разрядность счетчика, 0 – начальное значение, 1 – шаг, 1 – идентификатор счетчика (по умолчанию 1). Данный макрос позволяет добавить или заменить указанный фрагмент атрибута на значение счетчика.
**Внимание!** Для корректного использования счетчика следует выделить одновременно все необходимые объекты в списке изделий и нажать кнопку или воспользоваться кнопкой .
· **Текущее значение атрибута [N]** – макрос, который заменяет указанный фрагмент атрибута на текущее значение атрибута.
Примечание: нельзя править спецсимвол **Текущее значение атрибута[N]**.
2\. Замена исходного значения атрибута на значение любого другого строкового атрибута доступна в режиме **Значение атрибута**. Все найденные фрагменты, заданные в области **Найти в значении атрибута** , будут заменены на значение выбранного атрибута в выпадающем списке. 
**Внимание!** Пользователю доступны только те строковые атрибуты какие отображены в рабочей области.
Команда **Регистр** позволяет установить необходимые условия для преобразования всех букв в указанном варианте замены найденного фрагмента атрибута в прописные или строчные, или выбор другого способа расстановки прописных и строчных букв. Выбор требуемый варианта преобразования букв осуществляется с помощью выпадающего списка. 
Для поиска и замены фрагмента атрибута на закладке **Изменение атрибутов** предусмотрены следующие кнопки:
· – кнопка поиска необходимого фрагмента атрибута в списке копируемых объектов.
· – кнопка замены одного фрагмента атрибута в списке копируемых объектов. Каждое нажатие данной кнопки последовательно заменяет найденные фрагменты.
· – кнопка замены всех найденных фрагментов в списке копируемых объектов.
Процесс копирования выбранных элементов сопровождается характерными иконками, расположенной в колонке **Статус**. В зависимости от исхода процесса копирования элементов, объект может принимать разные статусы:
 – статус незавершенного процесса копирования объектов.
 – статус корректно проведенной замены атрибута **Обозначение.**
 – статус некорректной замены значения атрибута **Обозначение.**
Примечание: для завершения прототипирования объектов следует повторить процесс замены атрибута у объекта с данным статусом.
 – статус прототипируемого объекта, который является исполнением.

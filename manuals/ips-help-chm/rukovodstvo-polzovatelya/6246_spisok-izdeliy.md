# Список изделий
Пользователю предоставляется возможность настроить отображение колонок. Для этого следует вызвать команду контекстного меню **Настройка отображения** в любой части списка изделий.
**Внимание!** В зависимости от того, какие колонки отображения были настроены, такие строковые атрибуты будут доступны для изменения. 
В колонке **Статусы** отображаются статусы информационных объектов при изменении строкового атрибута. Возможные статусы описаны ниже:
 – Ошибка применения атрибута.
 – Атрибуты успешно применены.
 – Объект попал в список так как является исполнением.
 – Создается копия существующего объекта.
Для объектов в списке доступны следующие команды контекстного меню:
**Взять на изменение** – команда, с помощью которой можно взять на редактирование объект непосредственно в самом редакторе **Изменение атрибутов**. 
**Отменить правки объекта** – команда, с помощью которой можно отменить внесенные изменения в строковый атрибут. 
**Внимание!** Команда **Отменить правки объекта** доступна при условии, что изменения не были применены посредством нажатия кнопки .

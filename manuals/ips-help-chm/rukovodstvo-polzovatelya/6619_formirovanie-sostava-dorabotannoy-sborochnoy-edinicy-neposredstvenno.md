# Формирование состава доработанной сборочной единицы непосредственно\\вручную в системе IPS
Для ручного формирования состава доработанной сборочной единицы в системе IPS следует:
1\. Создать объект типа **Доработанная сборочная единицы**.
2\. Далее необходимо добавить или создать в составе доработанной сборочной единицы компоненты посредством существующих команд по работе с составом.
Примечание: созданные или добавленные в состав доработанной сборочной единицы, компоненты отображаются в составе виртуального узла **Вновь устанавливаемые составные части.**
3\. Далее следует выбрать дорабатываемые изделия посредством команды **Состав объекта \ Доработка \ Использовать как дорабатываемое изделие** или **Состав объекта \ Доработка \ Добавить дорабатываемое изделие** из контекстного меню.
4\. Из контекстного меню следует вызвать команду **Состав объекта \ Доработка \ Снять составные части** с помощью которой следует добавить в состав снимаемые компоненты из развернутого состава дорабатываемого изделия.
Внимание! Перед выполнением системой осуществляется проверка на наличие в составе первого уровня доработанной сборочной единицы компонента, выступающего в качестве дорабатываемого изделия, т.е. объекта, у которого в атрибуте **Тип доработки** связи типа **Состав изделия** установлено значение **Доработка**.

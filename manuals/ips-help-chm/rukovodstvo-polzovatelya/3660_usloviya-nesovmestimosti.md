# Условия несовместимости
При выборе значения опции объекта есть возможность назначить условия несовместимости - правила, позволяющие указать несовместимость значения опции со значением других опций:
Условие несовместимости представляет собой один или несколько критериев несовместимости, которые могут быть объединены в логические группы с помощью функций **И** и(или) **ИЛИ**. Все команды, управляющие процессом создания/изменения условий, вынесены на панель инструментов и в контекстное меню:
Кроме того, в дереве условий допускается перетаскивать элементы с помощью мыши (drag’n’drop).
Например, с помощью команды **Добавить условие** был добавлен новый критерий. С помощью выпадающего списка в колонке **Опция** следует выбрать опцию, со значением которой настраивается несовместимость. В приведенном примере выбрана опция **Используемое топливо**.

В данном примере для значения опции **[FAP] Противосажевый фильтр** была назначена несовместимость со значениями **Бензин А-95** и **Бензин А-98** опции **Используемое топливо** (см. текст-подсказку внизу редактора условий несовместимости).

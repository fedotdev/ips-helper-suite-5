# Создание ТСЕ из ТЭСИ
Для головного объекта ТЭСИ имеется возможность создать дополнительные объекты ТСЕ и включать в них объекты из КЭСИ. 
Для создания ТСЕ из ТЭСИ следует:
1\. Выбрать из правого поля необходимую сборку ТЭСИ и вызвать из контекстного меню команду **Создать ТСЕ** или воспользоваться кнопкой на панели инструментов редактора – . 
2\. В окне **Создание нового объекта** указать необходимые параметры ТСЕ.
Примечание: обозначение не должно совпадать с уже имеющимися в системе подсборками КЭСИ.
3\. Для завершения создания объекта ТСЕ следует нажать кнопку . 
**Внимание!** ТСЕ в ТЭСИ добавляется связью типа **Состав технологических ЭСИ** с атрибутом связи **Количество** =1шт. ТСЕ, созданная в составе ТЭСИ, не связана с какой-либо конструкторской сборкой.
Созданный объект ТСЕ можно исключить из состава ТЭСИ по команде контекстного меню **Удалить из ТЭСИ** либо по кнопке . С помощью команд контекстного меню, объекта ТСЕ так же можно редактировать.
Примечание: исключенный объект ТСЕ из состава ТЭСИ не удаляется из списка объектов в **Навигаторе**.

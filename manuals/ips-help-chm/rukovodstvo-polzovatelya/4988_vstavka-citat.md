# Вставка цитат
В сообщение можно вставить любое количество цитат. Нажмите кнопку для вставки в сообщение тегов цитаты **[cit]** …**[/cit]**. Текст, который будет обрамлен этими тегами, будет оформлен как цитата.
Можно также вставить цитату в текст, выделив цитируемый текст и перетащив его мышью в окно редактирования текста.
При вставке текста не в режиме ответа на чужое сообщение в цитате не будет указано имени автора.

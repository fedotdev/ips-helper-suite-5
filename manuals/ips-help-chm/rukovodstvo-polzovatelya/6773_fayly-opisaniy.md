# Файлы описаний
Система IPS предоставляет возможность создавать настройки шаблона **Файлы описаний** (ФО) на типы объектов. Данные настройки доступны для пользователей с правами администратора по пути **Настройка \ Параметры IPS \ Система \ Файлы описаний**.
Для добавления шаблона на тип объекта следует нажать кнопку . Выбрать тип объекта и задать необходимые настройки ФО в редакторе.
В графе **Обозначение реквизита** необходимо указать **Обозначение реквизита в *.xml** на латинице для каждого выбранного атрибута или параметра. 
**Внимание!** Если реквизиты не назначены для какого-либо атрибута или параметрам, то система не даст возможность сохранить внесенные изменения.
 – данная кнопка позволяет выбрать атрибут из списка атрибутов объекта данного типа.
 – кнопка позволяет выбрать необходимые атрибуты объекта типа **Электронные подписи.**
 – позволяет указать набор вычисляемых системой параметров: **Тип подписи** (**Простая подпись IPS, Неквалифицированная ЭП, Квалифицированная ЭП**), **Статус подписи** (**Подпись актуальна, Подпись устарела**) и **Результат проверки всех подписей**.
 – данная кнопка позволяет выбрать атрибуты объекта типа **Пользователь**.
 – кнопка позволяет показать предустановленный набор атрибутов файлов из закладки **Файл** или **Свойства.**
Для удаления реквизитов из настроек следует вызвать команду **Удалить** из контекстного меню типа объектов. Так же реквизиты можно перемещать в пределах групп реквизитов с помощью команд контекстного меню.
Настройки формирования ФО копируются вниз по иерархии типов объектов в соответствии с правилами унаследования.
При условии, что на тип объекта уже добавлена настройка ФО, то в контекстном меню объекта появляется команда **Создать настройку по прототипу**.
При выполнении команды **Сохранить на диск** , на вкладке **Файлы описаний** предоставлена возможность выбора – формировать ли ФО и выводить ли в ФО наименование атрибутов и параметров IPS. 
Примечание: при выполнении команды **Сохран ить на диск** для состава объекта, ФО формируется для каждого документа состава отдельно. 
Файл описания формируется с именем файла: **Заголовок объекта ID ФО.xml**.

# Связанные значения
Связанные значения позволяют ускорить процесс заполнения значений опций у объекта в составе заказа или комплектации. Список связанных значений может быть назначен каждому значению опции. При этом, если будет выбрано данное значение опции, то автоматически будут заполнены все связанные значения:
Например, для значения опции **[FAP] Противосажевый фильтр** назначим связанное значение с опцией **Используемое топливо**. Для этого добавляется новое связанное значение с помощью команды **Добавить значение опции** , затем в колонке **Опция** выбирается связанная опция (в примере – **Используемое топливо**), а в завершение в колонке **Значение** выбирается автоматически назначаемое значение для этой опции:
Таким образом, если при заполнении значений опций объекта в составе будет выбрано значение **[FAP] Противосажевый фильтр** для опции **Очистка выхлопных газов** , автоматически будет назначено значение **[ДТ] Дизельное топливо** для опции **Используемое топливо**.

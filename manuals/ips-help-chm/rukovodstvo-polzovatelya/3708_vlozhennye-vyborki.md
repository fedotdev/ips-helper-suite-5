# Вложенные выборки
В составе любой выборки могут быть созданы дочерние (вложенные) выборки. Таким образом, выборки могут иметь иерархический вид. Они используются для задания более сложных правил отбора объектов. Каждая нижестоящая в дереве иерархии выборка отбирает по заданным в ней условиям объекты вышестоящей (родительской) выборки.

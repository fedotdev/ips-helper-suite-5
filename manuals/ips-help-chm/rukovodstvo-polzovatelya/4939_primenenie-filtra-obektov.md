# Применение фильтра объектов
После создания нового фильтра он сразу становится активным, то есть по нему немедленно выполняется фильтрация списка объектов:
При открытии выпадающего списка пользователю предоставляется набор доступных фильтров. Синим цветом отмечены системные фильтры, черным – фильтры, которые были созданы пользователями системы IPS.
После выбора фильтра выполняется немедленная фильтрация объектов в списке, как показана на рисунке.
**Внимание!** Данный способ фильтрации работает только для списков объектов. Применять в составах его нельзя, по этой причине в списках с составами элементы управления фильтров отсутствуют. Для фильтрации составов используются другие механизмы (подробнее см. раздел ).

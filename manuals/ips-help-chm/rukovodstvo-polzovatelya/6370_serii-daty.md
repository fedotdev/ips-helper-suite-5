# Серии\\Даты
Закладка **Серии\Даты** позволяет задать настройки фильтрации составов по сериям изделий и датам выпуска/действия.
Строка **Головное изделие** :
Посредством кнопки **Редактировать** пользователь имеет возможность вызвать диалог выбора объектов типа **Головное изделие**. 
Примечание: в выпадающем списке хранятся значения заголовков головных изделий, которые ранее выбирались в этом диалоге.
Строка **Серия:**
Ввод данных в строку осуществляется посредством клавиатуры.
Примечание: в выпадающем списке хранятся значения серий, которые ранее выбирались в этом диалоге.
Строка **Дата:**
Посредством кнопки **Редактировать** пользователь имеет возможность вызвать календарь для выбора даты.
Примечание: в выпадающем списке хранятся значения дат, которые ранее выбирались в этом диалоге. 
Посредством кнопки **Очистить** пользователь имеет возможность очистить значение, выбранное из выпадающего списка.
При изменении любого из значений выпадающих списков перенастраиваются и применяются настройки фильтрации составов по сериям изделий и датам выпуска/действия для формируемого состава заказа.

# Исключение объектов из состава ручной выборки
Чтобы исключить объекты из состава ручной выборки, выберите их в списке выборки и выполните команду **Исключить из выборки** контекстного меню. Таким образом, вы можете включать и исключать из выборки объекты в любой момент после ее создания.

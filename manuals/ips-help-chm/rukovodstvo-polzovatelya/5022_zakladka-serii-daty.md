# Закладка Серии/даты
В списке закладок **Навигатора** для типов объектов, которые могут участвовать в подборе версий по сериям/датам, отображается указанная закладка:
Закладка состоит из панели инструментов с кнопками **Добавить/Удалить головное изделие** , списка головных изделий и применяемостей в этих головных изделиях для указанного объекта, окна, содержащего подсказку и текста, в котором перечислены применяемости других версий указанного объекта (по сериям или по датам, в зависимости от того, какая ячейка в списке является активной).
Редактор контролирует пересечения диапазонов серий одного головного изделия у разных версий объекта. Если пользователь указывает серии, которые используются в других версиях для данного головного изделия, система выдаёт предупреждение:
Примечание: диапазоны серий могут содержать только натуральные числа.

# Отображение колонки Статусы
Чтобы настроить отображение колонки **Статусы** в дереве состава или в списке состава, необходимо вызвать команду **Настройка отображения** любого из объектов состава и выбрать для отображения атрибут **Статусы**. (см. п. ).

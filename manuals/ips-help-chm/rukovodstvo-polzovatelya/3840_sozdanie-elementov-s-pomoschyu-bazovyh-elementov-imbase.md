# Создание элементов с помощью базовых элементов IMBASE
Системой IPS предоставлена возможность создания некоторых элементов с помощью контекстного меню типов объектов, входящих в состав базовых объектов IMBASE. На рисунке выделены объекты, с помощью которых можно создать такие элементы, как каталог и таблица.

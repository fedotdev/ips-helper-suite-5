# Подтверждения
Опция **Подтверждения** :
· **Запрашивать подтверждение при возврате назад** и **Запрашивать подтверждение при отправке дальше** – параметры, включение которых позволяет добавить диалоговое окно, подтверждающее действие.
· **Требовать подтверждение открепления вложений** – параметр, включение которого позволяет добавить диалоговое окно, подтверждающее действие.
· **Выдавать предупреждение перед удалением** – параметр, включение которого позволяет добавить диалоговое окно, подтверждающее действие.

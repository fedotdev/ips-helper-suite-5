# Удаление конфигурации
Для таго чтобы удалить конфигурацию следует нажать кнопку **Удалить конфигурацию** и в открывшемся окне выбрать конфигурацию, которую необходимо удалить.
Для подтверждения удаления конфигурации следует нажать кнопку в системном сообщении.

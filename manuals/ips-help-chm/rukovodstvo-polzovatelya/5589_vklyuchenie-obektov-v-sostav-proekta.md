# Включение объектов в состав проекта
В системе IPS предоставлена возможность включать в состав проекта объекты с помощью команды **Состав объекта / Добавить в состав** контекстного меню, данная возможность позволяет не только добавить уже существующий в базе объект, но и отобразить его в составе проекта. 
**Внимание!** Невозможно добавить объект в проект пользователю, не являющемуся участником этого проекта.

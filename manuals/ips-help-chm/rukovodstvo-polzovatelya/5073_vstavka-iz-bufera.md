# Вставка из буфера
Чтобы вставить из буфера скопированные записи, необходимо открыть в режиме редактирования таблицу, в которую планируется поместить записи (таблицу-приемник), и нажать кнопку панели инструментов **Вставить из буфера**. Левая часть кнопки позволяет вставить последнюю скопированную группу записей, правая часть кнопки позволяет выбрать таблицу-источник, из которой нужно вставить скопированные записи. 
Команда **Очистить буфер обмена** позволяет освободить буфер обмена от всех скопированных записей.

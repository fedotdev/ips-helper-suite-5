# Включение объектов в извещения
В IPS есть три различных способа включить объекты в извещение:
1\. Выбрать нужные объекты в **Навигаторе** и выполнить для них команду локального меню **Извещения и контексты/Изменить по извещению** (либо **Выпустить по извещению** , **Заменить** , **Аннулировать** или **Присвоить литеру**).
2\. Создать версию объекта (см. п. ), для типа которого в Конфигураторе базы данных на текущем шагу жизненного цикла была с свойстве **Необходимость извещения** выбрана настройка **Требовать включения в извещение** либо **Предлагать включение в извещение**.
3\. Открыть извещение для редактирования и выполнить команду локального меню **Включить в извещение/Объекты** (см. п. ) либо просто перетащить объекты в окно редактора извещений (drag & drop).
В первом и втором случаях в первую очередь придется создать извещение, в которое будут вставлены объекты, либо выбрать одно из существующих извещений. В последнем случае извещение уже выбрано, но требуется выбрать объекты, которые нужно включить.
Объекты, выбранные для включения в извещение, называются **основными**. Кроме основных, в извещение могут включиться и **дополнительные** объекты, которые будут созданы при создании версий основных объектов (например, при создании версии спецификации всегда создается и версия связанного с нею изделия).

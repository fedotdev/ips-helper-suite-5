# Итерации объекта
Итерация объекта представляет собой сохранённое состояние атрибутов и состава версии объекта, предназначенное для отката сделанных после создания итерации изменений. Список итераций объекта можно посмотреть на закладке **Итерации**. Эта закладка присутствует у объекта в том случае, если его тип допускает создание итераций (см. )
Для создания новой итерации или сохранения в уже существующую итерацию используется **Мастер работы с итерациями** , который вызывается по командам контекстного меню **Создать / Итерацию** и**Сохранить в итерацию,** соответственно. Команды будут доступны, если для выбранного типа объекта разрешено создание итераций. 
При первом использовании мастера рекомендуется настроить отображаемые колонки дерева структуры объекта. Для настройки колонок щелкните правой клавишей мышки по шапке дерева, выполните команду **Настройка отображения** и выберите в открывшемся окне необходимые для отображения колонки. Система запоминает сделанный выбор и при последующей работе с мастером итераций отображает те колонки, которые были выбраны при последнем сеансе работы с мастером.
**Внимание!** Настройка отображаемых колонок снимает выделение со всех объектов дерева, кроме корневого, поэтому ее лучше выполнять до непосредственной работы с итерациями.
В диалоге мастера работы с итерациями отображается структура выбранной версии объекта. С помощью чек-боксов выбираются те элементы структуры изделия, которые требуется сохранить в итерацию.
Переход между итерациями объекта осуществляется с использованием выпадающего списка внизу окна. Содержащаяся в списке опция **Создать новую итерацию** позволяет создать новую итерацию объекта.
При смене выбранной итерации в мастере текущее состояние дерева сбрасывается и отображается состав выбранной итерации.
При создании новой итерации необходимо ввести наименование итерации в соответствующее поле перед сохранением итерации.
Если была выбрана команда **Сохранить в итерацию** , то мастер покажет структуру последней сохраненной или восстановленной для данного объекта итерации. Если таковой для объекта нет, то мастер работы с итерациями откроется в режиме создания новой итерации. Идентификатор последней восстановленной или сохраненной итерации для данной версии объекта записывается в соответствующий атрибут объекта (если атрибут описан у данного типа объектов). При сохранении в существующую итерацию система полностью заменяет ее содержимое на новое.
· Кнопка **Выделить все объекты** выделяет все объекты дерева.
· Кнопка **Выделить объекты выбранной итерации** выделяет объекты входящие в выбранную в выпадающем списке итерацию. Нажатие этой кнопки не сбрасывает выделение с уже отмеченных пользователем элементов.
· Кнопка **Выделить объекты, взятые на изменение мной** выделяет объекты, взятые на изменение текущим пользователем. Нажатие этой кнопки не сбрасывает выделение с уже отмеченных пользователем элементов.
· Кнопка **Снять отметки со всех объектов** снимает выделение со всех объектов дерева, кроме корневого.
**Внимание!** Если администратор системы установил свойство **Скрывать диалог включения в итерацию объектов состава** в положение **Да** , то мастер по работе с итерациями будет иметь следующий вид.
Информацию об итерациях объекта можно просмотреть на закладке **Итерации**. Полужирным курсивом выделена активная (последняя сохраненная или восстановленная) итерация. 
Выпадающее меню **Версии** позволяет отфильтровать список итераций объекта по номеру версии, на основании которой были созданы итерации объекта.
В контекстном меню списка итераций доступны следующие команды:
· **Обновить** – перечитывает из базы данных список итераций объекта.
· **Восстановить** – восстанавливает выбранную версию объекта из указанной в списке итерации. Также будут восстановлены и другие версии объектов, сохраненные в данную итерацию. При этом восстановление этих версий будет производиться в версии, подобранные с использованием текущего контекста редактирования и правила подбора, используемого в системе по умолчанию.
**Внимание!** Если администратор системы включил настройку **Запрашивать создание новой итерации объекта перед его восстановлением из итерации** , то при выполнении команды **Восстановить** , система предложит пользователю создать новую итерации для объекта перед восстановлением старой.
Для выполнения команды нужны права доступа на изменение выбранной версии объекта. Восстановленная версия объекта автоматически перемещается на первый шаг схемы ЖЦ, поэтому для восстановления итерации в рабочую копию объекта необходимо, чтобы данная версия объекта была на первом шаге схемы ЖЦ.
Если хотя бы одна из версий объектов не может быть изменена в момент восстановления итерации, выдается диалог, который позволяет либо отменить операцию, либо попытаться восстановить объекты в итерации. В последнем случае система восстановит итерацию в объекты, для которых существуют соответствующие разрешения для их модификации. 
· **Удалить** – команда удаляет выбранные в списке итерации объекта.
· **Переименовать** – команда позволяет переименовать итерацию.
· **Найти текст/Найти далее** – команды для поиска строк в списке итераций объекта.
· **Сравнить сохраненный состав с актуальным** – команда позволяет показать изменения в актуальном составе объекта относительно состава, сохранённого в итерации.
На панели инструментов в меню **Вид** можно включить режимы просмотра свойств и состава выбранной в списке итерации. Вся информация по итерациям доступна только для просмотра.

# Настройки отображения органайзера
В настройках отображения органайзера есть следующие параметры:
· **Отображать задачи с Высоким приоритетом жирным шрифтом** – позволяет включить отображение задач с высоким приоритетом **жирным шрифтом**.
· **Отображать задачи с Низким приоритетом курсивом** – позволяет включить отображение задач с низким приоритетом _курсивом_.
· **Режим отображения вкладки «Неделя» по умолчанию** – позволяет установить режим отображения вкладки по умолчанию **Рабочая неделя** или **Полная неделя**. Однако, персонально можно менять данный режим в течении сессии посредством переключателей на панели, подробнее переключатели описаны в п. .
· **Режим отображения календаря по умолчанию** – позволяет выбрать режим отображения календаря по умолчанию: **День, Неделя** или **Месяц**.
· **Цвет текста задач с Высоким приоритетом** – позволяет выбрать цвет задач с высоким приоритетом для отображения их в органайзере. Доступные цвета: черный и красный.

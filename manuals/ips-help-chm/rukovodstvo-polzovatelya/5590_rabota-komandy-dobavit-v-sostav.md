# Работа команды Добавить в состав
Для того чтобы включить в состав проекта, созданный ранее в базе объект следует:
1\. Выбрать проект и вызвать команду **Состав объекта / Добавить в состав** из контекстного меню.
2\. В открывшемся диалоговом окне следует выбрать необходимый объект из допустимых типов. 
3\. Для завершения добавления объекта в проект следует нажать кнопку .
Примечание: в состав проекта включаются непосредственно выбранные объекты без их состава. Но в дереве **Навигатора** будет отображен полный состав включенного объекта.

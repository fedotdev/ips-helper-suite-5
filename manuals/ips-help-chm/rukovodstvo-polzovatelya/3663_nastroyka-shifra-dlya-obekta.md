# Настройка шифра для объекта
Закладка **Шифр** позволяет настроить способ генерации шифра для заказа, создаваемого на указанный объект:
Шифр может состоять из нескольких элементов, каждый из которых может представлять собой следующее:
· **Атрибут объекта** – в шифр будет выводиться значение выбранного атрибута объекта.
· **Код опции** – в шифр будет выводиться код опции.
· **Код значения опции** – в шифр будет выводиться код выбранного значения опции.
· **Фиксированный текст** – в шифр будет выводиться введенный текст (можно использовать для включения в шифр различных разделителей или фиксированных наименований и кодов).
Добавить новый элемент в шифр можно с помощью команды **Добавить часть шифра** , удалить – с помощью команды **Удалить часть шифра**. Команда **Удалить шифр** позволяет полностью очистить шифр от составляющие его элементов. Команды перемещения позволяют передвигать части шифра влево-вправо.
Если для элемента шифра выбран **Атрибут объекта** , то в списке под видом элемента доступны атрибуты указанного объекта:
Если требуемого атрибута нет в списке, следует отметить пункт **Выбрать атрибут…** При этом будет отображено окно по выбору произвольных атрибутов объектов:
После выбора атрибута нажмите кнопку , чтобы внести изменения в элемент шифра.

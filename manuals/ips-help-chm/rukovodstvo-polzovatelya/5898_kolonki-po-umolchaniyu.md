# Колонки по умолчанию
**Внимание!** Опция**Колонки по умолчанию** доступна только пользователям с правами администратора.
Опция**Колонки по умолчанию** , с помощью которой можно настроить отображение колонок в папках почты. В рабочей области опции находятся вкладки, название которых дублируют название папок из приложения **Почта**. Для выбора настройки отображения следует:
1\. Выбрать необходимую вкладку и нажать на кнопку .
2\. В открывшемся окне **Настройка отображения** необходимо настроить отображение колонок.
3\. Для сохранения настроек необходимо нажать кнопку .

# Изменение масштаба схемы по осям координат
Для увеличения или уменьшения ширины схемы следует воспользоваться кнопками соответственно на панели инструментов визуализатора.
Для увеличения или уменьшения высоты схемы воспользуйтесь кнопками соответственно на панели инструментов визуализатора.

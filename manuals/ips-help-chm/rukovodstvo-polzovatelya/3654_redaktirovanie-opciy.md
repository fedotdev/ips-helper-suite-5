# Редактирование опций
Выбрав опцию среди объектов указанного типа, можно открыть её в новом окне **Навигатора**. При этом страничка **Опция** среди закладок позволяет осуществлять просмотр и редактирование содержимого опции:
Верхняя часть редактора позволяет просматривать и изменять следующие параметры опции:
− название опции;
− код опции;
− тип данных значений опции (строка, целое/дробное число, логическая величина, дата);
− категорию;
− описание опции;
− опция устарела (использование запрещено).
Изменять тип данных опции можно только в том случае, если в опции нет ни одного значения (в том числе и удаленного). 
Оставшуюся часть редактора опций занимает список значений опций, представленный в виде таблицы. Допускается отображать данный список с изображениями, назначенными значениям опций, либо без изображений:
Добавление значения опции осуществляется при помощи команды **Добавить** из панели инструментов либо контекстного меню в списке значений. Перемещение по ячейкам редактора можно осуществлять с помощью клавиш стрелок или мышью, редактирование значений начинать с помощью клавиши **[F2]** , либо однократным кликом мыши в требуемой ячейке.
Вызов команды **Удалить** позволяет отметить указанное значение опции как удаленное:
**Внимание!** Физически значения опций не удаляются, они только помечаются как удаленные. В дальнейшем значение опции можно восстановить, либо оставить как удаленное. Данный механизм используется для того, чтобы обеспечить корректную работу со старыми заказами и комплектациями, в которых используются указанные значения опции, в том случае, если требуется запретить дальнейшее использование данных значений в новых объектах, заказах, комплектациях, т.п.
Кнопка **Восстановить** отмечает выделенное значение как восстановленное, позволяя вновь использовать это значение в новых объектах:
Для каждого значения опции сохраняется информация о том, кто и когда последним изменял состояние и (или) содержимое данного значения. Для просмотра этой информации следует воспользоваться командой **История** :
При этом в список значений будут добавлены две новые колонки – **Кто внёс изменения** и **Дата изменений**.
Изменение изображений для значений осуществляется с помощью клика мышью в ячейке столбца **Изображение** для требуемого значения опции. При этом будет отображено окно, позволяющее выполнить следующие действия с изображением для значения:
− выбрать/заменить изображение;
− очистить текущее изображение;
− подтвердить/отменить внесенные изменения.
Кнопка **Выбрать…** открывает окно по выбору библиотечного изображения для значения опции, кнопка **Очистить** удаляет текущее изображение.
Флажок требуется для того, чтобы отметить опцию, как устаревшую. В этом случае в новых объектах использование данной опции будет недопустимо, но в старых объектах, например, в заказах и комплектациях, содержимое составов будет конфигурироваться корректно, если там использовалась данная опция.

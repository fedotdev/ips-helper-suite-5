# Создание ярлыка таблицы IMBASE
Таблицы в IMBASE являются основным местом хранения информации. Каждая таблица может иметь несколько ярлыков: в таком случае реальные данные из таблицы будут фигурировать одновременно в различных каталогах или под различными именами в одном каталоге. Следует рассмотреть несколько способов создания ярлыков: создание ярлыка для новой таблицы или создание ярлыка существующей таблицей.

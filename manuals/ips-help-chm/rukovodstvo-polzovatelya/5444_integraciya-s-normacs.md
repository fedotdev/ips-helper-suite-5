# Интеграция с NormaCS
Для корректной работы интегратора следует убедится, что на локальном компьютере пользователя установлена информационная система NormaCS, а затем загружен модуль расширения **Интегратор с NormaCS**.
Для того чтобы загрузить модуль расширения следует:
1\. На главной панели выбрать меню **Настройка \ Модули расширения \ Загрузить модуль расширения**.
2\. В открывшемся диалоге **Менеджер загрузки модулей расширения IPS** необходимо выбрать **Интегратор** **с NormaCS** и нажать на кнопку .
После загрузки модуля расширения **Интегратор** **с NormaCS** в контекстном меню появляется подменю **NormaCS** , в которой в свою очередь находятся следующие команды **Вызвать…** , **Поиск по номеру** , **Поиск по наименованию** , **Поиск по тексту** , функциональное значение представлено ниже:
· **Вызвать…** – команда, которая позволяет открыть информационную систему NormaCS из клиента IPS.
· **Поиск по номеру** – команда, которая реализует поиск по номеру нормативного документа.
· **Поиск по наименованию** – команда, которая осуществляет поиск по наименованию нормативного документа.
· **Поиск по тексту** – команда, которая осуществляет поиск по тексту.
_Примечание: команды_** _Поиск по номеру_** _,_**_Поиск по наименованию_** _,_**_Поиск по тексту_** _автоматически открывают_ _информационную_ _систему_ _NormaCS._

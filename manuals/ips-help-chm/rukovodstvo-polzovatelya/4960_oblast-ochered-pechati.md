# Область Очередь печати
В области **Очередь печати** отображается список документов, отправленных в очередь на печать. Данная область предоставляет информацию о применяемых параметрах печати для каждого документа: название принтера и выбранного макета, а также наименование документа.
Документ, который находится в очереди на печать, имеет набор команд контекстного меню. Каждая команда позволяет выполнить дополнительную операцию по настройке параметров печати документа.
Функциональное значение команд описано ниже:
 **Игнорировать проверку копий** – отключает режим проверки указанного количества копий для разных форматов страниц одного документа.
 **Изменить** – вызывает окно **Настройка печати документа** , в котором предоставляется возможность внести дополнительные изменения в существующие параметры печати при этом не удалять документ из очереди.
В окне **Настройка печати документа** пользователю предоставляется возможность изменить количество копий при печати документа перемещенного с помощью кнопки .
В поле **Документ** добавлено наименование документа.
Поле **Принтер** предоставляется возможность выбрать принтера.
В поле **Макет** пользователь может указать необходимый макет, который будет использован для печати документа.
В поле **Страницы** предоставляется возможность выбрать конкретные страницы для печати.
В поле **Диапазон** страниц предоставлены общая информации о количестве страниц документа.
В поле **Копии** пользователь может указать количество необходимых копий для печати.
Включенный чекбокс **Вписать** позволяет вписать содержимое страницы в область печати принтера.
Команда **Игнорировать проверку копий для этого документа** дублирует функцию команды **Игнорировать проверку копий** из контекстного меню документа, установка флажка отключает данный режим проверки. 
 **Печать** – отправляет на печать выделенную часть документа 
 **Удалить** – удаляет документ из очереди и переместить его в область **Документы**.

# Создание нового правила сравнения составов
Для создания правила следует выбрать объекты необходимого типа и вызвать команду **Дерево сравнения**. 
В открывшемся окне следует:
1\. Нажать на кнопку  и выбрать тип создаваемого объекта, а затем нажать кнопку .
2\. В открывшемся диалоговом окне **Создание правила сравнения составов** следует заполнить поле **Наименование** , а затем – поле закладки **Поиск состава**.
Примечание: закладка **Поиск состава** необходима для выбора объектов соответствующего типа, по которым будет осуществляться сравнение состава.
3\. С помощью кнопки следует добавить необходимые родительские типы объектов со своими типами связей для поиска.
4\. В добавленном объекте следует настроить типы связей. Для этого необходимо выбрать те типы объектов, которые входят в состав родительского объекта.
Результат заполненной закладки **Поиск состава** для сравнения составов технологических процессов показан на рисунке ниже:
Закладка **Атрибуты сортировки** позволяет назначить атрибут **Сортировка (связь)** конкретного типа объекта, это необходимо для указания последовательности отображения и сравнения входящих в состав объектов. 
Например, в состав цехозахода входят операции, которые имеют последовательную нумерацию. Для корректного отображения данной нумерации следует:
5\. Открыть закладку **Атрибуты сортировки** и выбрать тот объект, элементы которого должны быть отсортированы, а затем нажать кнопку , расположенную в области **Атрибуты для сортировки на уровне состава**.
6\. В открывшемся окне **Добавить атрибуты сортировки** следует указать принадлежность добавляемого атрибута, а затем нажать кнопку 
7\. В диалоговом окне **Выбор атрибута** следует ввести наименование искомого атрибута в строку поиска, выбрать его из списка и нажать кнопку .
Примечание: если атрибут не отобразился в общем списке, то следует установить флажок в строке **Показать скрытые атрибуты**. 
8\. Далее следует нажать кнопку .
Закладка **Идентифицирующие атрибуты** позволяет назначить любому добавленному типу объекта и связи идентифицирующий атрибут.
Примечание: идентифицирующими являются атрибуты, совокупность которых позволяет системе определить являются ли сравниваемые объекты одной и той же сущностью с точки зрения алгоритма сравнения объектов. Чаще всего для этой цели достаточно атрибута **Идентификатор объекта**. Но, например, для сравнения технологических операций, переходов и пр. нужно использовать другие атрибуты, т.к. в каждом техпроцессе создаются копии объектов данного типа.
Закладка **Сравниваемые атрибуты** позволяет назначить любому добавленному типу объекта и связи конкретный атрибут, который следует сравнить. 
Например, в каждую операцию входит объект **Нормирование на операцию** , описывающими атрибутами которого являются атрибуты **Норма штучного времени** и **Норма подготовительно-заключительного времени**. Для назначения атрибута сравнения следует:
9\. Открыть закладку **Сравниваемые атрибуты** выбрать необходимый тип объекта или тип связи и нажать кнопку в поле **Атрибуты для сравнения**.
10\. В открывшемся окне **Выбор атрибута** следует ввести наименование искомого атрибута в строку поиска и нажать кнопку .
11\. Для завершения создания нового правила сравнения составов следует нажать кнопку .

# Назначение грифа документа
Назначение грифа документа производится через команду контекстного меню **Изменить гриф документа.**
Команда доступна при условии, что **Документам** назначен атрибут **Гриф документа** и все**в** ыбранные документы взяты на редактирование текущим пользователем.
Команда предлагает выбрать назначаемый гриф, после чего показывает непосредственную входимость выбранных документов в другие документы связью **Состав документации**. Это сделано для информирования о том, в файлах каких документов может понадобиться изменить ссылки на данный документ. Если документ не входит связью **Состав документации** в другие документы, то он не будет отображен в списке слева.

По нажатию кнопки **Назначить гриф документам** документам, для которых была вызвана команда, будет назначен соответствующий атрибут **Гриф документа** , также будет переименован первый файл документа по шаблону, указанному в настройках IPS **Параметры/Файлы/Шаблон для имени файла с грифом секретности**(см. ).

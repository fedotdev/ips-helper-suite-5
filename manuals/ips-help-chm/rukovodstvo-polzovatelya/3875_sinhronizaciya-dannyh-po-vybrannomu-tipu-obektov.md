# Синхронизация данных по выбранному типу объектов
Для синхронизации данных по выбранному типу объектов необходимо выбрать в дереве навигатора тип, объекты которого необходимо синхронизировать. Если есть возможность для синхронизации, то при нажатии правой клавиши мыши появится контекстное меню с командой **IMBASE/Синхронизировать** , в противном случае команда будет отсутствовать.

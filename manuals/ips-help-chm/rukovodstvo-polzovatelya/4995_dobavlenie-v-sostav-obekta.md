# Добавление в состав объекта
Система IPS располагает сервисом, позволяющим в состав отмеченного объекта добавлять другие объекты из специального диалога. Чтобы воспользоваться данным сервисом, необходимо выполнить следующие действия:
· Отметьте объект, в состав которого необходимо добавить другие объекты, и примените команду **Состав объекта/Добавить в состав** его контекстного меню для вызова диалога выбора объектов.
· В появившемся диалоге в левом поле выберите один из допустимых типов объектов, в правом поле отметьте объекты, которые нужно добавить в состав, и нажмите **ОК**.

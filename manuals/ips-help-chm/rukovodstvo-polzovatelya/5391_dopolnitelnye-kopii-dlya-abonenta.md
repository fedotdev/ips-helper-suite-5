# Дополнительные копии для абонента
С закладки **Список копий** осуществляется рассылка абоненту дополнительных копий, которые превышают указанное количество на закладке **Лист рассылки**. При рассылке таких копий система IPS выдает сообщение с предупреждением, вид такого сообщения показан на рисунке ниже.

# Изменение свойств фильтра
Список фильтров позволяет просматривать и изменять свойства для фильтров, которые были созданы пользователями IPS. Для этого следует выбрать такой фильтр в списке и нажать кнопку **Свойства (Карточка) текущего фильтра**.
При этом будет отображено окно карточки для фильтра, в котором можно просмотреть и, при необходимости, внести изменения в свойства фильтра:
После изменения свойств фильтра содержимое фильтруемого списка будет обновлено. Подробнее о настройке условий выборок можно прочитать в п. .

# Опции
Для каждого информационного объекта может быть задан список опций, отражающих его ключевые характеристики или варианты комплектации. Каждая опция может принимать значения из заданного списка. Например, для такого изделия как трактор, может быть создана опция **Климатическое исполнение** со списком значений **Умеренное** , **Тропическое** , **Арктическое** и т.д.. Для управления установкой дополнительного оборудования трактора может быть создана опция **Кондиционер** со значениями – «Нет», «Toshiba», «Mitsubishi» и т.д.
Опции сами являются информационными объектами системы IPS:
Каждая опция характеризуется следующими параметрами:
− название опции;
− код опции;
− тип данных значений опции (строка, целое/дробное число, логическая величина, дата);
− категория;
− описание опции;
− список значений.
Более подробно данные параметры будут описаны далее в разделе **Редактор опций объектов**.

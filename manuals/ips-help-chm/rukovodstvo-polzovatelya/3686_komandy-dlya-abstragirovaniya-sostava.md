# Команды для абстрагирования состава
Команды абстрагирования находятся в подменю **Абстрагирование** контекстного меню дерева **Навигатора**. Данное подменю состоит из следующих команд:
· **Весь состав** – команда, которая удаляет мягкую конкретизацию у всего состава объекта, выбранного в дереве **Навигатора**. 
Примечание: удаление конкретизации осуществляется только у тех связей, которые можно модифицировать в данный момент.
· **Текущая версия** – команда, которая удаляет мягкую конкретизацию с выбранной в дереве **Навигатора** связи. 
Примечание: команда доступна только если выбрана связь с включенной конкретизацией, а родительский объект доступен для изменения.
· **Текущая версия в составе** – команда, которая удаляет мягкую конкретизацию выбранной в дереве **Навигатора** версии объекта во всем составе объекта, находящегося в данный момент в корне дерева **Навигатора**. 
Примечание: команда доступна только если выбрана связь с включенной конкретизацией. Конкретизация будет удалена только у связей, допускающих изменение в данный момент.

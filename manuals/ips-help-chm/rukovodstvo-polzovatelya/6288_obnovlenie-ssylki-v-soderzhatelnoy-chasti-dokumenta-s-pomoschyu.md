# Обновление ссылки в содержательной части документа с помощью команды Обновить ссылку
Данная команда необходима для контроля над актуальностью созданных ссылок в содержательной части документа. На рисунке представлен фрагмент текста, где в пункте 6 создана ссылка на информационный объект **ИБПМ.322366.001 Барабан** , который со временем утратил свою актуальность – был изменен атрибут **Наименование** в системе IPS.
Для обновления ссылок следует вызвать команду закладки **IPS** меню приложения MS Word. В открывшемся диалоговом окне будет представлен полный перечень процедур выполняемой команды. Для завершения обновления ссылок в содержательной части ДЭ следует нажать кнопку .
После обновления все ссылки приобретут актуальный вид. 
Примечание: если ссылка в документе не была синхронизирована с базой данных в системе IPS из-за отсутствия ссылочного объекта, то вместо ссылки будет отображено предупредительное сообщение.

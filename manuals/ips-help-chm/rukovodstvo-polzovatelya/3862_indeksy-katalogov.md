# Индексы Каталогов
Эталонная система управления НСИ IPS IMBASE использует табличное хранение данных, при котором для линейного поиска необходимо одновременно обрабатывать большое количество таблиц, что приводит к некоторым затратам времени. **Индекс** – объект базы данных, с целью повышения производительности поиска данных. Поэтому система позволяет индексировать каталоги и справочники, что позволяет решить несколько задач. Во-первых, значительно ускоряет поиск в таблицах, так как индекс хранится в одной таблице базы данных и для поиска не надо просматривать большое количество отдельных таблиц и вычислять в них данные. Во-вторых, использование индекса позволяет еще на этапе ввода данных в таблицы контролировать их уникальность и избегать дублирования информации.
Индекс представляет собой таблицу в базе данных, содержащую значения атрибута, по которому построен индекс, для всех записей всех таблиц определенного каталога.
**Внимание!** Закладка **Индексы** доступна пользователям, которые зарегистрированы в системе IPS под ролью Администратор НСИ или Администратор.

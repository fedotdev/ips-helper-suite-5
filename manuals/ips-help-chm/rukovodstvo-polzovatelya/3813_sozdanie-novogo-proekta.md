# Создание нового проекта
Для того чтобы создать проект следует:
1\. В дереве **Навигатора** отметить тип объектов **Проекты** и вызвать команду **Создать** из контекстного меню.
2\. В открывшемся диалоговом окне **Создание нового объекта** следует заполнить свойства проекта.
Примечание: поля, отмеченные знаком обязательны для заполнения.
3\. Для продолжения настройки свойств создаваемого объекта следует нажать кнопку .
4\. При необходимости можно скорректировать шаблон проекта.
5\. Для настройки участников проекта следует нажать кнопку . 
Примечание: с помощью команд и предоставляется возможность добавить пользователя в список участников проекта или удалить указанного пользователя из списка.
6\. Для создания объекта в системе IPS следует нажать кнопку .

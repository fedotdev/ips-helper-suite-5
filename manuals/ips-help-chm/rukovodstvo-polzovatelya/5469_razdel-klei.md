# Раздел Клеи
Данный раздел содержит марки клеев, их свойства (характеристики, режимы склеивания) и склеиваемые материалы.
Клеи классифицированы по областям их преимущественного применения, а также по химической природе основного компонента, входящего в состав композиции.
Коллекция папок клеев имеет древовидную структуру. Выбрав конечную папку одной из ветвей, можно посмотреть клеи, которые она объединяет. Список клеев отображается в левой части закладки **Клеи**. После выбора одного из клеев, в правой части окна можно посмотреть его свойства (область применения, физико-механические характеристики, технология склеивания, срок и условия хранения).

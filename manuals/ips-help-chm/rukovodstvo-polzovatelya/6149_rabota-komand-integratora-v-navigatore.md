# Работа команд интегратора в Навигаторе
В системе IPS реализован поиск нормативной документации в NormaСS для объектов с атрибутом **Ссылка на объект Imbase** , характер поиска отличен от поиска в IMBASE.
Команды поиска подменю **NormaСS** в дереве состава объекта и в состава спецификации ведут себя следующим образом:
· **Поиск по номеру**. Поиск нормативной документации в NormaСS реализован по значению атрибута **ГОСТ** в объекте. 
_Примечание: если у объекта не заполнен атрибут**ГОСТ** , то система выдаст предупредительное сообщение._
· **Поиск по наименованию**. Поиск нормативной документации в NormaСS реализован по значению атрибутов **Наименование** или **Заголовок объекта** в объекте.
· **Поиск по тексту**. Поиск нормативной документации в NormaСS реализован по принципу совпадения выбранного текста и данных в соответствующих разделах NormaСS.
При вызове команд **Поиск по наименованию** и **Поиск по тексту** открывается диалоговое окно, в которое заносится текст из выбранной ячейки и на основании данного текста осуществляется поиск в системе NormaCS.

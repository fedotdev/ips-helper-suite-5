# Списки объектов
Списки объектов базы данных системы являются основным видом информации, отображаемым в рабочей области **Навигатора**. Каждый из списков связан с выбранным в дереве навигации элементом. Контекстное меню объектов списка предоставляет доступ к большинству действий, которые можно совершать над объектами. Списки объектов системы могут быть весьма объемными, однако система IPS имеет ряд возможностей по управлению списками объектов (см. п. ), облегчающих ориентирование среди них.

# Добавление комплекта, поставляемого отдельно
Для добавления комплекта, поставляемого отдельно, следует воспользоваться командой контекстного меню **Состав объекта/Добавить комплект, поставляемый отдельно**.
В появившемся окне выберите нужный комплект и нажмите кнопку **ОК**. В результате проделанных действий в состав будет добавлен выбранный комплект связью **Комплект, поставляемый отдельно.** По умолчанию данные комплекты в составе изделия не отображаются. Для отображения необходимо выполнить соответствующие настройки в меню **Настройка/Отображение и сортировка составов**.

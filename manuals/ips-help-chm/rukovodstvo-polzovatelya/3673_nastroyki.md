# Настройки
На закладке **Настройки** находится ряд параметров, которые можно настроить:
· **Оставлять созданные объекты взятыми на изменение** – созданные объекты будут оставлены взятыми на изменение по завершении работы диалога.
· **Копировать документацию** – в точные изделия будут добавлены конструкторская и технологическая документации допустимых типов из состава прототипов.
Так же на закладке **Настройки** находятся текстовые поля, каждое из которых задает часть шаблона обозначения точного изделия. Сам шаблон отображен в виде формулы снизу под названием настраиваемой группы – **Генерация обозначений.**
При включенном флажке **Использовать шифр** обозначения будут генерироваться ко шифру конфигуратора составов.

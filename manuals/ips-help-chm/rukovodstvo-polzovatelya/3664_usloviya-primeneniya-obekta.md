# Условия применения объекта
Закладка **Условия применения** позволяет указать условия, при выполнении которых объект будет применен в составе. Закладка доступна в том случае, если объект располагается в конфигурируемом составе:
Работа с редактором условий применения идентична работе с редактором условий несовместимости (см. п. ).

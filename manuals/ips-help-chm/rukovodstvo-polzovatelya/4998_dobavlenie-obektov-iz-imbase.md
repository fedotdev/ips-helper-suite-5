# Добавление объектов из IMBASE
Система IPS позволяет использовать записи базы системы IMBASE для создания на их основе новых объектов и добавления их в состав других объектов. Чтобы вставить в состав объект из базы системы IMBASE, выполните следующие действия:
· Отметьте объект, в который нужно вставить объект из базы IMBASE, и примените команду **Состав объекта/Добавить из IMBASE** его контекстного меню.
· В появившемся диалоге выберите необходимый каталог, папку, таблицу и запись таблицы и нажмите **ОК**.
В результате проделанных действий на основе выбранной записи будет создан новый объект и добавлен в состав.

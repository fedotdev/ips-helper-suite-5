# Контексты состава
Закладка **Контексты состава** позволяют выбрать один или несколько контекстов состава изделий, по которому будет выполняться формирование состава ПЗ:
По умолчанию выбраны **Общий** и **Производственный** контексты составов.
Примечание: кнопка позволяет вернуть настройки контекста состава к исходным значениям.

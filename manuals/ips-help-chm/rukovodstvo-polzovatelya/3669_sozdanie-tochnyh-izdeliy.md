# Создание точных изделий
Создать точное изделие можно с помощью команды контекстного меню **Создать/Точное изделие.**
Данная команда доступна только для сборочных единиц входящих в состав **Заказа** или **Комплектации**. Данная команда создает **точные изделия** на основе **общих сборок** (**Общая сборка** – сборочная единица, имеющая избыточный состав, на связях которого указаны условия применения той или иной позиции в зависимости от значений опций) путем вычисления всех ее исходящих связей с помощью заданных значений опций. После выбора команды из контекстного меню появится диалоговое окно.
Функционал предоставляемый диалогом создания точных изделий разделен на несколько закладок.
В окне **Создание точных изделий** находится элемент **При совпадении обозначений подсборки связывать создаваемые сборки с уже существующими подсборками**.
Если параметр **При совпадении обозначений подсборки связывать создаваемые сборки с уже существующими подсборками** неактивен, а обозначение создаваемых точных подсборок совпадает с обозначениями имеющихся в системе изделий, то появляется ошибка. 
Если параметр **При совпадении обозначений подсборки связывать создаваемые сборки с уже существующими подсборками** активен, то в описанном выше случае ошибка не возникает, а изделия, имеющиеся в системе, с совпадающими обозначениями с точными подсборками, будут включены в состав создаваемой точной сборки.
По нажатию на кнопку Создать производится трассировка заготовок создаваемых точных сборок, в случае возникновения ошибок, они будут выведены в списке ошибок внизу диалога, если ошибок нет отобразится сообщение об успешном создании точных сборок.

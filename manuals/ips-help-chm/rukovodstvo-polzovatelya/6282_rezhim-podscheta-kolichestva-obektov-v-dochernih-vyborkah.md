# Режим подсчета количества объектов в дочерних выборках
Для пользователя доступен режим вывода количества объектов в дочерних выборках. Для этого следует:
1\. На главном меню системы выбрать **Настройка\ Параметры IPS \ Пользователи \ Оптимизация системы** и установить значение **Да** для параметра **Фоновая проверка вложенных узлов дерева.**
2\. По завершению настройки параметра **Фоновая проверка вложенных узлов дерева** нажать кнопку и закрыть диалог **Параметры IPS**. 
3\. В дереве **Навигатора** выбрать родительскую выборку и в свойствах добавить атрибут **Подсчитывать количество объектов в дочерних выборках** , затем установить значение **Да** добавленному атрибуту. 
4\. Нажать кнопку .
5\. Для корректной работы режима вывода количества объектов в дочерних выборках следует обновить дерево **Навигатора** нажатием кнопки или перезагрузить клиента.

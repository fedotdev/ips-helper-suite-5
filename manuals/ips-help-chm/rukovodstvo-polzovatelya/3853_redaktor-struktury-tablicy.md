# Редактор структуры таблицы
Атрибуты, отображаемые в виде колонок таблицы, и свойства этих атрибутов представляют собой структуру таблицы. При необходимости пользователь может редактировать структуру таблицы. Редактор структуры можно вызвать, нажав кнопку **Редактор структуры** , расположенную на панели инструментов редактора таблиц (подробная инструкция по редактору структуры таблицы приводится в п. ).

# Исправление предупреждений по маршрутам обработки в составе
В приведённом примере трассировка отыскала объект, в составе которого есть несколько маршрутов обработки. Для такого объекта следует указать маршрут, который попадёт в состав производственного заказа:
Выберите запись трассировки, содержащую предупреждение о маршруте обработки. Будет выполнен переход на объект состава, в котором найдено несколько маршрутов обработки. Затем откройте страничку **Маршруты обработки** , на которой будет отображён список найденных маршрутов.
Двойной клик мышью либо выбор в списке и нажатие кнопки **Выбрать маршрут** позволяют указать маршрут, который должен попасть в состав производственного заказа.
После выполнения указанных действий в результатах трассировки будет изменён значок для записи:
Это означает, что для указанной записи нет критических замечаний, либо все замечания были исправлены.

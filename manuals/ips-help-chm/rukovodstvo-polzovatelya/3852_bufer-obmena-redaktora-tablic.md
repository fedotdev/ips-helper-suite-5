# Буфер обмена редактора таблиц
Механизм буфера обмена позволяет с помощью команд копирования или удаления помещать записи одних таблиц во внутренний буфер и вставлять их из внутреннего буфера в другие таблицы. Одновременно в буфер может быть помещено неограниченное количество скопированных групп записей из разных таблиц.

# Просмотр актуального состава в Навигаторе
Пользователь имеет возможность скрыть из состава объекта в **Навигаторе** допустимые заменители, оставив только актуальный состав. Для этого необходимо воспользоваться кнопкой **Актуальный состав вкл./выкл.** , расположенной на панели инструментов **Фильтрация состава**.
Следует учесть, что для каждого окна **Навигатора** данный режим включается индивидуально, т.е. режим зависит от окна.

# Исключение объекта из состава рабочего стола
Если требуется исключить объект из списка объектов рабочего стола, отметьте его и примените команду его контекстного меню **Состав объекта/Исключить из состава**. При этом объект исчезнет из состава рабочего стола, но останется в базе данных.

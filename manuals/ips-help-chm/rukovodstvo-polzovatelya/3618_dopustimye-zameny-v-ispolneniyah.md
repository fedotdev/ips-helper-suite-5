# Допустимые замены в исполнениях
Редактор допустимых замен умеет работать с исполнениями. Логика работы следующая – при открытии состава объекта, который является исполнением, редактор отыскивает общую часть исполнения. При этом она будет отмечена в списке объектов состава специальным значком в столбце **Статусы** , например, для двух исполнений (в окнах **Навигатора**).

Во время редактирования групп и заменителей редактор не допускает размещать в одной группе заменителей объекты из переменной и общей частей. Если в группу добавляется объект из общей части состава, то в дальнейшем в эту группу можно добавить только объекты из общей части состава. Аналогичные действия выполняются и для объектов из переменной части состава.
При этом в ячейках столбца **Примечание** в дереве допустимых замен для каждой группы указывается, объекты из какой части состава применяются в данной группе, из общей части исполнения или из переменной.
В остальном работа с допустимыми заменами в исполнении идентична тому, что описано в предыдущих разделах.
При внесении изменений в состав исполнения (нажатие на кнопку **ОК**) изменения, внесенные в общую часть исполнения автоматически вносятся в общие части остальных исполнений. Изменения переменной части сохраняются только в редактируемом исполнении.

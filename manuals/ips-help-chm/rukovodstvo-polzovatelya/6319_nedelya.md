# Неделя
Режим **Неделя** позволяет пользователю увидеть расписание задач с ограничениями по времени на всю неделю.
Пользователь имеет возможность установить переключатель либо на **Рабочая неделя** , либо **Полная неделя**. При включенном режиме отображения недели **Рабочая неделя** пользователю будут доступны для отображения только рабочие дни, настроить которые может пользователь с правами администратор, подробное описание по настройке календаря представлено в п. 4.5.1.8.4. Системные календари в «Руководстве администратора». 
**Полная неделя** – включает в себя отображение и выходные дни.

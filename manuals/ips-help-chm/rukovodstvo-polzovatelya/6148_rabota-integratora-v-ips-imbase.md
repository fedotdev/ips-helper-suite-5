# Работа интегратора в IPS IMBASE
**Внимание!** При использовании команд поиска подменю **NormaCS** из таблицы IMBASE поиск осуществляется по тексту выбранной ячейки таблицы в соответственных разделах информационной системы **NormaСS.**
Для того чтобы воспользоваться поиском в таблицах **IPS IMBASE** следует:
1\. Перейти в каталоги и справочники **IMBASE**. 
2\. Открыть таблицу необходимого каталога выбрать запись.
3\. На панели рабочей области нажать на кнопку **NormaCS** , а из выпадающего списка выбрать необходимую подкоманду.
_Примечание: команды поиска можно вызвать из контекстного меню выделенного значения в таблице IMBASE_ _. На рисунке ниже показан пример вызова команды**Поиск по номеру** :_

# Работа команды Изменить по маске
Для того что бы изменить строковый атрибут посредством команды **Изменить по маске** следует:
1\. В списке **Навигатора** выбрать необходимые объекты и взять их на редактирование.
2\. Затем вызвать команду **Атрибуты \ Изменить по маске**.
В открывшемся окне **Изменение атрибутов** следует настроить маску поиска:
3\. В поле **Атрибут** выбрать в выпадающем списке необходимый строковый атрибут, в котором следует осуществить поиск, а затем замену.

Найденный объект будет выделен синим цветом в списке изделий.
7\. Для замены маски поиска следует нажать кнопку .
8\. Для продолжения поиска по маске следует нажать кнопку **Найти далее**. 
Если поиск завершен и более нет ни одного совпадения, то система выдаст следующее окно:
9\. Для завершения замены следует нажать кнопку .
10\. При успешном применении атрибута в колонке **Статусы** появится значок .
11\. Для завершения работы с редактором по заменен строковых атрибутов следует нажать кнопку .

# Настройка печати
Область настройки печати состоит из текстовых полей со строками, заполнение которых, позволяет задать необходимые параметры для печати документа. Вид области настроек печати представлен на рисунке ниже:
**Принтер** – строка с выпадающим списком подключенных к компьютеру пользователя принтеров. 
**Макет** – строка с выпадающим списком созданных макетов.
**Копии** – текстовое поле с двунаправленным счетчиком, с помощью которого можно указать количество копий для печати документа.
**Разрешить масштабировать страницы под макет** – параметр, включение которого позволяет размещать страницы большего формата на макетах меньшего формата путем их масштабирования под меньший формат.
**Вписать в область печати** – параметр, включение которого позволяет вписать содержимое страницы в область печати принтера.
В области настройки печати также расположены две кнопки:
 – кнопка, которая позволяет переместить документ в область **Очередь печати** с настроенными параметрами принтера, макета и количеством копий.
 – кнопка, которая вызывает команду автоматического распределения документа на принтер, который поддерживает печать документов данного формата. Программа выбирает первый настроенный принтер в списке, который совпадает по формату документа.
Примечание: если среди настроенных принтеров отсутствует необходимый, удовлетворяющий формат печатаемого документа, то механизм автоматического распределения выберет макет, в рамки которого впишется формат данного документа.

# Создание архива по прототипу
Создание архива по прототипу — это вариант ускоренного создания архивов, при использовании которого создаваемый объект принимает значения свойств архива-прототипа. Чтобы создать объект по прототипу, выполните следующие действия:
· Отметьте в дереве навигации архив, по прототипу которого необходимо создать новый архив.
· Примените команду **Создать/Архив по прототипу** его контекстного меню.
· В появившемся диалоговом окне отредактируйте значения свойств нового архива и нажмите **Готово**.

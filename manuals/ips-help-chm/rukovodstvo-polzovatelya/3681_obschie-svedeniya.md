# Общие сведения
Подбор версий объектов в составах по сериям изделий и датам в IPS использует следующие понятия и правила:
1\. **Серия** – несколько (более одного) однотипных изделий, запускаемых в производство. Изделия в рамках одной серии могут иметь отличия друг от друга как по составу изделия, так и по технической документации.
2\. **Применяемость изделия в серии** (диапазон применяемости) – параметры **Серия с:** и **Серия по:** для изделия, значения которых указывают на то, в каких сериях применяется данное изделие (например, с 1 по 9999, т.п.).
3\. **Головное изделие** – дополнительный параметр к применяемости изделия, позволяющий использовать одно и то же дочернее изделие в разных сериях для разных головных изделий, независимо друг от друга (например, для головного изделия А – с 1 по 100 серии, для головного изделия Б – с 10 по 9999 серии, т.п.).
4\. **Применяемость изделия по дате** (диапазон применяемости) – параметры **Дата с** : и **Дата по:** для изделия, значения которых указывают на то, в какой период времени применяется данное изделие (например, с 01.01.2013 г. ).
Применяемость по сериям и датам управляется глобальной настройкой базы данных IPS. Данный вид подбора работает, только если включена глобальная настройка **Параметры IPS / Система / База данных и оптимизация / Подбор версий: режим \ Подбор по сериям\датам**(Включение настройки требует перезапуска клиента). 
Допускается настраивать применяемости объектов составов по сериям и по датам. Один и тот же объект состава может применяться в одних головных изделиях по сериям, а в других – по датам.
Примечание: разные версии одного объекта не могут применяться в одних и тех же или пересекающихся диапазонах серий и дат.
**Внимание!** Фильтрация составов по сериям и датам имеет более высокий приоритет, чем фильтрация по контекстам редактирования, конкретизации связей и правилам подбора версий.

# Создание нового объекта
Все объекты системы, включая документы, создаются по одной и той же схеме, однако интерфейс диалогового окна, в котором задаются основные свойства объектов, может быть разным, в зависимости от типа создаваемого объекта. Существует несколько способов создания объектов.

# Уровень доступа к объектам проекта
Проекты помогают управлять уровнями доступа принадлежащих им объектов, для типа которых включен режим мандатного разграничения доступом (см. ). Каждому проекту можно назначить свой уровень доступа. При включении объекта в проект система автоматически назначает объекту аналогичный уровень доступа в том случае, если для объектов данного типа включено мандатное разграничение доступа, а пользователь обладает правом на соответствующее изменение уровня доступа объекта, включаемого в проект. 
Изменить уровень доступа пользователя может только администратор системы в окне **Администратор базы данных** в карточке данного пользователя (см. ). Изменить уровень доступа к проекту может пользователь – создатель проекта или участник проекта, имеющий право редактировать проект.

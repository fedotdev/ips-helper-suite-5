# Отображение состава электронного документа с помощью команды Открыть состав
Данная команда позволяет открыть и отобразить состав документа в виде дерева в новом окне. Команда работает на основании созданных ссылок в содержательной части документа. Для просмотра дерева состава документа следует нажать кнопку .

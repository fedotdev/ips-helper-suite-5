# Редактор составов
**Редактор составов** – это один из способов формирования составов информационных объектов IPS. Он представляет собой специальное плавающее окно, содержащее список объектов, которые можно добавлять в формируемый состав. Рассмотрим подробно работу с редактором составов.
Откройте в новом окне **Навигатора** объект, состав которого требуется сформировать. Далее воспользуйтесь командой **Вид/Редактор состава** главного меню IPS для вызова редактора составов:
При этом будет открыта панель редактора состава.

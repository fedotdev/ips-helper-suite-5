# Работа с командой Состав по прототипу
При необходимости копирования сборочной единицы, включая ее состав, следует:
1\. Выбрать СЕ и с помощью ее контекстного меню вызвать команду **Создать / Состав по прототипу**.
В открывшемся диалоговом окне **Состав по прототипу** следует воспользоваться элементами управления для поиска и отметки копируемых элементов. Для поиска объекта необходимо:
2\. В строку поиска вписать полное или частичное значение одного из строчных атрибутов искомого объекта.
Примечание: при вводе данных регистр не учитывается.
3\. Нажать кнопку или . 
Примечание: если нажать кнопку , то будут выделены все элементы, содержащие введенное значение строчного атрибута. На рисунке ниже показан результат поиска:
4\. Для продолжения копирования элементов необходимо отметить каждый выделенный объект в столбце **Копия** , для этого следует нажать кнопку .
Примечание: при копировании нижестоящих элементов, вышестоящие копируются автоматически.
При необходимости можно воспользоваться кнопками:
 – команда, которая позволяет отметить или снять отметку **Копия** для всех элементов в составе выбранной сборочной единицы. 
При условии, что выбран элемент в составе сборочной единицы, то команда позволяет отметить или снять отметку **Копия** для выбранного элемента. 
 – команда, которая позволяет отметить или снять отметку **Удалить** для всех элементов в составе выбранной сборочной единицы.
При условии, что выбран элемент в составе сборочной единицы, то команда позволяет отметить или снять отметку **Удалить** для выбранного элемента.
5\. Для изменения атрибута копируемых элементов следует нажать кнопку .
На закладке **Изменение атрибута** следует скорректировать значения атрибута **Обозначение** , так оно должно быть уникальным, для этого следует:
1\. В области **Атрибут** выбрать строковый атрибут.
2\. В строку для ввода маски поиска ввести сочетание букв и/или символов. 
Примечание: при необходимости можно воспользоваться дополнительными командами по учету регистра и сходства букв кириллицы и латиницы.
3\. Далее следует нажать кнопку . 
Примечание: найденный объект подсвечивается цветом в списке всех копируемых объектов.
Режим **Текст** включен по умолчанию, поэтому для дальнейшей замены найденного фрагмента атрибута на произвольное значение следует:
1\. Заполнить строку для ввода сочетания букв или символов.
Для замены указанного фрагмента на значение другого атрибута следует нажать кнопку **Значение атрибута** , а далее:
2\. С помощью выпадающего списка выбрать необходимый атрибут.
Примечание: при необходимости следует использовать команду **Регистр**.
3\. Для замены фрагмента в значении атрибута необходимо нажать кнопку .
Примечание: если указанное значение применимо для всех копируемых элементов, то рекомендуется использовать кнопку , которая позволит заменить синхронно все фрагменты атрибутов, удовлетворяющие значению вписанной маски поиска в области **Найти в значении атрибута**.
С учетом всех установленных условий, измененный фрагмент атрибута будет выглядеть следующим образом:
**Внимание!** Любые внесенные изменения можно отменить с помощью команд контекстного меню.
4\. Для завершения процесса копирования элементов следует нажать на кнопку .
Корректная замена атрибутов и дальнейшее создание копий в базе IPS сопровождается появлением соответствующей иконки в столбце **Статус**.

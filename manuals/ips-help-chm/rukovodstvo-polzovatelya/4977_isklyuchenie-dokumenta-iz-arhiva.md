# Исключение документа из архива
Чтобы исключить документ из архива, откройте карточку документа с помощью команды **Свойства (Карточка)** контекстного меню документа, выделите архив в поле **Зарегистрирован в архиве** закладки **Карточка документа** и нажмите **[Delete]**.

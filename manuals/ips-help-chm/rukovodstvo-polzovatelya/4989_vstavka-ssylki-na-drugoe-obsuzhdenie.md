# Вставка ссылки на другое обсуждение
Кнопка позволяет вставить в сообщение ссылку из другого обсуждения. При её нажатии появляется окно выбора обсуждения:
Выберите в левой панели обсуждение, после чего в правой панели появится список сообщений этого обсуждения. Выберите одно сообщение, выделив его галочкой в левой части сообщения, и нажмите кнопку **ОК**. После этого в окне редактирования появится ссылка на выбранное сообщение, обрамленная тегами **[ref]** …**[/ref]**. После сохранения сообщения на эту ссылку можно будет нажать, чтобы перейти к выбранному сообщению.

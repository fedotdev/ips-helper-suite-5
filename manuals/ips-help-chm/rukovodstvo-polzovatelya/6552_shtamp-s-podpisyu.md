# Штамп с подписью
**Внимание!** Создание и настройка шаблонов штампа доступна только пользователя с правами администратора.
Создание штампа с подписью идентично по создание штампа без подписи, подробное описание представлено в п. . В данном пункте будут раскрыты основные отличия.
Для шаблона с одной подписью был применен следующий сценарий:
<!DOCTYPE html>
<html>
<body style="padding:0px; margin:0px;">
<div style="padding:0px; margin:0px; border:solid thick black; border-width:2px;">
<table width="100%" cellspacing="0" cellpadding="0">
<tr>
<td style="padding:5px;"><img src="[Изображение штампа]" width="30" padding="5"></td>
<td valign="top">ООО "Комитет важных дел"</td>
</tr>
</table>
<p style="font-size:14px; color:black; margin:5px; padfing:5px; line-height: 1.5; text-align: left;">[Графа подписи] <b>[Выводимое имя]</b>
</br>[Дата подписи]</p>
</div>
</body>
</html>
**Внимание!** Для атрибута **Дата подписи** доступны следующие форматы вывода значения:
· {dd.MM.yyyy hh:mm} – 29.10.2024 14:56.
· {dd.MM.yyyy HH:mm tt} – 29.10.2024 02:56 PM.
· {dd.MM.yyyy hh:mm zzz} – 29.10.2024 14:56 +03:00.

Для создания штампа с подписью следует:
1\. В редакторе штампа указать тип штампа в строке **Тип штампа**.
2\. Добавить сценарий в область **Шаблон штампа**.
3\. Указать тип подписи в строке **Тип подписи**.
При выборе типа штампа и подписи становятся доступными для настройки следующие параметры:
Группа **Подпись** :
· **Дата подписи** , параметр, который выводит фактическую дату подписания документа.
· **Графа подписи** , параметр, который выводит графу подписи.
· **Фамилия подписавшего** , параметр, который выводит фамилию пользователя, который подписал документ.
· **Должность подписавшего** , параметр, который выводит должность пользователя, который подписал документ.
· **Исполняющий обязанности** , параметр, который выводит фамилию имя и отчества пользователя, который исполняет обязанности подписавшего.
**Внимание!** Для вывода информации об исполняющем обязанности, следует убедится, что строка **Исполняющий обязанности** заполнена.
Группа **Пользователь** :
· **Выводимое имя** , параметр, который выводит фамилию, имя и отчество пользователя, который подписал документ.
· **Фамилия** , параметр, который выводит фамилию пользователя, который подписал документ.
· **Инициалы** , параметр, который выводит инициалы пользователя, который подписал документ.
· **Должность** , параметр, который выводит должность пользователя, который подписал документ.
· **Электронная почта** , параметр, который выводит электронную почту пользователя, который подписал документ.

4\. После добавления типа объекта применяемости следует нажать кнопку **Добавить графы для подписи** , и в открывшемся окне выбрать необходимую графу для подписи.
**Внимание!** Следует помнить, что при настройке штампа с подписью следует добавить только одну графу для подписи.

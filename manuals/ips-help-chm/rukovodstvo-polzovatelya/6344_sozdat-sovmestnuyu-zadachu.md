# Создать совместную задачу
Для того чтобы создать совместную задачу, у которой несколько исполнителей, следует:
1\. На панели нажать кнопку **Создать совместную задачу**.
2\. В открывшемся окне следует добавить участников события, для этого необходимо нажать на кнопку **Добавить** в строке **Участники**.
3\. В открывшемся диалоге следует выбрать пользователей и нажать кнопку .
4\. С помощью календаря следует настроить начальную дату предстоящего события.
5\. Далее указать временной диапазон, в котором будут рассмотрены свободные «окошки» участников события, а в поле **Продолжительность** указать планируемое, отведенное время на проведения события.
На рисунке выше показана временная шкала, где красным цветом обозначено время, которое недоступно для создания совместной задачи, а салатовым цветом – доступное время для всех участников события. 6\. Для продолжения создания совместной задачи следует нажать на кнопку .
7\. В открывшемся окне следует внести необходимые данные. Описание мастера по созданию задачи представлено в п. .

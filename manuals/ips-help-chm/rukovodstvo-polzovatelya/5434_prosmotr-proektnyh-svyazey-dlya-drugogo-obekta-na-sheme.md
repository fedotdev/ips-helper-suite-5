# Просмотр проектных связей для другого объекта на схеме
Для того, чтобы отобразить схему связей для другого объекта следует:
1\. Выбрать необходимый объект на схеме и щелкнуть по соответствующей пиктограмме левой кнопкой мыши.
2\. Далее следует вызвать из контекстного меню команду **Сделать корнем**.

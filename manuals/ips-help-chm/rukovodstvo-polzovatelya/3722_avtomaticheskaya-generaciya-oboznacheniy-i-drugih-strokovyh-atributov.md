# Автоматическая генерация обозначений и других строковых атрибутов
Чтобы упростить процессы учета и обозначения объектов, IPS позволяет использовать автоматическую генерацию обозначений и других строковых атрибутов с помощью классификаторов. Общая формула строкового атрибута объекта формируется объединением формул папок, т.е. складыванием их значений, начиная с формулы корня классификатора и заканчивая формулой папки, в которой будет содержаться классифицируемый объект.
Для автоматической генерации значений используются шаблоны подстановки:
· {9999} – генерация числового значения, начиная с 1 и последующим инкрементом на 1. В этом типе подстановки можно указывать несколько цифр 9, например, {99}, {999} и т.д., в этих случаях при вычислении подстановки недостающие позиции в числе слева будут заполняться нулями. Например, для шаблона подстановки {999} нумерация будет следующая: 001, 002, 003 и т.д. В шаблоне также можно через двоеточие указать стартовое значение и шаг инкремента, например, {9999:5:10}, в этом случае последовательность номеров будет следующая: 5,15,25… Также существует возможность контроля превышения максимального значения. Для этого в шаблон после двоеточия необходимо добавить максимальное значение (например, {9999:5:10:999999}), и включить опцию **Контроль превышения допустимого диапазона формулы**. 
· {dd.MM.yyyy} – всевозможные комбинации даты (включают символы 'd','D','m','M','y','Y','.','/','-' и символ пробела).
| **Символы** | **Результат подстановки** |
| --- | --- |
| d или D | День месяца. Ноль не предшествует однозначным числам, обозначающим дни. |
| dd или DD | День месяца. Однозначным числам, обозначающим дни, предшествует ноль. |
| M или m | Числовое представление месяца. Ноль не предшествует однозначным числам, обозначающим месяцы. |
| MM или mm | Числовое представление месяца. Однозначным числам, обозначающим месяцы, предшествует ноль. |
| MMM или mmm | Сокращение для названия месяца (например, "Янв", "Фев", "Мар", и т.д."). |
| MMMM или mmmm | Полное название месяца (например, “Февраль”). |
| y или Y | Год без указания века. Когда числовое представление года без указания века меньше 10, ноль ему не предшествует. |
| yy или YY | Год без указания века. Когда числовое представление года без указания века меньше 10, ему предшествует ноль. |
| yyy или YYY | Год, обозначенный тремя цифрами. Если значение года меньше 100, ему предшествует ноль. |
| yyyy или YYYY | Год, обозначенный четырьмя цифрами, включая век. Используются предшествующие нули для получения четырех цифр. |
· Использование букв латинского алфавита. Например, если одноразрядное значение {Z}, то последовательность значений будет следующая: A, B, С и т.д. Если двухразрядное значение {ZZ}, то – AA, AB, AC..AZ, BA, BB и т.д. Для трехразрядного значения {ZZZ} – AAA, AAB..AAZ, ABA и т.д.
Примечание: Для кириллицы в качестве шаблона подстановки используется последний символ алфавита – {Я}, {ЯЯ}, {ЯЯЯ} и т.д..
· При добавлении символа «**^** » в начало формулы папки классификатора, то его вычисляемому значению не будет добавлено слева значение из формулы соответствующего атрибута вышестоящего классификатора или папки.
· **{@Наименование_атрибута}** – значение произвольного атрибута классифицируемого объекта. Например, **{@Код организации-разработчика}** , классификатор автоматически подставляет значение атрибута **Код организации-разработчика** в вычисляемое значение, однако пользователь всегда имеет возможность управлять значением подставляемого атрибута на вычисление счетчика. 
Для этого следует добавить классификатору атрибут **Учитывать атрибут объекта в формуле** и задать ему значение **Да**. При таких условиях значение атрибута **Код организации-разработчика** будет подставляться в формулу до поиска последнего значения для счетчика, и значение атрибута **Код организации-разработчика** будет влиять на поиск.
Если атрибут **Учитывать атрибут объекта в формуле** выключен, имеет значение **Нет** , то значение атрибута **Код организации-разработчика** будет подставляться в формулу после поиска последнего значения для счетчика, т.е. будет сквозная нумерация, и значение атрибута **Код организации-разработчика** не будет влиять на поиск.
При вычислении значения счетчика производиться поиск среди объектов, типы которых указаны в атрибуте классификатора **Типы объектов для поиска при вычислении значений атрибутов**. При отсутствии этого атрибута поиск будет производиться среди объектов типа, которому непосредственно присвоен вычисляемый атрибут.
**Внимание!** Если включена опция **Только локальные объекты** , то поиск будет производится среди объектов, созданных в текущем узле (главное меню **Настройка / Параметры IPS** , в открывшимся диалоге **Параметры** **IPS** следует выбрать **Система / Выборки и классификаторы**).

# Создание устойчивой комплектации
Для создания комплектации требуется выполнить команду **Файл/Создать/Новый объект…** и выбрать в дереве тип объектов **Комплектации** , либо при помощи команды контекстного меню:
В окне мастера по созданию объектов заполните поля и нажмите кнопку для создания новой комплектации:
Пополните состав новой комплектации. После этого следует открыть комплектацию в новом окне **Навигатора** , например:
Выделите объект, входящий в состав комплектации, например, **Автомобиль…** , и на закладке **Конфигуратор** / **Применить с опциями** укажите значения опций данного объекта, с которыми он будет применяться в составе комплектации.
Например, после заполнения значений опций объекта можно просмотреть полный и сконфигурированный состав комплектации. Управление конфигурированием составов осуществляется на панели **Фильтрация составов** с помощью кнопки :

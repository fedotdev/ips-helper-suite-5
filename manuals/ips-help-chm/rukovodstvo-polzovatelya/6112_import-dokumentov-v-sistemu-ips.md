# Импорт документов в систему IPS
Для хранения созданного файла в системе IPS необходимо импортировать файл, расположенного на локальном диске компьютера пользователя. Данная функция позволяет регистрировать в базе данных документы, которые были созданы вне системы IPS. Для импорта документа следует:
1\. На главной панели системы IPS выбрать меню **Экспорт / Импорт** , а затем вызвать команду **Импортировать файлы.**
2\. В открывшемся окне следует выбрать необходимый файл.
3\. При выборе импортируемого файла, расположенного вне области файлового хранилища, система предложит переместить файл в хранилище. Для корректного завершения импорта следует нажать кнопку __ при условии, что импортируется один файл и кнопку ____ при условии, что импортируется несколько файлов.
Примечание: импортируемый файл перемещается в файловое хранилище, а не копируется.
Если у клиента IPS создано несколько пользовательских типов документов, то система выдаст диалоговое окно, в котором следует указать необходимый тип документа и нажать кнопку .
Примечание: пользователь имеет возможность создать любой тип документа, для возможности импорта файла в дерево **Навигатора** , для этого следует создать заявку администратору систему IPS. Подробное описание пользовательских типов документов представлено в .
**Внимание!** В начале сеанса работы с IPS система предлагает пользователю выбрать типа документа, в который следует импортировать документ. При последующем импорте, запускается режим автоподбора определения типа документа, который формируется на базе первого выбора типа документа в диалоговом окне **Импорт документа**. На рисунке ниже показан диалог автоподбора:
· **Да, для всех таких файлов** – все импортируемые файлы, с расширением .odt создаются в дереве **Навигатора** в указанном ранее типе документов.
· **Да, только для этого файла** – конкретный файл будет импортирован в указанный ранее тип документа.
· **Нет, только для этого файла** – для конкретного импортируемого файл следует выбрать другой тип документа.
· **Нет, для всех таких файлов** – опция, которая позволяет задать новый тип документа в текущем рабочем сеансе системы IPS.
· **Изменить правило и попробовать снова** – опция, работает при импорте 3D документов. 
При выборе опций **Нет, только для этого файла** и **Нет, для всех таких файлов** система выдает диалог **Импорт документа** для выбора необходимого типа документа.
**Внимание!** Правила выбора подбора типа документа для импортируемого файла сохраняется только на время текущего сеанса.

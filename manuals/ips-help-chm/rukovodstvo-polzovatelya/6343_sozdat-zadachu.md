# Создать задачу
Объект типа **Задачи органайзера** можно создать, как при помощи панели управления, нажав кнопку **Создать задачу** , так и с помощью двойного клика по ячейке, выбранного интервала времени. На рисунке представлена маска создания объекта **Задачи органайзера** :
Объект содержит следующие поля:
· **Тема –** строка для ввода наименования задачи. Введенный текст будет высвечиваться во временном интервале режимов отображения задач.
· **Дата начала:** **–** поле, в котором следует настроить дату и время начала задачи. 
· **Дата окончания** : – поле, в котором следует настроить дату и окончания задачи. 
Примечание: для корректного отображения задачи в органайзере рекомендуется задать время окончания задачи отличное от ее времени начала.
· **Состояние** – поле с выпадающим списком, которое носит информативный характер.
· **Приоритет** – поле с выпадающим списком, в котором следует выбрать приоритетность задачи.
Примечание: для визуального различия задач с разным приоритетом следует настроить параметры органайзера, подробное описание настроек представлено в п. .
· **Категория** – поле с выпадающим списком, которое носит информативный характер. 
· **Повторение** – поле с выпадающим списком, в котором можно указать периодичность повторения задачи. 
· **Получатель** – поле, в котором следует указать участника или участников задачи.
Примечание: пользователя, создающего задачу, добавлять не нужно.
Основные кнопки для управления:
 **Добавить** – кнопка, которая открывает список зарегистрированных пользователей. В списке необходимо выбрать исполнителя\участника создаваемой задачи.
 **Удалить** – кнопка, которая позволяет удалить добавленного получателя.
 **Редактировать** – кнопка, которая позволяет заменить добавленного получателя на нового пользователя.
 **Очистить** – кнопка, которая полностью очищает список добавленных получателей.
 **Карточка объекта** – кнопка, которая позволяет открыть карточку, выбранного из списка получателей, пользователя.
· **Напоминание** – параметр с выпадающим списком, который позволяет установить время для напоминания о предстоящей задаче.

При необходимости пользователь может отложить напоминание, для этого следует выбрать время, на которое нужно отложить оповещение и нажать кнопку .
С помощью кнопки пользователь может перейти на карточку задачи, а по кнопке – выключить напоминание.
· **Выводить упоминание во всплывающем окне** – параметр, включение которого предоставляет возможность создать описание к предстоящей задаче и запустить описание задави во всплывающем окне.
Кнопки **Открыть** , **Прекратить** и **Отложить** позволяю соответственно: открыть карточку задачи, выключить напоминающее уведомление и отложить напоминание.
Пользователю, который создал задачу, доступны следующие возможности: 
− задачу можно перенести на другой день с помощью обычного перетаскивания, время начала которой останется неизменно. Перетягивание задачи доступно в режимах **Неделя** и **Месяц**.
− у задачи можно изменить срок выполнения с помощью перетягивания за указанные ниже на рисунке узелки.

# Заимствование опций из объектов
Редактор позволяет осуществлять заимствование опций из следующих источников:
− из списка выбранных объектов;
− из выбранных объектов и их составов первого уровня;
− из выбранных объектов и их развернутых составов.
Для выбора источника опций нажмите кнопку **Импорт опций** и выберите источник:
В появившемся окне выберите объекты, которые будут проанализированы на наличие опций. После нажатия кнопки будет запущен процесс, изучающий содержимое выбранных объектов и собирающий список опций:
Нажатие кнопки прекращает работу мастера по импорту опций.
После завершения работы анализатора объектов, если будут найдены новые опции (которых нет у текущего объекта), будет отображено следующее окно, позволяющее выбирать опции для заимствования:
В дереве слева отображается список всех найденных опций, упорядоченный по категориям. При выборе опции справа отображается список объектов, в которых данная опция была обнаружена.
Мастер позволяет импортировать не только сами опции, но и их условия несовместимости и списки связанных значений. Для этого следует установить отметки в соответствующих колонках в списке справа.
При этом автоматически в списке опций слева будут отмечены все взаимосвязанные опции. 
Обратите внимание на список внизу окна. На приведенном примере в нем отображается, что выбранная опция **Очистка выхлопных газов** в объекте **Автомобиль…** задействована в списках связанных значений и условиях несовместимости совместно с опцией **Используемое топливо**. Соответственно, при выборе первой опции **Очистка выхлопных газов** и условий несовместимости и(или) связанных значений для нее автоматически будет выбрана и опция **Используемое топливо** :
После нажатия кнопки мастер выполнит проверку выбранных опций. Если будет обнаружена ошибка, появится окно с сообщением вида:
В данном случае ошибка была вызвана тем, что из списка импортируемых опций была убрана опция **Используемое топливо** , хотя она применяется в условиях несовместимости или в связанных значениях у импортируемой опции **Очистка выхлопных газов**.

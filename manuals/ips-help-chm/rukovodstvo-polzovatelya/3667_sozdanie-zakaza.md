# Создание заказа
Для создания заказа требуется выполнить команду **Файл/Создать/Новый объект…** и выбрать в дереве типов **Заказы** , либо выполнить команду контекстного меню:
Рассмотрим мастер по созданию заказов более подробно.
На первой страничке формируется состав заказа (с помощью команд **Добавить объект** и **Удалить объект**):
При выборе команды **Добавить объект** будет открыто окно по выбору объектов, которые будут размещены в заказе:
После нажатия кнопки в состав заказа будут внесены изменения:
После нажатия кнопки будет открыта следующая страничка, позволяющая задать значения опций для объектов, добавленных в состав заказа:
После заполнения требуемых значений опций нажмите кнопку . На следующей страничке будет предложено сгенерировать шифр для обозначения заказа:
С помощью кнопки […] следует открыть окно, в котором будет выбран объект, на основании информации из которого будет сгенерирован шифр заказа:
В данном окне отображаются объекты, включенные в состав заказа. После выбора объекта нажмите , чтобы внести изменения в обозначение заказа:

# Создание нового исполнения объекта
Примечание: данная команда будет доступна в том случае, если загружен модуль расширения **Управление информацией об изделиях PDM**.
Система IPS обеспечивает работу не только с обычными (единичными) документами, но и с групповыми конструкторскими документами, описывающими различные исполнения объектов. Чтобы создать исполнение объекта, выполните следующие действия:
· Выберите из списка объектов рабочей области тот объект, для которого будет создаваться исполнение, и воспользуйтесь командой его контекстного меню **Создать/Исполнение** для перехода в диалог создания нового объекта. Данная команда доступна только для тех объектов, у которых можно создавать исполнения – по умолчанию это изделия;
· В появившемся диалоговом окне внесите необходимые изменения в создаваемый объект
· Нажмите **Готово**.
Объект и его исполнения видны на закладке Объект, которая отображается в карточках объектов типа Документы. Закладка предоставляет быстрый доступ к связанному с документом объекту, его исполнениям и свойствам, избавляя пользователя от необходимости искать данные объекты среди множества других объектов:
Просмотреть список исполнений объекта можно также с помощью команды **Список исполнений** в контекстном меню для информационного объекта.

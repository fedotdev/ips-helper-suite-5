# Работа с окнами
Многооконный интерфейс IPS позволяет работать одновременно с несколькими приложениями, объектами, составами, архивами и т.п., располагающимися в отдельных окнах. 
Специальный элемент интерфейса главного окна системы — так называемая панель окон — отображает все открытые окна, находящиеся в рабочем пространстве IPS. Каждое окно на панели представлено в виде кнопки, содержащей заголовок окна.

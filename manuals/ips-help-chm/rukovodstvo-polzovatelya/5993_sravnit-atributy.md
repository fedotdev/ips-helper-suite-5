# Сравнить атрибуты
Для сравнения атрибутов объектов или версий одного объекта следует:
1\. Отметить объекты в списке и вызвать команду **Атрибуты** **/ Сравнить атрибуты** контекстного меню.
2\. В открывшемся окне **Сравнение объектов** представлен список атрибутов для сравнения.
В окне **Сравнение объектов** отображены списки атрибутов выбранных объектов, где посредством цветового фона, система выделяет атрибуты, которые имеют различные значения и отсутствующие атрибуты.

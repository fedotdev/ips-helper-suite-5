# Формирование состава объекта
Формирование состава объекта может происходить автоматически и вручную. Автоматически в состав одних объектов попадают другие объекты согласно настройкам системы (так, например, при открытии объекта типа **Сборочная единица** система автоматически создает и добавляет в его состав объект типа **Спецификация**). Вручную пользователь может добавлять объекты в состав с помощью специальных команд. 
Пользователь имеет возможность добавлять как уже существующие объекты, так и создавать новые объекты в составе других. Существует несколько способов добавления одних объектов в состав других.

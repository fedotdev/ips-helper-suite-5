# Просмотр аутентичного файла
Для того чтобы просмотреть аутентичный файл, сформированный на конструкторско-технологический документ, следует:
1\. Открыть необходимый тип объекта в приложении **Навигатор** и в рабочей области выделить интересующий объект.
2\. С помощью контекстного меню объекта следует вызвать подкоманду **Смотреть** в команде **Аутентичные файлы**.
Примечание: если объект содержит несколько аутентичных файлов, то команда **Смотреть** откроет первый по списку аутентичный файл.
Для реализации просмотра конкретного аутентичного файла следует:
1\. Открыть необходимый объект в новом окне с помощью команды **Открыть в новом окне** его контекстного меню или воспользоваться сочетанием клавиш **[Ctrl+Enter]**.
2\. Открыть закладку **Файлы** и выделить необходимый аутентичный файл к атрибуту **Файл** в области **Список атрибутов**.
3\. С помощью контекстного меню выделенного файла вызвать команду **Смотреть**.

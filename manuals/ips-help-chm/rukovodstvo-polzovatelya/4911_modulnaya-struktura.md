# Модульная структура
По своей структуре Intermech Professional Solutions представляет собой информационное ядро с набором функциональных модулей, расширяющих возможности ядра. Модульная организация упрощает работу с системой, позволяя загружать на клиентское приложение только необходимый данному пользователю набор функций в зависимости от роли, в которой он входит в систему.
API-интерфейс системы позволяет предприятиям-пользователям создавать собственные модули расширения, как для серверной, так и для клиентской части системы для реализации дополнительных функций. Модули могут быть написаны на любом .NET языке программирования и наследовать открытую функциональность любого модуля, входящего в состав системы. API-интерфейс позволяет также интегрировать IPS с другими информационными системами.

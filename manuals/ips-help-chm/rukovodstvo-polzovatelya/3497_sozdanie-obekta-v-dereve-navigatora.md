# Создание объекта в дереве Навигатора
Система IPS позволяет создавать объекты определенных типов непосредственно в дереве **Навигатора**. Для этого необходимо выполнить следующие действия:
· В дереве навигации отметьте тип объектов, которому будет принадлежать создаваемый объект, и примените команду **Создать** его контекстного меню для перехода в диалог создания нового объекта:
· В появившемся диалоговом окне внесите необходимые сведения о создаваемом объекте.
· Нажмите **Готово**.

# Марочник материалов
Модуль расширения**Марочник материалов (Intermech materials handbook – IMH)** предназначен для управления информацией о материалах, которую можно использовать в процессе автоматизированного конструкторского и технологического проектирования.
**Марочник материалов** состоит из следующих разделов:
· [**Клеи**](_11.md)**.**
· [**Лакокрасочные**](_1.md)**материалы.**
· **Масла и смазки.**
· **Материалы.**
· **Покрытия.**

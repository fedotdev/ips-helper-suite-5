# Опции для объектов
Если тип объекта позволяет осуществлять конфигурирование составов, то при выборе таких объектов в дереве и списках **Навигатора** будет доступна закладка **Конфигуратор**.
Данная закладка является комплексным инструментом, позволяя осуществлять следующие действия:
− назначать/удалять опции для текущего объекта;
− импортировать опции из других объектов;
− настраивать видимые значения для опций;
− редактировать условия несовместимости для значений опций;
− редактировать списки связанных значений опций;
− просматривать изображения для значений опций;
− редактировать условия применения текущего объекта, если он расположен в составе;
− редактировать значения опций, которые будут применяться во вложенном составе объекта.
Внешний вид закладки **Конфигуратор** приведен на изображении:
Основной закладкой является **Опции объекта** , остальные закладки будут рассмотрены далее.
Опции, назначенные объекту, отображаются в дереве **Категории и опции**. При выборе категории или опции в дереве в списке справа будут отображаться значения выбранных опций. Доступно четыре режима отображения значений опций в данном списке:
1\. Отображение видимых значений без изображений:
В этом случае скрываются все невидимые значения, а также изображения для значений опции.
2\. Отображение всех значений без изображений:
В этом случае скрываются только изображения для значений опции.
3\. Отображение видимых значений с изображениями:
В этом случае скрываются все невидимые значения опции.
4\. Отображение всех значений с изображениями:
В этом случае отображается все содержимое опции.
Управление режимами просмотра осуществляется с помощью кнопок и . Первая кнопка отвечает за отображение/скрытие изображений, вторая фильтрует невидимые значения опций.
В списке значений опций также доступно контекстное меню:
Кнопка управляет видимостью вложенных закладок **Условия несовместимости** , **Связанные значения** и **Изображение** для выбранного значения опции:
Данные редакторы будут рассмотрены более подробно далее.

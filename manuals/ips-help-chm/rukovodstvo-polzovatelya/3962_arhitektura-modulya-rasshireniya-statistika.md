# Архитектура модуля расширения Статистика
Модуль расширения **Статистика** представляет собой приложение, которое отрывается в отдельном окне при вызове команды **Статистика** из главного меню **Приложения**. 
Архитектура модуля проста: слева – область навигации, разделенная на группы. Данные группы классифицируют созданные команды сбора статистики на часто используемые и все объекты статистики. Справа – рабочая область, в которой предоставляется возможность осуществлять необходимые манипуляции с созданным методом сбора статистики. На рисунке показан внешний вид окна модуля **Статистика** с ранее выбранным объектами команды статистики.

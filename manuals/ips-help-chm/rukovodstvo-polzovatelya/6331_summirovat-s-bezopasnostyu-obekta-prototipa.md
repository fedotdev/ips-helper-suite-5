# Суммировать с безопасностью объекта-прототипа
Система IPS предоставляет возможность суммировать данные права доступа объекта-прототипа с правами доступа объекта, созданного по прототипу, суммарная безопасность отображается на закладку **Безопасность**. 
Такая возможность доступна при условии, что администратор системы добавит атрибут **Суммировать с безопасностью объекта-прототипа** необходимому типу объекта, на который будут созданы прототипы, на рисунке ниже показан добавленный атрибут для объекта типа **Детали** :
Примечание: для корректного отображения суммирования безопасности, следует включить параметр **Возможна модификация без взятия на изменение** для атрибута **Суммировать с безопасностью объекта-прототипа** , так как показано на рисунке выше.
На рисунке ниже показана закладка **Безопасность** с настроенным атрибутом **Суммировать с безопасностью объекта-прототипа:**
**Внимание!** Настройка атрибута **Суммировать с безопасностью объекта-прототипа** доступна только пользователю с правами администратор системы IPS.

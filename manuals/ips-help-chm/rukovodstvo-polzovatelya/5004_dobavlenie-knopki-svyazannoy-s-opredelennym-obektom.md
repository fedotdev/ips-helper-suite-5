# Добавление кнопки, связанной с определенным объектом
Для размещения на панели инструментов кнопки, связанной с каким-либо информационным объектом IPS, имеющим состав, нажмите кнопку **Добавить** и выберите пункт меню **Кнопка состава объекта**. При этом будет отображено окно, в котором следует выбрать объект IPS:
Например, был выбран объект **Стол рабочий арт.А-1 (Технологическая сборка)** , затем была нажата кнопка **ОК**. После этого в редакторе кнопок появится соответствующая запись в списке кнопок:

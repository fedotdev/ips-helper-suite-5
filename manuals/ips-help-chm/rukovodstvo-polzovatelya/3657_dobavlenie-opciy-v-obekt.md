# Добавление опций в объект
Чтобы добавить опцию в объект, следует нажать кнопку **Добавить опции** либо вызвать одноименную команду из контекстного меню в дереве опций:
При этом будет отображено окно, позволяющее выбрать опции для объекта:
Выберите требуемые опции и нажмите кнопку , чтобы внести изменения в объект. Если были выбраны опции, которые уже присутствуют в редактируемом объекте, они будут проигнорированы.

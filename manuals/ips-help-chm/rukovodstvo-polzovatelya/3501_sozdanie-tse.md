# Создание ТСЕ
Примечание: данная команда будет доступна в том случае, если загружен модуль расширения **Управление информацией об изделиях PDM** и выключен модуль**Редактор технологической ЭСИ**.
IPS предоставляет возможность создать технологическую сборочную единицу (далее ТСЕ) на основе существующего конструкторского состава объекта. Для этого необходимо выполнить следующие действия:
1\. Выбрать объект, на основе которого будет создана ТСЕ, и взять его на редактирование.
2\. Вызвать команду **Создать/ТСЕ** из контекстного меню.
3\. В появившемся диалоговом окне следует выбрать контекст формирования состава и нажать кнопку .
4\. В открывшемся окне **Создание нового объекта** следует внести необходимые сведения о создаваемом объекте.
5\. Для продолжения создания ТСЕ следует нажать кнопку .
6\. В открывшемся редакторе предоставляется возможность выделить дочерние объекты и переместить их в созданную ТСЕ. Для этого следует нажать кнопку .
7\. В открывшемся окне необходимо указать количество для каждого переносимого объекта в состав ТСЕ. Например, смотрите рисунок ниже.
8\. Для исключения объектов из состава ТСЕ необходимо выделить объекты и нажать на кнопку **Удалить указанные элементы из состава технологической сборочной единицы.**
9\. После формирования состава, следует завершить редактирование ТСЕ, для этого необходимо воспользоваться командой **Завершить редактирование** из контекстного меню ТСЕ.
10\. Для подтверждения действия следует нажать кнопку в системном диалоговом окне.
В составе сборочной единице, на основании которой была создана ТСЕ отобразиться технологический объект.
Чтобы просмотреть состав объекта с учетом его контекста, можно воспользоваться соответствующим режимом фильтрации состава – см. п. .

# Формирование состава в доработанной сборочной единицы в системе IPS на основании данных из CAD-системы
Для формирования состава в доработанной сборочной единицы пользователю следует инициировать расширенное сохранение состава доработанной сборочной единицы изделия из CAD-системы в IPS.
**Внимание!** При сохранении расширенного состава, автоматически запускается процесс проверки на корректность и достаточность данных для формирования состава доработанной сборочной единицы.
Примечание: если при проверке будет выявлена ошибка, то система выдаст соответствующее сообщение о причине некорректности данных и формирование состава в доработанной сборочной единице будет остановлено.
При успешном завершении проверки осуществляется расширенное сохранение модели доработанной сборочной единицы. В рабочей области **Навигатора** будет сформирован объект нового типа **Доработанная сборочная единица**.

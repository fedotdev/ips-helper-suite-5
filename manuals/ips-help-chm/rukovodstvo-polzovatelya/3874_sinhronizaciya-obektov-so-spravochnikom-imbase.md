# Синхронизация объектов со справочником IMBASE
Система IMBASE предоставляет пользователю возможность обновлять данные объектов IPS связанных с объектом IMBASE. Для этого служит команда контекстного меню **IMBASE/Синхронизировать**. Синхронизацию данных объектов IPS можно производить двумя способами.

# Аналоги
Примечание: данная функциональность будет доступна в том случае, если загружен модуль расширения **Управление информацией об изделиях PDM**.
Механизм аналогов предназначен для реализации глобальной замены в составах одного объекта на другой аналогичный объект. В отличие от допустимых замен (см. п. ), аналоги действуют сразу на все входимости объекта в другие объекты по связям любого типа. Аналоги могут быть использованы, например, для назначения глобальных замен стандартных покупных изделий в составе сборочных единиц в случаях временных или постоянных изменений в номенклатуре закупаемых комплектующих.
Настройка аналогов для версии объекта производится на закладке **Аналоги**. Данная закладка доступна для объектов тех типов, для которых администратор в **Конфигураторе БД** назначил исходящие связи типа **Аналоги**. На панели инструментов закладки расположены следующие команды:
**Добавить** – добавляет существующие объекты в качестве аналогов.
 **Создать** – создает новый объект и добавляет его в качестве аналога.
 **Удалить** – исключает выделенные объекты из списка аналогов.
 **Карточка** – открывает карточку выбранного аналога на закладке **Свойства связи** , чтобы пользователь мог указать для аналога значения следующих атрибутов. Для аналогов доступны следующие атрибуты:
**Дата начала действия** – задается дата начала действия аналога.
**Дата окончания действия** – задается дата окончания действия аналога.
**Приоритетный аналог** – позволяет указать приоритетный аналог при наличии нескольких вариантов.
 **Обновить** – позволяет обновить содержимое окна.
Подбор аналогов в составе производится с помощью кнопки Подбор аналогов, которая доступна на тулбаре **Фильтрация состава**. Поддерживаются следующие режимы подбора:
**Не подбирать аналоги** – система не предпринимает никаких действий по подбору аналогов (это значение по умолчанию).
**Подобрать действующий аналог** – система заменяет в составе объект на его аналог, но только если найдет однозначный вариант замены. 
**Подобрать один аналог** – система в любом случае заменяет объект, для которого назначены аналоги, на один аналог.
Статусы подбора могут быть следующие:
 **Действующий аналог**. Объект является единственным аналогом, который назначен действующим на данную дату.
 **Приоритетный или единственный аналог**. Объект является аналогом, назначенным в качестве приоритетного аналога при выполнении подбора аналогов для объекта. Либо на объект назначен только этот аналог.
**Аналог**. Объект является просто одним из аналогов, назначенных на объект. Он не является приоритетным, на него либо не назначен период действия, либо его период действия не соответствует заданной дате. 
 **На объект назначены аналоги**. Этот статус рисуется рядом с объектом в составе, для которого в базе назначены аналоги.
По умолчанию подбор аналогов идет на текущую дату. Если включен подбор по сериям и датам (см. п. ) и задана дата, то подбор аналогов идет на заданную дату.

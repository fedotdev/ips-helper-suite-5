# Настройка отображения
В рабочей зоне **Состав объекта** пользователь может изменить набор отображаемых колонок, вызвав с помощью команды **Настройка отображения** контекстного меню одного из объектов состава диалог настройки отображения (см. п. ). После выполнения настройки отображения в дереве групп допустимых замен будут отображаться те же самые колонки плюс колонка **Примечание** , в которой отображается текст расшифровки допустимых замен.

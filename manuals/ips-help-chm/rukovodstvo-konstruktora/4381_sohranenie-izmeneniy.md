# Сохранение изменений
При сохранении изменений в документах Altium Designer интегратор перечитывает значения атрибутов документа **Данные проектирования** из параметров файла проекта, и наоборот, при редактировании синхронизируемых атрибутов в карточке документа **Данные проектирования** интегратор сохраняет новые значения параметрам файла проекта.
Аналогично сохраняются изменения и у электрических схем. Синхронизация происходит между настроенными атрибутами документов IPS и параметрами документа в схеме Altium Designer (файлы *.SchDoc).

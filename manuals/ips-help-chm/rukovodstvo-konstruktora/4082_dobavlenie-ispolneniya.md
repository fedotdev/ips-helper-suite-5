# Добавление исполнения
Для того чтобы к уже существующим исполнениям объекта добавить исполнение необходимо:
· В правой части окна **Список исполнений** выбрать корневой элемент дерева **Список исполнений** и вызвать для него команду контекстное меню **Добавить исполнение**.
· В появившемся диалоговом окне необходимо выбрать объект, который будет исполнением, и нажать кнопку **ОК**.

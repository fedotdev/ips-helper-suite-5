# Соответствия типов объектов
· **Файлы производства**. Настройка списка возможных типов объектов IPS, с которыми интегратор будет работать при создании файлов производства. 
Примечание: если задано значение **Файлы производства ПП** , то будут создаваться объекты только этого типа.

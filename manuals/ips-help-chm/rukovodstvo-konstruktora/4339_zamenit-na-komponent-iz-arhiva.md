# Заменить на компонент из архива
Данная команда позволяет вставить компонент CAD-системы (деталь или сборку) в проектируемую сборку из архива IPS вместо выбранного компонента.
Для замены компонента вызовите команду **Заменить на компонент из архива** , откройте необходимый архив и выберите компонент для вставки.

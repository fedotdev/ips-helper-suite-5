# Подготовка Altium Designer к работе
Для работы интегратора IPS необходимо установленное в Altium Designer расширение **IPSAddIn**. Для установки следует запустить файл **File\AltiumDesigner\IPSAddln.Installer.exe** из комплекта поставки IPS.

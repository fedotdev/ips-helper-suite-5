# В текущую строку добавить данные из Imbase
Действие данной команды аналогично команде **Добавить из Imbase** , но данные заносятся в имеющуюся текущую строку. Т.е. вначале необходимо создать основную строку, заполнить ее данными с клавиатуры, а затем добавить данные из Imbase. Т.к. данные из Imbase заносятся в ячейки не зависимо от их заполненности, то по данной команде можно корректировать (изменять) имеющиеся записи.

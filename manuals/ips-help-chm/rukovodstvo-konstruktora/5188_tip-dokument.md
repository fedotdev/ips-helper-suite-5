# Тип Документ
· Откройте закладку **Тип Документ**.
· На данной странице введите необходимые данные.
· **Наименование типа документа**. Введите **Ведомость крепежа**.
· **Отрисовывать наименование типа в штампе чертежа**. Выберите **Да**.
· **Код типа документа**. Введите **ВК**.
· **Код типа документа входит в обозначение**. Выберите **Да**. Это дает возможность создания документа с **Обозначение изделия** \+ **Код типа документа**.
Нажмите кнопку **Применить**.

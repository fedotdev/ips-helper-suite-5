# Вид НТД
Атрибут **Вид НТД** используется в **Ведомости ссылочных документов.**
Этот атрибут содержит значение, используемое в сортировке согласно ГОСТ Р 2.106-2019 п. 4.4
В каждом разделе документы рекомендуется группировать по видам в следующей последовательности:
− стандарты;
− технические условия на покупные изделия и материалы;
− инструкции и т.п.
В **Конфигураторе базы** данных параметры атрибута должен соответствовать следующим
**Допустимые значения** определяются требованиями сортировки и содержат значения, по которым и осуществляется сортировка.

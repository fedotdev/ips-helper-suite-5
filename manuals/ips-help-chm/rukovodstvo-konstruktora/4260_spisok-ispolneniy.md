# Список исполнений
Данная команда доступна только в групповых документах.
У ведомости, созданной автоматически из групповой спецификации, данная команда недоступна т.к. количество исполнений и их обозначения не могут отличаться от исполнений изделия.
По данной команде можно:
· Добавить новые исполнения.
· Переименовать исполнения.
· Удалить исполнения.
По команде отображается диалог.

# Основные принципы работы
Система IPS при работе с CAD-системами поддерживает два режима работы:
· Работа с моделями.
· Работа с моделями и изделиями.
Все файлы моделей хранятся в папке рабочей области системы IPS (т.н. файловом хранилище). Данная папка указывается при установке клиента IPS на компьютер.

# Создание спецификации с помощью главного меню
· Вызовите с помощью главного меню **Файл/Создать/Новый объект** диалоговое окно **Создание нового объекта** , в нем выберите тип объектов **Документы/Конструкторские документы/Спецификации** и нажмите кнопку **Далее**.
· В появившемся диалоговом окне выберите тип специфицируемого изделия, введите обозначение и наименование новой спецификации и нажмите **ОК**.

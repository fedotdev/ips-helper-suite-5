# Создание нового шаблона
· Выполните команду **Приложения/Навигатор**.
· В дереве конфигуратора выберите **Объекты/Настройки системы/Шаблоны документов (бланки) / Шаблоны ведомостей.**
· В правой части отображается список уже имеющихся шаблонов. 
· В этом списке по правой кнопке откройте контекстное меню.
· Выберите команду **Создать/По прототипу** (рекомендуется) или **Создать/Создать Шаблон ведомости**.
· Введите (измените) имя файла.
· Нажмите кнопку **Далее**.
· Введите **Наименование** , **Обозначение** и **Формат**.
· Заголовок объекта не заполняйте, он будет изменен автоматически.
· Нажмите кнопку **Готово**.

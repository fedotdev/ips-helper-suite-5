# Тип ведомости
По этой команде текущему типу ведомости можно присвоить основные свойства определенной системной ведомости. Например, если текущая ведомость - **Ведомость крепежа**. Это ведомость пользовательская. По этой команде ей можно присвоить основные свойства **Ведомости покупных изделий**. Данная кнопка отображается только при настройке пользовательских ведомостей.

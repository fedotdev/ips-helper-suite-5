# Создать документ заново
По этой команде производится автоматическое создание ведомости, для той спецификации, по которой создавалась текущая ведомость. Команду рекомендуется выполнять если изменился состав изделия или правила создания ведомости.
Для ведомости, созданной не из спецификации автоматически, данная команда не доступна.

# Основная строка
Используется для вывода информационных записей. 
В основной строке имеются различные ячейки и **Подтаблица Куда входит**. В строках этой подтаблицы выводятся данные о входимости в различные изделия.
В данную подтаблицу входят строки **Строка Куда входит** , которые в свою очередь содержит различные ячейки.
В подтаблицу входит строка **Строка Кол итого**. Эта подтаблица завершается ячейкой **Кол итого** для оформления надчеркивания итогового количества

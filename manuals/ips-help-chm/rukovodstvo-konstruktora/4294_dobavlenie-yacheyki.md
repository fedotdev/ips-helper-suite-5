# Добавление ячейки
· Выберите в дереве ячейку, после которой необходимо добавить новую ячейку или выберите в дереве нужную запись, в которую добавить ячейку.
· Выберите в текущей строке шаблона ячейку.
· Введите имя **Xml**.
· Нажмите кнопку **Добавить**.

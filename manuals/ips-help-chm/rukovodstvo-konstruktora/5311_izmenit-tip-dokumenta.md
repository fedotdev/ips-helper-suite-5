# Изменить тип документа
Данная команда позволяет изменить тип текущей ведомости в пределах ведомостей аналогичного типа. Например, если существуют Ведомости покупных изделий, выполняемых на различных бланках. По данной команде производится только изменение вывода информации на бланк. Изменение самой информации не производится.
Команда доступна только если есть несколько типов ведомости, ссылающихся на один, общий тип ведомости.

# Чтение документов AVS6
Конструкторские ведомости и конструкторские таблицы, разработанные в программе AVS v.6 можно внести в систему IPS.
В редакторе конструкторской ведомости или таблицы в меню **Документ** доступны команды:
· **Читать данные из файла AVS6**.
· **Создать документ из файла AVS6**.
Команда **Читать данные из файла AVS6** предназначена для выбора файла программы AVS6 и внесения данных из этого файла в **текущий** документ IPS, т.е. открытый в текущем окне редактора.
Команда **Создать документ из файла AVS6** предназначена для выбора файла программы AVS6 и создания соответствующего **нового** документа в системе IPS.
Настройка соответствия документов AVS и IPS производится по команде **Настройка / Настройка чтения документов AVS6** (см. п. ).
Настройка правил ввода данных производится в диалогах **Настройка конструкторских ведомостей** и **Настройка конструкторских таблиц**.
Эти команды доступны только если включена **Настройка / Параметры IPS / Редактор AVS / Чтение документов AVS6.**

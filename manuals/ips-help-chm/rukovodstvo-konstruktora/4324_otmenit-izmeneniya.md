# Отменить изменения
С помощью команды **Отменить изменения**  все произведенные изменения над документом, сделанные в рабочей копии удаляются и документ возвращается в архив. Рабочая копия удаляется из PDM системы, остаётся только архивная. Команда не доступна для группы компонентов.

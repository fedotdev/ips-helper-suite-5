# Редактор примечаний программной спецификации
Согласно ЕСПД при отсутствии места в графе **Примечание** допускается записывать только порядковые номера примечаний, а текст примечаний переносится в конец соответствующих разделов спецификации. Допускается текст примечаний записывать на последних листах спецификации, на листах без граф с проставлением порядкового номера примечания.
Для программных спецификаций доступна возможность создавать примечания к разделам, для этого следует:
1\. Взять на редактирование программную спецификацию и открыть в новом окне.
2\. На главной панели инструментов выбрать меню **Документ** , а затем команду **Редактор примечаний**.
3\. В открывшемся окне **Примечания** необходимо выбрать раздел спецификации, к которому следует добавить примечание.
4\. Для продолжения создания примечания в разделе следует нажать кнопку .
5\. В появившейся пустой строке необходимо проставить нумерацию с помощью кнопку , а затем в строке для ввода добавить необходимый текст. Активировать строку ввода необходимо двойным кликом мышки.
6\. Для завершения создания примечания следует нажать кнопку .
С помощью кнопок и пользователь может настроить последовательность примечаний в разделе. При нажатии кнопки все примечания будут перенесены на отдельную страницу.
На отдельных строках можно через локальное меню выполнить команду **Создать ссылку на примечание** и выбрать примечание из списка. В данной строке отобразится ссылка на это примечание.
В редакторе программной спецификации есть отдельная команда **Добавить лист примечаний**. По этой команде добавляется отдельный лист.

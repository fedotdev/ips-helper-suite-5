# Титульный лист
Титульный лист должен иметь имя – **Титульный лист**.
На листе имеются таблицы с ячейками, заполняемыми пользователем. Настройки заполнения ячеек см. в примерах ведомости.
Параметр листа **Следующая страница** должен иметь текст **Следующая страница**.
Примечание: если **Титульный лист** необходимо выводить в каждой ведомости данного типа, то этот лист в шаблоне должен находиться первым. В этом случае при создании ведомости в **Навигаторе** ,**Титульный лист** создается автоматически.

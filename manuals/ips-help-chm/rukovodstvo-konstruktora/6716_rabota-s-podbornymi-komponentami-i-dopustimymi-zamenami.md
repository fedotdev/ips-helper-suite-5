# Работа с подборными компонентами и допустимыми заменами
Для организации в IPS работы с подборными компонентами в составе, полученном по проекту Delta Design, необходимо произвести предварительную настройку интегратора и компонентов на схеме проекта Delta Design.
Подборный компонент на схеме должен обладать следующим набором параметров: 
· **Идентификатор того, что компонент подбирается при регулировании**. По наличию данного признака, при формировании состава система включит компонент отдельной связью со значением атрибута связи **Подбор = Да**. Для данного компонента будет возможным добавление компонентов для подбора.
Для этого необходимо у компонента на схеме в свойстве **Подборные радиодетали** выбрать из списка доступные радиодетали для подбора.

· **Предельные значения** , которые необходимо указать у компонента на схеме в свойстве **Параметры подбора**.
· **Позиционное обозначение ДС** — это дополнительные символы к позиционному обозначению, которые необходимо указать в дополнительных свойствах подборного компонента на схеме.

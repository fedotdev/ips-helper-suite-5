# Расширенное сохранение
Команда **Расширенное сохранение**  выполняется для формирования состава изделий или обновления информации по изделиям. При выполнении данной команды для сборок она будет автоматически применена для всех подсборок и деталей входящих в сборку.
При выполнении расширенного сохранения для документа, не зарегистрированного в базе данных IPS, он будет автоматически зарегистрирован в IPS.

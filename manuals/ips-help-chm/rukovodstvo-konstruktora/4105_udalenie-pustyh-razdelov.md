# Удаление пустых разделов
Чтобы удалить все пустые разделы конструкторского документа можно применить команду **Документ/Удалить пустые разделы** главного меню. Команда так же проверяет переменные данные в групповом документе формы А и если они не содержат данных, то заменяет заголовки исполнений общим заголовком с надписью типа: **Различия исполнений по сборочному чертежу**.
Чтобы вернуть заголовки всех исполнений в переменных данных формы А, необходимо выполнить команду **Документ/Показать переменные данные** главного меню. При добавлении записей в переменных данных, заголовки возвращаются автоматически.

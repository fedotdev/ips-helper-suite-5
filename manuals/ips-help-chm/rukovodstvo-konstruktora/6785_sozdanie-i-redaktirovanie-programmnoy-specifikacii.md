# Создание и редактирование Программной спецификации
Создание спецификации при выполнении соответствующей команды в **Навигаторе**.
При диалоговом создании программной спецификации автоматически (если включено в настройке) создаются **Титульный лист** и **Лист утверждения**.
Запись о **ЛУ** автоматически заносится в спецификацию.
Большинство команд редактора описаны для редактора ведомостей (см. п. ).
Некоторые команды характерны для **Программных документов**.

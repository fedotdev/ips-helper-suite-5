# Настройка импорта данных
Для настройки импорта данных, в свойствах интегратора есть две настройки.
**Не импортируемые папки.** В этом списке перечислены папки, которые не будут импортированы в базу данных IPS (различные временные папки и папки с бэкапами).
**Дополнительные файлы проекта.** Содержит список расширений файлов (через запятую, например: emp,emn,schlib), которые при наличии в одной с проектом папке, записываются в качестве дополнительных файлов к проекту Altium Designer.
Папки **_Previews** и **History,** которые могут находиться в папке проекта, не записываются в IPS по умолчанию.

# Создавать ведомость автоматически
Большинство ведомостей могут создаваться программой автоматически, исходя из данных головной и последующих спецификаций. При этом сохраняется возможность создавать и редактировать эти ведомости в диалоге.
Для некоторых ведомостей могут отсутствовать правила автоматического сбора, например, **Ведомость эксплуатационных документов**. При выключенном данном переключателе, на диалоге скрываются закладки, относящиеся к автоматическому сбору.
Для ведомостей, у которых при поставке отсутствуют правила автоматического создания, достаточно включить данный переключатель и настроить параметры сбора.

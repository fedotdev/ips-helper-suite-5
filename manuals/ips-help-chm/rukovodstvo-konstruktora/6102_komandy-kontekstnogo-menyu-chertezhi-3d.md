# Команды контекстного меню Чертежи 3D
Для работы с чертежами, которые хранятся как дополнительные файлы, в основном контекстном меню есть подменю **Чертежи 3D** с рядом команд, которые дублируют функции основных команд: **Редактировать чертеж** ,**Смотреть чертеж** ,**Смотреть чертеж…** ,**Создать аутентичный файл чертежа**.
На рисунке ниже представлено отображение команд подменю **Чертежи 3D** :
Для просмотра чертежей следует вызвать из контекстного меню объекта команду **Чертежи 3D / Смотреть** **чертеж** , которая запускает приложение **ViewDrawing**. Данное приложение назначается для конкретного типа объекта, настройка команды запуска приложения для просмотра чертежей 3D описана в п. .

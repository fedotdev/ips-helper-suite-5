# В текущую строку добавить данные из существующего объекта
Действие данной команды аналогично команде **Добавить существующий объект** , но данные заносятся в имеющуюся текущую строку. Т.е. вначале необходимо создать основную строку, заполнить ее данными с клавиатуры, а затем добавить данные. Т.к. данные заносятся в ячейки не зависимо от их заполненности, то по данной команде можно корректировать (изменять) имеющиеся записи.

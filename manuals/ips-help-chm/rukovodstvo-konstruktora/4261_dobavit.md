# Добавить
По этой команде начинается процесс создания нового исполнения. Предлагается выбрать прототип для нового исполнения.
После выбора прототипа по нажатию кнопки **ОК** отображается диалог редактирования данных исполнения.
По нажатию кнопки **ОК** отображается первое окно диалога.

# Общие
· **Параметр с типом объекта.** Строка для назначения имя параметра компонента схемы, в значении которого указывается тип создаваемого объекта в IPS.
· **Позиционное обозначение ДС.** Параметр компонента схемы, в значении которого указываются дополнительные символы к позиционному обозначению.

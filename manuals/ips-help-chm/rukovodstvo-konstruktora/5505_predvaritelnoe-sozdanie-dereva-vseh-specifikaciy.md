# Предварительное создание дерева всех спецификаций.
Этапы создания дерева спецификаций:
· Чтение «головной» спецификации.
· Последовательное чтение последующих спецификаций.
· Сортировка полученного списка спецификаций.
· Суммирование одинаковых ссылок.
· Обработка (сортировка, суммирование) всех записей дерева.
Затем, на основе этого дерева спецификаций производится создание конкретной ведомости.

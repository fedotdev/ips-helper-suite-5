# Дальнейшие действия по созданию ведомости по команде
В дальнейшем отображается диалог выбора разрабатываемой ведомости.
Выберите тип ведомости и нажмите кнопку **OK**.
Если главная спецификация групповая, то диалог имеет вид.
Выберите тип ведомости.
Укажите – создавать групповую ведомость или ведомость на одно исполнение.
· Если выбрана разработка групповой ведомости, то для ВС и ВП выберите форму документа А или Б.
· Если выбрана разработка ведомости на одно исполнение, то выберите обозначение исполнения.
По результатам данных команд будет создана выбранная ведомость. Ведомость будет создаваться согласно настройкам.

# Настройки синхронизируемых атрибутов
· **Атрибуты проекта**. В этих настройках хранится информация, какие атрибуты будут синхронизированы интегратором между файлами Delta Design и объектами в IPS. В редакторе записываются пары **Имя параметра** **ECAD = Имя атрибута данных IPS**.
· **Атрибуты элемента**. Свойство, которое позволяет задать синхронизируемые атрибуты для элемента.
· **Атрибуты связи с элементом**. Свойство, которое позволяет задать синхронизируемые атрибуты для связи с элементом. Настройка предоставляет возможность задать соответствие имени параметра связи компонента в IPS и его название на схеме.

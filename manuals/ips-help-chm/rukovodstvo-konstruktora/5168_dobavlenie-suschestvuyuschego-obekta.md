# Добавление существующего объекта
В спецификацию можно добавить объект, который уже был создан ранее в базе данных. Для этого необходимо выполнить следующие действия:
1\. Воспользуйтесь командой **Добавить существующий объект** контекстного меню спецификации или раздела спецификации, к которому будет принадлежать создаваемый объект. 
2\. В появившемся диалоге выберите объект, который необходимо добавить в спецификацию.
3\. Нажмите кнопку **ОК**.

# Многоплатные проекты DxDesigner
DxDesigner позволяет в одном проекте создавать несколько Board (печатных плат).
Разработчик в проекте делит его на части (платы). При этом существует два варианта:
· На каждую плату своя схема. При этом одна из схем, входящих в board будет являться схемой соединения других входящих в проект board.
· Схема одна общая на все входящие в проект платы (board). К каждой плате относятся определенные листы этой схемы.
Далее будут показана работа системы при обработке двух вышеуказанных вариантов.

# Создать документ из файла AVS6
Команда **Создать документ из файла AVS6** предназначена для выбора файла программы AVS6 и создания соответствующего **нового** документа в системе IPS.
Для доступа к команде необходимо открыть окно с любой ведомостью или таблицей.
Выполните команду **Создать документ из файла AVS6**.
Откроется диалог для выбора файла программы AVS6.
По нажатию кнопки **Открыть** в соответствии с настройкой (п. ) будет создан новый документ IPS и данные из выбранного файла AVS6 будут занесены в этот документ (IPS).
Все записи документа AVS6 будут, по возможности, связаны с объектами системы IPS.
Данная команда доступна только если включена **Настройка / Параметры IPS / Редактор AVS / Чтение документов AVS6.**

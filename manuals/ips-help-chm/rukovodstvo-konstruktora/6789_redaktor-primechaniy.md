# Редактор примечаний
По данной команде открывается **Редактор примечаний**. Данный редактор позволяет:
· Переносить примечания из графы **Примечания** на отдельный лист.
· Объединять примечания.
· Создавать ссылки к примечаниям.
Примечания из записей могут быть:
· Вынесены в отдельные записи в конце раздела.
· Вынесены на отдельную страницу **Примечание**.
Например, в записях есть примечания.
При выполнении в меню **Документы** команды **Редактор примечаний** открывается диалог.
**Примечания** из записей заносятся в этот **Редактор примечаний**.
 – после текущей строки добавляется новая строка для записи примечания.
 – из редактора удаляется текущая строка.
 – текущая строка переносится в раздел **Общие примечания**. После завершения работы диалога строки этого раздела выводятся на отдельной странице **Примечания**.
 – примечания нумеруются.
 – все примечания переносятся в раздел **Общие примечания**.
По завершении редактирования:
· Примечания выводятся в соответствующих строках.
· В записи спецификации заносятся ссылки на примечания.
Для создания ссылки на новое примечание необходимо:
· Выбрать строку спецификации.
· Выполнить команду **Документ / Создать ссылку на примечание**.
· Выбрать в **Редакторе примечаний** нужное примечание.
При необходимости, можно, не обращаясь к **Редактору примечаний** , выполнить команду **Документ / Добавить Лист примечаний**.

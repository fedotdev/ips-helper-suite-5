# Создание программной спецификации на основе программных изделий
В дереве **Навигаторе** по пути **Объекты / Изделия** имеются ветки **Программные комплексы** и **Программные компоненты**. На основе «дерева» программных объектов можно автоматически собрать **Программную спецификацию**.
Для этого необходимо выбрать головное **Программное изделие** и, по нажатию правой кнопки мыши, выполнить команду **Отчеты и документы / Создать программную спецификацию**.
Исходя из данных дерева будет создана спецификация, которая отобразится в редакторе.

# Ручное редактирование допустимых замен
С помощью внешнего редактора ячейки **Примечание** в объекте типа **Спецификация** пользователю доступна возможность редактирования текста допустимой замены. На рисунке ниже показан внешний редактор: 
Окно **Редактор графы Примечание** открывается посредством двойного клика мышки в ячейке Примечание или при вызове команды **Редактировать...** из контекстного меню ячейки.
Примечание: диалоговое окно **Редактор графы Примечание** позволяет удалить созданные вручную изменения и в любой момент вернуть исходный текст дополнительной замены.

# Сохранение изменений
При сохранении изменений в проекте Delta Design интегратор перечитывает значения атрибутов документа **Проекты Delta Design** из параметров проекта, и наоборот, при редактировании синхронизируемых атрибутов в карточке документа **Проекты Delta Design** , интегратор сохраняет новые значения у параметров проекта.
Воспользоваться командой **Сохранение изменений** можно, как из контекстного меню документа **Проекты Delta Design** в IPS, так и с помощью соответствующей команды из меню интерфейса Delta Design.

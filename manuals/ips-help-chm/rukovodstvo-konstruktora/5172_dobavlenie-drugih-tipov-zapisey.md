# Добавление других типов записей
Пользователю доступна возможность создавать в спецификации другие типы записей. Чтобы вставить примечание в спецификацию, необходимо отметить раздел, к которому она будет относиться, и выбрать команду из группы команд **Другие типы записей**.
В зависимости от выбранной команды, система создаст строку в указанном месте раздела, куда с помощью клавиатуры можно ввести текст.
На рисунке ниже показаны шаблоны применения подкоманд:
· Примечание 1 – команда, которая объединяет столбцы и выравнивает введенный текст по левому краю. 
· Примечание 2 – команда, которая позволяет ввести текст в правом или левом столбце и выравнивает введенный текст по левому краю.
· Примечание 3 – команда, которая позволяет ввести текст в правом или левом столбце и выравнивает введенный текст по центру с подчеркиванием.

# Порядок создания ведомости
Автоматическое создание ведомости возможно:
· По команде из **Навигатора**.
· По команде из **Редактора спецификации**.
При создании из **Навигатора** или **Редактора спецификаций** ведомость создается автоматизировано, исходя из данных главной (текущей) спецификации.

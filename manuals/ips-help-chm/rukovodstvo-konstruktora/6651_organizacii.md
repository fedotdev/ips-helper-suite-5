# Организации
Для создания **Ведомости держателей подлинников** в **Навигаторе** должен быть заполнен список **Организаций** , например:
В дальнейшем, в документах указывается только ссылка на организацию, которая при выводе видна, как наименование этой организации, а в базе по этой ссылке можно определить все данные организации.

# Редактирование допустимых замен
Редактирование созданной группы допустимых замен осуществляется посредством команды **Редактировать доп. замены**. В процессе выполнения данной команды появится диалоговое окно аналогичное окну создания **Доп. замены**. Эта команда позволяет внести изменения в предварительно сделанный список допустимых заменителей.

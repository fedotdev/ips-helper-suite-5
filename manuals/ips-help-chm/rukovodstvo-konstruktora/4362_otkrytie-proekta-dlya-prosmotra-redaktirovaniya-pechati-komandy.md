# Открытие проекта для просмотра/редактирования/печати (Команды Открыть, Редактировать, Смотреть, Печатать)
При использовании команды на документе Mentor Graphics производится запуск приложения DxDesigner с последующей загрузкой файла проекта *.prg. Если на компьютере уже запущено приложение DxDesigner, то проект загружается в него. Перед загрузкой проекта производится выгрузка файлов проекта в рабочую область. Взятие на изменение документа Mentor Graphics производится в соответствии с выбранной командой.

# Формирование наименования компонента схемы в IPS из нескольких атрибутов компонента в схеме Delta Design
Система позволяет формировать **Наименование** компонента из нескольких параметров компонента на схеме. Для этого в свойствах интегратора с Delta Design необходимо задать в настройках маску, по которой будут собираться параметры для синхронизации атрибутов.

# Активизировать вариант допустимой замены
При необходимости активизировать допустимую замену можно из контекстного меню командой **Активизировать** , предварительно выбрав требуемый вариант заменителя, либо через диалог создания – редактирования вариантов допустимых замен по команде **Сделать выбранный вариант активным**.

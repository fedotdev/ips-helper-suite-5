# Добавить лист регистрации изменений
Лист регистрации изменений добавляется при автоматическом сборе ведомости при выполнении условий настройки см. п. .
В основном меню **Документ** есть команда **Добавить лист регистрации изменений**.
По данной команде в документ добавляется **Лист регистрации изменений**. Первоначально на листе есть одна пустая запись. Редактирование данного листа производится пользователем.
В ячейках **Листа регистрации изменений** (ЛРИ) доступны команды вставки записей в ЛРИ

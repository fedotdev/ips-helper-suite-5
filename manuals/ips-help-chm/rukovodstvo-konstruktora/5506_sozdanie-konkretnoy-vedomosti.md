# Создание конкретной ведомости
Этапы создания конкретной ведомости:
· Вводятся данные из каждой спецификации, читаемой из дерева.
· Сортировка полученных данных.
· Суммирование одинаковых записей ведомости.
· Создание заголовков.
· Оформление собранных данных в виде документа.
· Сохранение документа в базе данных.
Понимание этих этапов необходимо при настройке ведомостей.

# Формирование электронного состава изделия на основании модели из CAD-системы
Если конструктор разработал модель изделия в CAD-системе, то у него есть возможность сформировать электронный состав изделия в системе IPS на основании информации из этой модели. Для этого используется механизм интеграции системы IPS с CAD-системами.
На основании иерархии файлов модели из CAD-системы в IPS формируется состав документов, в содержимое которых копируется информация из этих файлов. По структуре модели формируется электронный состав изделия. Если для модели существуют несколько конфигураций (исполнений), то для создаваемого электронного состава изделия формируются исполнения. Завершающим этапом работы интегратора является создание взаимосвязей между сформированными составами документов и изделий.
В дальнейшем конструктор получает возможность вносить изменения в атрибуты (параметры) моделей, выполнять просмотр моделей, получение печатных копий, а также осуществлять редактирование моделей изделий и деталей.

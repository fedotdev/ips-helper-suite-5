# Доп. Файлы
Команда **Доп. Файлы** служит для вызова окна дополнительных файлов компонента **Дерева состава**. После вызова команды будет открыта карточка документа на закладке **Файл,** на которой отображается список файлов составляющих документ. Список содержит все файлы документа. Обычно список файлов формируется автоматически, например, сюда попадут все файлы исполнений.

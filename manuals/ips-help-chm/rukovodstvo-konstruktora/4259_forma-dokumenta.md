# Форма документа
По данной команде можно изменить групповую форму документа.
Для ВС и ВП возможно преобразовать документ в форму Б, для всех остальных документов возможно создание единичного документа или групповой формы А.
У ведомости, созданной автоматически из единичной спецификации, данная команда недоступна т.к. для единичного изделия ведомость не может быть групповой.
**Внимание!** Документы, после преобразования в форму Б, нельзя преобразовать в форму А или единичную.

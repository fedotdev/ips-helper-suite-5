# Настройка команды Чертежи 3D / Смотреть чертеж
Для корректной работы команды **Чертежи 3D / Смотреть** **чертеж** следует настроить команды запуска приложений. Для это необходимо:
1\. На главной панели системы IPS выбрать меню **Настройка** и вызвать команду **Настройка инструментов**.
2\. В открывшемся окне **Настройка инструментов** на странице Команды запуска приложений следует выбрать в дереве Навигатора **Объекты / Документы / Конструкторские документы / Электронные модели деталей / Детали КОМПАС**.
3\. В рабочей области окна **Настройка инструментов** на закладке **Редактор команд** следует нажать кнопку **Создать**.
4\. Далее в открывшемся окне **Создание новой команды** следует выбрать тип запуска приложения для создаваемой команды, затем необходимо нажать кнопку .
5\. Далее следует указать тип создаваемой команды запуска приложения, затем нужно нажать кнопку .
6\. После создания команды необходимо настроить ее параметры, для этого следует воспользоваться командой **Свойства**. 
7\. В открывшемся окне следует заполнить основные строки, а затем нажать кнопку и . 
8\. В окне **Настройка инструментов** перейти на закладку **Команды по умолчанию** и назначить для команды **Просмотр** команду по умолчанию.
9\. Для завершения настройки команды **Чертежи 3D / Смотреть** **чертеж** необходимо нажать кнопку .

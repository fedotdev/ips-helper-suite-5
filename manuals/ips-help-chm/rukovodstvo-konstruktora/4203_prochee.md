# Прочее
Область **Лист регистрации изменений** позволяет установить параметры вывода бланка листа регистрации изменений.
Лист регистрации изменений добавляется при автоматическом формировании ведомости, когда количество листов достигает количества листов, определенного настройкой.
Можно изменить это, граничное число листов.
Можно выключить возможность автоматического вывода бланка ЛРИ.
Лист регистрации изменений (ЛРИ) добавляется не заполненный.
Область **Пропуск строк:**
Область**Дополнительные записи:**
Имеется возможность использовать в редакторе дополнительные записи, которые отличаются параметрами вывода от других записей. Для этого в шаблоне (бланке) предусматриваются соответствующие типы строк. В данном элементе настройки включается возможность использования этих записей.

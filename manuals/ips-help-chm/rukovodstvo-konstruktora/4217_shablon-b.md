# Шаблон Б
Согласно ЕСКД **Ведомость спецификаций** и **Ведомость покупных изделий** могут быть групповой формы Б. При настройке ведомостей типа ВС и ВП можно к шаблону единичной ведомости выбрать соответствующий шаблон формы Б. Данная кнопка отображается только для ведомостей типа ВС и ВП.

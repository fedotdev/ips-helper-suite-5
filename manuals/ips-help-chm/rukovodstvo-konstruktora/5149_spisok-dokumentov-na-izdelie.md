# Список документов на изделие
Схема позволяет отыскать документы, которые входят в состав выбранного в дереве или списке **Навигатора** изделия. При поиске изучается состав на один уровень вниз.
Например, для сборочной единицы будет найдена конструкторская спецификация, если она есть в составе.

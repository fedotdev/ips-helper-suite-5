# Ввод документов AVS6
На данной странице производится настройка вывода данных из файлов программы AVS6.
Порядок работы на данной странице полностью аналогичен порядку работы по настройке вывода (п. ). Только в левом списке выбирается соответствующее поле AVS6.
Данная страница доступна только если включена **Настройка / Параметры IPS / Редактор AVS / Чтение документов AVS6.**
Ввод данных AVS6 возможен для всех документов, кроме спецификаций.

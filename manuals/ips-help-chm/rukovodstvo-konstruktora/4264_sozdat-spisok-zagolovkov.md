# Создать список заголовков
ГОСТ Р 2.106-2019 п. 4.5.4 допускает вывод списка заголовков разделов. Например:
Для этого предназначена команда **Ведомости/Создать список заголовков**.
Команда доступна только для **Ведомости покупных изделий**.

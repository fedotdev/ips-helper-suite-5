# Шаблоны программных документов
Согласно требованиям ЕСПД все программные документы имеют **Титульный лист**. Соответственно каждый шаблон имеет **Титульный лист**. Имя этой страницы **Титульный лист**.
Следующая страница имеет имя **Следующая страница**.
Затем расположена страница **Лист регистрации изменений**.
Затем расположена страница **Примечания**.
Такую структуру имею шаблоны **Программной спецификации** и **Программных ведомостей**.

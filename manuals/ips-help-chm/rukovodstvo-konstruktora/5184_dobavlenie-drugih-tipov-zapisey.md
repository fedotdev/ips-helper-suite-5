# Добавление других типов записей
Кроме разделов и записей об объектах перечня элементов может содержать и другие типы записей — заголовки и примечания. Чтобы вставить одну из записей в перечень элементов, необходимо отметить раздел, к которому она будет относиться, и выбрать необходимую команду из группы команд **Другие типы записей**.
В зависимости от выбранной команды, редактор создаст запись, куда с помощью клавиатуры можно ввести текст.

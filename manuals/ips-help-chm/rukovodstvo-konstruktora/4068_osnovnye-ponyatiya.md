# Основные понятия
В данной главе приводится описание основных терминов, которыми оперирует Intermech Professional Solutions. Знание терминологии необходимо для понимания принципов работы в системе, поэтому пользователям рекомендуется внимательно ознакомиться с содержимым главы. Для удобства поиска информации понятия приведены в алфавитном порядке.
| **Термин** | **Описание** |
| --- | --- |
| Входимость | Понятие, характеризующее использование составных частей изделия в составе другого изделия и/или его составных частей. |
| Групповой конструкторский документ | Конструкторский документ, содержащий постоянные и переменные данные исполнений двух и более изделий. |
| Документ | В системе IPS документ является одной из разновидностей информационных объектов типа **Документы**. В качестве документов могут выступать бумажные документы, деловая документация, извещения, конструкторские документы, отчеты, проектная документация, технологические документы, электронные книги и прочие документы. В данном руководстве особое внимание уделяется электронным конструкторским документам – конструкторским спецификациям. Спецификация в IPS содержит в себе один уровень состава (электронной структуры) изделия, на которое она выпущена. Документы, сформированные на основе информации, полученной из CAD-систем, содержат в себе модели изделий и параметры моделей. |
| Изделие | Изделия также является одной из разновидностей информационных объектов типа **Изделия**. В качестве изделий могут выступать детали, комплексы, комплекты, сборочные единицы, стандартные и прочие изделия. С точки зрения пользователя, IPS хранит в изделии состав сборочной единицы, комплекса, комплекта, т.п., а также иерархические отношения (связи) между его составными частями; прочие данные в виде атрибутов изделий и их значений. |
| Контекст | Организационная совокупность элементов данных и связей между ними, созданная в рамках информационной модели для группирования и визуального отображения необходимой части состава информации с определенной целью. В системе IPS реализованы контексты составов, позволяющие разделить состав изделия на общую, конструкторскую и технологическую составные части, чтобы в дальнейшем по требованию пользователя отображать (использовать при разработке) только необходимые части, скрывая избыточную информацию. |
| Информационная модель (изделия) | Совокупность данных и отношений между ними, описывающая различные свойства реального изделия. В системе IPS модель – это составной документ, который создается конструктором в CAD-системе, а затем на его основе в IPS формируется электронная структура изделия (состав изделия), сохраняется состав документов модели, а при необходимости создаются исполнения изделий, описанных в модели. |
| Исполнение изделия | Конструкция одного из изделий, информация о которых содержится в одном групповом или базовом основном конструкторском документе. |
| Основное исполнение | Исполнение изделия, обозначение которого совпадает с обозначением группового основного конструкторского документа. |
| Переменные данные исполнений | Информация об исполнениях изделий, неодинаковая для группы изделий. |
| Постоянные данные исполнений | Информация об исполнениях изделий, одинаковая для группы изделий и содержащая в одном конструкторском документе. |
| Применяемость | Характеристика связи, показывающая, при каких условиях данная составная часть использована в конечном изделии или другой составной части. Конструктор может выполнять поиск состава и применяемости для любого изделия, документа в системе IPS. |
| Структура изделия | Совокупность составных частей изделия и связей между ними, определяющих входимость составных частей. |
| Электронная структура изделия | Конструкторский документ, содержащий состав сборочной единицы, комплекса, комплекта, т.п., а также иерархические отношения (связи) между его составными частями и другие вспомогательные данные. Является обобщающим документом, собирающим технические данные об изделии. Используется для предоставления информации о составе изделия, об иерархии составных частей (изделий), об свойствах изделия и его составных частей. В системе IPS электронная структура изделия позволяет отображать различные варианты состава и структуры изделия, в зависимости от настроек фильтрации составов. С помощью электронной структуры изделия можно получить информацию о применяемости и входимости изделий, управлять взаимозаменяемостью изделий в составах (допустимые замены), организовывать и структурировать проектную и рабочую конструкторскую документацию на изделие, управлять разработкой изделия, получать текстовые документы на изделие и его составные части в электронной форме, осуществлять документирование изменений в конструкции изделия. |

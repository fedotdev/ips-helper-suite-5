# Сортировка
Сортировка записей в окне PDM Browser осуществляется по одному из полей **Обозначение** , **Наименование** и **Раздел СП**. Для сортировки необходимо навести курсор на наименование столбца, и указать левой кнопкой мышки. При повторном указании изменяется порядок сортировки (сверху–вниз, снизу-вверх). По полю **Раздел СП** сортировка осуществляется по порядку следования разделов в ГОСТ.

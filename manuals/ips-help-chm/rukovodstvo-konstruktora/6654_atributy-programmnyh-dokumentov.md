# Атрибуты программных документов
Для создания **Программных документов** в **Конфигураторе базы данных** должны быть созданы атрибуты:
1\. Наименование атрибута:**Наименование программы**
Глобальный идентификатор: **cadd9c1c-306c-11d8-b4e9-00304f19f545**
Тип: **Строка**
Список: **Атрибут может содержать одно значение**
2\. Наименование атрибута: **Наименование программного документа**
Глобальный идентификатор: **cadd9c3c-306c-11d8-b4e9-00304f19f545**
Тип: **Строка**
Список: **Атрибут может содержать одно значение**
3\. Наименование атрибута: **Вид носителя данных**
Глобальный идентификатор: **cadd9c42-306c-11d8-b4e9-00304f19f545**
Тип: **Строка**
Список: **Атрибут может содержать одно значение**
4\. Наименование атрибута: **Тип ПД**
Глобальный идентификатор: **cadd9c20-306c-11d8-b4e9-00304f19f545**
Тип: **Строка**
Список: **Атрибут может содержать одно значение из списка разрешённых значений**
Допустимые значения: **Назначены**
У каждого документа в карточке должен быть заполнен атрибут **Тип ПД** из списка.
У документов в карточке должен быть заполнен атрибут **Держатель подлинника** из списка.

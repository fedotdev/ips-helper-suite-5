# Статус текущего типа ведомости
В нижней части страницы **Прочее** отображается статус текущего типа ведомости:
· Для системной ведомости отображается – **Ведомость системная.**
· Для пользовательской – **Ведомость пользовательская** и - какой ведомости это аналогично.

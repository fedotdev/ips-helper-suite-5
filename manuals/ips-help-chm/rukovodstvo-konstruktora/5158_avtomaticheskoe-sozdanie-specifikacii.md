# Автоматическое создание спецификации
Модуль расширения **Редактор конструкторских документов (AVS)** позволяет автоматизировать создание спецификаций для следующих типов объектов:
· **Сборочные единицы.**
· **Комплексы.**
· **Комплекты.**
· **Заказы.**
· **Экземпляры и партии изделий.**
Команда **Редактировать** контекстного меню для объектов любого из указанных типов при необходимости, берет сам объект на изменение, а затем создает спецификацию (если она еще не была создана). После этого открывается редактор спецификаций с новой (или уже существующей) спецификацией для выбранного объекта.

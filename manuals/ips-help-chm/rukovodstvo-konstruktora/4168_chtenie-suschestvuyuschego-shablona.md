# Чтение существующего шаблона
· Выполните команду **Приложения/Навигатор**.
· В дереве конфигуратора выберите **Объекты/Настройки системы/Шаблоны документов (бланки) /Шаблоны ведомостей**.
В правой части отображается список уже имеющихся шаблонов. 
· В этом списке по правой кнопке откройте контекстное меню.
· Выберите команду **Создать/Создать «Шаблон ведомости»**.
· В открывшемся окне заполните необходимые данные.
· Нажмите кнопку **Далее**. 
· В открывшемся окне, в строке <без имени> нажмите правую кнопку мыши и выберите команду **Заменить файл.**
· В открывшемся окне выберите папку с существующими шаблонами и выберите файл шаблона.
· Проверьте и заполните необходимы данные.
· Нажмите кнопку **Готово**.

# Ведомости эксплуатационных документов
Ведомость эксплуатационных документов в **Навигаторе** располагаются по пути: **Документы / Конструкторские документы / Документы эксплуатационные.**
Шаблон **Ведомости эксплуатационных документов** содержит страницы: **Титульный лист** , **Следующая страница** , **Лист регистрации изменений**.
По умолчанию автоматической разработки данного документа нет. Для настройки автоматической разработки необходимо: 
· На странице настройки **Сервис** включить переключатель **Создавать ведомость автоматически**.
· Настроить все параметры сбора.

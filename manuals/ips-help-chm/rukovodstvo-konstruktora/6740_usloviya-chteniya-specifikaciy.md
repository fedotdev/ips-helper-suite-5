# Условия чтения спецификаций
На данной подстранице производится настройка:
· Из каких разделов спецификации производить поиск и обработку спецификаций.
· При выполнении каких условий раскрывать эти спецификации.
Например, в настройке сбора Ведомости ЗИП
Спецификации из раздела **Комплекты** раскрываются не все, а только при выполнении условия.

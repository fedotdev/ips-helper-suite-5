# Расширенное сохранение
При расширенном сохранении документа **Проекты Delta Design** интегратор производит сканирование электрической схемы, входящей в состав проекта. В результате расширенного сохранения создается объект типа **Сборочная единица**. Значения атрибутов созданной СЕ интегратор берет из соответствующих параметров проекта. В процессе сканирования формируется состав созданного изделия, куда попадают компоненты схемы. Значения атрибутов, создаваемым изделиям, интегратор извлекает из соответствующих параметров компонентов схемы.
Воспользоваться командой **Расширенное сохранение** … можно, как из контекстного меню документа **Проекты Delta Design** в IPS, так и с помощью соответствующей команды из меню интерфейса Delta Design.

# Атрибуты НТД
Для создания **Ведомости держателей подлинников** и **Ведомости ссылочных документов** в **Конфигураторе базы данных** должны быть созданы атрибуты:
· Тип НТД.
· Вид НТД.
Для документов значение атрибутов **Вид НТД** и **Тип НТД** должны выбираться из данных списков.

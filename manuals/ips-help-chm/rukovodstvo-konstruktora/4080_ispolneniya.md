# Исполнения
Примечание: данная функциональность будет доступна в том случае, если загружен модуль расширения **Управление информацией об изделиях PDM**.
Система IPS обеспечивает работу не только с обычными (единичными) документами, но и с групповыми конструкторскими документами, описывающими различные исполнения объектов. Объект и его исполнения видны на закладке **Объект** , которая отображается в карточках объектов типа **Документы**.
Просмотреть список исполнений можно с помощью команды **Список исполнений** в контекстном меню для информационного объекта.

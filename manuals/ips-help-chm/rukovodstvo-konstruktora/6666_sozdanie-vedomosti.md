# Создание ведомости
Для этого в головной программной спецификации необходимо выполнить команду **Документ / Создать ведомость ЕСПД**.
Ведомость создается автоматически согласно настройкам и открывается редактор данной ведомости.
Обязательные атрибуты:
· **Наименование программы**.
· **Тип программного документа.**
· **Количество экземпляров.**
· **Место.**

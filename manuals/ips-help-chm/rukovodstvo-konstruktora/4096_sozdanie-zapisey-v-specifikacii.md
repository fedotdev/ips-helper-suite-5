# Создание записей в спецификации
Каждая спецификация состоит из записей. Записями спецификации могут являться объекты (изделия и документы), наименования разделов, номера позиций, исполнений, заголовки, примечания и т.п. Ввод записей в спецификацию осуществляется с помощью ввода с клавиатуры (например, заголовков, примечаний), извлечения из базы данных (например, объектов) или автоматически (например, наименований разделов, позиций).
Создание записей в спецификации и работа с ними производится с помощью команд панели инструментов **Спецификация** или контекстного меню спецификации.

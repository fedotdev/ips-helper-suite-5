# Создание нового исполнения объекта
Чтобы создать исполнение объекта, выполните следующие действия:
· Выберите из списка объектов рабочей области тот объект, для которого будет создаваться исполнение, и воспользуйтесь командой его контекстного меню **Создать/Исполнение** для перехода в диалог создания нового объекта. Данная команда доступна только для тех объектов, у которых можно создавать исполнения – по умолчанию это изделия.
· В появившемся диалоговом окне внесите необходимые изменения в создаваемый объект.
· Нажмите **Готово**.

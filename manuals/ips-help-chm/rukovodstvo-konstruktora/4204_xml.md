# XML
На данной странице производится настройка вывода данных в файл XML и ввода данных из файла XML.
В файл XML выводятся только данные из ячеек строки. Поэтому настраиваются только имя ячейки и имя поля в файле XML.
В левой части диалога показано дерево настройки. В дереве отображаются настройки для всех типов записей.

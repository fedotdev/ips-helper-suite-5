# Настройка словаря замен для заголовка групп записей
Настройки словаря замен являются сквозными для всех типов конструкторских документов, где используется групировка записей. Они не привязаны к шаблонам или конкретным документам. Пользователи могут добавлять или изменять новые замены ключевых слов для заголовков групп записей.

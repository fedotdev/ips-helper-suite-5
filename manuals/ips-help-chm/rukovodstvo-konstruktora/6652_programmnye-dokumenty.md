# Программные документы
К программным документам относятся документы, разрабатываемые согласно требованиям ЕСПД. Основным программным документом является **Программная спецификация**. Кроме этого имеется множество других программных документов.
Редактором обрабатываются:
· Спецификация.
· Ведомость эксплуатационных документов.
· Ведомость держателей подлинников.
В конфигураторе должна быть «ветка» **Типы объектов \ Документы \ Программные документы**.
И в «ветке» **Типы объектов \ Изделия** должны быть:
· **Типы объектов \ Изделия \ Программные комплексы**.
· **Типы объектов \ Изделия \ Программные компоненты**.

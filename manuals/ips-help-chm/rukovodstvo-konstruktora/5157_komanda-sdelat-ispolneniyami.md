# Команда Сделать исполнениями
Команда **Сделать исполнениями** предназначена для объединения нескольких изделий в групповое изделие и доступна в контекстном меню **Навигатора** для нескольких выделенных однотипных изделий (сборочные единицы или детали). Причем указанные изделия должны быть взяты текущим пользователем на изменение.
Если у одного или более выбранных изделий уже есть исполнения, то система в диалоге предложит выбрать изделие, исполнениями которого сделать все выбранные изделия.
При нажатии на кнопку **Отмена** операция будет отменена.

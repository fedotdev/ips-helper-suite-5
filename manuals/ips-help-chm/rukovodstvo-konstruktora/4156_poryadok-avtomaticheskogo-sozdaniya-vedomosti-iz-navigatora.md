# Порядок автоматического создания ведомости из Навигатора
Для выполнения команды из **Навигатора** :
· Откройте в **Навигаторе** ветку **Объекты/Документы/Конструкторские документы/ Спецификации**.
· Выберите головную спецификацию.
· Вызовите локальное меню.
· Откройте подменю **Отчеты и документы**.
· Выполните команду **Создать конструкторскую ведомость.**

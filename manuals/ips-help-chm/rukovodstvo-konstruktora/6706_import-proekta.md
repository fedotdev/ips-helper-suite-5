# Импорт проекта
Для импорта файлов проекта необходимо воспользоваться командой **Зарегистрировать в IPS** из меню IPS в интерфейсе Delta Design. Импортируемый проект Delta Design сохраняется внутри файлового хранилища IPS.
Особенностью Delta Design является то, что процесс проектирования и связанные с ним данные хранятся не в файлах, а в базе данных. После импорта проекта в IPS создается объект типа **Проекты Delta Design** , экспортированный из базы Delta Design файл проекта с расширением *.DDC.
Синхронизация атрибутов созданного документа производится в соответствии с настройками интегратора.

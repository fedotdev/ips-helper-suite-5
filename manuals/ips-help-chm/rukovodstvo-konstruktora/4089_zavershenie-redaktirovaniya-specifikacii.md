# Завершение редактирования спецификации
Имеется возможность завершить редактирование спецификации без выхода из редактора. Для этого воспользуйтесь командой **Документ / Завершить редактирование документа**. В результате документ вернется в архив и редактор откроется в режиме **Для чтения**.

# Создание файлов производства
Для работы в IPS с файлами производства, созданными в Delta Design, необходимо выполнить следующее: 
1\. В настройках интегратора выбрать тип объекта, который будет соответствовать файлам производства в Delta Design.
2\. Для создания файлов производства в Delta Design необходимо воспользоваться командой **Файлы для производства** из меню IPS в интерфейсе Delta Design.
3\. Установить необходимые настройки, применимые к производственным файлам. 
4\. На вкладке **Настройки сохранения** следует активировать опцию **Архивировать**.
5\. После завершения создания файлов производства необходимо выполнить команду **Сохранить изменения** для проекта Delta Design. В системе IPS создастся объект типа, указанного в настройках интегратора, который войдет в состав объекта **Проекты Delta Design**.
При вызове команды **Расширенное сохранение** проекта Delta Design, объект **Файлы производства ПП** войдет в состав ЭСИ.

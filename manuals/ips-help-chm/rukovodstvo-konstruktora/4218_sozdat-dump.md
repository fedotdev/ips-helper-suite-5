# Создать Dump
При возникновении у пользователей вопросов к разработчикам программы можно собрать определенный набор файлов. Данный набор файлов формируется по нажатию кнопки **Создать Dump**. Файлы формируются в одной из папок:
· Если в настройках Windows указана системная переменная IPS_VED_DUMP, то файлы помещаются в папку, описанную в этой системной переменной;
· Иначе в папке, на которую указывает системная переменная **TEMP** создается папка **IMClient.Debug/Vedomost**. Все файлы Dump помещаются в эту папку.
В эту папку помещаются:
· Файл – шаблон данного типа ведомости.
· Файл со всеми настройками.
Если в системных переменных имеется переменная **isCreateDumpVed = 1** , то в этой папке при каждой разработке ведомости создаются файлы:
· Файл – шаблон данного типа ведомости.
· Файл со всеми настройками.
· Протоколы процесса сбора ведомости.
· Файл созданной ведомости (xml).
· Созданная ведомость (pdf).
Дальнейшая передача всех этих файлов разработчикам программы позволит более быстрому решению вопросов между пользователями и разработчиками.
Кроме того, данная команда позволит передавать настройки другому предприятию.

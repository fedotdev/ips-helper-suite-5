# Свойства
В созданной справа странице на закладке **Свойства** введите необходимые данные.
· **Атрибут-описатель**. В выпадающем списке выберите **Обозначение + Наименование**. С такой закладкой документ будет отображаться в редакторе.
· **Имя объекта**. Введите **Ведомость крепежа**.
· **Краткое наименование**. Ведите код документа, например, **ВК**.
· **Наименование.** Введите **Ведомости крепежа**. (Множественное число. Так будет отображаться общее наименование в диалогах).
Нажмите кнопку **Применить**.

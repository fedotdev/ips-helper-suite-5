# Добавление записей в текущий набор исполнений
В групповой спецификации формы Б можно добавлять записи не во все исполнения, а только в исполнения находящиеся на текущей странице, для этого необходимо включить настройку **Добавлять в текущий набор исполнений** (Пункт главного меню **Настройка/Параметры IPS/Редактор спецификаций AVS**).

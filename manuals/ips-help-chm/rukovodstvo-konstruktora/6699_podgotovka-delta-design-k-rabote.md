# Подготовка Delta Design к работе
Для работы интегратора IPS с Delta Design необходимо добавить расширение. Для этого следует:
1\. Распаковать архив расширения, который расположен по пути: **...\IPS.InstClient \ Files \ DeltaDesign** _,_ в папку **Extensions** каталога установленного Delta Design: **C:\Program Files \ Eremex \ Delta Design 3.7 \ Extensions \ Intermech.DeltaDesign.Extension.**
2\. Из распакованного архива расширения скопировать файлы с именем Intermech и вставить в корень каталога установленной программ: **C:\Program Files \ Eremex \ Delta Design 3.7.**

# Предварительный сбор
На этой подстранице определяется – какие этапы предварительного сбора ведомости (см. п. ) выполнять.
Эти этапы необходимы для большинства ведомостей, но не для всех. Например, при сборе **Ведомости состава изделия** все этапы выключены.
Если включено **Раскрывать только основную спецификацию** , то ведомость собирается исключительно из этой основной спецификации. Состав последующих спецификаций не раскрывается.

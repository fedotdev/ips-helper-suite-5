# Читать данные из файла AVS6
Команда **Читать данные из файла AVS6** предназначена для выбора файла программы AVS6 и внесения данных из этого файла в **текущий** документ IPS, т.е. открытый в текущем окне редактора.
Создайте в системе IPS новый документ (ведомость, таблицу) или откройте уже существующий документ IPS.
Выполните команду **Читать данные из файла AVS6**.
Откроется диалог для выбора файла программы AVS6.
Тип файла AVS6 будет соответствовать текущему документу IPS.
По нажатию кнопки **Открыть** данные из выбранного файла AVS6 будут занесены в текущий документ IPS.
Все записи документа AVS6 будут, по возможности, связаны с объектами системы IPS.
Данная команда доступна только если включена **Настройка / Параметры IPS / Редактор AVS / Чтение документов AVS6.**

# Создание и редактирование таблиц
Для создания новой таблицы:
· Откройте в **Навигаторе** **Объекты \ Документы \ Конструкторские документы \ Таблицы \ Конструкторские таблицы**.
· Выберите конкретный вид таблицы, например, **Таблицы соединений**.
· В правой части окна вызовите локальное меню.
· Выполните команду **Создать**.
· Выполните команду **Создать «Таблица соединений»**.
Откроется окно задания учетных данных ведомости. 
· Заполните **учетные** данные и нажмите кнопу **Готово**.
Откроется редактор данной таблицы. Заполнение и редактирование данной таблицы производится пользователем (см. п. ).
Рекомендуемый порядок создания записей, например, в **Таблице соединений** :
· Выполните команду **Добавить основную строку**.
· Заполните данные соединения.
· Выполните команду **В текущую строку добавить данные из Imbase**. 
· Выберите провод.

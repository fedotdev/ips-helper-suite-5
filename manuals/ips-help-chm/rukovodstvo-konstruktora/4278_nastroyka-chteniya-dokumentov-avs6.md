# Настройка чтения документов AVS6
Данная команда доступна, если в окне IPS открыта ведомость, таблица или их шаблон. По этой команде открывается окно диалога.
В левой части отображается список документов AVS6, которым еще не настроено соответствие документов IPS. Т.е. при полном отсутствии настроек слева будет список всех документов AVS6. При полной настройке левый список будет пуст.
Параметры настройки программы AVS6 читаются из файла настройки AVS6. Имя этого файла отображается под окном списка документов AVS6.
Если программы AVS6 на данном рабочем месте нет, то окно имеет вид.
В левой нижней части доступны кнопки:
· **Программа**. При нажатии этой кнопки данные настройки AVS6 формируются программой.
· **Открыть**. При нажатии этой кнопки можно найти файл **AVS6MAIN.INI** , предварительно скопированный из другого компьютера.
В правой части в правом столбце отображается список конструкторских ведомостей и таблиц системы IPS. В левом столбце отображены соответствующие документы программы AVS6. Т.е. при чтении документа AVS6 создается соответствующий документ IPS.
Для добавления новой связи необходимо:
· В левом списке выбрать строку с типом документа AVS6.
· В правом списке выбрать строку с соответствующим типом документа IPS с пустым левым столбцом.
· Нажать кнопку .
Добавить документ AVS6 можно только в строку с пустым левым столбцом.
Если документ IPS необходимо связать с двумя или более документами AVS6 необходимо в правой части создать копию строки. Например, **Ведомость покупных изделий ВП2** (AVS6) хотим связать с **Ведомость покупных изделий** (IPS). Для этого необходимо:
· В правой части выбрать строку с **Ведомость покупных изделий**.
· Нажать кнопку . Будет создана новая строка.
· Теперь ведомость ВП2 связать с этой новой строкой.
Для удаления связи необходимо:
· В правой части диалога выбрать строку.
· Нажать кнопку .

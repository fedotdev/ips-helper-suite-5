# Уведомление о необходимости обновить ПЭ3 после сохранения файла Delta Design (на основании которого был сформирован ПЭ3) в IPS
Если в составе СЕ уже есть ранее созданный перечень элементов, то при последующих повторных выполнениях расширенного сохранения проекта Delta Design, система будет предупреждать пользователя о необходимости обновления (пересоздания) перечня элементов. Это сделано с целью обеспечения минимизации несоответствия данных в составе и перечне элементов.

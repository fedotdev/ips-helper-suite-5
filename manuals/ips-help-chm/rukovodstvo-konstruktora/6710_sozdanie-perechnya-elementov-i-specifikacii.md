# Создание перечня элементов и спецификации
Примечание: команды **Создать спецификацию** и **Создать перечень элементов** доступны при условии, что загружен модуль **Редактор конструкторских документов (AVS)**.
По команде контекстного меню **Редактировать** на сборочной единице создается спецификация, которая включается в документацию к сборке.
По команде контекстного меню **Создать / Перечень элементов** , вызванной по сборочной единице создается **Перечень элементов**. 
Воспользоваться командами **Создать спецификацию** и **Создать перечень элементов** можно из меню интерфейса Delta Design.
При первом вызове созданный документ включается в состав документации для соответствующей сборки.

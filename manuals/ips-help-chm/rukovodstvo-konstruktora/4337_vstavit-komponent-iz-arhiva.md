# Вставить компонент из архива
Данная команда позволяет вставить компонент CAD-системы (деталь или сборку) в проектируемую сборку из архива IPS.
Для вставки компонента вызовите команду **Вставить компонент из архива**, откройте необходимый архив и выберите компонент для вставки.

# Создание ведомости пользователем
Для создания новой ведомости:
· Откройте в **Навигаторе** **Объекты/Документы/Конструкторские документы/Ведомости**.
· Выберите конкретный вид ведомости, например, Ведомость крепежа.
· В правой части окна вызовите локальное меню.
· Выполните команду **Создать**.
· Выполните команду **Создать ведомость …**
Откроется окно задания учетных данных ведомости. Заполните учетные данные и нажмите кнопу **Готово**.
Откроется редактор данной ведомости. Заполнение и редактирование ведомости производится пользователем (см. п. ).

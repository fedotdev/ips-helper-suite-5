# Тип НТД
Атрибут **Тип НТД** используется в **Ведомости держателей подлинников** и **Ведомости ссылочных документов.**
Этот атрибут содержит описание, включаемое в наименование документа.
В **Конфигураторе базы данных** параметры атрибута должен соответствовать следующим.
**Допустимые значения** определяются на предприятии и содержат наименования типов документов.

# Вставить компонент из базы данных объектов
Данная команда позволяет вставить компонент CAD-системы (деталь или сборку) в проектируемую сборку из списка объектов IPS.
Для вставки компонента вызовите команду **Вставить компонент из БД объектов**и выберите компонент для вставки.

# Установка совместных позиций
Для неединичных спецификаций имеется возможность настроить записи у которых будут одинаковые позиции. Для этого выберите запись и воспользуйтесь командой контекстного меню **Совместные позиции.** В открывшемся диалоге выберите те записи, которые будут иметь одинаковую позиция с позицией выделенной записи.
Автоматически создается новый номер условной позиции, но он может быть изменен вручную. Совместная позиция записывается в атрибут **Условная позиция**.

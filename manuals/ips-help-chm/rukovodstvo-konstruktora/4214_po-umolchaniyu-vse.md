# По умолчанию все
По этой команде всем страницам настройки для текущего типа ведомости присваиваются значения по умолчанию.
Для пользовательских типов ведомости, ссылающихся на системный тип, устанавливаются параметры этой системной ведомости. Для остальных эта команда не доступна.

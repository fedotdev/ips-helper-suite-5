# Организации
Для создания **Ведомости держателей подлинников** в **Конфигураторе базы данных** должен быть создан объект **Типы объектов \ Организационные единицы \** **Организации**
Для документов значение **держателя подлинника** должно назначаться из списка **Организации**.

# Если отображается сообщение типа
1\. Нажать кнопку Записать в файл.
2\. Данный файл добавить к архивам, описанным выше.
3\. Передать разработчикам (cad@intermech.ru) этот архив.
4\. Возможно подробнее описать сам вопрос, ссылаясь на конкретные позиции ТЕКУЩЕГО документа.

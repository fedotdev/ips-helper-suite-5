# Структура файлов XML
Файлы XML для ввода данных в документ должны иметь определенную структуру. Для подробного изучения их структуры по тексту текущего раздела описания рекомендуется создать такие файлы из **Ведомости** и **Таблицы**.
В общем структура файла имеет вид:
<?xml version="1.0" encoding="windows-1251" standalone="yes"?>
<DOCUMENT>
<OBLIGATORY GroupForm="A" />
<PASSPORT />
<DATA>
<RECORD />
<RECORD />
.........
</RECORD>
................
................
</DATA>
</DOCUMENT>
· **DOCUMENT.** Основной элемент файла имеет имя <**DOCUMENT** >.
· **OBLIGATORY.** Обязательный элемент <OBLIGATORY GroupForm="A" />. В этом элементе описывается групповая форма документа и, если это форма Б, заголовки исполнений.
· **PASSPORT.** Необязательный элемент **PASSPORT**. В этом элементе описываются данные Основной надписи. Данные записываются в виде атрибутов. Например, <PASSPORT DocumentDesignation="ЖВБ.998877.010 ВП" NameArticle="Пульт" />.
· **DATA.** Обязательный элемент **DATA**. В этой области описываются множество записей документа (RECORD).
· **RECORD.** Каждая запись документа описывается в элементе RECORD. В каждом элементе описываются данные ячеек. Данные записываются в виде атрибутов. Например, <RECORD TypeRec="Info" Name="Лента I-2-225" Document="ОСТ 4Г0.866.001" ObjectIdIzd="1210415">
Атрибут ObjectIdIzd – это "Идентификатор версии объекта", описываемого элемента. Он связывает запись с базой данных.
· **SUBTABLE.** Записи ведомостей могут содержать вторичный элемент SUBTABLE. В этом элементе описываются вторичные данные "Куда входит" и количества. Имя элементов SUBRECORD.
Если вторичных строк несколько, то эту область завершает элемент **TOTAL** , в котором описано итоговое количество.
Например,
<SUBTABLE>
<SUBRECORD DesignationOfWhere="ЖВБ.200887.313" CountInTheComplect="100" CountOfAll="100" />
<SUBRECORD DesignationOfWhere="ЖВБ.400923.301" CountInTheProduct="80" CountOfAll="80" />
<SUBRECORD DesignationOfWhere="ЖВБ.400923.302-01" CountInTheProduct="72" CountOfAll="72" />
<SUBRECORD DesignationOfWhere="ЖВБ.400923.305-01" CountInTheProduct="48" CountOfAll="48" />
<TOTAL CountTotal="300" />
</SUBTABLE>

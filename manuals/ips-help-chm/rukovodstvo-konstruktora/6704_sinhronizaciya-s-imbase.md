# Синхронизация с Imbase
· **Проводить синхронизацию.** Настройка, позволяющая включить обязательную синхронизацию с базой Imbase при расширенном сохранении. 
· **Проверка применяемости.** Настройка, позволяющая включить проверку применяемости элемента, добавленного в проект Delta Design с базой данных IPS Imbase. 
· **Атрибут для синхронизации.** Поле для выбора атрибута изделия, по которому будет происходить синхронизация с Imbase. 
· **Обновлять состав, при наличии ошибок синхронизации**. Настройка, позволяющая обновлять состав сборочной единицы после вывода отчета по несинхронизированным компонентам.

# Добавить из Imbase
По данной команде можно выбрать и вставить в ведомость запись, имеющаяся в базе данных Imbase.
Данные заносятся в **новую строку** в соответствии с настройкой **Вывод** (см. п. ). Диалог, после ввода данных, возвращается в редактор документа.
Если в ведомости имеются несколько разделов, которые имеют разные настройки, то отображается диалог выбора раздела

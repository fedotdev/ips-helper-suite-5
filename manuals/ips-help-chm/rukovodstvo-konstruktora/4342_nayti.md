# Найти
В окне поиск пользователь может выбрать, по каким атрибутам будет осуществляться поиск. 

После нажатия кнопки **Найти** в окне **PDMBrowser** будет выделен документ удовлетворяющий критериям поиска, для перехода к следующему документу выберете в окне кнопку **Далее**.

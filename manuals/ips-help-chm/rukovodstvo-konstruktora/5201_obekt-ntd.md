# Объект НТД
В **Конфигураторе базы данных** должен быть создан объект НТД. Объект НТД используется в настройке сбора **Ведомости ссылочных документов**. В свою очередь НТД (в соответствие с ГОСТ 2.106) разделяются по уровню документа: Государственные документы, Документы предприятий, Межгосударственные документы, Отраслевые документы, Республиканские документы.

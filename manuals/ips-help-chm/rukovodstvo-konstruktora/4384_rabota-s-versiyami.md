# Работа с версиями
Для подбора версий при работе с составом и применяемостью используется правило подбора по умолчанию. При необходимости изменения версии объекта система автоматически берёт версию объекта на изменение или выпускает его версию в соответствии с настройками текущего шага ЖЦ.

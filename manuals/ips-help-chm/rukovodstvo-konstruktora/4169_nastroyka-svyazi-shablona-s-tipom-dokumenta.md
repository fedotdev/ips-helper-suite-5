# Настройка связи шаблона с типом документа
· Выполните команду **Настройка/Настройка инструментов**.
· В открывшемся диалоге откройте список **Команды запуска приложений** и в этом списке выберите команду **Интеграторы с приложениями**.
· В открывшемся диалоге выберите **Интегратор с редактором документов**.
· Нажмите кнопку **Свойства**.
· В открывшемся диалоге нажмите кнопку **Добавить**
· В открывшемся диалоге выберите **Документы/Конструкторские документы/ Ведомости/ Ведомости крепежа.**
· Нажмите кнопку **Ок**.
· В открывшемся диалоге выберите курсором **[шаблон не задан]**.
· В изменившемся диалоге выберите курсором пиктограмму объекта-шаблона.
Отобразится диалог выбора.
· В дереве выберите **Шаблоны ведомостей**.
· В правом списке выберите **Шаблон ведомости крепежа**.
· Нажмите кнопку **Ок**.
· Нажмите кнопку **Применить**.
· После этого можно приступить к настройке**Ведомости крепежа**(п. ).

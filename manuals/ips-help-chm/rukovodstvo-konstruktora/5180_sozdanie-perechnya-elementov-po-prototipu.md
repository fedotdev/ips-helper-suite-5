# Создание перечня элементов по прототипу
· В списке объектов типа перечня элементов выделите любой перечень элементов и примените команду **Создать/Создать по прототипу** его контекстного меню.
· В появившемся диалоговом окне введите обозначение и наименование нового документа и нажмите **Готово**.

# Создание перечня элементов с помощью главного меню
· Вызовите с помощью главного меню **Файл/Создать/Новый объект** диалоговое окно **Создание нового объекта** , в нем выберите тип объектов **Документы/Конструкторские документы/Схемы/[Нужный тип перечня элементов]** и нажмите кнопку **Далее**.

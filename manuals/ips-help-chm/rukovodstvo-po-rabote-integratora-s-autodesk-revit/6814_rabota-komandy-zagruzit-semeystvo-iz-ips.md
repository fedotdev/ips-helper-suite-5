# Работа команды Загрузить семейство из IPS
Для того, чтобы загрузить семейство в проект Revit необходимо воспользоваться кнопкой **Загрузить семейство из IPS** на закладке **IPS**. 
В открывшемся диалоговом окне пользователь имеет возможность выбрать семейство из списка стандартных библиотеки Revit. для загрузки следует выбрать семейство и нажать кнопку . Выбранное семейство будет загружено в проект, а так же находится в диспетчере проекта.
Для загрузки созданного или уже существующего семейства в системе IPS необходимо импортировать файл, а далее объект готов к работе. Подробное описание импорта проектов в систему IPS представлено в п. .
Помимо уже существующих семейств, система IPS предоставляет возможность создать семейство непосредственно из самой системы. Для этого следует:
1\. В дереве Навигатора выбрать тип объектов Семейства Revit и из контекстного меню вызвать команду Создать «Семейство Revit».
2\. В открывшемся окне следует задать значения необходимым атрибутам: **Обозначение** и **Наименование** , а затем нажать дважды кнопку .
3\. В появившемся окне необходимо выбрать шаблон семейства, а затем кнопку и кнопку .
Примечание: при необходимости, администратор может самостоятельно дозагрузить файлы прототипы, для создания семейств.

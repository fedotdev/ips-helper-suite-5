# Работа команды Добавить файл общих параметров
Для того, чтобы загрузить файлы общих параметров (ФОП) в проект Revit необходимо воспользоваться кнопкой **Добавить файл общих параметров** на закладке **IPS**. 
В открывшемся диалоговом окне пользователь имеет возможность выбрать необходимый файл и нажать кнопку .
**Внимание!** ФОП автоматически обновляются в системе IPS.

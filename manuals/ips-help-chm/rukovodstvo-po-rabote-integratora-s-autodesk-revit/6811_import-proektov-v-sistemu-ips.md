# Импорт проектов в систему IPS
Для создания объекта в системе IPS необходимо импортировать проекты Revit, которые расположены на локальном компьютере пользователя. Для импорта проекта следует:
1\. В меню **Экспорт\Импорт** выбрать команду **Импортировать файл**.
2\. В открывшемся окне следует выбрать необходимый файл.
3\. Далее необходимо выбрать, перемещать только выбранный файл в файловое хранилище или составные файлы тоже.
4\. В открывшемся окне следует указать необходимый тип объекта и нажать на кнопку .
**Внимание!** При импорте одиночных проектов следует выбирать тип объекта **Проекты Revit** , а если совместные проекты, то – **Совместным проектам Revit.**
Примечание: если при импорте совместного проекта был выбран тип объекта **Проекты Revit** , то система IPS запретит совместную работу в этом проекте.

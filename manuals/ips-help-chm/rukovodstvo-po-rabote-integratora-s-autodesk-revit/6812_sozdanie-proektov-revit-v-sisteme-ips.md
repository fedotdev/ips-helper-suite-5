# Создание проектов Revit в системе IPS
Все файлы Revit можно найти в дереве **Навигатора** по пути **Объекты \ Документы \ Конструкторские документы \ Revit.**
Для того чтобы создать объект типа **Проекты Revit** в системе IPS следует:
1\. В дереве **Навигатора** выбрать **Объекты \ Документы \ Конструкторские документы \ Revit \ Проекты Revit** и из контекстного меню вызвать команды **Создать**.
2\. В открывшемся окне **Создание нового объекта** следует ввести необходимые данные, а затем нажать кнопку .
3\. Далее следует выбрать **Файл шаблона** посредством кнопки . 
4\. В открывшемся окне представлен список стандартных шаблонов Autodesk Revit, после выбора необходимого шаблона следует нажать кнопку , а затем кнопку .
**Внимание!** При создании объекта типа **Совместные проекты Revit** помимо выбора шаблона так же следует выбрать и место хранения центрального файла в сетевой папке.

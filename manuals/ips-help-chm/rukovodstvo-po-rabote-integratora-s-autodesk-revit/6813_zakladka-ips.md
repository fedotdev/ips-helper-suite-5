# Закладка IPS
На главной панели в приложении Revit находится закладка **IPS**. Список функциональных кнопок перечислен ниже:
 **Открыть карточку объекта** – команда, которая позволяет открыть окно **Свойства (карточка)** проекта в системе IPS.
 **Открыть проект** – команда, которая позволяет открыть один из проектов, загруженных в систему IPS, непосредственно из Revit. 
**Загрузить семейство из IPS** – команда, которая позволяет загрузить в проект семейство из системы IPS.
 **Добавить файл общих параметров (Добавить ФОП)** – команда, которая позволяет загрузить в проект ФОП из системы IPS.
 **Добавить связь с проектом Revit** – команда, которая позволяет создать связь в Revit между открытым проект и другим, загруженным в систему IPS, созданная связь между проектами сохраняется в самой системе IPS.
 **Добавить связь с САПР** – команда, которая позволяет создать связь в Revit между открытым проектом и документами формата DWG, DGN и DXF, которые загружены в систему IPS, созданная связь между ними сохраняется в самой системе IPS.
 **Импорт САПР** – команда, которая позволяет импортировать документы формата DWG, DGN и DXF из системы IPS в Revit. Между проектом Revit и импортированным документом формата DWG, DGN и DXF связь не создается в системе IPS. 
 **Импорт PDF** – команда, которая позволяет импортировать документы формата PDF из системы IPS в Revit. Между проектом Revit и импортированным документом формата PDF связь не создается в системе IPS.
 **Информация о плагине** – команда, которая позволяет узнать версию плагина.
Интеграция функциональных возможностей системы IPS в приложении Autodesk Revit предоставляет возможность открыть зарегистрированный документ, работая в приложении Autodesk Revit не переключаясь между программой и системой. Для этого следует вызвать команду и в открывшемся окне выбрать необходимый документ, для завершения команды следует нажать кнопку .
Примечание: если был выбран **Проект Revit** , который взят на редактирование другим пользователем, то он откроется в режиме чтения.

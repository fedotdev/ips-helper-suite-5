# Настройка интегратора
Перед настройкой интегратора с Autodesk Revit следует убедиться, что на клиенте системы IPS загружен модуль расширения **Интегратор с Autodesk Revit** , путь к списку загруженных модулей **Настройка \ Модули расширения \ Список:**
Если модуля расширения **Intermech.ADRevit.Integrator.dll** в списке нет, то его следует загрузить по пути **Настройка \ Модули расширения \ Загрузить модуль расширения:**
Для корректной работы интегратора с Autodesk Revit следует настроить его сетевую папку, через которую Revit будет работать с пользовательскими проектами. 
Для настройки интегратора следует:
1\. На главной панели выбрать меню **Настройка \ Настройка инструментов** и в строке **Страница:** выбрать из выпадающего списка **Интеграторы с приложениями**.
2\. В открывшемся окне необходимо нажать кнопку .
3\. В открывшемся окне **Создание объекта интегратора** следует выбрать из списка **Интегратор с Autodesk Revit**.
4\. В списке конфигурационных объектов интеграторов необходимо выбрать **Интегратор с Autodesk Revit** и нажать кнопку .
5\. В открывшемся окне, в настройке **Путь к в папке с центральными файлами** следует указать сетевую папку, в которой будут храниться центральные файлы Revit совместных проектов.
6\. В общих настройках следует задать объекты для свойства **Типы документов**. Для этого необходимо нажать мультикнопку на строке свойства **Типы документов** , а затем, в открывшемся окне **Типы документов,** нажать кнопку и выбрать **Проекты Revit** и **Совместные проекты Revit** по пути **Документы \ Конструкторские документы \ Revit**.
7\. Для завершения настроек следует нажать кнопку и закрыть диалоговое окно **Настройка инструментов**.

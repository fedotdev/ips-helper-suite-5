# Связь с проектами Revit
Для создания связи с проектом Revit следует:
1\. На закладке **IPS** интегратора Revit нажать кнопку **Добавить связь с проектом Revit**.
2\. В открывшемся окне следует выбрать необходимый проект и нажать кнопку .
3\. Далее выбрать тип размещения связанного файла.
Интегратор с Revit поддерживает три типа размещения файла:
· **Совмещение внутренних начал**.
· **От базовой точки проекта до базовой точки проекта**.
· **По общим координатам**.
Примечание: если модели имеют разные системы координат, то при выборе типа размещения **По общим координатам** – размещение будет невозможно и система выдаст сообщение об ошибке. В таком случает рекомендуется выбрать другой тип размещения файла.

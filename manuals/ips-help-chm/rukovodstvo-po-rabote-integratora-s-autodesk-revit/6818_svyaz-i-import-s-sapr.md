# Связь и импорт с САПР
Интегратор с Revit предоставляет возможность добавить связь между проектом с документами формата DWG, DGN, DXF, которые загружены в системе IPS, или импортировать их из системы IPS в Revit.
Для того, чтобы добавить связь с САПР следует:
1\. На закладке **IPS** интегратора Revit нажать кнопку **Добавить связь с САПР**.
2\. В открывшемся окне следует выбрать необходимый объект\файл и нажать кнопку для завершения связи файла с проектом Revit.
Для импорта документа формата DWG, DGN и DXF алгоритм действий такой же, как описан выше, за исключение того, что следует нажать кнопку **Импорт САПР** на панели закладки **IPS** интегратора с Revit.

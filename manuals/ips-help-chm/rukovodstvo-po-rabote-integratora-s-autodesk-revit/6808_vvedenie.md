# Введение
Autodesk Revit – это программный комплекс для автоматизированного проектирования, реализующий принцип информационного моделирования зданий (BIM). Комплекс предоставляет возможности З-D моделирования частей здания и плоского черчения элементов оформления, создания пользовательских объектов, организации совместной работы над проектом. 
Система IPS разработала интегратор с Autodesk Revit. Данное руководство предназначено для описания работы интегратора с Revir.

# Настройка шаблонов генерации документов
В данном разделе будут рассмотрен пример шаблона генерации документов.
Предварительно рекомендуется ознакомиться с .
Пример шаблона комплекта документов для единичного ТП показан ниже.
В начале создается **Головная папка настройки сбора глобальной таблицы**.
Внутрь глобальной таблицы вставляются типы объектов, по которым будет вестись сбор данных. 
Для каждого из объектов в параметрах оператора на вкладке **Параметры** можно указать собираемые атрибуты объектов и связей.
На вкладке **Поиск объектов** необходимо указать тип связи и дочерние объекты, по которым будет вестись сбор данных.
Сохранение данных в глобальную таблицу позволяет существенно сократить количество обращений к базе данных, а, следовательно, и сократить время на формирование документа.
Возвращаемся к шаблону комплектов документов. Далее добавляются несколько комплектов документов для разных видов производств. Разграничение комплектов по видам производств определяется условием.
Внутрь комплектов вставляется оператор **Документ** с параметром **Документ генератора ЭС**(для скриптов генерации документов), или **Сценарий генерации на С#,** или **Документ TECHCARD**(для настройки документов TECHCARD).
Наименование каждого скрипта или настройки документов TECHCARD должно быть уникальным в пределах комплекта документов и состоять из не более 150 символов.

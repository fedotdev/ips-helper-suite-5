# Работа со сварочными швами
Добавление сварочных швов в операцию производится с помощью объектов **Сварочный шов**. Все дополнительные объекты, применяемые для сварочного шва (оборудование, оснастка, материал, режим, нормирование и т.п.) необходимо вставлять внутрь объекта сварочный шов. Данная схема работы, при использовании дочерних объектов в расчетах, позволит не перепутать объекты, добавленные на операцию с объектами, относящимися к сварному шву. Существующие в системе расчёты сварочных швов и правила поиска объектов настроены для работы по данной схеме.

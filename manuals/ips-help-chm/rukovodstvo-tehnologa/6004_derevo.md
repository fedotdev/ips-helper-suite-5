# Дерево
Инструмент позволяет на карточке размещать дерево объекта.
Имеет дополнительные настройки:
· **Головной объект**. Это тот или те объекты, с которых начинается построение дерева. Возможные варианты работы:
− **Выделенный объект**. Это тот объект, который выбран в текущий момент и карточка которого отображается.
− **Схема поиска**. Это объект, который будет найден по схеме поиска. При выборе данного варианта становиться доступно поле **Схема поиска**.
· **Отображаемые колонки**. Позволяет настроить отображаемые колонки в данном поле в карточке.
· **Сортировка по умолчанию**. Позволяет настроить сортировку по заданным в предыдущем поле колонкам.
· **Схема поиска**. Позволяет указать схему поиска объекта. Схема поиска работает от текущего объекта. Поле доступно при выборе в поле **Головной объект** опции **Схема поиска**.
· **Фильтр состава по типам объектов**. Позволяет указать **Фильтр состава,** по которому будет отсортирован состав выводимых объектов.

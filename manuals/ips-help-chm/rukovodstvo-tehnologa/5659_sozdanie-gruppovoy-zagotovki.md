# Создание групповой заготовки
Объекты групповой заготовки находятся в **Навигаторе** по пути **Информационное пространство / Объекты / Технологические объекты / Групповая заготовка**. 
Создание **Групповой заготовки** производится по команде контекстного меню **Навигатора** **Создать / Новый.**
Добавление ДСЕ осуществляется на вкладке **Список ДСЕ** по команде **Добавить**.
Выбранные в **Диалоге выбора** изделия необходимо связать с групповой заготовкой.
Если у изделий нет МО, он будет создан автоматически при нажатии кнопки **Применить**. При этом будут созданы единичные заготовки для соответствующих изделий, которые будут добавлены как в состав МО изделий, так и в состав групповой заготовки.
Редактирование параметров заготовки осуществляется в новом окне при использовании команды контекстного меню **Открыть единичный объект**.
Единичные заготовки в состав групповой подвязываются связью **Технологическая связь с элементом ГТП/ТТП**.

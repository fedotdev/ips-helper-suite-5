# По параметрам объектов
Серверная настройка, распространяется на всех клиентов. Позволяет настроить фильтры показа содержимого каталогов/справочников Imbase в зависимости от того, какой именно объект в данный момент выделен. В качестве примера данного типа фильтров можно использовать фильтр от цехозаходов на операции, когда для конкретного цеха необходимо показывать ограниченный список папок каталога **Операции**. Настройка фильтра производится путем указания условий на фильтр и указания папок каталогов, которые должны быть показаны, если параметры объекта удовлетворяют условиям.
Пример, показанный на рисунке: выделенный фильтр можно использовать, если курсором в **Навигаторе** выделен цехозаход. При включенном фильтре в справочнике операций будет показана только папки **Обработка резанием** и **Общие** , если цех цехозахода = 02.
По команде **Создать фильтр** контекстного меню списка фильтра открывается окно создания нового фильтра Imbase, в котором необходимо указать наименование фильтра, а также тип объекта, при выделении которого курсором данный фильтр можно будет использовать. Для указания типа объекта используется атрибут **Глобальный идентификатор типа объекта**.
По команде **Изменить** контекстного меню будет открыто окно, в котором можно изменить параметры фильтра, заданные при его создании.
При помощи команд **Копировать** и **Вставить** создается полная копия фильтра по параметрам объектов с условиями и настройками на справочник/каталог.
По команде **Удалить** происходит удаление выделенного курсором фильтра.
По команде **Обновить** происходит обновление списка фильтров. Данная команда актуальна, если настройкой списка фильтров параллельно занимается несколько пользователей, либо если создание фильтров производится в **Навигаторе** , минуя специально предназначенный для этого интерфейс.
Для указания параметров объектов, по которым необходимо производить фильтрацию справочника, служит поле **Условия фильтра** окна **Настройка фильтров Imbase для объектов**. Для каждого фильтра можно настроить свой перечень условий фильтрации. Для этого необходимо использовать контекстное меню данного поля.
По команде **Добавить условие** открывается редактор формул экспертной системы, позволяющий задать новое условие для выделенного фильтра.
По команде **Изменить** открывается редактор формул экспертной системы, позволяющий отредактировать выделенное условие.
По команде **Копировать** происходит копирование только выделенного условия без указания папок справочника.
По команде **Копировать с данными фильтра** происходит копирование выделенного условия вместе с отметками папок справочников.
По команде **Вставить** происходит вставка скопированного условия.
По команде **Удалить** происходит удаление выделенного условия.

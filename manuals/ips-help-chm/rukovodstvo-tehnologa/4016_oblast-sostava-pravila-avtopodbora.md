# Область состава правила автоподбора
У области состава правила автоподбора существует свое контекстное меню, при помощи команд которого производится редактирование правила.
Создание нового элемента правила осуществляется по команде контекстного меню **Создать / Новый элемент** (в случае, когда элемент должен находиться на верхнем уровне вложенности правила), или по команде **Создать/В составе** (когда новый элемент должен находиться в составе выделенного). В окне, открывающемся по данным командам, необходимо выбрать тип элемента автоподбора.
Перечень возможных типов элементов автоподбора:
· **Создать объект IMBASE** – используется, когда для выбранного элемента дерева автоподбора необходимо подобрать объект, который будет создан при помощи каталога (справочника) Imbase.
· **Создать объект** – используется, когда для выбранного элемента дерева автоподбора необходимо создать новый объект определенного типа, либо выбрать уже существующий в базе объект.
· **Папка** – служит для группировки других элементов автоподбора (например, для назначения одного условия на ряд элементов).
· **Запрос пользователю** – используется, если в процессе автоподбора необходимо показать пользователю текстовое сообщение.
· **Вызов процедуры** – используется в случае, когда внутрь редактируемого правила автоподбора необходимо вставить уже существующее правило для данного типа объекта.
· **Сценарий автоподбора** – используется в случае, когда внутрь редактируемого правила автоподбора необходимо вставить пользовательский сценарий, написанный на одном из поддерживаемых системой языков программирования (в настоящее время только C#). 
· **Заполнить атрибуты** – используется для заполнения значений атрибутов при добавлении объектов. 
Команда **Удалить** контекстного меню служит для удаления выделенного элемента правила автоподбора и всех его дочерних элементов.
При помощи выпадающего меню команды **Переместить** можно настроить порядок выполнения элементов правила во время работы автоподбора, а также извлечь выделенный элемент правила из вложения на уровень выше, либо на верхний уровень правила. 
При помощи выпадающего меню команды **Копировать в буфер** можно скопировать текущий элемент правила, либо все его элементы. Скопированные элементы при помощи выпадающего меню команды **Вставить из буфера** могут быть вставлены либо на верхний уровень правила, либо в состав его выделенного элемента.
Команда **Таблица** контекстного меню становится доступной для элемента **Папка** , в свойствах которого установлен тип папки **Папка Выбора**. Таблица выбора определяет правила выбора элементов, принадлежащих данной папке выбора.
Удаление таблицы для папки выбора производится по команде **Удалить таблицу**.
По команде **Условие** открывается редактор формул, в котором можно задать условие выполнения выбранного элемента автоподбора. Если в процессе подбора условие, назначенное на элемент, не выполняется, то он и все входящие в него элементы во внимание не принимаются. Древовидная структура позволяет расставлять условия наиболее рационально: если у соседних элементов часть условия совпадает, то эту часть можно вынести в качестве условия на элемент-владелец.

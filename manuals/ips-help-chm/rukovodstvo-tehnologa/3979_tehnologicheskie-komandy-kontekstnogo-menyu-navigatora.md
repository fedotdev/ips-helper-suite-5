# Технологические команды контекстного меню Навигатора
Рассмотрим другие технологические команды контекстного меню **Навигатора**.
Команда **Автоподбор** запускает процедуру автоматизированного подбора объектов к объекту, выделенному курсором в дереве техпроцесса. Процедура настройки дерева и правил автоподбора описана в разделе **Настройка автоподбора**(см. п. ). По команде **Автоподбор** открывается окно с запросом:
По команде **Изменить** должен открыться справочник Imbase, если изменяемый объект был создан на его основе, а курсор спозиционируется на объекте Imbase, по которому был создан данный объект. Изменение текущего объекта происходит путем выбора другого объекта Imbase данного справочника с его атрибутами. В случае, когда использование справочника Imbase не позволяет создания копий объектов (атрибут **Создание копий объектов** имеет значение **Нет**), по команде **Изменить** производится исключение из состава техпроцесса и создание нового с сохранением атрибутов связи (количество, сортировка и т.п.). Если объект дерева техпроцесса был создан не на основе справочника Imbase, то по команде **Изменить** будет открыта страница свойств объекта, либо форма редактирования (при ее наличии), где пользователь сможет изменить значения атрибутов.
Команда **Копировать с атрибутами связи** позволяет скопировать выделенный объект с имеющимися у него атрибутами связи. Например, скопировать объект **Материал** со значением атрибута **Количество**. При использовании данной команды, будет выдаваться окно для выбора копируемых атрибутов связи.
При помощи подменю команды **переместить (внутри родит. объекта)** можно установить требуемый порядок следования элементов в дереве техпроцесса – переместить в начало, на один уровень вверх, на один уровень вниз, в конец в пределах родительского объекта. При помощи подменю команды **Перенумеровать** производится перенумерация объектов, номера которых приобрели неверные значения в результате перемещения, вставки, удаления. На рисунке ниже отображена команда **Перенумеровать** :
По команде **Перенумеровать/Объекты** будут перенумерованы объекты такого же типа и находящиеся на том же уровне, что и выделенный курсором в дереве техпроцесса объект.
По команде **Перенумеровать/Объекты в составе** будут перенумерованы объекты выбранного типа из состава объекта, выделенного курсором в дереве техпроцесса.
При выполнении данных команд вызывается окно с настроенным для данного типа объекта правилом нумерации. Пользователь может выбрать способ нумерации (автоматический или ручной) и начальный объект (нумерация с первого элемента, или с текущего). При выборе автоматического способа нумерации изменение ее параметров недоступно и перенумерация производится в соответствии с предварительно настроенным правилом. При выборе ручного способа нумерации пользователю доступно изменение параметров предварительно настроенного правила (см. п. ). Если тип выделенного в дереве техпроцесса объекта не имеет предварительно настроенного правила нумерации, то по команде **Перенумеровать/Объект** все равно будет подаваться окно настройки правила нумерации с предустановленным ручным режимом перенумерации и возможностью изменения ее параметров. При помощи подменю команды **Элемент типового фрагмента** можно добавлять в дерево техпроцесса объекты из состава типовых фрагментов.
По нажатию команд **Элемент типового фрагмента/Добавить** и **Элемент типового фрагмента/Добавить в состав** открывается окно выбора типового фрагмента. 
После выбора типового элемента пользователю подается окно с деревом состава типового фрагмента. В данном дереве необходимо установить отметки для тех элементов, которые необходимо добавить в техпроцесс.

По команде **Развернуть состав** происходит раскрытие дерева состава выделенного объекта техпроцесса на определенное число уровней.
По команде **Свернуть состав** происходит сворачивание дерева состава выделенного объекта техпроцесса.
По команде **Выделить все** происходит выделение (выбор галочками) всех объектов техпроцесса.

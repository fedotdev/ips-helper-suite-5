# Настройка элементов расцеховочного маршрута
В состав расцеховочного маршрута может входить несколько объектов с типами, являющимися дочерними для типа объекта **Технологические объекты/Расцеховочный объект/Шаблон расцеховки базовый**. По умолчанию это объекты типа **Шаблон изготовления** и **Шаблон сборки**. В свою очередь объекты указанных типов в своем составе будут содержать объекты типа **Расцеховочный элемент**. Вид элементов в расцеховочном маршруте определяется соответствующими настройками (см. п. ).
Создание шаблона расцеховочного элемента (тип объекта **Технологические объекты/Расцеховочный объект/Шаблон расцеховочного элемента**) выполняется по команде контекстного меню **Создать/Новый**. 
Шаблон элемента расцеховочного маршрута определяется указанием цеха/участка и вида работ.
Для правильной работы редактора технологических процессов должна быть настроена привязка видов работ к видам производств. В этом случае будет отслеживаться связь вновь создаваемого техпроцесса с расцеховочным маршрутом. Для этого необходимо выполнить команду контекстного меню **Открыть в новом окне** для вида производства (**Технологические объекты/Вид работ/производства базовый**) и добавить (команда контекстного меню **Состав объекта/Добавить в состав**) в открывшемся диалоговом окне вид работ к имеющемуся виду производства.
На рисунке изображена привязка четырех видов работ (вырезка, механообработка, отрезка, слесарные работы) к виду производства **Механообработка**. Это означает, что для изделия техпроцесс с видом производства **Механообработка** может быть привязан к расцеховочному маршруту только в том случае, если в состав этого маршрута входит расцеховочный элемент с видом работ вырезка, механообработка, отрезка или слесарные работы.

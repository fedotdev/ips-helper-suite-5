# Расцеховочный маршрут
Для создания расцеховочного маршрута необходимо воспользоваться командой **Добавить** / **Расцеховочный маршрут** , выделив изделие либо маршрут обработки. Окно создания нового расцеховочного маршрута представлено на рисунке ниже:
По умолчанию расцеховке присваивается обозначение вида:
· **< обозначение изделия> <порядковый номер расцеховки> РМ**
Наименование расцеховки совпадает с наименование изделия. 
В поле **Тип маршрута** из выпадающего списка есть возможность выбрать **Постоянный** или **Временный**.
В поле **Назначение** из выпадающего списка есть возможность выбрать **Собственный** , **По кооперации** и **Для запчастей**.
В поле **Вид** из выпадающего списка есть возможность выбрать **Единственный** или **Множественный**.
Поле **Прототип** служит для указания прототипа для вновь создаваемого расцеховочного маршрута.
Для расцеховочного маршрута могут быть указаны даты ввода и аннулирования.
При создании дополнительного расцеховочного маршрута на изделие необходимо указать новый маршрут обработки.
При необходимости создания нескольких расцеховочных маршрутов в одном маршруте обработке, настройках параметров IPS для свойства **Контроль уникальности РМ** **в МО** следует установить значение «**нет** » (см. п. ).
Если расцеховочный маршрут был создан при помощи команды контекстного меню **Навигатора** **Создать расцеховочный маршрут** , то в разделе **Привязка к изделию** информация об изделии заполнятся автоматически не будет. 
Автоматически будет заполнено поле **Маршрут обработки** , если создается первый расцеховочный маршрут на изделие. 
Не следует создавать РМ одновременно по прототипу и с привязкой к определенному МО.
В состав вновь созданного расцеховочного маршрута по умолчанию автоматически будут включены объекты типов **Шаблон изготовления** и **Шаблон сборки**. 
Шаблону изготовления присваивается обозначение вида:
· **< обозначение изделия> <порядковый номер шаблона изготовления> ШИ**
Обозначение шаблона сборки будет иметь следующий вид:
· **< обозначение изделия> <порядковый номер шаблона сборки> ШС**
Для того чтобы для расцеховочного маршрута заполнить параметр **Строка маршрута** , необходимо в состав шаблона изготовления и в состав шаблона сборки включить в определенном порядке требуемые расцеховочные элементы. Добавление в шаблон расцеховочного элемента осуществляется на вкладке **Элементы расцеховки** для выделенного в дереве **Навигатора** шаблона изготовления или сборки. **Параметры шаблона расцеховки** показаны на рисунке ниже:
Страница **Параметры шаблона расцеховки** разбита на две части. Внизу отображается перечень существующих в базе расцеховочных элементов. Создание и настройка элементов РМ описана в п. . Вверху – добавленные в состав шаблона расцеховочные элементы, отсортированные в требуемом порядке. В нижней части страницы также присутствует кнопочная панель со следующими командами:
**Добавить** – добавляет выбранный расцеховочный элемент последним по порядку в состав шаблона.
**Вставить** – вставляет выбранный расцеховочный элемент в состав шаблона перед выделенным расцеховочным элементом из его состава.
**Удалить** – удаляет из состава шаблона выбранный расцеховочный элемент.
**Очистить** – удаляет из состава выделенного шаблона расцеховки все расцеховочные элементы.
Добавить расцеховочный элемент в состав шаблона возможно также по двойному нажатию левой кнопки мыши.
Для сортировки расцеховочных элементов в составе шаблона используются команды контекстного меню в верхней части страницы **Параметры шаблона расцеховки**. Контекстное меню данной страницы показано на рисунке ниже:
После формирования составов шаблонов изготовления и сборки по нажатию кнопки **Применить** из атрибутов расцеховочных элементов будет сформирован атрибут **Строка маршрута** объекта **Расцеховочный маршрут** по правилам, описанным в п. .
Для списка объектов **Расцеховочных маршрутов** доступна группа команд контекстного меню **Групповые изменения РМ** и команда **Обновить строку маршрута**. Команды доступны в том случае, если в конфигураторе настроена допустимая связь между объектами **Расцеховочный маршрут** и **Расцеховочный элемент**.
Команда **Групповые изменения РМ** включает группу команд:
· **Добавить элемент в начало** — данная команда позволяет добавить расцеховочный элемент в начало каждого из списка выделенных расцеховочных маршрутов.
Выбор расцеховочного элемента производится в диалоговом окне.
· **Добавить элемент в конец** — команда позволяет добавить расцеховочный элемент в конец каждого из списка выделенных расцеховочных маршрутов.
· **Заменить элемент** — команда позволяет массово заменить расцеховочные элементы в списке выделенных расцеховочных маршрутов. Первоначально будет показано диалоговое окно выбора расцеховочного элемента, который необходимо заменить, затем показано диалоговое окно выбора расцеховочного элемента на который необходимо заменить. Если в расцеховочном маршруте используется несколько одинаковых расцеховочных элементов, подлежащих замене, все они будут заменены.
· **Применить изменения в других ПК ДСЕ** — команда доступна для одного выделенного расцеховочного маршрута и позволяет скопировать строку выделенного маршрута на другие расцеховочные маршруты данного ПК ДСЕ, если таковые имеются на основе той же версии.
· **Удалить элемент** — команда позволяет массово удалить расцеховочные элементы в списке выделенных расцеховочных маршрутов. 
После выполнения групповых изменений РМ строка маршрута автоматически не пересчитывается, для этого необходимо использовать команду **Обновить строку маршрута**.

# Групповой режим привязки или режим привязки для выбранного элемента ГТП/ТТП.
Режим групповой привязки доступен начиная с версии IPS8 и осуществляется с помощью команд **Групповой режим привязки** или**Режим привязки (в ГТП/ТТП)**. 
Команда **Режим привязки (в ГТП/ТТП)** вызывается из контекстного меню**Навигатора** , на рисунке ниже показано расположение команды:
Команда **Групповой режим привязки** вызывается из контекстного меню на закладке **Список ДСЕ** рабочей области **Навигатора**.
Архитектура диалогового окна **Режим привязки для ТП:** показана на рисунке ниже:
В одной части окна, как правило в левой, расположен список всех ЕТП привязанных к ГТП/ТТП. Во второй части расположено дерево элементов ГТП/ТТП.
Необходимо выделить ЕТП в левой части и при помощи галочек установить привязку к элементам ГТП/ТТП в правой части.
Кнопка **Режим привязки техпроцессов** позволяет менять местами режим привязки изделий и элементов ТП. Если кнопка отжата, выполняется привязка элементов ТП к выделенному изделию. Если нажата – привязка изделий к выделенному элементу ТП.
Галочка **Привязывать дочерние элементы** позволяет устанавливать связь не только с текущим элементом, но и со всеми вложенными в него.
В окне группового режима привязки доступно контекстное меню для списка ЕТП и контекстное меню для элементов ГТП/ТТП.
Команда **Копировать привязки выбранного элемента ТП** позволяет скопировать привязки с выделенного элемента ТП, включая дочерние, и вставить их для другого изделия при помощи команды **Вставить привязки**.
При помощи команды **Открыть в отдельном окне** можно открыть ЕТП для выделенного изделия в отдельном окне.
Команда **Свойства (Карточка)** открывает окно с карточкой ЕТП.
Команда **Найти в дереве** позволяет найти нужное ЕТП в дереве ЕТП.
Команда **Новая папка** позволяет создать дополнительные папки.
Команды **Развернуть все** / **Свернуть все** позволяют развернуть / свернуть дерево элементов ГТП/ТТП.
Команды **Связать со всеми ЕТП** / **Отвязать от всех ЕТП** позволяет связать / отвязать выбранный элемент ТП со всеми изделиями.
Команда **Инвертировать отметки** позволяет снять отметки с выделенных объектов списка и отметить невыделенные.
Команда **Свойства (Карточка)** открывает окно карточки выделенного элемента ГТП/ТТП.
Команда **Найти в дереве** позволяет найти нужный элемент в дереве ГТП/ТТП.
По нажатию команды **Применить** / **Отмена** осуществляется сохранение /отмена выполненных изменений в окне привязок.

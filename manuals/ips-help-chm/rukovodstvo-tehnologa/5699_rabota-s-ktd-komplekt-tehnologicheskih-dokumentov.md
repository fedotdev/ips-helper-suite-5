# Работа с КТД (комплект технологических документов)
При открытии КТД на просмотр, подгружается модуль редактора документов и шаблонов и соответствующие команды меню.

Окно просмотра открывается при формировании документов либо при использовании команды **Смотреть** контекстного меню, находясь на объекте КТД.
В окне просмотра КТД листание комплекта осуществляется при помощи клавиш **[Page Down]** (вперед) и **[Page Up]** (назад). Так же для листания комплекта предназначена панель **Навигация** :
Кнопки данной панели выполняют следующие действия:
 – переход на первую страницу отображаемого документа.
 – переход на предыдущую страницу комплекта.
 – быстрый переход на выбранную страницу отображаемого документа.
 – переход на следующую страницу комплекта.
 – переход на последнюю страницу отображаемого документа.
 – переход к предыдущему документу.
 – быстрый переход к выбранному документу из списка.
 – переход к следующему документу.
 – по нажатию на стрелочку можно отключать / включать команды панели **Навигация**.
Панель **Навигация** , как и остальные панели (**Красный карандаш** , **Редактировать замечание**) может быть добавлена/удалена путем установки, снятия галочки в контекстном меню. 
Команды панелей **Таблицы** , **Форматирование** , **Элементы страницы** в данном окне не активны.
Панель **Красный карандаш** содержит команды **Включить редактирование замечаний** и **Завершить редактирование замечаний** , позволяющие включить / выключить внутренний редактор замечаний для добавления замечаний. Подробнее работа с внутренним редактором замечаний описана в 
Панель **Редактировать замечания** содержит основные команды красного карандаша, которые доступны при активировании команды **Включить редактирование замечания**.
Сохранение КТД производится по команде меню **Файл** / **Сохранить как**. Для сохранения доступны форматы: 
По команде меню **Файл** / **Предварительный просмотр** либо по аналогичной команде панели инструментов **Предварительный просмотр** выполняется предварительный просмотр КТД перед печатью.
По команде меню **Файл** / **Печать** либо аналогичной команде меню панели инструментов **Печать** производится печать КТД.
Упрощенный просмотр сформированного КД осуществляется на вкладке **Просмотр**.
Выделив нужный документ при помощи клавиш **[Page Down]** (вперед) и **[Page Up]** (назад) можно осуществлять переход на другие страницы документа. Так же доступна панель **Навигации**.
Команда **Редактировать замечание** позволяет загрузить внутренний редактор замечаний для добавления замечаний. 
Команды панели **Зумирования** позволяют изменять масштаб отображения документа на экране.
 – возврат к предыдущему виду.
 – увеличить масштаб отображения.
 – уменьшить масштаб отображения.
 – устанавливает оригинальный размер документа.
 – позволяет вписать документ в окно по максимальной высоте или ширине.
Команда **Измерить расстояние** позволяет измерить расстояние и угол от указанной точки. Команда активна при использовании внутреннего редактора замечаний.
Команда **Внешний редактор замечаний** позволяет загрузить внешний редактор замечаний. Подробнее работа с внешним редактором замечаний описана в 
Для объекта КТД становятся доступны следующие команды контекстного меню **Отчеты и документы** :
· **Обновить комплект** – позволяет обновить уже сформированный основной КД.
· **Создать версию комплекта** – позволяет создать новую версию имеющегося КД.
· **Генерация дополнительных комплектов** – формирует дополнительный комплект документов для уже имеющегося основного КД.
· **Обновить дополнительные комплекты** – позволяет обновить дополнительный КД.
· **Создать версию дополнительных комплектов** – позволяет создать новую версию имеющегося дополнительного КД.
Для того, чтобы сформировать аутентичный файл КДТ, необходимо воспользоваться командой контекстного меню **Аутентичные файлы.**

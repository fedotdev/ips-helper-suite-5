# Правила автоподбора
Настройка для выделенного в левой части окна типа объекта производится в центральной части окна настройки правил автоподбора при помощи команд контекстного меню.
Команда **Создать новое правило/Для типа объекта** используется в случае, когда автоподбор должен работать для любого объекта данного типа.
Команда **Создать новое правило/Для элемента справочника** используется в случае, когда автоподбор должен работать для объекта, созданного с использованием указанного элемента справочника (каталога) Imbase.
Команда **Назначить существующее /Для типа объекта** позволяет выбрать уже существующее правило автоподбора для выбранного в окне дерева автоподбора типа объекта.
Команда **Назначить существующее/Для элемента справочника** позволяет выбрать уже существующее правило автоподбора для выбранного в окне дерева автоподбора типа объекта, созданного с использованием указанного элемента справочника (каталога) Imbase.
При помощи выпадающего меню команды **Переместить** можно настроить порядок выполнения правил во время работы автоподбора.
Команда **Исключить из справочника** исключает выбранное правило автоподбора из списка правил для выбранного типа объекта или элемента справочника (каталога) Imbase.
Команда **Удалить** удаляет выбранный объект **Правило автоподбора** из базы данных.
Команда **Отладка автоподбора** позволяет произвести проверку автоподбора. Подробнее описано в п.

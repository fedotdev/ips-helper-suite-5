# Команды подменю Сервис
Команда меню **ТЕХ. ЭСКИЗ / Сервис / Обнуление координаты Z** применяется при использовании в качестве базовых деталей чертежей AutoCAD, полученных трансляцией в формат .dwg моделей 3D-систем конструирования. Использование этой команды позволяет избежать возможных проблем при создании эскизов, вызванных некорректной конвертацией данных. 
По команде меню **ТЕХ. ЭСКИЗ/Сервис/Поиск объектов за пределами эскиза** открывается окно, в котором указывается, какие эскизы имеют объекты за пределами границы поля рисунка.
Кнопки этого окна позволяют либо удалить объекты, находящиеся за существующей границей поля рисунка, либо самому выбрать границы, за пределами которых будут удалены ненужные элементы эскиза.

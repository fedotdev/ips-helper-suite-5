# Область вложенных страниц
В области вложенных страниц присутствуют одна обязательная страница **Условия** (для всех элементов) и две дополнительные – **Анкета** и **Условия на столбцы** (для элементов **Создать объект IMBASE**).
На странице **Условия** отображаются условия, заданные на выбранный элемент по соответствующей команде контекстного меню в области состава правила автоподбора. Данная страница имеет также свое контекстное меню, при помощи команд которого можно изменить условие, скопировать его, вставить или удалить.
Если для элемента правила **Создать объект IMBASE** в его свойстве **Папка IMBАSE** указана таблица, то на странице **Анкета** будет показано содержимое этой таблицы.
**Анкета** чаще всего содержит более одной записи, поэтому для того, чтобы автоматизированный подбор дал требуемый результат, необходимо задать критерии выбора записи анкеты. Цель определения критериев подбора одна: отсечение как можно большего количества неподходящих записей таблицы. Наилучший вариант, конечно, такой, при котором однозначно определяется требуемая запись – в этом случае программа сделает все самостоятельно. Для каждой анкеты можно определить критерии двух видов: условия на столбцы и минимум/максимум.
· Условия на столбцы – это условия, накладываемые на параметр, значения которого приводятся в данном столбце анкеты. Те строки анкеты, в которых находятся значения, не удовлетворяющие условию, отсекаются.
· Минимум/Максимум – это дополнительный критерий оптимизации, позволяющий выбрать одну запись из числа тех, которые удовлетворяют условиям на столбцы.
Для создания условия на столбец, необходимо на нем вызвать по правой кнопке мыши контекстное меню и выполнить команду **Добавить условие**.
Если на столбец анкеты задано условие, то его заголовок меняет цвет с серого на голубой.
Изменение или удаление уже существующего условия на столбец также осуществляется при помощи соответствующих команд контекстного меню **Изменить условие** и **Удалить условие**.
Минимум или максимум назначается на столбец и позволяет выбрать наибольшую или наименьшую по данному столбцу строку. Для установки критерия минимума или максимума следует использовать соответствующие команды контекстного меню страницы **Анкета – Модификатор – Мin** и**Модификатор - Max**. Чаще всего указанные критерии имеет смысл назначать в комплексе с условием на столбец, но можно также устанавливать минимум или максимум даже на те столбцы, для которых не заданы условия – это позволяет ограничить количество строк анкеты по одному параметру для последующего выбора по-другому.
Отсев записей анкеты при подборе происходит в следующем порядке: сначала проверяются условия на столбцы, затем применяются критерии минимума-максимума. Если после всех этих проверок в качестве отобранных будет числиться более одной записи анкеты, то пользователь будет иметь возможность выбрать конкретную запись вручную. Разумеется, выбора записи вручную можно избежать при правильно расставленных критериях.
Команды **Выделить / Снять выделение** вложенного меню **Строки по-умолчанию** позволяют выделить / снять выделение голубым цветом строки, на которой расположен курсор. При помощи команды **Очистить** производиться снятие выделение со всех строк. Команда **Инвертировать** позволяет обратить выделение строк на обратное: выделенные строки становятся не выделенными, не выделенные – выделенными.
Вложенная страница **Условия на столбцы** позволяет просмотреть уже назначенные условия на столбцы в виде списка и отредактировать их с помощью команд контекстного меню.
В правилах автоподбора оснастки, которые были импортированы из баз более ранних версий Techcard, могут встречаться условия, содержащие атрибуты с кратким наименованием **ЭТО** (Числовое значение параметра в столбце анкеты оснастки) или **ЭТО_** (Строковое значение параметра в столбце анкеты оснастки). Использование данных атрибутов обусловлено тем, что ранее было невозможно указать в условии атрибут, связанный со столбцом анкеты оснастки.
Сейчас при настройке автоподбора оснастки вместо атрибутов **ЭТО** и **ЭТО_** в условиях на столбцы анкеты можно указывать атрибуты, соответствующие этим столбцам.

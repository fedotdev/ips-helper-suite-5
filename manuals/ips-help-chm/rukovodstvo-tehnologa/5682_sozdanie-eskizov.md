# Создание эскизов
В главном меню системы проектирования эскизов необходимо выбрать пункт меню – **ТЕХ. ЭСКИЗ** , после чего откроется набор команд, представленных на рисунке.
Команды меню **ТЕХ. ЭСКИЗ** дублируются кнопками панелей **TECHCARD** , отображение которых настраивается по команде меню **ТЕХ. ЭСКИЗ/Панели TECHCARD**.
Система позволяет генерировать изображение операционного эскиза на основе чертежа детали, спроектированного конструктором, чертежа любой другой детали, операционных эскизов другого техпроцесса, а также самостоятельно отрисовывать эскиз средствами CADMECH. Использование готового чертежа детали в некоторых случаях затруднительно, например, при проектировании эскиза заготовки и эскизов на начальные операции. В этом случае предоставлена возможность использовать в качестве прототипа эскиз любой операции. Проектирование начинается с создания нового эскиза. Для задания наименования эскиза необходимо воспользоваться кнопкой **Имя нового эскиза** , после чего появится диалог выбора эскиза:
Содержимое дерева соответствует перечню наименований операций технологического процесса, передаваемому из системы TECHCARD.
Каждая операция может иметь несколько эскизов. Для того, чтобы добавить эскиз к операции, следует установить на нее курсор и нажать кнопку **Добавить** , после чего в дереве появится новый лист, имя листа будет определять название эскиза. Изменение названия эскиза производится при помощи щелчка левой кнопкой мыши, когда указатель мыши находится на соответствующем листе дерева. Также можно создавать и любое количество эскизов на сам техпроцесс. Для этого необходимо установить курсор на обозначение техпроцесса и нажать кнопку **Добавить**.
При необходимости может быть задан прототип эскиза. Прототипом может быть любой эскиз из любого техпроцесса, загруженного в IPS в отдельном окне. Для выбора прототипа необходимо нажать кнопку **Прототип эскиза...** и из появившегося списка существующих эскизов выбрать требуемый эскиз.
Переключатель **Копировать размеры** указывает на необходимость копирования размеров из прототипа в новый эскиз. Переключатель **Зеркальное отображение** позволяет получить эскиз детали в зеркальном отображении.

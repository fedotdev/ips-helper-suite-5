# Создание слайдов эскизов
Команда меню **ТЕХ.ЭСКИЗ/Слайд эскиза** и кнопка **Слайд эскиза** используется для создания слайдов. 
При выборе команды меню **ТЕХ.ЭСКИЗ/Закончить работу с эскизами** или кнопки **Закончить работу с эскизами** произойдет сохранение эскизов и выход из CADMECH-T.

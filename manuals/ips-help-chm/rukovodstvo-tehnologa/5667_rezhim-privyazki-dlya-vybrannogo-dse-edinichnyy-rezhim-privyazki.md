# Режим привязки для выбранного ДСЕ (Единичный режим привязки)
Данный режим привязки применяется только для определенного изделия и осуществляется по команде **Режим привязки**.
Привязка производится путем установки отметок в соответствующих полях слева от требуемых элементов.
При привязке изделия к элементам ТП работает механизм наследования привязок от родительского элемента к подчиненному. Например, привязав к изделию операцию, все переходы данной операции, оборудование, оснастка и т.д. будут автоматически привязаны к данному изделию.
Если элемент техпроцесса не привязывается к маршруту обработки изделия, а привязывается часть элементов из его состава (не все), то данный элемент также помечается в окне привязки, но поле для отметки при этом затемнено.
Контекстное меню окна **Привязка элементов ГТП/ТПП к изделию** содержит команды.
Команды **Выделить все** / **Снять выделение** позволяет связать / отвязать все элементы ТП с изделием.
Команда **Инвертировать отметки** позволяет снять отметки с выделенных объектов списка и отметить невыделенные.
Команды **Развернуть все** / **Свернуть все** позволяют развернуть / свернуть дерево элементов ГТП/ТТП.
По нажатию команды **Применить** / **Отмена** осуществляется сохранение /отмена выполненных изменений в окне привязок.

# Настройка элементов бланка редактор текста
Для настройки вывода значений атрибутов в шапку бланка и в варианты рабочей области, на бланке присутствуют элементы **Редактор текста**. Для них доступны настройки.
В поле **Условие** задается условие вывода поля **Значение** в ячейку документа.
В поле **Значение** в выпадающем списке выбирается тип выводимого элемента бланка.
В поле ниже задается шаблон для выбранного из выпадающего списка типа элемента.
Если для примитива варианта не требуется повторение значения соответствующего элемента бланка, то может быть включен режим **Не повторять**. 
Свойство **Рассчитывать при формировании документа** назначается элементу бланка, расчет которого необходимо проводить непосредственно в процессе формирования документа.
Для значений с **Типом: Вещественный** добавляется возможность ввода **Количество цифр после точки**.

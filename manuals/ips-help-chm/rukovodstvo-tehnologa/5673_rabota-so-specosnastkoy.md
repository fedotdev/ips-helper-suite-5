# Работа со спецоснасткой
Порядок работы со спецоснасткой определяет каждое предприятие для себя самостоятельно.
Как правило, схема работы со спецоснасткой состоит из следующих этапов:
1\. Технолог создает заявку на проектирование технологической оснастки. 
Создание производится по команде контекстного меню **Добавить** , выделив объект **МО, техпроцесс** или **операция**

Путь нахождения объекта **Заявка на проектирование** в навигаторе – **Информационное пространство / Объекты / Заявки / Заявки на проектирование оснастки**.
В окне **Создание нового объекта Заявка на проектирование оснастки** необходимо заполнить поля.
В поле **Наименование СТО** указывается наименование заявки на проектирование оснастки.
В поле **Оборудование** выбирается оборудование, на котором данная оснастка будет применяться.
В поле **Основание заявки** выбирается основание создания заявки на проектирование.
В поле **Номер заявки** указывается номер заявки.
**Дата внедрения изделия** – указывает на дату внедрения изделия, для которого разрабатывается СТО.
**Дата внедрения СТО –** указывает на дату внедрения самого СТО.
В поле**Технические требования (описание СТО)** указывается технические требования, которым должна удовлетворять СТО.
Поле**Маршрут обработки** и**Изделие** заполнятся автоматически после нажатия кнопки **Готово**.
В поле **Заявку составил** указывается автор заявки на проектирование СТО. По умолчанию будет установлен текущий автор.
Далее заявка согласовывается и направляется конструктору.
2\. Конструктор на основании **Заявки на СТО** разрабатывает и заносит в IPS объект **Специальная технологическая оснастка**. 
Целостные детали специальной технологической оснастки заносятся в IPS по пути **Информационное пространство / Объекты / Изделия / Детали / Специальная технологическая оснастка (детали)** , сборочные единицы**–Информационное пространство / Объекты / Изделия / Сборочные единицы / Специальная технологическая оснастка.**

Далее конструктор заполняет вкладку **Резолюция КБ Заявки на проектирование**.
В поле **Резолюция КБ** вносится комментарий конструктора о проделанной работе или невозможности ее выполнения.
В поле **Спроектированная оснастка** отображается обозначение и наименование спроектированной оснастки. Поле подтягивается автоматически после добавления объекта СТО в состав заявки на проектирование.
В полях **Дата начала проектирования СТО** и **Дата окончания проектирования СТО** указывается дата начала/окончания проектирования специальной оснастки.
3\. Технолог, ответственный за добавление объектов НСИ, оформляет и согласовывает «Заявку на добавление НСИ». Данный объект в навигаторе находится по пути **Информационное пространство / Объекты / Заявки / Заявки на ввод / Изменение НСИ.**
В поле **Каталог** указывается каталог, в который будет вводится новая запись. При использовании на предыдущем этапе классификатора, поле заполнится автоматически.
В поле **Наименование НСИ** указывается полное наименование НСИ. Полное наименование НСИ, формируемое автоматически, не всегда является правильным, поэтому при занесении объекта в базу, оператор НСИ сам формирует наименование НСИ.
В поле **Изделие** указывается изделие, на которое разрабатывалась данная оснастка.
В поле **Примечание** указывается примечание к заявке, например, путь расположения объекта в каталоге.
На вкладке **Состояние** в поле **Созданный объект** указывается спроектированная конструктором СТО.
Данная заявка направляется оператору НСИ.
4\. Оператор НСИ заносит на основании заявки НСИ запись в Imbase.
Далее в заявке НСИ необходимо изменить статус заявки с **Новая** на**Данные внесены** или**Данные существуют**(если запись присутствовала в Imbase) и указывается **Путь расположения** объекта НСИ. 
При необходимости, на закладке **Параметры** корректируется поле **Наименование НСИ.**
Далее заявка возвращается технологу.
5\. Технолог по команде **Добавить / Оснастка** добавляет в техпроцесс, созданный оператором НСИ объект Imbase.
При необходимости внесения изменений в КД технологической оснастки, по заявке технолога конструктор создает и согласовывает извещение об изменении.

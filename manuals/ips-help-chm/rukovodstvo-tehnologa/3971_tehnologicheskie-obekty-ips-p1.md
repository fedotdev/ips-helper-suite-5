# Технологические объекты IPS (часть 1)

В данном разделе приводится перечень объектов IPS, которые по умолчанию могут быть использованы при технологической подготовке производства. В процессе эксплуатации системы внешний вид иконок и наименования типов объектов могут быть изменены.
Большинство объектов, которые могут применяться для технологической подготовки производства собраны в дереве **Навигатора** в группу **Типы объектов/Технологические объекты**.
| **Типы объектов** | **Описание** |
| --- | --- |
| Вид заготовки | Тип объекта, ссылка на который указывается при редактировании заготовки. Определяет, какие формулы, таблицы или скрипты будут использоваться при расчете параметров заготовки. |
| Вид изделия | Тип объекта, ссылка на который указывается при редактировании заготовки. Определяет, какие формулы, таблицы или скрипты будут использоваться при расчете параметров заготовки. |
| Вид работ/производства базовый | Группирующий тип объекта для типов объектов **Вид работ** и **Вид производства**. |
| Вид производства | Тип объекта, ссылка на который указывается при создании нового техпроцесса. |
| Вид работ | Тип объекта, ссылка на который указывается при создании нового расцеховочного элемента (пары **Цех + Вид работ** , использующейся при формировании шаблона расцеховочного маршрута). Объекты **Вид работ** могут входить в состав объекта **Вид производства** – по этой входимости определяется возможность привязки вновь создаваемого техпроцесса к расцеховочному маршруту. Т.е. техпроцесс на механообработку может быть привязан к расцеховочному маршруту, в котором использован вид работ, входящий в состав вида производства **Механообработка**. |
| Группа операций | Тип объекта, который используется для группировки операций по какому-либо признаку в составе техпроцесса. |
| Групповая заготовка | Тип объекта, который используется для группировки заготовок по какому-либо признаку. |
| Дополнительный прием | Тип объекта, который может входить в состав операций или переходов, и служит для более подробного описания данных объектов. |
| Единица состава изделия | Группирующий тип объекта для типов объектов **Комплектующая единица** и **Собираемая единица**. |
| Комплектующая единица | Тип объекта, используемый для ссылки на изделие, которое будет участвовать в комплектовании собираемой единицы на данном этапе техпроцесса. |
| Собираемая единица | Тип объекта, используемый для ссылки на изделие, которое будет собираться на данном этапе техпроцесса. |
| Заготовка | Тип объекта, служащий для описания заготовки на изделие, а также расчета ее параметров. Объекты типа **Заготовка** не включаются непосредственно в состав изделий, а только через объект типа **Маршрут обработки** , входящий в состав изделия непосредственно. |
| Изменения ТП | Тип объекта, используемый для фиксирования изменений в техпроцессе. |
| Комментарий | Тип объекта, используемый для добавления комментариев в состав технологических объектов. |
| Контролируемый параметр базовый | Группирующий тип объекта для типов объектов **Группа контролируемых параметров** и **Контролируемый параметр**. |
| Группа контролируемых параметров | Тип объекта для указания перечня контролируемых параметров операции или перехода. В состав группы контролируемых параметров может входить оснастка, при помощи которой будет осуществляться контроль. |
| Контролируемый параметр | Тип объекта для указания контролируемого параметра операции или перехода. В состав контролируемого параметра может входить оснастка, при помощи которой будет осуществляться контроль. |
| Нормирование | Группирующий тип объекта для типов объектов **Нормирование на доп. прием** , **Нормирование на операцию** , **Нормирование на переход** , **Нормирование на техпроцесс**. |
| Нормирование на доп. прием | Тип объекта для указания норм времени на дополнительный прием. |
| Нормирование на операцию | Тип объекта для указания норм времени на операцию. |
| Нормирование на переход | Тип объекта для указания норм времени на переход. |
| Нормирование на сварочный шов | Тип объекта для указания норм времени на сварочный шов. |
| Нормирование на техпроцесс | Тип объекта для указания норм времени на техпроцесс. |
| Объекты технологического маршрута | Группирующий тип объекта для типов объектов **Входимость маршрута обработки** , **Маршрут обработки.** |
| Входимость маршрута обработки | Тип объекта для указания входимости маршрута обработки. |
| Маршрут обработки | Тип объекта, определяющий способ обработки изделия. В состав изделия может входить несколько объектов типа **Маршрут обработки**. В состав маршрута обработки может входить только один объект **Расцеховочный маршрут** , один объект **Заготовка** и любое количество техпроцессов, описывающих процесс обработки изделия по данному расцеховочному маршруту из данной заготовки. |
| Операция | Тип объекта, описывающий законченную часть технологического ​процесса, выполняемую на одном рабочем месте. |
| Оснастка базовая | Группирующий тип объекта для типов объектов **Инструмент** , **Инструментальная позиция** , **Оснастка**. |
| Инструмент | Тип объекта, в состав которого может входить оснастка, являющаяся частью составной оснастки (например, сборный резец, в состав которого входят державка и режущая пластина). |
| Инструментальная позиция | Тип объекта, в состав которого может входить оснастка, закрепленная в определенном положении многопозиционного приспособления. |
| Оснастка | Тип объекта, описывающий средства технологического оснащения, дополняющие технологическое оборудование для выполнения определенной части технологического процесса. Примерами технологической оснастки являются режущий инструмент, штампы, приспособления, калибры, пресс-формы, модели, литейные формы, стержневые ящики и т.д. |
| Переход | Тип объекта, описывающий законченную часть технологической операции, выполняемую одними и теми же средствами технологического оснащения при постоянных технологических режимах и установке (технологический переход), либо состоящую из действий человека и (или) оборудования, который не сопровождаются изменением свойств предметов труда, но необходимы для выполнения технологического перехода (вспомогательный переход). |
| Поверхность базовая | Группирующий тип объекта для типов объектов **Поверхность дополнительная** и **Поверхность основная**. |
| Поверхность дополнительная | Тип объекта для описания параметров дополнительной поверхности (для автоматического формирования техпроцесса с использованием кодирования поверхностей). |
| Поверхность основная | Тип объектов для описания параметров основной поверхности (для автоматического формирования техпроцесса с использованием кодирования поверхностей). |
| Производственные единицы | Группирующий тип объекта для типов объектов **Рабочий центр** , **Участок** и **Цех**. |
| Рабочий центр | Тип объекта, являющийся звеном технологической цепочки, состоящим из одного или более операторов и/или оборудования с одинаковыми возможностями, которые могут рассматриваться в ходе планирования мощностей и составления графика производства как единый объект. |
| Участок | Тип объекта, являющийся совокупностью рабочих мест, на которых выполняются технологически однородные операции или различные операции по изготовлению одного-двух видов продукции. |
| Цех | Тип объекта, являющийся административно-обособленной частью предприятия, специализирующейся либо на изготовлении продукции или части ее, либо на выполнении определенной стадии производственного процесса. |
| Расцеховочный объект | Группирующий тип объекта для типов объектов **Расцеховочный маршрут** , **Расцеховочный элемент** , **Шаблон расцеховки базовый** и **Группа цехов закрепления**. |
| Группа цехов закрепления | Тип объекта, служащий для указания перечня цехов, которые могут быть использованы при создании расцеховочного маршрута. |
| Расцеховочный маршрут | Тип объекта, описывающий цепочку цехов (участков), по которым проходит деталь в процессе изготовления, с указанием видов работ. |
| Расцеховочный элемент | Тип объекта, содержащий ссылки на объекты типа **Цех** , **Участок** , **Вид работ** , из которого формируется строка расцеховочного маршрута. По умолчанию может входить в состав объектов типа **Шаблон расцеховки**. |
| Шаблон расцеховки базовый | Группирующий тип объекта для типов объектов **Шаблон изготовления** , **Шаблон сборки**. |
| Шаблон изготовления | Тип объекта, являющийся частью расцеховочного маршрута, в состав которого входят расцеховочные элементы, описывающие процесс изготовления изделия. Объекты данного типа могут входить в состав объектов **Расцеховочный маршрут**. |
| Шаблон сборки | Тип объекта, являющийся частью расцеховочного маршрута, в состав которого входят расцеховочные элементы, описывающие процесс сборки изделия. Объекты данного типа могут входить в состав объектов **Расцеховочный маршрут**. |
| Шаблон расцеховочного элемента | Тип объекта для создания шаблонов расцеховочного элемента, используемых в дальнейшем в **Расцеховочном маршруте**. |
| Режим | Тип объекта для описания режимов обработки на операции, переходе или дополнительном приеме. |
| Сварочный шов | Тип объекта для описания параметров сварочного шва на операции, переходе или дополнительном приеме. |
| Технологический объект представления | Тип объекта, служащий для передачи данных о входимости в сборочный узел в заказе, помещаемом на рабочий стол. |
| Техпроцесс базовый | Группирующий тип объекта для типов объектов **Техпроцесс групповой** , **Техпроцесс единичный** , **Техпроцесс типовой** , **Типовой элемент техпроцесса**. |
| Техпроцесс групповой | Тип объекта, описывающий технологический процесс изготовления группы изделий с разными конструктивными, но общими технологическими признаками. |
| Техпроцесс единичный | Тип объекта, описывающий технологический процесс изготовления или ремонта изделия одного наименования, типоразмера и исполнения, независимо от типа производства. |
| Техпроцесс типовой | Тип объекта, описывающий технологический процесс изготовления группы изделий с общими конструктивными и технологическими признаками. |
| Типовой элемент техпроцесса | Тип объекта, описывающий избыточные многовариантные наборы операций, оборудования, переходов, оснастки вместе с операционными эскизами. Служит для сокращения трудоемкости проектирования техпроцессов, создающихся на его базе. |
| Требования базовые | Группирующий тип объекта для типов объектов **Технические требования базовые** , **Технические условия базовые** , **Требования по технике безопасности базовые**. |
| Технические требования базовые | Группирующий тип объекта для типов объектов **Группа технических требований** , **ТТ – технические требования**. |
| Группа технических требований | Тип объекта для задания нескольких технических требований к технологическому объекту. |
| – ТТ- технические требования | Тип объекта для задания технических требований к технологическому объекту. |
| Технические условия базовые | Группирующий тип объекта для типов объектов **Группа технических условий** , **ТУ – технические условия**. |
| Группа технических условий | Тип объекта для задания нескольких технических условий к технологическому объекту. |
| – ТУ-технические условия | Тип объекта для задания технических условий к технологическому объекту. |
| Требования по технике безопасности базовые | Группирующий тип объекта для типов объектов **Группа требований по технике безопасности** , **Требования по технике безопасности**. |
| Группа требований по технике безопасности | Тип объекта для задания нескольких требований по технике безопасности к технологическому объекту. |
| Требования по технике безопасности | Тип объекта для задания требований по технике безопасности к технологическому объекту. |
| Управляющие программы | Тип объекта, позволяющий включать в состав техпроцесса файлы с управляющими программами. |
| Цех закрепления | Тип объекта, служащий для указания цехов, один из которых может быть использован при формировании РМ. |
| Цехозаход | Тип объекта, характеризующий перемещение изделия в определенный цех в процессе обработки. В состав цехозахода входят операции, сам же цехозаход создается непосредственно в составе техпроцесса. |
| Эскиз базовый | Группирующий тип объекта для типов объектов **Группа эскизов** , **Эскиз**. |
| Группа эскизов | Тип объекта для создания нескольких операционных эскизов на технологический объект (техпроцесс, операцию, переход). |
| Эскиз | Группирующий тип объекта для типов объектов **Эскиз Cadmech-T** , **Эскиз OLE**. |
| Эскиз Cadmech-T | Тип объекта, содержащий информацию об эскизах на техпроцессы, операции, переходы, созданных при помощи редактора эскизов Cadmech-T. |
| Эскиз OLE | Тип объекта, содержащий информацию об эскизах на техпроцессы, операции, переходы, созданных в приложениях, поддерживающих OLE-технологию (технологию присоединенных и встроенных объектов). |
Следующие типы объектов не внесены в группу **Технологические объекты** , но также могут применяться при технологической подготовке производства. Данные типы объектов находятся непосредственно в группе **Типы объектов**. 
 Заявки на проектирование оснастки | Тип объекта предназначенный для оформления заявки на проектирование специальной технологической оснастки (СТО). 
 Материал базовый | Группирующий тип объекта для типов объектов **Группы материалов** , **Марки материалов** , **Материалы** ,**Материалы** , **неопределенные** ,**Материалы составные** ,**Наборы материалов** ,**Свойства материалов.** 
 Группы материалов | Тип объекта, предназначенный для включения в его состав нескольких объектов типа **Материал** , используемых на определенном этапе техпроцесса.

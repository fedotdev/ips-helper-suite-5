# Список объектов по схеме поиска
Инструмент позволяет вывести список объектов, найденных по схеме поиска, с вкладки поиск состава в данное поле на карточке объекта.
Имеет настройки:
· **Использовать псевдонимы колонок**. Позволяет разрешить/запретить использовать псевдонимы колонок. Псевдонимы назначаются в поле **Псевдонимы колонок**.
· **Отображаемые колонки**. Поле аналогично соответствующему полю компонента **Дерево**.
· **Псевдонимы колонок**. Позволяет задать псевдонимы отображаемых колонок.
· **Сортировка по умолчанию**. Поле аналогично соответствующему полю компонента **Дерево**.
· **Схема поиска**. Позволяет указать схему поиска объекта. Схема поиска работает от текущего объекта.

# Настройка документов TechCard
Начиная с версии 7 в IPS был добавлен механизм настройки документов TechCard, по аналогии со старой системой TechCard, без использования скриптов генерации документов. 
Примечание: данный функционал доступен при условии, наличия загруженного модуля Intermech.TechCard.Document.Client на клиенте и модуля Intermech.TechCard.Document.Server на сервере. 
Объект **Настройка документов Techcard** создается по пути **Информационное пространство/Объекты/** **Настройки системы/Настройки документов TechCard**. 
При создании объекта, в диалоговом окне необходимо указать объект **Шаблон документов (бланки)** , на основе которого будут производиться настройки формируемого документа. Данный шаблон будет записан в атрибут **Шаблон генерируемого документа**. 
При первом взятии объекта на редактирование будет предложено сгенерировать настройки документа TechCard по умолчанию.
При нажатии «**Да** » система автоматически попытается сгенерировать настройки бланка по умолчанию.
Окно настройки документов TechCard состоит из вкладок **Настройки бланка** (п. - п. ) и **Настройка порядка вывода объектов**(п. ). 
На вкладке **Настройка бланка** производится настройка свойств самого документа (бланка), вариантов рабочей области бланка и элементов бланка **Редактор текста** или**Контейнер**. Слева в окне отображается дерево состава бланка, справа – доступные настройки свойств для выделенного слева элемента.
Контекстное меню дерево состава бланка содержит команды:
· **Обновить** – позволяет обновить данные дерева состава бланка при изменении шаблона.
· **Показать шаблон документа** – позволяет отобразить шаблон документа, автоматически выделив элемент бланка для которого была выполнена данная команда.

# Выбор из справочника без создания объекта
Для автоматического выбора атрибута из справочника Imbase без создания соответствующего объекта, необходимо в свойстве **Режим выбора из справочника IMBASE** установить опцию **Выбор из справочника** , а в параметре **Справочник IMBASE** указать справочник, из которого будет производиться выбор.
В этом случае при выборе соответствующего атрибута будет отрываться окно справочника Imbase (указанного в параметре **Справочник IMBASE**), но объект в навигаторе создаваться не будет.
Атрибут будет ссылаться на элемент справочника Imbase.
Способ описанный в п. и []() применяется в том случае, если имеется сложная иерархия элементов справочника.

# Создание эскизов
IPS позволяет создавать следующие виды эскизов:
· **С использованием редактора** **эскизов CADMECH-T.** (см. п )
· **OLE эскизы.**(см. п )
· **Технологические эскизы NanoCad и Технологические эскизы SolidWorks.** (см. п. )
· **Технологические эскизы SolidWorks по модели сервисной сборки** (см. п. )
Создание эскизов производится по команде контекстного меню **Добавить,** находясь на элементе ТП, для которого создается эскиз, и далее необходимо выбрать соответствующий тип эскиза.

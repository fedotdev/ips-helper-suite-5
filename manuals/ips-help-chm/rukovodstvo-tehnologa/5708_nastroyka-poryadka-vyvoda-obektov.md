# Настройка порядка вывода объектов
На вкладке **Настройка порядка вывода объектов** указывается очередность вывода элементов техпроцесса в документ.
Исходя из примера, показанного на рисунке выше, первым в рабочей области документа в варианте **Операция** будет выводиться **Комментарий** , затем **Оборудование базовое** , **Персонал базовый** и т.д. 
Команда контекстного меню **Добавить** позволяет добавить объект на главный уровень списка объектов.
Команда **Вставить настройку сортировки** позволяет вставить объект внутрь головного объекта списка сортировки.
Команда **Удалить** позволяет удалить выделенный курсором объект из списка.
Команды подменю**Переместить** позволяют изменить порядок следования элементов в списке.
При помощи команды **Сбросить настройки вывода по умолчанию** можно вернуться к первоначальной установке элементов в списке.

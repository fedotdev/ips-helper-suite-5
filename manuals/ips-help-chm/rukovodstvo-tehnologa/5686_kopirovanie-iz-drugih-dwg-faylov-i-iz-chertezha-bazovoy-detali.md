# Копирование из других DWG-файлов и из чертежа базовой детали
Копирование из других DWG-файлов и из чертежа базовой детали производится через буфер эскизов. Для этого необходимо выбрать на текущем чертеже примитивы, затем скопировать их в буфер эскизов с помощью команды меню **ТЕХ.ЭСКИЗ/Редактировать тех эскиз/Копировать в буфер**. После этого, с помощью команды меню **ТЕХ.ЭСКИЗ/Редактировать тех эскиз/Вставить в эскиз** , вставить выбранные примитивы в любой эскиз. При выборе этой команды необходимо выбрать эскиз-назначение в окне выбора операции, аналогичном окну **Операция-назначение**. 
Также при помощи буфера эскизов можно копировать эскизы целиком, для этого используются команды меню **ТЕХ.ЭСКИЗ / Редактировать тех эскиз/Копировать эскиз в буфер** и **ТЕХ.ЭСКИЗ / Редактировать тех эскиз / Вставить в эскиз**. 
Для переключения между эскизами операций и чертежом базовой детали можно пользоваться командами меню **ТЕХ.ЭСКИЗ / Эскиз** и **ТЕХ.ЭСКИЗ / Базовая деталь**. 
Существует также возможность загрузки чертежа другой детали из базы данных IPS, для этого необходимо воспользоваться командой меню **ТЕХ.ЭСКИЗ / Загрузить чертеж из SEARCH**.

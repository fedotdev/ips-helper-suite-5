# Контекстные сборочные единицы
В данном разделе задаются настройки отображения статусов позиций, комплектующих и режимы подсчета / отображения количества, добавляемых по команде контекстного меню **Вставить в собираемый узел**.
В области **Настройки статусов позиций** указываются цвета позиций комплектующих для статусов: **Изделие не выбиралось в ТП,** **Не все количество выбрано** , **Все количество выбрано** , **Версия. Не все количество выбрано** , **Версия. Все количество выбрано** , **Выбрано с превышением количества**. Цветовое отображение статусов позиций будет передаваться в атрибут **Статус позиции**.
Статусы **Версия. Не все количество выбрано** и **Версия. Все количество выбрано** отображаются в том случае, если в ТП добавляются комплектующие, из ДСЕ разных версий. Например, в операции 010 входит собираемая единица с комплектующей единицей на деталь первой версии (Деталь [1]), а в операцию 015 входит собираемая единица с комплектующей единицей на эту же деталь уже второй версии (Деталь [2]).
В области **Общие** указываются настройки:
· **Запрет добавления с превышением количества**. При включенном режиме «**да** », появится возможность добавления в ТП комплектующих в количестве, превышающим общее количество соответствующих деталей в конструкторской сборке.
· **Отображение оставшегося количества для комплектующих**. При включенном режиме «**да** » при вставке комплектующих в собираемую единицу, в окне **Добавление объекта** будет дополнительно отображаться поля со значением **Общее кол-во** и **Оставшееся кол-во** комплектующих. При выборе опции «**нет** » данные поля будут отсутствовать.
· **Режим подсчета “конструкторского” количества.** Позволяет указать настройку подсчета “конструкторского” количества. При выбранной опции **Развернутый состав** будет подсчитано общее количество данной комплектующей в собираемой единице. Например, согласно рисунку, ниже общее количество комплектующих Д5 будет равно 13\. 
При выборе опции **Первый уровень** общее количество комплектующих будет равно количеству выделенных комплектующих, входящих в сборку первого уровня. По примеру с рисунка выше при добавлении комплектующей Д5, находясь внутри сборки СБ5, общее количество будет равно 5, выделив Д5 внутри сборки СБ10 общее количество будет равно 3.

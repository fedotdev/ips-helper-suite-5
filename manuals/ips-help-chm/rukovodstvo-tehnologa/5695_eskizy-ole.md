# Эскизы OLE
Существует возможность вставки в техпроцесс графического фрагмента документа другого приложения с сохранением связей с исходным оригиналом при помощи технологии OLE.
Для этого используется команда **Добавить** /**Эскиз OLE**. В новом окне будет предложено выбрать вариант создания объекта: **Создать новый объект** или **Создать из файла**. При создании нового объекта необходимо выбрать его тип. 
После нажатия кнопки **ОК** , останется окно отображения эскиза.
В случае создание эскиза из файла OLE объект будет отображаться в окне.
В случае создания нового OLE объекта, по команде меню **Файл** /**Открыть внешний редактор** либо аналогичной команде контекстного меню, будет загружена внешняя программа для создания эскиза. 
После создания эскиза и закрытия приложения (без сохранения в нем файла) эскиз OLE появится в окне просмотра. Далее необходимо закрыть окно просмотра командой **Закрыть** либо командой меню **Файл** /**Выход**. 
Появится окно создания объекта Эскиз OLE, к которому будет привязан файл с OLE эскизом, созданном на предыдущем этапе.
В окне необходимо указать **Обозначение** эскиза, **Наименование** и выбрать **Формат листа КЭ**. После нажатия команды **готово** в дереве объектов ТП появится новый объект Эскиз OLE.
Редактирование объекта OLE эскиз осуществляется на вкладке Эскиз OLE по команде **Редактировать.** Будет загружен внешний редактор, в котором следует производить изменение.
На вкладке Эскиз OLE в меню также доступны следующие команды:
· **Обрезать** – эскиз будет приведен к 100% масштабу.
· **Растянуть** – растягивает эскиз на всю ширину/высоту окна просмотра, без соблюдений пропорций ширины/высоты изображения.
· **Масштаб** – увеличивает изображение до максимальной ширины/высоты окна просмотра, с соблюдением пропорций изображения.

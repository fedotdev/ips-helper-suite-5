# Свойства правила автоподбора
В правой части окна настройки автоподбора отображается перечень свойств выбранного элемента правила автоподбора. При этом свойства самого правила можно редактировать, тогда как свойства входящих в него элементов доступны только для отображения.
**Атрибут – ссылка на IMBASE** – заполняется в том случае, если правило автоподбора было создано для элемента справочника.
В атрибут **Идентификатор объекта** записывается идентификатор объекта **Правило автоподбора**.
В атрибут **Наименование** по умолчанию записывается наименование типа объекта, для которого создано данное правило автоподбора, а если правило было создано для элемента справочника – наименование этого элемента.
Свойство **Режим запуска** определяет, когда будет работать данное правило автоподбора:
· **Подбирать по команде** – правило автоподбора будет работать по команде **Автоподбор** контекстного меню, вызываемого по правой кнопке мыши в дереве **Навигатора** для технологических объектов.
· **Подбирать автоматически для объекта** – правило автоподбора будет работать при создании объекта данного типа.
· **Подбирать автоматически для связи** – правило автоподбора будет работать в случае включения уже существующего объекта данного типа в состав других объектов.
Свойства **Режим наследования** определяет, как будет унаследовано правило автоподбора:
· **Собственное** – значение, при котором правило автоподбора отрабатывает для текущей папки и для дочерних, при условии, что у дочерних нет других правил автоподбора.
· **Общее** – значение, при котором правило автоподбора отрабатывает для текущей папки справочника и всегда для дочерних подпапок, независимо от наличия в них собственных правил автоподбора.
**Внимание!** Для правил автоподбора в системе IPS по умолчанию установлено значение **Собственное** , при миграции из TechCard – значение **Общее**.
Свойство **Сортировка** определяет положение правила автоподбора в перечне правил для типа объекта или элемента справочника. Чем меньше значение данного атрибута, тем выше в перечне правил он располагается.
В свойство **Тип объекта** записывается тот тип объекта, для которого данное правило автоподбора было создано.

# Генерация технологических документов (для техпроцесса и для состава изделия)
Генерация документов производится по команде контекстного меню **Отчеты и документы.**
Команда **Ведомости и сложные отчеты** описана в 
Команда **Генерация комплектов документов** позволяет сформировать комплект документов на выделенный объект, как правило техпроцесс. Настройки параметра Комплекты документов описаны в . После выбора команды, в диалоговом окне необходимо указать шаблон комплекта документов.
Пример настройки шаблонов комплектов документов описана в п. .
Генерация комплекта будет выполняться как фоновая задача, и ее выполнение не препятствует работе в системе IPS. После создания первого документа система позволяет просмотреть формирующийся комплект – он открывается в новом окне.
После завершения генерации КД будет показано окно **Сгенерированный документ** с отчетом о выводимой информации. 
Отключить отображение окна трассировки можно в параметрах IPS **Система / Экспертная система / Трассировка,** указав для свойства **Окно трассировки** значение **Нет.**
У объекта, для которого было запущено генерация комплекта документов, появится новый объект КТД (комплект технологических документов). 
Описание команд для работы с КТД будет дано в п. .
Команда **Отчеты и документы** /**Генерация дополнительных** **комплектов** позволяет сформировать дополнительный комплект документов для уже сформированного основного КД. Данный КД в шаблоне комплекта документов помечается как **Дополнительный комплект** (см. рисунок ниже) и при формировании основного комплекта командой **Генерация комплектов документов** не формируется.
Данный комплект документов добавится в основной с соответствующим постфиксом.
По команде **Документ Techcard** производится формирование отдельного документа, созданного по шаблону **Настройки документа Techcard**(см. п. ). Необходимую настройку, по которой будет формироваться документ Techcard, выбирают в диалоговом окне. 
Данный документ не будет привязан к комплекту документов.

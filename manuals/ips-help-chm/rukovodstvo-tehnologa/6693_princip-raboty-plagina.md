# Принцип работы плагина
Плагин позволяет автоматически запускать расчет атрибута **Текст перехода основной** при переходе на вкладку, в которой имеется элемент с данным атрибутом, при этом кнопку **Расчет** нажимать не нужно. Автоматический расчет атрибута **Текст перехода основной** дает возможность, например, видеть весь список переходов в одном окне.
Примечание: данный плагин работает только для атрибута **Текст перехода основной**.

# Технологические эскизы SolidWorks по модели сервисной сборки
Технологические эскизы SolidWorks по модели сервисной сборки предназначены для оформления эскизов моделей сервисных сборок Solidworks и моделей технологических деталей (см. п. ).
Предварительно необходимо провести создание объекта технологические эскизы (в нашем случае объект будет называться **Технологические эскизы Solidworks CCБ**) и произвести его настройку (см. п. ).
Создание объекта **Технологические эскизы Solidworks CCБ** производится по команде **Добавить**.
Перед взятием объекта на редактирование следует открыть в редакторе SolidWorks модель сервисной сборки. 
Далее в редакторе SolidWorks следует оформить эскиз и произвести возврат документа в архив.
После этого в состав эскиза будет включена модель сервисной сборки.

# Свойства элементов правила автоподбора
Каждый тип элемента правила автоподбора имеет свой перечень свойств. Рассмотрим свойства каждого типа отдельно.
· **Создать объект IMBASE**
Свойство **Сортировка** определяет положение элемента автоподбора в перечне элементов для правила или в составе родительского элемента. Чем меньше значение данного атрибута, тем выше в составе правила или в составе элемента он находится.
В свойство **Каталог IMBASE** записывается наименование каталога (справочника), на основании которого будет создан подбираемый объект.
В свойство **Наименование** по умолчанию записывается наименование типа элемента автоподбора. При изменении свойства **Тип объекта** в **Наименование** записывается наименование типа объекта, который должен быть создан в результате автоподбора.
Свойство **Карточка объекта** позволяет задать будет ли открываться карточка объекта после его выбора в окне автоподбора - «**да** » или нет – «**нет** ».
Признак **Обязательный элемент** позволяет указать, является ли данный элемент правила обязательным (необязательным). Если элемент является обязательным, и он не выбирается в процессе подбора, то не выбирается и элемент-владелец. Пример: если не была выбрана втулка, то нет смысла выбирать и сверло, для которого эта втулка обязательна.
Свойство **Папка IMBASE** появляется после заполнения свойства **Тип объекта**. Указать объект IMBASE, на основании которого будет создаваться подбираемый объект, можно по кнопке . Эта кнопка появляется при выделении свойства **Папка IMBASE**.
В свойстве **Тип объекта** указывается, какой тип объекта необходимо создать для данного элемента правила.
Свойство **Тип связи** появляется после заполнения свойства **Тип объекта**. Здесь указывается, каким типом связи необходимо включить подобранный объект в состав исходного. Поле будет заполнено автоматически, если у между объектами только одна связь, если связей несколько, тогда выбор связи необходимо произвести вручную.
В свойство **Тип элемента** записывается наименование текущего типа элемента.
В свойстве **Начальные параметры** раздела **Параметры включаемого объекта** указывается перечень атрибутов, которые необходимо будет присвоить подобранному объекту, их значения и режим заполнения.
В свойстве **Рассчитываемые параметры** раздела **Параметры включаемого объекта** указывается перечень атрибутов, которые необходимо будет рассчитать для подобранного объекта.
В свойстве **Начальные параметры** раздела **Параметры связи** указывается перечень атрибутов, которые необходимо будет присвоить связи исходного и подбираемого объекта, их значения и режим заполнения.
В свойстве **Рассчитываемые параметры** раздела **Параметры связи** указывается перечень атрибутов, которые необходимо будет рассчитать для связи исходного и подбираемого объекта.
· **Создать объект.**
Свойство **ID объекта** появляется после заполнения свойства **Тип объекта**. Указать объект, который в результате автоподбора будет добавлен в состав исходного объекта (либо по прототипу которого будет создаваться подбираемый объект), можно по кнопке . Эта кнопка появляется при выделении свойства **ID объекта**.
В свойстве **Режим добавления объекта** указывается, будет в результате автоподбора создан новый объект по прототипу, или будет подобран объект, уже существующий в базе данных.
· **Папка.**
В свойстве **Тип папки** существует возможность выбора одного из пяти вариантов работы данного элемента правила автоподбора:
Обычная папка ( ) служит для удобства структурирования информации в правиле автоподбора.
Папка выбора ( ) служит для выбора одного элемента из нескольких, вложенных в эту папку. Папка выбора может иметь таблицу (для этого у нее существует свойство **Таблица**), которая будет помогать делать выбор вложенного элемента. Основное назначение таблицы выбора – выбрать один элемент из нескольких. Таким образом, при определении правил подбора можно использовать как условия для любых папок, так и таблицы выбора для папок выбора. При наличии у папки выбора таблицы и элементов правила с условиями приоритет имеет таблица выбора. Если в результате подбора по таблице будет выделен элемент с условием, то это условие будет также проверено.
Папка диалога ( ), как и папка выбора, служит для выбора одного элемента из числа тех, что вложены в нее. Особенностью папки диалога является то, что вложенный элемент будет выбирать пользователь вручную (а не программа автоматически).
Папка множественного выбора ( )служит для выбора нескольких элементов из числа тех, что вложены в нее. Так же, как и при использовании папки диалога, выбор элементов осуществляет пользователь вручную.
Папка слайдового меню ( ) служит для выбора при помощи слайдов, привязанных к элементам, включенным в данную папку.
· **Запрос пользователю.**
В свойство **Текст сообщения** записывается сообщение, которое необходимо будет показать пользователю во время работы автоподбора. В окне редактирования текста сообщения существует возможность его загрузки из текстового файла, а также сохранения набранного сообщения в текстовый файл.
· **Вызов процедуры.**
В свойстве **Внешнее процедура/правило подбора** указывается правило автоподбора для этого же типа объекта, которое необходимо использовать в текущем правиле.
· **Сценарий автоподбора.**
В свойстве **Сценарий автоподбора** указывается сценарий автоподбора, написанный на одном из поддерживаемых системой языков программирования (в настоящее время только C#).
· **Заполнить атрибуты.**
В свойствах **Начальные параметры** и**Рассчитываемые атрибуты** указываются параметры включаемого объекта и параметры связи, которые будут заполнены или рассчитаны при добавлении объекта. Например, при добавлении объекта **Оснастка** (см. рисунки ниже), автоматически будет заполнен атрибут **Количество** равный**7шт**.

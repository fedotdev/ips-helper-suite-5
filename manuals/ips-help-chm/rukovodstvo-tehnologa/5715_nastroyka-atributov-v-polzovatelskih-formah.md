# Настройка атрибутов в пользовательских формах
При создании пользовательских форм, для установки ссылки на атрибут объекта, выбираемого из справочника, используются 2 вида компонента:
· **Ссылка на объект** — устанавливается для атрибутов объектов, выбираемых из списка объектов в Навигаторе.
· **Ссылка на объект IMBASE** — устанавливается для атрибутов объектов, выбираемых из справочников IMBASE.

# Отладка автоподбора
Для того, чтобы убедиться в том, что автоматизированный подбор правильно срабатывает по занесенному алгоритму во всех случаях, требуется его проверить. Это можно сделать по команде **Отладка автоподбора** контекстного меню в окне правила автоподбора.
Окно отладки автоподбора содержит две страницы.
Страница **Начальные данные** предназначена для ввода исходных данных, необходимых для подбора. Результаты подбора отображаются на закладке **Лог автоподбора**. Цель отладки – выработка правильных условий выбора. Отладка может помочь определить, какие условия в дереве подбора работают не так, как было задумано, и почему.

# Настройка параметров IPS Techcard
Настройка параметров Techcard производится по команде меню **Настройка / Параметры IPS** либо аналогичной команде инструментального меню . В дереве окна **Параметры IPS** настройки Техкард находятся по пути**Система / Техкард.**

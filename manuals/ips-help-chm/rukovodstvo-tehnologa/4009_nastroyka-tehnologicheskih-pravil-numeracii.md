# Настройка технологических правил нумерации
Система позволяет гибко настроить нумерацию технологических объектов. Настройка правил нумерации выполняется в два этапа: сначала создаются элементы для правил нумерации, а затем на их основе формируются сами правила. При этом объекты, подвергающиеся нумерации, должны иметь атрибут **Номер объекта**.

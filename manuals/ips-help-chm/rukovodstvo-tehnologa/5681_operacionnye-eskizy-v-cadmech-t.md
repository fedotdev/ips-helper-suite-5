# Операционные эскизы в Cadmech-T
Для создания и редактирования операционных эскизов в Intermech Professional Solution используется AutoCAD в сочетании с системой CADMECH-T. Для работы с редактором эскизов на серверной стороне должен быть загружен серверный модуль **Интегратор с Cadmech 2D** (Intermech.Cadmech.Server), на клиенте – **Эмулятор COM-поддержки для Techcard** (Intermech.TechAcad.Connector).
При построении операционных эскизов система CADMECH-T использует слои, что позволяет хранить все необходимые изображения в одном файле.
Запуск системы CADMECH-T выполняется по команде **TechCard/Редактор эскизов** , находящейся в главном меню. При этом в отдельном окне должен быть открыт объект типа **Техпроцесс**.

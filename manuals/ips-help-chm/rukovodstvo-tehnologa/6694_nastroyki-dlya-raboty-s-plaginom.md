# Настройки для работы с плагином
Для работы с плагином необходимо выполнить следующие этапы:
1\. Необходимо записать в папку Client на машинах файл и добавить его, как клиентский модуль **Consulting.AutomaticFormCalculation.Client.dll.**
2\. Для объекта **Операция** добавить атрибут **Текст перехода основной** и установить значение свойств: 
**Влияет на дату модификации содержимого объекта** – **Нет**.
**Возможна модификация без взятия на изменение** – **Да**.
3\. На форму для операции добавить атрибут **Текст перехода основной**.
4\. Создать правило расчета атрибута **Текст перехода основной**. На примере ниже, для формирования списка переходов использовался расчетный скрипт экспертной системы.

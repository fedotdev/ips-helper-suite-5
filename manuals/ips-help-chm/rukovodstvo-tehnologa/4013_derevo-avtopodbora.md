# Дерево автоподбора
Добавить в левую часть окна типы объектов, для которых необходимо настроить правила автоподбора, возможно при помощи команды **Добавить новый тип объектов** контекстного меню (вызывается по нажатию на правую кнопку мыши). Исключить тип объекта из настройки правил автоподбора можно по команде **Удалить тип объекта** этого же контекстного меню.
По команде **Добавить новый тип объектов** появляется окно, в котором необходимо выделить тип объекта, требующего настройки правил автоподбора.
Команда **Удалить тип объектов** позволяет удалить выделенный курсором объект.
Команда **Обновить** позволяет обновить информацию о объектах и элементах справочников (каталогов).

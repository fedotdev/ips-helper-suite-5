# Элементы правила нумерации
Элементы правила нумерации представляют собой объекты типа **Элемент правила нумерации** (см. тип объектов **Технологические правила нумерации**). 
При создании элемента необходимо указать тип нумеруемого объекта, атрибут, содержащий номер, и типы объектов, относительно которых будет производиться нумерация.
На примере нумерации переходов:
После создания элемента можно назначить ему наименование (напр. **Переход: Номер объекта**) в окне свойств объекта.

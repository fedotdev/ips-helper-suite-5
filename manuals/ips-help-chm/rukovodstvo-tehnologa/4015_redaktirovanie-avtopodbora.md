# Редактирование автоподбора
Редактирование правила автоподбора производится по команде **Редактировать правило подбора** контекстного меню центральной части окна настройки правил автоподбора.
Открывающееся по данной команде контекстного меню окно разделено на три части:
− вверху слева расположена область состава правила подбора; правило подбора определяет, что должно автоматически подбираться для соответствующего типа объекта;
− вверху справа отображаются свойства выделенного элемента правила автоподбора;
− внизу находится область вложенных страниц (**Условия** , **Анкета** и **Условия на столбцы**).

# Удаление эскизов
Пункт меню **ТЕХ.ЭСКИЗ/Редактировать тех. Эскиз/Удалить...** и кнопка **Удалить эскиз** позволяют удалить один или несколько эскизов. Диалог удаления аналогичен диалогу выбора эскиза. При удалении эскиза удаляется только эскиз, соответствующая операция не изменяется.

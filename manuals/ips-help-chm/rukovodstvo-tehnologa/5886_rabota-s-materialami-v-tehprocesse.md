# Работа с материалами в техпроцессе
Добавление материалов в ТП производится с помощью объектов группы **Материал базовый**.
Для сокращения трудоемкости проектирования некоторые материалы, применяемые совместно можно объединить в группирующий объект **Наборы материалов**. Для этого следует создать объект **Набор материалов** , в состав которого добавить материалы, применяемые совместно. В ТП следует добавлять сам объект **Набор материалов**.
Имеется возможность хранения и информации о составах различных растворов или многокомпонентных смесей. Это осуществляется при помощи объектов **Составные материалы**. Создание, настройка и редактирование таблиц составных материалов производится в каталогах IMBase. 
Перечень составных материалов должен храниться в таблице, в свойствах которой у атрибута **Тип создаваемого объекта** указан объект **Материалы составные**.
Добавление компонентов составного материала и указание их необходимого количества для данного составного материала производится в таблице составных объектов. Для ее создания необходимо воспользоваться командой **Создать «Таблица составных объектов»**.
Окно редактирование таблицы составных объектов показано на рисунке ниже.
Окно разбито на 2 части: в верхней части добавляются материал, для которого будет составлена рецептура, в нижней части добавляются компоненты составного материала. 
Для добавления нового составного материала следует воспользоваться командой **Новая рецептура**. Далее в поле **Состав:** при помощи команды **Добавить компонент** следует добавить составные компоненты раствора.
В области **Рецептура:** добавляется материал из таблицы Перечня составных материалов (описание см. выше). В нижней части **Состав:** добавляются материалы из любой таблицы материалов.
Если требуется изменить выбранный компонент раствора, то это можно сделать по кнопке , которая появляется рядом с компонентом, если его выделить и нажать левой кнопкой мыши на наименовании. 
В поле **Часть** указывается количество компонента в растворе.
После внесения изменений следует сохранить все настройки при помощи команды **Сохранить**.
Добавление материалов составных в ТП производится с помощью команды контекстного меню **Добавить / Материалы составные**.
Пример части скрипта генерации документа для вывода материалов с расчетом количества компонентов показан ниже.
Первоночально мы осуществляем поиск всех материалов и выводим их в строку. В переменной запоминаем количество составного материала. Далее для каждого материала осуществляем поиск компонентов материала. В элементе **Запись данных в поле** осуществляем вывод наименования компонента и нормы расхода компонента, котороя равна количеству компонента умноженное на количество составного материала. Функцию ЗНАЧ используем для того, чтобы убрать из атрибута **Количество** единицы измерения выраженные в процентах. Таким образом итоговое значение будет в единицах измерения указанных для атрибута **Количество** для составного материала.

# Правила нумерации
Правила нумерации представляют собой объекты типа **Правила нумерации** (см. тип объектов **Технологические правила нумерации**). Правила нумерации задаются на основе элементов правил нумерации.
При создании правила (объекта с типом **Правило нумерации**) по команде **Навигатора** **Создать** необходимо указать, каким образом производить нумерацию.
**Способ нумерации** указывает, будет нумерация автоматической либо нумерацией вручную. При автоматической нумерации производится немедленное присвоение номера целевому объекту при его создании или перемещении в списке однотипных объектов. При нумерации вручную присвоение номеров производится только после явного указания команды на перенумерацию.
**Тип нумерации** позволяет определить, будет ли производиться нумерация цифрами или буквами.
**Область нумерации** позволяет определить область действия нумерации: внутри родительского объекта, внутри вида производства, сквозную нумерацию внутри базы данных, либо нумерацию внутри техпроцесса.
Признак **Вызов нумерации при удалении** позволяет указать, будет ли данное правило запущено, при удалении в составе техпроцесса объекта, для которого правило создано.
**Список букв** представляет собой список допустимых литер при нумерации буквами.
Поле **Количество знаков в номере** указывает, сколько символов должно быть в номере при цифровой нумерации. 
Первоначальный номер задает начальное значение при цифровой нумерации.
**Шаг номера** задает шаг, с которым следует выполнять цифровую нумерацию каждого последующего элемента.
Система позволяет создавать заменители объектов (например, варианты операций). Для случаев нумерации вариантов применяются настройки **Разделитель** и **Тип нумерации**. Разделитель используется для разделения номера основного объекта и номера заменителя при условии включенного параметра **Использовать номер основного объекта**.
После нажатия в окне создания правила кнопки **Применить** необходимо установить в **Навигаторе** курсор на созданный объект и произвести дополнительную настройку: назначить правилу наименование в окне свойств объекта по команде контекстного меню **Свойства** (напр. **Нумерация переходов**), а также добавить в состав правила объект типа **Элемент правила нумерации** (**Переход: Номер объекта**) по команде контекстного меню **Состав объекта/Добавить в состав**.

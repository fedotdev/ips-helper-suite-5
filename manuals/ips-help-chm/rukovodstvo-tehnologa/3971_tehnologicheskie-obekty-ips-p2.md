# Технологические объекты IPS (часть 2)

 Марки материалов | Тип объекта, описывающий марки материала, которые могут применяться в составе объектов техпроцесса. 
 Материалы | Тип объекта, описывающие материалы, которые могут применяться в составе объектов техпроцесса. 
 Материалы неопределенные | Тип объекта, описывающие материалы неопределенные, которые могут применяться в составе объектов техпроцесса. 
 Материалы составные | Тип объекта, описывающие материалы составные, которые могут применяться в составе объектов техпроцесса. 
 Наборы материалов | Тип объекта, описывающие наборы материалов, применяемых в составе объектов техпроцесса. 
 Свойства материалов | Тип объекта, описывающие свойства материалов, применяемых в составе объектов техпроцесса. 
 Оборудование базовое | Группирующий тип объекта для типов объектов **Группа оборудования** , **Модель оборудования** , **Оборудование**. 
 Группа оборудования | Тип объекта, предназначенный для включения в его состав нескольких моделей или единиц оборудования, используемых на определенном этапе техпроцесса. 
 Модель оборудования | Тип объекта, описывающий модель оборудования, которая может применяться в составе объектов техпроцесса. 
 Оборудование | Тип объекта, описывающий единицу оборудования (с инвентарным номером), которая может применяться в составе объектов техпроцесса. 
 Персонал базовый | Группирующий тип объекта для типов объектов **Группа персонала** , **Персонал**. 
 Группа персонала | Тип объекта, предназначенный для включения в состав нескольких единиц персонала, используемых на определенном этапе техпроцесса. 
 Персонал | Тип объекта, описывающий, кто будет выполнять родительский объект техпроцесса. 
Следующие типы объектов будут по умолчанию создаваться в составе технологических объектов по команде контекстного меню **Навигатора** **Отчеты и документы/Генерация комплекта документов**. В группе **Типы объектов/Комплекты документов** : 
 Комплекты технологических документов | Группирующий тип объекта для типов объектов **Альбомы КТД** , **Комплекты ведомостей** , **Комплекты документов ТП** , **КТД**. 
 Альбомы КТД | Тип объекта, который создается в составе КТД и содержит объекты типа **Технологические ведомости** или **Технологические документы ТП**. 
 Комплекты ведомостей | Тип объекта, который создается в составе изделия и содержит объекты типа **Технологические ведомости**. 
 Комплекты документов ТП | Тип объекта, который создается в составе объектов техпроцесса и содержит объекты типа **Технологические документы ТП**. 
 КТД | Тип объекта, который создается в составе изделия и содержит объекты **Альбомы КТД** , **Технологические ведомости** или **Технологические документы ТП**. Данный тип объекта используется для группировки документов по виду производства и цеху в один комплект из техпроцессов состава изделия. 
В группе **Типы объектов/Документы** это: 
 Технологические документы | Группирующий тип объекта для типов объектов **Модели технологических деталей, Сервисные сборки, Технологические ведомости, Технологические документы ТП, Технологические эскизы NanoCAD, Технологические эскизы SolidWorks**. 
 Модели технологических деталей | Тип объекта, созданный из копии конструкторской модели детали и входящий в состав объекта сервисная сборка. 
 Сервисные сборки | Тип объекта, позволяющий создавать 3d модели технологических сборок SolidWorks на основе конструкторских моделей деталей. 
 Технологические ведомости | Тип объекта, предназначенный для отображения технологической информации состава изделия в виде документа (отчета, подетальной (сводной) ведомости). 
 Технологические документы ТП | Тип объекта, предназначенный для отображения технологической информации по составу техпроцесса в виде документа (маршрутная карта, операционная карта и т.д.). 
 Технологические эскизы | Группирующий тип для объектов типа **Технологические эскизы NanoCAD** , **Технологические эскизы SolidWorks**. 
 Технологические эскизы NanoCAD | Тип объекта, содержащий информацию об эскизах на техпроцессы, операции, переходы, созданных при помощи NanoCAD. 
 Технологические эскизы SolidWorks | Тип объекта, содержащий информацию об эскизах на техпроцессы, операции, переходы, созданных при помощи SolidWorks.

# Окно Состав изделия
Окно Состав изделия имеет следующий вид:
Для детального отслеживания количества комплектующих в данном окне можно использовать атрибуты:
· **Количество по ТП** — показывает количество комплектующих используемых в данном ТП.
· **Количество по конструкторскому составу** — показывает количество комплектующих заложенных в конструкторском составе.
· **Оставшееся количество** — показывает количество неиспользованных в ТП комплектующих.
· **Статус позиции** — представляет собой цветовую схему отображения статуса выбора комплектующих в ТП (**Изделие не выбиралось в ТП,** **Не все количество выбрано** , **Все количество выбрано** , **Версия. Не все количество выбрано** , **Версия. Все количество выбрано** , **Выбрано с превышением количества**). Настройка цветов статусов позиций производиться в **Параметрах IPS** (см. п. ).
При выделении комплектующей единицы на вкладке **Применяемость в ТП** будет отображены операции ТП, в которых данная комплектующая единица используется.
Для каждого технологического объекта на вкладке **Применимость ТП** доступна команда контекстного меню **Перейти к объекту**. 
При ее использовании окно конструкторским составом должно закрыться и в дереве ТП будет выделен, выбранный ранее технологический объект. Если в текущем окне открыт не техпроцесс, а другой технологический объект (цехозаход, операция и т.д.), то позиционирование выполняться не будет.
Для добавления комплектующей единицы в ТП необходимо ее выделить в окне состава и воспользоваться командой контекстного меню **Добавить**. В открывшемся окне, необходимо указать количество добавляемых комплектующих в ТП.
Включить / отключить отображение полей **Оставшееся количество** и **Общее количество** можно в настройках параметров IPS Techcard (см. п. ).
Система также позволяет контролировать количество использованных в техпроцессе изделий из состава головного. Для этого предназначена команда контекстного меню **Навигатора** **Отчет по составу изделия** , которая доступна для объектов **Собираемая единица** и **Комплектующая единица** из состава техпроцесса.
В зависимости от установленного переключателя в окне отчета о составе, пользователь может установить, что именно необходимо отобразить в отчете: **Используемые в составе ТП изделия** , **Неиспользуемые в составе ТП изделия** , либо **Отсутствующие в конструкторском составе**. 
При установке опции **Отображать входимость по составу изделия** в окне отчета по составу появляется дополнительный столбец **Входимость – Сборка** с информацией о входимости каждого изделия состава.
При установке опции **Отображать входимость по составу ТП** появляется дополнительный столбец **Входимость – ТП** с информацией о том, в какой элемент ТП данное изделие входит.

# Принцип работы плагина
Плагин позволяет автоматически сбрасывать подписи, подпись приобретает значение статуса **Подпись не верна** , у объекта родителя при изменении дочернего объекта любого уровня. Сопоставление типов объекта-родителя, у которого будет изменен статус подписи, и изменяемого дочернего объекта осуществляется в настройках системы IPS.

# Настройка форм редактирования для объектов типа Шаблоны комплектов документов
Зачастую при генерации комплекта технологических документов (в основном ведомостей) необходимо указать дополнительные сведения, которые должны быть отображены в формируемых документах. Также с учетом этих дополнительных сведений в скриптах генерации документов могут быть установлены условия попадания информации в формируемые документы. Обычно такими дополнительными сведениями могут являться фамилии проверяющего, разработчика комплекта документов, номер цеха, по которому необходимо вывести технологическую информацию и т.д.
IPS предоставляет возможность настроить для каждого шаблона комплекта документов свой список форм редактирования. Для этого необходимо открыть шаблон в новом окне и перейти на вкладку **Список форм редактирования**. 
Команды контекстного меню данной закладки позволяют добавить новую форму в список, открыть для просмотра выбранную форму в новом окне, исключить из списка.
При помощи кнопок выбранную форму можно соответственно сделать первой в списке, переместить выше, переместить ниже, сделать последней в списке.
Если по команде контекстного меню **Отчеты и документы/Генерация комплекта документов** выбрать шаблон комплекта документов с привязанной формой редактирования, то данная форма будет предоставлена пользователю для редактирования. При этом значения атрибутов, заполненных на данной форме, будут внесены в свойства формируемого комплекта документов.
Для правильного вывода в документе заданных на форме атрибутов и использования их в условиях скриптов генерации документов, необходимо, чтобы эти атрибуты входили в **Конфигураторе базы данных** в группу **Временные атрибуты без объектов**.

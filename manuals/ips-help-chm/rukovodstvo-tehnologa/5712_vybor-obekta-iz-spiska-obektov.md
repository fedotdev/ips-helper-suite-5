# Выбор объекта из списка объектов
Если необходимо производить выбор объекта из списка объектов в **Навигаторе** , 
для соответствующего атрибута (для примера возьмем атрибут **Вид заготовок**) в настройках Конфигурации базы данных необходимо указать в свойстве **Режим выбора из справочника IMBASE** опцию «**нет** ».

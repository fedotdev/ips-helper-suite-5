# Работа с сервисными сборками в техпроцессе
Имеется возможность добавлять в состав техпроцесса 3d модели деталей SolidWorks, делать на их основе эскизы и выводить в документы. Для этого используются объекты **Сервисные сборки SolidWorks** и **Модели технологических деталей SolidWorks** .
Данные объекты находятся в навигаторе по пути **Информационное пространство** / **Объекты** / **Документы** / **Технологические документы**.
Для работы с объектами **Сервисная сборка Solidworks** или **Модель технологических деталей Solidworks** необходимо выполнить настройки (см. п. ).
Принцип работы с сервисными сборками состоит из следующих этапов:
· Создание объектов **Сервисная сборка Solidworks** или **Модель технологических деталей Solidworks**.
· Добавление 3d моделей в сервисную сборку Solidworks.
· Создание и оформление технологических эскизов (см. п. ).
Ниже будут рассмотрены каждый из этапов по-отдельности.

# Выбор из справочника с созданием объекта
Можно организовать автоматическое создание объектов на основе справочников при выборе элемента из справочника Imbase. Для этого необходимо в свойстве **Режим выбора из справочника IMBASE** установить опцию **Создание объекта по справочнику** , в параметре **Справочник IMBASE** указать справочник из которого будет производиться выбор, в параметре **Тип объекта** указать тип объекта, который будет создаваться по данному справочнику.
В этом случае при выборе соответствующего атрибута будет отрываться окно справочника Imbase (указанного в параметре **Справочник IMBASE**) и после выбора соответствующего элемента справочника в **Навигаторе** будет создан объект, тип которого указан в параметре **Тип объекта** , со ссылкой на соответствующий справочник Imbase. 
Если такой объект в **Навигаторе** уже имеется, новый объект создаваться не будет.
Атрибут при этом будет ссылаться на созданный или имеющийся объект в навигаторе, который в свою очередь будет ссылаться на элемент справочника Imbase.

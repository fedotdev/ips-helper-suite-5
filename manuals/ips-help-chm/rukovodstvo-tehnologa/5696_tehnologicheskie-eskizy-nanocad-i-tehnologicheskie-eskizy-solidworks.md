# Технологические эскизы NanoCad и технологические эскизы SolidWorks
Для создания эскизов NanoCad или SolidWorks без использования редактора Cadmech-T необходимо воспользоваться командой контекстного меню **Добавить** / **Технологические эскизы NanoCad** или **Добавить** /**Технологические эскизы SolidWorks.** Будет открыто окно создания нового объекта, в котором необходимо указать **Обозначение** и **Наименование** эскиза.
По нажатию кнопки **Готово** , будет создан объект **Технологический эскиз NanoCad** или **Технологический эскиз SolidWorks** соответственно, с прикрепленным файлом-прототипом. 
Настройка редактора и файла прототипа для технологических эскизов осуществляется в конфигураторе (см. п. )
Далее данный файл можно открыть в редакторе NanoCad или SolidWorks по команде **Редактировать** либо включить автоматическое открытие редактора эскизов в окне **Создание нового объекта,** отметив галочку **Открыть редактор после создания**.
Объекты **Технологический эскиз NanoCad** и **Технологический эскиз SolidWorks** расположены в **Навигаторе** по пути **Информационное пространство** / **Объекты** / **Документы** / **Технологические документы** / **Технологические эскизы.**

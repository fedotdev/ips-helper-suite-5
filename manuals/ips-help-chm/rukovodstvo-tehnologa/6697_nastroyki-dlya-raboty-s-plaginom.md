# Настройки для работы с плагином
Для работы с плагином необходимо выполнить следующие этапы:
1\. Разместить файл **Consulting.SignatureReset.Server.dll** в папке сервера и добавить подключение к файлу **ConsoleServer.exe.cfg.**
2\. Разместить файл **Consulting.SignatureReset.Client.dll** в папке клиента и подключить данный плагин при последующей загрузке.
3\. В **Параметры IPS \** **Система \ Плагины \ Сброс подписи объекта** выполнить настройки объектов, для которых будет осуществляться контроль подписей. В правой части окна настройки дана поясняющая информация о том, как указать объекты для сброса подписей. Ввод конфигурации производится вручную. Поэтому следует внимательно относиться к написанию наименования объекта.

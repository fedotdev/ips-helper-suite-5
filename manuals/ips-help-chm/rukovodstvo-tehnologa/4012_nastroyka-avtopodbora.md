# Настройка автоподбора
В IPS существует механизм, который позволяет осуществлять автоматизированное добавление одних типов объектов в состав других по заранее заданным условиям. Для работы с автоподборами на серверной стороне должен быть загружен серверный модуль AutoSelection (Intermech. AutoSelection.Server), на клиенте – модуль автоподбора (Intermech.AutoSelection.Client).
Для того, чтобы начать настройку автоподбора, необходимо выполнить команду меню **Настройка / Настройка автоподбора**. Если в открывшемся окне панели задач выбрать раздел **Администрирование** и выполнить команду **Настройка автоподбора** – будет открыто окно **Настройка правил автоподбора**. При нажатой кнопке **Свойствa** данное окно разделено на четыре части.
В левом окне указываются типы объектов и отображаются элементы справочников (каталогов), для которых настраиваются правила автоподбора. В центральном окне вверху отображаются сами правила автоподбора для выделенного в левой части окна типа объекта или элемента справочника (каталога), а внизу – условия применения правила. В правой части окна отображаются свойства выделенного в центральном окне элемента правила автоподбора.

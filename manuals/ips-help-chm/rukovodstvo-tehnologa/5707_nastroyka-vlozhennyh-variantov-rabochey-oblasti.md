# Настройка вложенных вариантов рабочей области
Создание документа, имеющего варианты, вложенные друг в друга, возможно двумя способами: в настройках документов Techcard при помощи вложенных элементов или в шаблоне бланка при помощи вложенных областей.
Ниже рассмотрим каждый из вариантов подробнее.
Для создания вложенных вариантов в настройках документов Techcard необходимо в шаблоне бланка создать 2 варианта на одном уровне.
В настройке документов Techcard, путем перетаскивания, вложить один вариант внутрь **Вложенного элемента** второго варианта.
Исключение вложенного варианта из родительского осуществляется по команде контекстного меню **Исключить**.
На рисунке ниже показан пример вывода документа **Карта контроля** в соответствии с настройками документа Techcard, сделанными выше.
Особенностью данного метода является то, что варианты будут идти друг за другом.
В случае, когда необходимо два варианта рабочей области расположить на одной строке документа, необходимо создать вложенную область в родительском варианте рабочей области шаблона бланка. Внутри области создать дочерний вариант.
Свойства внутренней области в настройках документа Techcard не заполняются.
Настройка свойств дочернего варианта в настройке документа Techcard аналогична настройкам отдельно расположенных вариантов.

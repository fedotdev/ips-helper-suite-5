# Настройка элементов бланка контейнер
Для вывода на бланк эскизов используется элемент бланка **Контейнер**.
Для данного элемента в настройке бланка необходимо активировать свойство **Поле эскиза**.
В списке **Тип эскиза** необходимо выбрать тип выводимого эскиза: **DWG-эскиз** или **OLE-эскиз**.
Если эскиз выводится в рабочую область бланка, данный элемент необходимо вставлять в вариант рабочей области, привязанный к типу записи **Эскиз** (см. п. )

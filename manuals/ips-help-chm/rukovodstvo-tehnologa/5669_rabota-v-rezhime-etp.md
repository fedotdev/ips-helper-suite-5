# Работа в режиме ЕТП.
При необходимости ввести индивидуальные параметры (отличные) по каждой детали, необходимо войти в режим единичного ТП по команде контекстного меню **Открыть единичный ТП** находясь на ЕТП закладки **Список ДСЕ** (п. ). В новом окне будет сформирован единичный ТП на основе привязок, выполненных в ГТП/ТПП.
Все элементы, добавленные в ЕТП будут автоматически привязаны только к данному ЕТП, в ГТП/ТТП данные элементы ТП отображаться не будут.

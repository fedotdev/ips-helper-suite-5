# Текстовое поле с DragDrop
Инструмент аналогичен инструменту **Многострочное поле** с дополнительной возможностью использования **События DragDrop**. 
· **Действие**. Позволяет выбрать действие, которое будет выполняться при перетаскивании объектов. Возможные варианты обработчика:
− **Нет**. Ничего происходить не будет.
− **Добавляет заголовок объекта**. При перетаскивании добавляется заголовок объектов. 
− **Выполнить сценарий**. При перетаскивании объекта будет выполняться сценарий, указанный в **Параметрах события**.
· **Параметры события**. Позволяет указать соответствующий сценарий, выполняемый при перетаскивании объектов.

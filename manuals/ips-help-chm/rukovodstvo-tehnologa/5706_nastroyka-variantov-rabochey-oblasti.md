# Настройка вариантов рабочей области
Доступные свойства для вариантов рабочей области позволяют связать варианты с типами записи ТП и настроить их вывод.
В поле **Тип записи ТП** выбирается элемент ТП которому будет привязан данный вариант рабочей области бланка. 
Если несколько вариантов связывается с одним типом записи, очередность вывода информации по вариантам устанавливается в поле **Номер по порядку**.
Если необходимо, чтобы в данном варианте выводилась информация из ГТП/ТТП, устанавливается галочка **Вариант для ГТП/ТТП**. При снятии признака выводится информация из единичного техпроцесса.
На вариант/поле могут быть наложены условия. Если наложенное условие не выполняется, то соответствующий вариант/поле на бланк не выводится.

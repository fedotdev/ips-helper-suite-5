# Свойства документа
Для документа доступны следующие настройки свойств.
В поле **Наименование документа** выводиться наименование шаблона бланка на основе которого производятся данные настройки.
В области **Нумерация документа** поля **Символов в номере** , **Начать нумерацию** с и **Интервал нумерации** позволяют задать способ нумерации листов документа.
В поле **Принадлежность документа** необходимо указать, предназначен документ на операцию или на техпроцесс.
Переключатели панели **Виды документов** определяют для документа его вид:
· **Маршрутная карта** — устанавливается для документов типа **Техпроцесс**. При установке этого переключателя не будут выводиться тексты переходов для операций, на которые существует документ с признаком **Операционная карта**.
· **Операционная карта** — устанавливается для документов, предназначенных на операцию.
· **Пооперационная ведомость** — используется в том случае, если в документе необходимо отобразить только операции с требуемой информацией (например, операции, на которых есть оборудование).
· **Пустая строка перед операцией** — позволяет разделить операции пустыми строками.
Для документов также можно установить **Дополнительные параметры** :
· **Подетальный документ** — устанавливается для документов, в которые информация выводится подетально (в рамках ГТП/ТТП)**.**
· **Документ с эскизом** — показывает, что в документ должен попадать операционный эскиз.
· **Показать вид оснастки** — для оснастки в документе будут также указываться краткие обозначения видов оснастки. Обозначение вида оснастки будут добавляться вначале, перед группой оснастки одного вида.
· **Не повторять оснастку** — включает режим однократного упоминания оснастки в пределах документа.
Панель **Параметры печати** позволяет выбрать вид вывода информации по цехам, переходам и оснастке.
Если следующая операция выполняется в другом цехе, то эта операция записывается с нового листа, если в поле **Цех** установлено **Цех с нового листа**. Операция записывается с нового заглавного листа, если установлено **Цех** с нового заглавного листа.
В полях **Переход** , **Оснастка** и **Всп. материал** устанавливает, каким образом будет выводиться информация при печати документа. На рисунках ниже показан пример вывода перехода в зависимости от включения опций:
· **С чередованием ОТР.** 
· **Без чередования ОТР.**
· **Сплошным текстом.**

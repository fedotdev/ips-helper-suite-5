# Работа со сквозными техпроцессами
Разработчик создает основной техпроцесс в виде последовательности операций (“набрасывает” операции в техпроцесс). Выделив элемент техпроцесса, к которому требуется подвязать вспомогательный ТП, необходимо воспользоваться командой контекстного меню **Добавить объекты сквозного ТП**. 
Откроется окно, в котором необходимо выбрать подвязываемый вспомогательный объект.
При выборе в качестве вспомогательного объекта - **Технологические объекты**(например, **Операция**) он сразу будет добавлен в основной ТП. При выборе в качестве вспомогательного объекта - техпроцесс, будет предложено окно выбора объектов сквозного ТП. 
Отмеченные галочками объекты будут добавлены в объект основного ТП, для которого была вызвана команда **Добавить объекты сквозного ТП**. Добавлять можно как отдельно объекты, входящие в вспомогательный ТП, так и весь ТП целиком. На рисунке ниже слева представлено добавление в основной ТП отдельных операций, справа – добавление всего ТП.
Для возможности включения в объект ТП объектов вспомогательных сквозных ТП необходимо чтобы данные объекты были связаны в конфигураторе связями **Технологический сквозной ТП – Состоит из** / **Технологический сквозной ТП – Входит в.**
Для исключения вспомогательных объектов из основного ТП необходимо воспользоваться командой **Состав объекта** / **Исключить из состава**.

# Наcтройка работы с объектами технологические эскизы Solidworks по модели сервисной сборки
Объект **Технологические эскизы SolidWorks по модели сервисной сборки** должен быть создан в навигаторе по пути **Информационное пространство / Объекты / Документы / Конструкторские документы**. Для данного объекта необходимо произвести настройки аналогичные как для **Технологических эскизов Solidworks** (см. п. ).
Для возможности включения объекта **Сервисная сборка** **SolidWorks** в объект**Технологический эскиз SolidWorks по модели сервисной сборки** следует в **Конфигураторе** установить между объектами связь **Состав документации**.

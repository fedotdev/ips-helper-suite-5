# Настройки для работы с плагином
Для настройки работы с плагином необходимо выполнить следующие этапы:
1\. Необходимо записать в папку Client на машинах следующий файл и добавить его как клиентский модуль:
· **Consulting.ColoredTreeAndGrid.Client.dll**
2\. В параметрах IPS **Пользователи / Интерфейс / Цвета объектов** параметрах указать цвета для выбранных объектов или шагов ЖЦ. 
Окно настройки цветов объектов разбито на две части. В левой части окна производиться указание цветов для выбранных объектов, в правой части для шагов ЖЦ для выбранной схемы ЖЦ.
Указание цветов объекта/шага ЖЦ выполняется при помощи команд:
 – добавление нового объекта/ шага ЖЦ.
 – удаление выделенного объекта/шага ЖЦ.
 – выбор цвета строк выделенного объекта/шага ЖЦ.
 – выбор цвета шрифта выделенного объекта/шага ЖЦ.
 – удаление цвета строк выделенного объекта/шага ЖЦ.
 – удаление цвета шрифта выделенного объекта/шага ЖЦ.
Шкала **Степень подкрашивания взятых на изменение объектов** позволяет указать степень окрашивания строки объекта, взятого на изменение, когда данный объект не выделен. Слева максимальная степень окрашивания, справа – минимальная. Настройка предназначена для всех объектов и шагов ЖЦ. На рисунке ниже слева показан пример установки максимальной степени окрашивания, на рисунке ниже справа – минимальной (в этом случае выделение объекта отображается стандартным синим цветом).
Ниже присутствуют следующие настройки:
· **Назначать цвета по объектам, отобранным по выборкам** — позволяет устанавливать цвета для объектов, отобранных по выборкам. Для корректной работы плагина параметр **Принадлежность** выборки должен установлен на **Не задана** или **Все типы объектов**. При необходимости вести поиск среди объектов локальных типов необходимо включать параметр - **Искать среди объектов глобальных и локальных типов**.
Цвет текста и строки задаются в соответствующих атрибутах свойств выборки.
Пример работы команды показан на рисунке ниже.
· **Разрешать пользователям настраивать свои цвета для типов объектов и шагов жизненного цикла** — позволяет добавить или убрать для пользователя возможность самому настраивать цвета для объектов и шагов ЖЦ (если свойство не активно, для пользователей меню **Цвета объектов** будет отсутствовать).
· **Разрешать окрашивать версии объектов** — устанавливается при необходимости локального изменения цвета определенного объекта. В этом случае становиться доступна команда контекстного меню **Назначить цвет объекту**.
· **Разрешать окрашивать версии объектов на связях** — устанавливается при необходимости локального изменения цвета определенного объекта на связях. 
Для этого становится доступна команда контекстного меню **Назначить цвет объекта в составе** для объектов состава в навигаторе и на соответствующих вкладках **Состоит из** , **Применяемость** и т.п.

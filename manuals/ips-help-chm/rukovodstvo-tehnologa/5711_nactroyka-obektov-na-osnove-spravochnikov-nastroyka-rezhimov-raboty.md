# Наcтройка объектов на основе справочников (настройка режимов работы со справочниками)
Некоторые объекты (например, **Вид заготовки** , **Вид изделия** , **Вид работ** , **Вид производства** и т.п.) могут быть созданы как самостоятельные объекты IPS или как объекты, имеющие ссылку на объект Imbase.
Для возможности создания объектов на основе справочника в свойствах папки справочника Imbase указывается тип объекта, который будет создаваться по данному справочнику.
В этом случае при создании объекта (например, **Вид заготовок**) будет выдаваться окно соответствующего справочника Imbase.
В котором необходимо выбрать, отметив галочкой, вид создаваемого объекта. После нажатия **Применить** будет создан новый объект (из примера выше - **Вид заготовок)** , **Заголовок объекта** в котором будет такой же как заголовок выбранного на предыдущем этапе элемента справочника. В карточке объекта в свойстве **Ссылка на объект** **IMBASE** будет дана ссылка на элемент справочника Imbase, по которому создавался данный объект.
Объекты, которые могут быть созданы как самостоятельные объекты IPS или как объекты, имеющие ссылку на объект Imbase, при указании на них в другом объекте (Например, поле **Вид Заготовки** в окне создания заготовки, см. рисунок ниже) могут иметь несколько вариантов выбора: **Выбор объектов из списка объектов** (п. ), **Выбор объекта из справочника с созданием объекта** (п. ), **Выбор объекта из справочника без создание объекта** (п. ).

# Работа с границами поля рисунка в бланке
Границы полей рисунков необходимы как для многоэскизного режима работы, так и при выводе на печать технологической документации. Кнопки, используемые для работы с границами полей рисунков бланков, находятся на кнопочной панели **Граница поля рисунка**. Команды, аналогичные этим кнопкам, находятся в подменю команды **ТЕХ.ЭСКИЗ/Граница поля рисунка**. 
Существует граница поля рисунка на отдельный эскиз и граница поля рисунка на все эскизы. Граница поля рисунка на все эскизы используется тогда, когда для вывода всех эскизов техпроцесса будет использоваться один и тот же бланк карты эскизов. Это позволит избежать масштабирования эскиза в бланке, если размеры границы поля рисунка будут совпадать с размерами поля вывода эскиза в бланке. Для создания границ используются кнопки **Граница поля рисунка на эскиз** и **Граница поля рисунка на все эскизы**. При нажатии на эти кнопки появляется диалог задания параметров границы.
В поле **Базовая точка** задается левая нижняя точка бланка. Координаты точки можно как задать вручную, так и указать на рисунке, нажав кнопку **Указание >**. 
В поле **Размеры** задается ширина и высота бланка. Размеры, как и базовую точку, можно задать вручную либо указать на рисунке, нажав кнопку **Рамка >**. Можно также задать размеры бланка, выбрав их из списка по кнопке **Выбрать**. Изменить список размеров можно по команде контекстного меню **Изменить список**. 
Границы бланка можно скрывать и показывать с помощью кнопок **Вкл. границу поля рисунка** и **Выкл. границу поля рисунка**.

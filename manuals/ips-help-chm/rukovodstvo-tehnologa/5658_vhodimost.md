# Входимость
Начиная с версии IPS7 появилась возможность указывать входимость маршрута обработки в отдельном объекте **Входимость**. Для добавления входимости в маршрут обработки необходимо воспользоваться командой контекстного меню **Добавить** / **Входимость маршрута обработки**. Окно создания входимости показано ниже.
В поле **Заказ** необходимо выбрать заказ, к которому будет привязан данный маршрут обработки. 
В области **Входимости - Сборка** будут отображены все сборки первого уровня, входящие в заказ и имеющие в составе изделие, на которое добавлен МО.
Имеется несколько вариантов фильтрации:
· **Без фильтрации** — будут показаны все сборки.
· **Только привязанные** — будут показаны только привязанные сборки.
· **Только не привязанные** — будут показаны только не привязанные сборки.
· **Отсутствующая применяемость** — будут показаны сборки, которые есть в атрибутах привязки, но не найдены по связям (например, если входимость осталось привязана к сборке, а саму деталь уже исключили из сборки).
Если открыть изделие в составе сборки или заказа, то в контекстном меню для самой входимости, маршрута обработки и детали, куда он входит, появятся дополнительные команды **Добавить текущую входимость** и**Исключить текущую входимость** , при помощи которых можно добавить или исключить входимость изделия в текущую сборку / заказ. 
При этом, при использовании данных команд, сам объект **Входимость** не создается и не удаляется, а происходит только снятие либо установка галочки напротив текущего объекта входимости.
При необходимости указать несколько входимостей маршрута обработки следует установить для свойства **Контроль уникальности входимости** **в МО** значение «**нет** » (п. ), либо для второй и последующей входимости указать новый маршрут обработки.

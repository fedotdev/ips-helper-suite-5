# Редактор эскизов
Настройка редактора эскизов является клиентской настройкой: на каждой клиентской машине может быть своя настройка. 
· Поле **Редактор эскизов** содержит имя программы, в которой выполняется редактирование эскизов.
· Поле **Параметры** содержит параметры командной строки при запуске редактора эскизов.
· Поле **Прототип эскизов** указывает на файл, использующийся редактором эскизов в качестве прототипа при создании нового файла.
· Поле **Рабочая папка** указывает рабочую папку программы редактирования эскизов, то есть папку, в которой будут храниться файлы, созданные редактором.
· Поле **Расширение файлов** хранит информацию о типе файлов, с которыми работает редактор эскизов.
При помощи команды **Настройки по умолчанию,** можно установить настройки, прописанные в системе IPS по умолчанию.

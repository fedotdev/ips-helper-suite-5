# Добавление 3d моделей в сервисную сборку Solidworks
По команде **Редактировать** следует взять на редактирование модель **Сервисной сборки Solidworks** или **Модель технологических деталей Solidworks** в редакторе Solidworks. Откроется файл-прототип, настроенный для данного объекта (см. п. ).
Дальнейшая работа по редактированию объекта будет вестись в редакторе Solidworks.
По команде **Вставить компоненты** можно добавить модель конструктора в состав сервисной сборки.
Добавить модели из базы данных IPS в состав сервисной сборки можно по команде **Компонент из архива**. 
В диалоговом окне выбрать модель.
Добавить изделия из базы данных IPS в состав сервисной сборки можно по команде **Компонент из БД изделий**. 
В диалоговом окне выбрать изделие.
Для создания нового компонента необходимо использовать команду **Создать компонент**.
Для завершения редактирования сервисной сборки, необходимо включить основную конфигурацию и воспользоваться командой **Вернуть в архив**.
В техпроцессе в составе объекта **Сервисная сборка Solidworks** появится добавленные объекты.
Далее по модели можно оформить Технологические эскиз SolidWorks (см. п. ).

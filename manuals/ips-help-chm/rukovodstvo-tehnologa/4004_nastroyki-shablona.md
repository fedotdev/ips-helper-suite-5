# Настройки шаблона
Редактирование перечня шаблонов, в соответствии с которым будет формироваться строка расцеховочного маршрута, производится в окне, которое вызывается командой меню **Настройка / Параметры IPS / Система / Техкард / Расцеховки / Настройки шаблона**.
Окно настройки шаблона строки расцеховочного маршрута разделено на две части. Слева указываются типы шаблонов, слияние которых при редактировании типа объекта **Расцеховочный маршрут** будет формировать его атрибут **Строка маршрута**. Порядок заполнения атрибута **Строка маршрута** определяется порядком следования типов шаблонов в данном окне (сверху вниз).
По правой кнопке мыши в части окна **Типы шаблонов** доступно контекстное меню.
По команде **Добавить** контекстного меню можно добавить в окно **Типы шаблонов** недостающий шаблон расцеховки (этот тип объекта должен быть дочерним для типа объекта **Шаблон расцеховки базовый**).
По команде **Изменить** контекстного меню можно заменить в окне **Типы шаблонов** выделенный курсором тип шаблона на недостающий.
По команде **Удалить** контекстного меню выделенный курсором тип шаблона будет удален из списка.
При помощи выпадающего меню команды **Переместить** можно настроить порядок отображения типов шаблонов и, соответственно, порядок формирования строки расцеховочного маршрута.
В правой части окна настройки шаблона строки расцеховочного маршрута отображаются атрибуты типа объекта **Расцеховочный элемент**. Для того, чтобы добавить атрибут элемента в шаблон строки расцеховки для выделенного типа шаблона, достаточно выполнить двойное нажатие левой кнопки мыши на выбранном атрибуте – он будет вставлен в поле **Шаблон**. Также для вставки атрибута в шаблон можно воспользоваться командой контекстного меню в окне **Атрибуты элемента** **Добавить в шаблон** _._
Наименования атрибутов расцеховочного элемента в поле **Шаблон** заключаются в фигурные скобки **{}**. Использование квадратных скобок позволяет указать на необязательность размещения информации в строке расцеховки при условии, что упомянутые внутри **[]** скобок атрибуты не назначены. Например, если не указан участок, то символ «/» в строке расцеховки отображаться не будет.
При помощи команд контекстного меню **Копировать** , **Вырезать** , **Вставить** в поле **Шаблон** добавленные атрибуты можно упорядочить внутри шаблона. Кроме атрибутов расцеховочного элемента в поле **Шаблон** могут быть включены и различные спецсимволы. 
Расцеховочные элементы в атрибуте **Строка маршрута** объекта **Расцеховочный маршрут** будут разделяться символами, указанными в поле **Разделитель**.
Настройка шаблонов является серверной настройкой и распространяется на всех клиентов.

# Принцип создания версии КТД при выключенном запрете копирования связей
При копировании КТД в новую версию после проведения изменений в ТП, требуется создать версии документов, в которые вносятся изменения. Для этого следует, выбрав документ, выполнить команду контекстного меню **Создать** / **Версию**.
При создании версии документа из состава КТД, версия КТД создается автоматически. При необходимости, ее можно включить в состав извещения об изменении.
Все документы, на которые создавались версии объектов, а также сам комплект документов будут включены в контекст редактирования при активированной настройке свойств объектов **Комплекты технологических документов** **\- Включать новые версии в текущий контекст редактирования** см. 
Для того, чтобы увидеть внесенные в технологический процесс изменения в КТД, требуется обновить комплект. Для этого в контекстном меню необходимо выбрать команду **Отчеты и документы** / **Обновить комплект**. После чего, содержание всех доступных для изменения документов обновится.

# Системные календари
Для создания, редактирования календарей необходимо создать объект календаря и открыть его карточку **Объекты / Настройки системы / Календари**.
**Внимание!** Изменение стандартной рабочей недели доступно только в системном календаре на карточке объекта календаря при нажатии кнопки .

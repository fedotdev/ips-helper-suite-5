# Создание OLE-объекта
Чтобы создать OLE-объект, выполните следующие действия: 
· Отметьте элемент **Контейнер** на странице и примените команду **Создать OLE-объект** его контекстного меню. 
· В появившемся диалоге выберите приложение, в котором будет создаваться OLE-объект. 
· Создайте изображение в открывшемся приложении и закройте его. 
В результате этих действий созданное изображение загрузится в поле элемента **Контейнер**.
Существует также возможность создать OLE-объект из уже существующего файла. Для этого необходимо отметить пункт диалога **Создать из файла** и указать путь к файлу. При этом файл загрузится в соответствующем приложении. При необходимости отредактируйте его и закройте приложение. В результате этих действий выбранное изображение загрузится в поле элемента **Контейнер**.

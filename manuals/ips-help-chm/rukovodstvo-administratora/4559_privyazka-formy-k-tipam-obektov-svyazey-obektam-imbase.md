# Привязка формы к типам объектов/связей, объектам IMBASE
Настраиваемая форма ввода данных может быть связана с:
− типами объектов;
− типами связей;
− объектами IMBASE.
Привязку к типам объектов можно выполнить в разделе **Конфигуратор/Типы объектов**. В дереве типов следует выбрать требуемый тип объектов, а затем на странице **Формы на тип объекта** с помощью команд контекстного меню назначить одну или несколько форм ввода данных:
Аналогично формы ввода назначаются различным типам связей:
Есть альтернативный способ назначить форму типу объекта, связи, либо связать с объектом IMBASE. Для этого используется диалоговое окно **Редактор привязки формы**. Вызвать данное окно можно в редакторе форм, нажатием кнопки **Связать форму** :
В окне **Редактор привязки формы** можно выполнить все вышеуказанные способы привязки:
· Кнопка **Добавить** – открывает выпадающее меню, в котором можно выбрать тип элемента, с которым требуется связать редактируемую форму
· Кнопка **Удалить** – позволяет удалить связь между формой и указанным элементом.
· Кнопка **Очистить** – удаляет все связи между формой и элементами.
Способ **Условие привязки** – это способ привязки формы по самостоятельно созданному условию зависимости результата от исходных параметров в виде формул. Формулы поддерживают множество функций, среди которых как элементарные математические, так и системные функции, а также специальные функции для прикладных нужд.
При выборе способа Условие привязки пользователю открывается окно **Условие Редактирование формулы [логическое значение]**. Подробное описание создания и редактирования формул представлено в п. .

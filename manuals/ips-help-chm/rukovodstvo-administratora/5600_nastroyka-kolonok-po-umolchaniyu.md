# Настройка колонок по умолчанию
Администратор системы IPS имеет возможность настроить набор колонок с информационными данными об объекте на каждый конфигуратор для отдельного типа объекта (включая дочерние типы). Для этого следует воспользоваться командой **Настройка колонок по умолчанию** из контекстного меню.
Для того чтобы настроить колонки по умолчанию следует:
1\. Выбрать конфигуратор в колонке с конфигурациями ролей.
2\. В колонке с родительскими типами объектов и видимыми типами связи следует выбрать необходимый тип объекта и из контекстного меню вызвать команду **Настройка колонок по умолчанию**.
3\. В открывшемся диалоге следует выбрать и переместить необходимые атрибуты из окна с допустимыми колонками, в окно с отображаемыми колонками, а затем нажать кнопку .
Примечание: для переноса необходимых атрибутов можно воспользоваться кнопками , которые расположены на панели между окнами, или двойным кликом левой кнопки мышки.
В диалоговом окне **Настройка отображения** расположена кнопка , которая позволяет задать отображаемые колонки предлагаемые системой. 
_Примечание: если отображаемые колонки_ _не заданы с помощью данной настройки или настройки сброшены командой контекстного меню**Удалить настройки колонок**_** _по умолчанию_** _, то используются отображаемые колонки, автоматически выбранные системой или модулями расширения для объектов данного типа._

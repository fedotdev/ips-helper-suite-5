# Связи множественно-условных действий
При создании каждой связи, исходящей от действия **Выбор,** пользователю предлагается задать условие, выполнение которого необходимо для перехода по данной связи. С помощью кнопки осуществляется переход в диалог **Задание условий**. С помощью кнопки **Проверить** можно проверить корректность созданного выражения.

Переключатель **Перейти по связи, если ни одно из назначенных условий не выполнено** позволяет назначить связь, по которой будет идти процесс, в случае невыполнения ни одного из назначенных условий.
В редакторе шаблонов процессов связи множественно-условных действий помечаются зеленым цветом. Условия, при которых произойдут переходы, подписываются под связями.

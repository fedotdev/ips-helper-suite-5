# Приоритеты и настройки контроля подписей
Контроль подписей настраивается в следующих разделах (по убыванию приоритета):
· **В схеме жизненного цикла у типа объекта**. Самый высокий приоритет.
· **В схеме жизненного цикла**. Применяется, если нет настроек в схеме ЖЦ у типа объекта;
· **У уровня продвижения**. Применяется, если нет предыдущих настроек. Используется при перемещении объектов на какой-либо шаг ЖЦ.
Настройка контроля подписей в схеме жизненного цикла у типа объектов выполняется следующим образом. В приложении **Конфигуратор базы данных** отыскивается тип объекта, открывается страница **Схема жизненного цикла** , а на схеме выполняются настройки для требуемых шагов ЖЦ:
Например, выбран шаг ЖЦ **Согласование и утверждение**. В свойствах шага есть элемент **Контроль подписей**. Нажав на кнопку [**…**] в этом элементе, можно вызвать окно для настройки контроля подписей.
Если настроек ещё нет, окно **Настройка граф для подписи** будет пустым, иначе в нем можно будет увидеть дерево групп с графами для подписей.
В данном окне с помощью команды **Добавить новую группу** контекстного меню можно выбрать графы для подписей. Например, в контроль подписей добавлена графа **Н. контр.** :
Нажатием кнопки **ОК** можно внести изменения в контроль подписей в схему жизненного цикла выбранного типа объекта.
Для каждой графы доступен переключатель **Строгий контроль подписей**. Если этот переключатель включен для какой-то графы, то контроль подписей будет требовать наличие неустаревших подписей. Иначе допускается наличие устаревшей подписи в данной графе.
Допускается создание нескольких групп граф для подписей. В этом случае контроль подписей будет пройден, если любая из групп граф для подписей окажется корректно подписанной.
Если требуется настроить контроль подписей для схемы жизненного цикла, следует найти ее в списке схем ЖЦ в приложении **Конфигуратор базы данных** , открыть ее страницу **Схема жизненного цикла** и выполнить аналогичные настройки для шагов ЖЦ.

Самый низкий приоритет – у настроек контроля подписей для уровней продвижения. Чтобы выполнить эти настройки, требуется выбрать какой-либо уровень продвижения в приложении **Конфигуратор базы данных**.

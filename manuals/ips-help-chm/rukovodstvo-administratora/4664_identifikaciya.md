# Идентификация
· **Идентификатор**. Уникальный номер страницы, присваиваемый системой автоматически.
· **Имя**. Позволяет присвоить странице имя.
· **Номер страницы**. Отображает номер страницы.
· **Тип элемента**. Отображает тип создаваемого элемента.

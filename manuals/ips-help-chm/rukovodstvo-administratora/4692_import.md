# Импорт
Импорт данных из портфеля в базу данных производится по команде **Экспорт / Импорт / Портфель / Импорт**. 
Сначала указывается место расположения файлов портфеля. 
Затем необходимо указать папку с файлами портфеля и выставить необходимые опции импорта.
Если включена опция **Произвести синхронизацию метаданных** , то в процессе импорта метаданные базы приемника будут приведены в соответствие с метаданными в портфеле. Если метаданные в базе источнике и базе приемнике отличаются, то рекомендуется включить эту опцию.
При отключении режима синхронизации метаданных становится возможным включение опций импорта **Без модификации метаданных** и **Игнорировать ошибки импорта**. Включение опции **Без модификации метаданных** позволяет произвести импорт только объектов и связей портфеля, а опция **Игнорировать ошибки импорта** включает/отключает контроль ошибок импорта объектов и связей при несинхронизированных метаданных.
При включенной опции **Режим Только добавление** будут импортированы только отсутствующие в базе-приемнике метаданные портфеля, существующие метаданные изменены не будут.
Опция импорта **Смена владельца** позволяет не импортировать вместе с объектами отсутствующих в базе приемнике пользователей: создателей и владельцев импортируемых объектов. В этом режиме такие пользователи будут заменены на пользователя базы приемника, указанного в поле **Новый владелец**.
После нажатия кнопки **Далее** при необходимости будет произведена проверка метаданных. При обнаружении проблем будут показаны сообщения об ошибках или предупреждения:
Если все в порядке, то после указания папки для временного хранения файлов портфеля можно будет приступить непосредственно к процедуре импорта.
В процессе импорта файлы портфеля передаются на сервер и там производится импорт данных.

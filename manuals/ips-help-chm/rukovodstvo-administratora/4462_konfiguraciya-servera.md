# Конфигурация сервера
На закладке **Конфигурация сервера** можно просмотреть содержимое конфигурационного файла, на основании данных из которого текущий сервер приложений выполняет подключение к СУБД, менеджеру лицензий, т.п. Описание файла конфигураций см. в .

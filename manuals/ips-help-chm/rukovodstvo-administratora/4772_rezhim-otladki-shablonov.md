# Режим отладки шаблонов
После создания нового шаблона процессов, либо после создания новой версии шаблона, созданному шаблону назначается режим отладки. Чтобы увидеть какие шаблоны находятся в режиме отладки нужно проверять значение атрибута **Шаблон в режиме отладки**.
Если шаблон находится в режиме отладки, его редактирование допускается даже когда по нему уже созданы процессы. При открытии такого шаблона в редакторе будет отображаться надпись: **Шаблон находится в режиме отладки**. Также в меню **Шаблон** будет доступна команда **Закончить отладку шаблона** , которая завершает режим отладки текущего шаблона и переводит его в рабочее состояние.
При вызове команды **Сделать базовой версией** на версии шаблона, значение атрибута **Шаблон в режиме отладки** устанавливается в **Нет**. Если шаблон некорректный, то запрещается перевод версии в базовую и запрещается изменение атрибута **Шаблон в режиме отладки**. При этом выводиться сообщение о том, что некорректный шаблон нельзя сделать базовым и завершить режим отладки.
Если у шаблона завершена отладка, его редактирование возможно только с выпуском новой версии, либо после удаления всех процессов, запущенных по данному шаблону.
При запуске процессов все пользователи (**кроме администраторов**) видят только **базовые** версии шаблонов, у которых атрибут **Шаблон в режиме отладки** = **Нет**. Все остальные версии для них невидимы. Администратору доступны все шаблоны для запуска.

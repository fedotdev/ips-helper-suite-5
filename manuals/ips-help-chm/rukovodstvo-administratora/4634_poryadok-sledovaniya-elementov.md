# Порядок следования элементов
Элементы, размещаемые на странице, могут перекрывать друг друга. Пользователь может изменить последовательность перекрытия элементов, воспользовавшись одним из способов:
· С помощью команд контекстного меню элементов:
− **Переместить выше** — перемещает отмеченный элемент на один уровень вверх.
− **Переместить ниже** — перемещает отмеченный элемент на один уровень вниз.
· В схеме документа, переместив отмеченный элемент с помощью указателя мыши в нужное место.

# Оформление
· **Наименование типа документов**. Позволяет ввести наименование документа, которое будет отображаться в штампах чертежей и в графе **Наименование** конструкторских спецификаций.
· **Код типа документов**. Позволяет ввести код, который будет добавляться к обозначению документа.
**Наименование** и **Код типа документов** , используются при оформлении документации. Например, код может использоваться для автоматической генерации обозначений создаваемых документов, а наименование — для заполнения раздела **Документация** в конструкторских спецификациях.
· **Отрисовывать наименование типа в штампе чертежа**. Данная функция дает возможность отображать **Наименование** типа документа при отрисовке штампа чертежа в CADMECH после наименования чертежа, а в спецификации осуществляет вывод документации в соответствии с ГОСТ 2.106-2019, п. 4.2.17.5.
Например: Насос пневматический. Сборочный чертеж.
· **Код типа документа входит в обозначение**. Данная функция дает возможность автоматически добавлять Код типа документа к обозначению создаваемых документов данного типа.
· **Прототипы**. В этот список можно добавить один или несколько файлов-прототипов, которые будут использоваться системой при создании новых документов данного типа. Кнопка **Сослаться** позволяет выбрать уже созданный в системе объект-прототип, файлы которого могут быть использованы в качестве прототипов при создании новых документов данного типа (см. п. ).
· **Типы объектов, выпускаемых по документам данного типа**. Данная функция дает возможность выбрать типы объектов, которые могут выпускаться по документам данного типа.
· Для добавления **Типа объекта** выпускаемых по документам данного типа следует нажать кнопку **Добавить** и выбрать из списка необходимый тип объекта.
· Для завершение выбора нажмите кнопку **Ок**.

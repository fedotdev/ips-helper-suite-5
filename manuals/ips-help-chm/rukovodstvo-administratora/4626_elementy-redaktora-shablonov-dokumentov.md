# Элементы редактора шаблонов документов
Процесс создания шаблона документов состоит из нанесения на его страницы элементов и изменения их свойств. Элементы редактора — это изображения, с помощью которых формируется содержимое документов: линии, таблицы, текст, графические объекты и т.п. Элементы редактора извлекаются с помощью команд главного меню **Элементы страницы** или из панели инструментов **Элементы страницы** редактора шаблонов документов.
· **Выбор элемента** — указатель, позволяющий отмечать элементы в рабочей области и текстовые фрагменты элементов.
· **Редактор текста** — создает многострочное текстовое поле. При создании документа позволяет вводить текст в поле.
· **Метка** — создает однострочное поле с фиксированным текстом. Текст, вводимый в шаблон с помощью метки, становится фиксированным. При создании документа текст метки изменить нельзя.
· **Таблица** — позволяет создать таблицу.
· **Полилиния** — позволяет создавать полилинии (один и более соединенных между собой отрезков).
· **Контейнер** — позволяет загрузить изображение в поле элемента. Это могут быть рисунки графических файлов или OLE-объекты, хранящие информацию из приложений, поддерживающих интерфейс OLE.

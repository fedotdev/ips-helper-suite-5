# Узел \<PluginManager\>
В данном узле хранится список серверных модулей расширения, которые должны загружаться при старте сервера приложений.
Каждый элемент списка хранится в дочернем узле XML примерно такого содержания: 
<Plugin Location=".\Plugins\Intermech.Signs.Server.dll" />,
где значение атрибута Location – относительный или абсолютный путь к сборке, в которой содержится один или несколько модулей расширения.

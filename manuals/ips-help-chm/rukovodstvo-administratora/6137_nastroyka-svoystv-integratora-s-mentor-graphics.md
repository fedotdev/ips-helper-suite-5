# Настройка свойств интегратора с Mentor Graphics
Выберите конфигурационный объект **Интегратор с Mentor Graphics** и нажмите кнопку **Свойства**.
Рассмотрим подробнее доступные свойства интегратора с Mentor Graphics:
· **Параметр, идентифицирующий главную схему**. Параметр штампа, наличие которого идентифицирует главную схему проекта.
· **Параметр для номера листа**. Параметр штампа, наличие которого идентифицирует штамп, а также указывает номер листа.
· **Атрибуты прочего изделия**. Список атрибутов, синхронизируемых между прочим изделием в базе данных IPS и соответствующим элементом в схеме.
· **Атрибуты документа**. Свойство позволяет задать список синхронизируемых атрибутов для документа.
· **Атрибуты сборочной единицы**. Список атрибутов, синхронизируемых между сборочной единицей в базе данных IPS и штампом соответствующей схемы.
· **Позиционное обозначение прочего изделия**. Наименование параметра элемента схемы, значение которого соответствует позиционному обозначению в применяемости прочего изделия.
· **Компонент подбирается при регулировании**. Параметр компонента схемы и его значение, при котором компонент в IPS идентифицируется, как основной для подбора.
· **Допускается замена компонента**. Парамент компонента схемы и его значение, при котором компонент в IPS идентифицируется, как имеющий допзамены.
· **Предельные значения**. Наименование параметра компонента, в котором приведены предельные значения для выполнения подбора.
· **Не импортируемые папки**. Список папок проекта Mentor Graphics, содержимое которых (файлы, папки) не импортируется в базу данных IPS.
· **Типы перечней элементов**. Список соответствий суффиксов в обозначении схем и типов создаваемых перечней элементов.
· **Настройки фильтрации составов.** Содержит настройки фильтрации списка компонентов схемы для состава изделия и перечня элементов.
· **Имя параметра.** Имя параметра компонента, по значению которого определяется принадлежность компонента к соответствующему варианту состава.
· **Наименование функциональной группы.** Наименование параметра штампа, в котором указано наименование функциональной группы.
· **Обозначение функциональной группы.** Наименование параметра штампа, в котором указано обозначение функциональной группы.
· **Позиционное обозначение функциональной группы.** Наименование параметра штампа, в котором указано позиционное обозначение функциональной группы.
· **Позиционное обозначение ДС.** Наименование параметра, в котором указано позиционное обозначение ДС.
· **Не заносить в IPS.** Позволяет определить, какие board проекта не будут импортированы в IPS.
· **Проводить синхронизацию.** Обязательная синхронизация с базой Imbase при расширенном сохранении.
· **Проверка применяемости.** Проверка применяемости изделия.
· **Атрибут для синхронизации.** Атрибут изделия, по которому будет производиться синхронизация с Imbase.

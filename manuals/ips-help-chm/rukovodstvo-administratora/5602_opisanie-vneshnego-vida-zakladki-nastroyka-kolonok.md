# Описание внешнего вида закладки Настройка колонок
Вид закладки **Настройка колонок** представлена ниже:
Рабочее окно закладки разделено на области со своими элементами управления: 
Справа область **Роли** , в которой создается список ролей, для которых и будут настроены отображаемые колонки. Для создания и коррекции списка ролей на панели расположены следующие кнопки с командами:
 **Добавить роль** – кнопка, которая позволяет выбрать из списка необходимую роль и добавить ее в область **Роли**.
 **Удалить роль** – кнопка, которая позволяет удалить текущую роль из области **Роли**.
 – кнопка, которая позволять настроить отображения колонок для всех неуказанных ролей в области **Роли**. 
Слева область **Колонки** , которая предназначена для настройки колонок под каждую отдельную роль. Для настройки отображаемых колонок на панели инструментов добавлена кнопка , нажатие которой позволяет открыть стандартное диалоговое окно **Настройка отображения**.

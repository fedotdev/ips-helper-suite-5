# Выбор (множественно-условный переход)
Действие **Выбор** подобно действию **Условие** передает управление по определенным связям в зависимости от результата вычисления выражения. Отличие заключается в том, что оно может вычислять несколько разных условий, каждому из которых сопоставляется связь.

# Ссылка на версию объекта
Оператор ссылки на объект вводится в формулу кнопкой и позволяет перейти от текущего объекта контекста к тому объекту, на который указывает атрибут перед этим оператором. Разумеется, атрибут должен иметь тип данных **Ссылка на версию объект а** , чтобы этот оператор сработал, и этот объект должен быть задан.
Это единственный оператор, изменяющий контекст, в котором вычисляется формула. Как правило, он применяется в виде **< Ссылка на версию объект> -> <Атрибут>**, для получения какого-либо атрибута объекта по ссылке.
Например, исходя из примера на рисунке ниже находясь в контексте объекта **Электронные подписи** по ссылочному атрибуту **Подписал** будет осуществлен переход к объекту **Пользователи** у которого будет получено значение атрибута **Фамилия**.
Примечание: если атрибут, стоящий перед символом **- >**, может иметь множество значений, формулу можно будет сохранить, но перехода к объекту не будет, поскольку невозможно перейти сразу к нескольким объектам.

# Поиск по индексу
· **Использовать расширенную проверку прав доступа:** Данный параметр позволяет включить проверку прав доступа для строк и колонок таблиц при поиске по индексу.
**Внимание!** Использовать не рекомендуется, т.к. негативно влияет на скорость поиска по индексу!
Примечание: изменить значение может только пользователь с ролью **Администратор**.

# Модификаторы контекста
Модификаторы контекста управляют контекстом, в котором должны выполняться вложенные операторы. Они делятся на две группы: модификаторы управления (**Для всех** и **Для первого** ) и экстремальные модификаторы (**Для минимума** и **Для максимума** ).
Параметры модификатора управления показаны на рисунке выше слева, экстремальных модификаторов – справа.
Модификаторы управления имеют один основной параметр – условие, которое может и отсутствовать. Модификатор **Для первого** означает, что вложенные операторы должны выполняться только один раз, в контексте первого объекта из набора, для которого выполняется заданное условие. Если условие не задано, они будут выполнены для первого объекта из набора – это имеет смысл только в том случае, если набор отсортирован либо выбор объекта не важен. 
Модификатор **Для всех** означает, что вложенные операторы должны выполняться по одному разу для каждого объекта из набора, для которого выполняется заданное условие. При отсутствии условия они будут выполнены для всех объектов набора.
При обработке модификатора **Для всех** программа автоматически заполняет два временных атрибута. Количество найденных объектов автоматически помещается во временный атрибут **Число объектов в контексте** (краткое имя **ЧИСЛО_ОБЪЕКТОВ**). Временный атрибут **Номер текущего объекта в контексте** (краткое наименование **НОМЕР_ОБЪЕКТА**) хранит порядковый номер объекта, обрабатываемого модификатором **Для всех** , начиная с нуля. То есть, при обработке первого из найденных объектов он будет содержать 0, затем 1, 2 и так далее.
Переключатель **Сохранить найденные объекты в качестве контекста** позволяет заменить текущий контекст не для вложенных операторов, а для всех операторов, которые будут выполняться после текущего. Это может оказаться полезным, например, если скрипт рассчитан на работу с изделиями, но должен правильно работать и при передаче в качестве контекста спецификаций на эти изделия. Достаточно проверить тип переданных объектов и заменить контекст при обнаружении неправильного типа.
Переключатель **Для всех исполнений** организует цикл для всех исполнений данного изделия. Перед этим необходимо сохранить исполнения, выполнив оператор поиска объектов, использующий исполнения. При обработке каждого исполнения система заполняет атрибуты **Номер текущего исполнения** и **Обозначение текущего исполнения**.
Экстремальные модификаторы выполняют вложенные операторы только один раз, в контексте того объекта, для которого заданная формула принимает минимальное или максимальное значение. Сначала нужно выбрать тип результата формулы (**Целое число** , **Число с плавающей точкой** , **Строка** , **Дата** , **Число в единицах измерения)** в верхней панели, а потом – щелкнуть правой кнопкой мыши в поле **Формула** и выполнить команду **Изменить**. 
**Внимание!** В отличие от модификаторов управления, которые могут работать и без введенного условия, экстремальные модификаторы **не могут** работать без формулы.

# Использование сертификатов
Использование усиленных подписей является более предпочтительным при выполнении ЭП, чем простых подписей, так как удостоверяющие центры, выдающие сертификаты, позволяют обеспечить требования к надежности и безопасности, предъявляемые стандартами криптографической защиты.
Список сертификатов, предлагаемых для ЭП, извлекается из личного хранилища сертификатов актуального пользователя операционной системы и фильтруется на наличие закрытых ключей, позволяющих выполнить подписание. Выполненная с использованием сертификата ЭП сохраняется в базе данных IPS в виде криптографического сообщения PKCS#7.
Сертификаты могут быть отозваны, например, в случае компрометации закрытого ключа. Отзыв сертификата выполняется путем помещения скомпрометированного сертификата в список отозванных сертификатов сервера отзыва сертификатов. С этого момента все подписи, выполненные скомпрометированным сертификатом, будут считаться недействительными (в отличие от подписей, выполненных сертификатами, срок действия которых истек). 
Сервер IPS использует при проверке подписей серверы отзыва сертификатов при условии установки настройки **Проверка сертификатов** в значение **Да** (по умолчанию **Нет**) и настройки **Проверка сертификатов онлайн** в значение **Да**. В этом случае для серверной части IPS должен быть доступен сервер отзыва сертификатов. Если сервер отзыва сертификатов недоступен, то проверяемая подпись будет считаться недействительной. Информация по факту недоступности сервера отзыва сертификатов записывается в файл логов сервера IPS.
При установке настройки **Проверка сертификатов** в значение **Да** , а настройки **Проверка сертификатов онлайн** в значение **Нет** проверка валидности сертификатов будет выполняться через локальные списки отзыва сертификатов. Данный способ подходит для случаев, когда сервер отзыва находится вне локальной сети и недоступен напрямую.
Усиленные подписи могут быть обычными и совместимыми. 
Если у пользователя имеется несколько сертификатов в личном хранилище, система предоставляет возможность добавить один или несколько сертификатов в список избранных. 
В случае если пользователь создал список избранных сертификатов, то при подписании усиленной подписью ему будут предложены те сертификаты, которые добавлены в этот список.
Примечание: если в список избранных добавлен только один сертификат, то при подписании диалог выбора сертификата отображаться не будет.
**Внимание!** Так как в списке избранных сертификатов находятся лишь ссылки на сертификаты, то это значит, что они не доступны для подписания. Сами сертификаты должны находится в личном хранилище сертификатов пользователя.
Для указания избранных сертификатов пользователя в меню **Параметры IPS** следует настроить настройку по адресу **Пользователи / Текущий пользователь / Электронные подписи / Избранные сертификаты**. На рисунке показано расположение настройки:
Для того чтобы добавить ссылку на сертификат в список избранных следует нажать кнопку .
Для настройки фильтра, применяемого к информациии, считываемой из сертификатов и отображаемой при проверке усиленных подписей следует настроить глобальный параметр **Параметры IPS \ Система \ Электронные подписи \ Общие настройки** \ **Фильтр отображения информации из сертификата**. 
Фильтр представляет собой регулярное выражение (regexp). Регулярное выражение – это строка специального синтаксиса, позволяющая находить в исходной строке другие строки, соответствующие определенным шаблонам. Таким образом, с помощью regexp фильтра можно выделить из описания сертификата минимально необходимую для отображения информацию, скрывая лишнюю или «чувствительную» информацию.

# Правила подбора версий
При получении составов, в которых есть версионные дочерние объекты, используется механизм подбора версий, основанный на правилах подбора версий.
Правило подбора версий – это объект специального типа (**Правило подбора версий**), хранящийся в базе данных. Тело правила хранится в виде XML в содержимом атрибута **Правила** , который назначен указанным типам объектов.

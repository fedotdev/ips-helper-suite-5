# Свойства
Задать или изменить свойства группы атрибутов можно на закладке **Свойства** рабочей области конфигуратора, выделив группу в дереве метаданных:
· **Глобальный идентификатор**. Глобальный идентификатор группы атрибутов.
· **Идентификатор**. Локальный идентификатор группы атрибутов. Назначается системой автоматически и не подлежит дальнейшей модификации.
· **Наименование**. Уникальное наименование группы атрибутов (может содержать до 255 символов).
· **Комментарий**. Комментарий для группы атрибута, поясняющий назначение ее атрибутов (может содержать до 450 символов).
· **Предметная область**. Позволяет отметить в выпадающем списке предметные области, к которым относится данная группа атрибутов. Если указано значение **Все** , то данная группа атрибутов будет видна всем пользователям, независимо от предметных областей, с которыми они работают.
· **Языковой вариант**. Языковой вариант, к которому относятся атрибуты данной группы. Позволяет выбрать языковой вариант, существующий в системе, или указать язык по умолчанию, т.е. тот, который назначен по умолчанию в свойствах языкового варианта.

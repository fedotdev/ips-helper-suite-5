# Закладка Возврат
Закладка **Возврат** отображается в свойствах действий типа **Задача** , **Утверждение** и **Регистрация**. На этой закладке можно настроить, на какой из этапов должен будет вернуться процесс, если пользователь вернет сообщение назад (для действий типа **Задача** и **Утверждение**), или если при занесении объектов в архив произойдут ошибки (для действий типа **Регистрация**). 
С помощью переключателей можно установить один из следующих видов возврата:
· **В начало маршрута** — в случае возврата процесс вернется на действие **Старт** , т.е. вернется инициатору процесса.
· **На предыдущее действие** — возврат произойдет к предыдущему пользовательскому действию, т.е. вернется пользователю, который инициировал запуск данного действия.
· **По стрелке** — возврат будет производиться к действию, указанному обратной связью.
· **Возврат запрещен** — запрещает возврат для действий типа **Задача** и **Утверждение** (для действий типа **Регистрация** эта опция недоступна).

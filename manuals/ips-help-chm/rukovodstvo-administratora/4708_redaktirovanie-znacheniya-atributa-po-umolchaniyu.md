# Редактирование значения атрибута по умолчанию.
Для атрибутов структуры архива могут быть назначены значения по умолчанию, отличающиеся от значений по умолчанию для атрибутов в конфигураторе. В таком случае, при добавлении документа в архив и при отсутствии у него конкретного атрибута из структуры архива (либо если атрибут есть, но он пустой) – в атрибут пропишется значение по умолчанию, указанное в структуре архива. Если у документа уже есть такой атрибут с прописанным в него значением – то значение такого атрибута останется неизменным и не будет переписано.
Значение по умолчанию можно сбросить на значение, указанное в конфигураторе базы данных, вызвав для атрибута контекстное меню и выбрав пункт **Сбросить значение по умолчанию**. Значение выбранного атрибута у находящихся на этот момент в архиве документов не изменится. 
Атрибут типа строка позволяет менять значение непосредственно в ячейке. Для этого необходимо выполнить в ячейке **Значение по умолчанию** двойной клик мышкой.
Для других типов атрибутов по нажатию на кнопку, находящуюся в ячейке справа, открывается соответствующий типу атрибута редактор.
После указания нового значения атрибута появится сообщение с запросом на подтверждение изменения структуры архива. 
По нажатию на кнопку значение по умолчанию для атрибута изменится, но значение атрибута документов, находящихся в этот момент в архиве, изменено не будет. Новое значение будет использоваться только для новых, добавляемых в архив документов.
Возможность установки значения по умолчанию не предусмотрена для многозначных атрибутов, атрибутов типов внешняя ссылка, двоичные данные, короткие двоичные данные, пароль, файл. Также нельзя устанавливать значения по умолчанию для атрибутов, которые запрещено редактировать вручную.

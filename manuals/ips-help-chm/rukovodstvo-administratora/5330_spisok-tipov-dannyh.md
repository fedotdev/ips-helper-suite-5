# Список типов данных
Главной характеристикой атрибута в системе является его тип данных, который задается при создании типа атрибута. Список поддерживаемых типов представлен ниже:
 **Автоинкрементное целое число**. Целое число, значение которого по умолчанию инициализируется системой с помощью числовой последовательности начиная с 1 и с шагом 1 (т.е. при создании следующего объекта с данным атрибутом система увеличивает его начальное значение на единицу вне зависимости от типа создаваемого объекта или связи). В дальнейшем значение атрибута может быть изменено пользователем.
**Вещественное число**. Вещественное число от 5.0Е10-324 до 1.7Е10+308 и точностью до 15 знаков.
 **Вещественное число, выраженное в единицах измерения**. Значение данного атрибута должно обязательно содержать единицу измерения. В настройках атрибута можно указать физическую величину – в этом случае данный атрибут сможет принимать единицы измерения только данной физической величины. Список единиц измерения редактируется в окне **Администратор базы данных** (см. п. ).
 **Глобальный идентификатор**. Тип данных используется различными модулями системы для хранения глобальных идентификаторов.
 **Дата**. Дата в формате, установленном в региональных настройках Windows. Атрибут также может содержать время.
 **Двоичные данные**. Двоичные данные произвольной длины. Значения таких атрибутов хранятся в файловых шкафах системы (см. п. ) в упакованном виде. Такие атрибуты не видны в свойствах объектов. Обычно они используются различными модулями системы для хранения внутренней информации.
 **Короткие двоичные данные**. Двоичные данные ограниченной длины. Максимально допустимый размер устанавливается администратором (но не более 131072 байт). Значения атрибута хранятся непосредственно в системных таблицах, поэтому операции записи и чтения значений такого атрибута выполняются быстрее, чем аналогичные операции с двоичными данными произвольной длины.
 **Логический**. Тип данных позволяет хранить одно их двух значений – да/нет.
**Пароль**. Тип данных предназначен для хранения хэшей строк. Максимальная длина строки задается администратором (но не более 40 символов). Прочитать значение такого атрибута нельзя – система может только сравнивать хэши строк со значением хэша в атрибуте. Текущий алгоритм хэширования всех атрибутов такого типа задается в диалоге **Настройка / Параметры IPS / Пользователи / Безопасность учетных записей** (см. п. ). 
**Системный атрибут**. Этот тип данных означает, что атрибут является обязательным для какой-либо категории данных (например, **Идентификатор объекта** для информационных объектов). Список системных атрибутов фиксирован, т.е. в конфигураторе базы данных нельзя добавлять и удалять такие атрибуты, а также изменять их свойства и ограничивать видимость их значений. 
 **Ссылка на версию объекта**. Тип данных предназначен для хранения ссылки на версию объекта. Допустимый тип объектов, на которые может ссылаться данный атрибут, указывается в поле **Тип объекта** (при этом допускается ссылка и на объекты любого дочернего типа). В настройках атрибута применительно к типам объектов/связей можно указать поведение атрибута при удалении объекта, на который ссылается данный атрибут (свойство **Правило**).
 **Ссылка на объект без конкретизации версии.** Тип данных предназначен для хранения ссылки на объект, в строковой части атрибута хранится заголовок базовой версии объекта, на который он ссылается.
 **Строка**. Символьная строка длиной до 850 символов. Максимально допустимая длина значения может быть изменена администратором с помощью свойства **Размер**.
 **Текст**. Текст длиной до 131072 символов (максимальная длина текста также регулируется с помощью свойства **Размер**). 
 **Файл**. Тип данных позволяет хранить в системе файлы. Вместе с телом файла сохраняется информация об имени файла, его размере, способе упаковки и дате модификации. Также к файлу могут прилагаться текстовые примечания длиной до 450 символов. Максимально допустимый размер файла зависит от типа файлового шкафа, в который он помещается. Список файловых атрибутов у информационного объекта доступен на закладке **Файл** (см. в ). С файлами также работают стандартные команды **Навигатора** (**Редактировать** , **Смотреть** , **Открыть** , **Открыть с помощью…**).
**Целое число**. Целое число от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807.
При изменении типа данных атрибута следует помнить, что не все типы данных могут быть преобразованы друг в друга. Также следует помнить, что та информация, которая не может быть конвертирована, будет утеряна. Например, если вы уменьшите у атрибута максимальную длину, то при конвертации данные в этом атрибуте будут усечены до новой длины.

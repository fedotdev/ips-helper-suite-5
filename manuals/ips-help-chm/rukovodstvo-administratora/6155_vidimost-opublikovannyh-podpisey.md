# Видимость опубликованных подписей
Список узлов, для которых разрешено видеть все опубликованные подписи, вне зависимости от списка разрешенных узлов, указанных у этих подписей.
· Наименование: **ObligatorySignEnableSites**
· Значение: строка с кодами узлов.
Например, **_< add key="ObligatorySignEnableSites" value="ABCD"/>___**

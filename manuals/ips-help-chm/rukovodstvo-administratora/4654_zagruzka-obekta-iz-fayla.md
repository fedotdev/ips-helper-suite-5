# Загрузка объекта из файла
Чтобы загрузить изображение в контейнер, выполните следующие действия:
· Отметьте элемент **Контейнер** на странице и примените команду **Загрузить объект из файла** его контекстного меню.
· В появившемся диалоге укажите путь к графическому файлу. 
В результате этих действий содержимое выбранного файла отобразится в поле контейнера.

# Удаление атрибута
Если требуется удалить атрибут из структуры архива, выделите его в списке атрибутов архива и воспользуйтесь командой контекстного меню.
Программа выдаст запрос на удаление атрибута из всех документов, хранящихся в архиве:
Нажатием кнопки подтвердите намерение удалить атрибут из документов и структуры архива. Кнопка отменяет удаление атрибута у документов, находящихся в архиве, но сам атрибут будет все равно удален из структуры архива и вложенных в него архивов.
Примечание: в случае ошибки атрибут не будет удален из структуры архива и его документов.

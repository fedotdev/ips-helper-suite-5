# Внутренняя канцелярия подразделений
Каждое подразделение предприятия может иметь собственную канцелярию. Это означает, что зарегистрированные в системе канцелярские документы, могут быть зарегистрированы в собственных канцеляриях подразделений. При этом, помимо основного регистрационного номера документу присваиваются внутренние регистрационные номера.
Для включения/выключения такого режима работы канцелярии необходимо установить флаг **Внутренняя канцелярия у подразделений** в окне **Настройка / Параметры IPS / Канцелярия / Общие**.

# Типы переменных
Переменные маршрутизатора IPS могут быть одного из следующих типов:
**Строка** — позволяют хранить строку.
**Целое число** — позволяют хранить целое число.
**Вещественное число** — позволяют хранить вещественное число.
**Дата** — хранят дату; могут использоваться для указания сроков исполнения действий и в таймерах для указания даты и времени срабатывания.
**Список строк** — с переменными этого типа связывается список возможных строковых значений, из которых должно быть выбрано значение переменной.
**Список пользователей** — хранят список пользователей или групп пользователей. Переменные данного типа могут быть использованы в качестве исполнителей действий. Их значения могут заполняться пользователями при помощи форм на каких-то этапах процесса (например, на старте).
**Логический** — хранят логическую величину, значение которой равно Истина или Ложь. Обычно используются в условных переходах.
**Архив** — хранят ссылку на архив. Переменные данного типа предназначены для использования в действиях **Регистрация**.
 **Текст** — позволяет хранить произвольный текст.

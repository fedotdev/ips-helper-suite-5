# Настройка команд по умолчанию
Команда **Настройка команд по умолчанию** позволяет выбрать команду контекстного меню, которая будет срабатывать по двойному клику мышки на выделенном объекте указанного типа (включая дочерние типы). 
Выбранная команда будет актуальна только для данного конфигуратора.
Для настройки команд по умолчанию следует:
1\. Выбрать конфигуратор в колонке с конфигурациями ролей.
2\. В колонке с родительскими типами объектов и видимыми типами связи следует выбрать необходимый тип объекта и из контекстного меню вызвать команду **Настройка команд по умолчанию**. 
3\. В открывшемся диалоге следует выбрать необходимую команду, а затем нажать кнопку .
Примечание: если команда не задана с помощью данной настройки или настройки сброшены командой контекстного меню **Удалить настройки команд по умолчанию** , то используется команда, автоматически выбранная системой или модулями расширения для объектов данного типа.

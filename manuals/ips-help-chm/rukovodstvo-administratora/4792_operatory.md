# Операторы
Арифметические операции:
· **Сложение** ;
· **Вычитание** ;
· **Умножение** ;
· **Деление** ;
· **Возведение в степень**.
Логические операции:
· **Логическое И** ;
· **Логическое ИЛИ** ;
· **Отрицание (одноместная операция)**.
Операции отношения:
· **Равно** ;
· **Не равно** ;
· **Меньше** ;
· **Больше** ;
· **Меньше или равно** ;
· **Больше или равно** ;
· **Меньше или равно** ;
· **Больше или равно** ;
· **Больше или равно**.
Вспомогательные операции:
· **Начало набора**(см. п. );
· **Конец набора**(см. п. );
· **Разделитель для диапазона**(см. п. );
· **Разделитель для перечисления**(см. п. );
· **Проверка**(см. п. );
· **Открывающая скобка,Закрывающая скобка** – применяются в редакторе формул для изменения порядка вычислений. Порядок, в котором элементы формулы берутся на вычисление, зависит от приоритета операции. Операция с большим уровнем приоритета будет приниматься во внимание раньше, чем с меньшим уровнем приоритета.
В порядке убывания приоритета операции можно расположить следующим образом:
| 1 | ^ |
| --- | --- |
| 2 | / * |
| 3 | \+ - |
| 4 | : |
| 5 | , |
| 6 | операции отношения: =, <>, >, >=, и т.п. |
| 7 | НЕ |
| 8 | ИЛИ И |
| 9 | ) ( |
Пример 1: S= X**^** 2+Y*Z., где X, Y, Z , S – числового типа
X=2, Y=3, Z=4; тогда S= 2**^** 2**+** 3*4 =16.
· **Перевод строки** – позволяет перенести вывод значений атрибутов, находящихся в формуле после данной операции на новую строку. В формуле операция будет отображаться как <**CR** >. На рисунке ниже показан пример вывода значения атрибута **Номер КЭ/ВТД/ВО**.

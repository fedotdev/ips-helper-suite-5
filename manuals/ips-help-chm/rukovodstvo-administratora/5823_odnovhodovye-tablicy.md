# Одновходовые таблицы
Особенностью таких таблиц является то, что в них присутствуют только вертикальные столбцы условий на аргументы (серого цвета).
Справа от столбцов условий располагаются столбцы решений (белого цвета). В таблице с одним входом всегда должен быть хотя бы один столбец условия и один столбец решения. 
При расчете результатов по такой таблице экспертная система определяет правильную строку, и эта строка определяет возвращаемые результаты для каждого атрибута: они находятся на пересечении правильной строки и столбца атрибута. Если не удается найти строку, удовлетворяющую всем условиям, таблица не выдаст никаких результатов. Большинство таблиц принадлежат к этому виду.
Например, в таблице, изображенной на рисунке выше, есть два столбца условия (**Оборудование.Код** и **Оборудование.1-я характеристика станка**) и один столбец решения (атрибут **Нормирование на операцию. Процент времени на обслуживание рабочего места**). Если атрибут **Оборудование.Код** будет иметь значение 845737, **Оборудование.1-я характеристика станка** = 400, то, атрибуту-решению **Процент времени на обслуживание рабочего места** будет присвоено значение 4.
Примечание: в некоторых ситуациях все условия могут выполняться сразу для нескольких строк таблицы. В этом случае экспертная система находит первую подходящую строку и отбрасывает остальные.

# Удалённый подпроцесс
Действие **Удаленный подпроцесс** позволяет запустить процесс на удаленном узле, используя службы портала IPS (см. п. ). В запускаемый процесс на удаленном узле будут переданы вложения текущего процесса (если настроено – с правами владения), значения переменных и текст сообщений шагов, предшествующих текущему шагу.

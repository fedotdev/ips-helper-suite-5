# Создание карточки объекта
Чтобы создать новую форму редактирования данных, выделите пункт **Формы редактирования данных/Формы редактирования атрибутов объектов и связей** в дереве навигации **Администратора базы данных**. Из контекстного меню выполните команду **Создать**. 
В появившемся окне укажите уникальное наименование и нажмите кнопку **Готово**.

# Настройка отображения в дереве состава
Функционал системы IPS позволяет администратору системы настроить отображение колонок в дереве состава для конкретной роли. 
В модуле **Отображение и сортировка составов** для каждой конфигурации ролей можно настроить отображение колонок под каждый конкретный тип объекта. 
На рисунке ниже представлены команды:
**Настройка отображения в дереве состава** – команда, которая позволяет задать отображение колонок в дереве состава для выбранного типа объекта.
**Удалить отображения в дереве состава** – команда, которая позволяет удалить созданные администратором настройки отображения в дереве состава.
**Внимание!** Пользовательские персональные настройки отображения имеют приоритет над настройками отображения в дереве состава, поэтому для отображения настроек в каждой отдельной роли, созданные администратором системы с помощью команды **Настройка отображения в дереве состава** , следует задать значение **«ДА»** у атрибута **Блокирование настройки отображения составов** для каждой настраиваемой роли, подробное описание данного атрибута представлено в п. .

# Регистрация документа из файла в архиве
При необходимости можно выполнить импорт файла с документом с диска компьютера, автоматически зарегистрировав его в текущем архиве. Для этого воспользуйтесь командой **Зарегистрировать в архиве** контекстного меню текущего архива в дереве.
Программа отобразит окно, в котором требуется выбрать файл с документом. Если для расширения имени выбранного файла есть настройки для импорта документов (см. п. ), то в IPS будет создан соответствующий информационный объект с документом из указанного файла, который затем будет размещен в текущем архиве.

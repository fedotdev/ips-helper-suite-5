# Создание
Создать новую группу атрибутов можно, применив команду **Создать группу** контекстного меню элемента **Атрибуты**. При этом в дереве появится новая группа атрибутов с наименованием **Новая группа атрибутов**. Отредактируйте свойства созданной группы и нажмите кнопку **Применить**.

# Утилиты администратора
При загрузке под административной ролью модуля **Конфигуратор базы данных** , а также некоторых других модулей расширения, в меню **Настройка** появляется группа команд **Утилиты администратора** , в которой находятся следующие административные команды:
· **Актуализировать версии подписей**. Команда корректирует невалидные подписи (кроме усиленных ЭП), которые стали невалидными вследствие изменения администратором настроек в метаданных у типов подписанных объектов.
· **Исправить значение граф для подписей**.
· **Настройки синхронизации со службами каталогов.**
· **Перегенерировать представления данных**. Производит обновление оптимизационных таблиц в базе данных. Выполняется как фоновая задача. Команда используется для исправления ошибок, связанных с работой оптимизатора запросов IPS. Данную команду следует выполнять только по согласованию со службой технической поддержки «ИНТЕРМЕХ», т.к. самостоятельно определить необходимость ее выполнения очень сложно.
· **Обновить представления для указанных объектов**. Данная команда обновляет информацию в оптимизационных таблицах для группы выделенных в **Навигаторе** объектов. Если объекты выделены в составе или применяемости других объектов, то команда также обновляет и оптимизационные таблицы соответствующих связей между объектами.
· **Перечитать кэш сервера**. Перечитывает серверный кэш метаданных. Рекомендуется выполнять при работе нескольких серверов приложений с одной базой данных в случае, если данный сервер приложений не «увидел» изменений метаданных, которые были сделаны другим сервером приложений.
· **Проверить целостность данных**. Производит проверку базы данных на наличие различных ошибок и нарушений целостности данных, которые могут быть исправлены системой автоматически.
· **Удаление устаревших данных**. Производит процедуру очистки базы данных от устаревшей информации (удаленных объектов, записей журнала доступа и пр.). Выполняется как фоновая задача. Процедура может также выполняться автоматически по заданному расписанию (см. п. ).
· **Перестроить нормализованные индексы**. Пересчитывает значения атрибутов типа **Нормализованный индекс**. Данная команда может понадобиться в случае, если при изменении настроек нормализованных индексов (см. п. ) автоматический пересчет значений по каким-либо причинам не произойдёт.
· **Поиск недопустимых атрибутов**. Осуществляет поиск объектов, у которых имеются недопустимые для данного типа объектов атрибуты. Выводит список типов объектов и принадлежащих им атрибутов, которые не назначены данному типу объектов, но в базе данных имеются версии объектов с этими атрибутами. В список попадают только те типы объектов, которые не допускают наличия любых атрибутов. В списке приводится количество версий объектов с данным атрибутом, а также процент версий объектов с данным атрибутом к общему количеству версий объектов данного типа. Команда может использоваться, например, для перенастройки типов объектов после процедуры импорта данных из систем Search, IMBASE и Techcard. Администратор может проверить базу на наличие недопустимых атрибутов и либо назначить типам объектов недостающие атрибуты, либо включить у типов переключатели, допускающие наличие любых атрибутов у данных типов объектов. Используя полученную информацию, администратор с помощью выборок может найти в базе данных объекты с недопустимыми атрибутами и удалить у них лишние атрибуты.
· **Очистить атрибут «Узел информационной сети»**. Команда очищает информацию об узлах (создателе, владельце) у выбранных объектов базы данных.
· **Проверить очередь индексации объектов**. Команда проверяет есть ли в данный момент объекты, поставленные в очередь на индексацию, и выводит окно с их списком. Индексация производится задачей **Фоновая индексация изменившихся атрибутов** , которую администратор системы должен назначить в Планировщике задач IPS (см. п. ).
· **Добавить объекты в очередь на индексацию**. Данная команда помещает выделенные в **Навигаторе** объекты в очередь на индексацию. Для этого у выделенных объектов должен быть хотя бы один индексируемый атрибут.
· **Вывести список открытых сессий**. Выводит список пользовательских сессий, которые в данный момент подключены к серверу приложений, с которым работает данный клиент. Кроме имени пользователя для каждой сессии выводится имя компьютера, с которого пользователь подключился к серверу приложений, время последнего обращения к серверу, количество клонов сессии, а также счетчик активности сессии.
· **Проверить номера групп изменений**. Данная команда проверяет у выбранных в **Навигаторе** версий объектов значение атрибута **Номер группы изменений** и обнуляет его в случае, если данная версия объекта не входит ни в один из контекстов редактирования.
· **Проверить наличие петель в составе.**
· **Исправить шаги ЖЦ**. Команда предназначена для поиска и исправления объектов, находящихся на шагах ЖЦ, которые не принадлежат схеме ЖЦ, указанной в Конфигураторе БД для данного типа объектов. Такая ситуация может возникнуть в случае, если администратор изменил схему ЖЦ для типа объектов, отказавшись переносить уже существующие объекты на шаги новой схемы. При выборе типа объектов, среди которых нужно искать объекты с неверными шагами ЖЦ, достаточно указать родительские типы объектов – система произведёт поиск и среди всех дочерних типов объектов. Поиск соответствия шагов в старой и новой схеме ЖЦ производится по наименованию и уровню продвижения шагов. Однако есть одно исключение: если в исходной схеме шаг был первым, то объект в любом случае перемещается на первый шаг в новой схеме ЖЦ.
· **Диагностика ошибок патча БД**. Команда служит для просмотра и анализа результатов патча БД скриптами автообновления при старте сервера приложений. По команде отображается окно диагностики ошибок. В данном окне на закладке Ошибки автообновления отображены ошибки последнего патча. Ошибки можно отфильтровать по полному или частичному совпадению текста в результате чего они также не будут записываться в лог-файл при выполнении патча базы. Список фильтров отображается и редактируется на закладке Фильтрация ошибок. В окне доступны следующие команды:
 Обновление списка ошибок в окне. Происходит чтение лог файла с применением фильтров. 
 Применение фильтров к списку ошибок. 
 Сохранение итогового списка ошибок в текстовый файл.
 Копировать текущую строку в буфер обмена.
 Добавить новый фильтр. При выполнении команды на закладке со списком ошибок, в фильтр автоматически добавляется текст выделенной строки ошибки.
 Редактировать текст фильтра.
 Удалить фильтр.
 Очистить весь список фильтров.
· **Обработка импортированных извещений**. Данную команду рекомендуются выполнить непосредственно после процедуры переноса данных из системы Search утилитой миграции данных для восстановления значений некоторых атрибутов у импортированных извещений об изменениях.
· **Удаление объекта (заготовки)/связи**. Данная команда помогает удалить из базы версию объекта или связь в том случае, если это не получается сделать обычными командами **Навигатора**. В представленном ниже диалоге нужно ввести идентификатор версии объекта или идентификатор связи и нажать кнопку **Удалить**. Кнопка **Информация** позволяет проверить наличие данной версии объекта или связи в базе данных и вывести в информационное окно краткую информацию о ней.
· **Поиск нечитаемых файлов**. Данная команда производит поиск объектов, у которых есть нечитаемые атрибуты типа **Файл** или **Двоичные данные**. Такие атрибуты могут возникнуть, например, при восстановлении рассинхронизированных страховых копий файлового шкафа и системной базы данных IPS. После поиска атрибутов откроется специальная панель, показанная на рисунке ниже:
На панели представлен список объектов со значениями атрибутов, которые система не смогла прочитать из файлового шкафа. Для работы со списком доступны следующие команды:
 **Открыть в новом окне** – открывает текущий объект в новом окне **Навигатора** ;
 **Удалить** – удаляет выделенные объекты из базы данных IPS;
 **Удалить блоб** – удаляет выделенные значения файловых атрибутов или двоичных данных, при этом сами объекты в базе данных остаются;
 **Выделить всё** – выделяет/снимает выделение всех объектов и файлов в списке;
 **Выделить все файлы** – выделяет/снимает выделение всех значений атрибутов в списке.
· **Поиск неиспользуемых атрибутов**. Команда позволяет найти неиспользуемые типы атрибутов и, при необходимости, удалить их. При этом будет проанализирована применяемость атрибутов только в объектах, связях, таблицах IMBASE и метаданных IPS, поэтому удаление атрибутов может привести к неработоспособности модулей расширения системы, в настройках которых применены удаляемые атрибуты.
· **Найти связи объекта**. Команда позволяет выводить информацию о существующих связях по составу (закладка **Состоит из**) и применяемости (закладка **Применяемость**) в табличном виде для выбранного объекта. А также позволяет выводить идентификаторы связей и тип связи, идентификаторы, заголовки и информацию о типе объектов, для которых созданы связи.
· **Поиск объектов, на которые есть подписки на уведомления.** Производит поиск объектов, у которых есть подписки на уведомления об изменениях в соответствии с условиями поиска.
· **Удаление подписок на уведомления.** Позволяет удалить у объектов подписки на уведомления об изменениях в соответствии с условиями поиска.
· **Преобразование старых ключей IMBASE.**
· **Почистить объекты IMBASE.**
· **Реструктуризация таблиц IMBASE.**
· **Переименование атрибутов…**
· **Импорт таблицы IMBASE…**
· **Обновление внутренних индексов IMBASE.**
· **Синхронизировать с Imbase 5.0.** Производит проверку объектов, которые связаны с IMBASE, при необходимости восстанавливает значения атрибутов данных объектов из IMBASE, либо удаляет связь между объектом и IMBASE, если в IMBASE информации по такому объекту не найдено.
· **Импорт (синхронизация) таблиц рецептуры из Imbase 5.0.**
· **Очистить кэш экспертной системы**. Экспертная система (ЭС) хранит в кэше множество информации, для ускорения работы. При изменении объектов ЭС они должны также изменяться в кэше, но иногда этого не происходит или происходит с задержкой, особенно если изменения произведены на другом сервере. Команда очищает кэши правил расчета атрибутов, правил поиска объектов, таблиц, формул, скриптов и условий, а также накопленной информации об объектах IPS и схем сбора данных визуализатора проектных связей.
· **Обновить списки атрибутов у объектов ЭС.**
· **Проверить код сценариев C#.**

# Файл основных настроек клиентской программы
В данном файле хранятся основные настройки клиентской программы IPS. Имя файла – **IMClient.exe.config**.
Данный файл является XML-документом, в узлах которого содержатся атрибуты и значения с настройками. Рассмотрим его содержимое подробнее.

# Создание проекта по шаблону
Для создания проекта по созданному шаблону воспользуйтесь командой главного меню **Файл/Создать/Новый объект**. На первой странице мастера по созданию объектов выберите тип объектов **Проекты** и нажмите кнопку **Далее**.
На следующей странице укажите обозначение и наименование проекта. Затем выберите шаблон проекта:
После выбора шаблона проекта нажмите кнопку **Далее** , чтобы перейти к следующей странице:
Укажите значения требуемых атрибутов и нажмите Далее, чтобы перейти на страницу, позволяющую управлять созданием состава нового проекта на основании информации из шаблона проекта:
На данной странице изучите предлагаемую структуру состава проекта, которая зачастую бывает избыточной, и уберите отметки с тех дочерних элементов, которые не требуется создавать в составе нового проекта.
Затем нажмите **Готово** , чтобы завершить создание нового проекта и его состава.
Результаты работы в приведенном примере можно увидеть на следующем рисунке:
Был создан новый проект, в его состав был добавлен новый дочерний объект по шаблону проекта. Атрибуты у данного дочернего объекта были заполнены согласно указанным значениям и макросам из шаблона объекта.

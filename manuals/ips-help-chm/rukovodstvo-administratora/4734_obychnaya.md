# Обычная
Обычными связями соединяются действия, которые должны выполняться при последовательном ходе выполнения процесса. Если обычная связь исходит из действия, которое имеет исполнителя, то она будет отработана по команде **Отправить дальше** , если из действия, выполняемого системой — при корректном выполнении действия этого действия.

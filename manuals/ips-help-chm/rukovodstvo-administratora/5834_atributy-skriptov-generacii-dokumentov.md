# Атрибуты скриптов генерации документов
У скриптов генерации документов есть несколько атрибутов, которые определяют параметры тех документов, которые будут сгенерированы на основе каждого скрипта. Самые важные из этих атрибутов можно установить или изменить в окне параметров генерируемого документа, которое появляется при нажатии кнопки **Параметры документа**(см. п. ).
Прочие атрибуты можно редактировать только в карточке скрипта генерации документов.
**Создавать связь между документом и изделием** – логический атрибут, который определяет, должна ли программа после генерации документа автоматически создавать связь между исходным объектом и новым документом.
**Тип связи для включения документации в состав** – если после генерации документа нужно создавать связь с исходным изделием, в этом атрибуте нужно указать глобальный идентификатор типа связи. 
**Способ изменения документа** – определяет, что должна делать система, если в базе данных уже есть документ данного типа для данного исходного объекта. Для этого атрибута существует четыре возможных значения:
· **Создавать новую версию** – для нового документа будет создана новая версия существующего объекта документа. Эта возможность недоступна, если тип документа не является версионным.
· **Заменять существующий документ** – записать новый документ в существующий объект документа.
· **Создавать новый документ** – для нового документа будет создан новый объект документа, никак не связанный со старым объектом. 
· **Спрашивать пользователя** – после генерации каждого документа позволить пользователю выбрать один из первых трех вариантов, если программа найдет существующий объект документа данного типа для того же исходного объекта. Недопустимые варианты будут запрещены.

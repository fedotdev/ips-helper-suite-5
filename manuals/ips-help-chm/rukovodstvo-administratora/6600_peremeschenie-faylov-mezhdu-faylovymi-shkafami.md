# Перемещение файлов между файловыми шкафами
Для того, чтобы запустить процесс перемещение файлов между файловыми шкафами следует:
1\. В информационном пространстве навигатора выбрать тип объекта **Перенос файлов между файловыми шкафами** , который находится по пути **Объекты \ Настройки системы \ Перенос файлов между файловыми шкафами**.
2\. В рабочей области **Навигатора** вызвать команду **Создать** из контекстного меню.
3\. В открывшемся окне **Перенос файлов между файловыми шкафами** следует заполнить поле **Наименование**. 
4\. На закладке **Объект** необходимо добавить информацию по каждой существующей группе. Пример показан на рисунке ниже: 
Где,
· **Создатель объекта** – это поле, в которое следует добавить объект типа **Пользователь** , фильтр которого активен при наличии искомых значений. 
· **Владелец объекта** –это поле, в которое следует добавить объект типа **Пользователь** или **Группа пользователей** , фильтр которого активен при наличии искомых значений.
· **Группа** -**владелец** – это поле, в которое следует добавить объект типа **Группа пользователей** , фильтр которого активен при наличии искомых значений.
· **Тип объекта** – это поле, в которое следует добавить тип объекта, фильтрация активна при наличии искомых значений.
5\. В строку **Файловый шкаф (приемник)** следует добавить созданный ранее файловый шкаф, в который будет переносится необходимая информация.
6\. На закладке **Файл** следует указать шкаф источник.
7\. При необходимости можно заполнить строку **Имя файла содержит подстроку**. Доступен ввод нескольких значений подстроки без пробела и через разделитель «;». Пример ввода показан на рисунке ниже:
8\. Для завершения создания объекта типа **Перенос файлов между файловыми шкафами** следует нажать кнопки и .
9\. Далее необходимо **Планировщик задач** через меню **Настройка** , которое расположено на главной панели системы IPS. Описание работы планировщика задач представлено в п. 
10\. В открывшемся окне необходимо нажать кнопку и создать задачу.
11\. В строке **Выполняемая задача** следует выбрать **Перенос файлов между файловыми шкафами**.
12\. Строка **Наименование задачи** автоматически заполняется сразу после выбора значения **Выполняемая задача**.
13\. В строке **Имя сервера** следует выбрать рабочий сервер.
14\. Для корректной работы задачи, необходимо заполнить расписание задачи: **Периодичность** и **Дату запуска**.
15\. Для завершения создания задачи следует нажать кнопку .

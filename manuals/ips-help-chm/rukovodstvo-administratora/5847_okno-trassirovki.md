# Окно трассировки
Окно трассировки предназначено для просмотра последовательного выполнения команд и значений переменных на данном шаге выполнения программы, что позволяет легче обнаружить ошибки. Окно трассировки отображается после выполнения скрипта **Шаблон комплекта документов**(п. ), **Скрипт генерации документов** (п. ) или **Командного скрипта ЭС** (п. ), если в параметрах IPS **Система/Экспертная система/Трассировка** установлено значение**Да** для свойства **Окно трассировки**.
Окно трассировки показано на рисунке ниже.
В зависимости от типа скрипта количество вкладок может меняться.
В левой части окна трассировки отображается дерево из комплекта документов для объектов на который он запускался. Выделив определенный документ в правой части окна можно просматривать информацию по конкретному документу. Данное панель доступна только для скриптов шаблона генерации документов. Правая часть окна состоит из вкладок **Информация по трассировки** , **Документ** , **Отчет** , **Глобальная таблица**. 
На вкладке **Информация трассировки** представлена информация о выполнении скрипта по шагам с полученными значениями рассчитываемых атрибутов на каждом этапе выполнения скрипта. Данная вкладка доступна для всех из перечисленных выше скриптов. 
Параметры трассировки позволяют управлять видом и объемом информации, изображаемой в окне трассировки. Правильная установка параметров позволит быстро обнаружить причину неправильной работы системы, не продираясь через лишнюю информацию. Параметры трассировки задаются в параметрах IPS **Система/Экспертная система/Трассировка.**
Команда **Сохранить** позволяет сохранить информацию трассировки в XML файл.
На вкладке **Документ** отображается готовый документ, формируемый по скрипту генерации документов или скрипту **Шаблон комплекта документов**.
Команда **Сохранить** позволяет сохранить файл документа в формате Intermech Documents (*.imdx).
На вкладке **Отчет** выводятся (дублируются) сообщения, возникающие при генерации документов на вкладке **Вывод**.
Вкладка **Глобальная таблица** присутствует только у скриптов, для которых она была задана и позволяет отследить значения атрибутов объектов, которые были указаны при сборе глобальной таблицы.

# Уровни продвижения
**Уровень продвижения объекта** — это категория, определяющая статус объекта в процессе его жизненного цикла. Уровни продвижения служат для объединения одинаковых по смыслу шагов в жизненных циклах объектов различных типов. Это позволяет унифицировать их обработку различными модулями системы.

# Создание корневого хранилища
Понятие корневого хранилища в службе IPS.DVS идентично понятию файлового шкафа в IPS. Т.е. каждому объекту типа **Файловый шкаф** , созданному в IPS, соответствует только одно корневое хранилище.
Для создания нового корневого хранилища следует:
1\. Нажать кнопку на панели и выбрать из контекстного меню команду **Новый**.
2\. В открывшемся окне необходимо заполнить строки **Путь к корневому хранилищу** и **Максимальный размер Гб**. 
В качестве имени хранилища принимается имя папки верхнего уровня, это имя должно быть указано в поле **Наименование** для создаваемого файлового шкафа. 
Примечание: не рекомендуется создание корневых хранилищ с путями, в которых имена папок верхнего уровня идентичны.

# Назначение допустимых атрибутов
Для назначения допустимых атрибутов типа объекта, изменения набора атрибутов и корректировки их свойств необходимо воспользоваться закладкой **Атрибуты**. 
Рабочая область закладки **Атрибуты** делится на два основных раздела:
· **Список атрибутов** – раздел со списком атрибутов, назначенных данному типу объектов, расположен с левой стороны рабочей области;
· **Свойства выбранного атрибута** – раздел с возможностью корректировки свойства атрибутов под данный тип объектов, расположен с правой стороны рабочей области.
В таком случае, для объектов данного типа свойства этого атрибута будут принимать значения не из общих его свойств, а из скорректированных для данного типа объектов.
Значения свойств атрибута рассмотрены в п. и функционируют аналогичным образом, кроме свойств, рассмотренных ниже:
· **Оптимизация операций**. Задает способ оптимизации операций с атрибутом при работе со списком объектов данного типа:
− **Запись атрибута**. Оптимизация операций записи значений в атрибут. Рекомендуется использовать для атрибутов, которые не будут просматриваться пользователями в списках объектов данного типа (например, пароли или двоичные данные).
− **Сортировка и поиск по атрибуту**. Оптимизация операций поиска и сортировки значений атрибута при просмотре списка объектов данного типа в табличном виде. 
− **Чтение атрибута**. Оптимизация чтения значений атрибута при просмотре списка объектов данного типа в табличном виде.
**Внимание**! Если при запросе на атрибуте не стоит оптимизация по чтению, то запрос может не открытся, а система выдаст сообщение об ошибке:
**Условие «Не содержит атрибут или значение» для атрибута «Литера» не может быть применено, т.к. у рассматриваемого списка атрибутов не установлена оптимизация на чтение или на поиск значений этого атрибута.**
· **Правило**. Позволяет задать правило через выражение **[Value]** , ограничивающее параметры вводимых значений атрибутов абсолютным значением или значением другого атрибута. Например, выражение **[Value] > 0 and [Value] <= [Всего листов]** не даёт ввести в данный атрибут число, меньшее нуля или превышающее значение атрибута **Всего листов**. В правиле нельзя ссылаться на обязательные атрибуты объекта (номер версии, идентификатор и пр.), а также на атрибуты других объектов. Подробнее о синтаксисе формул написано в Приложении 5 .
Применительно к атрибутам вещественным числам, выраженным в единицах измерения, для поля **Правило** можно вызвать специальный диалог настройки атрибута. 
Поле **Единица измерения по умолчанию** содержит краткое наименование единицы измерения, которая будет использоваться в данном атрибуте по умолчанию. Список выбора при этом ограничен допустимыми единицами измерения для данного атрибута.
· **Принадлежность типу объектов**. Позволяет указать обязательность наличия данного атрибута у объекта.
· **Обязательный атрибут, добавляемый автоматически**. Данный атрибут автоматически добавляется при создании нового объекта. Присутствие данного атрибута обязательно, и удалить его невозможно.
· **Необязательный атрибут, добавляемый автоматически**. Данный атрибут автоматически добавляется при создании нового объекта. Наличие данного атрибута необязательно, поэтому пользователь имеет возможность удалить его из набора атрибутов объекта, например, с помощью команды **Удалить** контекстного меню на закладке **Свойства**.
· **Атрибут может быть добавлен вручную**. Атрибут не добавляется при создании нового объекта, но может быть добавлен пользователем вручную, например, с помощью команды **Добавить** контекстного меню на закладке **Свойства**.
· **Свойство наследования атрибута**. Свойство определяет порядок наследования атрибутов и значений их свойств в иерархии типов объектов:
− **Общий**. При создании дочернего типа объектов, общие атрибуты и значения их свойств автоматически копируются у родительского типа объектов и передаются дочернему, где данные атрибуты принимают статус **Унаследован**.
− **Собственный**. При создании дочерних типов объектов собственные атрибуты не копируются у родительского типа объектов и не передаются дочернему типу.
− **Унаследован**. При создании дочернего типа объектов, общие атрибуты и значения их свойств автоматически копируются у родительского типа объектов, передаются дочернему и становятся унаследованными. При этом все значения свойств данных атрибутов становятся неактивными и изменить их можно, только изменив значения свойств атрибутов родительского объекта. Если необходимо изменить значения свойств атрибута именно у дочернего объекта, необходимо свойству наследования присвоить значение **Общий** или **Собственный**.
· **Тип**. Определяет тип данных атрибута (только для чтения).
· **Уникальность**. Метод контроля уникальности значений атрибута:
− **Контролировать уникальность среди всех объектов**. Данный режим позволяет контролировать уникальность значения атрибута среди объектов всех глобальных типов, при этом версии одного объекта могут иметь одинаковые значения атрибута.
− **Контролировать уникальность среди всех объектов и их версий**. Не позволяет присваивать значение атрибуту, если в системе уже есть объекты или версии объектов с таким значением этого атрибута.
− **Контролировать уникальность среди объектов данного типа**. Не позволяет присваивать значение атрибуту, если в системе уже есть объект данного или дочерних типов с таким значением этого атрибута.
− **Контролировать уникальность среди объектов данного типа и версий данного объекта**. Не позволяет присваивать значение атрибуту, если в системе уже есть объект или версия объекта данного или дочерних типов с таким значением этого атрибута.
− **Не контролировать уникальность**. Позволяет присваивать неуникальное значение атрибуту, независимо от того, что в базе данных уже существуют объекты с таким значением данного атрибута.
Тип данных, допустимые значения и идентификаторы атрибута можно изменять только в общих свойствах атрибута (см. п. ).
Чтобы добавить атрибут в список атрибутов, расположенный слева рабочей области, нажмите правую кнопку мыши и выберите команду контекстного меню **Добавить**. В появившемся диалоговом окне выберите необходимый атрибут и нажмите кнопку **ОК**. При этом в списке появится выбранный атрибут с его общими свойствами. При необходимости отредактируйте свойства атрибута под данный тип объекта и нажмите кнопку **Применить**.
Чтобы исключить атрибут из списка, выделите его и выполните команду **Удалить** его контекстного меню. Нельзя удалить атрибут из списка, если у атрибута включено свойство **Влияет на дату модификации содержимого объекта** , а в базе данных существуют объекты данного типа, которым назначен этот атрибут.

# Закладка История поисковых запросов
На закладке **История поисковых запросов** предоставляется возможность посмотреть историю вводимых значений в поле **Искать**. На рисунке ниже показан вид закладки.
Для того чтобы вводимые значения в поле **Искать** сохранялись и отображались на закладке **История поисковых запросов** , следует включить настройку **Сохранять историю поисковых запросов** в **Параметры IPS / Пользователи / Безопасность учетных записей**. На рисунке ниже показано расположение настройки. 
На рабочей зоне закладки **Истории поисковых запросов** находятся панель с инструментами для возможности фильтровать сохраненные данные и таблица с данными.
Фильтрация данных осуществляется по пользователю, дате и по наименованию.

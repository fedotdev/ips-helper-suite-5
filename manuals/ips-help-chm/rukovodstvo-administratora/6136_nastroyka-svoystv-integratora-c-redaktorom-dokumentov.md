# Настройка свойств интегратора c редактором документов
Выберите конфигурационный объект **Интегратор с редактором документов** и нажмите кнопку **Свойства**.
Инструмент используется при работе с различными объектами, содержащими документы:
В настройках указывается перечень типов объектов, с которыми будет работать интегратор. Для каждого типа объекта можно задать объект-прототип (шаблон), который будет использован интегратором при создании новых объектов указанного типа.
Кнопка **По умолчанию** заполняет список типами объектов:
Кнопка **Добавить** открывает окно со списком типов объектов, в котором требуется отметить типы объектов, связываемые с интегратором:
После выбора типов объектов и нажатия кнопки **ОК** данные типы объектов будут связаны с интегратором, и будут показаны в списке типов объектов.
Чтобы назначить для типа объекта какой-либо объект-шаблон, требуется кликнуть левой кнопкой мыши в ячейке **Шаблоны** в строке с требуемым типом объекта (по надписи **[Шаблон не задан]**).
В появившемся редакторе доступны две кнопки – удалить ссылку на шаблон и выбрать объект-шаблон. 
· Кнопка **Убрать ссылку на объект-шаблон**позволяет очистить данное поле для выбранного типа объекта.
· Кнопка **Выбрать объект-шаблон** открывает окно по выбору объектов, причём в окне доступны только объекты выделенного в списке типа объекта:
После выбора объекта и нажатия кнопки **ОК** строка с выделенным типом объектов будет обновлена, в ней будет показан заголовок выбранного объекта-шаблона:

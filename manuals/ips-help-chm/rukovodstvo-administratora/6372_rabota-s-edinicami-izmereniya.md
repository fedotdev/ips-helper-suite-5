# Работа с единицами измерения
Система позволяет выделить одну из единиц измерения в выпадающем списке жирным шрифтом.
Для этого необходимо произвести следующие настройки:
1\. В конфигураторе для атрибута, у которого одна из единиц измерения будет выделяться жирным шрифтом, установить свойство **Фильтрация единиц измерения** \- **Да** ;
2\. Для объекта добавить атрибут **Базовая единица измерения** и указать единицу измерения, которая будет выделяться жирным шрифтом. Данная единица измерения будет выделена у всех атрибутов данного объекта, для которых установлено свойство **Фильтрация единиц измерения** \- **Да** ;
Допускается добавление в список альтернативных единиц измерения, для этого необходимо добавить атрибут **Альтернативные единицы измерения** для объекта и указать единицу измерения и коэффициент пересчета данной единицы измерения к базовой.

# Настройки MS Office
· **Использовать макрос AutoOpen** – это параметр, который включает вызов макроса при каждом изменении атрибутов в файле документа.
Для необходимости включить режим вызова макроса следует установить переключатель в режим «**Да»** с помощью всплывающего окна или двойного клика левой кнопки мыши напротив параметра **Использовать макрос AutoOpen**.

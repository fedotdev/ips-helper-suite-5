# Безопасность
Система IPS поддерживает следующие права доступа для работы с инструментами:
· **Разрешено настраивать все инструменты**. Пользователь имеет право выполнять настройки персональных и общих инструментов.
· **Разрешено настраивать персональные инструменты**. Пользователь имеет право выполнять настройки только персональных инструментов.
· **Разрешено использовать существующие элементы**. Пользователь имеет право только пользоваться инструментами, создавать новые и настраивать существующие он не имеет права.
Для настройки прав доступа следует открыть окно настройки инструментов и выбрать страницу **Безопасность** :
В списке отображаются учетные записи пользователей, которым назначены определенные права доступа для работы с инструментами.

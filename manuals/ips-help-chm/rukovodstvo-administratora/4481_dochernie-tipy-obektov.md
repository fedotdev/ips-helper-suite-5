# Дочерние типы объектов
Состав объекта включает в себя три компонента: родительский тип объекта, тип связи и допустимые дочерние типы объектов. Настройки отображения и сортировки составов позволяют администратору указать, в какой очередности в составе по каждому типу связи будут отображаться дочерние типы объектов.
Рассмотрим на примере. Состав сборочных единиц по типу связи **Состав изделий** может быть из различных дочерних типов объектов (с учётом их наследования). Редактор позволяет указывать, в каком порядке отображать эти дочерние типы объектов, кнопки  перемещают выделенный тип объекта вверх/вниз на одну позицию, а кнопки  – в начало или конец списка дочерних типов объекта.
Примечание: указанные настройки действуют на дочерние типы объектов с учётом их наследования. По этой причине дочерние типы объектов отображаются в виде дерева, с отображением всех наследуемых типов. Перемещение типа объекта перемещает всю ветвь типов-наследников.
В колонке **Группирующий элемент** позволяет сгруппировать объекты по типам в дереве Навигатора. Выбрав необходимые дочерние типы объектов в колонке **Группирующий элемент** система будет отображать эти объекты данного типа в составе родительского типа в виде виртуального нода с именем и иконкой их типа. 
Примечание: виртуальный нод отображается в составе родительского объекта при условии, что объекты дочернего типа действительно есть в составе.

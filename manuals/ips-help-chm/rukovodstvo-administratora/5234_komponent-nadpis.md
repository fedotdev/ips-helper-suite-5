# Компонент Надпись
· **Авторазмер.** Задает значение, показывающее, изменяет ли элемент управления размеры автоматически для отображения своего содержимого.
· **Выравнивание изображения**. Задает выравнивание изображения, отображаемого в элементе управления.
· **Выравнивание текста**. Задает выравнивание текста в элементе управления.
· **Изображение из библиотеки**. Позволяет выбрать изображение для элемента управления из библиотеки изображений.
· **Изображение с диска**. Позволяет выбрать изображение для элемента управления из файла, хранящегося на локальном или сетевом диске.
· **Текст**. Текстовое значение, связанное с элементом управления.

# Команды запуска приложений
Данный инструмент может быть назначен любому типу объекта. Инструмент позволяет выполнять задачи **Просмотр** , **Редактирование** и **Печать** для объектов указанного типа. Обработка команд может возлагаться на установленные в системе IPS интеграторы приложений, а также на операционную систему и установленные в ней приложения.
На странице размещено несколько основных элементов:
· **Дерево типов объектов** – позволяет выбрать тип объектов, для которого настраиваются команды запуска приложений.
· **Редактор команд** – список назначенных команд для указанного типа объектов.
· **Команды по умолчанию** – страница позволяет настроить стандартные команды **Редактирование** , **Просмотр** и **Печать** для указанного типа объекта, если на странице **Редактор команд** создано несколько разных вариантов однотипных команд (например, несколько вариантов команды **Просмотр**).

# Закладка События
На закладке **События** расположена панель с инструментами, с помощью которых предоставлена возможность осуществить необходимые действия для настройки отображения зарегистрированных событий. 
Описание основных кнопок панели ниже:
 – кнопка, которая позволяет обновить список событий.
 – кнопка, которая позволяет открыть панель с дополнительной информацией о параметрах события:
· **Категория** – параметр с информацией о категории, к которой относится событие.
· **Вид действия** – параметр, который описывает операцию.
· **Тип события** – параметр, который описывает событие.
· **Идентификатор объекта** – параметр, который содержит идентификатор объекта той категории, к которой относится событие.
· **Имя объекта** – параметр, который содержит наименование объекта, к которому относится событие.
· **Идентификатор версии объекта** – параметр, содержащий идентификатор версии информационного объекта, к которому относится событие. Если событие не имеет отношения к версии информационного объекта (например, при записи значения в атрибут связи), то данное поле содержит **0**.
· **Идентификатор связи** – параметр, содержащий идентификатор связи, к которой относится событие. Если событие не имеет отношения к связи (например, при записи значения в атрибут объекта), то данное поле содержит **0**.
· **Начало события** – параметр, который отображает дату и время начала операции, вызвавшей событие.
· **Завершение события** – параметр, который отображает дату и время завершения операции, вызвавшей событие.
· **Имя пользователя** – параметр, который указывает имя пользователя, инициировавшего событие.
· **Имя компьютера** – параметр, который указывает имя компьютера, с которого было инициировано событие.
· **Комментарии к событию** – поле с дополнительной системной информацией о событии.
 – кнопка позволяет показать панель для группировки по значениям колонок.
**Журнал событий** – строка для выбора типа журнала событий. С помощью строки **Журнал событий** осуществляется переход из списка с оперативными данными в список с архивными или файловыми данными. 
Примечание: в файловом журнале отображаются данные, которые были загружены из файлов при использовании кнопки , описание кнопки ниже.
 – кнопка вызывает диалоговое окно, в котором можно указать дату начала архивации записей журнала событий, не дожидаясь выполнения задачи **Удаление устаревших данных** планировщика задач. 
**Фильтр событий** – строка для выбора динамического фильтра записей.
 – кнопка, которая позволяет создать новый динамический фильтр событий.
 – кнопка, которая позволяет внести изменения в выбранный фильтр событий.
 – кнопка, которая позволяет удалить выбранный фильтр событий.
 – кнопка, которая позволяет открыть xml файл с журналом.
 – кнопка, которая позволяет экспортировать события в Excel.
Примечание: в Excel экспортируются только те события, которые были выделены в общем списке.
Кроме инструментов, расположенных на панели закладки **События** , пользователю доступны команды контекстного меню, описание которых дано ниже:
 **Обновить** – команда позволяет обновить содержимое закладки.
 **Открыть в новом окне** – команда позволяет открыть в новом окне объект, к которому относится данная запись.
Примечание: если запись не относится к какому-либо объекту, то данная команда недоступна.
 **Копировать** – команда позволяет скопировать отображенную в рабочей области информацию о событии в виде текста, который можно вставить в **WordPad** или **Блокнот**.
 **Отметки** – команда с подкомандами, с помощью которых предоставляется возможность выделить записи в той комбинации, в которой укажет сам пользователь. Варианты выбора отметок представлены на рисунке:
 **Удалить запись** – команда позволяет удалить группу записей, которые выделены в общем списке событий.
**Очистить журнал** – команда вызывает диалоговое окно **Удаление записей журнала** , в котором следует выбрать вариант удаления зарегистрированных событий: удалить записи ранее указанной даты или удалить все записи.
**Внимание!** Записи удаляются физически и не переносятся в архивный журнал.
**Отчет в Excel** – команда дублирует действие кнопки , которая находится на панели инструментов.
 **Найти текст** – команда вызывает диалоговое окно **Найти текст** , с помощью которого можно настроить параметры для поиска необходимого текста.
 **Найти далее** – команда позволяет последовательно переходить по найденному тексту. 
Примечание: команда **Найти далее** работает при условии, что запущен режим поиска текста посредством команды **Найти текст**.
 **Настройка отображения…** – команда открывает диалоговое окно, в котором осуществляется настройка отображения колонок.
**Сбросить настройки отображения** – команда позволяет вернуть исходные настройки отображения данных в рабочей области.

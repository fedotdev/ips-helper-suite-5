# Удаление пользователя/группы пользователей или подгруппы пользователей
Для удаления пользователя или группу пользователей необходимо выполнить следующие действия:
1\. Следует выделить необходимую учетную запись пользователя/группу пользователей/подгруппу пользователей и вызвать команду контекстного меню **Удалить**.
Примечание: если учетная запись пользователя/подгруппа входила в число других групп, то она будет удалена из них тоже.
Для исключения пользователя/подгруппы пользователей из состава группы необходимо:
2\. Выделить учетную запись пользователя/подгруппу пользователей и вызвать команду контекстного меню **Состав объекта/Исключить из состава**.
Примечание: система позволяет удалить учетную запись пользователя/подгруппу пользователей клавишей **Delete**.

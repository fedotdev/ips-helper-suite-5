# Импорт списка пользователей из домена Active Directory
Чтобы импортировать пользователей из домена Active Directory, выполните следующие действия:
1\. В приложении **Администратор базы данных/Пользователи групп** следует выделить группу, в которую необходимо импортировать пользователей из домена, и с помощью команды контектсного меню **Импорт из домена** вызвать диалоговое окно **Импорт пользователей из домена**. 
2\. В поле **Имя домена** выбрать имя из списка и нажать кнопку .
3\. В появившемся списке следует отметить пользователей, которых необходимо импортировать, и нажать кнопку . 
В окно импорта пользователей из домена реализован поиск, который ведется по подстроке по всем полям (пользователь, полное имя, почта и т.д.) без учета регистра.
Если в процессе импорта IPS обнаружит, что пользователь с таким именем (полным или кратким) уже зарегистрирован в базе данных, то система предложит пропустить регистрацию данного пользователя или прервать операцию импорта пользователей в IPS.
**Внимание!** При импорте в IPS заносится информация только о полном и кратком имени пользователя, а также SID пользователя в службе каталогов. Пароль такого пользователя остается пустым и должен быть незамедлительно назначен либо самим пользователем, либо администратором системы. Для обеспечения безопасности пользователей можно импортировать в какую-либо группу с ограниченными правами, а затем по мере необходимости исключать их из этой группы.

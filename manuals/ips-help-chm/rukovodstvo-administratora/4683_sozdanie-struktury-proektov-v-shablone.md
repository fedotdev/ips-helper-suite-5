# Создание структуры проектов в шаблоне
Основное назначение шаблона проекта – генерация состава в создаваемых по этому шаблону проектах.
Для этих целей в самом шаблоне создается избыточный состав из объектов типа **Шаблоны объектов**. Данный тип объектов содержит атрибут, ссылающийся на какой-либо тип информационного объекта IPS. Также в состав шаблона проекта можно добавлять объекты любых других типов (например, выборки или классификаторы) – в этом случае они будут автоматически включены в состав проекта, создаваемого по данному шаблону.
Когда пользователь создает проект по шаблону, мастер по созданию объектов изучает состав шаблона. Для каждого шаблона объекта из этого состава в IPS создается новый объект, тип которого указан в шаблоне объекта. Значения атрибутов этого объекта заполняются из атрибутов шаблона объекта.

Логический атрибут **Чекбокс по умолчанию** предоставляет возможность выводить флажки с элементами шаблона в диалоге создания объекта по шаблону и отключать ненужные элементы. По умолчанию атрибут **Чекбокс по умолчанию** включен.
Примечание: если создаваемый шаблон является вспомогательным и планируется использоваться редко, то рекомендуется поставить атрибут**Чекбокс по умолчанию** в значение «**нет** ». 
Атрибут **Глобальный идентификатор типа объекта** – это атрибут, который ссылается на какой-либо тип информационного объекта IPS. В примере создадим шаблон объекта, который будет создавать в составе нового проекта объект типа Пояснительная записка. После нажатия кнопки **ОК** мастер по созданию новых объектов добавит в шаблон объекта ссылку на выбранный тип объекта, а также атрибуты из указанного типа объекта:
В значениях атрибутов шаблона объекта допускается использовать тексты, содержащие формулы для автоматической генерации значений (макросы). Значения макросов при создании нового объекта по указанному шаблону будут заменяться на значения соответствующих атрибутов родительского или корневого объекта (проекта).
В таблице приведен список стандартных макросов и их описание:
| **Макрос** | **Описание** |
| --- | --- |
| **%Имя атрибута%** | Вместо **Имя атрибута** укажите название атрибута, имеющегося у родительского объекта, в составе которого создается по шаблону дочерний объект (т.е. поиск значения атрибута выполняется вверх по дереву состава). Например, у проекта указано обозначение **Пример проекта**. Если в шаблоне дочернего объекта в атрибуте **Обозначение** содержится макрос вида **Документация на проект %Обозначение%** то при создании дочернего объекта в составе данного проекта обозначение у дочернего объекта будет равно **Документация на проект Пример проекта**. |
| **%9%** | Предназначается для включения в значение атрибута порядкового номера объекта. Например, если значение атрибута **Обозначение** у шаблона объекта имеет вид **%Обозначение%-%9%** , то первому созданному по шаблону дочернему объекту будет присвоено обозначение **Пример проекта-1** , второму - **Пример проекта-2** , и т.д. Если макрос содержит несколько цифр 9, то при вычислении значения формулы IPS заполнит недостающие позиции нулями (например для макроса **%Обозначение%-%999%** для третьего создаваемого объекта будет сгенерировано значение **Пример проекта-003**). |
| **%DATE%** | Используется для вставки в значение атрибута объекта текущей даты. |
| **%ROOT%** | Значение макроса заменяется на значение атрибута из корневого объекта. Имя этого атрибута совпадает с именем атрибута в шаблоне объекта, в значении которого применяется данный макрос. Например, в шаблоне объекта указано значение атрибута **Обозначение** , равное **Обозначение:** **%ROOT%**. При создании дочернего объекта в составе проекта по такому шаблону **Обозначение** у этого объекта будет получено у проекта (как у корневого объекта состава), и будет иметь значение **Обозначение: Пример проекта**. |
В рассмотренном выше примере с шаблоном проекта и шаблоном дочернего объекта для генерации заголовка дочернего объекта используется макрос **Пояснительная записка к проекту %Обозначение%**. При создании нового проекта, например с обозначением **Пример проекта** , в его составе будет создан дочерний объект типа **Пояснительные записки** , с заголовком, имеющим значение **Пояснительная записка к проекту Пример проекта**.
**Внимание!** Все атрибуты, используемые в макросах **%Имя атрибута%** , должны быть явно назначены в конфигураторе на создаваемый тип шаблона объектов. Значение свойства атрибута **Запрет копирования значения у прототипа** должно быть выставлено в положениее **Нет**.

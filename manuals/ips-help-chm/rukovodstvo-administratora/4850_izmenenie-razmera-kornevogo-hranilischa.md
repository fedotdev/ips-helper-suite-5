# Изменение размера корневого хранилища
Для того, чтобы изменить размер корневого хранилища, необходимо выделить хранилище в дереве и нажать кнопку , а затем выбрать из контекстного меню команду **Изменить размер**.
В открывшемся диалоге необходимо указать новый максимально допустимый размер корневого хранилища.
Для завершения проведения изменений, следует нажать кнопку .

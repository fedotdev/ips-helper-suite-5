# Работа со скриптами
Скрипт – это программа, написанная на специальном упрощенном языке программирования, которая позволяет указать, какие действия должна выполнить экспертная система в том или ином случае. Скрипт имеет древовидную структуру, которая значительно облегчает его понимание и редактирование. Каждый элемент скрипта представляет собой оператор, который иногда может сопровождаться модификатором. Существуют разные виды скриптов (см. рисунок ниже), но все они редактируются одинаковым образом, с помощью специализированного редактора скриптов (см. п. ).

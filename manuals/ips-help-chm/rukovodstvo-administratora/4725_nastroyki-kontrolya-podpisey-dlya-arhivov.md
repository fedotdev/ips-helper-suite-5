# Настройки контроля подписей для архивов
Контроль подписей для архивов выполняется следующим образом. Требуется выделить архив в дереве архивов и открыть страницу **Контроль подписей**.
С помощью команды **Добавить новую группу** контекстного меню вызывается окно **Выберите графы для подписей** :
После нажатия кнопки **ОК** будет создана группа подписей:
Для каждой графы подписи можно включить или убрать строгий контроль подписей.
После настройки контроля подписей в архив можно будет помещать только подписанные объекты (согласно указанным настройкам).
Допускается создавать несколько групп подписей (групп с графами). Контроль подписей для размещаемого в архив объекта будет пройден, если любая из групп с графами окажется корректно подписанной.

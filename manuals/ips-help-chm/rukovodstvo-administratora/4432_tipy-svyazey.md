# Типы связей
**Связь** — это категория, устанавливающая подчиненное отношение между версией информационного объекта и другим информационным объектом, т.е. в версию объекта с идентификатором версии объекта входит объект с идентификатором объекта. Такой способ связывания позволяет оставлять без изменения связи родительского объекта при выпуске новой версии любого из дочерних объектов. Автоматический выбор версий дочерних объектов при получении состава родительского объекта производится с помощью текущего правила подбора версий. Все связи делятся на типы, которые определяют: 
− допустимый набор атрибутов, которые могут присваиваться связи автоматически или вручную;
− допустимые типы объектов, между которыми может существовать связь;
− видимость связей в клиентских приложениях;
− хранение истории связей;
− способы обработки связей различными модулями системы и т.д.

# Активный файловый шкаф
Активным является файловый шкаф, в который помещаются все создаваемые и регистрируемые в IPS файлы документов. В системе может быть только один активный шкаф и по умолчанию в него попадают все файлы системы.
Сделать активным файловый шкаф можно на закладке **Свойства** карточки файлового шкафа в поле **Активный файловый шкаф**. При этом файловый шкаф, который был активным прежде, перейдет в статус неактивного.

# Подбор
· **Выбор объекта**. Используется при необходимости захвата объекта, расположенный на форме.
Примечание: **Выбор объекта** доступен во всех группах панели компонентов.
· **Подбор компонента по атрибуту**. Позволяет подобрать компонент в зависимости от выбранного атрибута.

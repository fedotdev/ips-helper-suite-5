# Значения для сравнения
В зависимости от функции сравнения в качестве аргументов могут выступать не только атрибуты фильтруемой версии объекта, но и значения для сравнения.
Значения для сравнения бывают следующих видов:
− константа;
− переменная;
− другой атрибут фильтруемой версии объекта.
Значения-константы задаются при проектировании правила подбора версий. Значения-переменные получают какие-то начальные значения при проектировании правила подбора версий, а затем каждый пользователь имеет возможность задавать несколько вариантов значений таких переменных. Перед началом фильтрации все переменные значения должны быть инициализированы. Значения-атрибуты заполняются непосредственно во время самой фильтрации на основании атрибутов фильтруемой версии объекта.
Критерии подбора можно группировать между собой с помощью логических функций ИЛИ и И. Кроме того, к результату вычисления любого значения критерия для сравнения может быть применено логическое отрицание НЕ.

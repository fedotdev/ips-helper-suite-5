# Диалог редактирования параметров таблицы
Для редактирования таблицы достаточно выполнить на объекте таблицы команду **Редактировать** или **Открыть в новом окне**. После создания новой таблицы также открывается редактор таблиц.
В окне **Параметры таблицы** находятся поля для ввода **Названия таблицы** , выбора ее типа и поля ввода аргументов: **Аргументы по вертикали** , **Аргументы по горизонтали** , **Слои/Решения**.
Для добавления атрибутов в соответствующее поля используется контекстное меню.
· **Добавить** — позволяет добавить атрибут в выделенное поле.
· **Изменить** — заменяет выделенный атрибут на новый.
· **Удалить** — удаляет выделенный атрибут.
· **Очистить** — удаляет все атрибуты в выделенном поле.
· **Переместить Вверх/Вниз** — позволяет изменить расположение атрибутов, тем самым поменять последовательность отображения аргументов в таблице.
При добавлении нескольких атрибутов в поле **Слои/Решения** значение в поле **Слои** будет меняться. 
В зависимости от того, к какому типу принадлежит таблица, различные управляющие элементы диалога работают по-разному (некоторые из них вообще невидимы, если соответствующие параметры не имеют смысла):
· Таблицы без входов служат для задания отношения между несколькими аргументами. Для каждого столбца такой таблицы необходимо определить аргумент, значения которого будут находиться в этом столбце. Поскольку для таких таблиц не требуется определять аргументы слоев, панели Слои результатов отключаются. Количество столбцов автоматически устанавливается равным количеству аргументов в соответствующем списке, а количество строк требуется ввести в соответствующем поле ввода.
· Одновходовые таблицы не нуждаются в панели **Аргументы по горизонтали** , которая становится невидимой. Необходимо задать набор аргументов, которые будут участвовать в условии, в панели **Аргументы по вертикали** , а также набор аргументов-решений в панели **Слои/Решения**. Кроме этого, необходимо установить количество строк в таблице (количество столбцов получается автоматически, поскольку каждому столбцу назначен ровно один аргумент).
· Для таблицы с двумя входами все панели диалога активны. Необходимо задать наборы аргументов для условий по горизонтали и вертикали, а также аргументы для слоев. Кроме этого, необходимо определить количество строк и столбцов, поскольку для таких таблиц программа не может сделать этого автоматически.

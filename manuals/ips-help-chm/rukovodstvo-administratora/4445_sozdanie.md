# Создание
Чтобы создать новую схему жизненного цикла, в дереве метаданных отметьте элемент **Схемы жизненного цикла** и примените команду **Добавить** его контекстного меню. При этом в дереве появится новая схема, большинству свойств которой будут присвоены значения по умолчанию. Отредактируйте свойства созданной схемы и нажмите кнопку **Применить**.

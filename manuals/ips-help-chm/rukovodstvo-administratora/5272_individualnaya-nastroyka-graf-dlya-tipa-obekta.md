# Индивидуальная настройка граф для типа объекта
Установленный флажок в строке **Индивидуальная настройка граф для типа объекта** позволяет переключить закладку **Подпись** в режим настройки индивидуальных граф для подписей на отдельный тип объекта. 
 – элемент, который позволяет добавить тип объекта.
 – элемент, который позволяет добавить графы.
 – элемент, который позволяет удалить запись.

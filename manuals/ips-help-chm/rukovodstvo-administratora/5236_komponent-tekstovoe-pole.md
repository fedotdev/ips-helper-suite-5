# Компонент Текстовое поле
В данном компоненте основные свойства унаследованы от компонента **Надпись с атрибутом** , кроме того есть дополнительные свойства:
· **Добавлять атрибут**. Позволяет добавлять атрибут в объект или связь, если там нет такого атрибута.
· **Индекс переключения**. Порядок включения активности компонента с помощью табуляции (порядковый номер элемента управления в списке элементов, принадлежащих одному родительскому контейнеру, на которые может быть выполнен переход по табуляции).
· **Переключение** (табуляция). Данное свойство разрешает или запрещает фокусу ввода переходить на данный элемент управления.

# Добавление родительского типа объекта
Чтобы добавить новые настройки для родительского типа данных, вызовите команду контекстного меню **Добавить родительский тип** в дереве родительских типов объектов.
В появившемся окне следует выбрать один или несколько родительских типов, настройки для которых планируете сделать. После нажатия **ОК** выбранные типы объектов появятся в дереве родительских типов. Если повторно выбрать какой-либо тип объекта, на дерево типов и существующие настройки это никак не повлияет.
Удалить родительский тип можно с помощью команды контекстного меню **Удалить родительский тип** и соответствующей кнопки на панели инструментов.

# Модификаторы циклов
Модификаторы циклов позволяют организовать циклическое выполнение операторов, вложенных в текущий оператор. К ним относятся модификаторы **Цикл** , **Цикл с сортировкой** , **Цикл с группировкой** , **Версии объектов** .
Модификатор **Цикл** дает возможность выполнять вложенные операторы, пока заданное условие не станет ложным (аналог цикла ПОКА в языках программирования) либо определенное количество раз, используя какой-нибудь временный атрибут в качестве счетчика (цикл ДЛЯ). 
В верхней части окна в поле **Переменная цикла** необходимо выбрать атрибут, который будет являться результатом выполнения цикла на каждом из его шагов.
Далее необходимо выбрать нужный тип цикла, включив соответствующий переключатель (**Выполнять, пока верно условие** , По**значениям атрибута, Выполнить, начиная с**). Если включен верхний переключатель, можно ввести условие продолжения цикла, а прочие поля запрещены. Приращение в данном виде цикла необходимо создавать вручную внутри цикла при помощи переменной (например, переменной**х** присвоить значение **х+1**), предварительно присвоив ей начальное значение перед циклом (например, **х=0**). 
Если включен переключатель **По значениям атрибута** , в поле справа необходимо выбрать атрибут, который может содержать множество значений. Цикл будет выполняться по значениям данного атрибута.
Если включен переключатель **Выполнять начиная с** , то можно выбрать стартовое значение и формулу, которая будет возвращать его конечное значение. Для ввода формулы необходимо щелкнуть в соответствующем поле правой кнопкой мыши и выполнить команду **Изменить**.
Модификатор **Цикл с сортировкой** позволяет сортировать объекты контекста по выбранным атрибутам, а потом выполнить вложенные операторы для каждого из этих объектов по очереди. Для добавления атрибутов объектов используется команда **Добавить атрибут объекта** , для добавления атрибутов связей – **Добавить атрибут связи**. Кнопка **Удалить** применяется для удаления атрибута.
Модификатор **Цикл с группировкой** позволяет выполнить вложенные операторы один раз для каждой группы объектов из набора. В панели параметров этого модификатора аналогично модификатору **Цикл с сортировкой** можно задать атрибуты сортировки (две верхние кнопки) так и дополнительно атрибуты группировки (две нижние). Для вставки атрибутов группировки объекта используются кнопка **Атрибуты объекта для группировки** , для вставки атрибутов связи – **Атрибуты связи для группировки**.
Переключатель **Встроенная сортировка** применяется в том случае когда необходимо использовать встроенную сортировку разделов спецификаций (см. команду **Настройка сортировки** в окне **Параметры генерируемого документа,** отрываемого по команде **Параметры документа** на панели служебных кнопок п. ).
Этот модификатор сначала сортирует набор объектов по атрибутам сортировки, а потом группирует полученный результат по атрибутам группировки. Группой является последовательность объектов сортированного набора, имеющих одинаковые значения атрибутов группировки.
Примечание: группировка практически всегда проводится по тем же атрибутам, что и сортировка, или по их части – в противном случае вместо одной группы с одинаковыми значениями атрибутов группировки может получиться несколько. В данном случае атрибут **Название функциональной группы** вычисляется по значению атрибута **Код функциональной группы** , и нескольким кодам может соответствовать одно и то же название.
Модификатор **Версии объектов** позволяет перебрать все версии для входного объекта контекста. Работает только для папок и операторов поиска объектов.
В зависимости от выбранного переключателя **Для первой версии** или **Для всех версий** возвращает либо первую версию, либо все версии объекта.
При включенном переключателе **Для первой версии** вернет первую версию при той сортировке, которая выбрана в поле **Сортировка версий**. Это позволяет, например, получить, последнюю версию. Или последнюю измененную.
Переключатель **по убыванию** провести сортировку в обратную сторону тем самым получив, например, первую версию объекта.
Также, в модификаторе можно задать дополнительные **Условие выбора версий** , что позволит сразу выбрать версии, соответствующие определенным критериям.

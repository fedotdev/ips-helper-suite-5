# Прочие
· **Типы документов поддерживающие рецензии** – это параметр, в котором следует указать типы документов , для которых будет разрешено создавать рецензии.
· **Добавлять количество материалов, входящих в объект, при добавлении ссылки на часть составного материала** – это параметр, включение которого позволяет пользователю добавлять количество при создании ссылки на часть составного материала в текстовых документах.
· **Синхронизировать ссылки на объекты в документе с составом документа** – это параметр, который включает режим создания состава документа на основании ссылок из содержательной части электронного документа. Включенный интегратор позволяет синхронизировать ссылки на другие документы, находящиеся в данном документе.
Для необходимости включить режим синхронизации ссылки следует установить переключатель в режим «**Да»** с помощью всплывающего окна или двойного клика левой кнопки мыши напротив параметра **Синхронизировать ссылки на объекты в документе с составом документа**.

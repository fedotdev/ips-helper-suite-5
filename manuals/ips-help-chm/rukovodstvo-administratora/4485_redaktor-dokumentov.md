# Редактор документов
**Редактор документов** – это модуль, который позволяет создавать документы, редактировать их и просматривать содержимое в рабочей области системы IPS.
Для настройки модуля необходимо выбрать команду **Параметры IPS** из меню **Настройка** панели инструментов. В открывшемся окне открыть пункт **Редактор документов**.
В состав пункта**Редактор документов** входит подгруппа **Общие настройки** со своими параметрами. Параметры этой подгруппы описаны ниже:
· **Абзац.** Данный параметр дает возможность настроить формат абзаца документа по умолчанию. Однако, на документы, которые созданы по форме, назначенной настройками параметров отдельных модулей, значения данного параметра не распространяются. 
Для настройки формата абзаца следует раскрыть его с помощью стрелки и указать необходимые значения для каждого параметра.
Примечание: настройки данного параметра распространяются на **Шаблоны документов (бланки)** , однако, каждый объект в текстовом редакторе документа можно дополнительно настроить с помощью команды **Свойства…** контекстного меню выделенной области или настроек на панели инструментов.
· **Вертикальная линейка.** Данный параметр дает возможность отображать вертикальную линейку в редакторе документов.
· **Горизонтальная линейка.** Данный параметр дает возможность отображать горизонтальную линейку в редакторе документов.
· **Исправлять десятичный разделитель.** Данный параметр позволяет включить режим автоматического исправления десятичного разделителя вводимого числового значения «,» или «.» на указанный в региональных настройках операционной системы. Исправление десятичного разделителя происходит только в дополнительных настройках документа по команде контекстного меню **Свойства…** __
**Внимание!** Основной текст документа не подлежит автоматическому исправлению десятичного разделителя введенного числового значения. __
**Внимание!** Отключение данной возможности может привести к ошибке в системе, которая не даст откорректировать необходимое значение.
· **Показывать диалог после создания элемента.** Данный параметр дает возможность вызвать окно с настройками геометрии при создании следующих элементов:
− **Редактора текста** – объект для ввода текста;
− **Метка –** объект для создания штрихкода;
− **Контейнер** – объект для хранения изображений и редактирования OLE объектов.
_Примечание: изменить тип любого созданного элемента можно по команде контекстного меню._
· **Показывать невидимые линии.** Данный параметр позволяет отобразить невидимые при печати линии границ.
· **Показывать размеры при изменении.** Данный параметр позволяет включить режим отображения всплывающего окна с размерами изменяемого элемента в таблице. Для просмотра всплывающего окна следует навести указатель мыши на границу элемента.
· **Положение пользовательской системы координат.** Данный параметр позволяет указать точки начала отсчёта пользовательской системы координат относительно верхнего левого угла страницы.
· **Проверять правописание.** Данный параметр включает режим проверки правописания при редактировании документа.
· **Радиус привязки**. Данный параметр позволяет назначать расстояние до существующих объектов в режиме создания элементов страницы. В данном режиме используются назначенные координаты вместо текущих координат указателя мыши.
· **Размер сетки.** Данный параметр позволяет указать размер сетки при выборе координат мышью.
· **Редактировать OLE объекты как файлы.** Данный параметр позволяет внедрить, связать и редактировать объекты в составе документа в виде файлов. В противном случае, данные объекты открываются и редактируются в виде OLE объектов. 
Примечание: включать настройку рекомендуется в случае, если возникают ошибки в работе с OLE-объектами.
· **Режим отладки.** Данный параметр позволяет включить режим отображения раздела Debug в свойствах документа, в данном разделе отображены настройки отладки. Данная информация полезна для администратора.
· **Система координат**. Данный параметр позволяет выбрать ориентацию координатных осей пользовательской системы координат:

· **Создавать лог.** Данный параметр позволяет создавать и хранить файлы событий в хронологическом порядке в отдельной папке на рабочем компьютере. Система самостоятельно создает папку для хранения таких файлов.
· **Шрифт**. Данный параметр позволяет настроить шрифт для некоторых документов по умолчанию. Однако, на документы, которые созданы по форме, назначенной настройками параметров отдельных модулей, значения данного параметра не распространяются.

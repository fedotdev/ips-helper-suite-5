# Временные права доступа
На закладке **Вложения /** **Временные права** размещена группа параметров, настройка которых позволяет задать пользователю дополнительные права доступа к вложенному в действие объекту. Данные права несут временный характер и их действие распространяется при условии, что кэш прав доступа обновлен, а действие с объектом еще не перемещено на следующий шаг.
В поле **Тип объектов для временных прав** предоставляется возможность скорректировать список типов объектов, на которые назначаются временные права.
**Внимание!** При настройке параметров следует помнить, что результат назначенных прав доступа зависит от прав пользователя, который прикрепил объект к действию.

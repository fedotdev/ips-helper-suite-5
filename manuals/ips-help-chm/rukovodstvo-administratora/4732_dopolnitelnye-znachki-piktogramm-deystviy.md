# Дополнительные значки пиктограмм действий
Пиктограммы действий могут иметь пояснения в виде появляющихся на них значков.
 — означает, что для данного действия была создана пользовательская форма.
— означает, что действие не до конца определено (некорректно), т.е. не заполнены или не указаны его необходимые свойства. При наведении курсора на знак вопроса показывается пояснение, почему действие считается некорректным.
 — действие-коллектор, которое начинает выполняться только тогда, когда все предыдущие действия выполнены.
 — означает, что для данного действия было задано изменения статуса (шага жизненного цикла или уровня продвижения).
 — означает, что для данного действия было задано сообщение для пользователя.
 — означает, что для данного действия назначен общий сценарий.
 — означает, что для данного действия назначен локальный сценарий.

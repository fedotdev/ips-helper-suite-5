# Синхронизация с Imbase 5.0
**Внимание!** Если данные не перекачивались из Imbase 5.0 (предыдущее поколение ПО Intermech) – данная группа настроек в процессе работы не используется и не нуждается в корректировке.
Примечание: синхронизация может выполняться только после процесса миграции (перекачки данных).
· **Удалять дубликаты ссылок на таблицы Imbase:** Данный параметр включает режим, при котором из папок **Imbase** удаляются ярлыки с одинаковым наименованием, кроме самого нового ярлыка.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Дата начала синхронизации:** Данный параметр задает дату, начиная с которой будут обрабатываться события из журнала событий Imbase 5.0. По мере обработки событий данный параметр изменяется автоматически.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Останавливать синхронизацию при ошибке:** Данный параметр позволяет остановить процесс синхронизации при возникновении какой-либо ошибки. В случае если установлено значение «нет», текст ошибки будет записан в журнал и процесс синхронизации будет продолжен.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Путь к файлу PumpSettings.xml:** Данный параметр указывает путь, где расположен файл с параметрами миграции PumpSettings.xml. Путь указывается на машине, где работает сервер приложений. 
**Внимание!** Если путь не задан или путь некорректный, то процесс синхронизации не может быть запущен!
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Тип СУБД:** Данный параметр указывает тип СУБД для подключения к базе-источнику Imbase 5.0.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Имя сервера/Имя (SID) базы данных: *** Данный параметр задает имя сервера (или SID) базы-источника Imbase 5.0.
Имя параметра зависит от Типа СУБД.
Примечание: Изменить значение может только пользователь с ролью **Администратор**.
· **Файл/Имя базы данных: *** Данный параметр задает файл (или имя) базы-источника Imbase 5.0.
Имя параметра зависит от Типа СУБД.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Имя пользователя:** Данный параметр задает имя пользователя, для подключения к базе-источнику Imbase 5.0.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Пароль:** Данный параметр задает пароль, для подключения к базе-источнику Imbase 5.0.
Примечание: изменить значение может только пользователь с ролью **Администратор**.

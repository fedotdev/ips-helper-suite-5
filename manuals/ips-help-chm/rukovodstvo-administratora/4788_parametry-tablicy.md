# Параметры таблицы
Основной параметр таблицы – это количество ее входов. Вход – это несколько исходных атрибутов, которые связаны друг с другом при определении результатов. Таблицы экспертной системы делятся на три типа в зависимости от количества входов: безвходовые, одновходовые, двухвходовые.

# Размещение компонентов шаблона процесса
Любой шаблон должен содержать действие **Старт** и, по крайней мере, одно действие **Стоп** — эти действия определяют начальную и конечную точку выполнения процесса.
· Чтобы поместить необходимое действие в редактор, отметьте его в палитре и при нажатой левой клавише мыши переместите в область редактора с помощью указателя мыши (drag-n-drop). Таким образом, разместите все необходимые для создаваемого шаблона процессов действия. 
· Управление действиями осуществляется с помощью команд контекстного меню их пиктограмм. Набор команд зависит от типа выбранного действия.

Команда **Создать связь** используется для создания связей между действиями. При выборе этой команды появляется стрелка, которую нужно направить к тому действию, с которым должно быть связано исходное действие, и щелкнуть левой кнопкой мыши по его пиктограмме. 
Команда **Создать обратную связь** доступна для действий **Задача** , **Утверждение** и **Регистрация, Сценарий, Подпроцесс и Удаленный подпроцесс**. С ее помощью можно указать действие, на которое нужно будет вернуться, при невыполнении исходного действия.
Команда **Создать параллельный блок** используется для создания параллельно протекающих действий, результат которых не зависят между собой. Например, при запуске процесса по утверждению КД одновременно нескольким рецензентам, удобнее создавать параллельные ветви с действиями. 
Параллельный блок должен начинаться на действии, из которого исходят связи в параллельные ветви. 
При возврате в одной из ветвей, параллельный блок позволяет запустить повторное выполнение с той ветки, из которой был осуществлен возврат.
**Внимание!** Работа блока распространяется по направлению выполняемых ветвей действия, из которого и выходят связи к ветвям, и заканчивается в объединяющем параллельные ветви действии с коллектором.
Примечание: признак коллектора будет выставлен автоматически если на действии в конце блока его нет.
Каждое действие имеет команду контекстного меню **Свойства** , вызывающую диалоговое окно, на закладках которого осуществляются настройки действия (описание закладок см. в п. ). Открыть свойства текущего действия можно также при помощи двойного клика по пиктограмме действия.
С помощью команд контекстного меню пиктограмм вы можете **Копировать** или **Вырезать** действие данного шаблона и **Вставить** его в этот же или в другой шаблон процесса. При этом также будут копироваться все свойства данного действия.
Для действий, имеющих исполнителей (**Старт, Задача** и **Утверждение**), доступна команда контекстного меню **Редактировать форму** , которая открывает редактор пользовательских форм. Если для данного действия была создана форма, в его контекстном меню появятся команды **Смотреть форму** и **Удалить**. В редакторе шаблонов действия, имеющие назначенную форму, графически помечаются значком **F** в нижнем левом углу пиктограммы.
Чтобы удалить действие из редактора, отметьте его в редакторе и выберите команду его контекстного меню **Удалить** или нажмите клавишу **Delete**. При этом, если действие было соединено связями с другими действиями, то соединяющие его связи также удалятся.
Чтобы удалить связь между действиями, отметьте ее и нажмите клавишу **Delete** , или выполните команду **Удалить** из контекстного меню.

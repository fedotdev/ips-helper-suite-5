# Разрешенные типы документов
Для настройки типов документов, разрешенных для хранения в выбранном архиве, воспользуйтесь закладкой **Разрешенные типы документов** из списка закладок архива. 
Кнопки  и используются для составления списка типов документов. Переключатель устанавливает режим использования списка. Если в списке находится документ, имеющий дочерние типы, то настройка режима использования распространяется и на них.

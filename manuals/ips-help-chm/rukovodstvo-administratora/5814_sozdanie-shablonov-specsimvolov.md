# Создание шаблонов спецсимволов
Шаблоны спецсимволов предназначены для вставки графических фрагментов (специальных символов, графических изображений и т. д.) с параметрами в тексты документов. Шаблоны спецсимволов можно разделить на две группы: графические (пример на рисунке слева) и текстовые (справа).
Текстовые шаблоны обычно создаются при необходимости расположить текст особым образом.
Для того чтобы использовать шаблоны спецсимволов, необходимо внести их в **Библиотеку формул и спецсимволов**. Данные типы объектов создаются в **Навигаторе** по пути **Информационное пространство / Объекты /Настройки системы / Библиотеки формул и спецсимволов.**
Как правило, в поставочной базе уже создана библиотека стандартных примитивов. 
Отредактировать данную библиотеку можно по команде контекстного меню **Редактировать**.
Редактор формулы состоит из области со списком спецсимволов и их составляющими элементами, области отображения текущей формулы, поля для заполнения параметров и области отображения общей формулы.
Создание спецсимволов состоит из следующих этапов:
1\. При помощи команд меню **Формула** / **Вставить новую формулу перед текущей** или **Формула** / **Вставить новую формулу после текущей**.
2\. В свойствах элемента необходимо указать наименование элемента и его характеристики. При указании размеров элемента спецсимвола стоит понимать, куда он в дальнейшем будет вставляться. Как правило, данные элементы вставляются в документы со строками, ограниченными по высоте, соответственно при указании размеров группирующего элемента его высота не должна превышать данное значение.
3\. Внутрь группирующего элемента могут вставляется элементы **Редактор текста** , **Метка** , **Таблица** , **Полилиния** , **Контейнер**. Добавление данных элементов производиться при помощи соответствующих команд меню **Элементы страницы** и далее при помощи курсора на группирующем элементе необходимо указать область вставки выбранного элемента.
Размеры и положение области можно в дальнейшем изменить в свойствах элемента или вручную.
4\. Далее по аналогии внутрь группирующего элемента спецсимвола добавляются все необходимые элементы.
Примечание: окно **Редактирование формулы** можно открыть в окне редактора спецификаций в графе **Примечание** для единственной записи с помощью вызова команды **Вставить формулу…** из контекстного меню. На рисунке ниже показано расположение команды **Вставить формулу…:**
Особенности создания спецсимволов:
1\. Если требуется создать круг или эллипс можно воспользоваться элементами страницы **Редактор текста** , **Метка** , **Контейнер** , установив для них значение свойства **Эллипс** – **Да**.
2\. Сложные графические элементы можно создавать как при помощи вставки нескольких элементов страницы, так и при помощи добавления стороннего рисунка спецсимвола через элемент контейнер.
3\. При создании текстовых спецсимволов, имеющих несколько текстовых полей (например, спецсимвол Д_РАЗМ) предпочтительно использовать элемент **Таблица**.
4\. Для элементов, содержащих динамический текст в свойстве **Авторазмер по ширине** следует устанавливать значение **Да**.
5\. Для возможности изменения размеров страницы спецсимвола необходимо свойству **Авторазмер** установить значение **Нет**.

# Схема документа
Шаблон документа можно представить в иерархическом виде, где высшим звеном является сам документ, а его дочерними элементами являются страницы и элементы страниц. Дерево документа отображается на панели **Схема документа** , которая вызывается с помощью команды главного меню **Вид/Схема документа**.
Используя эту панель, можно отыскивать элементы по их названию (отмеченный в дереве элемент отмечается и в рабочей области шаблона), применять различные действия к элементам и страницам с помощью команд их контекстного меню, менять порядок следования элементов, перетаскивая их с помощью указателя мыши.

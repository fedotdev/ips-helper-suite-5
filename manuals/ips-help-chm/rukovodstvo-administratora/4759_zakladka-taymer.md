# Закладка Таймер
Закладка отображается в свойствах действий типа **Таймер**. Ее настройки позволяют установить время срабатывания таймера. 
· Переключатель **Период от начала выполнения действия** позволяет жестко задать период времени, через который будет срабатывать таймер.
· Переключатель **Взять из переменной типа Дата** позволяет взять время срабатывая таймера из переменной типа **Дата**(если таковые имеются в списке переменных шаблона). Обычно в таком случае переменная заполняется при помощи пользовательской формы.

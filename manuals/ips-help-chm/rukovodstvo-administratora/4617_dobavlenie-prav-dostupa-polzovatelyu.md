# Добавление прав доступа пользователю
Если требуется добавить определенные права доступа пользователю системы IPS, нажмите кнопку **Добавить** :
В появившемся окне выберите учетную запись, для которой назначаются права доступа и нажмите кнопку **ОК**.
В появившемся новом диалоговом окне выберите требуемые права доступа и нажмите **ОК** , чтобы сохранить изменения:
В результате в списке будет отображена новая учетная запись с выбранными правами доступа:

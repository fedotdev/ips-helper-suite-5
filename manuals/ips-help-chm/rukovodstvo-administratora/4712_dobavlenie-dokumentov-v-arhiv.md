# Добавление документов в архив
Чтобы разместить документ в архиве, выделите архив в дереве и воспользуйтесь командой контекстного меню **Добавить документы** :
Программа отобразит окно, в котором требуется выбрать документы для добавления в архив:
После нажатия кнопки выбранный документ будет размещен в текущем архиве. При этом в документ будут добавлены атрибуты из структуры архива, а у самого документа будет заполнен ссылочный атрибут **Архив** – атрибут будет ссылаться на текущий архив:
Примечание: если требуется удалить документ из архива, выделите данный документ, откройте его свойства и удалите содержимое атрибута **Архив**.

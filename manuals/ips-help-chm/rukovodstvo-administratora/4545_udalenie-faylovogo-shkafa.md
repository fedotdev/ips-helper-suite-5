# Удаление файлового шкафа
Чтобы удалить файловый шкаф, необходимо отметить его в списке файловых шкафов и применить команду **Удалить** его контекстного меню. Невозможно удалить файловый шкаф, если он содержит файлы. В таком случае, перед удалением файлового шкафа, нужно перенести файлы в другой шкаф или удалить их из базы данных. Из системы нельзя удалить активный файловый шкаф, поэтому перед удалением нужно активизировать другой шкаф.
Удаление файлового шкафа из IPS не влечет за собой удаления базы данных, в которой он находился. Если в файле этой базы данных больше нет необходимости, его можно удалить средствами СУБД или операционной системы.

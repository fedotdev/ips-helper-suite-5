# Права доступа
Закладка **Безопасность** позволяет назначить пользователям права доступа к типу объектов. По умолчанию всем пользователям разрешен просмотр типа объектов в списке, просмотр и создание объектов данного типа. Все права доступа даны только администратору системы. Однако система позволяет изменять права доступа отдельным пользователям, группам пользователей или ролям, под которыми пользователи входят в систему. Система позволяет назначать следующие права доступа:
· **Просмотр типа объектов в списке** — разрешает видеть данный тип объектов в списке типов объектов.
· **Просмотр списка всех объектов** — разрешает просматривать список объектов данного и дочерних нелокальных типов. Выключение данного права скрывает механизмы поиска объектов данного типа (выборки и классификаторы) в соответствующем узле **Навигатора**. Данное право действует только на список объектов данного типа в **Навигаторе** – в других ситуациях (например, на рабочем столе или при просмотре состава объектов) данное право доступа не действует.
· **Изменение свойств типа объектов** — разрешает изменять свойства типа объектов.
· **Удаление типов объектов** — разрешает удалять данный тип объектов.
· **Добавление дочерних типов объектов** — разрешает добавлять дочерние типы объектов в состав родительских.
· **Удаление дочерних типов объектов** — разрешает удалять дочерние типы объектов из состава родительских.
· **Настройка взаимосвязей между типами объектов** — разрешает назначать связи между данными типами объектов и изменять их свойства.
· **Создание объектов** — разрешает создавать объекты данного типа.
· **Просмотр прав доступа** — разрешает просматривать набор прав доступа к данному типу объектов.
· **Изменение прав доступа** — разрешает назначать права доступа на данный тип объектов.
**Внимание!** В системе IPS предоставлена возможность копировать права, при условии, что место, куда копируются выбранные права, может принимать такие права доступа.

# Настройка шаблонов проектов
Система IPS позволяет создавать новые проекты на основе имеющихся в системе так называемых шаблонов объектов. В комплект поставки IPS входят два шаблона для проектов – **Шаблон проекта** (тип данных **Шаблоны проектов**) и **Шаблон стройки** (тип данных **Шаблоны архитектурно-строительных проектов**). 
Вы можете создать свои шаблоны для типовых для вашей организации структур объектов. Рекомендуем вам сначала внимательно ознакомиться с шаблонами, включенными в поставку в качестве примеров.
Шаблоны проектов – это информационные объекты IPS. Доступно два типа шаблонов проектов:
− Шаблоны проектов;
− Шаблоны архитектурно-строительных проектов.
Структуру шаблонов проектов можно получить, открыв приложение **Конфигуратор базы данных** в узле дерева **Типы объектов/Настройки системы/Шаблоны проектов** :
По умолчанию, в типе объекта **Шаблоны проектов** есть только один атрибут – **Уровень доступа**.
Список объектов указанного типа можно получить в приложениях **Навигатор** и **Администратор базы данных** :
По своей сути, шаблоны проектов являются информационными объектами с предопределенными структурой состава и настройками. Это упрощает выполнение типовых пользовательских операций – создание нового проекта, включение в его состав дочерних объектов со своей структурой и т.п.
Состав объектов-шаблонов заранее избыточен с целью упрощения последующих действий пользователей при создании на их основе новых проектов.
**Внимание!** Настоятельно рекомендуется не проводить изменения в стандартных шаблонах **Шаблон проекта** и **Шаблон стройки**.

Состав данного объекта избыточен. При создании нового проекта на основе данного шаблона пользователь должен будет выбрать элементы состава, которые должны быть созданы в новом проекте.

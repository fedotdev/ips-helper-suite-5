# Закладка Удаленный подпроцесс
Закладка **Удаленный подпроцесс** доступна при редактировании свойств действий типа **Удаленный подпроцесс** и позволяет настроить, где и какой процесс требуется запускать при выполнении действия. На этой закладке нужно выбрать, на каком узле будет производиться запуск процесса (из списка всех зарегистрированных узлов), а также шаблон процесса, на основе которого будет запускаться процессы (шаблоны процессов, которые могут запускаться удаленно, должны быть предварительно опубликованы на портале).

Если в настройках действия **Удаленный подпроцесс** выбрана опция **Ждать завершения** , выполнение основного процесса продолжится только после завершения подпроцесса. В этом случае все вложения подпроцесса (вместе с правами владения), а также значения переменных и сообщения будут переданы назад в основной процесс.
При включенной опции **Передавать права владения** права владения для каждого прикрепленного объекта будут сняты для текущего узла и делегированы узлу-получателю. В случае, если выполнение после прохождения удаленного подпроцесса будет возвращаться в основной процесс (настройка **Ждать завершения** включена), права владения на вложения будут возвращены узлу-инициатору процесса после прохождения подпроцесса.

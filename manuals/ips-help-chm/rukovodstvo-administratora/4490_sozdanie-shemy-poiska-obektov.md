# Создание схемы поиска объектов
Создать схему поиска объекта можно несколькими способами:
· Войти в приложение **Администратор базы данных / Настройки системы / Схемы поиска объектов** , выбрать тип создаваемого объекта (это могут быть или **Общие схемы поиска объектов** , или **Персональные**), вызвать диалоговое окно правой кнопкой мыши и выбрать команду **Создать**.
· С помощью команды контекстного меню объекта на рабочей области**Создать / Новый**. В открывшемся окне открыть **Настройки системы / Схемы поиска объектов** и выбрать тип создаваемого объекта. Неважно, в каком приложении вы работаете на данный момент. 
· Войти в приложение **Навигатор /Информационное пространство / Объекты / Настройки системы / Схемы поиска объектов** , выбрать тип создаваемого объекта, вызвать диалоговое окно правой кнопкой мыши и выбрать команду **Создать**.
· Воспользоваться кнопкой **Создать новую схему поиска** на панели инструментов закладки **Поиск состава**. Выбрать тип создаваемого объекта и нажать кнопку .
Для корректного создания схемы поиска необходимо заполнить следующие пункты:
1\. Заполнить строку**Название схем**.
2\. С помощью выпадающего списка выбрать направление поиска **Состав** или **Развёрнутый состав** (в зависимости от пути создания схемы поиска, список может быть дополнен направлениями **Применяемость** и **Развернутая применяемость** , однако, эти направления относятся к закладке **Поиск применения**).
Примечание: данные направления определяют, как будет выполняться поиск состава – на один уровень вниз или на все допустимые уровни вложенности.
3\. При необходимости группировать объекты по их версиям и отображать актуальные версии следует установить флажок в соответствующих областях**Группировать по версиям объектов** и **Только актуальные версии**.
4\. Для применения условий какой-либо выборки к найденным объектам необходимо настроить элементы управления **Условия выборки объектов** :
· **Добавить условие существующей выборки**. Позволяет указать выборку, условия которой будут применяться для фильтрации списка найденных объектов.
· **Свойства (карточка) выборки**. Позволяет открыть и отредактировать карточку выборки, если она назначена схеме поиска.
· **Создать и добавить условие выборки**. Позволяет вызвать мастера по созданию новых выборок, а затем применяет условия созданной выборки в схеме поиска.
5\. Выбрать правило подбора версии в поле **Правило подбора версий** по которому будет производиться основной поиск. Для этого необходимо нажать кнопку **Добавить правило подбора.**
6\. Для дополнительной фильтрации списка найденных объектов состава по системной ручной выборке следует установить флажок в области **Найденные объекты входят в выборку Продукция**.
7\. Для выбора типов объектов, среди которых будет выполняться поиск состава, следует выделить **Типы объектов, по которым ведётся поиск** , и нажать кнопку . В списке диалогового окна следует выбрать необходимые типы объектов и нажать кнопку .
8\. Для выбора типов объектов, среди которых необходимо выполнить полное раскрытие состава, следует выделить **Типы объектов, для которых требуется разворачивать состав** и нажать кнопку . В списке следует выбрать необходимые типы объектов и нажать кнопку .
9\. Для выбора типов объектов, среди которых не требуется выполнять полное раскрытие состава, следует выделить **Типы объектов, для которых нельзя разворачивать состав** и нажать кнопку . В списке следует выбрать необходимые типы объектов и нажать кнопку .

10\. Для выбора типов связей следует выделить **Типы связей, по которым ведётся поиск** и нажать кнопку. В списке следует выбрать необходимые типы связей и нажать кнопку.
Примечание: если для поиска не задан ни один тип связи, тогда будут использоваться типы связей по умолчанию.
11\. При необходимости привязки схемы к ролям следует выделить **Роли, использующие схему** и нажать кнопку . В списке необходимо выбрать одну или несколько ролей, для которых будет доступна данная схема поиска и нажать кнопку .
Примечание: для выбора нескольких ролей следует удерживать кнопку **[CTRL]** и выбирать требуемые роли. 
12\. Для отображения дополнительных колонок в списке найденных объектов (атрибутов объекта, связей) следует выделить **Дополнительно отображаемые колонки** и нажать кнопку . В появившемся окне необходимо указать атрибут, его принадлежность и ширину колонки.
Примечание: действия п. 12. следует повторять столько раз, сколько требуется отображать дополнительных столбцов в результате поиска.

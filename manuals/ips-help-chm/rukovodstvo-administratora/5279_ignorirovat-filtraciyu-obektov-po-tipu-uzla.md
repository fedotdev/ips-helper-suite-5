# Игнорировать фильтрацию объектов по типу узла
По умолчанию узлы различных систем (IPS и SEARCH) не видят друг друга, а также объектов, которые они опубликовали на портал. Такую фильтрацию можно отменить, указав эту настройку в конфигурационном файле.
**·** Наименование:**SitesSystemTypesIgnore**
**·Значение:true или false**
Например, **_< add key="_SitesSystemTypesIgnore _" value="true"/ >_**

# Ввод функций (часть 1)

Редактор формул поддерживает множество различных функций – как стандартных, так и специфических для экспертной системы и IPS. Каждая функция имеет определенный результат и может также иметь несколько параметров. Для ввода функции в формулу достаточно щелкнуть и стрелке выпадающего списка **Вставить функцию** и дважды щелкнуть на нужной функции.
При описании функций используются следующие обозначения типов данных: 
А – тип атрибута, 
Д – дата, 
Л – логическое значение (истина или ложь), 
О – тип объекта, 
П – число с плавающей точкой, 
Е – число с плавающей точкой в единицах измерения, 
С – строка, 
Н – набор, 
Ц – целое число.

Попытка получить значение не заданного атрибута приведет к тому, что экспертная система попытается вычислить его значение (вероятнее всего, неудачно) и выдаст ошибку, либо, что еще хуже, рассчитает это значение с помощью каких-либо объектов ЭС, которые не предназначались для подобных расчетов. |

Пример 3: nom( M20 *1 -6h ) = 20 . Пример 4: nom( G 1 1/2 ’’ -А ) = 112 . Если в качестве аргумента функции nom подается обозначение дюймовой цилиндрической (G), трубной цилиндрической (R) или конической дюймовой (K) резьбы, то результатом этой функции будет некоторое условное значение (без разделителей / и ’’), которое может использоваться затем для обращения к таблицам или формулам, работающим для упомянутых резьб. |

| ФЛАГ(Ц,Ц) | Л | Установлен ли флажок Функция выполняет проверку установки битовых флагов в числе. На вход функции подается первым аргументом – номер битового флага, вторым аргументом – десятичное число, внутри которого требуется проверить установку флагов. Поиск установленного флажка осуществляется по двоичному представлению второго аргумента функции. Отсчет номера позиции флажка в двоичном представлении ведется справа, начиная с 1. Пример: десятичному числу 42 соответствует двоичное представление 0010 1010. Каждый бит двоичного числа представляет собой состояние флажка, где 1 означает, что флажок включен (True), а 0 что выключен (False). | | 42 |
| --- | --- |
| Флаги | 0 | 0 | 1 | 0 | 1 | 0 | 1 | 0 |
| N флага | 8 | 7 | 6 | 5 | 4 | 3 | 2 | 1 |
| Результат | F | F | T | F | T | F | T | F |
ФЛАГ(2, 42) = True (0010 10**1** 0)
ФЛАГ(3, 42) = False (0010 1**0** 10)

val2(С,С) | С | Строка с разделителем для ведомости Функция позволяет склеить две строки в одну. Данная функция может применяться, например, для вывода обозначения документов в которых присутствует повторяющая часть. Пример: val2("ИОТ ", <Номер инструкции по охране труда>) = "ИОТ 12" . Если значение какого-либо входного параметра пустое, возвращаемое значение также будет пустое. 
val3(С,С,С) | С | Строка с префиксом и постфиксом Функция позволяет склеить три строки в одну. Данная функция может применяться, например, для вывода значения какого-либо атрибута в кавычках. Пример: val3("«", <Графа для подписей>, "»") = "«Проверил»" . Если значение какого-либо входного параметра пустое, возвращаемое значение также будет пустое.

Результат функции возвращается в "тиках". В одной секунде 10 миллионов тиков. Пример: Tdiff(<Дата подписания>,<Дата модификации содержимого объекта>)

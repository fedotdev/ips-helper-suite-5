# Файлы
Параметр **Файлы** позволяет настроить работу с аутентичными файлами. Для настройки параметра **Файлы** необходимо открыть команду **Параметры IPS** из меню **Настройка** панели инструментов системы IPS. В открывшемся окне выбрать параметр**Файлы** из пункта **Система**.
**Внимание!** Настройки параметра проводятся только администратором системы.
В области **Генерация дополнительных листов** доступны следующие параметры для настройки:
· **Вызов скрипта генерации.** Данный параметр позволяет указать будет ли включен режим вызова дополнительного скрипта генерации при формировании аутентичных файлов.
· **Скрипт генерации.** В данном параметре указывается скрипт, который будет выполняться при формировании аутентичного файла, для последующего добавления дополнительных листов к аутентичному файлу.
· **Режим вставки.** В данном параметре указывается месторасположение дополнительно сформированных скриптом листов в аутентичном файле (перед или поле аутентичного файла). Например, исходя из рисунка выше при формировании аутентичного файла, в начало файла будут добавлен лист с подписями сгенерированный по скрипту **Лист подписей**.
В области **Общие** доступны следующие параметры для настройки:
· **Алгоритм расчета контрольной суммы по умолчанию.** Данный параметр дает возможность выбрать алгоритм расчета контрольной суммы, которым будет пользоваться система по умолчанию при расчете.
· **Разрешать альтернативные алгоритмы.** Данный параметр дает возможность пользователю разрешить или заблокировать расчет контрольных сумм по алгоритмам.
· **Копировать аутентичные файлы у версий и прототипов.** Данный параметр позволяет копировать аутентичный файл с предыдущей версии объекта при создании новой или при создании объекта по прототипу. 
Примечание: по умолчанию команды не заимствуют аутентичные файлы из исходных версий или объектов-прототипов.
· **Аутентичные файлы документов.** Данный параметр позволяет указать расширение аутентичных файлов, которые формируются из документов, не связанных с интегратором.
Применение: формирование файлов из таких документов осуществляется в ручном режиме.
· **Атрибут суффикса для имен аутентичных файлов.** При назначении данному параметру атрибута строкового типа при сохранении файлов по команде **Сохранить на диск** или **Аутентичные файлы/Сохранить на диск** и при наличии соответствующего атрибута у объектов, для которых производится сохранение, к именам сохраняемых аутентичных файлов добавляется суффикс в виде значения атрибута. При включенном параметре **Добавлять версию объекта к именам аутентичных файлов** суффикс добавляется в имени аутентичного файла после версии объекта.
· **Шаблон для имени файла с грифом секретности.** Данный параметр задает шаблон, по которому будет переименован первый файл документа при назначении этому документу грифа секретности. Указанные в треугольных скобках наименования атрибутов будут заменены на значение соответствующих атрибутов документа. **< Гриф документа>** будет заменен на назначенный гриф. **< Расширение файла>** будет заменено на расширение переименовываемого файла документа. Шаблон по умолчанию: **< Гриф документа> <Наименование>.<Расширение файла>**.
· **Добавлять версию объекта к именам аутентичных файлов.** При установленном в **Да** значении параметра при сохранении файлов по команде **Сохранить на диск** или **Аутентичные файлы/Сохранить на диск** и при наличии версионности у объектов, для которых производится сохранение, к именам сохраняемых аутентичных файлов добавляется суффикс вида **[ <версия>]**.

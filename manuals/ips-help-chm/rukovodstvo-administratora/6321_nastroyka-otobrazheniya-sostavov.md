# Настройка отображения составов
Дерево родительских типов объектов, кроме настройки типов связей, предоставляет администратору возможность настроить колонки (столбцы), которые будут отображаться для составов указанных типов объектов. 
Для этого требуется выделить родительский тип объекта и вызвать команду контекстного меню **Настройка отображения составов**. Появится стандартное окно **Навигатора** , в котором можно выбрать отображаемые столбцы и указать их порядок и ширину на экране.
Подробнее ознакомиться с окном по настройке отображения можно в .
Примечание: данные настройки будут применяться у пользователей указанной роли в том случае, если пользователь не сделал свои персональные настройки для просматриваемых элементов пространства навигации.

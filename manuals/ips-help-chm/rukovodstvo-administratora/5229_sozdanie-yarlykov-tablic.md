# Создание ярлыков таблиц
· **Запретить создание нескольких ярлыков на одну таблицу:** Данный параметр позволяет запретить создавать несколько ярлыков на одну таблицу Imbase.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
Синхронизовать объекты можно в том случае, если список атрибутов типа объектов содержит атрибут **Ссылка на объект IMBASE** либо у самого типа свойство **Любой атрибут** выставлено в значение **Да**.
Однако стоит учитывать, что при таком методе синхронизации происходит обновление данных, как объектов выбранного типа, так и объектов всех дочерних типов (при условии, что синхронизация возможна).

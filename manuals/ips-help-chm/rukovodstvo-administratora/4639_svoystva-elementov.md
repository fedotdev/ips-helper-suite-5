# Свойства элементов
Свойства элементов отображаются на специальной панели, которую можно вызвать, воспользовавшись командой **Свойства** контекстного меню любой страницы или элемента редактора. На панели пользователь может изменять свойства элементов. Свойства элементов разделены на группы, содержимое которых можно скрыть или отобразить по мере необходимости. В зависимости от типа выбранного элемента, набор свойств на панели может меняться. Рассмотрим группы и их свойства, которые наиболее часто встречаются в элементах.

# Создание связей и ссылок
· **Учитывать применяемость Imbase при формировании состава:** Данный параметр включает режим, когда при выборе записи Imbase проверяется **Применяемость** и в зависимости от значения происходит следующее:
− **Применяемость = «+»** – отсутствуют ограничения на использование записи;
− **Применяемость = «!»** – при выборе через окно Imbase в Techcard или AVS система не позволит выбрать запись, показывая при этом сообщение об отключенной применяемости;
− **Применяемость = «*»** – при выборе записи через окно Imbase система выводит диалог «Позиция НСИ не входит в ограничительный перечень. Продолжить операцию?». В этом диалоге пользователь может отменить выбор либо продолжить операцию;
− **Применяемость = «-»** – при выборе записи через окно Imbase система выводит сообщение об отключенной применяемости и не позволит выбрать запись.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Иконки папок в зависимости от значения атрибута Применяемость:** Данные параметры дают возможность назначить иконки папкам Imbase для конкретного значения применяемости.
**Внимание!** Иконка будет отображаться в колонке **Статусы**.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Цвета записей таблиц в зависимости от значения атрибута Применяемость:** Данные параметры дают возможность указать цвет записи таблицы Imbase для конкретного значения применяемости.
**Внимание!** Данные настройки не влияют на редактор таблиц Imbase.
Примечание: изменить значение может только пользователь с ролью **Администратор**.

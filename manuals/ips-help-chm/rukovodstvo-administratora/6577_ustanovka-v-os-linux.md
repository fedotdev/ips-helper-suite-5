# Установка в ОС Linux
Установка в ОС Linux осуществляется через консоль, при этом для установочного файла должны быть предоставлены права запуска. Это можно сделать с помощью следующей команды:
· **cd <каталог к установочному файлу> &&.**
· **chmod 777 SetupIpsDVS.linux-x64.run &&.**
· **./SetupIpsDVS.linux-x64.run.**
При успешном выполнении команды, появится окно установки в терминале. В данном окне необходимо ввести все запрошенные в процессе установки параметры.
**Внимание!** При установке в Linux может появится следующая ошибка:
· ошибка **< username> is not in sudoers file** – следует отредактировать файл /etc/sudoers, добавив строчку <username> ALL = (ALL : ALL) ALL в конец файла (либо если она закомментирована символом # – убрать этот символ), где <username> – имя пользователя в системе.
После установки служба запустится автоматически в качестве сервиса (daemon). Состояние, которого можно проверить командой: **systemctl status IpsDVS**. Для входа в интерфейс администратора следует перейти по ссылке из терминала.
Изменение параметров программы в последующем можно выполнить в файле appsettings.json, который находится в каталоге программы, либо выполнить заново установку программы.

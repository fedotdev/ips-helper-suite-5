# Нормализованные индексы
В состав типов объектов могут входить атрибуты, которые хранят свои значения в так называемом нормализованном виде. Такие атрибуты хранят информацию в специальном виде, позволяющем учитывать типовые ошибки, которые совершают пользователи при вводе строковых значений (различное количество пробелов, разный регистр букв, ввод латинских символов вместо кириллицы и т.п.). Нормализованные индексы не видны в карточках и списках информационных объектов, однако их можно использовать в условиях выборок для поиска информации.
Использование нормализованных атрибутов (индексов), например, по идентификационным параметрам изделий и документов (**Обозначение** , **Код ОКП** , **Наименование**), позволяет избежать дублирования записей об объектах в базу данных IPS из-за ошибок при ручном вводе пользователями идентификационных параметров добавляемых/изменяемых объектов. К таким ошибкам относятся лишние пробелы, схожие по начертанию латинские символы вместо кириллических и наоборот, использование строчных букв вместо прописных, т.п.
Значения нормализованных атрибутов вычисляются по формулам, указанным в свойстве **Формула** типа атрибута для типа объекта. При необходимости можно наложить условия уникальности значений нормализованного атрибута среди объектов указанного типа либо всех типов (см. п. \*\*\*\*\*\*\*\*\*\*\*\*).
Все настройки нормализованных индексов выполняются в окне **Настройка / Параметры IPS / Система / Нормализованные индексы**.
В группе Общий поисковой индекс имеет следующие настройки:
· **Минимальная длина слова для индексации**. Настройка, которая позволяет задать минимальную длину слова для индексации.
· **Поиск в индексе по подстроке**. Регулирует значение по умолчанию переключателя **Искать подстроку** в диалоге настройки поиска по общему индексу (см. ). Не рекомендуется использовать поиск подстроки в индексе, т.к. это значительно замедляет работу алгоритмов поиска.
Настройки нормализованных индексов глобальны, т.е. действуют на всю базу данных IPS. Рассмотрим правила формирования нормализованных индексов:
· **Верхний регистр** — выполняется преобразование всех символов введенной строки к верхнему регистру.
· **Нормализовать символы** — буквы кириллицы преобразуются в одинаковые по начертанию латинские символы, если есть таковые (это позволяет устранить ошибки, связанные с ошибочным вводом похожих по написанию кириллических символов вместо латинских и наоборот).
· **Удалять пробелы** — значения нормализованных атрибутов формируются без пробелов (позволяет устранять ошибки, связанные с вводом лишних пробелов или отсутствием требуемых пробелов в исходной строке данных).
Помимо указанных настроек, для нормализации доступны дополнительные настройки.
· **Устранять дублирование символов** — в данной таблице можно указать символы (символьные последовательности), повторяющиеся подряд значения, которых будут удалены из нормализованного значения. Например, указанное на рисунке значение правило преобразует строку вида **12--07--2008** в строку **12-07-2008** (удалит дублирование символа «–»);
· **Заменять строку на строку** — в данной таблице можно указать символы (символьные последовательности) в столбце **строку:** значения которых во время нормализации будут заменяться на значения из столбца на строку.

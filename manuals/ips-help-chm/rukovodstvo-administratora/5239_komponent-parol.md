# Компонент Пароль
В данном компоненте основные свойства унаследованы от компонента **Текстовое поле** , кроме того есть дополнительные свойства:
· **Использовать системный кодовый символ**. При значении **Разрешить** в элементе управления используется системный символ, отображаемый вместо символов пароля.
· **Кодовый символ**. Если задано значение данного свойства, то символы пароля будут закрыты данным символом.

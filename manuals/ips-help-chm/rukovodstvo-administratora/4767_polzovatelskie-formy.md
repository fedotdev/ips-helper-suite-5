# Пользовательские формы
Основным инструментом взаимодействия с пользователем в маршрутизаторе являются **пользовательские формы**. Это спроектированные дизайнером и связанные с определенными пользовательскими действиями наборы компонентов ввода и отображения, которые позволяют изменять или просматривать значения связанных с ними переменных. Пользовательские формы дают возможность пользователю управлять процессом с помощью вводимых в форму данных, значения которых тем или иным образом могут влиять на ход выполнения процесса. Использование пользовательских форм позволяет добиться большой гибкости процессов, делая их универсальными, меняющими свою логику в зависимости от входных данных.
Пользовательские формы могут быть назначены действиям, имеющим исполнителей, т.е. **Старт** , **Задача** и **Утверждение**. Если для действия **Старт** процесса назначена форма, то форму должен будет заполнить инициатор процесса. Если форма назначена для действия, приходящего в почту, то перед отправкой дальше исполнителю этого действия будет предложено ее заполнить.

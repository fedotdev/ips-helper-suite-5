# Данные
· **Дополнительные атрибуты**. Вызывает диалог создания дополнительных атрибутов, значения которых будут выводиться в поле элемента. Введите имя атрибута. Нажимайте **Добавить** , если атрибутов должно быть несколько.
· **Источник данных**. Позволяет создать ссылку на атрибут той категории информации, которая будет выбрана в поле **Тип ссылки**. В зависимости от типа выбранной ссылки необходимо указать также объект и атрибут.
Ссылка возможна на следующие данные:
· **Элемент документа** – ссылка на данные из собственно документа.
· **Объект системы** – ссылка на выбранный объект системы, либо на объект документа.
· **Подпись** – ссылка на подпись объекта системы или объекта документа.
· **Переносить на следующую страницу**. Данное свойство отображается для элемента **Таблица**. Позволяет переносить таблицу на следующую страницу.
· **Текст**. Позволяет ввести текст, который будет отображаться в поле элемента. 
· **Рисунок**. Данное свойство отображается для элемента **Контейнер** и позволяет выбрать изображение из файла.
· **Формат вывода**. Специализированное свойство только для элемента типа **Метка**. Позволяет задать формат вывода содержимого свойства текст.
Формат задаётся в виде строки вида: **Фиксированный текст {0} фиксированный текст _._** Часть строки **{0}** заменяется на значение свойства текст и вся строка выводится в метке вместо обычного текста.
Например, если поле настроено на вывод номера страницы, то можно оформить вывод номера так: **Лист {0}**. В результате для поля на странице 12 будет выведен текст **Лист 12**.
Для поля, которое ссылается на атрибут документа **Идентификатор версии объекта** , можно настроить формат вывода: **Идентификатор [{0}]**. В результате поле будет отображать текст **Идентификатор [123456]**.

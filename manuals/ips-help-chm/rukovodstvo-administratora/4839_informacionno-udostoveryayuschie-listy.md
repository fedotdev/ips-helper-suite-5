# Информационно-удостоверяющие листы
Удостоверяющие листы содержат информацию по документу, контрольную сумму файлов, представляющих документ, и список граф, в которых был подписан электронный документ с указанием фамилий подписавших и дат подписей.
В IPS удостоверяющие листы (УЛ) формируются на основании бланка УЛ (ГОСТ 2.051-2013). Бланк УЛ – это объект типа **Шаблоны документов (бланки)** определенной структуры с фиксированными идентификаторами для некоторых полей. При модификации оригинальных бланков УЛ, предоставляемых IPS, следует в целом сохранять структуру и фиксированные идентификаторы для возможности последующего корректного формирования УЛ. 
В системе можно настроить бланк для формирования УЛ (см. п. ).

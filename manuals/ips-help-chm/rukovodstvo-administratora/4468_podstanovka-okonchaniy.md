# Подстановка окончаний
В систему IPS встроен механизм, позволяющий формировать корректные окончания для значений, выраженных в единицах измерения. Например, генерировать значения вида **1 миллиметр** , **23 миллиметр _а_** , **27 миллиметр _ов_** там, где это требуется при выводе информации.
Настройка данного механизма осуществляется администратором системы в диалоговом окне **Настройка / Параметры IPS / Система / Подстановка окончаний** :
В списке **Язык** представлены все языковые варианты, поддерживаемые в настраиваемой базе данных IPS. Выбрав язык, например **Русский** , следует воспользоваться командой контекстного меню **Добавить слово** в дереве **Слова** :
В появившемся в дереве слов редакторе следует указать слово, для которого будут настраиваться окончания. Далее требуется добавить к слову список окончаний и правила формирования этих окончаний. Для этого воспользуйтесь командой **Добавить окончание** контекстного меню в дереве со словами:
В редакторе добавьте требуемое окончание. Следующим шагом требуется создать правило, на основании которого данное окончание будет применено к слову. Для этого выделите окончание в дереве и воспользуйтесь командой **Добавить правило** контекстного меню в дереве **Правила** :
Правило состоит из базовой операции и операции отношения:
**Базовая операция** – это действие, которое выполняется над значением, для которого генерируется слово с окончанием:
**Операция отношения** – это аргументы для базовой операции:
В примере сформировано следующее правило. Окончание **_а_** будет добавлено к слову **миллиметр** в том случае, если значение, для которого генерируется текст, находится в диапазоне от **2** до **4** :
В другом примере окончание **_ов_** будет добавлено к слову **миллиметр** в том случае, если значение, для которого генерируется текст, находится в диапазоне от **11** до **20** :
Примечание: 
_1) Допускается создавать несколько правила для формирования одного окончания. В этом случае между собой значения правил объединяются с помощью логической команды**И**._
_2) Выбор подходящего окончания по списку выполняется с помощью логической команды**ИЛИ**. Это означает, что по правилу (правилам) не подходит очередное окончание, система начинает проверять следующее. Процесс выполняется до тех пор, пока не будет найдено подходящее окончание. Если ничего не будет найдено, слово останется без изменений._
3) _Если необходимо сформировать одно и то же окончание для различных условий (логическое**ИЛИ**), следует добавить указанное окончание в слово столько раз, сколько есть условий. При этом для каждого окончания создается одно правило._
После формирования списка окончаний и правил их формирования можно осуществить проверку корректности генерации текстовых значений. Для этого выделите слово в дереве и нажмите кнопку **Проверка** :
При этом будет отображено окно с примерами сгенерированных по указанным правилам текстовых значений:

# Поведение шаблона
· **Обязательный элемент**. Позволяет указать, является ли элемент обязательным при создании документов на основании данного шаблона.
· **Последняя страница**. Позволяет указать последнюю страницу документа.
· **Следующая страница**. Позволяет указать шаблон для следующей страницы.

# Настройка свойств интегратора c AutoDesk Inventor
Выберите конфигурационный объект **Интегратор с Autodesk Inventor** и нажмите кнопку **Свойства**.
Рассмотрим подробнее доступные свойства интегратора:
· **Модели сборочных единиц**. Содержит список типов информационных объектов IPS, используемых для представления 3D-моделей сборочных единиц.
· **Модели деталей**. Содержит список типов информационных объектов IPS, используемых для представления 3D-моделей деталей.
· **Модели стандартных изделий**. Задает тип информационного объекта IPS, используемого для представления 3D-моделей стандартных изделий.
· **Чертежи сборочных единиц**. Содержит список типов информационных объектов IPS, используемых для представления чертежей сборочных единиц.
· **Чертежи деталей**. Содержит список типов информационных объектов IPS, используемых для представления чертежей деталей.
· **Суффиксы имен файлов чертежей.** Список суффиксов, которыми имена файлов чертежей отличаются от имен файлов моделей. Данный список используется для автоматического импорта чертежей при импорте файлов моделей.
· **Сохранять чертежи как документы**. При выключенной настройке чертежи сохраняются в виде файлового атрибута внутри моделей. Если же требуется согласование чертежей, то следует включить данную настройку (значение **Да**). В этом случае чертежи будут сохраняться в системе IPS в виде отдельных информационных объектов-документов.
· **Передавать в IPS информацию о допзаменах.** При включенной настройке допзамены оформляются в модели средствами PDM браузера и передаются в IPS при расширенном сохранении. При выключенном параметре допзамены оформляются средствами IPS и в модели не сохраняются.
· **Передавать в IPS типы связей между 3D моделями.** Включает режим, при котором интегратор определяет тип каждой связи между 3D-моделями и сохраняет его в атрибут **Тип связи в CAD-системе** , принадлежащий связи между документами. Включение этого режима снижает быстродействие интегратора.
· **Синхронизируемые атрибуты документов.** Содержит список атрибутов, синхронизируемых между документом в базе IPS и файлом этого документа.
· **Синхронизируемые атрибуты изделий.** Содержит список атрибутов, синхронизируемых между изделием в базе IPS и файлом документа, по которому выпускается изделие.
· **Непарные типы документов.** Содержит список типов документов, для которых не требуется автоматически создавать версию при создании версии изделия.

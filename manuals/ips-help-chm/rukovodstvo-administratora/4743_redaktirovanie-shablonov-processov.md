# Редактирование шаблонов процессов
Чтобы отредактировать существующий шаблон, воспользуйтесь одним из способов:
· Выберите пункт главного меню **Настройка/Редактор шаблонов процессов** , в открывшемся редакторе выберите необходимый шаблон из списка, двойным щелчком мыши или с помощью команды контекстного меню **Редактировать** откройте его для редактирования;
· В окне **Навигатора** (например, в ветке **Объекты маршрутизатора/Шаблоны процессов**) отметьте необходимый шаблон процесса и откройте его для редактирования двойным щелчком мыши или с помощью команды контекстного меню **Редактировать**.
При этом выбранный шаблон откроется в редакторе шаблонов процессов, где его можно отредактировать.
Внесите необходимые изменения и сохраните их, выбрав команду главного меню **Файл/Сохранить** или нажав кнопку панели инструментов**Сохранить**. 
Контекстное меню редактора процесса содержит основной набор команд, применяющихся к шаблонам, например, при помощи команды **Свойства** могут быть отредактированы основные параметры шаблона (**Название, Описание**), при помощи команды **Переменные** – его переменные и т.д. При правом клике на действии или связи будет показано контекстное меню выбранного действия или связи, при клике на пустой области будет вызвано контекстное меню шаблона/процесса.

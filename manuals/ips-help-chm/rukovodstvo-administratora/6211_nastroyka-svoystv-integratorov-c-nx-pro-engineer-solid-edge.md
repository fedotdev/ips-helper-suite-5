# Настройка свойств интеграторов c NX, Pro ENGINEER, Solid Edge, SolidWorks, Компас-3D
Выберите конфигурационный объект **Интегратор с NX** или другой из перечисленных CAD-систем и нажмите кнопку **Свойства**.
У всех интеграторов с указанными системами окно настроек идентичное, поэтому настройки будут рассмотрены на примере интегратора с NX.
Рассмотрим подробнее доступные свойства интегратора с NX:
**1\. Группы типов документов.**
· **Модели сборочных единиц**. Содержит список типов информационных объектов IPS, используемых для представления 3D-моделей сборочных единиц.
· **Модели деталей**. Содержит список типов информационных объектов IPS, используемых для представления 3D-моделей деталей.
· **Модели стандартных изделий**. Задает тип информационного объекта IPS, используемого для представления 3D-моделей стандартных изделий.
· **Чертежи сборочных единиц**. Содержит список типов информационных объектов IPS, используемых для представления чертежей сборочных единиц.
· **Чертежи деталей**. Содержит список типов информационных объектов IPS, используемых для представления чертежей деталей.
**2\. Сохранение изменений.**
· **Включить поддержку файлов __model.jt.** При включенной нстройке интегратор будет искать файлы __model.jt на диске и добавлять их к соответствующим документам NX в качестве дополнительных файлов.
· **Включить поддержку файлов IMViewer**. Свойство, которое позволяет включить или выключить возможность интегратора создавать или обновлять файлы IMViewer при сохранении изменений в документах CAD-системы.
· **Суффиксы имен файлов чертежей.** Список суффиксов, которыми имена файлов чертежей отличаются от имен файлов моделей. Данный список используется для автоматического импорта чертежей при импорте файлов моделей.
· **Сохранять чертежи как документы**. При выключенной настройке чертежи сохраняются в виде файлового атрибута внутри моделей. Если же требуется согласование чертежей, то следует включить данную настройку (значение **да**). В этом случае чертежи будут сохраняться в системе IPS в виде отдельных информационных объектов-документов.
· **Передавать в IPS информацию о допзаменах.** При включенной настройке допзамены оформляются в модели средствами PDM браузера и передаются в IPS при расширенном сохранении. При выключенном параметре допзамены оформляются средствами IPS и в модели не сохраняются.
· **Передавать в IPS типы связей между 3D моделями.** Включает режим, при котором интегратор определяет тип каждой связи между 3D-моделями и сохраняет его в атрибут **Тип связи в CAD-системе** , принадлежащий связи между документами. Включение этого режима снижает быстродействие интегратора.
· **Синхронизируемые атрибуты документов**. Список атрибутов, синхронизируемых между документом в базе IPS и файлом этого документа.
· **Синхронизируемые атрибуты изделий**. Список атрибутов, синхронизируемых между изделием в базе IPS и файлом документа, по которому выпускается данное изделие.
**3\. Завершение редактирования.**
· **Обновлять аутентичные .pdf-файлы для моделей.** Свойство, которое позволяет включить или выключить автоматическое обновление аутентичных .pdf-файлов при завершении редактирования моделей.
· **Обновлять аутентичные .pdf-файлы для чертежей.** Свойство, которое позволяет включить или выключить автоматическое обновление аутентичных .pdf-файлов при завершении редактирования чертежей.
**4\. Управление созданием версий.**
· **Непарные типы документов.** Содержит список типов документов, для которых не требуется автоматически создавать версию при создании версии изделия.
**5\. Нейтральные форматы документов.**
· **Нейтральные форматы для вставки в сборочные модели.** Свойство, в котором можно указать список так называемых нейтральных типов документов. 
Нейтральные документы не являются родными документами CAD-системы, но могут ею использоваться (например, **step** ; **parasolid** и др.). Вставленный документ нейтральный формат в сборочную модель, как правило, преобразуется в родной формат CAD-системы.
6\. **Поддержка чертежей 2D**.
· **Включить поддержку чертежей 2D.** Свойство, которое позволяет интегратору с Компас-3D обеспечивать двухсторонний обмен информацией с документами, не имеющими ассоциативных связей (не содержат ссылки на 3D модели) и создатавать по ним изделия.
· **Чертежи деталей 2D**. Содержит список типов информационных объектов IPS, используемых для представления чертежей деталей 2D.
· **Сборочные чертежи 2D.** Содержит список типов информационных объектов IPS, используемых для представления чертежей сборочных единиц 2D. Информация об изделии извлекается из файла спецификации, ассоциированого со сборочным чертежом.

# Персональный календарь пользователя
Система IPS предоставляет возможность использовать персональный календарь пользователя, календарь подразделения и системный календарь. Персональный календарь пользователя можно создать на основе календаря подразделения или системного календаря. 
Например, создан календарь подразделения, в состав которого входит пользователь, на которого следует построить персональный календарь. Таким образом, при создании персонального календаря пользователя осуществляется автоматический поиск подразделений, в которые пользователь входит. При создании персонального календаря на основе системного, используются атрибут **Календарь** , который находится у пользователя.
Примечание: выбрать календарь, на основе которого будет построен персональный календарь пользователя, можно автоматически либо вручную, для этого следует нажать кнопку .
При условии, что пользователь не относится ни к одному подразделению (организации), либо если у подразделения (организации) нет определенного календаря, то персональный календарь пользователя по умолчанию строится на основе стандартной рабочей недели. Если у подразделения (организации), к которым относится пользователь, в атрибутах определен календарь, то он будет использован при построении персонального календаря пользователя.
Примечание: система IPS предоставляет возможность принудительно привязать к пользователю определенный календарь.
**Внимание!** Спецпериоды текущего календаря являются приоритетными и перекрывают собой стандартные дни и спецпериоды календаря, на основе которого строится данный календарь.
Для того, чтобы открыть редактор персонального календаря, следует:
1\. Выбрать пользователя в рабочем окне **Навигатора** по пути **Объекты / Пользователи**.
2\. Открыть карточку пользователя с помощью команды **Свойства (Карточка)** из контекстного меню или воспользоваться горячей клавишей **[F4]**.
3\. В карточке выбрать закладку **Редактор календаря пользователя**.

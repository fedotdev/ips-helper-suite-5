# Ввод функций (часть 2)

Чразд(Н,С) | С | Собрать строку через разделитель Позволяет преобразовать набор Н в строку с перечислением параметров через заданный разделитель С. Пример: Чразд({10,30,35,40}, ";") = "10; 30; 35; 40" 
Класс(Ц,Ц) | Л | Классифицировать объект по папке Функция запускает классификатор. Первым параметром задается Идентификатор версии объекта, для которого необходимо запустить классификатор. Вторым - Идентификатор версии классификатора. После обрабатывания функции будет выдано окно, в котором необходимо подтвердить действие по переклассификации объекта. После этого обозначение объекта изменится в соответствии с заданным в классификаторе. Результат выполнения функции будет представлен как логическое значение True – при успешном выполнении переклассификации объекта и False – при ошибке. 
ra(П,Н) | П | Функция ra2 с коэфициентом 0.7 Функция аналогична функции ra2, только с фиксированным коэффициентом 0.7. 
ra2(П,Н,П) | П | Функция ra2 Функция позволяет задать правило округления значения П до ближайшего значения массива по заданному коэффициенту округления. Пример: Необходимо округлить число 43 об/с до ближайшего значения из массива: 30 об/с, 40 об/с, 64 об/с. Используя коэффициент округления 0,1. При стандартном округлении без коэффициента значения от 40 об/с до 52 об/с будут приведены к значению 40 об/с, а значения от 52 об/с до 60 об/с будут приведены к значению 60 об/с. При использовании коэффициента округления точкой изменения стороны округления является не середина диапазона между значениями набора (коэффициент 0,5), а ширина интервала умноженная на заданный коэффициент. В нашем случае при использовании коэффициента 0,1 это значение будет 40+(64-40)*0,1=42,4. Значения от 40 об/с до 42,4 об/с будут приведены к значению 40 об/с, а значения от 42,4 об/с до 60 об/с будут приведены к значению 60 об/с. 
КЕИзм(Е) | Ц | Код единицы измерения Функция возвращает идентификатор единицы измерения Пример: ЕИ_Коэф(23 см) = 2336. 
ИМЯ_ТД(Ц) | С | Имя типа документа Выводит наименование типа объекта (не только документа) по его идентификатору. Пример: ИМЯ_ТД(1075)=Операция. 
Минус(П) | С | Строковое представление со словом “минус” Преобразовывает вещественное и целое значение со знаком “-” в строку со словом “минус”. Пример: Минус(-356,536) = минус 356,536 
Формт(Н,С) | С | Форматирование набора Преобразовывает вещественное и целое значение в наборе со знаком “-” в строку со словом “минус”. Во втором параметре передаются опции форматирования. Пока поддерживается только опция "m", которая заменяет минусы на слово "минус". Пример: Формт(-12,5 об/мин, 16 об/мин, -20 об/мин, 25 об/мин, "m") = "минус 12,5 об/мин, 16 об/мин, минус 20 об/мин, 25 об/мин" 
ЕИ_Коэф(Е) | П | Коэффициент приведения к базовой единице Позволяет получить коэффициент приведения к базовой единице измерения для единицы измерения атрибута, подаваемого на вход функции. Пример: ЕИ_Коэф(23 см) = 10, ЕИ_Коэф(23 мм) = 1. 
ЗамС(С,С,С) | С | Заменить подстроку в строке Позволяет произвести замену одной подстроки в строке на другую Пример: ЗамС ("Притупить осттрые кромки", "осттрые", "острые") = "Притупить острые кромки" 
trim(C) | C | Убрать нечитаемые символы в начале и конце В начале и конце строки убирает пробелы, символы табуляции и перевода строки. Пример: trim(" Притупить ") = "Притупить" 
РазН(Н,Ц) | Ц | Размер набора по заданному измерению Позволяет получить количество элементов в наборе Н. Вторым параметром передается тип набора (0 - одномерный, 1 - двумерный). Поскольку большинство наборов в IPS одномерные, второй параметр будет равен 0. Пример: РазН({20,30,50,60,80}, 0) = 5 
СортН(Н,А) | Н | Сортировать набор по значениям атрибута Для набора Н у которого параметры являются ссылочными объектами позволяет отсортировать параметры набора по указанному атрибуту А. Возвращаемое значение будет набор, отсортированный по заданному атрибуту. Пример: Набор состоит из ссылок на объект Деталь {536-5658246 Гайка, 537-8956234 Болт, 538-8546493 Винт, 539-7514216 Шайба} При использовании формулы :СортН(<Набор>, <Обозначение>) Результат: {536-5658246 Гайка, 537-8956234 Болт, 538-8546493 Винт, 539-7514216 Шайба} При использовании формулы :СортН(<Набор>, <Наименование>) {537-8956234 Болт, 538-8546493 Винт, 536-5658246 Гайка, 539-7514216 Шайба} 
ФормП(С,П) | | Форматировать число с плавающей точкой Позволяет отформатировать входное число с плавающей точкой П согласно заданного спецификатора Microsoft С. Список доступных спецификаторов и принцип их работы можно узнать на сайте Microsoft в разделе Standard numeric format strings. Например, спецификатор "P" позволяет получить число, умноженное на 100 и отображенное со знаком процента, спецификатор "С" позволяет получить число со значением валюты. Пример: ФормП("P", 56) = 5 600,00 %, ФормП("C", 56) = 56,00 ₽. 
sum(A) | П | Сумма заданного атрибута по объектам поиска Позволяет суммировать атрибуты объектов, найденные по правилу поиска объектов. Пример: <Нормирование на операцию>.Норма основного времени = sum(<Нормирование на переход>.Норма основного времени). Т.е. в данном случае, находясь в контексте операции, необходимо будет создать дополнительно правило поиска объекта нормирование на переход от объекта нормирования на операцию. 
min(A) | П | Минимум заданного атрибута по объектам поиска Позволяет найти минимальное значение из атрибутов объектов, найденных по правилу поиска. 
max(A) | П | Максимум заданного атрибута по объектам поиска Позволяет найти максимальное значение из атрибутов объектов, найденных по правилу поиска. 
Разб(С,С) | Н | Разбить строку по разделителю Позволяет разбить строку С по разделителю С. Пример: Разб("R6, R8, R9, R11, R12", ".") = {R6 R8 R9 R11 R12}. 
ceil(П) | П | Ближайшее не меньшее целое Позволяет округлить вещественное число до ближайшего большего целого. Пример: 0,1 = 1, 3,005=4, 4,67=5. 
ФормД(С,Д) | С | Форматировать дату Позволяет привести значение атрибута типа Дата – Д, к заданному формату даты и времени. Пример: ФормД("yy-MM-dd", <Дата создания объекта>) = 24-04-30. ФормД("dd:MM:yy", <Дата создания объекта>) = 30:04:24. 
Экспертная система позволяет регистрировать пользовательские функции, если возникает такая необходимость. Это описано **в п. 5.1 Функции для формул в «Руководстве программиста. Модули расширения»**. При успешной регистрации пользовательских функций они добавляются в список функций, чтобы их можно было выбрать.

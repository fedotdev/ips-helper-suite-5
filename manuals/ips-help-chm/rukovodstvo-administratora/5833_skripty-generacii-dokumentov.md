# Скрипты генерации документов
**Скрипты генерации документов** предназначены для определения последовательности вывода информации из техпроцесса или изделия на бланк документа (шаблона) в нужном порядке. Каждый скрипт генерации документа связан с шаблоном документа, на основе которого создаются документы.
При создании скрипта генерации документов будет показан диалог выбора шаблона документа.
Далее в новом окне необходимо ввести наименование скрипта.
После этого откроется редактор скрипта генерации документов.

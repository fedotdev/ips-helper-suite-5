# Настройки для подразделений
Списком внутренних канцелярий предприятия служит список подразделений этого предприятия, у которых включен флаг **Собственная канцелярия**. По умолчанию подразделения не используют собственную канцелярию.
Справочник подразделений настраивается в **Навигаторе** по пути **Информационное пространство /Объекты /Организационные единицы /Подразделения**. В состав подразделения также должны быть включены группы пользователей, либо пользователи из этого подразделения. 
Также на закладке **Настройки канцелярии** для подразделения можно задать шаблон автоматической генерации внутреннего регистрационного номера. Настройки шаблона аналогичны настройкам, описанным в п. .

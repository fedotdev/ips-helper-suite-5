# Работа с редактором форм
Редактирование форм осуществляется в специальном редакторе, который вызывается из окна редактирования шаблона процесса с помощью команды **Редактировать форму** из контекстного меню пиктограммы действия. Принципы работы с редактором форм подробно описаны в п. . Редактор форм, открытый в контексте редактора шаблонов процессов, имеет несколько особенностей:
· Недоступны команды привязки формы, так как форма привязывается автоматически к действию, для которого она назначена.
· Диалог выбора атрибутов, к которым привязываются компоненты редактирования, заменяется на диалог выбора переменных текущего шаблона процесса.
· В палитру компонентов добавляется группа дополнительных компонентов **Компоненты маршрутизатора** , которая содержит набор компонентов, предназначенных специально для работы со специализированными переменными маршрутизатора. Это компоненты:
− **Дерево пользователей**. Позволяет выбрать пользователей или группы пользователей из списка. Если атрибут **Входная переменная** заполнен, то выбор производится из списка пользователей, хранящемся в этой переменной. Результат выбора пользователя записывается в переменную типа **Список пользователей** , указанную как **Выходная переменная**.
− **Список пользователей**. Работает аналогично дереву пользователей, за исключением того, что пользователи отображаются не в виде дерева, а в виде выпадающего списка; множественный выбор не возможен.
− **Групповой переключатель**. Позволяет пользователю выбрать нужный вариант из списка, заданного в переменной **Список строк**. Результат записывается в выходную переменную в виде порядкового номера выбранного варианта.

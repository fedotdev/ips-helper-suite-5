# Ввод текста
Текстовыми элементами являются **Редактор текста** , **Метка** и **Таблица**. Для них ввод текста возможен с клавиатуры в поле свойства **Текст** на панели **Свойства**. Введенный текст отображается и в поле элемента. Для элементов **Редактор текста** и **Таблица** ввод текста также возможен с клавиатуры непосредственно в поле этих элементов.
Существует возможность вставлять в поле элемента уже существующие фрагменты текста с помощью буфера обмена. Для этого необходимо выделить текст и применить команду **Копировать** или **Вырезать** его контекстного меню, затем установить текстовый курсор в поле элемента или в поле свойства **Текст** и применить команду **Вставить** его контекстного меню.
Если для свойства элемента **Только для чтения** установлено значение **Да** , то пользователь не сможет ввести текст непосредственно в поле этого элемента. Для ввода текста необходимо изменить значение этого свойства на **Нет** либо ввести текст в поле свойства **Текст** на панели **Свойства**.

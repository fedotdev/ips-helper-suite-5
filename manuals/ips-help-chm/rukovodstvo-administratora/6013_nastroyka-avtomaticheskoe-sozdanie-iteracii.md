# Настройка Автоматическое создание итерации
Настройка автоматической итерации выполняется в диалоге **Настройка / Параметры IPS / Система / Итерации / Автоматическое создание итерации.**
· **Разрешить автоматическое создание итерация при удалении объекта** – это параметр, который включает/выключает возможность автоматического создания итераций в момент удаления объектов. По умолчанию параметр выключен.
· **Схема создания итерации** – это параметр в виде списка задает схему создания итерации в виде элементов **Тип Связи** \+ **Тип Объекта.**
Для создания схемы создания итерации следует:
1\. Справа, на боковой панели, необходимо нажать кнопку .
2\. В открывшемся окне **Выбор связи** следует заполнить строки: **Тип связи** и **Тип объекта**. Для этого необходимо воспользоваться мультикнопкой 
3\. При завершении выбора следует нажать на кнопку .

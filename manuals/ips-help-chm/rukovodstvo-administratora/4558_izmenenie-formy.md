# Изменение формы
По умолчанию, формы редактирования можно редактировать после взятия на изменение. Для этого используется команда **Взять на изменение**. Команда **Редактировать** выполняет несколько действий – берет форму на изменение и открывает ее в редакторе формы в новом окне. Чтобы изменения формы вступили в силу, ее надо сохранить и выполнить для нее команду **Завершить изменения**.
Внешний вид IPS в режиме редактирования формы (объект с формой **Проекты** открыт в новом окне, взят на изменение):
Панель **Свойства** позволяет просмотреть/изменить свойства элементов формы редактирования. Панель **Палитра компонентов** содержит список элементов управления, которые можно размещать на форме.

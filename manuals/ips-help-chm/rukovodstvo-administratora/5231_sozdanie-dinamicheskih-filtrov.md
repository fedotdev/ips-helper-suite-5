# Создание динамических фильтров
Для создания динамического фильтра следует:
1\. В дереве **Навигатора** выбрать элемент **Журнал событий** и нажать кнопку , которая расположена на панели рабочего окна закладки **События**.
2\. В открывшемся диалоговом окне **Редактор фильтра журнала событий** следует настроить необходимые условия поиска записей журнала.
3\. Для завершения создания фильтра следует нажать на кнопку .
Для применения динамического фильтра к общему списку событий следует выбрать фильтр из выпадающего списка строки **Фильтр событий** , которая расположена на панели с инструментами.
4\. Для редакции выбранного фильтра следует нажать кнопку .
5\. В открывшемся редакторе следует внести необходимые изменения, а затем нажать на кнопку .
6\. При необходимости удалить действующий фильтр следует нажать кнопку .
7\. В открывшемся диалоговом окне следует подтвердить свое действие с помощью кнопки .
Примечание: редактор динамического фильтра для журнала событий имеет расширенный вариант условий для настраиваемых параметров.

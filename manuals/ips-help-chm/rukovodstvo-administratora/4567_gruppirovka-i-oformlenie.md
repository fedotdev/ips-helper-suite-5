# Группировка и оформление
· **Группа**. Служит для визуальной группировки элементов, их выравнивания или отображения заданного текста.
· **Панель**. Визуальный компонент, который может являться контейнером для других компонентов и может служить для группировки компонентов, их выравнивания или отображения заданного текста.
· **Закладки**. Используется для размещения компонентов, объединенных по смыслу.
· **Разделитель**.
· **Изображение**. Компонент отображает изображение компоненты из файла с расширением.
· **Предварительный прсмотр**. Компонент отображает содержимое атрибута **Превью** в форме.
После проектирования формы нужно связать ее с каким-либо типом документа или объекта, а также назначить, для каких пользователей или групп пользователей эта связь будет действовать (см. раздел ).

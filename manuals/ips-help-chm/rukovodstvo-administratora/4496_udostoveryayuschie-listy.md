# Удостоверяющие листы
Для настройки параметра **Удостоверяющие листы** необходимо открыть команду **Параметры IPS** из меню **Настройка** панели инструментов системы IPS. В открывшемся окне выбрать параметр **Удостоверяющие листы** из пункта **Система**.
**Внимание!** Настройки параметра проводятся только администратором системы.
Настройки параметра осуществляются с помощью следующих параметров:
· **Атрибут для графы 10** и **Атрибут для графы 9.** Данные параметры необходимы для настройки двух граф по ГОСТ 2.051-2013. В IPS можно настроить заполнение данных граф значениями атрибутов документа, на который выпускается удостоверяющий лист. 
Примечание: при необходимости вывода дат изменения и размеров файлов следует настроить атрибуты граф 9 и 10. Дата изменения файла в файловом шкафу и Размер файла в файловом шкафу соответственно.
· **Бланк удостоверяющего листа.** Данный параметр позволяет указать шаблон бланка удостоверяющего листа. Указанный шаблон будет использоваться при формировании документов по умолчанию.
· **Выводить информацию о подписях**. Данный параметр позволяет системе выводить информацию в поле подписи для граф, в которых проставлены подписи, в соответствии с настройками **Параметры IPS / Система / Электронные подписи** , параметры **Способ отображения, Текст для отображения актуальных квалифицированных ЭП, Текст для отображения актуальных простых ЭП, Текст для отображения неактуальных квалифицированных ЭП, Текст для отображения неактуальных простых ЭП**.
· **Выводить информацию об ИО в УЛ.** Параметр, который позволяет отображать информацию об исполняющих обязанности в УЛ. Если настройка включена, то в графе фамилии подписавшего будет отображаться информация следующим образом: [значение атрибута **Подписал**] + [приставка **и.о.**] + [значение атрибута **Исполняющий обязанности**]. 
Примечание: вышеописанная формула вывода подписи работает только при условии, что у объекта подписи есть атрибут **Исполняющий обязанности (guid=cadd91f5-306c-11d8-b4e9-00304f19f545)** и он заполнен.
· **Выводить только актуальные подписи**. Данный параметр предназначен для вывода в удостоверяющий лист только актуальных подписей. 
Примечание: следует иметь в виду, что при включенном режиме параметра **Выводить только актуальные подписи** на этапе формирования листа производится проверка подписей, а это может значительно увеличить время подготовки удостоверяющего листа.
· **Имя папки удостоверяющих листов.** Данный параметр позволяет присвоить необходимое наименование папке при сохранении по команде **Сохранить на диск** из приложения **Навигатор**
· **Порядок сортировки граф**. Параметр позволяет настроить особую сортировку граф. При установленном значении **По умолчанию** сначала выводятся графы с подписями, а за ними, если настроено в диалоге формирования УЛ, графы без подписей. При значении **По описанию графы** графы сортируются по наименованию графы для подписи, а при значении **По значению графы** сортировка производится по идентификатору графы для подписи независимо от наличия подписей в графах.

# Параметры сервиса
Основные настройки сервиса:
· **Перечень серверов приложений IPS** – настройка, с помощью которой добавляется автоматически адрес, указанный при установке и используемый для авторизации. При наличии нескольких экземпляров серверов приложений – необходимо их добавить вручную. Значок слева от адреса указывает на текущее состояние подключения к серверу.
· **Учетная запись** – специальная учетная запись, которую будет использовать сервис DVS для авторизации при получении файлов.
· **Уведомлять о недостатке свободного места** – настройка, которая при достижении заданного значения свободного места на диске будет направляться уведомление администраторам по почте IPS о необходимости принятия соответствующих мер по его расширению.
· **Минимальный размер файла для кэширования** – при установке значения больше 0 в процессе запроса файла в клиентском приложении будет учитываться его размер, т.е. файл из кэширующего сервера будет получаться только в случае превышения указанного значения.
· **Условия фильтрации для кэширования** – настройка, которая позволяет задать дополнительные условия, которые будут учитываться при запросе файла в клиентском приложении. Условия могут быть заданы по нескольким параметрам, включая их комбинации с помощью группировок «**И/ИЛИ** ». Каждый параметр может быть указан один раз.
· **Расписание синхронизации кэша** – период времени, в который будет выполняться синхронизация файлов в кэше (очистка неиспользуемых, обновление уже загруженных и дозагрузка новых файлов, удовлетворяющих настройкам сервиса).
· **Время жизни файлов/блобов в кэше с момента зачитки/последнего обращения** – интервал времени, по истечении которого файл может быть удален, если к нему больше не поступало обращений со стороны клиентского приложения.
· **Настройка логов**.
− по кнопке **Скачать** на группе **Логи** можно вывести на экран список файлов логов и скачать любой из них;
− **уровень лога** – определяет перечень сообщений, которые будут попадать в логи;
− **интервал, через который лог будет перенесен в новый файл** – период, по истечении которого будет формироваться новый файл лога;
− **ограничение размера файла лога** – после достижения заданного значения будет создан новый файл лога;
− **максимальное количество файлов лога** – предельное количество файлов лога. Если количество файлов лога превысит указанное значение, то будет удален самый старый файл.

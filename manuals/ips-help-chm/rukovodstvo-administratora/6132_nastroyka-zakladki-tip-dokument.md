# Настройка закладки Тип «Документ»
Для настройки поддерживающих расширений интеграторов с приложениями, а так же для настройки шаблона объектов-прототипов следует перейти на закладку **Тип «Документ»** в **Конфигураторе базы данных**.
На рисунке ниже представлены объекты типа **Документы LibreOffice** с открытой закладкой **Тип «Документ»** куда будут добавлены тип файла для документов и дополнительные файлы. 
Система IPS позволяет дополнять список шаблонов, а администратор может разработать желаемый шаблон, по которому буду создаваться новые документы, и добавить его в список объектов-прототипов.
Для изменения списка **Объект-прототип** необходимо воспользоваться командами, расположенными в поле **Прототипы** , данное поле выделено на рисунке ниже.
В поле **Прототипы** доступны следующие команды:
· – команда, которая позволяет добавить шаблон файловых объектов.
При нажатии на кнопку откроется окно, в котором следует заполнить поле **Наименование** и указать путь к файлу с помощью кнопки , расположенной в поле **Файл**.
Примечание: при необходимости можно изменить **Тип объекта** с помощью кнопки . В открывшемся окне следует выделить необходимый тип объекта и нажать кнопку .
Примечание: поле **Шаблон имени файла** не обязательно для заполнения, так как система IPS способна генерировать уникальное наименование файла для каждого нового документа. 
· – команда, которая позволяет добавить в список шаблоны, которые используются другими файловыми объектами.
Для использования таких шаблонов следует вызвать команду и в открывшемся окне выбрать прототип для файлового объекта.
Примечание: для обновления списка прототипов следует воспользоваться кнопкой 
Для завершения выбора объекта-прототипа следует нажать кнопку .
· – команда, которая позволяет изменить данные созданного шаблона.
Примечание: поля **Наименование** , **Файл** и **Шаблон имени файла** доступны для изменения.
При необходимости изменить объект-прототип следует выделить его и вызвать команду . Для завершения изменений следует нажать кнопку .
· – команда, которая позволяет удалить необходимый шаблон из списка объектов-прототипов.
Для удаления из списка объекта-прототипа следует выделить его и нажать кнопку .

# Фильтрация журнала событий
**Журнал событий** может содержать огромное количество записей, что зачастую препятствует поиску необходимых данных в журнале и замедляет работу системы при считывании информации. Система IPS предоставляет возможность использовать фильтры, позволяющие ограничивать списки событий, согласно условиям, указанным в фильтрах. Созданные фильтры отображаются в виде дочерних элементов журнала событий. Их настройки являются индивидуальными для каждого пользователя IPS. Система позволяет создать два важных и невзаимосвязанных типа фильтров – это **Именные** и **Динамические фильтры**.
**Именной фильтр** – это объект дерева **Навигатора** , выбор которого предоставляется возможность открыть **Журнал событий** с уже отфильтрованными записями.
**Динамический фильтр** – это дополнительный инструмент к общему списку записей журнала событий.
**Внимание!** Все фильтры являются персональными, поэтому они доступны только тому, кто их создавал.
Закладка **Параметры фильтра** , показанная на рисунке выше, является редактором фильтра журнала событий, в котором осуществляется настройка параметров для фильтрации событий. Описание параметров представлено ниже:
**Тип событий** – этот параметр позволяет указать тип события, относительно которого осуществляется фильтрация списка.
**Начало события** – этот параметр позволяет указать дату начало события, относительно которого осуществляется фильтрация списка.
**Завершение события** – этот параметр позволяет указать дату окончания события, относительно которой осуществляется фильтрация списка.
**ID события** – этот параметр позволяет ввести идентификатор события, относительно которого осуществляется фильтрация списка.
**Вид действие** – этот параметр позволяет выбрать действие, относительно которого связаны искомые события.
**Имя объекта** – этот параметр позволяет ввести текст или часть текста, содержащегося в имени объекта, относительно которого осуществляется фильтрация списка.
**Пользователь** – этот параметр позволяет выбрать пользователя, инициировавшего искомые события, относительно которого осуществляется фильтрация списка.
Примечание: фильтрация по параметру **Пользователь** можно использовать для контроля деятельности конкретного пользователя в системе.
**ID версии объекта** – этот параметр позволяет ввести идентификатор версии объекта, относительно которого осуществляется фильтрация списка.
**ID связи** – этот параметр позволяет ввести идентификатор связи, относительно которого осуществляется фильтрация списка.
**Комментарии** – этот параметр позволяет отфильтровать список по тексту, содержащемуся в колонке «Комментарий» у записей журнала событи
**Категория** – этот параметр позволяет выбрать категорию информации, относительно которой осуществляется фильтрация списка.
Примечание: чаще всего события в журнале относятся либо к версиям объектов, либо к связям между объектами.
**ID категории** – этот параметр позволяет ввести идентификатор категории, относительно которого будет вестись поиск.
Примечание: в зависимости от категории, к которой относится событие, в качестве идентификатора категории может выступать идентификатор версии объекта, идентификатор связи, идентификатор атрибута, типа объектов и т.п.
**Имя компьютера** – этот параметр позволяет ввести имя компьютера, с которого было инициированы искомые события, относительно выбранного значения осуществляется фильтрация списка.
**Внимание!** Каждое условие сопровождается выбором соответствующего оператора поиска указанного значения.
Рассмотрим два варианта создания фильтров для поиска зарегистрированных событий.

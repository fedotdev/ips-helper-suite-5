# Поиск и удаление дубликатов объектов
Команда контекстного меню **Объединить объекты** доступна роли **Администратор** в случае, если в рабочей области **Навигатора** выделено более одного объекта одинакового типа, причем ни один объект не должен быть взят на изменение. При вызове команды откроется окно для выбора версии объекта, в которую нужно перекинуть все ссылки и связи указанных объектов. 
Примечание: система не позволяет удалять базовые версии объектов при наличии небазовых.
Команда контекстного меню **Поиск одинаковых объектов** доступна в дереве **Навигатора** для типов объектов. При запуске команды на выполнение система запрашивает атрибут, по которому будет осуществляться сравнение объектов данного типа. Далее производится поиск объектов с одинаковым значением выбранного атрибута среди объектов данного и дочерних нелокальных типов объектов. В открывшейся форме будет показана первая найденная группа одинаковых объектов.
При нажатии на кнопку **Удалить** отмеченные объекты будут удаляться, все ссылки и связи, идущие к этим объектам, будут перекинуты на оставшийся объект (на первый попавшийся, если невыделенных объектов будет несколько) и будет показана следующая группа одинаковых объектов. Если выделены все записи, то будет вызвана форма удаления для всех объектов.
По кнопке **Пропустить** никаких действий над объектами производиться не будет, а пользователю будет предлагаться следующая группа одинаковых объектов.
Кнопка **Прервать** закрывает диалог без поиска следующих объектов.
Кнопка **Ометить все объекты** выделяет все объекты.
Кнопка **Снять все отметки** снимает выделение со всех объектов.
Включенный переключатель **Группировать по версиям** говорит о том, что для всех версий одного объекта с одинаковым значением искомого атрибута будет показана только одна версия, подобранная по текущим правилам подбора (или базовая, или первая попавшаяся, если в найденной группе версий не найдено версии по текущим правилам подбора или базовой версии). При включенном переключателе действия по удалению показанной версии означают действие над всеми версиями объекта, которые представлены подобранной версией. Если же в диалоге принимается решение оставить сгруппированную версию - именно на нее будут перекинуты связи с удаляемых объектов.

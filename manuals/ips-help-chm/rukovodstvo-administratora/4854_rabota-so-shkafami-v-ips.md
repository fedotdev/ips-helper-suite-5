# Работа со шкафами в IPS
В системе есть возможность назначить файловый шкаф для уровней продвижения, архивов, пользователей и групп пользователей путем назначения атрибута **Файловый шкаф** или для типов объектов путем назначения файловому шкафу атрибута **Глобальные идентификаторы типов объектов**.
При пересечении этих настроек, приоритет их учета следующий:
· **Архив**.
· **Уровень продвижения**.
· **Типы объектов**.
· **Пользователь**.
· **Группа пользователей**.
Примечание: если в системе IPS настроен отдельный файловый шкаф для итераций, атрибут **Файловый шкаф для хранения итераций** для ИО типа **Файловый шкаф** , то эта настройка является приоритетной по отношению к другим уровням.

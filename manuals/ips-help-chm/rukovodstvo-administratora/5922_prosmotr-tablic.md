# Просмотр таблиц
· **Учитывать права видимости записей при просмотре таблиц:** Данный параметр дает возможность скрыть записи, для которых текущему пользователю правами доступа запрещена видимость.
Примечание: изменить значение может только пользователь с ролью **Администратор**.
· **Скрывать пустые колонки:** Данный параметр позволяет не отображать пустые колонки при просмотре таблицы.
· **Сохранять состояние колонок:** Данный параметр позволяет автоматически сохранять состояние колонок (положение, размеры, видимость, сортировку) при переключении между таблицами.
· **Сохранять условия фильтра:** Данный параметр позволяет автоматически сохранять условия фильтра таблицы при переключении между таблицами.
· **Сохранять условия пользовательского фильтра:** Данный параметр позволяет автоматически сохранять условия пользовательского фильтра таблицы при переключении между таблицами.

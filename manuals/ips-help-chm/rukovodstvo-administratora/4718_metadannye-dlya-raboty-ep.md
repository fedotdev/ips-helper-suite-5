# Метаданные для работы ЭП
Работа механизма ЭП в системе IPS использует следующие метаданные и их настройки:
1\. В списке атрибутов должен быть атрибут **Дата модификации содержимого объекта**. С его свойствами можно ознакомиться на рисунке:

Атрибут должен быть назначен типам объектов, которые требуется подписывать, например:
Данный атрибут отличается от обязательного атрибута **Дата модификации объекта** тем, что последний обновляется при любом изменении объекта и любого из его атрибутов. А на изменение атрибута **Дата модификации содержимого объекта** действует настройка **Влияет на дату модификации содержимого объекта** для атрибутов, назначенных типу объекта и его допустимых типов связей. Если настройка установлена в **да** , то любое изменение атрибута **Файл** будет изменять значение атрибута **Дата модификации содержимого объекта**. В противном случае атрибут обновляться не будет, т.е. считается, что содержимое объекта не изменялось.
2\. В списке атрибутов должен быть многозначный атрибут **Графа для подписей**. Со свойствами атрибута можно ознакомиться на рисунке:

**Внимание!** Следует избегать изменения поля **Значения** у допустимых значений атрибута – это может привести к потере имеющихся подписей. Если используется несколько баз данных с обменом информацией подписанными объектами, то необходимо, чтобы в таких базах списки допустимых значений атрибута **Графа для подписей** были идентичными.

5\. Для автоматического заполнения атрибутов **Разработал** , **Утвердил** , **Т.контр.** и пр. у подписываемых объектов необходимо соблюдение следующих условий:
− полное или краткое наименование заполняемого атрибута должно совпадать с наименованием соответствующей графы для подписи;
− в момент подписания объекта данный атрибут должен быть доступен для изменения системой. Это значит, что для типов объектов, изменяемых через выпуск рабочей копии, должен быть включен флаг **Возможна модификация без взятия на изменение** у всех атрибутов, которые должны заполняться в момент подписания объекта. Также у этих атрибутов должен быть выключен флаг **Влияет на дату модификации содержимого объекта**(иначе их заполнение приведет к устареванию всех подписей данного объекта);
− следует учитывать, что заполнение данных атрибутов не означает автоматического заполнения штампов подписанных документов. Автоматическое заполнение штампов работает только для документов, обрабатываемых встроенными редакторами документов IPS – конструкторских спецификаций, извещений об изменениях и т.п. 6\. Для работы ссылки на атрибут элемента документа или объекта системы в шаблонах конструкторских документов следует выбрать **Информационное пространство / Объекты / Настройки системы / Шаблоны документов / (необходимый шаблон документа)**. На примере показан шаблон групповой спецификации формы Б.
Выбрать ячейку **Дата** , а в свойствах – поле **Источник данных** и вызвать диалоговое окно **Ссылка на атрибут элемента документа или объекта** , см. рисунок ниже.
В открывшемся окне следует настроить параметры следующим образом:
− выбрать режим **На подпись** ;
− с помощью выпадающего списка в строке **Тип ссылки** необходимо выбрать **На подпись объекта документа** ;
− в строке **Атрибут:** следует выбрать **Дата подписи** ;
− в строке **Графа подписи:** следует выбрать необходимую должность.
7\. Настройка копирования ЭП при создании версии объекта выполняется в диалоге **Настройка / Параметры IPS / Система / Электронные подписи / Общие настройки**.
8\. При подписании, если объект уже имеет актуальную подпись в выбранной графе, то при включенной настройке **Общие настройки / Проверять наличие актуальной подписи в выбранной графе при подписании** будет показано предупреждение о том, что объект уже подписан в данной графе и повторного подписания не произойдет. Если настройка выключена, то у объекта в одной графе будут две актуальные подписи, поставленные разными пользователями.

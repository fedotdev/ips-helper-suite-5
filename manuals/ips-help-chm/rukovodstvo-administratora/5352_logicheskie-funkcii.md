# Логические функции
| **Функция** | **Тип возвращаемой переменной** | **Описание** |
| --- | --- | --- |
| IIF(bool condition, expression1, expression2) IF(bool condition, expression1, expression2) | любой | Если значение condition равно Истина, возвращается выражение expression1, иначе expression2. Аргументы expression1 и expression2 должны быть одного типа, тип может быть любым. |
| AND(boolean, boolean, …) | логический | Если значения всех аргументов равны Истина, возвращает Истина; если хотя бы один из аргументов Ложь, то возвращает Ложь. |
| OR(boolean, boolean, …) | логический | Возвращает Истина, если любой из аргументов Истина; возвращает Ложь, если все аргументы равны Ложь. |
| IsNull(object) IsDBNull(object) | логический | Определяет, является ли заданное выражение DBNull. |

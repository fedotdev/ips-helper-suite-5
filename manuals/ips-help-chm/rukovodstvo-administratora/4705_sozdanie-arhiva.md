# Создание архива
Для создания архива выберите в дереве объектов архив, в составе которого Вы хотите создать новый архив (для создания архива главного уровня выберите в дереве папку **Архивы**). Затем выполните команду контекстного меню **Создать/Архив** или **Создать/ Архив по прототипу**:
В появившемся мастере по созданию новых объектов выберете требуемый тип архива, затем на следующей странице мастера создания архива заполните требуемые поля и нажмите кнопку.
После создания нового архива требуется выполнить настройку его структуры, контроля подписей и прав доступа.

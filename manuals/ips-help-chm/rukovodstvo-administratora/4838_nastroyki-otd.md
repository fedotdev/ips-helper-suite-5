# Настройки ОТД
Примечание: данная функциональность будет доступна в том случае, если загружен модуль расширения **Управление архивами**.
Настройка генерации инвентарных номеров ОТД производится в диалоге **Настройка / Параметры IPS / Система / Настройка ОТД**.
Для автоматического заполнения атрибута **Инвентарный номер ОТД** нужно включить переключатель **Автоматическая генерация инвентарного номера ОТД** и настроить формулы генерации для документов различных типов. В формуле допускаются следующие макроподстановки:
· **{Наименование атрибута}** – подставляет значение атрибута или пустую строку, если у документа такого атрибута нет;
· **{dd.MM.yyyy}** – подставляет текущую дату в указанном формате (месяц нужно записывать большими буквами M, иначе система подставит минуты);
· **{999}** – уникальное значение общего для всех документов счётчика, увеличивающего значение на 1 для каждого инвентаризируемого документа;
· **{T999}** – уникальное значение счётчика для документов данного и дочерних типов;
· **{T999:0}** – стартовое значение счетчика инвентарного номера.
Формула вычисления инвентарного номера ОТД распространяет своё действие на все дочерние типы документов, которым не присвоена собственная формула. Унаследованные формулы отмечены в дереве другим цветом.
**Инвентарный номер ОТД** можно также вычислять с помощью классификаторов. Для этого нужно в данном диалоге включить переключатель **Использовать классификаторы для вычисления инвентарного номера ОТД** и кнопкой добавить в список один или несколько классификаторов, у которых настроена формула присвоения значения атрибуту **Инвентарный номер ОТД**. Дополнительно система позволяет рассылать по E-mail уведомления о постановке на учёт в ОТД новых версий документов. Уведомления рассылаются абонентам, которые указаны в листе рассылки документа. Для получения рассылки у абонента должен быть указан адрес E-mail, а система должна быть настроена на работу с внешней электронной почтой (см. п. ).
Включенный параметр **Рассылка Email-уведомлений об актуализации новых версий** осуществляет рассылку уведомлений при постановке на учет новой версии документа. В рамках ОТД актуализированная версия – это версия, зарегистрированная в ОТД (имеющая инвентарный номер).
При включенной настройке **Рассылка уведомлений об отправке копии Абоненту и Получателю копии** абоненту и получателю копии на почту будут приходить уведомления о соответствующих назначениях. При этом если абонентом будет назначена группа пользователей – уведомление о назначении получит каждый пользователь в группе. Если абонентом будет назначена организационная единица или узел информационной системы – назначение получит пользователь, указанный в атрибуте **Получатель копии.**
При включенной настройке **«Кто вернул копию» равно «Получатель копии»** при выполнении команды **Вернуть копию** для одной копии на вкладке **Копии документа** поле **Кто вернул копию** будет автоматически заполняться значением атрибута **Получатель копии**.
Включенный параметр **Разрешить отправлять копии документов не возвращая устаревшие копии** позволяет для одного абонента отправлять копию версии документа, независимо от того была ли возвращена копия другой версии этого же документа.
При включенном переключателе **Автоматически создавать копии документа при публикации** после публикации на **WebPortal** зарегистрированного в ОТД документа, находящегося на указанном в настройке уровне продвижения, будет произведено автоматическое добавление абонентов (узлов информационной системы) в **Лист рассылки** опубликованного документа, а также создание копий для каждого узла с заполненными атрибутами: Вид – **Электронная** , Шаг жизненного цикла – **Выслана** , Абонент – **Узел информационной системы, на который выслана копия**. Копии будут создаваться при каждой публикации.
**Внимание!** Для корректной работы команды **Добавить по расцеховке** следует убедиться, что каждому созданному объекту типа **Расцеховочный элемент** назначен атрибут **Рассылка копий по расцеховочному маршруту** , значение которого является одной из созданных организационных единиц, а именно **Подразделения**.
Для настройки передачи атрибутов, которые необходимо передавать в копию из основного документа следует перейти в диалог **Настройка \ Параметры IPS \ Система \ Настройка ОТД \ Передача атрибутов в копию** и нажать кнопку , а затем выбрать необходимые атрибуты в диалоговом окне **Выбор атрибута**. Для сохранения настроек следует завершить добавление атрибутов кнопкой .

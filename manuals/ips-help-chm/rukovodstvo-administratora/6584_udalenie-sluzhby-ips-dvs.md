# Удаление службы IPS.DVS
Для удаления программы в ОС Windows воспользуйтесь стандартным менеджером приложений.
Для удаления в ОС Linux следует запустить скрипт uninstall.sh в каталоге приложения, для этого необходимо вызвать команду в терминале: **/var/lib/Intermech/IpsDVS/uninstall.sh.**

# Права доступа
Закладка **Безопасность** позволяет назначить права доступа ко всему списку предметных областей, зарегистрированных в системе. В конфигураторе можно назначить следующие права доступа:
· **Создание предметных областей** — разрешает создавать новые предметные области.
· **Удаление предметных областей** — разрешает удалять существующие предметные области.
· **Изменение свойств предметных областей** — разрешает изменять свойства предметных областей.
· **Просмотр прав доступа** — разрешает просматривать набор прав доступа к списку предметных областей.
· **Изменение прав доступа** — разрешает назначать права доступа на предметные области.
**Внимание!** В системе IPS предоставлена возможность копировать права, при условии, что место, куда копируются выбранные права, может принимать такие права доступа.

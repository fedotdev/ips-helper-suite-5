# Создание новой команды запуска приложений
Откройте настройки инструментов, выберите в дереве тип объектов, для которого требуется создать новую команду, затем на странице **Редактор команд** нажмите кнопку **Создать**. В появившемся диалоговом окне выберите тип запуска приложений для создаваемой команды:
После выбора типа запуска приложений нажмите кнопку **ОК**. На следующей странице мастера выберите тип создаваемой команды. Список доступных типов команд зависит от того, какие модули расширения были загружены вместе с IPS.

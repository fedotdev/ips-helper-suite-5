# Удаление шаблона процесса
Чтобы удалить шаблон процесса, воспользуйтесь одним из способов:
· Выберите пункт главного меню **Настройка/Редактор шаблонов процессов** , в появившемся диалоге отметьте шаблон, который необходимо удалить и выполните команду **Удалить** из контекстного меню.
· Выберите в дереве навигации тип объектов **Объекты маршрутизатора/Шаблоны процессов** , отметьте в рабочей области шаблон процесса, который необходимо удалить и выполните команду **Удалить** из контекстного меню.

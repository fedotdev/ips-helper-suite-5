# Изменение свойств команды запуска приложений
Откройте настройки инструментов, выберите в дереве тип объектов, для которого требуется создать новую команду, затем на странице **Редактор команд** выберите требуемую команду запуска приложений нажмите кнопку **Свойства**. В появившемся диалоговом окне настройте доступные свойства команды:
Список доступных свойств зависит от типа запуска приложений команды.
После внесения изменений нажмите кнопку **Применить** или **Закрыть**. Для отмены изменений следует нажать кнопку **Отменить**.

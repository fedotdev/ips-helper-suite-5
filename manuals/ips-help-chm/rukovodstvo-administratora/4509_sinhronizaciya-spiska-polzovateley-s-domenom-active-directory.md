# Синхронизация списка пользователей с доменом Active Directory
Система IPS позволяет синхронизировать список пользователей со списком пользователей домена Active Directory. Синхронизация является односторонней (из Active Directory в IPS), её запуск может быть выполнен как вручную, так и автоматически путем соответствующего указания задачи в планировщике задач IPS.
Для синхронизации вручную необходимо выполнить следующие действия:
1\. В приложении **Администратор базы данных** выбрать любою группу в объекте **Пользователи и группы**. С помощью контекстного меню открыть команду **Синхронизация со службой каталогов**.
2\. Указать имя домена и нажать кнопку .
В области **Пользователи IPS** список пользователей разбит на четыре столбца. При синхронизации важна колонка **Статус** в которой отображен статус связи пользователя системы IPS с пользователем зарегистрированном в домене. В колонке могут быть отображены следующие статусы:
· **OK** – синхронизация не требуется.
· **Локальный** – пользователь локализован в системе IPS и отсутствует в списке пользователей домена;
· **К удалению** – синхронизирован с доменом, но в настоящее время не имеет соответствия в списке пользователей домена.
· **Для домена по умолчанию** – пользователь относится к домену по умолчанию, но уточнить статус в настоящее время не представляется возможным, так как ведется работа с доменом не по умолчанию, SID у такого пользователя заполнен.
· **Локальный или для домена по умолчанию** – пользователь локализован в системе IPS либо он относится к домену по умолчанию, но уточнить статус в настоящее время не представляется возможным, так как ведется работа с доменом не по умолчанию, SID у такого пользователя не заполнен.
· **Для иного домена** – пользователь относится к другому домену и уточнить статус в настоящее время не представляется возможным.
· **К синхронизации** – пользователь имеет одинаковый атрибут SID как в базе, так и в службе каталогов, а логины или имя пользователя различаются.
· **Не подтверждено** – пользователь имеет пустой атрибут SID в базе, а в службе каталогов есть соответствие по логину пользователя.
По окончании настройки необходимо нажать кнопку для сохранения настроек и выполнения синхронизации, при этом в журнал событий IPS записывается информация о выполненных действиях или ошибках. Кнопка позволяет отменить изменения, сделанные в окне настройки. 
В процессе синхронизации у пользователей IPS будут обновлены некоторые атрибуты значениями из службы каталогов. К числу таких атрибутов относятся **Электронная почта** , **Служебный телефон** , **Мобильный телефон** , **Домашний телефон** , **Почтовый адрес** , **Домашний адрес** , **Комната**.
По окончании процесса синхронизации будут обновлены поля обоих списков. Поле **SID** содержит значение идентификатора безопасности Active Directory. Идентификатор безопасности является уникальным идентификатором и при синхронизации имеет приоритет перед именем пользователя. В частности, это означает, что если в домене будет пересоздан (удален и создан заново) пользователь под тем же именем, то он не будет иметь соответствия с синхронизированным ранее пользователем IPS с этим именем. 
Новые пользователи включаются в системную группу пользователей **Новые пользователи** ; синхронизированные ранее пользователи (с назначенным SID), которым не было найдено соответствие в списке пользователей домена, включаются в группу **Удаленные пользователи**. Включение пользователей в соответствующие группы дает возможность администратору IPS отреагировать на появление/удаление пользователей из домена и произвести дополнительное назначение параметров/удаление пользователей из IPS. Пользователи могут быть исключены из системных групп вручную, при этом они могут быть повторно включены в соответствующие группы во время последующей синхронизации, если это будет сочтено целесообразным.
При автоматической синхронизации, как и при синхронизации, вручную, в журнал событий записывается информация о выполненных действиях или ошибках.
Перед назначением в планировщик задачи синхронизации должна быть выполнена единовременная синхронизация вручную (см. выше). При этом настройки синхронизации с доменом сохраняются в базу данных для последующего использования. Если необходимо очистить настройки синхронизации, например, в случае удаления домена, то следует воспользоваться командой **Настройка/Утилиты администратора/Настройки синхронизации со службами каталогов**.

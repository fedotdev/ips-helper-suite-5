| --- | --- | --- |
| ABS(вещественное число) | вещественное число | Абсолютная величина |
| ACOS(вещественное число) | вещественное число | Арккосинус |
| ACOT(вещественное число) | вещественное число | Арккотангенс |
| ACSC(вещественное число) | вещественное число | Арккосеканс |
| ASEC(вещественное число) | вещественное число | Арксеканс |
| ASIN(вещественное число) | вещественное число | Арксинус |
| ATAN(вещественное число) | вещественное число | Арктангенс |
| AVERAGE(вещественное число, вещественное число, …) | вещественное число | Возвращает арифметическое среднее аргументов. |
| CEIL(вещественное число) | вещественное число | Наименьшее целое число, большее или равное заданному числу |
| COS(вещественное число) | вещественное число | Косинус |
| COSH(вещественное число) | вещественное число | Гиперболический косинус |
| COT(вещественное число) | вещественное число | Котангенс |
| COTH(вещественное число) | вещественное число | Гиперболический котангенс |
| COUNT(вещественное число, вещественное число, …) COUNT(вещественное число []) | вещественное число | Общее количество переданных параметров |
| CSC(вещественное число) | вещественное число | Косеканс |
| CSCH(вещественное число) | вещественное число | Гиперболический косеканс |
| EXP(вещественное число) | вещественное число | Число _e_ (основание натурального логарифма), возведенное в заданную степень |
| FLOOR(вещественное число) INT(вещественное число) | вещественное число | Наибольшее целое, меньшее или равное заданному числу |
| LN(вещественное число) | вещественное число | Натуральный логарифм |
| LOG(вещественное число, вещественное число ___base_) | вещественное число | Логарифм по заданному основанию |
| LOG10(вещественное число) | вещественное число | Логарифм по основанию 10 |
| MAX(вещественное число, вещественное число ___base_) MAX(вещественное число []) | вещественное число | Максимум |
| MIN(вещественное число, вещественное число ___base_) MIN(вещественное число []) | вещественное число | Минимум |
| NEG(вещественное число) | вещественное число | Число, взятое с обратным знаком |
| POWER(вещественное число, вещественное число ___power_) | вещественное число | Число, возведенное в заданную степень |
| RAND([вещественное число _max_]) | вещественное число | Случайное число от 0 до _max_. Если _max_ не определено, то возвращает случайное число от 0 до 1. |
| ROUND(вещественное число ___d_ , [целое число _decimals_]) | вещественное число | Возвращает число, близкое к заданному значению с указанной точностью. **Параметры** _d_ __ Число, которое нужно округлить. _decimals_ ____ Число значащих цифр (точность) в возвращаемом значении. **Возвращаемое значение**  Число, близкое к _d_ с точностью, соответствующей _decimals_. Если _d_ равноотстоит от двух чисел, одно из которых четное, а второе нечетное, то возвращается четное число. Если точность _d_ меньше _decimals_ , то возвращается неизмененное _d_. **Замечания** Параметр _decimals_ определяет число значащих чисел после запятой в возвращаемом значении и содержится в интервале от 0 до 28. Если _decimals_ равно нулю, то возвращается целое число. |

| TANH(вещественное число) | вещественное число | Гиперболический тангенс |

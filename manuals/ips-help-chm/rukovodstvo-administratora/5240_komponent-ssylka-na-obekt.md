# Компонент Ссылка на объект
В данном компоненте все свойства унаследованы от компонента **Текстовое поле**. 
Компонент **Ссылка на объект** имеет свойство **Контекстная выборка**. Этот свойство позволяет указать необходимую выборку (см. в ), которая будет фильтровать список выбранных объектов или связей. На вход выборки будет передаваться объект (атрибут связи), для которого открыта данная форма.

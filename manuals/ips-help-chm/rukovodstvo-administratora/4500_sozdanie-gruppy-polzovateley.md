# Создание группы пользователей
Для того, чтобы создать новую группу пользователей, следует выполнить следующие действия:
1\. Необходимо выделить одну из групп в дереве объектов, затем с помощью команды контекстного меню**Создать/** ‌‌**Создать «Группа пользователей»** вызвать диалоговое окно. 
2\. В диалоговом окне **Создание нового объекта** следует заполнить поле **Наименование** , которое имеет значок .
Примечание: все поля со значком , являются обязательными для заполнения!
3\. При необходимости можно заполнить поля **Код подразделения** и **Описание**. 
Поле **Код подразделения** заполняют при условии, что в компании ведется отдельный цифровой код каждого отдела, подразделения или департамента.
В поле **Описание** можно указать необходимые сведения о создаваемой группе.
4\. При необходимости редактирования объекта и/или открытия его в отдельном окне сразу после создания необходимо установить флажки **Открыть редактор после создания** и/или **Открыть создаваемы объект в Навигаторе**.
5\. Для проверки заполнения полей и свойств атрибутов, а также при необходимости добавить типы связи пользователю следует нажать кнопку . 
Примечание: если в проверке нет необходимости, то можно нажать кнопку сразу после ввода данных новой группы.
6\. Добавить связь группе необходимо с помощью кнопки **Добавить связь**.
7\. В диалоговом окне **Диалог выбора** следует выбрать необходимые данные и нажать кнопку .
8\. Для завершения создания группы необходимо нажать кнопку .

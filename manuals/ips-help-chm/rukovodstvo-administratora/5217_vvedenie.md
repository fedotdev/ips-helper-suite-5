# Введение
Intermech Professional Solutions (IPS) представляет собой универсальную систему информационной поддержки предприятий, выполненную по трехзвенной технологии клиентсервер приложенийСУБД. Для хранения данных можно использовать промышленные СУБД — Oracle, SQL Server или PostgreSQL. Система поставляется как в сетевом многопользовательском варианте, так и в однопользовательском варианте для работы на одной машине.
Данное руководство предназначено для администраторов системы IPS, а также для тех, кто работает с однопользовательской версией этой системы.
Если Вы хотите использовать сетевую версию системы, то перед ее установкой на компьютеры Вы должны выбрать одного или нескольких администраторов, которые будут отвечать за установку и конфигурирование IPS. Эти люди должны обладать навыками работы на компьютерах и в локальных сетях, а также иметь представление о том, что такое СУБД. В основные обязанности администраторов входит:
− установка системы на компьютеры;
− создание гибкой модели архивов предприятия;
− ведение списка ролей, пользователей и групп пользователей;
− настройка типов объектов, атрибутов и взаимосвязей между ними;
− назначение прав доступа пользователей к различным объектам системы;
− ведение списка должностей предприятия для поддержки электронных подписей документов;
− определение типовых маршрутов движения документов на предприятии;
− управление журналом регистрации действий пользователей в системе;
− настройка инструментов для работы с хранящимися в системе документами;
− администрирование СУБД и страховое копирование баз данных IPS и пр.
По умолчанию в IPS зарегистрирован один администратор с именем SYSDBA (Системный администратор) и паролем intermech, который администратор в целях обеспечения безопасности должен изменить сразу после установки системы. Данному пользователю в системе назначена роль **Администратор**. Эта роль по умолчанию имеет полный набор прав доступа на все категории объектов в системе. Назначение этой роли любому пользователю означает делегирование ему полномочий администратора системы.
Большая часть работы по администрированию системы производится с помощью клиентского модуля **Конфигуратор базы данных** , который входит в комплект поставки IPS и по умолчанию загружается при входе в систему в роли **Администратор**. Модуль регистрирует в системе два окна: **Конфигуратор базы данных** (позволяет настроить метаданные — типы атрибутов, объектов и связей, предметные области, языковые варианты и пр.) и **Администратор базы данных** (позволяет вести списки информационных объектов, предназначенных для администрирования системы — пользователи, роли, должности, правила подбора версий и пр.). Также модуль добавляет ряд административных команд в главном и локальном меню системы.
Модули расширения системы могут добавлять собственные административные окна, команды и закладки в интерфейс клиента IPS. Их описание смотрите в главе настоящего руководства или в документации на соответствующий модуль.

# Правила поиска объектов
Скрипт **правила поиска объектов** описывает, как система должна искать объект нужного типа, исходя из объекта другого типа. В отличие от правил расчета атрибутов, такие скрипты не создаются автоматически – пользователи должны создавать их самостоятельно. В большинстве случаев правила поиска объектов достаточно просты – достаточно перейти в нужном направлении по связям объекта.
Создание нового правила поиска объектов производится по команде **Создать**. В открывшемся окне необходимо указать какой объект и, при необходимости, атрибут подлежит поиску.
После этого откроется редактор командных скриптов ЭС. 
На рисунке выше показан пример поиска объекта **Оборудование Для типов объектов** **Операция** и **Нормирование на операцию**. В первом случае при помощи оператора **Дочерние объекты** с модификатором **Для всех** находим объект оборудование и возвращаем его при помощи оператора **Вернуть объект** . Во втором случае сначала при помощи оператора **Родительские объекты** с модификатором **Для всех** находим операцию, а только после этого помощи оператора **Дочерние объекты** с модификатором **Для всех** находим объект оборудование.
Редактирование скриптов будет описано в п. .
Описание операторов, применяющихся в скриптах правила поиска объекта, будет дано в п. .
Описание модификаторов, применяющихся в скриптах правила поиска объекта, будет дано в п. .

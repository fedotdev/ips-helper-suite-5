# Пользователи и группы пользователей
Перед началом работы с системой IPS каждый пользователь должен быть зарегистрирован администратором в утилите IPS в приложении **Администратор базы данных**. В базу данных, с которой работает IPS, этих пользователей вводить не нужно, так как для соединения с СУБД IPS используется специальный пользователь, который в самой системе IPS не зарегистрирован. 
**Внимание!** Данные настройки доступны только пользователям с правами администратора. Однако данное право может быть назначено любому пользователю, группе пользователей или роли – для этого достаточно разрешить им создавать объекты типа **Пользователи** и **Группы пользователей**.
Примечание:количество пользователей, которых можно зарегистрировать в IPS, не ограничено и оно не имеет ничего общего с количеством лицензий на программу, приобретенных предприятием.
Для просмотра всех групп пользователей необходимо войти в приложение **Администратор базы данных/Пользователи и группы**. Все пользователи системы могут быть зарегистрированы в разных группах, но они автоматически попадают в группу **ВСЕ ПОЛЬЗОВАТЕЛИ**. Таким образом один и тот же пользователь может входить в состав нескольких групп.

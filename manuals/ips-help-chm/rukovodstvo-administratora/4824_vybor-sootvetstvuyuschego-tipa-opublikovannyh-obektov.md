# Выбор соответствующего типа опубликованных объектов
По умолчанию все типы привязаны к типу **Опубликованные объекты**. Для выбора соответствующего типа опубликованных объектов базы **IPS WebPortal** необходимо нажать на кнопку в поле **Тип объектов на портале** . В появившейся форме будут отображены все доступные типы опубликованных объектов.

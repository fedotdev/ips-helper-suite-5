# Приложение 7 Получение отчета об ошибке
В случае возникновения какой-либо ошибки в программе на экран выводится соответствующее сообщение. Если из текста сообщения об ошибке не понятна причина возникновения ошибки, то для ее устранения необходимо сообщить об этой ошибке в «ИНТЕРМЕХ». Для этого рекомендуется написать электронное письмо на адрес ips@intermech.ru. Для скорейшего устранения ошибки просим в письме сообщить следующую информацию:
· Версия IPS, включая номер билда (отображается в окне **Справка/О программе**).
· Какая СУБД используется и версия СУБД.
· Какая операционная система установлена на компьютере, на котором происходит ошибка.
· Является ли ошибка регулярной либо происходит иногда.
· Последовательность действий пользователя, которая привела к ошибке – желательно по шагам со снимками экранов.
· Если ошибка происходит при выполнении каких-либо действий с определенным документом, просим, если это возможно, прикрепить к письму упакованный файл этого документа. Компания «ИНТЕРМЕХ» гарантирует, что присланный файл документа не будет использован ни в каких других целях, кроме поиска и устранения причин возникновения ошибки.
В окне с сообщением об ошибке имеется возможность сохранить файл с отчетом об ошибке (команда **Записать в файл**). Этот файл также следует прикрепить к письму в службу технической поддержки «ИНТЕРМЕХ». В файле содержится стек вызовов функций IPS, а также список загруженных модулей расширения системы. Стек вызовов можно увидеть, нажав кнопку **Подробнее** , однако для его расшифровки необходим файл отчета. Кнопка **Закрыть приложение** позволяет принудительно выгрузить клиент IPS. Это может понадобиться в случае, если ошибка не позволяет завершить выполнение программы обычными средствами.

# Список
Увидеть список атрибутов, принадлежащий одной из групп, можно не только в дереве метаданных, но и на закладке **Список** в рабочей области, где в виде таблицы представлены все атрибуты, принадлежащие данной группе. В таблице представлены все свойства атрибутов группы в режиме просмотра с возможностью отсортировать список по значению одной из колонок. Список можно также сгруппировать по значениям любого из свойств атрибутов. Для этого нужно перетянуть заголовок колонки левой кнопкой мыши в специальную область к фразе **Перетащите заголовок колонки в эту область для группировки по значениям этой колонки**.
Выделив двойным щелчком мыши один из атрибутов списка, можно перейти в режим редактирования данного атрибута на его закладку **Свойства**.

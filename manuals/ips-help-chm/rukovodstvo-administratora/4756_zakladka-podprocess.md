# Закладка Подпроцесс
Закладка отображается для действий типа **Подпроцесс** и позволяет настроить, по какому шаблону должен быть запущен подпроцесс на данном этапе.
· Чтобы выбрать шаблон вложенного процесса нажмите кнопку  поля **Запустить процесс по шаблону** и в появившемся диалоге выберите нужный шаблон. 
· Поле **Формат имени подпроцесса** предназначено для указания имени запускаемого процесса, под которым пользователь будет получать сообщения. Это может быть собственное имя подпроцесса или имя, сформированное с помощью автоматической генерации. Список возможных макроподстановок можно увидеть, нажав кнопку , расположенную с правой стороны поля.
Т.е., если в поле **Формат имени подпроцесса** запись будет выглядеть как %1% – %2% – %3% – %4%, то при получении сообщения процесс будет иметь название: (пример) Разработка документации – Регистрация в архиве – 15.04.2007 – 11.22.
· Установленный флажок **Ждать завершения** позволяет включить или выключить условия для выполнения следующего действия после подпроцесса: немедленно или только после его завершения. 
· Установленный флажок **Использовать базовую версию шаблона** позволяет запустить подпроцесс по базовой версии указанного шаблона.
· Установленный флажок **Использовать назначенного инициатора подпроцесса** позволяет задать инициатора подпроцесса.

# Объект удостоверяющего листа
Система IPS предоставляет возможность автоматизировать процесс сохранения УЛ в объект. Для этого следует:
1\. На главной панели выбрать меню **Настройка** и из контекстного меню вызвать команду **Параметры IPS**.
2\. В открывшемся окне перейти по адресу **Система \ Удостоверяющие листы \ Объект удостоверяющего листа.**
**Создать объект** – это параметр, включение которого позволяет создать дополнительный объект типа, который указывается в параметре **Тип объекта** при выполнении команды **Сформировать УЛ**. Файл УЛ записывается в атрибут **Файл** этого объекта, в атрибут **Обозначение** объекта будет записано обозначение объекта с приставной аббревиатурой **УЛ** , для которого вызвана команда **Сформировать УЛ**. Например, если необходимо сформировать УЛ для спецификации с обозначением АБВ11.22.00.000, то объекту удостоверяющего листа будет присвоено обозначение АБВ11.22.00.000 УЛ.
**Внимание!** Для атрибута **Обозначение** типа объекта необходимо отключить контроль уникальности.
Сформированный УЛ связан с объектом, для которого была применена команда **Сформировать УЛ** , связью типа, который указывается в параметре **Тип связи**.
Примечание: при повторном формировании УЛ, файловый атрибут связанного объекта будет перезаписан новым УЛ.

# Оператор присваивания
Оператор **Присваивания** позволяет присвоить новое значение какому-либо атрибуту – как атрибуту объекта или связи, так и временному атрибуту, не связанному с каким-либо объектом. Для указания типа атрибута используются выключатели в области **Присвоить атрибуту Объекта** или **Связи**. В скриптах генерации документов можно также присвоить значение одному из атрибутов текущего объекта документа. Для этого следует включить кнопку **Текущего элемента документа** вместо включенной по умолчанию кнопки **Объекта**.
Для выбора присваиваемого атрибута предназначены элементы управления, расположенные в верхней части окна **Параметры оператора**. Поскольку выбор атрибута встречается среди параметров многих операторов, рассмотрим его подробнее. В общем случае экспертная система работает не с одним атрибутом, а с парой **< Тип объекта>** и **< Тип атрибута>**. Если тип текущего объекта контекста не соответствует заданному типу объекта, экспертная система ищет объект нужного типа, используя правила поиска объектов (см. п. ).
Для того, чтобы выбрать атрибут, нажмите на кнопку в поле **Имя атрибута**. Если при этом переключатель **Тип объекта** включен, то программа позволит выбрать тип объекта вместе с типом атрибута, в противном случае – только тип атрибута. Не следует задавать тип объекта, если требуется работать только с текущим объектом или временным атрибутом, не принадлежащим никакому объекту.
**Внимание**! Все временные атрибуты, не принадлежащие объектам, должны принадлежать к группе **Временные атрибуты без объектов**. Без этого экспертная система не поймет, что искать объект не нужно.
В том случае если значение атрибута необходимо занести в глобальную таблицу стоит установить переключатель **Занести результат в глобальную таблицу**.
Признак **Массив** устанавливается в том случае, если необходимо несколько значений атрибута, имеющего в **Конфигураторе** свойство **Список** – **Атрибут может содержать одно значение** , собрать в массив данных (атрибут у которого свойство **Список** – **Атрибут может содержать множество значений**). Например, получить список значений атрибута **Обозначение** для всех изделий состава. Поля Х и Y предназначены для указания номера элемента массива (поле Х для одномерного массива, поле Y для двумерного).
В выпадающем списке **Операция над значением** , необходимо выбрать операцию, которая определит, какой именно результат необходимо присвоить атрибуту. Экспертная система позволяет автоматизировать несколько наиболее часто встречающихся задач:
· **Значение**. Указанному атрибуту будет присвоено значение, возвращаемое заданной формулой. Эта операция установлена по умолчанию.
· **Значение из таблицы**. Эта операция позволяет выбрать одно из значений в зависимости от результата формулы. Эта операция подробно описана ниже.__
· **Сумму**. Эта операция приводит к тому, что значение атрибута суммируется с результатом формулы, и результат сохраняется в качестве нового значения атрибута. Эта операция обычно используется внутри цикла.
· **Среднее**. При этой операции система рассчитывает среднее значение среди всех значений, рассчитанных в результате выполнения этого оператора, и присваивает его указанному атрибуту. Эта операция обычно используется внутри цикла.
· **Количество**. При этой операции формула не имеет значения: атрибуту будет присвоено количество раз, которое был выполнен оператор. Эта операция обычно используется внутри цикла.
· **Минимум**. Атрибуту будет присвоено минимальное значение из результатов расчета формулы. Эта операция обычно используется внутри цикла.
· **Максимум**. Атрибуту будет присвоено максимальное значение из результатов расчета формулы. Эта операция обычно используется внутри цикла.
· **Список через**. Атрибуту будет присвоена строка, состоящая из строковых представлений всех результатов расчета формулы. При выборе этой операции редактор скриптов позволяет также указать разделитель списка в соответствующем выпадающем списке (см. рисунок ниже). Например, можно получить список, разделенный запятыми или точками с запятой.
Операция **Значение из таблицы** требует ввода дополнительной таблицы значений, для чего служит закладка **Таблица значений**. Пример таблицы значений изображен на рисунке окно параметров оператора, справа. При вычислении присваиваемого значения система пытается проверить, находится ли результат вычисления формулы в пределах между указанными значениями **От** и **До** для каждой строки. Как только будет найдена первая строка, удовлетворяющая этому условию, атрибуту будет присвоено значение из этой строки. Например, по таблице, изображенной на рисунке выше, при результате формулы 9252 будет присвоено значение **Микросхемы**.
В столбцах **От** и **До** можно ничего не ставить – в этом случае программа считает, что соответствующее условие всегда истинно. Таким образом, строка без этих значений будет выбираться всегда, и ее следует ставить последней, поскольку в противном случае строки после нее не будут выбираться никогда. Для повышения производительности рекомендуется размещать наиболее часто встречающиеся строки в начале списка.

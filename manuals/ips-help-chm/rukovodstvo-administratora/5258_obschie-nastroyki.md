# Общие настройки
· **Типы документов** – это параметр, в котором следует указать типы документов, с которыми будет работать интегратор.
Для настройки параметра **Типы документов** следует воспользоваться кнопкой , которая позволяет вызвать диалоговое окно, в котором и будет создан рабочий список типов документов.

Для завершения настройки параметра следует нажать кнопку .
Пользователь имеет возможность создать свои типы объектов в дереве **Навигатора** , для того чтобы интеграторы могли идентифицировать документы, следует добавить эти типы документов в список параметра **Типы документов** для каждого из интегратора. 
Например, пользователю необходимо добавить в дереве **Навигатора** по ссылке **Объекты / Документы / Деловая документация** следующие типы документов:
· Автобиография.
· Резюме.
· Служебная характеристика.
Для этого следует:
1\. На главной панели системы IPS выбрать меню **Настройки** , а затем вызвать команду **Конфигуратор базы данных**.
2\. В открывшемся приложении **Конфигуратор базы данных** следует перейти по ссылке **Объекты / Документы / Деловая документация** и вызвать команду **Создать** из контекстного меню.
3\. В создаваемом объекте следует заполнить обязательные атрибуты **Имя объекта** и **Наименование** , а затем нажать кнопку .
4\. Созданные типы объектов следует добавить в список типов документов параметра **Типы документов**.
5\. По завершению добавления пользовательских типов объектов следует нажать кнопку .
**Внимание!** При условии, что в список документов параметра **Типы документов** добавлен только один тип, то при импорте файлов в систему IPS, документы будут помещены в указанный тип. Если в списке несколько типов документов, как показано в примере выше, то пользователю будет предложено выбрать из списка тот тип, в который необходимо импортировать документ.
**Внимание!** После создания пользовательского типа документ необходимо убедится, что все необходимые настройки отлажены как и для всех объектов системы IPS. 
· **Синхронизируемые атрибуты документа** – это параметр, который позволяет указать синхронизируемые атрибуты между файлом и документом в системе IPS.
Например, атрибуты **Обозначение** , **Наименование,** **Заголовок** **объекта.**
1\. Настроить параметр **Синхронизируемые атрибуты документа** следует с помощью кнопки , которая позволяет вызвать диалоговое окно **Список типов атрибутов**.
2\. С помощью кнопки необходимо выбрать тип атрибутов и нажать кнопку .
Примечание: выбор необходимого атрибута можно выполнить с помощью контекстного поиска (поиск по первым символам вводимого наименования атрибута). Для этого необходимо установить курсор мыши в поле для ввода и набрать текст.

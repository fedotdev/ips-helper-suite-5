# Создание единиц измерения
Чтобы создать новую единицу измерения для физической величины, нажмите правую кнопку мыши на названии нужной физической величины в списке и выполните команду **Создать/В составе**. 
Заполните значения полей и нажмите кнопку **Готово**. Связь единицы измерения с физической величиной будет создана автоматически.
Создать единицу измерения можно также командой **Создать** из контекстного меню пункта **Единицы измерения**. В этом случае нужно обязательно создать связь типа **Входит в** с одним из объектов типа **Физические величины**.

# Списки файлов
Файлы хранятся в шкафах в виде списков. Чтобы увидеть список файлов, необходимо открыть карточку файлового шкафа или панель с дополнительными видами и перейти на закладку **Список файлов**.
На данной закладке список файлов представлен в виде таблицы, колонки которой отображают информацию о файлах: имя файла, идентификатор файла, размер файла, дату обновления файла, идентификатор объекта или связи, упакованный размер файла, комментарии. 
На закладке можно изменить количество отображаемых колонок, вызвав диалог настройки отображения с помощью команды **Настройка отображения** контекстного меню любого из файлов списка. Также можно отсортировать список по значению одной из колонок, щелкнув по заголовку колонки левой кнопкой мыши, или сгруппировать по значениям любого из свойств файлов, перетянув заголовок колонки левой кнопкой мыши в специальную область к фразе **Перетащите заголовок колонки в эту область для группировки по значениям этой колонки**.

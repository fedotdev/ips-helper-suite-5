# Экспорт метаданных
Экспорт метаданных выполняется по команде меню клиента IPS **Экспорт/Импорт/Портфель/Экспорт метаданных**. Формируется портфель, в который попадают все метаданные (атрибуты, группы атрибутов, типы связей, типы объектов, уровни продвижения, языковые варианты, предметные области, схемы жизненных циклов) и объекты типов, помеченных в **Параметрах IPS\Система\Портфель** – настройка**Типы объектов, которые являются метаданными**. 
**Внимание!** Список объектов в настройке **Типы объектов, которые являются метаданными** проверяются на отсутствие в портфеле базы-приемника. 
**Внимание!** Следует следить за идентичностью настроек **Типы объектов, которые являются метаданными** в базе-приемнике и базе-источнике.
Для данных, которые содержат ссылочные атрибуты и состав по связям, необходимо добавить возможность экспорта объектов только первого уровня (не разворачивая состав по ссылкам и связям на все уровни). Для этого в **Параметры IPS \ Система \ Портфель** у настроек **Экспорт данных по ссылочным атрибутам** и **Экспорт данных по связям** из выпадающего списка выбрать значение **Только 1 уровень**.
При выборе значения **Только 1 уровень** для настройки **Экспорт данных по ссылочным атрибутам** , в портфель попадут сами экспортируемые объекты и объекты, которые указаны у них в ссылочном атрибуте. При выборе – **Развернутый состав** для настройки **Экспорт данных по ссылочным атрибутам** , портфель будет работать по текущему алгоритму.
При выборе значения **Только 1 уровень** для настройки **Экспорт данных по связям** , в портфель попадают объекты и их состав по связям только первого уровня. При выборе – **Развернутый состав** для настройки **Экспорт данных по связям** , портфель будет работать по текущему алгоритму.
**Внимание!** Для реализации экспорта полного состава объектов по определенному типу связей вне зависимости от настройки **Экспорт данных по связям** необходимо предусмотреть механизм подписчиков по аналогии с теми, которые применены в IPS WebPortal.
В поле **Экспортируемые данные** выбираются метаданные, которые необходимо экспортировать. 
Папка, в которую будет производиться экспорт, указывается в поле **Расположение портфеля**. В случае, если указан переключатель **Серверное размещение портфеля** , в поле **Расположение портфеля** указывается папка на машине с сервером приложений IPS.
Если необходимо произвести экспорт только системных метаданных, следует включить переключатель **Только системные метаданные**. 
Переключатель **Экспортировать права доступа** указывает, нужно ли извлекать в портфель информацию по правам доступа к метаданным. В этом случае в портфель будет также добавлена информация по пользователям, группам пользователей и ролям, для которых имеются назначенные на метаданные права доступа.
Переключатель **Экспорт информации о локализации** не влияет на содержимое портфеля при экспорте: выключенный переключатель указывает на то, что при импорте метаданные будут внесены в базу-приемник независимо от языка по умолчанию в ней. При включенном переключателе в базу-приемник будут импортированы только те метаданные, которые соответствуют по настройкам языковых вариантов. 
В поле **Комментарий** можно указать комментарий к получаемому портфелю.

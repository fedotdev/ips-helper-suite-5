# Выбор элемента
Для выбора прямоугольного элемента бланка достаточно щелкнуть левой кнопкой мыши внутри него. Точно также можно отметить ячейку таблицы. Чтобы отметить таблицу целиком, необходимо щелкнуть левой кнопкой мыши по ее верхней границе. Для выбора полилинии требуется щелкнуть левой кнопкой мыши по одному из ее отрезков.
Выбранный прямоугольный элемент выделяется на странице голубой рамкой. Выбранная полилиния выделяется узлами ее отрезков.
Если требуется провести какую-либо операцию сразу над несколькими элементами, можно выделить их одновременно, щелкнув на каждом из них левой кнопкой мыши и удерживая при этом нажатой клавишу **[Ctrl]**. Повторный щелчок мыши по выбранному элементу при нажатой клавише **[Ctrl]** отменяет его выбор.

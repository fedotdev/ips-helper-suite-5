# Панель служебных кнопок
Кнопка присутствует только для скриптов генерации документов. Каждый скрипт генерации документов связан с шаблоном документа, на основе которого будут созданы все документы. Кнопка позволяет открыть этот шаблон для редактирования (или для просмотра, если редактирование по какой-либо причине невозможно).
Кнопка присутствует в скриптах генерации документов и в командных скриптах ЭС и позволяет определить дополнительные параметры создаваемых документов.
Поле **Тип документа** определяет, к какому типу объектов должен принадлежать новый документ. В IPS существует множество типов документов, и в большинстве случаев требуется, чтобы создаваемые документы принадлежали к одному из них. Пока тип документа не задан, при генерации будут создаваться объекты типа **Отчет**.
Поле **Наименование генерируемого документа** **(будет присвоено каждому документу)** позволяет определить, как будут называться все документы, создаваемые на основе этого скрипта. В этом поле могут присутствовать ссылки на имена атрибутов исходного объекта контекста (изображаются в фигурных скобках), которые будут заменены значениями соответствующих атрибутов – например, на рисунке выше название нового документа будет состоять из обозначения исходного объекта, после которого следуют буквы ВС. Для вставки ссылки на атрибут используется кнопка . Если название не задано, новым документам будет присвоено название в формате: 
**< Название скрипта> для <Заголовок объекта, для которого сгенерирован документ>**. 
При помощи кнопок и в **Наименование генерируемого документа** **(будет присвоено каждому документу)** можно добавлять дату и время генерации документа.
Примечание: для командных скриптов ЭС поля **Тип документа** , **Наименование генерируемого документа** и кнопки , и будут заблокированы.
Для каждого скрипта следует определить типы исходных объектов, для которых его можно вызывать. Для этого предназначена кнопка в области **Типы исходных объектов, для которых можно запускать скрипт**. При нажатие кнопки открывается диалог **Типы объектов** , в котором можно выбрать необходимые типы. 
Скрипт будет доступен не только для объектов выбранных типов, но и для всех дочерних типов: например, на рисунке выше скрипт можно вызывать для всех спецификаций, комплексов и сборочных единиц. Для данных объектов скрипт будет доступен по команде контекстного меню **Отчеты и документы** / **Ведомости и сложные отчеты** – для скриптов генерации документов и по команде контекстного меню **Командные скрипты ЭС** – для командных скриптов ЭС.
Переключатель **Выдавать отладочную информацию** следует включать, если документ не генерируется либо не полностью соответствует скрипту – при этом программа выдаст информацию трассировки, из которой можно будет понять причину этой проблемы. Переключатель **Сохранять документ в исходном объекте** следует включать в том случае если комплект документов необходимо сформировать не как отдельный объект, а сохранить в файл исходного объекта.
**Внимание**! Данной настройкой необходимо пользоваться, когда в файле исходного объекта не используются другие файлы. Т.к. при наличии списка файлов в объекте, если будет запущена генерация подобного скрипта, один из имеющихся файлов может быть заменен на файл сгенерированного документа, т.е. один из файлов будет утерян. 
Переключатель **Контекст – все объекты выбранного узла Навигатора** следует включать, если при генерации документов на основе этого скрипта в качестве исходного контекста следует брать не выбранные объекты **Навигатора** , как обычно, а все объекты, входящие в текущий узел **Навигатора**. Примечание: если переключатель **Контекст – все объекты выбранного узла Навигатора** включен, при запуске скрипта командой контекстного меню **Отчеты и документы** / **Ведомости и сложные отчеты** на любом объекте из выборки, то скрипт отработает по всем объектам. 
Переключатель **Классифицировать документ** позволяет при генерации документа автоматически запустить окно выбора классификатора для генерируемого документа.
Переключатель **Актуальные заменители** позволяет вывести в документ все объекты, кроме объектов из групп допустимых заменителей.

Переключатель **Использовать настройки клиента** – работа переключателя в параметрах документа зависит от работы кнопки **Актуальный состав вкл./выкл**.
Кнопка позволяет настроить параметры сортировки объектов в ведомостях (см. »).
Возвращаемся к окну редактора скрипта. В скриптах ЭС данные настройки начинают работать когда в операторах поиска на вкладке **Прочее** активируется переключатель Встроенная сортировка (см. п. ) или на модификаторах циклов (см.п. ).
Кнопка редактора скрипта **Открыть объект ЭС** присутствует в скрипте **Правила расчета атрибута** и позволяет открыть соответствующую формулу, таблицу или скрипт на основе которой было создано правило.
Кнопка **Открыть скрипт** присутствует в скрипте **Шаблоны комплекта документов** и доступна для операторов создания документа в дереве скрипта. Данная кнопка позволяет открыть соответствующий скрипт генерации документов, настройку TECHCARD или скрипт С#.
Кнопка **Условие** присутствует в **Расчетные скрипты экспертной** системы и позволяет задать условие применения скрипта.
Кнопка присутствует во всех скриптах экспертной системы и позволяет сохранить всю информацию о скрипте в файле XML. Этот файл можно будет послать в техническую поддержку ИНТЕРМЕХ, если специалисты по технической поддержке попросят это сделать.
Кнопка присутствует во всех скриптах экспертной системы и позволяет импортировать информацию из файла XML текущий скрипт. Вся информация в данном скрипте будет заменена на информацию из файла XML.
Далее располагаются кнопки проверки. **Проверка шаблона** присутствует в скриптах генерации документов и предназначена для выявления ошибок в шаблоне генерируемого скрипта. Например, ошибка на рисунке ниже будет означать что для варианта VO в шаблоне установлено свойство **Обязательный элемент** – **Да** , тогда как для вариантов динамических таблиц данное свойство должно иметь значение – **Нет**. 
Кнопка **Проверка ниже** предназначена для выявления ошибок в скрипте ниже расположения курсора. При нахождении ошибки будет показано окно с указанием ошибки и выделена строка, в которой данная ошибка обнаружена. Например, ошибка на рисунке ниже будет означать, что атрибут, присутствующий в скрипте, был удален.
Переключатель **Шаблон соисполнителя** присутствует в скрипте **Шаблон комплектов документов** и позволяет пометить данный шаблон документов как шаблон сформированный соисполнителем. При формировании основного комплекта документов, имеющего документы, ссылающиеся на шаблон соисполнителя (см. свойство **Брать документ соисполнителя** в операторе**Создать документ** п. ), сформированные документы из шаблона соисполнителя перегенерированы не будут, а будут скопированы в основной комплект.
Переключатель **Брать на изменение** присутствует в скрипте **Генерация комплекта документов** и **Шаблон комплектов документов** и используется для указания будут ли документы после формирования взяты на редактирование или их редактирование будет завершено. Для работы данного переключателя необходимо чтобы объект **Технологические документы ТП** и **Комплекты технологических документов** на шаге жизненного цикла **В разработке** для свойства **Способ модификации объектов** имел значение **Через рабочую копию объекта**.
Команда **Сохранить** позволяет сохранить произведенные изменения в файл скрипта.

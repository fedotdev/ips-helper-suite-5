# Создание
Чтобы создать новый атрибут, выберите одну из групп атрибутов дерева метаданных, в которую будет входить создаваемый атрибут, и примените команду его контекстного меню **Создать атрибут**. При этом в группе появится новый атрибут, большинству свойств которого будут присвоены значения по умолчанию. Отредактируйте свойства созданного атрибута и нажмите кнопку **Применить**. 
Все созданные в составе различных групп атрибуты автоматически попадают также в состав системной группы **Все атрибуты**. Кроме того, атрибут, созданный в составе одной группы, может быть добавлен в состав другой группы.

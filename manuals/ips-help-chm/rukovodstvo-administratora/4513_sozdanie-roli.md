# Создание роли
Чтобы создать новую роль, выполните следующие действия:
· Отметьте в дереве элемент **Роли** и примените команду **Создать/Создать Роль** его контекстного меню;
· В появившемся диалоге введите данные о новой роли, укажите предметные области, для которых она может применяться, и нажмите **Готово**.

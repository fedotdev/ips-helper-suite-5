# Типы документов
Администратор может выполнить дополнительные настройки для типов документов в диалоге **Настройка / Параметры IPS / Система / Типы документов** :
Настройка **Разделитель в обозначении** позволяет указать строку-разделитель, которая будет автоматически применяться в документах при отображении обозначения документа и кодом типа документов.

# Приложение 9 Гиперссылки на объекты IPS
Документы Microsoft Office, HTML и другие, позволяющие использование гиперссылок, могут содержать в себе гиперссылки на объекты IPS, при помощи которых пользователь может совершать ряд действий с объектами прямо из документов. 
Гиперссылки вставляются в документ в формате URL в виде:
_ips:// <режим поиска>/<критерий поиска>/[команда]. _
Возможные режимы поиска:
· Поиск по идентификатору версии объекта (object), например _ips://object/ <числовой идентификатор версии объекта>_
· Поиск по обозначению документа/изделия (designation, d), например _ips://designatio/ <Обозначение документа>_
· Поиск по заголовку объекта, например _ips://caption/ <Заголовок объекта>_.
Примечание: следует учитывать, что в случае поиска по неуникальному в пределах всей базы атрибуту (обозначение/заголовок) будет найден первый попавшийся объект с данным значением атрибута, поэтому для точного поиска объекта предпочтительно использовать режим object.
Необязательная часть гиперссылки _[команда]_ может указывать на действие, которое должно быть выполнено, когда пользователь кликнет на гиперссылке. Возможны следующие команды:
| Команда | Действие |
| --- | --- |
| Команда отсутствует | Аналогично команде “Открыть в новом окне” |
| view | Просмотр |
| edit | Редактирование |
| card | Показать карточку документа |
| versions | Список версий |
| visual | Открыть визуализатор связей |
Вот несколько примеров гиперссылок:
· <ips://object/102550/view> – просмотр объекта с идентификатором версии 102550;
· <ips://d/ИНТМ.712333.004/edit> – вызов редактора для объекта с обозначением **ИНТМ.712333.004;**
· [ips://caption/Системный администратор/](ips://caption/Системный%20администратор/) – открытие свойств пользователя **Системный администратор** в новом окне.
Примечание: в целях совместимости с Intermech Search, IPS также может поддерживать протокол ims://, если это включено администратором на этапе инсталляции системы. В этом случае в ссылках вида ims://docid/.. и ims://artid/. IPS будет пытаться находить документы/объекты, перекаченные из старой системы в новую, по атрибутам **Идентификатор объекта в Search**.

# Настройка команды Смотреть…
Примечание: команда **Смотреть…** рассчитана только для просмотра и/или печати файла.
Команда **Смотреть…** позволяет записать в файл электронную подпись объекта, контрольную сумму и атрибуты регистрации документа в ОТД в файл. При выборе команды открывается диалоговое окно с доступными опциями, описание, которых представлено сразу после рисунка:
· **Разрешить записи подписи объекта в файл** – записывает подписи объекта в файл документа.
− **Записывать только фамилию подписавшего** – при выбранной предыдущей опцией, подписи будут записаны в файл без дат и статусов, а только фамилии подписавших.
· **Разрешить запись контрольной суммы в файл** – записывает контрольную сумму файла в сам файл. 
_Примечание: после применении опции**Разрешить запись контрольной суммы в файл** , контрольная сумма файла меняется._
· **Разрешить запись атрибутов объекта в файл** – записывает атрибуты объектов в файл, например, атрибут **Инвентарный номер (ОТД)**.
Для корректной записи атрибутов объектов в файл следует заполнить список типов синхронизируемых атрибутов, который расположен в настройках соответствующего интегратора. 
Для того чтобы заполнить список атрибутов следует:
1\. В главном меню открыть настройку инструментов по команде **Настройка / Настройка инструментов** :
2\. Выбрать страницу **Интеграторы с приложениями**.
3\. Выбрать необходимый интегратор и открыть окно **Свойства** с помощью кнопки **Свойства**.
4\. В общих настройках выбрать строку **Синхронизируемые атрибуты документа** , открыть редактор списка типов атрибутов и добавить необходимый атрибут. 
5\. Для завершения созданных настроек следует нажать кнопку в окне **Свойства**.
В отдельных случаях необходимо настроить в самом документе (например, для внутренних документов IPS или конструкторских документов). 
Пример, тип объекта **Документы / Конструкторские документы / Чертежи деталей** :
1\. В главном меню открыть настройку инструментов по команде **Настройка / Настройка инструментов** :.
2\. Выбрать страницу **Просмотр и печать файлов**.
Выбрав необходимый объект, следует настроить параметры в области **Запись атрибутов объекта в файл.**
3\. Для этого следует снять галочку в строке **Использовать настройки родительского типа объекта** и поставить ее в строке **Включить записи атрибутов**.
4\. Затем необходимо добавить атрибут.
5\. Для сохранения созданных настроек следует нажать кнопку .

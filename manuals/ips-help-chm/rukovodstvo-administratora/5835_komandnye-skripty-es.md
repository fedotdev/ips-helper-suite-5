# Командные скрипты ЭС
**Командные скрипты ЭС** предназначены для автоматизации выполнения различных задач, например, расчетов атрибутов объектов IPS. Данный скрипт вызывается по команде контекстного меню **Командные скрипты ЭС** и позволяет пройтись по связям объекта, для которого был вызван скрипт, рассчитать заданные атрибуты и сохранить рассчитанные значения. 
Создание нового командного скрипта ЭС производится по команде **Создать**. В открывшемся окне необходимо ввести наименование скрипта ЭС.
После этого откроется редактор командных скриптов ЭС. Пример скрипта показан ниже.
По команде **Параметры документа**(см п. ) необходимо указать, для какого типа объекта будет запускаться данный скрипт. Скрипт с примера на рисунке выше будет запускаться для всех объектов **Изделия**.
В данном скрипе мы будем производить перевод значений массы деталей из состава, на который вызывается скрипт в килограммы, а также производить перевод значений нормы штучного времени на техпроцесс в минуты. Для этого первоначально при помощи оператора поиска вложенных объектов с модификатором **Для всех** найдем все детали из состава. Внутрь вставляем оператор присваивания, в котором при помощи формулы **К_ЕД** приводим значение массы детали в любых единицах массы к значению в килограммах. 
Далее опять вставляем оператор поиска вложенных объектов с модификатором **Для всех** для поиска всех норм времени на ТП. Внутри по аналогии вставляем оператор присваивания, в котором приводим значения всех норм штучного времени к значению в минутах.
Редактирование скриптов будет описано в п. .
Описание операторов, применяющихся в командных скриптах, будет дано в п. .
Описание модификаторов, применяющихся в командных скриптах, будет дано в п. .
Описание операторов сбора глобальной таблицы будет дано в п. .

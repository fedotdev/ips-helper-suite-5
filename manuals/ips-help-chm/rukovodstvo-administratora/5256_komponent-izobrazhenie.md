# Компонент Изображение
В данном компоненте основные свойства унаследованы от компонента **Надпись**.
Свойство **Выбор** обозначения может принимать два значения: **Фиксированный выбор** и **Пользовательский выбор**.
При фиксированном выборе изображение указывается на этапе проектирования формы, при пользовательском выборе изображение может быть изменено на форме объекта с помощью команд контекстного меню и сохранено в атрибут файлового типа с одним значением, указываемый в поле **Атрибут**.

# Создание формулы
Окно создания формулы показано на рисунке ниже.
В верхней части выбирается **Тип объекта** и **Имя атрибута** значение, которого необходимо посчитать в формуле. Если нужный параметр не зависит от типа объекта (например, временный атрибут или атрибут объекта контекста), следует выключить переключатель **Тип объекта** перед нажатием кнопки . 
Очистить значение полей **Тип объекта** и **Имя атрибута** можно нажатием кнопки .
Поле **Наименование** автоматически заполняется по формуле:
· **Расчет <Тип объекта> <Имя атрибута> **
В поле **Редактирование формулы** по кнопке **Изменить** введется формула расчета атрибута. Редактирование формулы будет рассмотрено в п . 
В поле **Условие** задается условие применение формулы. Редактор для ввода условия аналогичен редактору ввода формул.
Очистка полей **Редактирование формулы** и **Условие** производится при помощи команды **Удалить**.
После нажатия кнопки **Создать** будет автоматически обновлено **Правило расчета атрибута** (см. п. ).

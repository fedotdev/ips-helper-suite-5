# Окно Статистика запросов
Статистика запросов производится в отдельном окне, которое можно открыть, применив команду главного меню **Настройка/** **Статистика запросов**.
Окно **Статистика запросов** имеет табличный вид. Строки таблицы представляют собой перечень имеющихся в системе атрибутов применительно к типам объектов и связей. Колонки таблицы отображают свойства атрибутов, необходимые для ведения статистики:
· **Атрибуты** — отображает атрибуты системы;
· **Типы объектов** — отображает типы объектов, которым назначены атрибуты;
· **Типы связей** — отображает типы связей, которым назначены атрибуты;
· **Количество чтений (поисков/сортировок, записей)** — отображает суммарное количество операций, произведенных над атрибутом;
· **Продолжительность чтений (поисков/сортировок, записей)** — отображает суммарное время, затраченное на операции, которые производились над атрибутом. 
· **Способ оптимизации** — отображает способ оптимизации, заданный в свойствах атрибута.
· **Рекомендуемый способ оптимизации** — отображает рекомендуемый способ оптимизации для атрибута.
По умолчанию в окне статистики запросов отображается таблица с перечнем существующих атрибутов и типами объектов и связей, которым эти атрибуты назначены, но статистика запросов не ведется, так как данный сервис может замедлять работу системы. Чтобы начать вести статистику, необходимо включить режим **Вести статистику** , нажав соответствующую кнопку на панели инструментов. Статистика ведется на сервере приложений и учитывает информацию, поступающую со всех клиентских приложений, подключенных к серверу. Для достоверности собираемой информации рекомендуется вести сбор статистики в течение нескольких дней. После завершения сбора статистики рекомендуется данный режим выключить. Перед повторной процедурой сбора статистики рекомендуется очистить предыдущие данные командой **Очистить** на панели инструментов.
Информация в таблице обновляется автоматически при перезагрузке системы. Также обновить информацию можно, применив команду **Обновить** контекстного меню любой из ячеек таблицы или нажав кнопку **Обновить** панели инструментов **Стандартный**.
Для удобного восприятия информации можно изменять последовательность колонок в таблице, перетаскивая их за заголовок курсором мыши. Система позволяет отсортировать список по значению одной из колонок, отметив заголовок курсором мыши. Повторное нажатие по заголовку изменяет направление сортировки. Список можно также сгруппировать по значениям любого из свойств атрибутов. Для этого нужно перетянуть заголовок колонки левой кнопкой мыши в специальную область к фразе **Перетащите заголовок колонки в эту область для группировки по значениям этой колонки**. 
Чтобы остановить ведение статистики, необходимо отключить режим **Вести статистику** , нажав соответствующую кнопку на панели инструментов.

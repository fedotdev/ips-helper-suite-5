# Редактор форм ввода данных
Для того чтобы сделать отображение параметров различных типов объектов в карточке более гибким, в IPS есть возможность настраивать карточки для конкретных задач. Настраиваемые карточки объектов и документов предназначены для дифференцированного отображения информации для различных групп пользователей. Система может быть настроена таким образом, что при просмотре карточки одного и того же объекта, например, пользователем из группы **Технологи** и пользователем из группы **Конструкторы** карточка будет иметь разный вид, и они будут видеть и изменять различные наборы параметров.

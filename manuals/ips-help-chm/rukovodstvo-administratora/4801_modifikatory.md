# Модификаторы
Модификатор позволяет изменить или уточнить смысл оператора. Некоторые модификаторы служат для создания сложных конструкций управления, например, циклов, другие позволяют накладывать дополнительные условия, третьи управляют контекстом выполнения операторов. Не все модификаторы можно сочетать с любым оператором – редактор скриптов не позволит сохранить скрипт, в котором существуют недопустимые сочетания.
Все модификаторы работают с некоторым набором объектов. Если модификатор применен к оператору поиска объектов (см. п. ), он использует в качестве набора объектов результат этого оператора. В противном случае в качестве набора объектов выступает текущий контекст оператора, который также может содержать несколько объектов.

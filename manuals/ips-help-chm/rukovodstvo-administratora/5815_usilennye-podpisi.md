# Усиленные подписи
По умолчанию для подписания объектов в системе IPS используется внутренняя реализация подписей (простые подписи). Усиленные ЭП выполняются в IPS с использованием внешних криптопровайдеров, совместимым с интерфейсом Microsoft CryptoAPI, и сертификатов, сгенерированных удостоверяющими центрами вне IPS.
**Внимание!** Для того, чтобы система IPS могла использовать внешние криптопровайдеры для работы с ЭП, у криптопровайдеров должна существовать реализация для Microsoft .NET Framework. В частности, при использовании криптопровайдера КриптоПро CSP должен быть также установлен КриптоПро .NET на клиентских машинах, с которых выполняется подписание, а также на машине с серверной частью IPS для реализации проверки подписей.

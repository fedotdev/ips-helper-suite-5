# Шаблоны комплектов документов
**Шаблоны комплектов документов** предназначены для создания структуры комплектов документов для различных объектов. Внутри скрипта шаблон комплекта документов указывается какие документы будут формироваться для объекта по команде контекстного меню **Отчеты и документы /Ведомости и сложные отчеты/Генерация комплектов документов/Генерация дополнительных комплектов**. Формирование документов будет производится либо по скриптам генерации документов, либо по настройкам Техкард, либо по скриптам C#.
Создание шаблона комплекта документов производится по команде **Создать**. В открывшемся окне необходимо ввести наименование шаблона комплекта документов, а также указать объект, для которого данный комплект документов будет формироваться.
После этого откроется редактор шаблонов комплектов документов. 
На рисунке выше показан пример скрипта шаблона комплекта документов для единичного ТП. Первоначально в скрипте производится сбор данных (параметров) в **Глобальной таблице** (см. п. ).
Далее в примере добавлены операторы создания головного комплекта документов для мехобработки и сборки. Каждый из комплектов будет формироваться только для соответствующего вида производства ТП. Различие применения комплектов задается условием.
Внутрь головных комплектов документов вставляются операторы **Создание документа** которые будут формироваться либо по скрипту генерации документов, либо C#, либо по настройке TECHCARD. Также внутри головного комплекта документов могут входить дополнительные комплекты документов, например, комплект документов на операцию или дополнительный комплект формируемый по команде **Дополнительный комплект**.
Редактирование скриптов будет описано в п. .
Описание операторов, применяющихся в скриптах шаблонов комплектов документов, будет дано в п. .
Описание операторов сбора глобальной таблицы будет дано в п. .
Генерация комплектов документов использованием универсальных скриптовых языков программирования будет описана в п. .

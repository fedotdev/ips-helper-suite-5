# Общие сведения
По умолчанию, в **Навигаторе** составы отображаются по одному типу связи – связи по умолчанию, что настраивается в **Конфигураторе базы данных**. Однако администратор может настроить отображение нескольких типов связей для разных типов родительских объектов, а также указать, в какой последовательности отображаются связи в составах.
Настройки позволяют указать типы родительских объектов, типы отображаемых связей, порядок отображения связей, а также порядок отображения дочерних типов объектов. Помимо этого, можно задать, какие колонки будут отображаться в списках с составами для конкретных родительских типов объектов (т.н. Настройки отображения **Навигатора**). Все указанные настройки хранятся в **Конфигуратор базы данных / Типы объектов / Настройки системы / Конфигурации ролей** в списке атрибутов **Сортировка и отображение составов** и **Настройки видов Навигатора**.
Привязка настроек выполняется к ролям. У каждого объекта типа **Роли** есть ссылочный атрибут **Конфигурация роли** , который может ссылаться на объект типа **Конфигурации роли**. Соответственно, при выполнении входа в систему с какой-либо ролью **Навигатор** получает настройки у соответствующего объекта с конфигурациями роли.
В базе данных есть системный объект типа **Конфигурации ролей** – **Настройки роли по умолчанию**. Если для роли не назначена конфигурация, то настройки будут получены из указанного объекта. Удалить данный объект не позволит система, т.к. объекту назначен системный GUID.
Чтобы открыть указанный редактор, следует выполнить команду главного меню **Настройка/Отображение и сортировка составов**.
Будет открыто приложение **Отображение и сортировка составов**. Рассмотрим подробнее его элементы управления.

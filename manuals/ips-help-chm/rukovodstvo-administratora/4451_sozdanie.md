# Создание
Чтобы создать новую предметную область, в дереве метаданных отметьте элемент **Предметные области** и примените команду **Добавить** его контекстного меню. При этом в дереве появится новая предметная область, большинству свойств которой будут присвоены значения по умолчанию. Отредактируйте свойства созданной предметной области и нажмите кнопку **Применить**.
Задать принадлежность типу объектов, типу связей, атрибуту и т.д. можно в их свойстве **Предметная область** , отметив в выпадающем списке ту или те предметные области, работая в которых, пользователь будет видеть данную информацию.

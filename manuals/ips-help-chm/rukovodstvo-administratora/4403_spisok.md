# Список
Увидеть содержимое элемента можно не только, открыв его узел в дереве метаданных, но и на закладке **Список** в рабочей области, где в виде таблицы представлен список метаданных, относящихся к выбранному в дереве метаданных элементу. В таблице представлены все свойства метаданных в режиме просмотра с возможностью отсортировать список по значению одной из колонок. Также список можно сгруппировать по значениям любого из свойств метаданных элемента. Для этого нужно перетянуть заголовок колонки левой кнопкой мыши в специальную область к фразе **Перетащите заголовок колонки в эту область для группировки по значениям этой колонки**. 
Выделив двойным щелчком мыши одну из строк списка, можно перейти в режим редактирования свойств выбранного экземпляра метаданных на его закладку **Свойства**.

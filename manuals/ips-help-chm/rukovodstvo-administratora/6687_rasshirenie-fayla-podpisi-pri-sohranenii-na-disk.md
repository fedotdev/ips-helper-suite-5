# Расширение файла подписи при сохранении на диск
По команде **Сохранить на диск** файл электронной подписи по умолчанию имеет расширением **.sig**.
Для того чтобы задать конкретное расширения файла подписи, при сохранении на диск, следует открыть диалог с настройками **Параметры IPS** , далее для настройки **Электронные подписи \ Общие настройки \ Расширение файла подписи** следует задать необходимое расширения для сохранения файла подписи. Для сохранения внесенных изменений следует нажать кнопку .
Примечание: настройка **Параметры IPS\** **Электронные подписи \ Общие настройки \ Расширение файла подписи** по умолчанию имеет пустое значение.

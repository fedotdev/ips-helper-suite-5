# Управление информацией об изделиях
Примечание: данные настройки будут доступны в том случае, если загружен модуль расширения **Управление информацией об изделиях PDM**.
**Внимание!** Данные настройки являются глобальными для всей базы данных. После их изменения, вновь создаваемые примечания в допустимых заменах будут формироваться по новым правилам. В старые спецификации изменения вноситься не будут. Все настройки проводятся только администратором системы.
**Управление информацией об изделиях** – это модуль, который предоставляет необходимую информацию об изделии на том или ином этапе жизненного цикла. Вызвать настройки модуля можно с помощью команды **Параметры IPS** из меню **Настройка** панели инструментов системы IPS. В открывшемся окне выбрать группу**Управление информацией об изделиях** из пункта **Система**. Данный модуль делится на две основные подгруппы со своими параметрами. Входящие в состав параметры можно настроить.
Группа **Допустимые значения** по умолчанию использует положения ГОСТ 2.109-73. Администратор системы имеет возможность изменить способ генерации расшифровок допустимых замен (в графе **Примечание** спецификаций).
Поле **Использовать неразрывный пробел в количествах** необходимо для автоматического применения неразрывного пробела в строках с количеством, вместо обычного. Данный пробел ставиться между количеством и единицей измерения.
Группа **Настройка синхронизации атрибутов документов и изделий** необходима для синхронизации атрибутов документов и изделий. Синхронизация атрибутов осуществляется только из **Документов** в **Изделие**. Далее пользователь может изменять значения атрибутов отдельно в изделиях, однако, в системе IPS не предусмотрена обратная синхронизация, поэтому изменения не будут переноситься в документы.
**Настройка синхронизации атрибутов документов и изделий** делится на две функциональные области.
Область **_1_** отображает список типов объектов, которые являются главными конструкторскими документами и в которых будет проводиться синхронизация по назначенным атрибутам с изделием. Данный список настроен по умолчанию, однако, его можно изменить с помощью кнопок и .
Область **_2_** отображает список назначенных атрибутов. Данный список можно изменять с помощью кнопок и .
**Внимание!** При синхронизации система IPS проводит изменение атрибута, только если может это сделать.

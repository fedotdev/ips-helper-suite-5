# Режим сохранения страховых копий удаляемых записей журнала
Система позволяет автоматически сохранять в xml-файлы записи журнала событий, удаляемые из журнала тем или иным способом. Для каждой операции удаления сохраняется свой файл, имя которого начинается на имя компьютера, с которого вызвали удаление записей. Каждый файл запакован и имеет расширение .ZIP. Файлы сохраняются в тот же каталог сервера приложений, в который пишутся логи IPS. Путь к каталогу содержится в переменной LogPath секции **< appSettings>** конфигурационного файла сервера приложений IPS. Ввиду большого количества записей, хранящихся в журнале аудита, страховые копии удаляемых записей могут занимать много места (даже в упакованном виде), поэтому при включении данного режима рекомендуется иметь не менее 10 гигабайт свободного пространства на диске с каталогом LogPath.
Режим сохранения страховых копий записей включается добавлением в секцию **< appSettings>** конфигурационного файла сервера приложений IPS следующей строки:
· **< add key="BackupEvenlogRecords" value="1" />**

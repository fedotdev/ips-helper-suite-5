# Закладка Роли для группы пользователей
Для группы пользователей в карточке объекта доступна закладка **Роли** , в которой предоставляется возможность добавить необходимые роли для всей группы. Для этого следует:
1\. В дереве **Конфигуратор базы данных** выбрать объект **Роли** и перейти на закладку **Допустимые связи**.
2\. В области списка связей из контекстного меню вызвать команду **Добавить.**
3\. В открывшемся диалоговом окне выбрать объект **Группы пользователей** и нажать кнопку .

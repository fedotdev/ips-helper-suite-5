# Синтаксис формул
Формулы представляют собой математическое выражение, состоящее из переменных, операторов, констант и разделителей. Результатом вычисления формулы может быть целое, вещественное число, строка или логическое значение. Выражение вычисляется слева направо, если иной порядок вычисления не указан при помощи круглых скобок.
Пример формулы, вычисляющей значение атрибута Размеры и параметры для таблицы Винты с полукруглой головкой исполнение 1:
'М'+[Диаметр резьбы D]+[Шаг]+'-'+[ПОЛЕ ДОПУСКА]+'*'+[Длина]+'.'+[КЛАСС ПРОЧНОСТИ]+'.'+[ПОКРЫТИЕ]
Для этой же таблицы вычисление массы одного винта производится по формуле:
[Масса 1000 шт]/1000
Константы могут быть целого типа, например 321, вещественного типа с использованием точки в качестве разделителя дробной части, например 3.1415, строковые – любые символы, заключенные в одиночные кавычки ('строковая константа') и логические TRUE и FALSE. Вычислитель формул имеет ряд предопределенных констант, перечисленных ниже.
| Константа | Значение |
| --- | --- |
| E | 2.71828 |
| PI | 3.14159 |
| TRUE | истина |
| FALSE | ложь |
В качестве переменных выступают имена атрибутов. Имя должно быть заключено в квадратные скобки, если внутри него содержатся символы, отличные от букв и цифр, например **[Размеры и параметры]**. 
Если имя состоит только из одного слова, то использование квадратных скобок не обязательно, например **Класс**. Но рекомендуется и такие имена заключать в скобки. Это, с одной стороны повышает наглядность формулы, и, с другой, позволяет избежать конфликта имен, если имя поля совпадает с именем функции или константы.
Операторы описывают действие, которое выполняется над константами и переменными. Операторы имеют приоритет, что надо учитывать при составлении формулы. Ниже приведена таблица с допустимыми операторами в порядке снижения их приоритета. Таким образом, операторы, расположенные выше в таблице, выполняются раньше. Как уже было сказано, для изменения очередности выполнения операторов следует использовать круглые скобки, например: 
1\. A+B*2 – сначала будет выполнено умножение переменной B на 2 а потом результат будет сложен с переменной A
2\. (A+B)*2 – Переменные А и B будут сложены, а потом результат будет умножен на 2
| Оператор | Выполняемое действие |
| --- | --- |
| () | Вызов функции |
| ~ | Битовый NOT, дополнение до 1 |
| ! | Логический NOT |
| * | Умножение |
| / | Деление |
| % | Модуль |
| + | Сложение |
| - | Вычитание |
| << | Сдвиг влево |
| >> | Сдвиг вправо |
| < | Меньше |
| > | Больше |
| <= | Меньше или равно |
| >= | Больше или равно |
| == | Равно |
| != | Не равно |
| & | Битовый AND |
| | Битовый OR |
| ^ | Битовый XOR |
| && | Логический AND |
| | | Логический OR |
| , | Запятая, служит для разделения параметров в вызове функции |
При выполнении вычислений система преобразует тип результата вычислений по следующим правилам:
1\. Если оба из аргументов одного типа, то в результате получается тот же тип
2\. Если аргументы целого и вещественного чисел – результат вещественное число
3\. При сложении строк с числами, последние преобразуются в строки и выполняется операция объединения строк и результат – строка. Другие операции со строками (умножение, деление и т.д.) вызывают ошибку.
В момент ввода система проверяет синтаксис выражения и корректность применения операторов и функций. При возникновении ошибки ошибочный фрагмент выражения выделяется подчеркиванием и выводится поясняющее описание.

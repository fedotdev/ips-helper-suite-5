# Внешний вид
Свойства этой группы позволяют настроить внешний вид страницы.
· **Альбомная ориентация**. По умолчанию создаваемые страницы шаблона имеют книжную ориентацию. Данное свойство позволяет изменить ориентацию страницы на альбомную.
· **Видимый**. Управляет видимостью элементов на странице. Позволяет сделать все элементы страницы невидимыми, в результате чего элементы исчезают со страницы. Чтобы вернуть их назад (сделать видимыми), необходимо отметить страницу и применить команду ее контекстного меню **Показать** или перейти на панель **Свойства** и включить ее свойство **Видимый**.
· **Печатать рамку**. Данное свойство позволяет включить режим, при котором при печати страницы будет выводиться рамка.
· **Размеры страницы**. Отображает размеры страницы и позволяет их редактировать.

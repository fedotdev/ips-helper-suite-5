# Настройка прототипов для файловых объектов
При создании новых объектов, содержащих файловые атрибуты (например, файловых документов), часто требуется инициализировать значения таких атрибутов файлами-прототипами. Для этого в IPS используется тип объектов **Прототипы для файловых объектов** , который находится в ветке типов **Настройки системы**. Прототипы разделены на персональные и общие, что позволяет создавать как индивидуальные файловые прототипы (видимые только создавшему их пользователю), так и общие файловые прототипы, доступные всем пользователям IPS.
В атрибуте **Глобальные идентификаторы типов объектов** указываются типы объектов, при создании которых система будет использовать данный файловый прототип. В поле **Заголовок объекта** указывается наименование прототипа. Прототипу можно добавлять атрибут **Глобальный идентификатор атрибута** , в котором можно указать атрибут, для которого будет использован данный файл-прототип. По умолчанию прототип используется для инициализации атрибута **Файл**.
На закладке **Файлы** настраивается список файлов, которые будут использоваться системой при создании файлового объекта соответствующего типа. Подробнее о работе с закладкой **Файлы** см. в . Для каждого файла в поле **Шаблон имени файла** укажите способ формирования имени файла в создаваемом объекте. В шаблоне в квадратных скобках можно использовать подстановку значений атрибутов создаваемого объекта, указывая полные наименования атрибутов. При отсутствии у создаваемого объекта данного атрибута вместо него будет подставлена пустая строка.
Если шаблон имени файла не задан, то имя будет сформировано по следующему шаблону: **F[Идентификатор версии объекта]_[FileIndex].[Расширение файла документа]** , где **FileIndex** указывает на подстановку порядкового номера файла в списке файлов прототипа, а расширение файла берётся из настроек типа объектов на закладке **Тип** **«Документ»** (см. п. ).
**Внимание!** Не забывайте в шаблоне указывать расширение для создаваемого файла.

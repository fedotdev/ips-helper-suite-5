# Роли
Различные модули системы имеют свой набор функций, с которыми пользователи работают на отдельных закладках рабочей области. Для каждого пользователя необходим свой набор функций, к тому же большое количество отображаемых закладок может препятствовать удобному восприятию информации на экране. Система IPS позволяет ограничивать набор отображаемых закладок различных модулей системы, в зависимости от ролей, под которой пользователи входят в систему, поэтому для каждого пользователя программой IPS необходимо настроить свою роль или создать новую, которой нет в стандартных настройках.
Вход в рабочую область настроек ролей осуществляется с помощью модуля Администратор базы данных, который входит в стандартных комплект поставки системы. Вызов окна настройки объекта осуществляется тремя способами:
· **Приложение/Навигатор/Информационное пространство/Администрирование/Администратор базы данных/Роли**.
· **Настройка/Администратор базы данных/Роли**
· **Вид/Панель задач/Администрирование/Администратор базы данных/Роли.**
Для коррекции функциональных возможностей любого типа объекта роли необходимо выполнить следующие настройки интерфейса пользователя:
· **Контекстное меню по умолчанию** — данная настройка дает возможность скрывать/отображать команды в контекстных меню для узлов **Навигатора**.
· **Закладки** — данная настройка дает возможность скрывать/отображать закладки для узлов **Навигатора**.
С помощью двойного клика мыши необходимо выбрать роль и войти в **Карточку объекта**. Для того чтобы выполнить одну из этих настроек, следует открыть закладки **Контекстные меню по умолчанию** и **Закладки**.

Принцип работы с закладками одинаков. Если убрать галку возле названия команды контекстного меню или закладки, то данный элемент не будет отображаться для узлов **Навигатора** в контекстных меню и списке закладок. Нажатие кнопки **По умолчанию** включит отображение всех элементов.
**Внимание!** По умолчанию данные настройки не перекрывают настройки пользователя! Они являются рекомендуемыми настройками! Если требуется запретить пользователю изменять видимость закладок, и назначать ему список видимых закладок из самой роли, следует открыть свойства требуемой роли и установить значение атрибута **Блокирование видимости закладок** в значение **Да**. В настройке команд контекстных меню есть возможность создавать/удалять группы, а также перемещать команды в пределах своего уровня (контекстное меню – древовидная структура).

# Список правил подбора версий
Список правил подбора версий можно отыскать с помощью приложения **Администратор базы данных** в дочернем узле дерева **Настройки системы/Правила подбора версий**.
Общие правила доступны для всех пользователей, персональные – только их владельцам. Системные правила по умолчанию создаются сервером приложений в соответствии с набором уровней продвижения, настроенных в базе данных – для каждого уровня продвижения – свое системное правило подбора версий.
Системные правила подбора версий, созданные таким образом, редактировать не допускается самой системой.

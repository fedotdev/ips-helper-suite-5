# Архитектура редактора ввода спец.символов
Открыть окно **Редактирование формулы** можно с помощью следующих команд:
1\. В модуле AVS следует выбрать меню **Правка** , а в выпадающем списке команду **Вставить формулу…**
2\. В текстовой строке выбрать команду **Вставить спец.символ / Открыть редактор** из контекстного меню.
Внешний вид редактора формул показан ниже на рисунке:
Описание функционала описано далее:
· **Строка поиска спец.символа**. При вводе текста появляется выпадающий список, в котором система отображаются все спец.символы, в наименовании которых входит введенный текст. По двойному клику система автоматически осуществляет позиционирование на выбранном спец.символе. На рисунке ниже показан процесс выбора спец.символа с помощью поисковой строки:
· **Вид.** Способ отображения спец.символов. 
· **Окно выбора спецсимвола.** В нем отображаются все доступные спецсимволы.
− **Избранные.** Часто используемые спец.символы можно добавить в группу **Избранны** е с помощью команды **Добавить в избранные** из контекстного меню необходимого спец.символа. 
Добавленные спец.символы в группу **Избранные** можно использовать не открывая редактор, прямо из меню редактирования текстового поля или на главной панели инструментов системы IPS.
Для исключения спец.символа из списка избранных необходимо выбрать команды **Удалить из избранного** из контекстного меню спец.символа.

− **Недавно использовавшиеся.** Группа, в которой сохранены последние, использованные пользователем, спец.символы. 
· **Текущая формула.** Окно, в котором отображается список введенных пользователем спецсимволов, только наименование.
· **Параметры.** Окно для ввода значений параметров спец.символа. В графе **Стиль** пользователь может настроить стиль текста.
· **Общая формула.** Окно с графическим видом выбранных спец.символов с параметрами. 
· **Кнопки управления.** Кнопки для добавления/удаления и замены спец.символа находятся слева от окна **Текущая формула**. Кнопки для изменения очередности спец.символом находятся справа от окна **Текущая формула.**

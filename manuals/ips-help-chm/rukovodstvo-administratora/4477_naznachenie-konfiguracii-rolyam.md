# Назначение конфигурации ролям
Выделите требуемую конфигурацию в дереве конфигураций, и с помощью команды контекстного меню **Назначить роли** вызовите окно **Выберите роль, которой требуется назначить указанный объект**.
В окне следует выбрать одну или несколько ролей, которым будет назначена указанная конфигурация. После нажатия кнопки **ОК** выбранная роль будет связана с текущей конфигурацией.
Удаление роли из конфигурации выполняется аналогично, с помощью команды контекстного меню **Убрать из роли**.
**Внимание!** Если в предыдущем окне выбрать роль, для которой уже была назначена конфигурация, то настройки будут изменены, роли будет назначена новая конфигурация. Если удалить роль из конфигурации, то для роли будет назначена конфигурация **Настройки роли по умолчанию**.
Примечание: назначение конфигурации для роли можно также выполнять с помощью перетаскивания мышью элементов в дереве с конфигурациями ролей. Для этого можно перетаскивать строку с ролью в дереве конфигураций из одной конфигурации в другую.

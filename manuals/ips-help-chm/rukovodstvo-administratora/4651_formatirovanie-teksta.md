# Форматирование текста
Система IPS располагает средствами, позволяющими форматировать текстовые поля элементов. Предназначенные для этого инструменты отображаются на панели **Свойства** в группе свойств **Внешний вид** , а также на панели инструментов **Форматирование**.
Форматирование на панели **Свойства** производятся в том случае, если изменения нужно применить ко всему тексту элемента. Для этого необходимо поместить текстовый курсор в поле элемента и установить необходимые значения свойств на панели.
Панель инструментов **Форматирование** во многом дублирует панель **Свойства** , но отличается тем, что позволяет производить форматирование, как над всем текстом элемента, так и над его фрагментами. Для форматирования фрагмента текста его необходимо предварительно выделить текстовым курсором. В этом случае форматирование будет произведено лишь над выделенным фрагментом.
 **Шрифт** — позволяет выбрать шрифт из списка шрифтов.
 **Размер шрифта** — позволяет выбрать размер шрифта.
 **Полужирный** — позволяет установить полужирное начертание текста.
 **Курсив** — позволяет установить наклонное начертание текста.
 **Подчеркнутый** — подчеркивает введенный текст.
 **Подстрочный индекс,** **Надстрочный индекс** — позволяют форматировать обычный символ в индекс. 
**Горизонтальное выравнивание** — набор инструментов, позволяющих выровнять текст относительно вертикальных границ элемента.
 **Выравнивание текста относительно границ** — предоставляет набор инструментов для выравнивая текста в поле элемента относительно всех его границ.
 **Междустрочный интервал** — позволяет установить интервал между строками текста.
**Формат абзаца** — вызывает диалог настройки абзаца, в котором можно настроить основные свойства текстового абзаца.
 **Направление текста** — позволяет изменить направление текста в поле элемента.
 **Границы** — позволяет установить режим отображения границ элемента.
 **Нумерованный список по умолчанию** — позволяет представить текст элемента в виде нумерованного списка.
**Маркированный список по умолчанию** — позволяет представить текст элемента в виде маркированного списка.
**Уменьшить отступ** — позволяет уменьшить отступ выделенной строки (строк) текста от начала строки.
**Увеличить отступ** — позволяет увеличить отступ выделенной строки (строк) текста от начала строки. 
 **Цвет фона** — позволяет выбрать цвет фона элемента из палитры цветов.
 **Выделение цветом** — позволяет выбрать цвет из палитры цветов для выделения текста.
 **Цвет текста** — позволяет выбрать цвет из палитры цветов для выделения символов текста.

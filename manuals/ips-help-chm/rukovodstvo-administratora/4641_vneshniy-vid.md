# Внешний вид
Свойства этой группы позволяют настроить внешний вид элементов. Основные свойства этой группы дублируются командами панели инструментов **Форматирование**.
· **Абзац**. Представляет собой подгруппу, включающую в себя настройки свойств абзаца. Здесь можно указать выравнивание текста в абзаце, междустрочные интервалы, отступы и т.п.
· **Блокировка структуры**. Свойство, которое позволяет включить запрет на изменение структуры таблицы. Т.е. при включенном параметре, пользователь не может менять количество столбцов и строк в таблице.
· **Базовая высота строки**. Отображается в свойствах элемента **Таблица**. Позволяет задать высоту строк таблицы.
· **Авторазмер по высоте (по ширине)**. Отображается для элемента **Редактор текста**. Позволяет установить режим, при котором высота (ширина) элемента будет подстраиваться под размер вводимого текста.
· **Видимый**. Управляет видимостью элемента. Позволяет сделать элемент невидимым на странице.
· **Выравнивание элемента**. Позволяет выровнять элемент относительно других (рядом расположенных) элементов или границ страницы.
· **Максимальная высота**. Отображается для элемента **Таблица**. Позволяет задать максимальную высоту таблицы. Если строки таблицы выходят за эту границу, то они переносятся на другую страницу.
· **Минимальная высота**. Отображается для таблиц и ячеек таблиц. Позволяет задать минимальную высоту элемента при автоматическом расчёте высоты исходя из данных внутри элемента. При изменении высоты элемента вручную, через свойства или перетаскивая границы мышью, новое значение высоты устанавливается как минимальное.
· **Ориентация текста**. Позволяет указать направление текста.
· **Прозрачный**. Если установлен данный режим, то, в случае перекрытия данным элементом других, пользователь будет видеть нижерасположенные элементы.
· **Фиксированная геометрия**. Свойство, которое позволяет включить запрет на изменение размеров элементов. Т.е. при включенном параметре, пользователь не может менять геометрию шаблон.
· **Размер рисунка**. Отображает размер загруженного рисунка для элемента **Контейнер**.
· **Режим масштабирования**. Позволяет выбрать масштаб загруженного изображения для элемента **Контейнер**.
· **Только для чтения**. Позволяет установить режим, при котором текст элемента будет отображаться только для чтения, без возможности его редактирования.
· **Цвет фона**. Позволяет выбрать цвет фона элемента из палитры цветов.
· **Шрифт**. Представляет собой подгруппу, включающую в себя настройки свойств шрифта.

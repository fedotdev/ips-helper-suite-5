# Объекты типа Документы
Помимо настройки свойств, являющимися общими для всех типов объектов, объекты типа **Документы** нуждаются в дополнительных настройках. Такие настройки осуществляются на закладке **Тип Документ** , которая отображается, если выбранный в дереве метаданных элемент является абстрактным типом **Документы** или одним из его дочерних типов.
Рабочая область **Тип Документ** разделена на три основные группы, описание которых представлено ниже.

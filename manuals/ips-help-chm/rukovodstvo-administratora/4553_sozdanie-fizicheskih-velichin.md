# Создание физических величин
Для создания новой физической величины выделите в дереве навигации **Администратора базы данных** пункт **Физические величины** и из контекстного меню выполните команду **Создать.** В появившемся диалоге укажите наименование и нажмите кнопку **Готово**. 
После этого в списке появится созданная физическая величина.

# Идентификация
· **Идентификатор**. Уникальный номер элемента, присваиваемый системой автоматически.
· **Имя**. Позволяет ввести название элемента, под которым он будет отображаться в схеме документа. Если поле не заполнено, то элементу автоматически присваивается наименование по типу элемента и номеру его идентификатора (например, **Редактор текста (48)**).
· **Тип элемента**. Отображает тип создаваемого элемента.

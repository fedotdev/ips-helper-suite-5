# Машиночитаемые доверенности
Машиночитаемая доверенность (МЧД) – это электронная форма бумажной доверенности, подписанная электронной подписью руководителя организации, выдаваемая сотруднику для возможности подписания документов организации электронной подписью физического лица.
Система IPS предоставляет возможность подписывать документы усиленной электронной подписью с использованием МЧД со следующими условиями:
· База данных должна быть настроена на применение МЧД.
· Контроль за тем, является ли МЧД действующей на момент подписания, возлагается на администратора системы/организацию.
· Система IPS не сохраняет в своей базе файлы МЧД, вместо этого он требует единый регистрационный номер МЧД, полученный при оформлении и регистрации МЧД у регистраторов МЧД. 
Единый регистрационный номер МЧД представляет собой GUID (Globally Unique Identifier) – стандартизованный глобальный уникальный идентификатор, текст которого записывается в виде строки из тридцати двух шестнадцатеричных цифр, разбитой на группы дефисами и опционально окружённой фигурными скобками, например {27657218-924c-43b5-8ac5-db58a2ad3fc7}.

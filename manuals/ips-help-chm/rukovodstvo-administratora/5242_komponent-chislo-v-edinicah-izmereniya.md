# Компонент Число в единицах измерения
В данном компоненте основные свойства унаследованы от компонента **Текстовое поле** , кроме того, есть дополнительные свойства:
· **Единица измерения**. Позволяет выбрать единицу измерения по умолчанию.
· **Значение по умолчанию**. Позволяет установить значение атрибута, которое будет показано пользователю по умолчанию.
· **Сортировка единиц измерения**. Позволяет установить порядок сортировки списка единиц измерения. 
Доступно три варианта сортировки:
− **По умолчанию** (от меньшего к большему в пределах физических величин),
− **По алфавиту А-Я** ,
− **По алфавиту Я-А**.
· **Список единиц измерения**. Позволяет вручную выбрать единицы измерения, которые будут показаны пользователю в списке."

# Приложение 4 Системные переменные маршрутизатора
В маршрутизаторе IPS наряду с пользовательскими переменными могут использоваться системные переменные. Основные системные переменные и их назначение описаны ниже:
· **Инициатор процесса** – список пользователей. Возвращает список пользователей, состоящий из одного элемента, содержит ссылку на пользователя, инициировавшего текущий процесс. __
Примечание: может использоваться для отправки сообщений и результатов выполнения процесса инициатору процесса, и т.д.
· **Предыдущий исполнитель** – список пользователей. Содержит ссылку на пользователя, выполнявшего предыдущее пользовательское действие.__
· **Запрещать удаление вложенных объектов** – логический. Запрещает удалять документы, участвующие в выполняющихся процессах с включенной настройкой. 
Значения:
0 (умолчание) – никаких ограничений;
1 – запрещено удалять документы, пока процесс выполняется.
· **Разрешать повторный запуск вложений** – логический. Определяет, можно ли отправлять одни и те же документы по процессу, основанном на одном и том же шаблоне, несколько раз. 
Возможные значения:
1 (умолчание) – можно запускать сколько угодно процессов без ограничений; 
0 – при попытке запуска процесса проводится поиск уже выполняющихся процессов по текущему шаблону, имеющих такие же вложения. Если текущие объекты (вложения) уже участвуют в выполняющемся процессе по этому же шаблону, в запуске нового процесса будет отказано.

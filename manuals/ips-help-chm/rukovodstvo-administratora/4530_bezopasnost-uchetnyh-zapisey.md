# Безопасность учетных записей
Настройки безопасности учетных записей доступны по команде **Настройка / Параметры IPS / Пользователи** :
Доступны следующие настройки:
· **Автоматическое повышение уровня доступа редактируемых объектов** – настройка позволяет автоматически повышать уровень доступа объектов до уровня сессии пользователя в момент взятия объектов на изменение (изменение настройки требует перезапуска сервера приложений).
· **Время жизни паролей (дней)** – время, в течение которого пароль пользователя считается действительным. По истечении указанного периода пользователь будет обязан изменить свой пароль. Значение **0** снимает ограничения на время жизни паролей;
· **Изменение паролей пользователями** – с помощью данной настройки администратор может разрешить (запретить) пользователям изменять свои пароли.
· **История паролей** – количество последних паролей, которые не должны повторяться. Используется системой для того, чтобы при очередной смене пароля пользователь не смог использовать повторно свои предыдущие пароли. Значение **0** – история паролей не хранится.
· **Метод шифровки паролей** – метод шифровки паролей. В самом незащищенном случае пароли могут храниться в открытом виде, но это не рекомендуется в целях безопасности. В большинстве случаев для этих целей используется одна из хэш-функций – **SHA1** или **MD5**.
· **Минимальная длина паролей** – минимальная длина паролей для всех учетных записей в системе. Значение **0** – нет ограничений на минимальную длину пароля. Максимальная длина пароля в текущей версии IPS – 40 символов.
· **Обновление кэша прав доступа, минут** – в течение какого времени информация о правах доступа к объектам считается актуальной (чтение прав доступа – ресурсоемкая операция, требующая кэширования).
· **Сложные пароли** – настройка, позволяющая администратору усилить защиту системы усложнением паролей пользователей. При ее включении IPS будет требовать пароли, состоящие из букв в разных регистрах, цифр и спецсимволов.
Примечание: если администратор запретил изменение паролей пользователями, а также установил время жизни паролей, то по истечении этого времени пользователи получат уведомление о том, что срок действия пароля истек, но изменить пароль они не имеют права. Соответственно, пользователям придется обратиться к администратору IPS.
· **Сохранять историю поисковых запросов** – настройка позволяет хранить историю поисковых запросов, с помощью которых пользователи искали информацию в общем поисковом индексе. Включенная настройка **Сохранять историю поисковых запросов** автоматически добавляет закладку **История поисковых запросов** на рабочую область объекта **Журнал событий** для отображения списка поисковых запросов. Описание закладки **История поисковых запросов** подробно представлено в п. . Данная настройка также позволяет сохранять поисковые запросы пользователя за последние 30 дней и сортировать их по частоте использования в строке **Искать.**
**Внимание!** История запросов заполняется с момента включения настройки **Сохранять историю поисковых запросов.**

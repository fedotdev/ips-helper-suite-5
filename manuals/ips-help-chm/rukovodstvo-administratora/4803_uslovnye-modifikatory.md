# Условные модификаторы
Условные модификаторы (**Если существует** и **Если все**) имеют параметры аналогичные параметрам модификаторов управления (см. п. ). 
В отличие от остальных модификаторов, условные **никогда не меняют контекст** : вложенные операторы всегда будут выполняться в том контексте, который вернул оператор поиска объектов либо в прежнем контексте, если модификатор применен к другому оператору.
Модификатор **Если существует** выполнит вложенные операторы один раз, и только в том случае, если **хотя бы для одного** объекта из набора выполняется заданное условие. 
Модификатор **Если все** выполнит вложенные операторы один раз, и только в том случае, если заданное условие выполняется для **всех** объектов из набора.
**Внимание**! Распространенной ошибкой является использование модификатора **Если существует** вместо модификатора **Для первого** , и наоборот. Они различаются тем, что модификатор **Для первого** передает в качестве контекста только тот объект, для которого условие было истинным, а модификатор **Если существует** не меняет контекст.

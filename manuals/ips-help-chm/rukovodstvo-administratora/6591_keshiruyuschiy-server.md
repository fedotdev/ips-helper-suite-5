# Кэширующий сервер
Для работы с кэширующим сервером необходимо привязать имеющей доступ к файлам всех типов объектов к специальной учетной записи. Для этого выведется сообщение при первом запуске сервера.
При создании учетной записи следует заполнить необходимые поля, а затем нажать кнопку 
**Внимание!** При появлении сообщения об отсутствии зарегистрированного объекта в БД, следует добавить соответствующий объект в IPS.
Для регистрации объекта типа **Кэширующие серверы** следует:
1\. Отркыть систему IPS и перейти в приложение **Администратор базы данных \ Настройка системы \ Кэширующие серверы** и в рабочей области вызвать команду создать.
2\. В открывшемся окне необходимо задать следующие параметры.
Где:
· **Заголовок объекта** – это наименование сервера для отображения в системе IPS. Которое может быть написано в произвольном виде.
· **Адрес сервера (URL)** – это адрес, по которому клиентское приложение будет обращаться к API кэширующего сервера. 
Примечание: адрес должен быть доступен с ПК пользователей и формироваться, как сочетание http(s)://<IP сервера DVS>:<Порт сервиса>, либо другой адрес при наличии настроенного прокси сервера.
· **Ключ шифрования** – это строковое значение для шифрования учетной записи сервиса DVS.
3\. Для завершения создания объекта типа **Кэширующие серверы** следует нажать кнопку .

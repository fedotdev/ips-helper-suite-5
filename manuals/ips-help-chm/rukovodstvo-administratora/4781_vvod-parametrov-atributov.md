# Ввод параметров (атрибутов)
Как правило, в формулах экспертной системы используются параметры, задаваемые парами **< Тип объекта>** и **< Тип атрибута>**. Для выбора такого параметра достаточно нажать кнопку в поле редактирования **Имя атрибута**. После этого появится диалог выбора типа объекта и типа атрибута.
Если нужный параметр не зависит от типа объекта (например, временный атрибут или атрибут объекта контекста), следует выключить переключатель **Тип объекта** перед нажатием кнопки .
После выбора параметра панель **Ввод атрибута** отображает тип объекта, тип атрибута и тип данных выбранного атрибута. Для вставки выбранного параметра в формулу нажмите кнопку **Вставить атрибут**. Кнопка **Очистить** сбрасывает выбранный параметр.
Все выбранные параметры попадают в выпадающий список **Использованные параметры** , чтобы в следующий раз их можно было выбрать из этого списка, а не искать заново. 
Переключатель **Если нет значения, подставлять пустое** , позволяет подставить **значение по умолчанию** для данного типа данных, если атрибута нет, или его значение не задано. Для строковых атрибутов будет подставлена пустая строка, для числовых – 0. В формуле данный атрибут будет помечаться символом**#** перед атрибутом.

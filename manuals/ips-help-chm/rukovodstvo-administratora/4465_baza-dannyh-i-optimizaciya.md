# База данных и оптимизация
В данном разделе собраны общие для всей базы данных IPS настройки, регулирующие различные режимы работы ядра системы, а также некоторых модулей расширения. Управлять данными настройками может только пользователь с правами администратора.
Для вызова окна настроек воспользуйтесь командой главного меню IPS **Настройка / Параметры IPS**. Далее следует перейти в раздел **Система / База данных и оптимизация.** На рисунке ниже показаны настройки, рекомендуемые для увеличения производительности работы системы:
В окне доступны следующие настройки:
· **Автоматическая мягкая конкретизация создаваемых связей**. Режим, при включении которого все связи с разрешённой конкретизацией пользователем будут конкретизироваться автоматически при их создании (т.е. на каждой связи будет автоматически указан номер подбираемой версии объекта). Данный режим использовать не рекомендуется, т.к. в этом случае пользователи далеко не всегда имеют возможность указать версию дочернего объекта у создаваемой связи и контроль над процессом конкретизации версий утрачивается.
· **Заменять настройки видимости объектов настройками видимости архивов**. В данном режиме настройки видимости объектов, находящихся в архиве, автоматически заменяются настройками видимости самого архива (если таковые имеются). Замена производится в момент помещения объекта в архив либо при изменении настроек видимости архива.
· **Заменять настройки видимости объектов настройками видимости проектов**. В данном режиме настройки видимости объектов с заполненным атрибутом **Принадлежность к проекту** автоматически заменяются настройками видимости указанных проектов (если проекты имеют настройки видимости). Замена производится в момент помещения объекта в проект либо при изменении настроек видимости проекта.
· **Запрет обновления версии базы данных сервером IPS.** Данный переключатель позволяет защитить базу данных от обновления более новой версией сервера приложений IPS.
· **Имя табличного пространства для хранения индексов.** Позволяет для СУБД Oracle и PostgreSQL указать имя табличного пространства, в котором будут размещаться индексы новых таблиц, создаваемых IPS. Настройка требует перезагрузки серверов приложений IPS после ее изменения и не влияет на индексы уже созданных таблиц. При перегенерации таблиц представлений данных их индексы также будут размещены в указанном табличном пространстве.
· **Использовать функцию скрытия состава.** При включении данной настройки будут скрыты следующие пункты контекстного меню: **Разрешить скрывать состав** , кнопки панели инструментов и команды главного меню для скрытия состава.
· **Максимум фоновых потоков на задачу**. Позволяет указать максимальное количество потоков на сервере приложений, которые могут быть использованы для выполнения задач, способных распараллеливаться. Не следует устанавливать в этой графе слишком большие значения, т.к. при многопользовательской работе такие задачи будут замедлять работу других пользователей системы. Значение используется сразу всеми серверами приложений, обслуживающими данную базу IPS.
· **Обновлять список закладок при изменении объекта**. Позволяет обновить список отображаемых закладок связанных с измененным объектом. По умолчанию параметр отключен, что в некоторых случиях приводит к необходимости подтверждения команд перечитывания, а при включенном параметре возможно замедление работы клиента.
· **Отложенная запись в журнал событий**. Режим, при включении которого запись в журнал событий (аудит событий) производится в фоновом режиме на сервере приложений. Режим предназначен для ускорения операций записи в журнал. Существует некоторая вероятность, что при падении сервера некоторые события могут не записаться в журнал, поэтому при повышенных требованиях к безопасности не рекомендуется включать данный режим.
· **Отложенная запись истории значений атрибутов**. Режим, при включении которого ведение истории значений атрибутов производится в фоновом режиме на сервере приложений. Режим предназначен для ускорения операций изменения значений атрибутов.
· **Подбор версий: алгоритм.** При выборе подбора версий **Стандартный** – механизм возвращает единственно подходящую версию либо выбирает одну из нескольких подходящих или из всех версий объекта по дополнительному критерию. При выборе подбора версий **С учетом приоритета** – механизм выбирает только из тех подходящих версий, чья группа критериев имеет самый высокий приоритет.
· **Подбор версий: режим**. Данная опция разрешает использование функций подбора состава объектов по серийным номерам и датам (см. ). Рекомендуется включать данную опцию только в случае использования данного функционала на предприятии, т.к. это влияет на производительность операций поиска применяемости и состава объектов. 
Пользователю доступны следующие режимы:
− **По умолчанию**. Данный режим не учитывает серии\даты и статусы версий.
− **Подбор по сериям\датам**. Включенный режим не учитывает статусы версий.
− **Подбор по применяемости статусов**. Режим отключает режим подбора по сериям\датам.
· **Разрешён конфигуратор составов**. Данная опция разрешает использование функций конфигурирования состава объектов (см. ). Не рекомендуется включать данную опцию, если на предприятии не используются функции конфигурирования состава, т.к. это приведёт к значительному замедлению всех операций поиска применяемости и состава объектов.
· **Разрешена фильтрация по атрибуту Видимость объекта.** Данная опция включает режим фильтрации списков объектов в соответствии с настройками, сделанными администратором на закладке **Видимость** (см. п. ). По умолчанию настройки видимости распространяются только на состав объекта, но включение данной опции позволяет скрывать невидимые объекты и в выборках, списках, архивах и пр. Побочным эффектом от включения данной опции является снижение скорости формирования списков объектов, а также некорректная работа механизма пакетного чтения объектов, т.к. фильтрация видимости производится на стороне клиента, а пакетное чтение выполняется сервером приложений IPS.
· **Разрешено редактирование общих выборок.** При включении данной настройки все пользователи смогут редактировать искомые значения в условиях общих выборок, но эти изменения будут действовать только на текущий сеанс работы с клиентом IPS.
· **Разрешить передачу значений атрибутов в службу автоматических уведомлений.** Включение данного режима позволит службе автоматических уведомлений проверять условия при рассылке уведомлений, а также разрешит рассылку уведомлений на изменение значений атрибутов. Однако данный режим снижает производительность системы, т.к. осуществляет дополнительные операции чтения атрибутов.
· **Разрешить редактирование дат истории ЖЦ.** Настройка, включение которой дает возможность редактировать даты истории ЖЦ.
· **Расширенная проверка прав доступа к атрибутам на шагах ЖЦ**. Режим включает дополнительную проверку прав доступа к атрибутам объектов на шагах ЖЦ применительно к типам объектов. Включение данного режима может значительно замедлять операции записи значений атрибутам объектов.
· **Расширенная проверка прав доступа к связям на шагах ЖЦ**. Позволяет включить дополнительную проверку прав доступа к связям объектов на шагах ЖЦ применительно к типам объектов. 
· **Режим ONLINE-модификации таблиц и индексов.** Включает режим модификации таблиц и ндексов в базе данных, который не приводит полной блокировки модифицируемых метаданных. Значительно замедляет ряд операция по модификации метаданных системы IPS, но позволяет выполнять их параллельно с работой пользователей в системе. Работает не для всех СУБД.
· **Режим аннулирования всех версий объекта.** В этом режиме перевод любой версии любого объекта на шаг ЖЦ с уровнем продвижения **Аннулировано** приводит к переводу на данный шаг всех версий данного объекта.
· **Режим работы с составами из различных CAD/ECAD источников.** Настройка, включение которой позволяет сохранить состав объекта сразу из нескольких CAD одновременно. Состав из одной CAD-системы не удаляет состав полученный из другой CAD-системы. 
· **Учитывать настройки безопасности архивов для изделий и объектов ПВ**. Режим включает дополнительную проверку прав доступа архивов у изделий и объектов производственных ведомостей, которым присвоен атрибут **Архив**.
· **Фильтровать контекстные версии объектов в составах.** Режим управляет отображением контекстных версий объектов в составах. Если включено значение **Нет** , то система при подборе версий использует все версии объектов, включая версии во всех контекстах редактирования. Если включено значение **Да** , то система при подборе версий использует только базовые версии, неконтекстные версии и версии в активном контексте и связанных с ним контекстах.
· **Фильтровать контекстные версии объектов в списках объектов.** Режим управляет отображением контекстных версий объектов в списках объектов. Если включено значение **Нет** , то система в списках объектов отображает все версии объектов, включая версии во всех контекстах редактирования. Если включено значение **Да** , то система в списках объектов отображает только базовые версии, неконтекстные версии и версии в активном контексте и связанных с ним контекстах.

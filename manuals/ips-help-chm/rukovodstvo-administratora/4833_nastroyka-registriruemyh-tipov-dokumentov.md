# Настройка регистрируемых типов документов
Любой объект, тип которого дочерний от типа Документы, можно зарегистрировать в канцелярии. Канцелярским является документ, который обладает набором атрибутов для канцеляр­ского документа, в частности имеет атрибут **Регистрационный номер**. Канцелярские документы могут быть нескольких видов:
· **входящий документ** – официальный документ, поступивший в учреждение; 
· **исходящий документ** – официальный документ, отправляемый из учреждения; 
· **внутренний документ** – официальный документ, не выходящий за пределы подготовившей его организации.
Допустимые виды регистрируемого канцелярского документа для каждого типа документов можно определить в **Конфигураторе базы данных** на закладке **Канцелярия**.
Система позволяет автоматически формировать регистрационный номер для регистрируемого документа по заданному шаблону. На закладке **Канцелярия** можно настроить эти шаблоны для каждого вида документа. Шаблон представляет собой строку, в которую включены подстановки, которые заключены в фигурные скобки: 
· **{9999}** – генерация числового значения, начиная с 1 и последующим инкрементом на 1. В этом типе подстановки можно указывать несколько цифр 9, например: **{99}** , **{999}** и т.д., в этих случаях при вычислении подстановки недостающие позиции в числе слева будут заполняться нулями. Например, для шаблона подстановки **{999**} нумерация будет следующая: 001, 002, 003 и т.д. до 999. В шаблоне также можно через двоеточие указать стартовое значение и шаг инкремента, например **{9999:5:10}** , в этом случае последовательность номеров будет следующая: 5,15,25…
· **{C}** – подставляется строковое значение из классификатора (классификатор выбирается в процессе регистрации, расчетная формула у классификатора должна быть только для одного атрибута). 
· **{@_Наименование_атрибута_}** – подставляется значение указанного атрибута регистрируемого документа.
· **{dd.MM.yyyy}** – всевозможные комбинации даты регистрации документа (включают символы 'd','D','m','M','y','Y','.','/','-' и символ пробела).
| **Символы** | **Результат подстановки** |
| --- | --- |
| d или D | День месяца. Ноль не предшествует однозначным числам, обозначающим дни. |
| dd или D | День месяца. Однозначным числам, обозначающим дни, предшествует ноль. |
| M или m | Числовое представление месяца. Ноль не предшествует однозначным числам, обозначающим месяцы. |
| MM или mm | Числовое представление месяца. Однозначным числам, обозначающим месяцы, предшествует ноль. |
| MMM или mmm | Сокращение для названия месяца (например, "Янв", "Фев", "Мар", и т.д."). |
| MMMM или mmmm | Полное название месяца (например, “Февраль”). |
| y или Y | Год без указания века. Когда числовое представление года без указания века меньше 10, ноль ему не предшествует. |
| yy или YY | Год без указания века. Когда числовое представление года без указания века меньше 10, ему предшествует ноль. |
| yyy или YYY | Год, обозначенный тремя цифрами. Если значение года меньше 100, ему предшествует ноль. |
| yyyy или YYYY | Год, обозначенный четырьмя цифрами, включая век. Используются предшествующие нули для получения четырех цифр. |
Если флаг **Нумерация в пределах типа объектов** выключен, то для вычисления нового числового значения, значение предыдущего регистрационного номера берется из общего счетчика регистрационных номеров, если же включен – то из индивидуального счетчика для текущего типа документов. Переключатели сброса счетчиков для текущего типа документов доступны только при включенном флаге **Нумерация в пределах типа объектов.**
Если флаг **Регистрационный номер не присваивается новому документу** включен, то внутренний регистрационный номер автоматически не заполняется, для присвоения регистрационного номера следует воспользоваться командами **Зарегистрировать в канцелярии** или **Зарегистрировать во внутренней канцелярии**.
Если флаг **Обозначение документа равно регистрационному номеру** включен, то во время создания нового канцелярского документа ему будет присвоено обозначение, равное сгенерированному регистрационному номеру.
**Внимание!** Значения допустимых видов и настройки генерации регистрационного номера не наследуются дочерними типами документов. 
Также на закладке можно указать шаблоны для различных процессов поручений, создаваемых по канцелярскому документу. Шаблоны процессов поручений заданы по умолчанию для типа объектов **Документы** и наследуются всем дочерним типам.
Настройка сброса для общих счетчиков осуществляется в настройках IPS: **Настройка / Параметры IPS** на закладке **Канцелярия / Общие**. В группе **Режимы обнуления счетчиков** доступны три допустимых счетчика для разных типов канцелярских документов. С помощью выпадающего списка можно указать необходимое значения для каждого из параметра. 
Список имеет следующие значения:
· Обнулять каждый год.
· Обнулять каждый месяц.
· Не обнулять.

В группе **Общие** находится параметр **Заголовок регистрируемого письма** , его настройка позволяет указать атрибут для создаваемого канцелярского документа, в значение которого записывается тема регистрируемого письма. 
Примечание: значение выбранного строкового атрибута распространяется на все объекты типа**Документы**.
**Внимание!** Если атрибут не выбран, то тема письма записывается в заголовок создаваемого канцелярского документа.

# Контроль действительности МЧД
По умолчанию назначенная пользователю МЧД считается действительной. Действительность МЧД можно регулировать назначением пользователю атрибута **Действующая МЧД** (cadd9f3b-306c-11d8-b4e9-00304f19f545). Если пользователю назначена МЧД и атрибут **Действующая МЧД** , то он сможет выполнять подписание усиленной подписью только в том случае, если атрибута **Действующая МЧД** примет значение **ДА**. 
**Внимание!** Атрибут **Действующая МЧД** не влияет на подписание при пустом или отсутствующем атрибуте **Регистрационный номер МЧД.**

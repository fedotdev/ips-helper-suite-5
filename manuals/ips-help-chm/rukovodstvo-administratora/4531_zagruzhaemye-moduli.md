# Загружаемые модули
Список загружаемых модулей можно изменить, открыв раздел **Администратор базы данных/Загружаемые модули**.
В версиях до IPS 6 основную смысловую нагрузку объектов данного типа несет значение атрибута **Загрузочный файл** , в котором указывается имя файла сборки загружаемого модуля без пути. На диске файл сборки должен находиться либо в основной папке клиента IPS, либо в подпапке **Plugins**.
Начиная с версии IPS 6 поддерживается размещение файлов сборок непосредственно в объектах загружаемых модулей в атрибуте **Файл**.
Для создания такого модуля необходимо сделать следующее:
1\. Создать объект загружаемого модуля и заполнить атрибут **Наименование**. Также можно заполнить атрибуты **Примечание** и **Версия** , но это не обязательно. Они являются информационными и не используются системой;
2\. Атрибут **Загрузочный файл** можно либо оставить пустым, либо, как и раньше, указать в нем имя файла сборки загружаемого модуля без пути (например, MyPlugin.dll);
3\. Переключиться на закладку **Файлы** и добавить файл сборки загружаемого модуля первым значением в атрибут **Файл**. Если сборка загружаемого модуля использует другие библиотечные сборки, не являющиеся частью IPS, то их также нужно добавить в атрибут **Файл**. Допускается использование относительных имен файлов сборок. Например, если основная сборка загружаемого модуля MyPlugin.dll использует библиотечную сборку MyPlugin.Library.dll, зависящую от битности операционной системы, то в атрибут **Файл** нужно поместить три файла: **MyPlugin.dll** , x86/MyPlugin.Library.dll, x64/MyPlugin.Library.dll.
При загрузке такого модуля клиент IPS сначала извлечет все его файлы на локальный диск, если это еще не было сделано раньше. Если в базе данных файл сборки новее, чем на локальном диске, то клиент IPS обновит локальный файл.
Для извлечения файлов сборок используется новая системная папка Cache/Plugins в файловом хранилище текущего пользователя IPS, причем для каждого загружаемого модуля используется отдельная подпапка внутри Cache/Plugins.
Если атрибут **Загрузочный файл** у объекта загружаемого модуля пуст, то точкой входа будет первый файл в атрибуте **Файл** загружаемого модуля. Если атрибут **Загрузочный файл** задан, то его значение должно совпадать с именем (без пути) одного из файлов в атрибуте **Файл**. В этом случае точкой входа будет указанный файл сборки.
Создав список загружаемых модулей, администратор может назначить их ролям (см. п. ). Также можно назначить загрузку модуля группам пользователей, включив нужные группы в состав загружаемого модуля.
При необходимости задать последовательность в загрузке модулей расширения, следует добавить атрибут **Сортировка** для типа объектов **Загружаемые модули**. Добавить атрибут можно в **Конфигураторе базы данных**.
_Примечание: если атрибут не_ _отображается_ _в списке_ _допустимых атрибутов_ _, тогда следует включить параметр_** _Показать скрытые атрибуты_** _._
После того, как атрибут **Сортировка** был добавлен типу объектов **Загружаемые модули** , в **Навигаторе** в списке объектов **Загружаемые модули** следует выбрать необходимые модули и добавить им данный атрибут, а затем настроить сортировку, добавив необходимое значение. 
**Внимание!** Загрузка модулей будет выполняться в порядке возрастания введенных значений.

# Функции для строковых переменных
| **Функция** | **Тип возвращаемой переменной** | **Описание** |
| --- | --- | --- |
| FIND (string textToFind, string textToSearch, int startIndex) | целое число | Возвращает индекс первого вхождения подстроки textToFind в строку textToSearch. Поиск начинается с указанной позиции. |
| LEFT (string, int nCount) | строка | Возвращает первые nCount символов из строки. |
| LEN (string) | целое число | Возвращает длину строки. |
| LOWER(string) | строка | Преобразует все символы к нижнему регистру. |
| MID (string, int nFirst, int nCount) | строка | Возвращает подстроку длины nCount, начиная с позиции nFirst. |
| SUBSTITUTE (string _text_ , string _oldText_ , string _newText, bool case_) | строка | Заменяет подстроку _oldText_ строкой _newText_ c учетом или без учета регистра ( параметр case) |
| TRIM (string) | строка | Удаляет пробелы, символы табуляции и пустой строки из начала и конца строки. |
| UPPER (string) | строка | Преобразует все символы к верхнему регистру. |

# Удаление
Для удаления типа связей нужно выделить его в дереве метаданных и выбрать команду его контекстного меню **Удалить**. Нельзя удалить тип связи в следующих случаях:
− если в базе данных существуют объекты, соединенные данным типом связи;
− если тип связи указан как связь по умолчанию в каком-либо типе объектов;
− если данный тип связи является системным.

# Окно редактора шаблонов документов
Редактор шаблонов документов состоит из рабочей области редактора, панелей инструментов и двух специальных панелей: 
· **Свойства** — позволяет редактировать свойства отмеченного элемента редактора.
· **Схема документа** — отображает перечень страниц и элементов документа в иерархическом виде.
Рабочая область редактора соответствует странице создаваемого шаблона документа. Панели инструментов редактора предоставляют средства для нанесения элементов на поля страниц и изменения их свойств.
Панели **Свойства** и **Схема документа** могут иметь плавающий вид на экране, т.е. располагаться в любом месте поверх рабочей области, а могут быть закреплены в определенном месте экрана методом стыковки, чтобы не мешать восприятию информации рабочей области. Чтобы закрепить панель в одной из сторон экрана, необходимо потянуть за его заголовок в желаемую сторону. При перемещении панелей, на экране появляются пиктограммы с указателями, предлагающими поместить панель в то или иное место рабочего пространства. Совместите удерживаемую указателем мыши панель с одним из этих указателей, и она закрепится в указанной стороне. Теперь можно изменять размеры рабочей области редактора и панели относительно друг друга для оптимального восприятия, регулируя их границы с помощью курсора мыши. Используя метод стыковки панели можно расположить рядом в виде закладок. Кнопка панелей **Автоматически убирать с экрана** позволяет автоматически сворачивать панели, вызывая их только при подведении указателя мыши к кнопке свернутых панелей. Кнопка позволяет вернуть панели в исходную позицию.
Пользователь имеет возможность менять масштаб отображения шаблона для удобного восприятия информации на его страницах. Масштаб можно выбрать из списка, воспользовавшись командой **Вид/Масштаб** главного меню.

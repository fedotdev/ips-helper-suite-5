# Настройка интерфейса пользователя
В системе IPS есть два варианта настроек интерфейса – для ролей и персональные пользовательские настройки. Первоначально следует выполнить настройки для ролей. Настройки по умолчанию пользователя будут получены у его роли, под которой он выполнил подключение к IPS. В дальнейшем, настройки пользователя имеют более высокий приоритет перед настройками роли, если это не настроено в свойствах роли. При необходимости, пользователь имеет возможность сбросить настройки на стандартные значения.
Рассмотрим подробнее каждый из вариантов этих настроек.

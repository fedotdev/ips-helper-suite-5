# Расчетные скрипты экспертной системы
**Расчетные скрипты экспертной системы** позволяют вычислить значение одного или нескольких параметров. По умолчанию считается, что скрипт рассчитывает значения всех параметров, которые встречаются в левой части операторов присваивания. Скрипт будет автоматически включен в правила расчета для всех этих параметров. Расчетные скрипты, как и формулы ЭС, могут иметь условия применения.
Создание нового скрипта экспертной системы производится по команде **Создать**. В открывшемся окне необходимо ввести наименование скрипта экспертной системы.
После этого откроется редактор командных скриптов ЭС. 
На рисунке выше показан пример скрипта экспертной системы с расчетом норм времени на операцию. 
Вначале при помощи оператора **Присваивания** обнуляем значения временных атрибутов **X** и **Y**. 
Т.к. нормы основного и вспомогательного времени присутствуют на объекте переход и на объекте сварные швы первоначально от объекта нормирование на операцию нам необходимо подняться по составу вверх по связи **Технологический состав** и найти требуемую операцию. Для этого в скрипт вставляем оператор поиска **Родительского объекта** с модификатором **Для первого** для поиска операции.
Далее внутрь добавляем два оператора поиска вложенных объектов с модификатором **Для всех** для поиска всех норм на переходы и сварные швы.
Внутрь каждого из операторов вставляем операторы **Присваивания** с модификатором **Если существует** для норм основного и вспомогательного времени. С помощью данных операторов будем прибавлять найденные нормы основного и вспомогательного времени к уже имеющимся значениям. Таким образом в атрибуте **X** суммарное значение норм основного времени на сварочный шов и переход, а в атрибуте **Y** суммарное значение норм вспомогательного времени на сварочный шов и переход,
В самом конце скрипта добавляем группирующий **Блок** внутри которого присваиваем атрибутам **Норма основного времени** и **Норма вспомогательного времени** найденные значения временных атрибутов **X** и **Y**.
Редактирование скриптов будет описано в п. .
Описание операторов, применяющихся в расчетных скриптах экспертной системы, будет дано в п. .
Описание модификаторов, применяющихся в расчетных скриптах экспертной системы, будет дано в п. .
Описание операторов сбора глобальной таблицы будет дано в п. .

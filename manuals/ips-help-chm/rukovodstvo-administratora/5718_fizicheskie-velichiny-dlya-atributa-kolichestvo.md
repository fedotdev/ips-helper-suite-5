# Физические величины для атрибута Количество
Настройка **Параметры IPS / Система / Конфигуратор БД / Физические величины для атрибута Количество** предоставляет возможность выбора физических величин из фиксированного списка, а так же предоставлена альтернатива – добавлять другие физические величины. 
Физические величины из фиксированного списка удалить нельзя. С помощью кнопки можно только добавлять/удалять иные величины. 
В **Конфигураторе БД** при редактировании типа атрибута **Количество** на поле **Физическая величина** добавлена подсказка, что при назначении любой физической величины следует смотреть настройку **Параметры IPS / Система / Конфигуратор БД / Физические величины для атрибута Количество**.

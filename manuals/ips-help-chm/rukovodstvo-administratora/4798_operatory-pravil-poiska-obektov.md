# Операторы правил поиска объектов
Правила поиска объектов используют два специальных оператора: **Для типа объектов** и **Вернуть объект**. Оператор **Для типа объектов** позволяет выполнить вложенные в него операторы только в том случае, если текущий объект контекста имеет выбранный тип. В поле **Условие** можно задать дополнительные условия, которым должен удовлетворять объект, чтобы его дочерние операторы были выполнены.
Оператор **Вернуть объект** предписывает экспертной системе вернуть текущий объект контекста в качестве результата работы скрипта поиска объектов. Он имеет такие же параметры, как операторы управления (см. п. ), то есть можно задать условие, при котором он будет выполняться. 
**Внимание**! После выполнения этого оператора экспертная система больше не будет выполнять никаких других операторов скрипта поиска объектов, поскольку результат уже найден.

# Составное форматирование
Строка составного формата состоит из фиксированного текста, в который включены индексированные местозаполнители, которые называются элементами форматирования и соответствуют объектам из списка. Операция форматирования создает результирующую строку, состоящую из исходного фиксированного текста, в который включено строковое представление объектов из списка.
Например:
FORMAT(‘Name = {0}, часов = {1:hh}’, ‘Петр’ ,Now()) = Имя = Петр, часов =12
Каждый элемент форматирования имеет следующий вид и состоит из следующих компонентов:
{ index[,alignment][:formatString]}
Парные фигурные скобки ("{" и "}") здесь обязательны.

# Параметризованные правила
Параметризованным называется правило подбора версий, в критериях которого есть значения для сравнения вида **Значение пользователя**. В этом случае начальные значения задаются при проектировании правила, а пользователь, выбирая такое правило, может создать несколько вариантов значений таких критериев и использовать их, выбирая один из вариантов в качестве основного.
Предположим, что на этапе создания правила в предыдущем примере виды значений для сравнения у критерия **Дата модификации содержимого объекта** были выбраны **Значение пользователя** (а не **Константа**). 
Содержимое такого правила представлено на рисунке:
Виды значений для сравнения изменены на **Значение пользователя**. Следовательно, такое правило подбора версий является параметризованным.
Рассмотрим, как требуется работать с такими правилами пользователям системы IPS:
1\. Откройте окно **Навигатора** в программе, а затем с помощью кнопки на панели инструментов **Фильтрация составов** вызовите диалоговое окно по выбору правил подбора версий:
2\. В списке выберите созданное в предыдущем примере правило подбора версий и нажмите **ОК**.
Данное правило подбора будет применено к текущему окну, а содержимое панели инструментов **Фильтрация составов** будет изменено:
В комбо-бокс добавилась ссылка на выбранное правило, это правило стало активным. Кроме того, стала доступной кнопка – выбор вариантов настроек правила подбора версий.
3\. Нажав на эту кнопку, вызовите диалоговое окно **Настройка фильтрации составов** :
Окно настроек состоит из следующих элементов управления:
1\. **Текущее правило подбора версий**. На данной панели инструментов размещается комбо-бокс с настраиваемым правилом подбора версий, а также кнопка, позволяющая выбрать другое правило для настройки и последующей активации в текущем окне программы;
2\. **Панель инструментов.** Содержит следующие кнопки:
 – добавить новый вариант настроек в параметризованное правило подбора версий.
 – редактировать текущий вариант настроек.
 – выбрать текущий вариант настроек в качестве основного.
 – обновить содержимое редактора, перечитав правило подбора версий из базы данных.
 – удалить текущий вариант настроек из списка.
3\. **Список вариантов** настроек в текущем правиле.
4\. **Подсказка.** Информирует о корректности текущего правила.
Чтобы добавить новый вариант настроек в параметризованное правило, нажмите кнопку . Появится диалоговое окно **Значения для сравнения:**
В данном окне отображаются все критерии для сравнения, в которых есть значения для сравнения вида **Значение пользователя** (остальные критерии и значения не отображаются). В данном окне укажите свои значения для данных критериев, затем нажмите **ОК** , чтобы внести изменения в настройки.
Примечание: в каждом варианте можно указать фильтрацию составов по дате, если это допускается критериями самого правила подбора версий.
Повторите действия ещё раз, добавив ещё один вариант значений. В результате получатся примерно следующие настройки правила подбора версий:
Один из вариантов должен быть выбран как основной (отмечен символом ). Значения критериев при подборе версий будут получены именно из этого варианта.
Если в параметризованном правиле нет вариантов значений, на панели инструментов **Фильтрация составов** появится дополнительная кнопка с подсказкой: 
Нажатие этой кнопки вызовет описанное выше диалоговое окно **Настройка фильтрации состава**. В появившемся окне требуется выбрать какой-либо вариант настроек, либо создать новый, а затем сделать его основным.
**Внимание!** Если пользователь сделал свои варианты настроек для правила подбора версий, а затем само правило было изменено, например, изменилось количество параметризованных критериев, то при попытке пользователя выбрать такое правило, на панели инструментов **Фильтрация составов** появится дополнительная кнопка вида: 
Нажатие этой кнопки вызовет вышеописанное диалоговое окно **Настройка фильтрации состава**. В данном окне требуется удалить все варианты настроек, а затем создать новый вариант, который соответствует изменениям, внесенным в правило подбора версий.

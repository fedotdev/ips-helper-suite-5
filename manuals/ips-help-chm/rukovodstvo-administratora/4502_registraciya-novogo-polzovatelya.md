# Регистрация нового пользователя
Для регистрации нового пользователя следует выполнить следующие действия:
1\. Необходимо выделить группу/подгруппу, в которой следует создать пользователя, и с помощью команды контекстного меню **Создать/В составе** открыть диалоговое окно.
Примечание: можно выделить уже существующего пользователя и вызвать команду контекстного меню **Создать/Создать «Пользователя»**.
2\. В диалоговом окне необходимо выбрать тип создаваемого объекта **Пользователи** , затем нажать кнопку .
3\. В появившемся диалоге следует ввести необходимые данные о новом пользователе.
Диалоговое окно **Создание нового объекта** имеет две закладки **Пользователь** и **Информация**. Данные закладки имеют свои параметры, которые следует заполнить.
Закладка **Пользователь** :__
· **Полное имя пользователя**. Данный параметр может содержать до 200 символов, он предназначен для удобства идентификации пользователя другими пользователями в различных диалогах IPS. 
· **Имя входа в систему**. Данный параметр может содержать до 20 символов, он предназначен для идентификации пользователя при входе в IPS. Система автоматически меняет буквы на верхний регистр. 
Примечание: поля **Полное имя** **пользователя** и **Имя входа в систему** являются обязательными для заполнения. Данные имена должны быть уникальными в пределах базы данных системы IPS, т.к. программа ведет свою внутреннюю идентификацию пользователей.
· **Пароль**. Данный параметр может содержать до 20 символов. 
Так как пользователь имеет возможность самостоятельно изменять свой пароль от входа в систему IPS, то с помощью данного параметра администратор может установить новый, не зависимо от того знает он старый или нет.
· **Фамилия в графе подпись.** Данный параметр может содержать до 50 символов, он предназначен для вывода имени пользователя, которое не подходит для записи в штампы подписываемых документов.
· **Должность**. Данный параметр позволяет указать занимаемую должность регистрируемого пользователя. 
4\. Для выбора должности следует нажать кнопку **Добавить** и выбрать необходимую должность в предложенном списке. Затем нажать кнопку .
Примечание: если необходимой должности нет в списке, то ее можно создать в уже открытом диалоговом окне, для это следует выделить любую должность в списке и правой кнопкой мыши вызвать команду **Создать/Создать «Должность»** , затем следует заполнить поля и нажать кнопку 
· **Уровень доступа**. Данный параметр дает возможность указать уровень доступа пользователя к секретной и несекретной информации.
· **Внешний пользователь**. Данный параметр не дает возможность войти в систему IPS регистрируемому пользователю. 
В закладке **Информация** можно ввести дополнительную информацию о пользователе, однако, заполнения данных полей не обязательно.
При заполнении всех параметров закладки будут иметь следующий вид:
5\. Если регистрируемый пользователь имеет флажок напротив параметра **Внешний пользователь** , то для завершения создания нового пользователя следует нажать кнопку , в противном случае необходимо нажать кнопку .
6\. В диалоговом окне следует присвоить роль новому пользователю, для это необходимо нажать на кнопку и выбрать роль из предложенного списка. Затем следует нажать кнопку .
Примечание: если необходимой роли нет в списке, то ее можно создать в уже открытом диалоговом окне, для это следует выделить любую роль и правой кнопкой мыши вызвать команду **Создать/Создать «Роль»** , затем следует заполнить поля и нажать кнопку 
7\. Для проверки заполнения полей и свойств атрибутов, а также при необходимости добавить типы связи следует нажать кнопку .
Примечание: если в проверке нет необходимости, то можно нажать кнопку сразу после ввода данных о пользователе.
8\. Необходимо добавить связь пользователю с помощью кнопки **Добавить связь**.
9\. В диалоговом окне **Диалог выбора** следует выбрать необходимые данные и нажать кнопку .
10\. Для завершения регистрации пользователя необходимо нажать кнопку .

# Создание нового правила
Для создания можно воспользоваться командой меню **Файл/Создать** или командой контекстного меню в списке правил **Создать/Создать Правило** (текст команды зависит от типа выбранного в списке правила подбора версий).
Если требуется создать правило по прототипу, можно воспользоваться командой контекстного меню **Создать/По прототипу**.
В результате вызова данных команд появится окно мастера по созданию новых объектов типа **правила подбора версий** :
Если была вызвана команда создания по прототипу, то второе поле в данном мастере (**Создать правило на основе шаблона**) будет заполнено заголовком объекта-прототипа.
На данном шаге работы мастера требуется указать заголовок нового правила. Кроме того, нажатием кнопки **Обзор** можно выбрать объект-прототип. При этом появится диалоговое окно, позволяющее выбрать шаблон для нового правила:
Нажатие кнопки **ОК** завершает работу окна по выбору объекта-прототипа.
Кнопка **Очистить** в мастере по созданию нового правила удаляет информацию об объекте-прототипе.
Кнопка **Далее** позволяет перейти к следующему шагу по созданию нового правила подбора версий.
На втором шаге работы мастера доступен редактор содержимого правила подбора версий объектов. В следующем разделе рассмотрим подробно данный редактор.

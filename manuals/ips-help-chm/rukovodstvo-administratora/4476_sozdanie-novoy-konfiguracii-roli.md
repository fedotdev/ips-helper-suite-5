# Создание новой конфигурации роли
Для создания новой конфигурации можно воспользоваться кнопкой на панели инструментов или командой контекстного меню **Создать конфигурацию** в дереве с конфигурациями ролей:
В появившемся окне мастера по созданию новых объектов заполните значения требуемых атрибутов (в данном случае достаточно уникального заголовка объекта) и нажмите кнопку **Готово**.
Вновь созданная конфигурация роли появится в списке конфигураций в первой панели редактора.

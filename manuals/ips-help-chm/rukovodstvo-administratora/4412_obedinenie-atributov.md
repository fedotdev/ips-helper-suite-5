# Объединение атрибутов
Команда **Объединить** для группы атрибутов доступна в списках атрибутов при выделении нескольких атрибутов, среди которых не более одного атрибута с системным GUID.
По команде открывается окно, в котором необходимо выбрать атрибут, который останется в базе данных и режим объединения данных, при наличии у объекта или связи обоих объединямых атрибутов.
**Отменить операцию** – операция по объединению атрибутов будет отменена.
**Заменять данными из удаляемого атрибута** – в выбранный атрибут будет сохранено значение удаляемого атрибута.
**Оставить данные выбранного атрибута** – значения выбранного атрибута не изменятся.
В результате выполнения команды в системе останется один выбранный атрибут.

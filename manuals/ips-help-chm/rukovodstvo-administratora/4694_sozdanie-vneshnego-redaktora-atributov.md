# Создание внешнего редактора атрибутов
Для создания нового внешнего редактора воспользуйтесь командой меню **Файл/Создать/Новый объект** и выберите в мастере по созданию объектов тип объекта **Внешние редакторы атрибутов** :
Заполните поле **Заголовок объекта** и нажмите кнопку **Готово**. Будет создан новый объект.

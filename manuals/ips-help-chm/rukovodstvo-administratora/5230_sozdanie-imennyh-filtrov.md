# Создание именных фильтров
Для создания именного фильтра следует:
1\. В дереве **Навигатора** выделить элемент **Журнал событий** и вызвать команду **Создать фильтр** из контекстного меню.
Примечание: в результате чего новый фильтр появится в виде дочернего элемента журнала событий в дереве навигации.
2\. На рабочей области откроется закладка **Параметры фильтра** , в которой следует настроить необходимые условия фильтрации записей журнала событий, а в строке **Название фильтра** следует задать имя именного фильтра.
3\. Для завершения создания фильтра и сохранения, созданных настроек, следует нажать на кнопку .
Список событий, сформированный по результатам заданной фильтрации, отображается на закладке **Отфильтрованные события**.
**Внимание!** При необходимости удалить созданный фильтр, следует воспользоваться командой **Удалить** из его контекстного меню.

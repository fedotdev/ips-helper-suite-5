# Исключение из группы атрибутов
Чтобы исключить атрибут из группы, выделите его в списке атрибутов данной группы в дереве метаданных и выполните команду его контекстного меню **Исключить.** Исключенный из группы атрибут останется в системной группе **Все атрибуты** и в других группах, если он добавлялся ранее в их состав.

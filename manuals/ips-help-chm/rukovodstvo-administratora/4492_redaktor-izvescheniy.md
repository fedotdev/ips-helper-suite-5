# Редактор извещений
Примечание: данные настройки будут доступны в том случае, если загружен модуль расширения **Контроль изменений**.
Для настройки модуля необходимо выбрать команду **Параметры IPS** из меню **Настройка** панели инструментов системы IPS. В открывшемся окне выбрать пункт **Редактор извещений**.
Настройки**Редактора извещений** состоят из нескольких групп. Параметры и их характеристики каждой из этих групп будут описаны ниже.
В группе **Атрибуты, копируемые в ДИ/ДПИ** указываются атрибуты, значение которых необходимо скопировать из ИИ в ДИ/ДПИ.
В группе **Каталоги IMBASE для вставки** настраиваются каталоги IMBASE, из которых можно вставлять наименование строки в извещение по команде контекстного меню **Вставить название из IMBASE** , для объекта, включенного в извещение. 
В группе **Лист рассылки** присутствуют настройка:
· **Копировать лист рассылки**. Данный параметр позволяет автоматически копировать лист рассылки извещения в лист рассылки документов. Параметр работает при условии, что объект, включенный в состав извещения, имеет связь **Изменяется по извещению.**
Примечание: если документ ранее не имел листа рассылки, то при включении параметра **Копировать лист рассылки** в документ будут добавлены абоненты, указанные в настройках типа объекта.
В группе **Общие настройки** присутствуют настройки:
· **Автоматически брать на изменение документы, вставляемые в извещение**. Данный параметр дает возможность автоматически брать на изменение объекты, которые входят в состав извещения.
· **Включить слово «комплекты» для серий**. Данный параметр позволяет установить по умолчанию включенным переключатель **добавить «комплект»** в окне **Диапазон серий и дат**. Эта возможность необходима для использования комплектов вместо серий, при подборе версий по сериям и датам.
· **Вместо Обозначения выводить данные документов по расширенному шаблону**. Данный параметр позволяет вместо обозначений документов в извещении выводить значение, собранное по шаблону, указанному в параметре **Расширенным шаблоном вместо обозначений документов** (описание см. ниже).
· **Заменять пустые обозначения по шаблону**. Данный параметр, если выбрана опция **Да** , позволяет заменить пустые обозначения документов по шаблону, указанному в параметре **Расширенным шаблоном вместо обозначений документов** (описание см. ниже). Если выбрана опция **Нет** , включение в извещение объектов без обозначения будет запрещено.
· **Запретить пользовательские коды причины изменения**. Данный параметр позволяет при выборе в редакторе извещений причины изменения **Другое** , добавлять слово **Другое** перед текстом изменения. Подробнее см. .
· **Количество дней, за которое надо предупреждать владельца извещения об окончании срока изменения**. Данный параметр позволяет указать количество дней, за которое автоматически будет производиться рассылка уведомления об окончании срока изменения. 
Примечание: чтобы отключить функцию этого параметра следует установить 0 дней.
· **Максимальное количество документов в извещении**. Данный параметр позволяет указать максимальное количество документов, которых можно добавить в извещение.
· **Не вставлять / в обозначение ДПИ**. Данный параметр позволяет формировать обозначение версий **ДИ** и **ДПИ** без «**/** ». Например, **34 ДИ** , **34 ДИ/1** , **34 ДИ/2** \- при выключенной настройке, **34 ДИ** , **34 ДИ1** , **34 ДИ2** – при включенной настройке.
· **Оригинальный размер изображений по умолчания**. Данный параметр позволяет отображать изображения, входящее в извещение, в исходном размере изображения (по умолчанию для элемента извещения **Рисунок** команда контекстного меню **Оригинальный размер** будет нажата). 
· **Оставлять номер ОТД при включении версии в извещение с целью «Изменение»**. Данный параметр позволяет сохранять историю номеров версий ОТД, при условии, что они создаются в извещении с целью изменения.
· **Переводить объекты на новые шаги ЖЦ по извещениям**. Данный параметр переводит на соответствующий шаг жизненного цикла все объекты, которые вошли в состав извещения, сразу после его актуализации.
· **Переносить аутентичный файл при изменении литеры.** Данный включенный параметр автоматически переносит аутентичные фалы в группу **Файлы, не влияющие на содержимое** при изменении литеры. 
· **Показывать обозначения объектов, включенных с целью** **«Замена»**. Данный параметр выводит обозначение объекта, который включен в состав извещения с целью замены. Если настройка выключена обозначение документа, подлежащего замене, в извещении в графе **Обозначение** отображаться не будет, а будет дана ссылка «**см. ниже»** на графу **Содержание изменения**.
· **Показывать скрытые объекты**. Данный параметр позволяет показать (при установке опции – **Да**) / скрыть (при установке опции – **Нет**) группу **Скрытые объекты** в составе дерева извещения.
· **Посылать сообщение о переводе объектов на новые шаги ЖЦ**. Данный параметр дает возможность отправлять уведомления о переводе объектов на очередной шаг жизненного цикла владельцу извещения с помощью модуля **Контроль изменений** посредством механизма документооборота IPS (см. ).
· **Присваивать литеру по развернутому составу изделия**. Если настройка включена, то в момент актуализации ИИ, для всех ДСЕ в развернутом составе Изделия / Исполнения, где есть атрибут **Литера** , будет присвоена **Литера,** указанная в извещении (версия не создается!!!). Если у изделия уже была такая литера или более высокая по приоритету – это изделие пропускается. 
Правило раскрытия состава используется в соответствии с контекстом актуализированного ИИ по связям типов **Состав изделий** и **Документация** с правилом подбора **Базовые версии объектов**.
У найденных объектов для атрибута **Номер изменения** будет присвоено значение, следующее по порядку, для значения атрибута **Извещение** присвоена ссылка на актуализируемое извещение. 
· **Проверять необходимость включения в извещение при создании объектов**. Данный параметр позволяет ввести запрет на создание нулевой версии объекта без выпуска извещения, у которого на шаге **ЖЦ В разработке** свойство **Необходимость извещения** установлено значение **Требовать включение в извещение**. Если настройка включена, при создании объекта, после нажатия кнопки **Готово,** будет автоматически показан диалог выбора извещения.
· **Разрешить скрытие основных объектов, включенных с целью «Создание»**. Данный параметр позволяет добавлять основные объекты, включенные в извещение с целью **Создание** , в группу **Скрытые объекты**. Если настройка выключена, документы для которых непосредственно была вызвана команда вставки в извещение и включенные в извещение с любыми целями, включая цель **Создание** , будут отображены в дереве извещения белым цветом и команда контекстного меню дерева извещений **Скрыть** для данных документов будет недоступна.
· **Расширенный шаблон вместо обозначений документов**. Данная возможность доступна при условии, что параметр **Вместо обозначения выводить данные документов по расширенному шаблону** переведен в режим **Да**. При соблюдении всех условий можно использовать новый шаблон, по которому будет создаваться текст, замещающий обозначение документа. 
Примечание: имена атрибутов необходимо вписывать в квадратные скобки, например, **[Обозначение]+[Инвентарный номер]**.
· **Создавать версии объектов, включаемых для присвоения литеры**. Данный параметр позволяет при включении объектов в извещение с целью присвоения литеры, создавать версии этих объектов и присваивать этим версиям следующий по порядку номер изменения. При включении группового документа с целью присвоения литеры, будет выдан запрос выбора исполнений, и перед включением объектов проверена литера каждого включаемого в извещение объекта. Если у одного из них литера будет с таким же или более высоким приоритетом, пользователю будет показано диалоговое окно с этой информацией и предложено отменить включение или выбрать другую литеру.
· **Спрашивать при включении объектов с новыми организациями в ЛР**. Данный параметр позволяет при включении в извещение документа с листом рассылки, включить выдачу предупреждения в случае, если абоненты в листе рассылки не совпадают с абонентами из листов рассылки других документов. Предупреждение будет появляться при условии, что абоненты были добавлены из раздела **Организации**.
· **Шаблон обозначения КИ**. Данный параметр дает возможность задать шаблон инвентарного номера, который будет использован при назначении номера для КИ. Символом **[#]** указывается место в инвентарном номере, где будет вставляться дробное число для ИИ входящих в КИ.
В группе **Скрываемые типы объектов** указываются объекты, которые при добавлении в извещение будут автоматически внесены в группу **Скрытые объекты**.
В группе **Типы извещений без номеров изменений для входящих объектов** указываются типы извещений, для которых требуется чтобы при включении в извещение документов, поле **Номер изменения** оставалось пустым.

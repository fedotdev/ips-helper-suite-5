# Сохранение изображения в файл
IPS позволяет сохранять созданные изображения элемента **Контейнер** на диске. Для этого необходимо выполнить следующие действия:
· Отметьте элемент **Контейнер** с изображением и примените команду **Сохранить изображение в файл** его контекстного меню.
· В появившемся диалоге укажите путь на диске, куда нужно сохранить файл, введите имя файла и нажмите кнопку **Сохранить**.

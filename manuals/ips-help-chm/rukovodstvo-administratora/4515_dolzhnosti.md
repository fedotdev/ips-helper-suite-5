# Должности
Для реализации электронных подписей объектов в IPS ведется список должностей, которые могут быть назначены пользователям IPS для того, чтобы они имели возможность подписывать объекты. Пользователь сможет подписывать объекты в тех графах, которые для его должности будут указаны на закладке **Графы для подписи**. 
На закладке Графы для подписи можно настроить следующие параметры:
· **Запрет более одной подписи в графе**. Включенный параметр позволяет системе отследить наличие актуальной подписи в графе, поставленной пользователем в этой должности, и запретить повторное подписание документа.
· Колонки **Простая** и **Усиленная**. Включенные параметры позволяют пользователю подписать тип документа в указанной должности простой и/или усиленной подписями.
Чтобы увидеть список должностей, имеющихся в системе, необходимо с помощью команды главного меню **Вид/Администратор базы данных** открыть окно администратора и отметить в дереве элемент **Должности**. При этом в рабочей области окна отобразится список имеющихся в системе должностей.

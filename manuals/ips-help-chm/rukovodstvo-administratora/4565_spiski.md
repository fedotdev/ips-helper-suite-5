# Списки
· **Список**. Позволяет выбрать значение параметра из выпадающего списка.
· **Список с множественным выбором**. Компонента для выбора из списка нужных значений атрибута.
· **Список ссылок на объекты**. Компонент, отображающий список ссылок на объект.
· **Список ссылок на объекты (табличная форма).** Компонент, отображающий список ссылок на объект в табличной форме.
· **Список чисел в единицах измерения**. Отображает список чисел, выраженных в единицах измерения.
· **Выпадающий список**. Отображает линейный список значений атрибута одного из типов: Строка, Целое число, Вещественное число, Вещественное число, выраженное в единицах измерения, Ссылка на версию объекта. 
· **Календарь**. Кроме ручного ввода и отображения значения ассоциированного параметра, позволяет выбрать значение из выпадающего календаря.
· **Список дат**. Позволяет отображает список значений многозначного атрибута типа **Дата.**
· **Список объектов**. Позволяет отобразить список объектов.

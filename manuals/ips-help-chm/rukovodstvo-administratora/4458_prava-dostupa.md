# Права доступа
Закладка **Безопасность** позволяет назначить права доступа к списку языковых вариантов, зарегистрированных в системе. В конфигураторе можно назначать следующие права доступа:
· **Создание языковых вариантов** — разрешает создавать новые языковые варианты.
· **Удаление языковых вариантов** — разрешает удалять существующие языковые варианты.
· **Изменение свойств языковых вариантов** — разрешает изменять свойства языковых вариантов.
· **Просмотр прав доступа** — разрешает просматривать набор прав доступа к списку языковых вариантов.
· **Изменение прав доступа** — разрешает назначать права доступа на список языковых вариантов.
**Внимание!** В системе IPS предоставлена возможность копировать права, при условии, что место, куда копируются выбранные права, может принимать такие права доступа.

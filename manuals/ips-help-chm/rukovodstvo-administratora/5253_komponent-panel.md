# Компонент Панель
В данном компоненте основные свойства унаследованы от компонента **Надпись**. Кроме того есть дополнительные свойства:
· **АвтоПрокрутка**. Задает значение, указывающее, будет ли контейнер давать возможность пользователю выполнять прокрутку элементов управления, помещенных вне его отображаемых границ.
· **АвтоПрокрутка мин. размеры**. Задает минимальный размер для автоматической прокрутки.
· **АвтоПрокрутка размеры**. Задает размер поля автоматической прокрутки.
· **Режим авторазмера**. Задает способ поведения компоненты при установленном значении **Авторазмер**. Если установлено значение **Только увеличение** , то компонента будет автоматически увеличиваться до размера при котором все дочерние компоненты будут находиться в области видимости. Если установлено значение **Увеличение и уменьшение** , то компонента будет также и уменьшаться до размеров пока не будет убрано лишнее пространство вокруг дочерних компонентов.

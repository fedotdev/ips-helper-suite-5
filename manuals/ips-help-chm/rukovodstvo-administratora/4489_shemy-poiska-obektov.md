# Схемы поиска объектов
Примечание: данные настройки будут доступны в том случае, если загружен модуль расширения **Управление информацией об изделиях (PDM)**.
**Схемы поиска объектов** – это информационный объект, который используются для поиска составов/развернутых составов и применяемостей/развернутых применяемостей. В настройках системы доступно два типа схем – **Общие схемы поиска объектов** и **Персональные схемы поиска объектов** , которые унаследованы от абстрактного типа **Схемы поиска объектов.**
В приложении **Конфигуратор базы данных** можно отследить и перенастроить свойства атрибутов, которые описывают данный объект.
Полный список всех доступных схем поиска можно получить с помощью приложения **Администратор базы данных / Настройка системы / Схемы поиска** :
Практическое применение функциональных возможностей данного информационного объекта реализуется в закладках **Поиск состава** и **Поиск применяемости**. Данные закладки есть в карточке любого объекта, у которого есть состав. В каждой закладке есть свой combo box (выпадающий список) напротив поля **Схема поиска**. В этом списке перечислены допустимые схемы поиска для узла.
На закладках есть своя панель инструментов. 
Значения кнопок описаны ниже:
 **Открывает панель с дополнительными видами**. Данная кнопка открывает карточку выделенного объекта внизу рабочей области.
**Показать панель для группировки по значениям колонок, разрешить группировку по значениям колонок.** Данная кнопка позволяет отсортировать объект по необходимому атрибуту.
**Восстановить схему колонок по умолчанию**. Данная кнопка возвращает список отображаемых столбцов до первоначального набора колонок.
 **Создать новую схему поиска**. Данная кнопка дает возможность создать новую схему поиска состава/применяемости. Подробное создание схемы поиска описано в пп. и .
 **Редактировать схему поиска**. Данная кнопка вызывает окно редактора текущей схемы поиска. 
Примечание: редактировать схему поиска можно через приложение **Администратор базы данных/ Настройки системы/ Схемы поиска объектов** или **Навигатор/ Информационное пространство/ Объекты/ Настройки системы/ Схемы поиска объектов**. В рабочей области следует найти схему поиска, которую необходимо отредактировать и двойным кликом мышки открыть **Редактор схемы поиска**.
**Выполнить запрос**. Данная кнопка запускает процесс поиска состава/применяемости по текущей схеме. 
Примечание: предварительно следует выбрать необходимую схему поиска во всплывающем списке
 **Обновить список схем поиска.** Данная кнопка обновляет список схем во всплывающем окне.
**Внимание!** Для отображения схемы поиска для объектов конкретного типа на закладках **Поиск состава** и **Поиск применяемости,** следует указать этот тип в атрибуте **Применяется для объектов типа.**

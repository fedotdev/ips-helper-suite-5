# Файл дополнительных настроек сервера приложений
В данном файле хранятся дополнительные настройки сервера приложений. Для консольного сервера приложений имя файла – **ConsoleServer.exe.cfg** , для сервера приложений, реализованного в виде службы NT имя файла – **Intermech.Server.Service.exe.cfg**.
Данные файлы представляют собой XML-документы, в узлах которого содержатся атрибуты и значения с дополнительными настройками. Рассмотрим содержимое данных файлов.

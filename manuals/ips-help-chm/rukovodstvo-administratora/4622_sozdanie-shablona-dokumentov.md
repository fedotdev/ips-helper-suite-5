# Создание шаблона документов
Создание шаблона документов в дереве навигации:
1\. В дереве навигации отметьте элемент **Настройки системы/Шаблоны документов (бланки)** (или один из его дочерних типов в зависимости от вида документа) и примените команду **Создать** его контекстного меню.
2\. В появившемся диалоговом окне введите данные о шаблоне и нажмите **Готово**.
Создание шаблона документов с помощью главного меню:
1\. Вызовите с помощью главного меню **Файл/Создать/Новый объект** диалоговое окно **Создание нового объекта** , в нем выберите тип объектов **Настройки системы/Шаблоны документов (бланки)** (или один из его дочерних типов в зависимости от вида документа) и нажмите кнопку **Далее** ;
2\. В появившемся диалоговом окне введите данные о новом шаблоне и нажмите **Готово**.

# Свойства компонентов редактора форм
Визуальные компоненты редактора форм обладают рядом свойств. Некоторые свойства доступны у всех компонентов, некоторые принадлежат только определённым видам компонентов.
Рассмотрим подробнее свойства всех элементов управления (компонентов) редактора свойств.

# Список ролей
Чтобы увидеть список ролей, созданных в системе, необходимо с помощью команды главного меню **Вид/Администратор базы данных** открыть окно администратора и отметить в дереве элемент **Роли**. При этом в рабочей области окна отобразится список имеющихся в системе ролей. 
Настройки роли производятся на соответствующих закладках, отображаемых в карточке роли, которую можно открыть, применив команду **Свойства (Карточка)** контекстного меню роли; либо на панели с дополнительными видами, открываемую с помощью кнопки **Вид**.

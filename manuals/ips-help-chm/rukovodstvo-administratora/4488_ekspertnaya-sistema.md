# Экспертная система
Примечание: данные настройки будут доступны в том случае, если загружен модуль расширения **Экспертная система**.
**Экспертная система** – это модуль, который предоставляет возможность рассчитывать параметры в технологических процессах, обрабатывать данные с целью нахождения ошибок, определять их причины и их решения, а также генерировать конструкторскую документацию. Вызвать настройки модуля можно с помощью команды **Параметры IPS** из меню **Настройка** панели инструментов системы IPS. В открывшемся окне следует открыть группу **Экспертная система** из пункта **Система**. Данная группа делится на три основные подгруппы со своими параметрами. Входящие в состав параметры можно настроить.
Параметры группы **Ввод недостающих параметров** позволяют включить режим, согласно которому при наличии в расчете атрибутов с отсутствующими значениями будет показан диалог для выбора значений или для ручного ввода данных.
В верхней части окна расположен выпадающий список с опциями:
· **Не заполнять!** При выборе данной опции диалог ручного ввода незаполненных понятий отображаться не будет.
· **Заполнять без сохранения в базе.** При выборе данной опции, введенные значения в окне **Заполнение недостающих параметров** (см. п. ) сохраняться в базе не будут.
· **Заполнять с сохранением в базе.** После ввода значений атрибутов и нажатия кнопки **Считать заново с заполненными атрибутами** в окне **Заполнение недостающих параметров** (см. п. ) данные будут сохранены в базе.
**Внимание!** Для отображения формы ввода данных необходимо включить хотя бы один из представленных переключателей.
Параметры группы **Другие настройки** позволяют использовать краткие имена для типов атрибутов и объектов.
Дополнительно можно настроить параметры группы **Настройки цветов** :
**Трассировка** – это процесс пошагового выполнения команд, вызванных программой. При выполнении трассировки предоставляется возможность просмотра последовательного выполнения команд и значений переменных на данном шаге выполнения программы, что позволяет легче обнаружить ошибки. 
Параметры данной группы описаны ниже:
· **Ограничение трассировки.** Данный параметр позволяет установить лимит на объем данных **Экспертной системы** в килобайтах для отображения в окне трассировки.
· **Окно трассировки.** Данный параметр позволяет отображать окно трассировки в рабочей области объекта.
· **Разрешить трассировку не администраторам.** Данный параметр позволяет вызывать команду **Трассировка** любому пользователю не зависимо от назначенной роли.
· **Создать expert.log.** Данный параметр позволяет создавать и хранить файлы событий в хронологическом порядке в отдельной папке на рабочем компьютере. Система самостоятельно создает папку хранения таких файлов. 
· **Сохранять неразбитый документ.** Данный параметр дает возможность сохранять сгенерированные документы во временную папку до его разбиения.
· **Флаги трассировки.** Данный параметр позволяет выбрать из всплывающего списка необходимые группы объектов, с которыми следует провести трассировку. Существуют следующие флаги параметров трассировки:
− **Показывать загрузку объектов ЭС** – показывает, была ли успешной загрузка объектов экспертной системы. Неудачная загрузка одного из объектов, приведет к ошибке при последующей попытке использования этого объекта;
− **Показывать загрузку прочих объектов** – показывает, была ли успешной загрузка объектов, не являющихся объектами экспертной системы;
− **Показывать проверку условий для объектов** – показывает, были ли истинными условия, наложенные на объекты. Это позволяет выделить случаи, в которых неправильно заданные условия отсеивают все объекты, либо напротив, пропускают слишком много объектов;
− **Трассировать поиск атрибутов** – показывает обработку правил поиска атрибутов. Это позволяет определить неправильную работу этих правил;
− **Трассировать обработку таблиц** – показывает обработку таблиц, что позволяет выявить ошибки в таблицах;
− **Трассировать обработку скриптов** – показывает отладочную информацию о каждом операторе скрипта, что позволяет определить, какой именно оператор работает неверно;
− **Показывать объекты контекста** – показывает информацию обо всех объектах контекста для каждого оператора скрипта. При включении этого переключателя общий размер отладочной информации увеличивается в несколько раз, не смотря на это, включение переключателя позволяет точно определить, в какой момент выполнения задачи произошла ошибка;
− **Показывать изменения атрибутов** – показывает информацию о присвоении значений атрибутам. Это включает явное присвоение значений со стороны приложения-клиента, присвоение в результате выполнения операторов присваивания, а также вычисление результатов таблиц, формул и скриптов;
− **Показывать результаты выборки объектов** – показывает информацию о наборе объектов, полученных всеми операторами поиска объектов. Это позволяет определить, насколько правильно работают операторы поиска объектов;
− **Показывать проверку условий в операторах скриптов** – показывает информацию о проверке глобальных условий, не связанных с объектами;
− **Показывать заполнение полей документов** – показывает выполнение операторов заполнения полей документов. Это позволяет определить, почему не заполняются поля, которые должны заполняться;
− **Трассировать поиск объектов** – показывает выполнение скриптов поиска объектов. Это позволяет определить, почему объекты не находятся, либо находятся неправильные объекты;
− **Показывать результаты присваивания** – показывает только выполнение операторов присваивания в скриптах, что выдает намного меньше информации, чем включение переключателя **Показывать изменение атрибутов** ;
− **Показывать глобальные таблицы** – позволяет установить или скрыть отображение глобальных таблиц на вкладке **Глобальная таблица**.

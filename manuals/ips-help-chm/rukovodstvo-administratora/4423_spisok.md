# Список
На закладке **Список** в виде таблицы отображаются дочерние типы объектов (или список корневых типов, если в дереве метаданных выбран узел **Типы объектов**). В таблице представлены все свойства типов объектов в режиме просмотра с возможностью отсортировать список по значению одной из колонок. Список можно также сгруппировать по значениям любого из свойств типов объектов. Для этого нужно перетянуть заголовок колонки левой кнопкой мыши в специальную область к фразе **Перетащите заголовок колонки в эту область для группировки по значениям этой колонки**.
Выделив двойным щелчком мыши один из типов объектов, можно перейти в режим редактирования данного типа объектов на его закладку **Свойства**.

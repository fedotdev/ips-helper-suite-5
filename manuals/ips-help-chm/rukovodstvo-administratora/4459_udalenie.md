# Удаление
Для удаления языкового варианта нужно выделить его в дереве метаданных и выбрать команду его контекстного меню **Удалить**. Нельзя удалить языковой вариант, если он назначен в системе по умолчанию или назначен каким либо атрибутам или группам атрибутов.

# Задача
Действие **Задача** обозначает задание, которое должен выполнить исполнитель — пользователь или группа пользователей. В связи с этим, с действием **Задача** должен быть ассоциирован пользователь (или группа пользователей), для которого предназначена эта задача. При выполнении этого действия у каждого из исполнителей в папке **Входящие** появится соответствующая запись, одним из свойств которой будет список всех объектов, дошедших до этого шага. После выполнения необходимых операций с присоединенными объектами и нажатия кнопки **Отправить дальше** или **Вернуть назад** , действие получит статус **Выполнено** и продолжение процесса будет идти в соответствии с исходящими из этого действия связями.

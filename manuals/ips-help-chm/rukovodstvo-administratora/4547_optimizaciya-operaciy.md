# Оптимизация операций
Система IPS располагает специальным сервисом, позволяющим вести статистику запросов и временных затрат на выполнение операций, производимых над атрибутами системы, выявлять наиболее подходящие способы оптимизации операций, и выдавать рекомендации по оптимизации. 
Всего в системе существует три способа оптимизации операций над атрибутами:
· **Запись атрибута** — оптимизация операций записи значений в атрибут.
· **Чтение атрибута** — оптимизация операций чтения значений атрибута при просмотре списка объектов заданного типа. 
**Внимание**! Если при запросе на атрибуте не стоит оптимизация по чтению, то запрос может не открытся, а система выдаст сообщение об ошибке:
**Условие «Не содержит атрибут или значение» для атрибута «Литера» не может быть применено, т.к. у рассматриваемого списка атрибутов не установлена оптимизация на чтение или на поиск значений этого атрибута.**
· **Сортировка и поиск по атрибуту** — оптимизация операций поиска и сортировки значений атрибута при просмотре списка объектов заданного типов.
Соответствующие способы оптимизации задаются у атрибута в общем списке атрибутов или у атрибута применительно к типу объектов или связей. С помощью окна **Статистики запросов** можно определить количество и время выполнения операций записи/чтения/поиска атрибутов и принять решение об изменении их способа оптимизации. Правильно подобранные для атрибутов способы оптимизации позволяют значительно увеличить быстродействие системы.

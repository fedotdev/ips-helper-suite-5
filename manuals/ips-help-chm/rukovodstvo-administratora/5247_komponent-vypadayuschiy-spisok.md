# Компонент Выпадающий список
В данном компоненте основные свойства унаследованы от компонента **Список**. Кроме того есть дополнительные свойства:
· **К-во строк**. Задает максимальное число элементов управления, отображаемых в раскрывающейся части поля со списком.

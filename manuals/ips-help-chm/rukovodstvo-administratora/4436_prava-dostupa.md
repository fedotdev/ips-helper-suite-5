# Права доступа
Закладка **Безопасность** позволяет назначить пользователям права доступа к типу связей. По умолчанию всем пользователям разрешен просмотр типа связей в списке, создание, удаление и редактирование связей данного типа. Все права доступа даны только администратору системы. Однако система позволяет изменять права доступа отдельным пользователям, группам пользователей или ролям, под которыми пользователи входят в систему. Система позволяет назначать следующие права доступа:
· **Просмотр типа связей в списке** — разрешает видеть данный тип в списке типов связей, имеющихся в базе данных.
· **Изменение свойств типа связей** — разрешает изменять свойства данного типа связей.
· **Удаление типа связей** — разрешает удалять данный тип связей.
· **Редактирование свойств связей данного типа** — разрешает изменять свойства связей данного типа.
· **Удаление связей данного типа** — разрешает удалять связи данного типа.
· **Создание связей данного типа** — разрешает создавать связи данного типа.
· **Просмотр прав доступа** — разрешает просматривать набор прав доступа к данному типу связей.
· **Изменение прав доступа** — разрешает назначать права доступа на данный тип связей.
**Внимание!** В системе IPS предоставлена возможность копировать права, при условии, что место, куда копируются выбранные права, может принимать такие права доступа.

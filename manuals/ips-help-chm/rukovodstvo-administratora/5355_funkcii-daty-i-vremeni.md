# Функции даты и времени
| **Функция** | **Тип возвращаемой переменной** | **Описание** |
| --- | --- | --- |
| NOW() | дата | Текущая дата и время в соответствии с настройками системы компьютера. |
| TODAY() | дата | Текущая дата. Установлено время полночь. |
| YEAR(date) | целое число | Год. |
| MONTH(date) | целое число | Число от 1 до 12, обозначающее месяц в году. |
| DAY(date) | целое число | Число от 1 до 31, обозначающее день месяца. |
| WEEKDAY(date) | Элемент списка DayOfWeek | Число, обозначающее день недели. |
| HOUR(date) | целое число | Число от 0 до 23, обозначающий номер часа в дне. |
| MINUTE(date) | целое число | Число от 0 до 59, обозначающий номер минуты в часе. |
| SECOND(date) | целое число | Число от 0 до 59, обозначающий номер секунды в минуте. |
| DATEADD(_interval_ , double _number_ , DateTime _date_) | дата | Добавляет к заданной дате интервал времени. **Параметры** _interval_ Элемент списка DateInterval или строковое выражение, представляющее временной интервал, который нужно добавить. _number_ __ Количество интервалов, которые нужно добавить. Оно может быть положительным или отрицательным. Может содержать дробную часть, если параметр _interval_ задает часы, минуты или секунды. Для других значений параметра _interval_ дробная часть игнорируется. _date_ Дата, к которой добавляется интервал. |
| DATEDIFF(_interval_ , DateTime _date1_ , DateTime _date2_ [, firstdayofweek [, firstweekofyear]]) | System.Int64 | Возвращает число интервалов между двумя датами. **Параметры** _interval_ Элемент списка DateInterval или строковое выражение, представляющее временной интервал между двумя датами. _date_ _1, date_ _2_ __ Даты, используемые в вычислении. _firstdayofweek_ Необязательный аргумент, значение, определяющее первый день недели. По умолчанию принимает значение _Воскресенье_. _firstweekofyear_ ____ Необязательный аргумент. Значение, определяющее первую неделю года. По умолчанию полагается неделя, в которую попадает 1-е января. **Примечания**  Если _date_ _1_ представляет более позднюю дату, чем _date_ _2_ , то функция возвращает отрицательное число. Если _interval_ приведен к виду DateInterval.Year, DateInterval.Quarter, или DateInterval.Month, то функция возвращает количество пересекающихся дат и временных границ между _date_ _1_ и _date_ _2_. |
| DATEPART(_interval_ , DateTime _date_ [, firstdayofweek [, firstweekofyear]]) | System.Int32 | Возвращает целое число, содержащее заданную компоненту указанной величины типа _Дата_. **Параметры** _interval_ Элемент списка DateInterval или строковое выражение, определяющее . |
| DATE(int _year_ , int _month_ , int _day_ [, int _hour_ , int _minute_ , int _second_]) | DateTime | Дата, обозначающая указанный год, месяц, день, час, минуту и секунду. **Параметры** _year_ __ Год (от 1 до 9999). _month_ ____ Месяц (от 1 до 12). _day_ ____ День (от 1 до количества дней в месяце). _hour_ __ Необязательный аргумент. Часы (от 0 до 23). _minute_ __ Необязательный аргумент. Минуты (от 0 до 59). _second_ __ Необязательный аргумент. Секунды (от 0 до 59). __ |
| MIN(DateTime _date1_ , DateTime _date2_ , …) MIN(DateTime[] _date_) | DateTime | Возвращает наименьшую дату из списка. |
| MAX(DateTime _date1_ , DateTime _date2_ , …) MAX(DateTime[] _date_) | DateTime | Возвращает наибольшую дату из списка |
| FORMAT(DateTime, string _style_) | string | Возвращает строковое выражение в формате, соответствующем командам форматирования. Описание параметра style смотрите в разделе составное форматирование. |
При использовании функции STR с данными типа **DateTime** используются стандартные параметры форматирования. Строка стандартного формата является просто псевдонимом для строки пользовательского формата. Преимуществом использования псевдонима для ссылки на строку пользовательского формата является то, что при изменении строки пользовательского формата псевдоним может оставаться неизменным. Это важно, поскольку строковые представления значений даты и времени обычно зависят от региональных параметров. Например, строка стандартного формата d указывает, что значение даты и времени будет отображаться с использованием шаблона короткого формата даты. Для инвариантных региональных параметров таким шаблоном является **ММ/ДД/ГГГГ**.
| Описатель формата | Имя | Описание |
| --- | --- | --- |
| d | Короткий шаблон даты | Представляет пользовательский формат даты в коротком виде: STR(NOW(),'d') = 01.11.2010 |
| D | Полный шаблон даты | Представляет пользовательский формат даты в полном виде: STR(NOW(),'D') = 1 ноября 2010 г. |
| f | Полный шаблон даты и времени (короткий шаблон времени) | Представляет полный шаблон даты (D) и короткий шаблон времени (t), разделенные пробелом. STR(NOW(),'f') = 1 ноября 2010 г. 12:13 |
| F | Полный шаблон даты и времени (полный шаблон времени) | Представляет пользовательский формат даты и времени в полном виде STR(NOW(),'F') = 1 ноября 2010 г. 12:13:45 |
| g | Общий шаблон даты и времени (короткий шаблон времени) | Представляет короткий шаблон даты (d) и короткий шаблон времени (t), разделенные пробелом. STR(NOW(),'g') = 01.11.2010 12:13 |
| G | Общий шаблон даты и времени (полный шаблон времени) | Представляет короткий шаблон даты (d) и полный шаблон времени (T), разделенные пробелом. STR(NOW(),'g') = 01.11.2010 12:13:32 |
| M, m | Шаблон дней месяца | STR(NOW(),'m') = ноября 01 |
| O, o | Шаблон цикла обработки даты и времени | Представляет строку пользовательского формата даты и времени, используя шаблон, который сохраняет данные о часовом поясе. STR(NOW(),'o') = 2008-04-10T06:30:00.0000000+02.00 |
| R, r | Шаблон RFC1123 | Когда используется этот спецификатор стандартного формата, операция форматирования или разбора всегда использует инвариантные региональные параметры. Форматирование не изменяет значение форматируемых объектов. STR(NOW(),'r') = Thu, 10 Apr 2008 13:30:00 GMT |
| s | Сортируемый шаблон даты и времени (соответствует ISO 8601) | Вид сторки не зависит от региональных настроек. STR(NOW(),'s') = 2008-04-10T06:30:00 |
| t | Короткий шаблон времени | STR(NOW(),'t') = 11:42 |
| T | Полный шаблон времени | STR(NOW(),'T') = 11:42:35 |
| u | Универсальный сортируемый шаблон времени и даты | STR(NOW(),'u') =2010-04-10 13:30:00Z |
| U | Универсальный полный шаблон даты и времени | STR(NOW(),'U') =1 ноября 2010 г. 09:21:23 |
| Y, y | Шаблон месяца года | STR(NOW(),'Y') =Ноябрь 2010 г. |

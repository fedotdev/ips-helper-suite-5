# Свойства
Задать или изменить свойства уровня продвижения можно на закладке **Свойства** рабочей области, отметив в дереве метаданных необходимый уровень:
· **Глобальный идентификатор**. Глобальный идентификатор уровня продвижения.
· **Идентификатор**. Уникальный идентификатор уровня продвижения. Назначается системой автоматически и не подлежит дальнейшей модификации.
· **Изображение**. Позволяет загрузить пиктограмму, отображающую суть данного уровня продвижения. Чтобы загрузить пиктограмму, нажмите кнопку, расположенную с правой стороны отмеченной строки, и в появившемся диалоге укажите путь к файлу пиктограммы. Рекомендуется использовать пиктограммы размером 32x16, 16x16 и 32x32 пикселов.
· **Использовать в качестве первого шага**. Используется для назначения по умолчанию первого шага схемы жизненного цикла. Т.е. при помещении на схему ЖЦ шага с данным уровнем продвижения он автоматически назначается первым шагом схемы.
· **Контроль подписей**. Позволяет настроить графы для подписей объектов, имеющих схемы жизненных циклов с таким уровнем продвижения. Объекты, не имеющие указанных подписей, невозможно будет перевести на шаг с данным уровнем продвижения. Чтобы настроить контроль подписей, вызовите диалог настройки граф для подписей с помощью кнопки, расположенной с правой стороны строки. Вызовите команду **Добавить новую группу** контекстного меню поля диалога. Отметьте графы, которые необходимо будет подписывать, и нажмите **ОК**. Переключатель **Использовать строгий контроль для данной графы** позволяет установить строгий контроль подписи, т.е. подпись объекта будет считаться устаревшей, если объект модифицировался после его подписания.
· **Литера**. Литера уровня продвижения (в настоящее время системой не используется).
· **Наименование**. Уникальное наименование уровня продвижения.
· **Предметная область**. Позволяет отметить в выпадающем списке предметные области, к которым относится уровень продвижения. Если указано значение **Все** , то данный уровень продвижения будет виден всем пользователям, независимо от предметных областей, с которыми они работают.
· **Файловый шкаф**. Позволяет указать файловый шкаф, в который будут перемещены двоичные данные и файлы версий объектов, перемещённых на шаг ЖЦ с данным уровнем продвижения. Перемещение производится соответствующей задачей, которую нужно настроить в **Планировщике задач** см. п. .

# Настройка итераций
Настройка итераций выполняется в диалоге **Настройка / Параметры IPS / Система / Итерации**.
· **Запрашивать создание новой итерации объекта перед его восстановлением из итерации** регулирует автоматический вызов окна создания итерации объекта перед его восстановлением из другой итерации. 
Если настройка **Запрашивать создание новой итерации объекта перед его восстановлением из итерации** включена и выполняется команда **Восстановить** , то система предлагает пользователю создать новую итерации для объекта перед восстановлением старой.
· **Максимальное время жизни итерации (дней)** определяет сколько дней будет существовать итерация. Пустое значение либо ноль означает, что данная настройка не действует.
· **Максимальное количество итераций на версию объекта** определяет сколько итераций на версию объекта можно будет создать. Лишние итерации будут автоматически удаляться процедурой удаления устаревших данных, начиная от более старых итераций. Пустое значение либо ноль означает, что данная настройка не действует.
· **Уровень продвижения, на котором у версии объекта удаляются итерации** определяет уровень продвижения объекта, на котором у него будут удалены итерации (в процессе ближайшей процедуры удаления устаревших данных). Пустое значение означает, что данная настройка не действует.

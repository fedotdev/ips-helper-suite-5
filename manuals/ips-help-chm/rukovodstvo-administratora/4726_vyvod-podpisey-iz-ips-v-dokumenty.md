# Вывод подписей из IPS в документы
Вывод подписей в документы осуществляется при помощи записи предварительно настроенных значений в параметры файлов. Запись параметров производится при выгрузке файлов документа из базы данных в рабочую область, при просмотре или печати. 
Отображение колонок подписей настраивается в диалоге **Настройка /Параметры IPS / Система / Электронные подписи / Настройка отображения колонок подписей.**
Отображение подписей в файле настраивается в диалоге **Настройка /Параметры IPS / Система / Электронные подписи / Общие настройки**.
Настройка имен параметров осуществляется в диалоге **Настройка / Параметры IPS / Система / Электронные подписи / Параметры вывода подписей**.
Если на вкладке **Параметры вывода подписи** указаны не все необходимые параметры, то для самостоятельной настройки дополнительных параметров вывода подписей в документы, следует перейти в диалог **Настройка / Параметры IPS / Система / Электронные подписи /Дополнительные параметры вывода подписей.**
С помощью кнопки **Добавить атрибут** можно добавлять необходимые атрибуты подписи для вывода в документ либо атрибуты пользователя, поставившего подпись.
При добавлении атрибута, шаблон для параметра вывода подписи создается автоматически в формате **[Графа для подписи]_Наименование атрибута**. При выводе в документ, подстановка **[Графа для подписи]** заменяется на наименование графы подписи без квадратных скобок. 
Примечание: шаблон для параметра можно изменить вручную (например, наименование атрибута слишком длинное).

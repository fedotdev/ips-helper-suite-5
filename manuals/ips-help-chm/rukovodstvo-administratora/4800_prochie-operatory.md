# Прочие операторы
Оператор **Подбор объектов** позволяет установить правило подбора версий, которое будет использоваться во всех операторах поиска объектов. Оператор работает исходя из текущего контекста.
В IPS у каждого объекта может быть несколько версий, и для выбора нужной версии существуют специальные правила. Единственный параметр оператора – это **Правило подбора версий** , которое можно назначить, нажав на кнопку . 
После этого появится диалог выбора правила подбора версий.
Примечание: если по параметру оператора **Правил о подбора версий** объект, удовлетворяющий условиям выбора, не найден, то выбирается последняя, имеющаяся версия объекта. Такое поведение прописано в коде IPS.
Примечание: выбранный контекст перекрывает все правила выбора версий. Если контекст выключен или его нет, то оператор **Подбор объектов** отработает по дереву версий объекта. Если контекст включен, то отработка реализуется по объектам в рамках выбранного контекста. 
Оператор **Пересчитать атрибуты** доступен только в скриптах пересчета (см. п. ); он позволяет задать атрибуты, значения которых должны быть пересчитаны. Нажмите кнопку для добавления атрибута объекта или кнопку для добавления атрибута связи. Чтобы удалить из списка атрибут, который не нужно пересчитывать, нажмите кнопку .
Оператор **Присвоить в базе** доступен только в командных скриптах ЭС (см. п. ); он делает то же, что и оператор **Присваивания**(то есть, присваивает новое значение атрибуту в задаче ЭС), но, кроме этого, он записывает новое значение прямо в базу. Параметры оператора практически аналогичны параметрам оператора **Присваивания**.
**Внимание!** Рекомендуется использовать этот оператор только в крайних случаях, когда без него нельзя обойтись. Вместо этого следует использовать обычный оператор присваивания, в результате чего пользователь получит возможность самостоятельно проверить, какие изменения в базе должны быть произведены, и одобрить их либо отказаться от них.

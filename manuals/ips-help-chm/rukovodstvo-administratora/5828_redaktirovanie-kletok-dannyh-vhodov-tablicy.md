# Редактирование клеток данных входов таблицы
Клетки входа представляют собой условия, накладываемые на атрибут соответствующего столбца (для вертикального входа) или соответствующей строки (для горизонтального входа). Это не обычное условие экспертной системы, а всего лишь краткое условие, в котором требуется задать операцию сравнения и значение, с которым сравнивается значение атрибута. 
На рисунке выше изображены доступные операции сравнения. Операция **Любые значения** (\*\*\*\*\*) всегда возвращает истину. Операция **Набор значений** (**{}**) возвращает истину, если значение атрибута совпадает с одним из заданных значений. Пустая ячейка означает повторение предыдущего условия – без этого условие пришлось бы вводить много раз, и, что важнее, вычислять много раз.
В зависимости от выбранного условия поле ввода значения может меняться, так на рисунке выше показан пример ввода только одного значения **Ссылка на объект IMBASE** \- **Четырехкулачковые**. Выбор значения в данном случае осуществляется при нажатии .
При выборе операции **Набор значений** (**{}**) появляется следующее окно.
Добавление значений по одному производиться при помощи контекстного меню по команде **Добавить** / **Значение**. Изменение выбранного значения из набора, производится путем его выделения и его перевыбора в поле **Значение** при нажатии .
Добавление диапазона значений возможно при помощи команды контекстного меню **Добавить** / **Диапазон**. Команда доступна для ввода вещественных чисел. В этом случае необходимо указать начало и конец диапазона
Значение диапазона будет записано через знак «**:»** (двоеточие).
Множественный выбор доступен при помощи команды , которая вызывает справочник, если этот справочник существует для выбранного атрибута и типа объекта. Например, для атрибута **Ссылка на объект IMBASE** и типа объекта **Оборудование** будет выдано диалоговое окно со справочником оборудования. Команда доступна и для остальных операций. Множественный выбор при использовании этой команды будет доступен, если операция позволяет выбрать несколько значений.
Если в таблице несколько строк или столбцов с условиями, то для упрощения ввода вместо многих повторяющихся значений можно просто оставлять клетки пустыми. Когда экспертная система будет искать нужную строку в этой таблице, она будет использовать следующий алгоритм (см. рис. к п. ):
1\. Сравнивается значение атрибута **Переход.Ссылка на объект IMBASE** со значениями, записанным в первой клетке столбца. Если **Переход.Ссылка на объект IMBASE** = 850110 или 850114, тогда проверяется условие второго столбца этой строки **Оснастка.Ссылка на объект IMBASE** = любое значение и затем третьего **Количество инструмента на операции** <=2.
2\. Предположим, что это условие **Количество инструмента на операции** <=2 неверно. Тогда система переходит к анализу второй строки, в которой находится пустые клетки для **Переход.Ссылка на объект IMBASE** и **Переход.Ссылка на объект IMBASE**. Пустая клетка считается повторением предыдущего условия.
3\. Если параметр **Количество инструмента на операции** был равен 3, то система выберет вторую строку, для которой будет анализироваться значение параметра **Оборудование.1-я характеристика станка** продолжит анализ следующих строк.
Желательно задавать условия так, чтобы любым значениям проверяемых параметров соответствовала хотя бы
одна строка или столбец.

# Параметр Сохранять выбор страниц у компонентов Закладки
В настройки IPS **Настройка / Параметры IPS / Система / Редактор форм** добавлен параметр **Сохранять выбор страниц у компонентов Закладки** , значение который выставлено по умолчанию **Да**. 
**Внимание!** При изменении значения параметра на **Нет** при последующем сохранении форм в **Редакторе форм** сохранение выбора страниц на компонентах **Закладки** (IMTabControl) не производится: в этом случае при открытии формы в карточке объекта будет выбрана первая страница компонентов **Закладки**.

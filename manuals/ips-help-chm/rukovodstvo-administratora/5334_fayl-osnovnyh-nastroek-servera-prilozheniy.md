# Файл основных настроек сервера приложений
В данном файле хранятся все основные настройки сервера приложений. Для консольного сервера приложений имя файла – **ConsoleServer.dll.config** , для сервера приложений, реализованного в виде службы NT имя файла – **Intermech.Server.Service.dll.config**.
Данные файлы представляют собой XML-документы, в узлах которого содержатся атрибуты и значения с основными настройками. Рассмотрим основные настройки.

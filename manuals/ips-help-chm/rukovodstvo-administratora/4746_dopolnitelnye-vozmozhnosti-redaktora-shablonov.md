# Дополнительные возможности редактора шаблонов
Редактор шаблонов процессов добавляет в главное меню пункт **Шаблон** , который содержит команды по управлению редактором. Например, имеется ряд дополнительных функций, облегчающих дизайнеру построение правильного шаблона. 
· С помощью команды **Шаблон/Проверить корректность** дизайнер может проверить корректность созданного шаблона процесса. Если шаблон некорректный, на экране появится диалоговое окно со списком ошибок. Такой шаблон не сможет использоваться для запуска процессов до тех пор, пока данные ошибки не будут устранены.
· С помощью команды **Шаблон/Выровнять по сетке** редактор автоматически выровняет по узлам сетки пиктограммы действий шаблона процесса.
· Команда **Шаблон/Переменные** вызывает диалоговое окно редактирования переменных, в котором дизайнер может добавлять, изменять или удалять переменные данного шаблона процесса. Подробнее о переменных маршрутизатора см. п. .
· Команда **Шаблон/Настройки редактора** вызывает окно основных настроек редактора, с помощью которых можно определить, как будет выглядеть окно редактора.
· Команда **Закончить отладку** позволяет снять с режима отладки шаблон, что означает последующее изменение данного шаблона допускается только при выпуске новой версии.
· Команда **Закончить отладку всех связанных шаблонов** позволяет снять с режима отладки шаблон и созданных в нем подпроцессов, а последующее изменение доступно только при выпуске новой версии.

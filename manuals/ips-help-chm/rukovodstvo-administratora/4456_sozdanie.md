# Создание
Чтобы создать новый языковой вариант, в дереве метаданных отметьте элемент **Языковой вариант** и примените команду **Добавить** его контекстного меню. При этом в дереве появится новый языковой вариант, большинству свойств которого будут присвоены значения по умолчанию. Отредактируйте свойства созданного языкового варианта и нажмите кнопку **Применить**.

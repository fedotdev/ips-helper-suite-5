# Модуль клиента IPS WebPortal
Модуль клиента **IPS WebPortal** представляет собой встроенную в ядро серверную часть и плагинную сборку **Навигатор портала** для клиента IPS. Серверный модуль представляет собой серверные службы, которые автоматически запуcтятся на сервере приложений после того как он будет сконфигурирован на соединение с порталом (см. п. ). Возможности по настройке метаданных, управлению расписанием задач и т.д. из клиента IPS будут доступны в том случае, если загружен модуль расширения **Навигатор портала**.
Для первичной настройки клиента необходимо знать данные текущего узла, указанные в следующем разделе. Эти данные должны быть переданы администратором портала.

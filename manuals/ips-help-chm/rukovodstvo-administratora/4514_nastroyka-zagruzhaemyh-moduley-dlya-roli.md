# Настройка загружаемых модулей для роли
Настройку модулей, которые будут загружаться при входе в систему, можно осуществить на закладке **Загружаемые модули** , отображаемую в карточке роли или на панели с дополнительными видами.
Загружаемые модули отображаются на закладке в виде списка. Чтобы добавить модуль в список, необходимо нажать кнопку **Добавить** и выбрать его в появившемся диалоге. Чтобы удалить загружаемый модуль, необходимо отметить его в списке и нажать кнопку **Удалить**.
Примечание: если по какой-то причине нельзя удалить загружаемый модуль из настройки роли (например, некоторые обязательные для роли модули), то после нажатия кнопки **Применить** модуль снова будет отображен в списке.

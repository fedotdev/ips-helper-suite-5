# Создание
Чтобы создать новый тип объектов, в дереве метаданных выделите элемент **Типы объектов** и примените команду **Создать** его контекстного меню. При этом в дереве появится новый тип объекта, большинству свойств которого будут присвоены значения по умолчанию. Отредактируйте свойства созданного типа объектов и нажмите кнопку **Применить**. Для создания дочернего типа объектов выполните команду **Создать** в локальном меню родительского типа объектов.

# Компонент Список
В данном компоненте основные свойства унаследованы от компонента **Текстовое поле** , кроме того, есть дополнительные свойства:
· **Горизонтальная прокрутка**. Позволяет управлять отображением горизонтальной линейки прокрутки в элементе управления.
· **Переключение**. Значение данного свойства определяет, можно ли передавать фокус ввода данному элементу при помощи клавиши **Tab**.
· **Сортировка**. Значение управляет сортировкой позиций в элементе управления по алфавиту.

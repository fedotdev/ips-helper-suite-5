# Элементы дерева метаданных
Элементы дерева метаданных — это главные составляющие конфигуратора, группирующие в себе данные и отличающиеся друг от друга набором свойств и назначением. 
· **Атрибуты (Группы атрибутов).**
· **Предметные области.**
· **Система.**
· **Схемы жизненного цикла.**
· **Типы объектов.**
· **Типы связей.**
· **Уровни продвижения.**
· **Языковые варианты.**
Подробное описание этих элементов приведено ниже.
Каждый из элементов дерева метаданных имеет две закладки в рабочей области, одна из которых отображает список с данными, принадлежащими выбранному в дереве метаданных элементу, а другая позволяет назначить общие права для всех данных элемента.

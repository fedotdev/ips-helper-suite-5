# Узел \<Updates\>
В данном узле хранится список папок, в которых содержатся скрипты автообновления.
Каждый элемент списка хранится в дочернем узле XML примерно такого содержания:
<UpdatesFolder Location=".\Updates"/>,
где значение атрибута **Location** – относительный или абсолютный путь к очередной папке, в которой содержатся скрипты автообновлений.

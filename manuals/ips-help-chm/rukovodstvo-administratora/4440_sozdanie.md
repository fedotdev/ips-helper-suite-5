# Создание
Создать новый уровень продвижения можно, воспользовавшись командой **Добавить** контекстного меню элемента **Уровни продвижения**. При этом в дереве появится новый уровень продвижения, большинству свойств которого будут присвоены значения по умолчанию. Отредактируйте свойства созданного уровня продвижения и нажмите кнопку **Применить**.

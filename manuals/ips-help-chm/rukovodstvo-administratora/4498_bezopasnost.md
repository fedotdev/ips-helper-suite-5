# Безопасность
Система IPS предлагает ряд эффективных возможностей по защите информации, хранящейся в базе данных предприятия. Перед настройкой с безопасностью необходимо ознакомиться с правилами по работе с объектами базы данных:
· Системный администратор должен зарегистрировать в списке пользователей IPS всех сотрудников предприятия и назначить **ИМЯ** , **ПАРОЛЬ** и **РОЛЬ** для каждого пользователя. Благодаря вводу указанных значений осуществляется авторизованный вход и доступ к объектам базы данных каждого пользователя системой IPS. Для полной конфиденциальности пользователи могут изменять свой пароль, однако, администратор имеет возможность изменить его на новый, независимо от того знает он старый или нет (подробнее в п. ).
· Администратор должен назначить пользователям права доступа к различной категории информации (объекты, атрибуты, архивы, шаблоны процессов и т.д.). Для облегчения установки прав доступа пользователи системы могут объединяться в группы.
· Система IPS позволяет назначить мандатное разграничение прав доступа на информационный объект помимо дискреционной (избирательной) модели управления доступом. Данная возможность необходима для того, чтобы любому объекту можно было назначить уровень доступа, который будет определять права доступа пользователя к этому объекту в зависимости от того, с каким уровнем доступа данный пользователь зашел в систему.
· Файловые документы IPS имеют три копии: архивную, рабочую и файловую. При взятии на редактирование документа, в файловом шкафу создается рабочая копия, которая появляется на рабочем столе пользователя. В то время на жёстком диске пользовательского компьютера создается файловая копия документа, в которую и вносятся все изменения. Третья копия документа – архивная (только для просмотра), находится в общем доступе для всех пользователей системой IPS. При завершении редактировании файла, отредактированная копия документа копируется в рабочую копию, после чего любой другой пользователь может продолжить работу с документом с любого компьютера в сети.
· Для защиты архивных и рабочих файлов в системе IPS созданы т.н. защищенные базы данных или файловые шкафы, где файлы хранятся в упакованном виде.
· Система IPS предоставляет возможность пользоваться электронной подписью, которая защищена специальными криптографическими алгоритмами. В системе создается архив, в котором можно регистрировать только те документы, на которые были собраны электронные подписи. У каждого пользователя есть возможность обладать несколькими подписями для соответствующей должности. Для реализации электронных подписей можно подключать внешнюю криптографическую систему, совместимую с **Microsoft Crypto API** , а также использовать сертификаты, подписанные удостоверяющими центрами.
· Система IPS ведет свой журнал регистрации происходящих событий: вход в систему, добавление, изменение, просмотр, удаление объектов и т.д.

# Закладка Условие
Закладка отображается только у действия **Условие** и предназначена для настройки условия перехода действия по связям, которые будут выбраны в результате вычисления этого действия. Результатом вычисления выражения может быть булева величина: **Истина** или **Ложь**.
В условных действиях реализован механизм, который по умолчанию рассчитывает условия без использования экспертной системы. При включенном переключателе**Использовать формулы экспертной системы** механизм позволяет использовать экспертную систему и ее редактор для задания условий перехода по связям.
Кнопка вызывает диалог задания условий.
С помощью данного диалога дизайнер может задать условное выражение. В выражение можно вставить:
· **Функцию** , выбрав ее из списка.
· **Переменную** , определенную в текущем шаблоне, выбрав ее из списка в поле **Имя атрибута**.
· **Значение переменной** (позволяется выбрать только значения, соответствующие данному типу переменной);
· **Операторы** :
Сравнения ( **«=», « >», «<», «<>», «<=» и «>=»**);
Логические (**И, Или, Не**);
Арифметические (**«+», «–», «*», «/»**).
Проверка корректности и вычисление выражения осуществляются нажатием кнопки **Проверить** на закладке.

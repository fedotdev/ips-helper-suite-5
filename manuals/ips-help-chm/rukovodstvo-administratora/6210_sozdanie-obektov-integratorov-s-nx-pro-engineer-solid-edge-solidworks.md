# Создание объектов интеграторов с NX, Pro ENGINEER, Solid Edge, SolidWorks, Компас-3D
Указанные интеграторы позволяют осуществить интеграцию системы IPS с системами NX, Pro/Engineer, Solid Edge и SolidWorks.
Откройте окно настройки инструментов, выберите страницу **Интеграторы с приложениями** и нажмите кнопку **Создать**. В появившемся окне укажите требуемый интегратор с приложением и нажмите кнопку **ОК**.

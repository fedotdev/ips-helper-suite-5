# Общий поисковый индекс
IPS ведёт общий поисковый индекс, в который попадают значения атрибутов с включенной опцией **Включать атрибут в общий поисковый индекс**. Индекс позволяет производить быстрый поиск объектов по значениям строковых, текстовых, ссылочных и файловых атрибутов с учётом общих словоформ и сортировкой по релевантности запроса. Для ссылочных атрибутов в индекс помещается заголовок объекта, на который ссылается атрибут. Для файловых атрибутов в индекс также попадают строки, содержащиеся в файлах тех форматов, для которых в системе зарегистрированы специальные конвертеры, извлекающие из файлов текстовую информацию. Вместе с системой поставляются конвертеры для документов встроенного редактора (спецификаций, ведомостей, извещений и пр.), XML-файлов, различных текстовых форматов (TXT, PDF, DOC, DOCX, RTF, HTML), таблиц MS Excel, графических форматов компании AutoDesk и др. Серверные модули расширения системы могут подключать собственные конвертеры для извлечения текста из файлов. Список загруженных конвертеров можно посмотреть командой converters в консольном сервере приложений.
Для строковых, ссылочных и текстовых атрибутов поисковый индекс обновляется в момент присвоения атрибуту нового значения. Файловые атрибуты сначала помещаются в очередь на индексацию, что позволяет отделить по времени ресурсоёмкий процесс индексации файлов и не замедлять операции занесения файлов в базу данных IPS. Для обработки очереди на индексацию предназначена задача **Фоновая индексация изменившихся атрибутов** , запуск которой следует настроить в **Планировщике задач** (см. п. ). Частота запуска задачи зависит от того, насколько быстро требуется отражать в поисковом индексе изменения в файлах. Также для корректной сортировки результатов поиска по релевантности запроса следует настроить периодический запуск задачи **Пересчёт релевантности данных в общем поисковом индексе**. Данную задачу рекомендуется запускать не чаще раза в неделю, т.к. погрешность в расчёте релевантности поиска накапливается достаточно медленно и частый пересчёт не требуется.
Поиск объектов по индексу производится с помощью поля **Искать** на панели фильтрации списка объектов (см. в ).

# Создание команды запуска типа Приложение Windows
Данный тип команд позволяет запускать приложения Windows для просмотра, редактирования и печати файлов, хранящихся в информационных объектах IPS.
Откройте настройки инструментов, выберите в дереве тип объектов, для которого требуется создать новую команду, затем на странице **Редактор команд** нажмите кнопку **Создать**. В появившемся диалоговом окне выберите тип запуска приложений для создаваемой команды (см. п. ), а затем укажите тип создаваемой команды – **Приложение Windows** :
После этого в списке команд будет отображена созданная команда:
Следующим шагом необходимо настроить свойства этой команды. Выделите её в списке и нажмите кнопку **Свойства**. В появившемся окне требуется заполнить свойства команды:
Например, была создана команда для просмотра изображений с помощью бесплатной программы FastStone Image Viewer (предполагается её наличие на компьютере пользователей по указанному пути).
В строку ввода **Исполняемый файл** следует ввести имя внешней программы для указанного типа файлов. Например, для просмотра изображений различных форматов может использоваться **программа FastStone Image Viewer: C:\Program Files\FSImgViewer\FSViewer.exe**.
Имя программы должно включать полный путь к программе (т.е. имя диска и директорий), кроме случаев, когда операционная система может сама найти эту программу (например, программа находится в директории, указанном в переменной окружения PATH). Допускается ввод сетевого пути для программы (UNC-формат), например:
**\\\SERVER\C$\Program Files\FSImgViewer\FSViewer.exe**. В этом примере SERVER – имя компьютера в сети Windows, C$ – имя ресурса на этом компьютере, остальная часть строки – путь к внешней программе в этом ресурсе.
Кнопка **Обзор** справа от строки ввода позволяет произвести выбор нужной программы в специальном окне, в котором Вы можете просмотреть имеющиеся программы на разных дисках и в разных директориях.
Кнопка **Системные переменные** позволяет добавить в редактор какие-то системные переменные окружения, например **%PATH%**.
В строку **Аргументы запуска** следует вводить параметры, которые будут передаваться программе при запуске. При вводе параметров требуется использовать следующие соглашения: 
| Спецсимволы | Описание |
| --- | --- |
| ! | Символ **«!»** в строке ввода **Аргументы** используется для передачи внешней программе в виде параметра имени файла, для редактирования или просмотра которого она вызвана. Имя файла в этом случае будет включать путь к этому файлу, но не будет включать расширения имени файла, например, **C:\TEMP\image** |
| !.! | При использовании строки **«!.!»** внешней программе будет передано полное имя файла (вместе с путем и расширением) для которого она вызвана, например, **C:\TEMP\image.png** |
| ? | Передать внешней программе только имя файла без пути и расширения, например, **image** |
| ?.? | Передать внешней программе только имя файла с расширением (без пути), например: **image.png** |

После выполнения настроек нажмите кнопку **Закрыть** :

# Исполнение обязанностей
На закладке **Исполнение обязанностей** предоставляется возможность назначить пользователя, который будет исполнять обязанности другого пользователя на момент его отсутствия.
**Внимание!** Такие настройки доступны только пользователям с правами администратора. 
Чтобы назначить пользователя, который будет исполнять обязанности, следует выполнить следующие пункты:
1\. Следует выделить необходимую учетную запись пользователя в дереве **Навигатора** , в рабочей области отобразится карточка пользователя с закладками. 
2\. В карточке следует выбрать закладку **Исполнение обязанностей.**
В состав закладки **Исполнение обязанностей** входят две закладки **Чьи обязанности исполняет пользователь** (закладка для настроек) и **Кто исполняет обязанности**(информационная закладка).
3\. В столбце **Исполняет обязанности** двойным кликом мышки следует взять на редактирование строку и с помощью кнопки открыть диалоговое окно **Редактирование списка «Исполняет обязанности»**.
3\. Для выбора пользователя, обязанности которого необходимо исполнять, следует нажать кнопку . Затем необходимо нажать кнопку .
Примечание: если сотрудник должен исполнять обязанности нескольких пользователей в один временной период, то следует добавить второго пользователя. Если учетная запись добавлена ошибочно, ее можно удалить с помощью кнопки .
Кнопка очищает весь добавленный список пользователей. 
4\. В столбце **Начальная дата** двойным кликом мышки следует взять на редактирование строку и с помощью кнопки необходимо выбрать в календаре с какого числа пользователь будет исполнять обязанности.
5\. В столбце **Конечная дата** двойным кликом мышки следует взять на редактирование строку и с помощью кнопки необходимо выбрать в календаре конечное число исполнения обязанностей.
6\. Во всплывающем списке столбца **Роль** следует указать роль пользователя, в которой он будет исполнять обязанности.
Примечание: в списке представлены те роли, которые назначены пользователю, обязанности которого будут исполнять.
7\. Для завершения нажмите кнопку .

# Пакетное чтение при работе с порталом
Данная настройка позволяет указать количество записей (размер пакета), которое будет использоваться при чтении информации из портала IPS.
Настройка доступна в диалоговом окне **Настройка / Параметры IPS / Сервисы портала / Навигатор портала** :
Настройка **Количество записей** указывает, сколько записей будет запрашиваться для каждого пакета данных, получаемого со стороны портала.

# Назначение допустимых атрибутов
Назначение допустимых атрибутов типу связей, изменение набора атрибутов и корректировка их свойств осуществляется на закладке **Атрибуты**. С левой стороны рабочей области отображается список атрибутов, назначенных данному типу связей, с правой стороны — свойства выбранного из списка атрибута. 
Здесь можно скорректировать свойства атрибутов под данный тип связей. В таком случае, для данного типа связей свойства этого атрибута будут принимать значения не из общих его свойств, а из скорректированных для данного типа связей. Значения свойств атрибута рассмотрены в п. и функционируют аналогичным образом, кроме свойств, рассмотренных ниже:
· **Влияет на дату модификации содержимого объекта**. Если включить данный переключатель, а также аналогичный переключатель на допустимости связи между данными типами объектов (см. п. ), то изменение значения данного атрибута изменит и значение даты модификации содержимого родительского объекта. Соответственно, изменение данного атрибута будет равносильно изменению родительского объекта и может потребовать взятия его на изменение или выпуска новой версии.
· **Оптимизация операций**. Задает способ оптимизации операций с атрибутом при работе со списком связей данного типа (составом/применяемостью объектов):
− **Запись атрибута**. Оптимизация операций записи значений в атрибут. Рекомендуется использовать для атрибутов, которые не будут просматриваться пользователями в списках с составом/применяемостью объектов (например, пароли или двоичные данные).
− **Сортировка и поиск по атрибуту**. Оптимизация операций поиска и сортировки значений атрибута при просмотре состава/применяемости объектов в табличном виде. 
− **Чтение атрибута**. Оптимизация чтения значений атрибута при просмотре его в составе/применяемости объектов по данному типу связей.
**Внимание**! Если при запросе на атрибуте не стоит оптимизация по чтению, то запрос может не открытся, а система выдаст сообщение об ошибке:
**Условие «Не содержит атрибут или значение» для атрибута «Литера» не может быть применено, т.к. у рассматриваемого списка атрибутов не установлена оптимизация на чтение или на поиск значений этого атрибута.**
· **Правило**. Позволяет задать правило через выражение **[Value]** , ограничивающее параметры вводимых значений атрибутов абсолютным значением или значением другого атрибута данной связи.
Применительно к атрибутам вещественным числам, выраженным в единицах измерения, для поля **Правило** можно вызвать специальный диалог настройки атрибута. 
Поле **Единица измерения по умолчанию** содержит краткое наименование единицы измерения, которая будет использоваться в данном атрибуте по умолчанию. Список выбора при этом ограничен допустимыми единицами измерения для данного атрибута.
· **Принадлежность типу связей**. Позволяет указать обязательность наличия данного атрибута у связи:
− **Обязательный атрибут, добавляемый автоматически**. Данный атрибут автоматически добавляется при создании новой связи между объектами. Присутствие данного атрибута обязательно, и удалить его невозможно.
− **Необязательный атрибут, добавляемый автоматически**. Данный атрибут автоматически добавляется при создании связи между объектами. Наличие данного атрибута необязательно, поэтому пользователь имеет возможность удалить его из набора атрибутов созданной связи в карточке объекта с помощью команды **Удалить** контекстного меню данного атрибута на закладке **Свойства связи**.
− **Атрибут может быть добавлен вручную**. Атрибут не добавляется при создании новой связи между объектами, но может быть добавлен пользователем вручную в карточке объекта с помощью команды **Добавить** контекстного меню любого из атрибутов на закладке **Свойства связи**.
Чтобы добавить атрибут в список допустимых атрибутов, нажмите правую кнопку мыши в области списка атрибутов и выполните команду контекстного меню **Добавить**. В появившемся диалоговом окне выберите нужный атрибут и нажмите кнопку **ОК**. При этом в списке появится выбранный атрибут с его общими свойствами. При необходимости отредактируйте свойства атрибута под данный тип связи и нажмите кнопку **Применить**.
Чтобы исключить атрибут из списка, выделите его и выполните команду **Удалить** его контекстного меню. Нельзя удалить из списка атрибут, влияющий на содержимое родительского объекта, если в базе данных существуют связи данного типа, у которых присутствует этот атрибут.

# Работа с таблицами
Таблицы экспертной системы позволяют определить зависимость между исходными атрибутами и атрибутами-результатами. Для создания таблицы следует выполнить команду **Создать** для типа объектов **Таблицы экспертной системы**. Эта команда откроет окно параметров таблицы, изображенное на рисунке ниже параметры таблицы, впоследствии можно будет изменить в редакторе таблиц.

# Перечень корневых папок для хранения кэша
В области **Перечень корневых папок для хранения кэша** содержит список корневых папок для хранения кэша, а так же их статусы и параметры.
При добавлении корневой папки следует указать:
1\. Путь к корневому хранилищу.
2\. Максимальный размер, Гб (при необходимости).
3\. Макс. заполнение диска (% от свободного места).
**Внимание!** На каждом локальном диске может быть создана только одна корневая папка для хранения кэша.

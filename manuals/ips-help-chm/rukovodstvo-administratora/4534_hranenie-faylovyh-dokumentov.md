# Хранение файловых документов
Для хранения файловых документов и различных двоичных данных в IPS используются так называемые файловые шкафы. Под файловым шкафом подразумевается место, в котором система хранит тела файловых или двоичных атрибутов. Это может быть таблица базы данных либо каталог на диске сервера. При этом файловые шкафы могут располагаться на любых компьютерах локальной сети предприятия, что позволяет легко масштабировать систему. 
Хранение файлов в шкафах исключает возможность получения доступа к ним в обход системы. На диск компьютера попадают только те файлы, документы которых принимают статус рабочих копий. После завершения работы с ними, эти файлы с диска удаляются и остаются только в базе данных IPS.
По умолчанию в системе существует один файловый шкаф с именем DOCUMS. Таблица этого файлового шкафа размещается в той же базе данных, что и системные таблицы IPS. По мере роста количества документов в базе данных и постоянно растущих потребностей в дисковой памяти администратор системы имеет возможность создавать новые шкафы файлов. Создавать файловые шкафы можно как на сервере, на котором установлена система, так и на любом другом сервере в локальной сети предприятия. Размещение системной базы данных IPS и файловых шкафов на различных серверах позволит существенно повысить быстродействие системы в целом.
Управление файловыми шкафами осуществляется в окне **Администратор базы данных**. По умолчанию файловые шкафы и их содержимое доступны только администратору, однако он может назначать права доступа к файловым шкафам другим пользователям системы.
Узнать название шкафа, в котором хранится файл документа, можно в карточке документа на закладке **Файл** в списке свойств файла.
**Внимание!** **Файловые шкафы** — внутренний механизм, предназначенный только для обеспечения распределенного хранения больших массивов двоичных данных. Для обычных пользователей IPS не имеет значения, в каком шкафу хранится тот или иной файл документа.
Файловые шкафы одной БД, могут быть использованы только в рамках этой БД. Для использования файлового шкафа в другой БД наложен запрет в виде заполненного атрибута **Системная база данных** , который принадлежит объекту-описателю файлового шкафа. Если атрибут **Системная база данных** пустой или отсутствует, то он заполняется автоматически системой при загрузке сервера приложений. В дальнейшем, при попытке доступа к файловому шкафу, сверяется его содержимое со строкой подключения к системной БД. Если значения атрибута **Системная база данных** не совпадают, то система выдает сообщение об ошибке, доступ к данным блокируется.
Для избежания данной ошибки при копировании системной БД следует скопировать и все ее файловые шкафы, а затем в копии системной БД при первом запуске IPS необходимо очистить атрибут **Системная база данных** у всех объектов типа **Файловый шкаф** , если данный атрибут есть у этих объектов.
**Внимание!** После изменения значения атрибута **Системная база данных** необходимо перезапустить сервер приложений.

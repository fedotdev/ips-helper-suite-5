# Создание объекта интегратора c AutoDesk Inventor
Данный интегратор позволяет осуществить интеграцию системы IPS с системой **AutoDesk Inventor**. 
Откройте окно настройки инструментов, выберите страницу **Интеграторы с приложениями** и нажмите кнопку **Создать.** В появившемся окне укажите **интегратор с Autodesk Inventor** , затем нажмите кнопку **ОК**.

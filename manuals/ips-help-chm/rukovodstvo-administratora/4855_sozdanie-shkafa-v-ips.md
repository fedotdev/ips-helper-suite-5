# Создание шкафа в IPS
После того, как с помощью программы администрирования было создано корневое хранилище службы, можно создавать шкаф в IPS.
Создание файлового шкафа описано в п. . Ниже рассмотрим заполнение атрибутов специфичных для файловых шкафов, с которыми работает служба IPS.DVS.
· **Наименование.** Наименование файлового шкафа в IPS должно совпадать с именем папки, в которой расположено корневое хранилище. В одном корневом хранилище может располагаться только один файловый шкаф. При попытке повторно добавить шкаф в хранилище будет выдано сообщение об ошибке.
· **Строка подключения к базе данных.** Строка подключения имеет следующий формат:
server=<server>; port=<port>
− **server** – имя сервера, на котором установлена служба IPS.DVS;
− **port** – порт, на котором IPS.DVS будет выполнять прослушивание входящих соединений от клиентских приложений. 
· **Тип файлового шкафа**. Для работы со службой укажите тип файлового шкафа – **Intermech Document Server**. 
· **Пароль подключения к Data Vault Service.** Укажите пароль для работы со службой. По умолчанию при установке пароль для подключения к службе – **masterkey**. 
После создания шкафа в IPS в корневом хранилище будет создана структура рабочих файлов, необходимая для упорядоченного хранения и систематизации файлов. 
Для того, чтобы начать работу с созданным файловым шкафом, необходимо сделать шкаф активным. После чего все файлы будут помещаться в корневое хранилище.

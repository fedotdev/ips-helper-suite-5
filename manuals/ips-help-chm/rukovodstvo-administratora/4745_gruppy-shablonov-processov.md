# Группы шаблонов процессов
Для удобства работы с шаблонами их можно группировать по определенным признакам, создавая группы шаблонов процессов и помещая шаблоны процессов в эти группы. 
Группы шаблонов процессов можно создавать одним из способов общей схемы создания объектов:
· Выберите пункт главного меню **Файл/Создать/Новый объект** , в появившемся диалоге выберите тип объектов **Объекты маршрутизатора/Группы шаблонов процессов** и нажмите **Далее** ; в поле **Заголовок объекта** появившегося диалога введите название и нажмите **Готово**.
· Отметьте в дереве навигации тип объектов **Объекты маршрутизатора/Группы шаблонов процессов** и выберите команду **Создать** его контекстного меню. В поле **Заголовок объекта** появившегося диалога введите название группы и нажмите **Готово**.
Чтобы поместить шаблон процесса в группу шаблонов процессов выполните следующие действия: 
· Выделите в дереве навигации тип объектов **Объекты маршрутизатора/Шаблоны процессов** ;
· В рабочей области **Навигатора** выделите в списке шаблонов необходимый и примените команду его контекстного меню **Копировать** ;
· Перейдите в дереве навигации к типу объектов **Объекты маршрутизатора/Группы шаблонов процессов** ;
· В рабочей области **Навигатора** выделите в списке групп шаблонов процессов необходимую и с помощью ее контекстного меню примените команду **Вставить**.
Примечание: перемещение шаблона процесса в группу шаблонов реализуется посредством обычного перетаскивания (drag-and-drop) шаблона в редакторе шаблонов процессов.

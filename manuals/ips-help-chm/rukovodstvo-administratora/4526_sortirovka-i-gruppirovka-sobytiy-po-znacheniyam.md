# Сортировка и группировка событий по значениям
По умолчанию события в журнале упорядочены по времени их регистрации, т.е. более поздние события размещаются в списке выше, чем ранее зарегистрированные. Однако список событий можно отсортировать по любому параметру, щелкнув по заголовку колонки левой кнопкой мыши. 
**Внимание!** Так как не все колонки отображают значение, равное тому, что физически хранится в базе данных, то и сортировка не для всех колонок будет возможна. Сортировка данных происходит по тому, что хранится в ячейки колонки.
Примечание: щелкнув по заголовку колонки повторно, порядок сортировки будет изменен. 
Для группировки записей по значениям одной из возможных колонок следует:
1\. На главной панели закладки **События** нажать кнопку . 
2\. В появившуюся область следует перетянуть необходимый заголовок колонки.

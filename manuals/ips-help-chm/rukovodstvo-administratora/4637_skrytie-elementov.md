# Скрытие элементов
Система IPS предоставляет возможность временного скрытия элементов на страницах шаблона. Для этого в контекстном меню любого из типов элементов имеется команда **Скрыть** , при применении которой элемент становится невидимым. При этом свойство **Видимый** данного элемента на панели **Свойства** приобретает значение **Нет** , а на панели **Схема документа** такой элемент выделяется серым цветом. Чтобы сделать элемент видимым, необходимо отметить его на панели **Схема документа** и применить команду его контекстного меню **Показать** или перейти на панель **Свойства** и установить значение **Да** для свойства **Видимый**.

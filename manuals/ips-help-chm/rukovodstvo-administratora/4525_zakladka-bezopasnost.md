# Закладка Безопасность
Закладка **Безопасность** предоставляет возможность назначить права доступа к журналу событий. Пользователь с ролью **Администратор** обладает всеми правами, однако права можно расширить для любой роли и пользователя. Для этого следует:
1\. Добавить пользователя, группу пользователей или роль с помощью кнопки 
2\. В открывшемся диалоговом окне выбрать необходимый элемент, затем нажать кнопку .
3\. В поле отметить необходимые права, а затем нажать кнопку .

# Закладка Настройка регистрации событий
Запись событий отнимает значительные ресурсы серверов СУБД и приложений, при отсутствии необходимости регистрации событий, системой предусмотрена возможность отключения данной функции. Для этого необходимо снять флажок переключателя режима регистрации событий в строке **Регистрировать события**.
Примечание: по умолчанию флажок переключения режима регистрации событий включен.
Закладка **Настройка регистрации событий** имеет дополнительные элементы управления, посредством которых администратор имеет возможность настроить условия регистрации событий.
Примечание: при выключенной регистрации событий дополнительные настройки закладки **Настройка регистрации событий** недоступны.
Для того, чтобы добавить объекты (типы объектов), действия над которым совершаются, но в регистрации не нуждаются, следует:
1\. Отметить соответствующую группу в поле и нажать кнопку .
1\. В открывшемся диалоговом окне необходимо выбрать объект, а затем нажать кнопку .
**Внимание!** Процесс добавления типов объектов осуществляется так же, как и добавление конкретных объектов.
Объект или тип объекта можно удалить из списка, для этого следует:
1\. Выделить объект или тип объекта и нажать кнопку .
2\. В открывшемся диалоговом окне **Запрос** следует подтвердить удаление объекта.
Примечание: для повышения производительности системы IPS, рекомендуется отключить регистрацию событий, для тех типов объектов, которые не представляют информационной важности.
На закладке **Настройка регистрации событий** расположены параметры, описание которых представлено ниже:
· **Количество данных в оперативном журнале** – строка, на которой предоставляется возможность указать количество дней хранения данных в оперативной части журнала. Данные, старше указанного срока хранения, автоматически переносятся в архивную часть.
· **Количество данных в архивном журнале** – строка, на которой предоставляется возможность указать количество дней хранения данных в архивной части журнала. Данные, старше указанного срока хранения, переносятся либо в файловую часть журнала, либо удаляются.
· **Данные из архивного журнала** – строка с выпадающим списком, в котором можно выбрать, как поступить с данными архивного журнала после устаревания:
− **Архивировать** ;
− **Удалять**.

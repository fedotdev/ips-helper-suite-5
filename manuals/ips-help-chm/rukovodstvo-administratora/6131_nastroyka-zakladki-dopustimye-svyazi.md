# Настройка закладки Допустимые связи
Для корректной работы модуля **Интегратор с редакторами офисных документов** следует убедиться, что настроена связь **Объект, добавленный в состав по ссылке** в объектах типа **Документы**. Данную связь следует настроить в **Конфигураторе базы данных** на закладке **Допустимые связи.**
В приложении **Конфигуратор базы данных** необходимо выбрать объект типа **Документы**. В рабочей области выбрать закладку **Допустимые связи** и с помощью всплывающего окна выбрать связь **Объект, добавленный в состав по ссылке** **– Состоит из**. 
С помощью команды контекстного меню следует выбрать необходимые типы объектов. В открывшемся диалоговом окне следует выбрать необходимые типы объектов, а затем нажать кнопку .
Примечание: для работы модуля **Интегратор с редакторами офисных документов** необходимо добавить объекты типам **Документ,** **Изделие** и **Материал базовый**. 
Добавив необходимые объекты, дерево **Связи** и область отображения атрибутов будут иметь следующий вид.
**Внимание!** Параметры закладки **Допустимые связи** должна быть настроена для всех созданных типов документов, пользовательских в том числе.

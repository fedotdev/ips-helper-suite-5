# Настройка процесса отправки уведомления адресатам
Если пользователь упоминается в качестве адресата в канцелярском документе, система высылает ему сообщение на внутреннюю почту. Вместо простого сообщения можно использовать уведомление через бизнес-процесс. Для этого необходимо указать шаблон процесса в поле **Шаблон процесса для отправки уведомлений адресатам** в настройках канцелярии. Настройка осуществляется в настройках IPS: **Настройка / Параметры IPS** на закладке **Канцелярия / Общие**. Адресат будет указан в переменной ADDRESSEE, которая должна присутствовать среди переменных шаблона процесса.

# Настройка свойств интегратора c AutoCAD
Выберите конфигурационный объект **Интегратор с AutoCAD** и нажмите кнопку **Свойства**.
Рассмотрим подробнее настройки интегратора:
· **Параметры подключения к приложению**. Свойство позволяет задать нужные параметры подключения к AutoCAD в зависимости от роли пользователя. Нажатие на кнопку [**…**] открывает специальное окно:
Описание свойств, которые можно изменить в этом окне для каждой роли пользователя представлены ниже:
− **Роль пользователя.** Позволяет выбрать роль пользователя IPS, на которую будут распространяться данные настройки. Если значение не задано, то настройки будут применяться для всех ролей.
− **Релиз AutoCAD.** Интегратор будет использовать последний запущенный AutoCAD, совместимый с указанным в данном свойстве релизом.
− **Использовать профиль?** Значение Да использует параметр **Имя профиля** , включает указанный профиль при подключении к AutoCAD. Значение Нет означает, что интегратор не будет выполнять никаких действий по смене профиля в подключенном AutoCAD.
− **Имя профиля**. Имя профиля AutoCAD, который будет становиться активным при подключении к AutoCAD из IPS.
· **Конструкторская документация: Включить поддержку**. Включает и выключает поддержку конструкторских чертежей.
· **Сборочные чертежи**. Список типов информационных объектов IPS, используемых для представления чертежей сборочных единиц. Также содержит дополнительные параметры настройки для сканирования и обработки чертежей:
После выбора типа объектов можно нажать кнопку **Свойства** , чтобы указать параметны сканирования и обработки в специальном окне (для каждого типа чертежей – свои настройки):
· **Чертежи деталей**. Список типов информационных объектов IPS, используемых для представления чертежей деталей.
· **Проектная документация: Включить поддержку**. Включает и выключает поддержку СПДС- чертежей.
· **СПДС-чертежи**. Список типов информационных объектов IPS, используемых для представления чертежей СПДС.

# Настройка колонок
**Внимание!** Закладка **Настройка колонок** доступна только для пользователей, вошедших в систему IPS под ролью **Администратор**.
Закладка **Настройка колонок** предназначена для настройки отображения колонок каждой роли отдельно в объектах типа **Архивы документов**. Посредством элементов управления закладки создаются настройки в родительских архивах, которые унаследуются в дальнейшем дочерними.
Примечание: если дочернему архиву настроен персональный набор колонок для одной и тоже роли, что и у родительского, то настройки родительского архива учитываться не будут. 
**Внимание!** Следует понимать, что пользователь может настроить персональное отображение колонок для родительского или дочернего архивов с помощью команды **Настройка отображения…** , пользовательские настройки будут первичны для системы IPS и настройки, созданные администратором, учитываться не будут.

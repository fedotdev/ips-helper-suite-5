# Права доступа
Закладка **Безопасность** позволяет назначить пользователям права доступа к данной группе атрибутов. По умолчанию всем пользователям разрешен просмотр группы в списках, а остальные права даны только роли **Администратор**. Однако система позволяет изменять права доступа отдельным пользователям, группам пользователей или ролям, под которыми пользователи входят в систему. Система позволяет назначать следующие права доступа:
· **Просмотр группы в списке** — разрешает видеть данную группу в списке групп атрибутов (запрет на видимость группы не означает запрета на видимость атрибутов, которые включены в данную группу атрибутов).
· **Изменение свойств группы атрибутов** — разрешает изменять свойства группы атрибутов.
· **Добавление атрибутов в группу** — разрешает добавлять атрибуты в группу.
· **Исключение атрибутов из группы** — разрешает исключать атрибуты из группы.
· **Удаление группы атрибутов** — разрешает удалять группы атрибутов.
· **Просмотр прав доступа** — разрешает просматривать набор прав доступа к данной группе атрибутов.
· **Изменение прав доступа** — разрешает назначать права доступа на данную группу атрибутов.
**Внимание!** В системе IPS предоставлена возможность копировать права, при условии, что место, куда копируются выбранные права, может принимать такие права доступа.

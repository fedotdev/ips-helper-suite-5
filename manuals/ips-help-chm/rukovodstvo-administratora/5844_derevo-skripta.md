# Дерево скрипта
Для каждого элемента дерева скрипта можно ввести комментарий, описывающий, что должен делать этот оператор. Для ввода метки достаточно щелкнуть на соответствующем поле левой кнопкой мыши (см рисунок ниже). Метка также используется для временного отключения операторов: если первым символом метки является решетка (#), сервер экспертной системы считает этот оператор закомментированным и не будет выполнять ни его, ни вложенные в него операторы. Так на примере с рисунка ниже в скрипте не будут выполняться оператор поиска дочерних объектов **Для переходов на операции**.
Метка (!) служит для уменьшения объема выдаваемой информации в трассировке. Если в скрипте есть хотя бы один (!), то в окне трассировки будет выводиться информация только по тем веткам, в которых он есть, и по их дочерним. При этом выполняться оператор, помеченный (!) будет.
Команды контекстного меню дерева скрипта дублируют команды находящиеся в верхней части панели редактирования скрипта (см. п. ).
Команды контекстного меню **Свернуть все** / **Развернуть все** позволяют свернуть (развернуть) дерево скрипта.
Добавление элементов в дерево скрипта состоит из этапов:
1\. В дереве скрипта выделить нужный элемент, относительно которого будет выполнятся вставка нового элемента скрипта. Если добавляется первый элемент в скрипт, данный шаг можно пропустить.
2\. На панели редактирования скрипта выбрать нужный оператор и модификатор.
3\. При помощи команд панели редактирования **Вставить Перед** , **Вставить После** и **Вставить Внутрь** втравить элемент в дерево скрипта.
4\. Ввести **Комментарий** , описывающий, что должен делать этот оператор.
5\. Отредактировать параметры оператора и модификатора на панели параметров.
6\. Применить изменения нажав **Изменить параметры элемента** .
7\. После добавления всех необходимых операторов выполнить проверку скрипта командами **Проверка шаблона** и **Проверка ниже**(см. п. ).
8\. При необходимости установить **Параметры скрипта** (см. п. ).
9\. Сохранить скрипт командой **Сохранить** (см. п. ).

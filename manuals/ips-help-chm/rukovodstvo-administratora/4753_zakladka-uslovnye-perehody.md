# Закладка Условные переходы
Закладка **Условные переходы** применима только для действий типа **Выбор**. Она предназначена для отображения и редактирования условий переходов действия по определенным связям, в зависимости от вычисляемого выражения. 
В условных действиях реализован механизм, который по умолчанию рассчитывает условия без использования экспертной системы.
При включенном переключателе **Фильтровать вложенные объекты в зависимости от условий** механизм выполняет проверку в одном условии, как по атрибутам объекта, так и по переменным процесса. Кнопка **Изменить тип объекта** позволяет изменить тип объекта, который был выбран на этапе создания связи. 
Указанный тип объекта не участвует в фильтрации вложений, а определяет набор атрибутов, которые будут отображены для задания условия в редакторе. 
Примечание: если выбрать тип **Любой тип объекта** , то отображены будут все атрибуты.
Условия привязаны к связям, исходящим из действий **Выбор** , и могут задаваться как на этапе создания связи, так и на закладке **Условные переходы**.
Чтобы отредактировать условие, выполните следующие действия:
· Выделите условие двойным щелчком мыши на закладке и нажмите появившуюся при этом кнопку .
· Внесите необходимые изменения.
· Нажмите **ОК**.
Проверка выделенного выражения осуществляется с помощью кнопки **Вычислить выбранное выражение**. Выражения, не содержащие ошибок, помечаются в списке пиктограммой , некорректные выражения — пиктограммой .
Если в свойствах действия **Выбор** включен переключатель **Фильтровать вложенные объекты в зависимости от условий** , то будет производиться фильтрация: для каждого объекта из списка прикрепленных будет вычисляться условие каждой связи (в этом случае в условиях могут использоваться параметры объектов). По связям, для которых условия выполняются, будет передано выполнение и соответствующие вложения. Таким образом, список вложений может быть разделен так, что по одним веткам могут идти одни объекты, а по другим – другие.
Включение переключателя **Использовать формулы экспертной системы** позволяет использовать экспертную систему и ее редактор для задания условий перехода по связям
**Внимание!** Во избежание зависания процессов при использовании множественно-условных переходов всегда рекомендуется для одной из веток использовать условие ИНАЧЕ, чтобы эта ветка гарантированно выполнилась, если ни одно условие не выполняется.

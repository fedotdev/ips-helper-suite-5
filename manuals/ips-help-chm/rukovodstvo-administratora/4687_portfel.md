# Портфель
IPS позволяет выполнять перенос объектов, метаданных и прав доступа между базами данных IPS. В процессе работы модуля **Портфель** формируется портфель, который представляет собой совокупность папок и файлов формата xml, схем xsd к ним, а также файлов с двоичными данными (подробнее см. **гл. 8 Структура файлов портфеля в «Руководстве программиста»**). Портфель позволяет выполнять как перенос новой информации из одной базы данных IPS в другую, так и синхронизацию существующих данных. 
Для работы с модулем портфеля активный пользователь, группа или роль должны иметь соответствующие права на экспорт и/или импорт данных (см.п. ).

# Управление инструментами
Открыть настройку инструментов можно с помощью команды главного меню **Настройка/Настройка инструментов** :
Настройка инструментов реализована в виде отдельного диалогового окна:
Редактор позволяет осуществлять настройку следующих элементов службы инструментов:
· **Команды запуска приложений** – создание/изменение/удаление команд запуска внешних приложений для объектов различных типов.
· **Интеграторы с приложениями** – создание/изменение/удаление интеграторов с приложениями.
· **Безопасность** – назначение прав доступа пользователям для их работы со службой инструментов.
· **Просмотр и печать файлов** – позволяет определить состав сведений, записываемых в файлы объектов перед просмотром и печатью объектов.
Рассмотрим подробно работу на каждой странице настройки инструментов.

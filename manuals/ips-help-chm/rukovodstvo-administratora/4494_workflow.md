# Workflow
Примечание: данные настройки будут доступны в том случае, если загружен модуль расширения **Документооборот**.
Для настройки группы необходимо выбрать команду **Параметры IPS** из меню **Настройка** панели инструментов системы IPS. В открывшемся окне выбрать группу**Workflow** из пункта**Система**.
Настройки группы осуществляются с помощью следующих параметров:
· **Администратор workflow**. Данный параметр дает возможность выбрать пользователя, который будет получать сообщения об ошибках при выполнении процессов **Workflow**.
Примечание: параметр **Администратор workflow** работает только в паре с параметром **Уведомлять администратора об ошибках в процессах** при условии, что его режим включен. (описание параметра **Уведомлять администратора об ошибках в процессах** см. ниже).
· **Использовать дополнительные вложения**. Параметр позволяет активировать возможность отправлять по БП дополнительные вложения, на которые не распространяются правила, действующие для основных вложений. Включенная настройка добавляет закладку **Дополнительные вложения** в приложении Почта и при запуске БП.
· **Календарь для вычисления сроков.** Этот параметр дает возможность пользователю контролировать бизнес-процесс в срок. При включенном режиме **Стандартный календарь** запускается автоматическая связь модуля **Документооборот** с **Таймером** (подробное описание **Таймера** в разделе **Модуль документооборота**). Для отключения режима **Стандартный календарь** следует его выделить и нажать клавишу **[Delete]**.
· **Максимальное количество действий без исполнителя подряд.** Данный параметр задаёт возможное количество действий без исполнителя при выполнении процесса. Допустимый диапазон изменения от 10 до 150 действий.
· **Не копировать в коллекторы пустые значения переменных**. Данный параметр позволяет пропускать пустые значения переменных при передаче значений их в коллекторы, которые ожидают выполнения предыдущих действий.
· **Не проверять скрытые объекты в составе извещений.** При включенной настройки подписи для скрытых документов извещения не проверяются.
· **Проверять права у владельца процесса**. Включение данного параметра позволяет расширить действие проверки прав администрирования процесса и на владельца процесса. 
Если параметр **Проверять права у владельца процесса** включен и у владельца процесса отсутствуют необходимые права, то ему будет запрещено выполнять административные действия над процессом (такие как прерывать, отзывать, заменять исполнителей). В противном случае владелец процесса по умолчанию считается его администратором.
· **Рассылать уведомления о новой почте по email.** Данный параметр позволяет дублировать на личный email пользователей уведомления, поступившие на почту IPS. 
**Внимание!** Включение данного режима может привести к замедлению работы программы.
· **Рассылать уведомления о новой почте по email для исполняющего обязанности**. Данный параметр позволяет включить или выключить опцию рассылки уведомления о задаче по email исполняющему обязанности исполнителя действия.
**Внимание**! Параметр **Рассылать уведомления о новой почте по email для исполняющего обязанности** действует только в паре с параметром**Рассылать уведомления о новой почте по email.**
· **Уведомлять администратора об ошибках в процессах**. Этот параметр дает возможность отправлять администратору Workflow уведомления о возникших ошибках в процессе **Workflow**.
· **Уведомлять о невозможности назначить временные права на вложения.** Данный параметр сообщает пользователю о том, что у него недостаточно прав доступа для назначения временных рамок.
· **Удалять вместе с процессом объекты типа «Ссылка на файл»**. Включение данного параметра позволяет удалять объекты типа **Ссылка на файл** , связанные с процессом маршрутизатора, при условии, что эти объекты используются только во вложениях данном процессе.
· **Удалять задачи из почты после выполнения процесса**. Данный параметр автоматически удаляет все задачи, относящиеся к процессу **Workflow** , из папок **Исходящие** и **Выполненные** почты пользователя. Сообщения удаляются сразу после выполнения данных задач.
· **Удалять задачи из почты после прерывания процесса**. Данный параметр действует аналогично параметру **Удалять задачи из почты после выполнения процесса** , однако, сообщения удаляются при прерывании процесса.

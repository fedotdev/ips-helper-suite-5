# Страницы редактора шаблона документов
Каждый новый шаблон документов по умолчанию имеет одну страницу формата **А4** (297*210 мм) без элементов. Пользователь может заполнять страницы элементами, создавать многостраничные шаблоны документов, добавляя и изменяя параметры страниц. Страницы шаблона отображаются в виде закладок с их номерами в левой нижней части редактора. Для перехода от одной страницы на другую достаточно щелкнуть левой кнопкой мыши по закладке с номером страницы или воспользоваться командами главного меню **Страница/Перейти к предыдущей странице** и **Страница/Перейти к следующей странице**.

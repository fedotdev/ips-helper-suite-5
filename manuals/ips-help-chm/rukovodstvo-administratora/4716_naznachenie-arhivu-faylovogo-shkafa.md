# Назначение архиву файлового шкафа
При необходимости архиву можно назначить файловый шкаф (см. п. ), в который будут автоматически перемещаться файлы документов, размещаемых в данном архиве. Для этого нужно добавить объекту архива атрибут **Файловый шкаф** , как показано на рисунке ниже. Действие атрибута не распространяется на дочерние архивы – для них файловый шкаф нужно задавать отдельно.
Для проверки размещения файлов и двоичных данных архива в назначенном файловом шкафу предназначена команда контекстного меню **Проверить размещение файлов в шкафу**. Данная команда выдает список документов архива, у которых файловые или двоичные атрибуты (версий документов или их итераций) размещены не в том файловом шкафу, который указан у данного архива в атрибуте **Файловый шкаф**.

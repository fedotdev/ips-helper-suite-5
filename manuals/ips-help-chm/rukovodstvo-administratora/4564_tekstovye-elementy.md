# Текстовые элементы
· **Надпись**. Используется для отображения пояснительной информации к тому или иному полю формы.
· **Надпись с атрибутом**. Метка для отображения значения атрибута.
· **Текстовое поле**. Служит для отображения пояснительной информации к тому или иному полю формы. Может использоваться также для вывода значения заданного параметра без возможности его редактирования.
· **Текстовое поле с маской**. Применяет маску, чтобы отличить допустимые данные, вводимые пользователем, от недопустимых.
· **Многострочное поле**. Позволяет работать с параметрами, имеющими значение из нескольких строк. 
· **Пароль**. Поле предназначено для ввода пароля для доступа к объекту.
· **Ссылка на объект**. Компонент для отображения атрибута типа **Ссылка на версию объекта**.
· **Ссылка на объект справочника IMBASE**. позволяет выбрать значение из справочника IMBASE.
· **Число в единицах измерения**. Позволяет ввести число с единицей измерения, которую можно выбрать из списка единиц измерения, существующих в системе.
· **Комментарии**. Позволяет ввести текстовое сообщение в поле для ввода, при нажатии на кнопку **Применить** появляется поле с выводом текста в формате отображение – ФИО автора, дата и время создания сообщения. При нажатии на кнопку **Отмена** – поле для ввода текста очищается. 
Отосланные сообщения можно удалить и изменить посредством кнопок **Удалить** и **Изменить**. 
**Внимание!** При условии, что у объект есть уже существующее текстовое описание, созданные данные переносятся в компонент **Комментарии** в поле для вывода сообщения в формате отображения «сплошным» текстом, без ФИО автора, даты и времени. Перенесенные комментарии могут быть отредактированы любым пользователем системы IPS. 
**Внимание!** Для того чтобы воспользоваться командами контекстного меню **Вставить ссылку на файл** и **Вставить картинку из буфера** следует установить значение **Разрешить** для свойства **Выделение ссылок** в редакторе форм.

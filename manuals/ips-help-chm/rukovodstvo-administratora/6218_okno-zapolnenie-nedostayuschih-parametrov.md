# Окно заполнение недостающих параметров
Окно **Заполнение недостающих параметров** будет появляется всякий раз, когда в расчете будут присутствовать атрибуты, значения которых не определены. В данном окне пользователь может заполнить значения недостающих параметров вручную или выбрать из справочника или таблицы. Для показа данного диалога в параметрах IPS должны быть включены соответствующие настройки см. п. . 
Окно **Заполнение недостающих параметров** показано на рисунке ниже.
В верхней части окна указаны атрибуты, значения которых не определены и объекты, для которых данные атрибуты назначены. В том случае если имеется возможность выбора значения атрибута из справочника или таблицы в соответствующем столбце напротив данного атрибута будет стоять \*\*\*\*\*\*\*.
В столбце **Значение** записываются значения атрибутов после их выбора из справочника/таблицы или ручного ввода.
В нижней части окна располагаются кнопки:
· **Выбрать из 0 справочников и пересчитать** — открывает диалог выбора из справочника, после выбора значения будет автоматически произведён перерасчет с использованием выбранного значения из справочника. 
· **Справочник** — позволяет выбрать недостающее значение из справочника. Кнопка доступна для полей, отмеченных \*\*\*\*\*\*\* в столбце **Справочник**.
· **Таблица** — позволяет выбрать недостающее значение из таблицы. Кнопка доступна для полей, отмеченных \*\*\*\*\*\*\* в столбце **Таблица**.
· **Ручной ввод** — кнопка позволяет открыть диалог для ручного ввода недостающих значений атрибутов.
· **Считать заново с заполненными атрибутами** — позволяет запустить расчет атрибутов заново с использованием введенных значений. 
· **Отмена** — закрывает окно **Заполнение недостающих параметров**.

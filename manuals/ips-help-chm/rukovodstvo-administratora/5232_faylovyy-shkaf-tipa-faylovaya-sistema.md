# Файловый шкаф типа Файловая система
Данный тип файлового шкафа позволяет хранить файлы и двоичные данные в каталоге файловой системы. Каталог должен быть доступен на запись и чтение всем серверам приложений IPS, которые могут обращаться за файлами и двоичными данными, расположенными в этом файловом шкафу. При этом не рекомендуется давать доступ к этому каталогу клиентским компьютерам. Если все клиенты IPS работают только с одним сервером приложений, то каталог может быть создан на том же физическом или виртуальном сервере и может быть не доступен в сети другим рабочим станциям и серверам.
В корне каталога система создает двухуровневую структуру подкаталогов, в которых располагаются файлы данных IPS. Имена файлов соответствуют их внутренним идентификаторам в таблице файлового шкафа. В подкаталоге TempDir размещаются временные файлы транзакций, которые не рекомендуется удалять вручную. Чисткой данного каталога занимается процедура удаления устаревших данных IPS. Также в корне каталога размещаются лог-файлы серверов приложений, которые работают с данным файловым шкафом. Имя каждого лог-файла содержат имя сервера приложений и порт, на котором он обслуживает запросы клиентских приложений IPS.
**Внимание!** Перед созданием файлового шкафа его каталог уже должен быть создан, и он не должен содержать каких-либо файлов и подкаталогов. Страховое копирование данного каталога должно осуществляться одновременно со страховым копированием системной базы данных IPS.
Примечание: в связи с тем, что работа с файловыми шкафами данного типа может приводить к размещению файловых данных в сетевых каталогах, доступ к которым сервер IPS проконтролировать не сможет, файловые шкафы данного типа можно создавать только после вписания определенного параметра в конфигурационный файл сервера приложений. Для получения этого параметра нужно обратиться в техническую поддержку компании Интермех, где можно получить дополнительные разъяснения по работе файловых шкафов данного типа.

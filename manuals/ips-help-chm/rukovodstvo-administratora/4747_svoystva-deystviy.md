# Свойства действий
Каждое действие редактора наделено набором свойств, которые задаются дизайнером для удовлетворения требованиям пользователей и корректной работы процесса. Вызвать диалоговое окно свойств любого из действий можно с помощью пункта его контекстного меню **Свойства** или двойным щелчком мыши по пиктограмме действия.
Диалоговые окна свойств действий представлены закладками, набор которых зависит от типа действия. В зависимости от того, в каком режиме открыт процесс или шаблон процесса, данный диалог позволяет просматривать или редактировать свойства.

# Блокирование настроек пользователя
Администратор имеет возможность заблокировать некоторые настройки для пользователей, входящих в систему под определённой ролью. Каждая роль имеет для этих целей несколько атрибутов:
Атрибут **Блокирование загрузки модулей** **расширения** по умолчанию имеет значение **Нет**. При включенном атрибуте **Блокирование загрузки модулей** **расширения** скрывается команда **Загрузить модуль расширения** в интерфейсе клиента IPS. Это можно использовать для того, чтобы пользователи не могли использовать команду **Загрузить модуль расширения** под определенной ролью, например, при ограниченном количестве лицензий.
Атрибут **Блокирование настройки видимости закладок** позволяет запретить пользователям настраивать отображаемые закладки. Список видимых и скрытых закладок будет взят у текущей роли во время подключения пользователя в систему.
Атрибут **Блокирование настройки контекстных меню** по аналогии с предыдущим атрибутом позволяет блокировать редактор контекстных меню, а также выполняет замену настроек пользователя на настройки роли по командам и группам контекстных меню.
Атрибут **Блокирование настройки отображения составов** запрещает клиентской программе сохранять изменения в настройках отображения (колонки **Навигатора**) для объектов, содержащих состав. Для таких объектов администратор может настроить списки колонок в редакторе **Отображение и сортировка составов** (см. п. ). Исключение составляют объекты выборок и классификаторов. Для всех остальных типов узлов **Навигатора** настройки отображения будут сохраняться и восстанавливаться при работе клиентской программы.
Атрибут **Блокирование панелей инструментов составов** может запретить пользователям скрывать панели, отвечающие за фильтрацию составов, а именно **Текущий контекст редактирования, Текущий проект** и **Фильтрация состава**.

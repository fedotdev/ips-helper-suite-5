# Подготовка производства
Примечание: данные настройки будут доступны в том случае, если загружен модуль расширения **Модуль настроек подготовки производства Intermech.MRP.Administrator**.
Для настройки модуля необходимо вызвать команду **Параметры** из меню **Настройка** панели инструментов системы IPS. В открывшемся окне выбрать группу **Подготовка производства (MRP)** из пункта **Система**.
**Внимание!** Данные настройки являются глобальными для всей базы данных. Изменения будут распространяться только на новые производственные заказы. В старые производственные заказы изменения вноситься не будут. Настройки модуля проводятся только администратором системы.
Настройки группы осуществляются с помощью следующих параметров:
· **Учитывать контекст состава.** Данный параметр позволяет добавлять в состав заказа записи с указанными значениями контекстов состава. Выключенный параметр в состав заказа добавляет объекты из **Общего** и **Производственного** контекстов.
· **Выбрать заменители.** Данный параметр позволяет указать определенный аналог для каждого случая допустимых замен (в трассировке состава показывает позиции, содержащие допустимые замены).
· **Включать в состав производственных заказов документацию.** Данный параметр добавляет связи с версиями документации в состав экземпляров и партий. 
· **Включать в производственные заказы составы покупных изделий**. Данный параметр позволяет отображать состав покупных изделий в производственных заказах.

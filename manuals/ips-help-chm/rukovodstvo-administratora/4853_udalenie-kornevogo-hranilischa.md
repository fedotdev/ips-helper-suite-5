# Удаление корневого хранилища
Для того, чтобы удалить корневое хранилище, необходимо выделить хранилище в дереве и нажать кнопку и подтвердить свои действия.
**Внимание!** Корневое хранилище будет удалено, только если в нём нет рабочих файлов.

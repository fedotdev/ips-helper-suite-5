# Создание объекта интегратора c редактором документов
Данный интегратор позволяет осуществить интеграцию системы IPS с редактором документов.
Откройте окно настройки инструментов, выберите страницу **Интеграторы с приложениями** и нажмите кнопку **Создать**. В появившемся окне укажите интегратор с редактором документов, затем нажмите кнопку **ОК**.

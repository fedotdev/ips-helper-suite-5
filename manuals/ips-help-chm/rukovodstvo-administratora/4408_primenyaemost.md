# Применяемость
Применяемость атрибута в типах объектов можно увидеть на закладке **Назначен типам объектов** , где в виде таблицы представлен список типов объектов, которым назначен данный атрибут. В таблице представлены все свойства типов объектов в режиме просмотра с возможностью отсортировать список по значению одной из колонок. В колонке **Наследование** указан способ наследования атрибута применительно к данному типу объектов. Список можно также сгруппировать по значениям любого из свойств типов объектов. Для этого нужно перетянуть заголовок колонки левой кнопкой мыши в специальную область к фразе **Перетащите заголовок колонки в эту область для группировки по значениям этой колонки**. 
Выделив двойным щелчком мыши одну из строк списка, можно перейти в режим редактирования атрибута для данного типа объектов.
Применяемость атрибута в типах связей можно увидеть на закладке **Назначен типам связей** , где в виде таблицы представлен список типов связей, которым назначен данный атрибут.

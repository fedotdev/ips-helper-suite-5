# Создание полилиний
Для того чтобы нанести на страницу полилинию, необходимо выполнить следующие действия:
· Выберите на панели инструмент **Полилиния**.
· Подведите указатель мыши к тому месту на странице, где должна будет располагаться начальная точка полилинии, и нажмите левую кнопку мыши.
· Переместите указатель мыши к следующей точке. При этом за указателем будет «тянуться хвост», изображающий отрезок полилинии. 
· Нажмите левую кнопку мыши, чтобы зафиксировать отрезок. 
· Перемещайте указатель столько раз, сколько граней должно быть у создаваемой фигуры. 
· Чтобы завершить нанесение полилинии, нажмите правую кнопку мыши и выберите одну из команд появившегося меню.

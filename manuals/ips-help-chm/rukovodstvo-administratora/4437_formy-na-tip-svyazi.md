# Формы на тип связи
Для любого из типа связей можно создать форму, которая будет отображаться в карточке объекта в виде отдельной закладки. Создание форм осуществляется в специальном редакторе, описание которого можно найти в п. . 
Назначить форму создаваемому типу связей можно на закладке **Формы на тип связи** , применив команду **Добавить форму** контекстного меню рабочей области. В появившемся диалоге необходимо выбрать форму и нажать **ОК**. С помощью команд контекстного меню можно просмотреть или редактировать назначенную форму в редакторе форм. Чтобы удалить форму, нужно применить команду ее контекстного меню **Удалить форму**. Команда **Условие** позволяет вызвать редактор, в котором можно задать условие, при выполнении которого будет отображаться форма.

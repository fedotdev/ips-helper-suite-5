# Изменение размера тома
Файлы в корневом хранилище располагаются в томах (см. п. ). Для изменения размера тома выберите свойство **Максимальный размер тома**. В выпадающем списке выберите одно из предложенных значений или введите своё значение.
При изменении размера тома, если единицы измерения не указаны явно, считается, что размер тома задан в байтах. 
Созданные изменения начнут действовать только для новых томов.

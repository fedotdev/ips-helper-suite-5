# Свойства
На рабочей области конфигуратора находится закладка **Свойства** , с помощью которой можно задать или изменить свойства необходимого атрибута, предварительно выделив его в дереве метаданных. В закладке**Свойства** имеется реестр задаваемых или изменяемых свойств атрибута:
· **Атрибут** -**источник**. Позволяет указать атрибут, из которого данный атрибут будет выбирать значение при присвоении мастер-атрибуту ссылки на объект. Если атрибут-источник не указан, то в качестве источника будет использован атрибут ссылочного объекта с таким же идентификатором, как у данного атрибута.
· **Включать атрибут в общий поисковый индекс.** Указывает системе на необходимость включения значений атрибута в общий поисковый индекс (см. п. ). После включения опции объекты, содержащие данный атрибут, будут помещены в очередь на индексацию.
· **Влияет на дату модификации содержимого объекта**. Это свойство можно задать, если информационному объекту назначен атрибут **Дата модификации содержимого объекта**. В таком случае, при включении этого свойства, изменение значения данного атрибута изменит и значение даты модификации содержимого объекта.
· **Возможна модификация без взятия на изменение**. Данное свойство позволяет модифицировать значение атрибута без взятия на изменение объекта, которому принадлежит атрибут, независимо от запретов на действия над объектами данного типа, установленных в их схемах жизненных циклов. 
· **Вызывать расшифровку значений**. Включает режим вызова службы для текстовой расшифровки значения атрибута в момент получения значения атрибута (см. ). Свойство действует только для строковых и текстовых атрибутов.
· **Выполнять обновление атрибутов, полученных от мастер-атрибута.** Параметр, включение которого позволяет проверить и обновить значения атрибутов, если они получены от объекта, на который ссылается мастер-атрибут. Параметр **Выполнять обновление атрибутов, полученных от мастер-атрибута** сработает только при условии если атрибут не влияет на дату модификации содержимого объекта и для него включен параметр **Возможна модификация без взятия на изменение**. Для автоматического обновления значений атрибута следует назначить задачу **Обновление значений атрибутов, полученных по ссылкам мастер-атрибутов** в планировщике задач. Подробнее описание работы с планировщиком представлены в п. .
· **Вычисление**. Способ вычисления значения атрибута (вычисляемыми могут быть только атрибуты простых типов — строковые, числовые и даты): 
− **Атрибут вычисляется в момент изменения данных**. Значение атрибута вычисляется в момент изменения значений атрибутов, участвующих в формуле вычисления значения данного атрибута. Поскольку вычисленное таким образом значение хранится в базе данных, то этот способ вычисления не снижает скорости чтения значений атрибута, а также позволяет производить поиск информации по вычисленным значениям.
− **Атрибут вычисляется в момент чтения данных**. Данный тип вычисления значений более не поддерживается системой. Вместо него используйте вычисление в момент изменения данных.
− **Невычисляемый атрибут**. Значение атрибута хранится в базе данных и не зависит от значений других атрибутов объекта.
− **Нормализованный индекс**. Переводит значение атрибута в нормализованный вид. Такие атрибуты вычисляют и хранят информацию в специальном формате, позволяющем учитывать типовые ошибки, которые совершают пользователи при вводе строковых значений атрибутов объектов (различное количество пробелов, разный регистр букв, ввод латинских символов вместо кириллицы и т.п.). Например, при поиске строки «ГОСТ 2503-90» будут также найдены строки, в которых по ошибке ввели латинские символы «О», «С» или «Т», либо вместо одного пробела ввели два (или записали строку вообще без пробелов). Нормализованные индексы не видны в карточках и списках информационных объектов, однако их можно использовать в условиях выборок для поиска информации.
· **Глобальный идентификатор атрибута**. Уникальный глобальный идентификатор атрибута.
· **Допустимые значения**. Список допустимых значений, которые может принимать атрибут. Это свойство становится доступным, если в свойстве **Список** выбрано значение **Атрибут может содержать множество значений из списка разрешенных значений** или **Атрибут может содержать одно значение из списка разрешенных значений**. Список допустимых значений настраивается в специальном диалоге, который вызывается с помощью кнопки , расположенной напротив поля **Допустимые значения**. 
Чтобы добавить значение в список следует:
1\. Заполнить поле **Значение:**.
2\. Заполнить поле **Описание:**.
3\. При необходимости добавить иконку нажав кнопку **Выбрать изображение** , а затем нажать кнопку . 
4\. С помощи кнопки **Очистить изображение** можно очистить область с иконкой-пиктограммой.
5\. Для сохранения допустимых значений следует нажать кнопку .
**Внимание!** Допустимый размер иконки 32x16, 16x16 и 32x32 пикселей. 
Примечание: иконки будут отображаться в дереве составов слева от значения атрибута.
· **Запрет редактирования вручную**. Позволяет запретить пользователю редактировать значение атрибута.
· **Запретить ввод пустых значений**. Позволяет запретить присвоение атрибуту пустых значений.
· **Значение по умолчанию**. Позволяет указать значение атрибута, которое будет присваиваться ему по умолчанию.
· **Идентификатор**. Локальный идентификатор атрибута. Назначается системой автоматически и не подлежит дальнейшей модификации.
· **Используется для хранения системной информации**. Позволяет указать, что данный атрибут должен быть скрыт от пользователей, так как он используется для хранения системной информации.
· **Комментарий**. Позволяет ввести комментарий для данного атрибута, поясняющий его назначение. Пользователь сможет увидеть данный комментарий в карточке объекта, выделив атрибут в списке атрибутов объекта или связи на закладке **Свойства** или **Свойства связей**.
· **Краткое наименование**. Краткое наименование данного атрибута (до 32 символов). Может содержать пустые и неуникальные значения. Используется для отображения в таблицах с различной справочной информацией, упрощенного отображения формул в экспертной системе и т.д.
· **Локальный атрибут IMBASE**. Флаг автоматически включается у атрибутов, которые были мигрированы из базы данных IMBASE и используются только в его таблицах. Такие атрибуты фильтруются в списках атрибутов IPS, если не включен режим отображения всех атрибутов.
· **Маска ввода**. Маска ввода значения атрибута (см. ). Применяется при вводе значений строковых атрибутов, а так же для атрибутов типа **Дата**. При добавлении значения **Дата** , атрибут будет выведен в краткой форме даты без времени.
· **Мастер-атрибут**. Позволяет выбрать ссылку на объект, атрибут которого (атрибут-источник) будет являться источником значений для подчиненного атрибута объекта, содержащего мастер-атрибут (соответственно мастер-атрибутами могут быть только атрибуты ссылочного типа данных). Присвоение значений подчиненным атрибутам происходит в момент присвоения значения мастер-атрибуту, но в дальнейшем значения подчиненных атрибутов могут быть изменены пользователем — система не производит постоянной синхронизации этих значений со значениями атрибутов в ссылочном объекте.
· **Наименование**. Позволяет ввести уникальное наименование атрибута (до 255 символов).
· **Не разбивать значения атрибута на слова при индексации**. Опция доступна для атрибутов с включенным флагом **Включать атрибут в общий поисковый индекс**. При индексации атрибута с такой опцией система помещает его значение в индекс целиком, не разбивая на слова и не пытаясь найти общие словоформы. Опция обычно применяется для строковых атрибутов, содержащих какие-либо коды, обозначения и пр.
· **Запрет копирования значения у версии.** Запрещает брать значение данного атрибута у исходной версии объекта при создании новой версии данного объекта.
· **Запрет копирования значений у прототипа**. Запрещает копировать значение данного атрибута у исходного объекта-прототипа при создании нового объекта на его основе. 
· **Запрет копирования значения у прототипа для исполнения**. Запрещает копировать значение данного атрибута у исходного объекта-прототипа при создании нового исполнения группового изделия на его основе. Данное свойство доступно в контексте типов объектов, для которых предполагается выпуск исполнений, например, для объектов типа **Сборочные единицы**.
· **Копировать значение дочернему объекту.** Включенное свойство атрибута позволяет системе проверять включен ли флажок свойства **Копировать атрибуты в дочерний объект** при создании дочернего объекта в составе родительского с соответствующим типом связи. Атрибуты копируются в те дочерние объекты, у родителей которых включен флаг **Копировать атрибуты в дочерний объект** , а также которым можно добавлять атрибут в соответствии с его типом. 
· **Оптимизация операций**. Задает способ оптимизации операций с атрибутом при работе со списком всех объектов системы:
− **Запись атрибута**. Оптимизация операций записи значений в атрибут. (Рекомендуемое значение для любых атрибутов в глобальном списке атрибутов).
− **Сортировка и поиск по атрибуту**. Оптимизация операций поиска и сортировки значений атрибута при просмотре списка объектов всех типов в табличном виде. 
− **Чтение атрибута**. Оптимизация чтения значений атрибута при просмотре списка объектов всех типов в табличном виде.
**Внимание**! Если при запросе на атрибуте не стоит оптимизация по чтению, то запрос может не открытся, а система выдаст сообщение об ошибке:
**Условие «Не содержит атрибут или значение» для атрибута «Литера» не может быть применено, т.к. у рассматриваемого списка атрибутов не установлена оптимизация на чтение или на поиск значений этого атрибута.**
**Внимание!** Не рекомендуется использовать оптимизацию атрибутов на чтение, сортировку и поиск в глобальном списке атрибутов без согласования со службой технической поддержки компании «ИНТЕРМЕХ», во избежание негативного влияния данных установок на производительность системы в целом. Система IPS располагает специальным сервисом, позволяющим собирать статистику работы с атрибутами и выдавать рекомендации по оптимизации системы (см. п. \*\*\*\*\*\*\*\*\*\*\*\*).
· **Предметная область**. Позволяет отметить в выпадающем списке предметные области, к которым относится атрибут. Если указано значение **Все** , то данный атрибут будет виден всем пользователям, независимо от предметных областей, с которыми они работают.
· **Псевдоним**. Позволяет ввести альтернативное уникальное наименование атрибута (используется модулями расширения системы).
· **Размер**. Определяет максимальное количество символов, которое пользователь сможет ввести в значение данного атрибута (активно только для таких типов атрибутов, как строка, текст, пароль и короткие двоичные данные).
· **Расширенная проверка прав доступа**. Данный режим дает возможность при назначении прав доступа к атрибуту использовать системные группы (например, ВЛАДЕЛЕЦ_ОБЪЕКТА или СОЗДАТЕЛЬ_ОБЪЕКТА). По-умолчанию режим выключен, т.к. вычисление принадлежности пользователя к системным группам не позволяет кэшировать результат проверки прав, что может значительно замедлить многие операции, связанные с проверкой прав доступа к атрибутам.
· **Регистрировать запись атрибута в журнале**. Включает режим записи в системный журнал регистрации событий (см. п. ) информации обо всех модификациях значений данного атрибута.
· **Содержит ссылку на запись таблицы IMBASE**. Флаг указывает системе на то, что данный атрибут используется для хранения ссылок на записи таблицы IMBASE. Доступен только для строковых атрибутов.
· **Сохранять общую историю значений**. Включает режим записи общей истории изменения значений атрибута. Эти значения отображаются и видны пользователям в специальном диалоге **История значений атрибута** при просмотре данного атрибута в свойствах объекта.
· **Сохранять персональную историю значений**. Включает режим записи персональной истории изменения значений атрибута. Эти значения отображаются и видны пользователю в специальном диалоге **История значений атрибута** при просмотре данного атрибута в свойствах объекта. Пользователи смогут удалять из базы данных свою историю изменения значений атрибута, однако, удаляемая пользователями персональная история сохраняется в базе данных для просмотра общей истории изменения значений атрибута (при включенном свойстве **Сохранять общую историю значений**).
· **Список**. Позволяет определить режим работы со списковыми параметрами:
− **Атрибут может содержать множество значений**. Позволяет присвоить атрибуту сразу несколько значений (количество значений системой не ограничено).
− **Атрибут может содержать множество значений из списка разрешенных значений**. Позволяет присвоить атрибуту сразу несколько значений из списка разрешенных значений, набор которых указывается в свойстве атрибута **Допустимые значения**.
− **Атрибут может содержать одно значение**. Атрибут может содержать только одно значение.
− **Атрибут может содержать одно значение из списка разрешенных значений**. Атрибут может содержать только одно значение из списка разрешенных значений, набор которых указывается в свойстве атрибута **Допустимые значения**.
· **Тип**. Определяет тип данных атрибута (список допустимых типов см. )
· **Уникальность**. Метод контроля уникальности значений атрибута (имеет смысл только для атрибутов информационных объектов):
− **Контролировать уникальность среди всех объектов**. Данный режим позволяет контролировать уникальность значения атрибута среди объектов всех глобальных типов, при этом версии одного объекта могут иметь одинаковые значения атрибута.
− **Контролировать уникальность среди всех объектов и их версий**. Не позволяет присваивать значение атрибуту, если в системе уже есть объекты или версии объектов с таким значением этого атрибута.
− **Контролировать уникальность среди объектов данного типа**. Не позволяет присваивать значение атрибуту, если в системе уже есть объект данного типа с таким значением этого атрибута.
− **Контролировать уникальность среди объектов данного типа и версий данного объекта**. Не позволяет присваивать значение атрибуту, если в системе уже есть объект или версия объекта данного типа с таким значением этого атрибута.
− **Не контролировать уникальность**. Позволяет присваивать неуникальное значение атрибуту, независимо от существования в базе данных объектов с таким значением этого атрибута.
· **Уровень продвижения**. Позволяет указать уровень продвижения объекта, на котором может существовать данный атрибут.
· **Формула**. Позволяет вписать формулу вычисления значения атрибута, задаваемую для вычисляемых атрибутов.
· **Языковой вариант**. Языковой вариант, к которому относится данный атрибут. Позволяет выбрать языковой вариант, существующий в системе, или указать язык по умолчанию, т.е. тот, который назначен по умолчанию в свойствах языковых вариантов.

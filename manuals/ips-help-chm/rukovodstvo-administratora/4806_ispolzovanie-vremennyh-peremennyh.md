# Использование временных переменных
Экспертная система не позволяет напрямую запускать расчет по формулам и таблицам. Если нужно все-таки это сделать, следует ввести в систему временный атрибут, который будет результатом формулы или таблицы, а потом запросить значение этого временного атрибута явно либо в составе другого объекта экспертной системы. Временные атрибуты не записываются в базу данных и существуют только в контексте текущей задачи экспертной системы. 
В IPS очень просто определить, является ли атрибут временным: временные атрибуты должны принадлежать одной из двух групп атрибутов:
· **Временные атрибуты объектов**. Эти атрибуты связаны с каким-либо объектом. Обычно имеются в виду атрибуты текущего объекта контекста. Если задан тип объекта, и при этом тип объекта контекста не совпадает с заданным, экспертная система попытается найти объект с помощью правил поиска объектов.
· **Временные атрибуты без объектов**. Это обычные временные переменные, не привязанные ни к каким объектам. Например, на рисунке выше видны временные атрибуты **Переменная X** и **Переменная Y**.
**Внимание**! При расчете временных атрибутов без объектов экспертная система не принимает во внимание текущий объект контекста, поскольку временный атрибут без объектов не должен от него зависеть! Если при расчете такого атрибута используются любые данные, которые нужно получить с помощью текущего объекта (или с помощью других объектов, находимых по правилам поиска объектов от текущего), расчет не удастся. В таких случаях следует использовать временные атрибуты объектов.
Чтобы сделать атрибут временным, достаточно просто добавить его в нужную группу средствами Конфигуратора базы данных. Если возникла необходимость сохранения атрибута, достаточно удалить его из группы временных атрибутов.

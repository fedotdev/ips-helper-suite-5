# Изменение режима работы с SQLite
Служба IPS.DVS для своей работы использует встраиваемую СУБД SQLite. Данная настройка управляет режимом работы с файлом базы данных на диске. При отключенном синхронном режиме база SQLite работает быстрее, но при возникновении сбоя в работе программы или, например, при незапланированном отключении питания есть риск повреждения файла базы. При включенном синхронном режиме – база работает медленнее, но риск повредить базу при сбое ничтожно мал. Отключать синхронный режим рекомендуется только, как временное решение для ускорения перекачки баз данных Search.

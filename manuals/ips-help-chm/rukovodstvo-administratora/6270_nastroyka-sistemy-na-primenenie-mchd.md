# Настройка системы на применение МЧД
Для подключения использования МЧД в систему IPS следует добавить атрибут **Регистрационный номер МЧД** (cadd9f37-306c-11d8-b4e9-00304f19f545) к типу объекта **Подпись с криптозащитой** (cad00138-306c-11d8-b4e9-00304f19f545), при этом, у добавляемого к типу объекта атрибута должны быть настроены необходимые свойства следующим образом:
· **Влияет на дату модификации содержимого объекта** имеет значение **НЕТ**.
· **Принадлежность типу объектов** имеет значение **Атрибут может быть добавлен вручную**. 
**Внимание!** После настроек выше описанных параметров следует перезагрузить сервера приложений.
Для возможности подписания пользователем усиленной подписью с МЧД необходимо добавить пользователю атрибут **Регистрационный номер МЧД** (cadd9f37-306c-11d8-b4e9-00304f19f545) и назначить ему значение. 
Примечание: если значение атрибута пользователю не назначено или атрибут отсутствует, то МЧД при подписании усиленными подписями для данного пользователя не применяется.
После подписания усиленной подписью с МЧД номер доверенности дополнительно отображается в карточке подписей объекта в колонке с информацией о сертификате, а также извлекается при сохранении документов на диск в виде xml файла с тем же именем, что и у файла подписи.

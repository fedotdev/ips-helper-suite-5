# Установка и удаление службы IPS.DVS
Установочные файлы IPS.DVS предусмотрены для 64-битных ОС Windows (SetupIpsDVS.win-x64.exe) и Linux (SetupIpsDVS.linux-x64.run), которые расположены в каталоге InstDVS инсталлятора.

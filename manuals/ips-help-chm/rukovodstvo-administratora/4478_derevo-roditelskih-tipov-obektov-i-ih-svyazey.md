# Дерево родительских типов объектов и их связей
Если выделить конфигурацию роли в дереве конфигураций, то редактор отобразит во второй части дерево родительских типов объектов, сортировка и отображение составов которых настроено.
Принципы работы данного редактора: в настройки добавляется родительский тип объекта, составы которого в **Навигаторе** следует показывать не по умолчанию, а с конкретными настройками. Для указанного типа объекта в редакторе будут показаны допустимые типы его связей. Например, для типа объекта **Сборочные единицы** доступны пять типов связей – **Документация на изделие** , **Технологический состав** , **Состав изделий** , **Собираемые технологические данные** и **Простая связь с сортировкой**. 
Переключателями отмечены типы связей, по которым будут отображаться составы объектов в **Навигаторе**. Если настроек не было, то отмечена будет только связь по умолчанию. Данный редактор позволяет управлять порядком отображения составов различными типами связей – позволяет перемещать отображаемые типы связей по дереву родительских типов объектов. Все команды доступны как в контекстном меню, так и на панели инструментов.
Администратор может отметить необходимые типы связей, а также задать порядок их отображения, переместив их внутри соответствующих родительских типов объектов.
Рассмотрим на примере, что означает порядок отображения типов связей в составе родительского типа объекта. Когда **Навигатор** будет отображать в списке состав объекта типа **Детали** , он отобразит в начале списка связи типа **Документация на изделие** , а затем добавит в список связи типа **Технологический состав**. Остальные типы связей он загружать не будет, так как их отображение отключено.
Примечание: настройки родительских типов объектов наследуются для дочерних типов объектов. Например, можно настроить типы отображаемых связей и их порядок для типа объектов **Сборочные единицы** , а **Навигатор** автоматически применит эти настройки при отображении составов типа объектов **Технологические сборочные единицы** , поскольку они являются дочерним типом для **Сборочные единицы**. Если же явно указать настройки для дочернего типа, то они перекроют унаследованные от родительских типов (и будут являться наследуемыми настройками для вложенных дочерних типов).
В колонке **Группирующий элемент** предоставляется возможность сгруппировать объекты по типам связи в дереве **Навигатора**. При выборе типа связи в качестве группирующего элемента система будет отображать объекты, связанные данным типом связи, в составе родительского типа в виде виртуального нода с именем и иконкой их типа. 
Примечание: виртуальный нод отображается в составе родительского объекта при условии, что объекты, связанные данным типом связи действительно есть в составе.

# Формы на тип объектов
Для каждого типа объекта можно создать одну или несколько форм редактирования атрибутов, которые будут отображаться при создании объекта данного типа и в карточке объекта. Формы удобны в использовании при создании объектов и редактировании их атрибутов. Создание форм осуществляется в специальном редакторе, описание которого можно найти в п. . 
Назначить форму создаваемому типу объектов можно на закладке **Формы на тип объектов** , применив команду **Добавить форму** контекстного меню рабочей области. В появившемся диалоге необходимо выбрать форму и нажать **ОК**. Существует возможность добавить несколько форм, в таком случае при создании нового объекта пользователю будет предложено заполнить их по порядку. С помощью команд контекстного меню можно просмотреть или редактировать назначенную форму в редакторе форм. Чтобы удалить форму, нужно применить команду ее контекстного меню **Удалить форму**. 
Команда **Условие** позволяет вызвать редактор экспертной системы, в котором можно задать условие, при выполнении которого будет отображаться указанная форма. Условие на форму можно также изменять с помощью команд контекстного меню, вызываемого на поле отображения условия. Доступны команды редактирования, удаления и копирования/вставки условия.

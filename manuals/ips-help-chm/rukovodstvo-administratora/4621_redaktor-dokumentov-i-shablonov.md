# Редактор документов и шаблонов
**Шаблон документов** — это файл определенного формата, представляющий собой форму (заготовку) для создания документов определенного типа. Как правило, различным типам документов соответствуют свои шаблоны документов. Шаблоны документов обычно создаются на основании соответствующих стандартов (ГОСТов либо стандартов предприятия). Правильно и грамотно построенный шаблон документов позволяет существенно экономить время при создании самих документов. 
Система IPS предоставляет возможность использовать специальный редактор для создания шаблонов документов, на основании которых впоследствии можно создавать разнообразные документы.
Шаблон документов может включать в себя одну или несколько страниц. Страницы соответствуют стандартам. Если стандарт предписывает различное оформление для разных страниц документа, то в шаблоне требуется создать несколько страниц. Как правило, в многостраничных документах первая (заглавная) страница оформляется не так, как последующие, следовательно, в шаблонах для таких документов нужно создавать две страницы — одну для первых страниц документов, и вторую — для последующих. В большинстве случаев размеры всех страниц шаблона совпадают, однако встречаются документы со страницами различного размера (например, страницы с чертежами или технологическими эскизами могут быть больше остальных). 
На страницах шаблона документов могут присутствовать поля ввода, таблицы, области изображений и другие элементы. Редактор шаблонов документов позволяет создавать, редактировать и изменять свойства элементов шаблонов.

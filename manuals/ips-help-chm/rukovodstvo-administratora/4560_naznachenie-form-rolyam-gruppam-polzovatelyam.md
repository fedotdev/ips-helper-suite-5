# Назначение форм ролям, группам, пользователям
По умолчанию, настраиваемая форма ввода данных может быть назначена:
· **Ролям.**
· **Группам пользователей.**
· **Пользователям.**
Если форма назначена роли, группе или пользователю, то она будет отображаться для информационных объектов IPS для пользователя, который входит в назначенную группу, либо зашёл в систему с указанной ролью.
При назначении форме указанных объектов они добавляются в состав объекта с формой. Поэтому, помимо закладок **Формы на тип объекта** и **Формы на тип связи** , назначение можно выполнять с помощью команд **Создать в составе** и **Добавить в состав** для объекта с формой:
В появившемся окне следует выбрать роль, группу или пользователей, которым требуется назначить указанную форму.

# Настройка внешнего редактора атрибутов
Выберите объект внешнего редактора атрибутов в списке объектов **Навигатора** , откройте его карточку:
Рассмотрим подробно настройку внешнего редактора:
· **Программа для редактирования значения атрибута**. Поле должно содержать полное имя и путь к внешней программе просмотра или редактирования содержимого атрибута. С помощью кнопки **Обзор** можно вызвать диалог для поиска программы на дисках компьютера или в локальной сети. Путь к программе может быть сетевым, например **\\\SERVER\SHARED_FOLDER\myprog.exe**. При задании локального пути следует следить за тем, чтобы программа присутствовала на всех компьютерах пользователей IPS в одном и том же расположении. Наиболее универсальным способом указания местоположения файла является использование переменных окружения. Список переменных окружения можно получить, указав команду SET в окне программы cmd.exe. При указании переменных окружения в полях карточки внешнего редактора атрибутов имена переменных окружения должны быть заключены между знаками %. Если имя программы указывается без пути, то на компьютерах путь к этой программе должен быть указан в переменной окружения PATH.
· **Дополнительные параметры для передачи программе**. В этом поле можно указать строку параметров для внешней программы. Например, при вызове редактора можно указать имя файла, через который IPS будет передавать ему содержимое атрибута.
· **Способ передачи значения.** Этот список позволяет выбрать способ передачи внешней программе содержимого атрибута. IPS предоставляет 3 способа передачи:
1\. **Строка параметров**. Содержимое атрибута передается внешней программе в строке параметров. Содержимое передается первым параметром. Далее идут параметры, которые Вы укажете в поле ввода **Дополнительные параметры для передачи программе**. Этот способ не позволяет передать программе строки длиной более 127 символов или содержимое текстовых полей.
2\. **Файл**. Содержимое поля перед вызовом внешней программы записывается в файл, имя которого задано в поле **Файл для обмена значениями**. Это самый универсальный способ передачи содержимого полей, так как позволяет передавать даже многострочные текстовые поля. При передаче чисел и дат в файл записывается их строковое представление.
3\. **Clipboard**. Содержимое поля записывается в буфер обмена Windows, из которого затем внешнее приложение должно само его извлечь. Данный способ действует только для Windows-программ. Он не позволяет передать содержимое больших текстовых полей.
· **Способ возврата значения.** В этом меню указывается способ, с помощью которого IPS будет принимать отредактированное значение поля из внешней программы. В меню есть 3 пункта:
1\. **Не возвращать**. Выберите этот пункт, если Вы используете внешнюю программу не для редактирования содержимого атрибута, а для просмотра другой информации с помощью значения этого атрибута.
2\. **Файл**. Внешняя программа должна записать отредактированное содержимое поля в файл для обмена значениями, содержимое которого IPS запишет в атрибут после завершения работы внешней программы. Если редактирование не производилось, то программа должна позаботиться о сохранении старого значения атрибута в этом файле, так как IPS всегда перезаписывает содержимое атрибута из этого файла, если Вы указали данный способ возврата значения. Числа и даты программа должна записывать в файл в их строковом представлении. Возвращаемое значение должно быть первой строкой в файле обмена (за исключением многострочных текстовых полей).
3\. **Clipboard**. Внешняя программа должна записать в буфер обмена Windows отредактированное содержимое поля. После закрытия программы IPS запишет содержимое буфера обмена в редактируемый атрибут. Если содержимое атрибута не редактировалось внешней программой, то она должна позаботиться о сохранности старого значения в буфере обмена, так как IPS всегда перезаписывает содержимое поля из буфера обмена, если Вы указали данный способ возврата значения.
· **Файл для обмена значениями**. В это поле нужно ввести имя файла, через который будет производиться обмен значениями поля с внешней программой. Во избежание путаницы рекомендуется задавать полный путь к этому файлу. Но нужно учитывать наличие такого пути на всех компьютерах в вашей сети;
· **Запретить изменять значение атрибута.** Включите этот переключатель, если Вам нужно использовать только внешний редактор для этого атрибута (например, редактор может проводить проверку правильности вводимых в этот атрибут значений).
· **Передавать значения всех атрибутов**. Этот переключатель можно включить только при передаче значений через файл. При этом в файл будут записаны все атрибуты в виде **Имя атрибута=Значение** , причем первым в списке будет идти тот атрибут, для которого была вызвана внешняя программа.
· **Создать**. Нажатие на кнопку позволяет сгенерировать имя файла, который будет использоваться для передачи и возврата значений через внешний редактор атрибутов.
· **Тест**. Проверить корректность настроек, вызвав настроенное внешнее приложение с тестовой строкой.

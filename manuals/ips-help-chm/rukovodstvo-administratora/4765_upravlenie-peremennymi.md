# Управление переменными
Создание и редактирование пользовательских переменных процесса осуществляется в специальном диалоге, который вызывается с помощью команды **Шаблон/Переменные** или из контекстного меню редактора шаблонов процессов.
Переключатели **Пользовательские** , **Системные** и **Глобальные** позволяют фильтровать отображение переменных соответствующего типа.
· Кнопка **Добавить** позволяет добавить новые переменные в шаблон процесса.
· Кнопка **Изменить** позволяет редактировать существующие переменные.
· Кнопка **Удалить** позволяет удалять существующие переменные.
Чтобы создать новую переменную, выполните следующие действия:
· В диалоге **Переменные** нажмите кнопку **Добавить**.
· В появившемся диалоге введите название, отражающее суть создаваемой переменной.

· В поле **Тип переменной** выберите тип из выпадающего списка.
· При необходимости задайте значение переменной по умолчанию. В зависимости от типа переменной оно может задаваться или в поле **Текущее значение** , или по нажатию кнопки **Список значений**.
· Установленный флажок в строке **Текущая дата** позволяет присвоить конкретную дату запуска процесса.
· Установленный флажок в строке **Глобальная переменная** позволяет добавить переменную в группу **Глобальные**.
При редактировании переменной типа **Список строк** выполняется проверка использования переменной в других шаблонах процессов.
Так как на полную проверку использования переменной может потребовать продолжительное время, то для оптимизации процесса по умолчанию выполняется поиск по строковому представлению атрибута **Переменные.** Если в системе присутствуют шаблоны с большим количеством переменных, то в списке найденных могут быть и те шаблоны, у которых отсутствует эта переменная. Для того чтобы выполнить углубленную проверку использования переменной, следует нажать комбинацию клавиш **[Ctrl+Shift+C]** в окне отображения возможных шаблонов процессов, а затем – кнопку .
**Внимание!** Для выполнения данной команды может потребоваться продолжительное время.

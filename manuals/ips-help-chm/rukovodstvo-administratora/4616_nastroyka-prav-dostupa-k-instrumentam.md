# Настройка прав доступа к инструментам
Выберите учетную запись пользователя из списка и нажмите кнопку **Изменить** :
В появившемся окне следует указать, какие права доступа надо назначить выбранной учетной записи. После нажатия кнопки **ОК** сделанные изменения будут сохранены.

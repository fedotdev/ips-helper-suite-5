# Закладка Исполнители
Данная закладка отображается только для действий типа **Задача** и **Утверждение** , и является обязательной к заполнению. Список исполнителей может состоять из пользователей, групп пользователей, пользователей в определенной должности, а также переменных типа **Список пользователей**.

Чтобы выбрать исполнителей действия, выполните следующие действия:
· Нажмите кнопу **Добавить** для вызова диалога выбора пользователей.
· В появившемся диалоге в поле **Фильтр** укажите список, из которого будут выбираться пользователи:
− **Группы и пользователи** — здесь можно выбрать целую группу или отдельных пользователей из состава группы.
− **Переменные** — позволяет выбрать пользователей из числа переменных типа **Список пользователей** , объявленных в текущем шаблоне процесса.
− **Должности** — позволяет указать в качестве исполнителей пользователей, находящихся в определенной должности.
· Отметьте необходимые значения.
· Нажмите **ОК**.
Выбор **На данном шаге участвуют** позволяет указать, все ли исполнители списка должны участвовать в действии процесса или достаточно любого исполнителя данного действия. В первом случае действие будет обязательно для исполнения всеми указанными пользователями, во втором — при выполнении действия каждый перечисленный пользователь получит системное сообщение с предложением взять задачу на рассмотрение. Пользователи, получившие такое сообщение, могут принять к рассмотрению данное действие, выполнив команду **Принять к рассмотрению** или отказаться от рассмотрения, выполнив команду **Отказаться от рассмотрения**. Если один из потенциальных исполнителей принимает действие к исполнению, подобные сообщения у всех остальных пользователей автоматически удаляются. Если ни один из пользователей не согласился выполнять действие (все отказались от рассмотрения), то выполнение автоматически возвращается назад с соответствующим сообщением.
При выборе условия **Любой пользователь из списка** предоставляется возможность включить режим **Назначать исполнителем последнего пользователя** , который позволяет автоматически назначить исполнителем задачи того пользователя, который последний отреагировал на сообщение.
**Внимание!** Если режим **Назначать исполнителем последнего пользователя** отключен, то отказаться от выполнения задачи могут все перечисленные пользователи.
Установленный флажок в строке **Запретить удаление действия из почты получателями** позволяет запретить удалять пользователям полученные действия из почты.
Установленный флажок в строке **Требовать заполнение ответа при отправке назад** позволяет назначить обязательное условие на действие. Выбор данного параметра обяжет пользователя заполнить закладку **Ответ** при условии, что данное действие будет отправлено назад.
Установленный флажок в строке **Выполнять рассылку на внешнюю почту** позволяет разослать данное действие на внешнюю почту пользователи, но при условии, что настроена привязка внутренней почты пользователя ко внешней.

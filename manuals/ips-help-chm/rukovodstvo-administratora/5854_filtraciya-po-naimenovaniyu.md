# Фильтрация по наименованию
Чтобы воспользоваться фильтром по наименованию следует:
1\. В строке **Наименование** нажать кнопку , в выпадающем списке в строку ввода ввести необходимое наименование объекта.
Примечание: фильтрация по наименованию производится на основании автоподстановки поисковых запросов.
2\. Затем следует нажать кнопку кнопку **Фильтровать.**

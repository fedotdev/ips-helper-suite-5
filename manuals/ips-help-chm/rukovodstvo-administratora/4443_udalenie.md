# Удаление
Для удаления уровня продвижения выделите его в дереве метаданных и примените команду **Удалить** его контекстного меню. Нельзя удалить уровень продвижения в следующих случаях:
− если он является системным;
− если он назначен по умолчанию;
− если в базе данных есть объекты, находящиеся или находившиеся на данном уровне продвижения, 
− если в базе данных есть жизненные циклы, содержащие данный уровень продвижения.

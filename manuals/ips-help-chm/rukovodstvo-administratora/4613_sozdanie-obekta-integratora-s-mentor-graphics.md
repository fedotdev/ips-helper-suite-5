# Создание объекта интегратора с Mentor Graphics
Данный интегратор позволяет осуществить интеграцию системы IPS с редактором электронных схем DxDesigner, входящим в состав Mentor Graphics Expedition Enterprise Flow EE7.9.3.
Откройте окно настройки инструментов, выберите страницу **Интеграторы с приложениями** и нажмите кнопку Создать. В появившемся окне укажите **Интегратор с Mentor Graphics** , затем нажмите кнопку **ОК**.

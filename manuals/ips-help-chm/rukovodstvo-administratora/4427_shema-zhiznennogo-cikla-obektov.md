# Схема жизненного цикла объектов
По умолчанию, созданному типу объектов назначается схема, которая указана в качестве схемы по умолчанию в свойствах схем жизненных циклов. Но различные типы объектов могут иметь свои схемы жизненных циклов. Закладка **Схема жизненного цикла** позволяет назначить схему жизненного цикла для типа объектов из существующих в базе данных схем. Чтобы назначить схему жизненного цикла типу объектов, нажмите кнопку , расположенную в правом верхнем углу рабочей области закладки. В появившемся диалоге выберите схему и нажмите . При изменении схемы жизненного цикла родительского типа объекта после нажатия кнопки система может предлагать распространение выполненного изменения схемы на дочерние типы, а также распространение этого изменения на уже существующие объекты.
Схема жизненного цикла объектов отображается на данной закладке в режиме просмотра, но позволяет настроить некоторые из свойств шагов схемы, скорректировав их под данный тип объектов:
· **Контроль подписей**. Позволяет настроить графы для подписей объектов, не заполнив которые невозможно будет перевести объекты на данный шаг жизненного цикла. Чтобы настроить контроль подписей, вызовите диалог настройки граф для подписей с помощью кнопки, расположенной с правой стороны строки. Вызовите команду **Добавить новую группу** контекстного меню поля диалога. Отметьте графы, которые необходимо будет подписывать, и нажмите **ОК**. Переключатель **Использовать строгий контроль для данной графы** позволяет установить строгий контроль подписи, т.е. подпись объекта будет считаться устаревшей, если объект модифицировался после его подписания.
· **Необходимость извещения**. Определяет необходимость включения создаваемых версий объектов в извещения об изменениях.
Если требуется отредактировать другие свойства данной схемы, нужно открыть ее непосредственно в дереве метаданных на закладке **Редактор схем жизненных циклов**.
Для любого из шагов жизненного цикла можно настроить следующие права доступа к объектам данного типа:
· **Просмотр файлов объекта** — разрешает просматривать содержимое файловых атрибутов объектов.
· **Редактирование объекта** — разрешает редактировать объекты данного типа.
· **Удаление объекта** — разрешает удалять объекты данного типа.
· **Удаление объекта без восстановления** — разрешает удалять объекты данного типа, без возможности их восстановления.
· **Перевод объекта на данный шаг ЖЦ** — разрешает переводить объекты данного типа на этот шаг жизненного цикла.
· **Работа с аутентичными файлами** – разрешает добавлять, изменять и удалять файлы типа **Аутентичный файл**.
· **Работа с файлами ОТД** – разрешает добавлять, изменять и удалять файлы типа **Файл ОТД**.
· **Удаление файлов замечаний** – разрешает удалять файлы типа **Файл замечаний**.
· **Просмотр прав доступа** — разрешает просматривать набор прав доступа к объектам данного типа.
· **Изменение прав доступа** — разрешает назначать права доступа на объекты данного типа.
· **Изменение владельца** — разрешает изменять владельцев объектов данного типа.
· **Изменение базовой версии** – разрешает изменять базовую версию объекта.
· **Изменение уровня доступа объекта** – разрешает изменять уровень доступа объекта.
· **Создание версии** – разрешает\запрещает создавать версии объекта, однако право не распространяется на создание 0-ой версии.
**Внимание!** В системе IPS предоставлена возможность копировать права, при условии, что место, куда копируются выбранные права, может принимать такие права доступа.
Настройка прав доступа производится с помощью команды **Безопасность** в контекстном меню схемы ЖЦ. Проверка прав не будет осуществляться в случае, если свойство **Контроль прав доступа к объектам** у данного шага ЖЦ содержит значение **Не проверять права**.

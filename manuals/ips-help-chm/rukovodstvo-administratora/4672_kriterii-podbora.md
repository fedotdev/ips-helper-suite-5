# Критерии подбора
Соответственно, по виду реализуемой функции сравнения, критерии подбора бывают двух видов - обычные и дополнительные. Если фильтрация всех версий объектов по обычным критериям подбора с помощью обычных функций сравнения не дала положительных результатов, или наоборот, дала несколько подходящих версий, то выполняется фильтрация по дополнительному критерию подбора по агрегатной функции сравнения и отыскивается единственная наиболее подходящая версия объекта. В связи с этим в каждом правиле подбора версий должен быть как минимум один обычный критерий подбора и только один дополнительный критерий подбора.
Основных критериев может быть от 1 до 100 шт., дополнительный критерий может быть всегда только один.
Список допустимых функций сравнения меняется в зависимости от типа данных атрибута для сравнения, а также от его вида (системный атрибут или пользовательский). Для атрибутов, представляющих собой простые типы данных (числовые, строковые), можно реализовать различные функции сравнения, но для сложных типов данных (например, BLOB), допустимо лишь проверять значение такого атрибута на NULL.

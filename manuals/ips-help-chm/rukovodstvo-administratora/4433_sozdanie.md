# Создание
Чтобы создать новый тип связей, в дереве метаданных отметьте элемент **Типы связей** и примените команду **Добавить** его контекстного меню. При этом в дереве появится новый тип связей, большинству свойств которого будут присвоены значения по умолчанию. Отредактируйте свойства созданного типа связей и нажмите кнопку **Применить**.

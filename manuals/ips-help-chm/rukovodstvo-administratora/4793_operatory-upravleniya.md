# Операторы управления
По умолчанию при выполнении каждого оператора экспертная система сначала выполняет сам оператор, а потом дочерние операторы (вложенные в текущий оператор). Если дочерних операторов несколько, сначала будет выполнен первый из них, затем его дочерние операторы, потом второй со своими дочерними операторами, и так далее. Операторы управления позволяют изменить обычную последовательность обработки операторов скрипта.
Оператор **Блок** служит в качестве оператора **ЕСЛИ** (то есть, позволяет выполнить группу дочерних операторов только при успешной проверке заданного условия), а также для логической группировки операторов. 
Для ввода или изменения условия достаточно дважды щелкнуть левой кнопкой мыши в поле условия или выбрать команду **Изменить** в контекстном меню. После этого появится редактор формул (см. п. ), в котором следует ввести или изменить условие. Команды **Копировать** и **Вставить** работают с буфером обмена и позволяют сэкономить время при вводе нескольких одинаковых или похожих условий.
Поле ввода **Перейти к объекту по ссылке** позволяет организовать косвенную адресацию – то есть, использовать в качестве контекста объект, ссылка на который хранится в одном из атрибутов текущего объекта. Выбор атрибута, содержащего ссылку на объект, осуществляется по нажатию кнопки . Если этот атрибут задан, то все операторы, дочерние по отношению к текущему, будут работать в контексте тех объектов, на которые указывают ссылки. Кнопка служит для удаления атрибута.
Оператор**Блок выбора** служит в качестве оператора выбора (case или switch), присутствующего во многих языках программирования, либо оператора **если-то-иначе**. В отличие от обычного блока, блок выбора выполняет только **один** дочерний оператор – тот, для которого первым выполняется назначенное условие. 
В тех случаях, когда требуется прекратить выполнение операторов текущего блока, используется оператор **Выход из блока** . Если выполняется условие, заданное для этого оператора, управление переходит к следующему оператору, находящемуся за пределами текущего блока. Не стоит создавать дочерние элементы для этого оператора, поскольку они никогда не будут выполняться!
Параметры операторов **Блок выбора** и **Выход из блока** аналогичные параметрам оператора **Блок**.
Оператор **Вызов процедуры** позволяет вызвать выполнение другого скрипта или оператора. В зависимости от выбранного переключателя окно ввода дополнительных параметров будет меняться.
· **Вызов оператора** — позволяет вызвать выполнение другого оператора из текущего скрипта.
· **Вызов пользовательской процедуры** — позволяет вызвать процедуру, зарегистрированную посредством функции **RegisterUserProc** (см. **п. 4.2 Модули расширения в «Руководстве программиста»**). При вызове пользовательской процедуры можно ввести до двух параметров. Это формулы, которые должны возвращать строковые значения. Если вызываемой процедуре нужны параметры других типов, она может сама привести строки к нужным типам данных.
· **Вызов другого скрипта** — позволяет вызвать выполнение другого скрипта.
· **Вызов функции из сценария** — позволяет вызвать функцию из сценария для экспертной системы. Аналогично пользовательской процедуре при вызове функции из сценария можно ввести до двух параметров.

# Скрипты пересчета
**Скрипты пересчета** определяют, какие параметры должны пересчитываться при изменении того или иного атрибута. Эти скрипты не имеют совершенно никакого отношения к расчетным скриптам: они никогда не вызываются при расчете какого-либо атрибута. Скрипт пересчета обычно вызывается, когда пользователь нажимает кнопку **Пересчитать** на форме параметров объекта. При этом экспертная система использует скрипт пересчета, чтобы определить, какие параметры нужно пересчитать, и запускает расчет для каждого из этих параметров.
Создание нового скрипта пересчета производится по команде **Создать**. В открывшемся окне необходимо указать атрибут объекта, при изменении которого необходимо пересчитать зависящие от него атрибуты.
После этого откроется редактор скриптов ЭС. 
На рисунке выше показан пример скрипта пересчета атрибутов количество заготовок из прутка (**КЗП**), **Норма расхода** , **Коэффициент использования материала** при изменении атрибута **Длина заготовки**. 
Редактирование скриптов будет описано в п. .

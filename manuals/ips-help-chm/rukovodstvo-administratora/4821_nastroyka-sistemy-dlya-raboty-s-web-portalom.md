# Настройка системы для работы с Web-порталом
Редактирование параметров соединения производится в программе **Конфигуратор** (файл Configurator.exe, расположен в папке сервера приложений).
В поля формы необходимо ввести следующие данные:
· **Наименование соединения** , которое будет отображаться в различных клиентских формах. 
· **Адрес** , по которому доступна web-служба **IPS WebPortal**.
· **Глобальный идентификатор** **текущего узла** информационной системы. 
· **Код текущего узла** информационной системы.
· **Информацию по системному репликатору и администратору текущего узла.** Для этого необходимо нажать на кнопку возле поля с отображаемым именем каждого из этих пользователей. В появившемся окне необходимо ввести: отображаемое имя пользователя, его логин для входа и пароль. 
При наличии соединения с интернетом можно проверить правильность введенных данных. Если выставлена галочка **Тест подключения к порталу** программа попробует произвести подключение к web-службе **IPS WebPortal** и авторизацию при помощи указанных данных.

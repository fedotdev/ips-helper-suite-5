# Работа с штрих-кодами
Для создания штрих-кодов используется элемент **Метка.** Необходимо выбрать **Тип вывода** -**Штрих-код**. Штрихкодирование идет в формате Code128.
Можно изменять размеры штрих-кода использую свойство **Масштаб штрих-кода.** В качестве кода используется свойство**Текст.**
IPS производит поиск по идентификатору версии объекта. Чтобы не заполнять его вручную, можно использовать ссылки на идентификаторы версий других объектов:
· Если необходимо вывести в поле идентификатор текущего документа, то для этого выберите свойство **Источник данных/На элемент документа/Атрибут/Идентификатор версии объекта**. 
· Если необходимо вывести в поле идентификатор другого объекта, то выберите свойство **Источник данных – На объект системы – Атрибут – Идентификатор версии объекта**.

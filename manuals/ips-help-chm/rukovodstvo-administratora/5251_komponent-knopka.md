# Компонент Кнопка
В данном компоненте основные свойства унаследованы от компонента **Надпись**. Кроме того есть дополнительные свойства:
· **Действие**. Имя обработчика, вызываемого при клике на элемент управления. Стандартные значения действия:
− **Нет** – действие на кнопку не назначено;
− **Применить** – применяет изменения;
− **Отмена** – выполняет отмену;
− **Классифицировать** – вызывает классификатор;
− **Вызвать справку –** вызвать пользовательский файл справки;
− **Вызвать редактор** – вызывает назначенный внешний редактор атрибутов.
Модули расширения могут добавлять свои обработчики действий, соответственно, данный список значений может расширяться в соответствии с загружаемыми модулями.
· **Параметры действия/Атрибут**. Свойство доступно, если на кнопку назначено действие **Вызвать редактор**. Позволяет указать атрибут, для изменения значений которого будет вызываться внешний редактор:
Примечание: внешний редактор можно применять только для атрибутов с простыми типами данных (строка, целое/дробное число, дата, текст).
· **Параметры действия/Внешний редактор**. Свойство доступно, если на кнопку назначено действие **Вызвать редактор**. Позволяет назначить внешний редактор, с помощью которого будут редактироваться значения назначенного атрибута:
· **Всегда активна**. Свойство доступно, если на кнопку назначено действие **Классифицировать**. Позволяет сделать кнопку активной, даже если документ не взят на изменение. Это может потребоваться для модификации атрибутов объекта, не требующих взятия его на изменение.
· **Плоский стиль**. Определяет внешний вид элемента управления при наведении указателя мыши и щелчке на элементе управления. Допустимые значения: **Системный** , **Стандартный** , **Всплывающий** , **Плоский**.
· **Результат**. Результат диалогового окна показывается в модальной форме после нажатия клавиши. Допустимые значения: **Нет** , **Да** , **Игнорировать** , **Повторить** , **Прервать** , **Отменить** , **ОК** , **Ничего**.
· **Действие Вызвать справку.** При выборе этого действия пользователь сможет вызывать собственный файл справки. Для этого необходимо заполнить поля свойств формы **Метка раздела** и **Наименование файла.** Описание полей находится в разделе **Свойства формы ввода данных.**
· **Отключить доступность по правилу**. Позволяет задать правило с помощью редактора формул, по которому будет рассчитана доступность кнопки на форме в зависимости от значения атрибутов.
· **Отключить видимость по правилу**. Позволяет задать правило с помощью редактора формул, по которому будет рассчитана видимость кнопки на форме в зависимости от значения атрибутов.

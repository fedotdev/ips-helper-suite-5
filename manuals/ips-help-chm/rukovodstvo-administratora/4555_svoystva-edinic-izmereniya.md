# Свойства единиц измерения
Выберите единицу измерения из списка и выполните команду **Свойства** из меню **Вид**. 
На закладке **Свойства** приводится следующая информация о единице измерения:
· **Коэффициент приведения к базовой единице.** Здесь указывается вещественное число, на которое нужно умножить значение физической величины, выраженное в данной единице измерения, чтобы получить данное значение в базовой единице. Базовой считается единица измерения физической величины, для которой значение коэффициента приведения равно 1.
· **Наименование**. Уникальное полное наименование единицы измерения.
· **Краткое наименование**. Краткое наименование единицы измерения.
· **По умолчанию**. Это свойство определяет, будут ли значения данной физической величины в качестве единице измерения по умолчанию.
· **Формула получения единицы измерения**. Здесь указываются математические формулы получения данной единицы измерения с помощью умножения или деления других единиц измерения. В формулах должны использоваться краткие наименования уже занесенных в базу единиц измерения. Например, **метр квадратный** можно получить следующей формулой: **м*м**.

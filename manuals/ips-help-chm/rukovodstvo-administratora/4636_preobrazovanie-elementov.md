# Преобразование элементов
При необходимости пользователь может преобразовывать одни типы созданных элементов в другие, не прибегая к проблеме создания их заново. Чтобы преобразовать один тип элемента в другой, необходимо отметить элемент на странице и применить команду его контекстного меню **Преобразовать в …**. При этом в зависимости от выбранного типа элемента, системой будут предложены те или иные виды элементов для преобразования.

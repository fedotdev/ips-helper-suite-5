# Создание схемы поиска применяемостей
Создать схему поиска применяемости можно несколькими путями:
· Войти в приложение **Администратор базы данных / Настройки системы / Схемы поиска объектов** , выбрать тип создаваемого объекта (это могут быть или **Общие схемы поиска объектов** , или **Персональные**) вызвать диалоговое окно правой кнопкой мыши и выбрать команду **Создать**.
· Войти в приложение **Навигатор / Информационное пространство / Объекты / Настройки системы / Схемы поиска объектов** , выбрать тип создаваемого объекта, вызвать диалоговое окно правой кнопкой мыши и выбрать команду **Создать.**
· С помощью команды контекстного меню объекта на рабочей области**Создать / Новый.** В открывшемся окне открыть **Настройки системы / Схемы поиска объектов** и выбрать тип создаваемого объекта. Не важно в каком приложении вы работаете на данный момент. 
· Воспользоваться кнопкой **Создать новую схему поиска** на панели инструментов закладки **Поиск применяемости**. Выбрать тип создаваемого объекта и нажать кнопку .

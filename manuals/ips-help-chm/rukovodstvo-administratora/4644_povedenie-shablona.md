# Поведение шаблона
· **Обязательный элемент**. Позволяет указать, является ли элемент обязательным при создании документов на основании данного шаблона.
· **Шаблоны из предыдущей**. Отображается для элемента **Таблица**. Позволяет использовать шаблоны подэлементов таблицы при переносе ее с предыдущей страницы.

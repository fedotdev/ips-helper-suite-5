# Взаимодействие со службами каталогов
Система IPS позволяет как импортировать информацию об учетных записях пользователей из доменов Active Directory, так и настроить синхронизацию учетных записей Active Directory и их атрибутов (имя, почтовый адрес и т.д.) со списком пользователей IPS. 
IPS может выполнять импорт и синхронизацию из нескольких доменов. При этом к имени входа импортируемого пользователя IPS добавляется постфикс **@ <имя домена Active Directory>**. Один домен может быть назначен доменом по умолчанию, при этом для учетных записей из домена по умолчанию постфикс к именам входа не добавляется.
Настройка домена по умолчанию выполняется по команде **Настройка / Параметры IPS / Система / Синхронизация со службами каталогов** , поле **Каталог по умолчанию**. 
Для выбора в качестве каталога по умолчанию система предлагает имена доменов из текущего леса доменов Active Directory, но вручную может быть указано имя любого существующего домена даже из другого леса. Таким образом, с одной базой данных IPS могут выполнять синхронизацию и импорт учетных записей серверы приложений, работающие в разных лесах Active Directory даже без доверительных отношений между собой. 
**Внимание!** Не рекомендуется производить изменение каталога по умолчанию без крайней необходимости, так как это может привести к изменению существующих имен входа пользователей IPS.

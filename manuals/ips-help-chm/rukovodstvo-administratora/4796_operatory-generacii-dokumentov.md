# Операторы генерации документов
Операторы генерации документов доступны только в скриптах генерации документов (см. п. ). Эти операторы обеспечивают создание нужных элементов документа и заполнение соответствующих полей. При создании скрипта генерации документов требуется не забывать о том, какой элемент документа является текущим при выполнении каждого оператора создания нового элемента документа и заполнения поля документа . Для выбора элемента документа используется соответствующий оператор **Выбор элемента документа** . 
Параметры оператора **Выбор элемента документа** показаны на рисунке ниже.
Элементы документа имеют идентификатор, по которому их можно найти. Если этот элемент присутствовал в шаблоне, он будет иметь такой же идентификатор, как и в шаблоне. Тем не менее, новые элементы документа (созданные оператором создания элемента) получат новые идентификаторы, поскольку идентификатор должен быть уникальным.
Чаще всего требуется выбрать тот элемент документа, внутри которого должны создаваться новые элементы. Для большинства технологических документов это рабочая область. Для выбора элемента шаблона требуется включить кнопку **Из шаблона** и нажать одну из кнопок в полях **ИД** и **Имя**. После этого появится диалоговое окно выбора элемента шаблона (см. рисунок ниже). Можно выбрать элемент шаблона как в окне, в котором он изображен, так и в дереве структуры шаблона. Если нужно выбрать весь документ, включите соответствующий переключатель **Выбрать весь документ** выше.
Группа **Направление поиска** позволяет определить, нужно ли искать выбираемый элемент среди дочерних элементов текущего (по умолчанию выбрано значение **Вниз от текущего**) или среди тех элементов, в которые входит текущий (переключатель **Вверх от текущего**). Если требуется выбрать один из новых элементов документа, следует включить переключатель **По формуле** и ввести формулу, возвращающую идентификатор искомого элемента. Информацию для этой формулы можно получить из параметров оператора создания объекта (см. ниже).
Переключатель **Использовать по умолчанию** следует включать, чтобы экспертная система искала элементы, начиная с этого элемента, если их не удалось найти для текущего элемента. В скриптах, генерирующих сложные документы, приходится часто менять текущий элемент документа, и задание элемента, выбранного по умолчанию, позволяет сократить количество операторов выбора и упростить скрипт. Например, в скриптах генерации технологических документов следует включать этот переключатель для рабочей области документа, поскольку именно в ней создается большинство элементов документа.
**Внимание**! Выбор элемента документа действует только до выхода из текущего блока. Это сделано для того, чтобы не приходилось восстанавливать текущий элемент. 
Параметры оператора **Создать элемент документа** показаны на рисунке ниже.
Необходимо понимать, что в скрипте нужно создавать только те элементы, количество которых заранее не известно – например, количество строк в рабочей области технологического документа. Элементы, которые уже присутствуют в шаблоне, создавать не нужно – они будут созданы автоматически при создании документа на основе шаблона. Все элементы, создаваемые скриптом, должны иметь выключенный переключатель **Обязательный элемент** в свойствах их шаблонов.
Прежде всего следует выбрать элемент шаблона, нажав кнопку в полях **Имя** или **Идент**. После этого появится окно выбора элемента шаблона, в котором нужно выбрать тот элемент шаблона, на основе которого нужно создать новый элемент. Если на основе этого элемента создается несколько элементов (например, в цикле), то можно определить идентификатор нового элемента, задав базовое значение в поле **Идент** , включив переключатель **прибавить** и выбрав атрибут, значение которого будет прибавлено к базовому для получения итогового идентификатора. Удобнее всего прибавлять атрибут **Номер текущего объекта в контексте** , поскольку система автоматически заносит в него номер объекта в цикле. При желании можно сохранить идентификатор нового элемента документа в каком-нибудь временном атрибуте, выбрав атрибут в соответствующем поле. Как назначение идентификатора, так и его сохранение в атрибуте позволяет впоследствии обратиться к новому элементу в других операторах – например, в операторе выбора объекта.
Переключатель **Сделать новый элемент текущим** позволяет сделать вложенный элемент текущим. После выполнения вложенных операторов восстанавливается тот текущий элемент, который был установлен прежде. 
Переключатель **Навсегда** доступен только при включении переключателя **Сделать новый элемент текущим**. Если переключатель **Навсегда** не включен, то новый элемент будет текущим только для операторов, которые входят в оператор создания элемента документа. После их выполнения будет восстановлен прежний текущий элемент. Если переключатель **Навсегда** включен, то новый элемент будет текущим до выхода из текущего блока.
Переключатель **Заполнить дочерние элементы из полей с совпадающими именами** позволяет автоматически заполнить в документе все поля, имена которых в шаблоне совпадают c именами атрибутов в объекте. Например, при выводе в документ значений атрибутов объекта **Операция** необходимо было бы использовать операторы **Запись данных в поле**(описание оператора см. ниже).
В том случае если для элемента скрипта **Создание строки А** включить переключатель **Заполнить дочерние элементы из полей с совпадающими именами** дочерние операторы **Номер операции** , **Операция** , **Код операции** , **Участок** можно не использовать в том случае, если имена полей в шаблоне совпадают с наименованиями атрибута объекта значение которого необходимо передать.
Переключатель **Использовать по умолчанию** аналогичен одноименному выключателю в операторе **Выбор элемента документа.**
Переключатель **Если последний элемент создан на основе того же элемента шаблона – использовать его, не создавая новый** применяется в том случае, когда необходимо избежать дублирования строки в документе. Например, если пустые строки создаются в разных местах скрипта, можно не знать, есть уже пустая строка или нет. При создании пустой строки без переключателя – в документ выведутся две пустые строки. При включении переключателя пустая строка всегда будет одна.
Поле **Тег для идентификации** применяется для однозначной идентификации элементов документа одного и того же типа, созданные разными операторами. Например, если скрипте в трех разных местах создаются строки А, то можно расставить в этих операторах разные теги. На внешний вид документов эти теги не оказывают никакого влияния. Данное поле добавлено для развития системы и в настоящее время не используется.
Для того, чтобы записать какие-либо данные в поле документа, нужно использовать оператор **Запись данных в поле** . Обычно этот оператор используется для записи текста, но с его помощью можно записать и графическое изображение в поле рисунка. Параметры оператора **Запись данных в поле** показаны на рисунке ниже.
Прежде всего следует выбрать поле в одноименной группе – точно так же, как и для оператора создания элемента документа. Например, можно **прибавить** к базовому идентификатору значение какого-нибудь атрибута.
Переключатель **Установить активную ссылку** позволяет установить активную связь между полем и атрибутом какого-либо объекта базы данных. Активная связь означает, что содержимое поля в документе будет обновляться при изменении значения атрибута, выводимого в этом поле, даже без переиздания комплекта документов. 
Переключатель **Ссылка на этот документ** позволяет поставить ссылку на атрибут того документа, который на данный момент генерируется. Самого объекта еще нет. Например, атрибут объекта документа **Количество листов в комплекте**. Если этот переключатель не включить - ссылка будет на текущий объект контекста.
Переключатель **Аутентичный файл** устанавливается в том случае, когда необходимо вывести в документ информацию не из основного файла объекта, а из аутентичного. Например, в ТП объект технологический эскиз имеет основной файл эскиза и аутентичный. 
При установке данного переключателя, информация в документ будет выводится из аутентичного файла документа, при снятии – из основного.
Поле **Тег идентификации** аналогичен одноименному поле в операторе **Создать элемент документа.**
В поле можно записать как значение атрибута либо результат вычисления какой-нибудь формулы – включите переключатель **Записать значение Атрибута** в первом случае и **Записать значение Формулы** во втором. После этого можно выбрать атрибут (аналогично выбору атрибута в параметрах прочих операторов) либо ввести значение формулы – для этого достаточно дважды щелкнуть в поле редактирования формулы.
**Внимание!** В некоторых случаях может показаться, что достаточно присвоить в поле значение атрибутов, но на самом деле потребуется формула с участием функции **СТР** для получения его строкового значения. Это относится к атрибутам, имеющим несколько представлений: например, атрибут **Пользователь** имеет как числовое представление (идентификатор пользователя), так и строковое (имя пользователя).
На вкладке **Формат текста** можно изменить параметры шрифта выводимо элемента. Задаваемые в этом окне параметры имеют высший приоритет над настройками шрифта указанными в шаблоне документа.
**Оператор управления документом** позволяет либо создавать новые листы документа, либо заменить уже имеющиеся. 
Обычно листы документа создаются автоматически при разбиении документа, но иногда возникает необходимость явного создания нужных листов. Например, при выводе нескольких эскизов на разные листы из шаблона документа в зависимости от формата эскиза. Для создания нового листа следует установить переключатель **Создавать новый лист**. Для замены текущего листа следует установить переключатель **Заменить первый лист**. В поле **Лист** выбирается лист из шаблона документов, который будет создан.
Переключатель **Сделать новый лист текущим** позволяет сделать вложенный элемент текущим. После выполнения вложенных операторов восстанавливается тот текущий элемент, который был установлен прежде. Это актуально в тех случаях, когда необходимо выводить группу объектов, например, эскизов, на нескольких листах. Если не включить переключатель, то текущим остается первый лист документа. Генератор документов не знает, на каком именно листе необходимо заполнить поле, и поэтому ищет в документе первое поле с заданным идентификатором, в которое и записываются все эскизы (новые переписывают старые, и в результате, на первом листе оказывается только последний эскиз). При этом чтобы вышеописанная схема работала, все операторы заполнения полей на этом листе необходимо вставить в оператор создания листа, потому что переключатель действует только на вложенные операторы.

# Права доступа
Любому элементу системы IMBASE (каталогу, папке, таблице) можно назначить права доступа к нему. Права доступа могут быть назначены пользователю, группам пользователей или ролям, под которыми пользователи входят в систему. Права доступа назначаются на закладке **Безопасность** , перейти к которой можно, отметив предварительно необходимый элемент в дереве навигации.
С помощью кнопки **Добавить** вызовите диалог выбора пользователей. Выберите пользователей, которым необходимо назначить права.
В колонках **Разрешить** и **Запретить** включите/выключите переключатели напротив соответствующих прав. Система позволяет назначать следующие права доступа:
· **Просмотр файлов** — разрешает просматривать файлы, прикрепленные к элементу.
· **Редактирование** — разрешает редактировать свойства элемента.
· **Удаление** — разрешает удалять элемент.
· **Удаление без восстановления** — разрешает удалять элемент без возможности его восстановления.
· **Изменение шага ЖЦ** — разрешает переводить элемент на другой шаг жизненного цикла.
· **Включение объектов в состав** — разрешает включать объект, для которого назначено право, в составы других объектов.
· **Исключение объектов из состава** — разрешает исключать объект, для которого назначено право, из составов других объектов.
· **Просмотр прав доступа** — разрешает просматривать набор прав доступа к элементу.
· **Изменение прав доступа** — разрешает изменять права доступа к элементу.
· **Изменение владельца** — разрешает менять владельца элемента.
· **Изменение базовой версии** — разрешает изменять базовую версию объекта.
**Внимание!** В системе IPS предоставлена возможность копировать права, при условии, что место, куда копируются выбранные права, может принимать такие права доступа.
Чтобы удалить пользователя из списка пользователей, которым назначены права, отметьте его на закладке **Безопасность** и нажмите кнопку **Удалить**.

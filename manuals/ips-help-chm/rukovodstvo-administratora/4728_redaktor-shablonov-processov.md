# Редактор шаблонов процессов
Меню **Настройка** в главном окне содержит команду **Редактор шаблонов процессов** , по которой открывается список шаблонов процессов. 
Редактор шаблонов процессов имеет многооконный пользовательский интерфейс, то есть для редактирования одновременно могут быть открыты несколько шаблонов процессов. Для создания шаблона процесса в редакторе дизайнер должен добавить в пустой шаблон необходимые действия и обозначить связями переходы между ними. Редактор также позволяет видоизменять существующие шаблоны, сохранять их под другим именем, а также просматривать шаблоны в режиме **только для чтения**. 
Редактор шаблонов процессов имеет палитру, где в виде специальных значков отображаются все действия, с помощью которых формируется шаблон процесса, и рабочую область, в которой формируется шаблон. Для создания шаблона процесса в редакторе дизайнер должен добавить в пустой шаблон необходимые действия из палитры, указать их свойства и соединить действия определенными связями.
Используя графический редактор, дизайнер процессов может описать все необходимые условия работы шаблона процессов:
· Последовательность пересылок документов пользователям или группам пользователей.
· Список переменных и пользовательские формы для управления процессом.
· Условия переходов по тем или иным веткам процесса.
· Действия пользователей с полученными документами и задания для пользователей, включая контроль движения документов и выполнения заданий.
· Получение необходимых электронных подписей документами или возврат их отправителю с замечаниями.
· Автоматическую передачу документов, успешно прошедших процедуру утверждения, в архивы утвержденных документов и т.д.

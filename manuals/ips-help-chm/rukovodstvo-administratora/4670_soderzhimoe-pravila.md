# Содержимое правила
Каждое правило подбора версий состоит из следующих элементов:
− основные критерии подбора;
− дополнительный критерий подбора;
− признак подбора составов на определённую дату;
− признак правило для редактирования;
− признак правило по умолчанию.
Основные и дополнительный критерии состоят из следующих элементов:
− атрибут фильтруемой версии объекта;
− логическая функция сравнения, флажок отрицания её результата;
− значения для сравнения.

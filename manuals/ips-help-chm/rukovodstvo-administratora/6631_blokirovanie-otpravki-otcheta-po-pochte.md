# Блокирование отправки отчета по почте
В приложении **Конфигуратор базы данных** для типа объекта **Роли** присутствует атрибут **Блокирование отправки отчета по почте** , значение которого по умолчанию **Нет**. Данный атрибут управляет возможность отправлять запрос в техподдержку в меню **Справка** и отправлять сообщение об ошибке по почте.
При необходимости блокировки кнопок и следует:
1\. Выбрать необходимую роль, в которой следует заблокировать отправку отчета по почте и открыть карточку объекта.
2\. На закладке **Свойства** выбрать атрибут **Блокирование отправки отчета по почте** и задать значение **Да**. 
Примечание: если атрибута **Блокирование отправки отчета по почте** нет в списках, то посредством команды из контекстного меню следует добавить описанный атрибут.

# Работа с файлами
· **Тип файла для документов**. Позволяет ввести расширение главного файла документа. Этот параметр используется системой для автоматического определения типа документа при импорте файлов с диска. Главным считается файл, находящийся первым в списке файлов атрибута **Файл**.
· **Дополнительные файлы**. Позволяет указать расширения файлов, которые должны автоматически подключаться к документам указанного типа. Это значит, что при занесении документа такого типа в базу данных система присоединит к нему все файлы с именем главного файла документа и указанными расширениями (если таковые имеются). При этом все файлы должны размещаться в том же каталоге, что и главный файл документа. Например, если Вы используете гибридные чертежи, состоящие из DWG-файла и растровой картинки форматов BMP или GIF, то администратор может задать в списке расширений дополнительных файлов данного типа документов строку .BMP, .GIF. В этом случае если пользователи будут давать правильные имена файлам растровых картинок, то IPS автоматически будет преобразовывать документы такого типа в многофайловые.

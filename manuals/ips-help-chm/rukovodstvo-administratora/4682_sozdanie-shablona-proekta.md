# Создание шаблона проекта
Для создания нового шаблона проектов воспользуйтесь командой контекстного меню **Создать** в списке шаблонов проектов:
В появившемся окне требуется заполнить заголовок шаблона проекта, а также указать уровень доступа по умолчанию к проекту, который будет создаваться на основе данного шаблона.
Нажатием кнопки **Готово** завершите работу с мастером по созданию объектов.

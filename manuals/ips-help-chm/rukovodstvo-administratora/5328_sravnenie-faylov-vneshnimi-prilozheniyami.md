# Сравнение файлов внешними приложениями
Настройка вызова внешних приложений для сравнения файлов двух объектов по коменде**Сравнить / Файлы** или **Сравнить / Аутентичные файлы** доступна администраторам системы по адресу **Настройка / Параметры IPS / Система / Сравнение файлов**. Система обращается к этим настройкам тогда, когда ни один плагин не подписан на сравнение файлов указанных типов.
 – Добавление новой настройки.
 – Редактирование выделенной настройки. 
 – Удаление выделенной настройки.
 – Перечитывание настроек из базы данных.
При добавлении новой настройки открывается окно, в котором следует заполнить параметры настройки.
В качестве примера заполнения приведена настройка сравнения файлов программой WinMerge.
**Внимание!** В строке **Аргументы командной строки** надо указать строку, которая будет передаваться как командная строка в программу сравнения. Следует учесть, что в строке обязательно должны присутствовать значения подстановок для путей к сравниваемым файлам: %file1 и %file2. Маски расширений файлов, которые следует сравнить с помощью выбранной программы, указываются через точку с запятой.

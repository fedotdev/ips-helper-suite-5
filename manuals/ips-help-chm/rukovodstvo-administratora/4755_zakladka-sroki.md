# Закладка Сроки
Закладка **Сроки** отображается в свойствах действий типа **Задача** и **Утверждение**. Ее настройки предназначены для ограничения сроков выполнения данных типов действий или прочтения сообщений об этих действиях в почте. Здесь можно установить время, отведенное на прочтение или выполнение задачи исполнителем. Также здесь можно включить автоматический возврат действия, если текущая задача не была выполнена или прочитана в указанный срок. 
Задачи, для которых установлен срок выполнения, и этот срок не истек, помечаются в папке **Входящие** синим цветом. Задачи с истекшим сроком выполнения помечаются красным цветом.

Чтобы задать срок выполнения/прочтения для выбранной задачи, выполните следующие действия:
· С помощью кнопки вызовите диалог **Указание срока выполнения** и в списке возможных опций выберите нужную: 
− Период от начала выполнения действия.
В этом случае в диалоге появится специальное поле, в котором необходимо указать количество и единицу времени. 
− Взять из переменной типа **Дата.**
Позволяет указать срок выполнения из переменной типа **Дата**(если таковые имеются в списке переменных шаблона). Обычно в таком случае переменная заполняется при помощи пользовательской формы, и затем используется в качестве срока выполнения в конкретном действии.
Если переключатель **Возврат, если не выполнено в указанный срок** включен, то действие будет автоматически возвращено назад, если оно не было выполнено к этому сроку. Если же срок выполнения назначен, но переключатель не включен, то срок выполнения является сугубо информационным для пользователя: задачи с назначенным сроком выполнения отображаются в почте синим цветом, задачи с просроченным сроком – красным.
**Срок прочтения** задает срок, в течение которого сообщение должно быть прочитано получателем (помечено как прочитанное) и настраивается аналогично сроку выполнения, с той лишь разницей, что оно всегда должно сопровождаться возвратом.
Группа **Отсчет сроков** в зависимости от выбранного действия, предоставляется возможность установить необходимый отсчет сроков с помощью выбора одной из предложенных опций.
**Внимание!** Данная группа доступна при условии, что на закладке **Исполнители** , в группе **На данном шаге участвуют** , выбрана опция **Любой пользователь из списка**.

# Редактирование клеток заголовков входов таблицы
Поскольку условия для клеток входа часто совпадают, редактор таблиц позволяет задать условие на весь столбец (или всю строку). Выбор значения условия производится из контекстного меню по щелчку левой кнопкой мыши. Это условие действует по умолчанию, если в клетке не было задано своего условия. Например, на рисунке ниже оба столбца имеют условия по умолчанию **равно** и последний столбец, и строка – **меньше** или**равно**.

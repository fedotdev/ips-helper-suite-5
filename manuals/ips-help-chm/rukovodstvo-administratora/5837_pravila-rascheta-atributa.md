# Правила расчета атрибута
**Правила расчета атрибутов** – это служебный скрипт, который описывает поведение экспертной системы при расчете каждого параметра. При создании или изменении формул ЭС, таблиц или расчетных скриптов система автоматически создает необходимые правила расчета атрибутов и добавляет в них ссылки на измененные объекты. Правила расчета атрибутов определяют порядок применения объектов экспертной системы при попытке расчета атрибута, а также позволяют оптимизировать алгоритм расчета, временно исключить из расчета некоторые объекты, и так далее. 
При расчете атрибута, ЭС пытается загрузить конкретное правило расчета (для заданной пользователем комбинации **< Тип объекта>**.**< Тип атрибута>**) и только если такого правила нет, она будет искать общее правило (только для одного **< Тип атрибута>**).
**Внимание**! Если в базе каким-то образом окажется несколько правил расчета для одних и тех же атрибутов, то для расчета будет использоваться любое из них! Рекомендуется избегать таких ситуаций.
Создание нового правила расчета атрибута производится по команде **Создать**. В открывшемся окне необходимо указать атрибут объекта, который необходимо рассчитать.
После нажатия кнопки **ОК** откроется редактор командных скриптов ЭС. 
На рисунке выше показан пример правила расчета атрибута **Заготовка**. **Норма расхода**. В данном правиле присутствуют 5 формул для расчета нормы расхода разных видов заготовки. Условие на формулы в данном случае указаны в самих формулах, поэтому в правилах расчета они отсутствуют.
Редактирование скриптов будет описано в п. .
Описание операторов, применяющихся в скриптах правил расчета атрибута, будет дано в п. .

# Окно редактора форм ввода данных
При открытии формы ввода данных на редактирование закладка **Редактор форм** создаёт в главном меню новый пункт команд меню – **Форма**.
Меню **Форма** главной панели содержит следующие команды: 
· **Связать форму с** … Команда вызывает редактор привязки форм, который позволяет редактировать список типов объектов и связей, связанных с формой. 
· **Условие**. Команда открывает окно **Условие на форму** , в котором можно задать дополнительное условие, при котором форма будет отображаться пользователю.
· **Авторазмещение**. Эта команда предназначена для автоматического размещения на форме компонента **Текстовое поле** для отображения значения атрибутов. Выберите тип атрибута из списка соответствующих типов объектов и связей, которые привязаны к форме редактирования. 
Затем нажмите кнопку **Далее** и укажите положение данного компонента на форме (указываются координаты левого верхнего угла компонента).
После этого нажмите кнопку **Далее** , появится сообщение о добавлении на форму нужных компонентов, нажмите кнопку Завершить для подтверждения выполненной операции.
· **Выравнивание**. Доступно у компонентов **Текст** , указывает, как будет выравниваться текст, возможные значения: **По левому краю** , **По правому краю** , **По центру**.
· **Размер к**. Доступно, когда выделено несколько элементов. Позволяет задать выделенным элементам одинаковые размеры, высоту или ширину.
· **Горизонтальное расстояние**. Позволяет управлять расстоянием по горизонтали между несколькими выделенными элементами.
· **Вертикальное расстояние**. Позволяет управлять расстоянием по вертикали между несколькими выделенными элементами.
· **Центрирование**. Команда размещает компонент по центру относительно горизонтальной или вертикальной оси формы.
· **Порядок**. Если несколько компонентов на форме совмещены, то командами Поместить наверх, Поместить вниз можно определить положение компонента относительно остальных компонентов. Команда Последовательность включает режим, с помощью которого можно определить порядок переключения активности компонентов формы с помощью табуляции. 
· **Сбросить настройки рабочей области**. Команда позволяет сбросить все настройки панелей с компонентами (размеры, положение) в самом редакторе форм на умалчиваемые.
· По умолчанию возможность редактирования и создания форм доступна только пользователю **Системный администратор** , но, используя систему настройки прав доступа, он может назначить эти права другим пользователям системы. 
Дизайнер, проектирующий настраиваемые карточки объектов или документов (формы), может использовать различные визуальные компоненты, размещенные на панели инструментов. С их помощью можно отображать значения параметров, выводить текст, визуально группировать сходные по смыслу параметры и т.д.

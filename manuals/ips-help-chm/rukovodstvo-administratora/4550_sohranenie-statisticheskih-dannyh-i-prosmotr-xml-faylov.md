# Сохранение статистических данных и просмотр XML файлов
Система IPS позволяет сохранить статистику запросов на диске в виде отдельного файла в формате .xml. Эта возможность может быть полезной, например, в том случае, если статистику необходимо передать для изучения в службу технической поддержки «ИНТЕРМЕХ». Чтобы сохранить информацию окна, необходимо нажать кнопку **Сохранить** панели инструментов, в появившемся диалоговом окне указать путь сохранения файла на диске и присвоить имя файлу.
Кнопка **Просмотр XML файла** используется в основном службой технической поддержки системы. Она позволяет загрузить файл формата .xml для изучения статистик запросов, присылаемых различными пользователями системы. 
Чтобы загрузить в окно статистики XML файл, нажмите кнопку **Просмотр XML файла** и укажите путь к файлу. В результате этих действий в окно статистики загрузится информация с файла. Чтобы вернуться к статистике, ведущейся на вашем сервере, примените команду **Обновить** контекстного меню любой из ячеек таблицы или нажмите кнопку **Обновить** панели инструментов **Стандартный**.

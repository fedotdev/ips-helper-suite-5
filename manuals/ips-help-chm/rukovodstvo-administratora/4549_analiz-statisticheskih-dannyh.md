# Анализ статистических данных
По мере того, как пользователи производят операции над атрибутами, в колонках **Количество** и **Продолжительность** суммируются количество произведенных операций и их продолжительность. В зависимости от вида операции, произведенной над атрибутом: чтение, запись или поиск/сортировка, значения записываются в соответствующие колонки. Сравнив значения в колонках можно проанализировать, какой способ оптимизации более подходит для того или иного атрибута. При сравнении следует в первую очередь использовать колонку **Продолжительность** , т.к. она более полно отражает влияние оптимизации на быстродействие системы. Например, если преимущественная продолжительность операций приходится на чтение атрибута, то логично для этого атрибута задать значение **Чтение атрибута** для его свойства **Оптимизация операций**. 
При правильной настройке оптимизации операций, значения в колонках таблицы **Способ оптимизации** и **Рекомендуемый способ оптимизации** для одной строки должны совпадать. Если значения в колонках **Способ оптимизации** и **Рекомендуемый способ оптимизации** не совпадают, то они выделяются цветом, и это является признаком того, что при такой настройке свойства атрибута может снижаться быстродействие системы.
При несовпадении существующего значения, заданного для атрибута в свойстве **Оптимизация операций** , с результатами статистики разработчики системы рекомендуют изменить это значение в соответствии с полученными статистическими данными. Изменить значение свойства атрибута можно в окне **Конфигуратор базы данных**.
Администратор системы может изменять значения свойств атрибутов любых типов, кроме системных. (Способы оптимизации системных атрибутов могут быть изменены только разработчиками системы.) В связи с этим по умолчанию системные атрибуты не отображаются в таблице статистики запросов. Однако администратор системы может увидеть статистику по системным атрибутам, активировав кнопку панели инструментов окна статистики **Системные атрибуты**. Если в процессе изучения статистики окажется, что есть необходимость изменения способа оптимизации какого-либо из системных атрибутов, то следует обратиться в службу технической поддержки «ИНТЕРМЕХ».

# Применение внешнего редактора атрибута в форме редактирования
Внешний редактор можно использовать в формах редактирования данных. Для этого используется , у которого свойство**Действие** установлено в значение **Вызвать редактор**.
При этом у компонента доступно составное свойство **Параметры действия**. Первый его элемент – **Атрибут** , ссылается на один из типов атрибутов системы IPS. Второй элемент – **Внешний редактор** , является ссылкой на объект типа **Внешние редакторы атрибута**.

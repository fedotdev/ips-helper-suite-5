# Файловое хранилище временных файлов
Этой настройкой можно указать порталу в какой папке будут храниться временные файлы, создаваемые при импорте и экспорте объектов. По умолчанию этой папкой является **%appdata%\ IPS.**
**·Наименование:PortalFileStorage**
**·Значение: абсолютный путь к папке**
Например, **_< add key="PortalFileStorage_ _" value="D:\Temp\Portal"/ >_**__

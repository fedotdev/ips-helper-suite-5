# Область действия команды запуска приложений
Настройка инструментов может быть выполнена как для всех пользователей системы IPS, так и для конкретного пользователя (персональные настройки).
В окне настроек инструментов доступна панель **Область действия настроек**. По умолчанию включен режим **Общие настройки** , который означает то, что выполняемые настройки будут доступны всем пользователям.
Кнопка **Общие настройки** включает режим общих настроек. 
Кнопка **Персональные настройки** переключает область действия настроек на текущего пользователя. После нажатия данной кнопки все изменения в настройках будут доступны только для текущего пользователя IPS.
Кнопка **Другой пользователь** позволяет выбрать любого пользователя IPS, для того, чтобы сделать для него персональные настройки инструментов. Данная возможность доступна только пользователям, обладающими правами группы **Администраторы**. После нажатия данной кнопки будет отображено окно, в котором требуется выбрать пользователя:
После нажатия кнопки **ОК** настройки будут выполняться для выбранного пользователя.

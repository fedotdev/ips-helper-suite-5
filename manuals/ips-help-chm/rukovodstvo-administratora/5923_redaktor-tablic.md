# Редактор таблиц
· **Удаление использованных записей:** Данный параметр задает режим удаления использованных записей. Допустимые значения: 
− **Запретить удаление** – запрещает удаление записи;
− **Запрос перед удалением** – выдает запрос, перед удалением записи;
− **Разрешить удаление** – разрешает удаление.
Примечание: изменить значение может только пользователь с ролью **Администратор**.

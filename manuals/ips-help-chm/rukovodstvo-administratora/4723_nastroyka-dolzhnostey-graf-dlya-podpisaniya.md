# Настройка должностей, граф для подписания
Пользователям, которые будут осуществлять подпись объектов, назначаются определённые должности.
Назначение должностей осуществляется в свойствах учётной записи пользователя. Например, для пользователя SYSDBA назначим должность **Нормоконтролер**.
Требуется выбрать в списке должность **Нормоконтролер** и нажать **ОК**. Результат виден на рисунке:
Для должностей требуется настроить графы для подписей.
Для этого следует открыть страницу **Графы для подписи** у настраиваемой должности:
На странице доступна кнопка **Добавить**. По нажатию этой кнопки будет вызвано диалоговое окно, позволяющее выбрать типы объектов и графы для подписей, которые будут назначены выбранной должности:
После нажатия кнопки **Готово** можно увидеть следующий результат:
В приведенном примере пользователи с должностью **Нормоконтролер** могут выполнять подписание информационных объектов типов **Документы** и **Изделия** (с учетом наследования типов) в графе **Н. контр.**.

В контекстном меню вкладки **Графы для подписи** доступны следующие команды:
· **Добавить графу**(доступна для типа объекта) позволяет добавить в дерево графы для подписания для выделенного типа объекта.
· Команда **Удалить** удаляет выбранную ветку дерева.
· Команда **Очистить** удаляет дерево с настройкой граф целиком.
Примечание: при подписании информационного объекта система IPS ищет у данного объекта атрибуты с именем или кратким наименованием, совпадающие с графами, в которых осуществляется подписание. Если такие атрибуты будут найдены, в их значение будет вписана информация о пользователе, который поставил свою цифровую подпись (значение из атрибута **Фамилия пользователя в графах для подписи** учетной записи данного пользователя). 
Например, в описание объектов типа **Спецификации** добавлен атрибут **Н. контр.**. Соответственно, когда пользователь будет выполнять подпись в указанную графу, система IPS попробует записать в данный атрибут фамилию этого пользователя.
**Внимание!** Для таких атрибутов должна быть сделаны следующие настройки свойств:
· **Влияет на дату модификации содержимого объекта – нет** ;
· **Возможна модификация без взятия на изменение – да**.
Данные настройки требуются для того, чтобы при выполнении подписи не нарушалось содержимое подписываемого объекта, а также, чтобы у системы IPS не возникло проблем с записью фамилии подписывающего в соответствующий атрибут, без необходимости брать подписываемый объект на изменение.

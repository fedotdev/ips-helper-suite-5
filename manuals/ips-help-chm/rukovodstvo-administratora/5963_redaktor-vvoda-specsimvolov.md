# Редактор ввода спецсимволов
Для удобной работы редактора ввода спецсимволов можно настроить параметры по пути **Настройка / Параметры IPS / Пользователь / Текущий пользователь / Настройки спец.символов**.
Пользователю доступны следующие настройки:
· **Настройки избранных спец.символов**. Таблица, в которой предоставляется возможность задать параметры **Горячая клавиша** и **Иконка** для каждого избранного спец.символа.
· **Общие настройки**. Параметр **Отображать в меню** позволяет задать способ отображения спец.символов в контекстном меню. Параметр **Отображать на панели** позволяет задать способ отображения спец.символов в панели инструментов.

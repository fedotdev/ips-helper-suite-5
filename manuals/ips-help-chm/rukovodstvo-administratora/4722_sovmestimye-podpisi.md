# Совместимые подписи
Совместимые подписи в IPS – это усиленные подписи, обеспечивающие подписание исключительно файлов объекта, содержащихся в атрибуте **Файл** подписываемого объекта. 
IPS начинает подписывать объекты совместимыми подписями после установки настройки **Совместимые подписи** в значение **Да**. Данные подписи совместимы с подписями Search и могут быть сохранены на внешние носители при указании в клиенте IPS команды **Сохранить на диск**. 
Если объект не содержит атрибут **Файл** или отсутствуют файлы для подписания, то объект подписывается обычной усиленной подписью.

# Экспорт базы данных
Экспорт всей базы данных выполняется по команде меню клиента IPS **Экспорт/Импорт/Портфель/Экспорт базы данных**. 
Папка, в которую будет производиться экспорт, указывается в поле **Расположение портфеля**.
Если указан переключатель **Серверное размещение портфеля** , то в поле **Расположение портфеля** указывается папка на машине с сервером приложений IPS.
Переключатель **Только системные данные** дает возможность указать, экспортировать ли все данные или только системные. Под системными данными понимаются системные объекты (напр. объект роли **Администраторы**) и системные метаданные.
Переключатель **Экспорт информации о локализации** не влияет на содержимое портфеля при экспорте: выключенный переключатель указывает на то, что при импорте данные будут внесены в базу-приемник независимо от языка по умолчанию в ней. При включенном переключателе в базу-приемник будут импортированы только те данные, которые соответствуют по настройкам языковых вариантов. 
Переключатель **Подробный лог** позволяет повысить детализацию лог-файла, создаваемого в папке с портфелем. Скорость создания портфеля при этом может снизиться. 
В поле **Комментарий** можно указать комментарий к получаемому портфелю.

# Настройка приема внешней электронной почты
Для зарегистрированных в системе учетных записей внешней электронной почты (см. п. ) модуль документооборота предоставляет автоматический прием входящих сообщений. Настройка расписания процесса приема осуществляется следующим образом:
· С помощью пункта главного меню **Настройка / Параметры IPS** вызовите диалог **Параметры**
· В левой части диалога **Параметры** перейдите на строку **Система \ Электронная почта \ Расписание приема почты**. 
В правой части диалога располагается настройка расписания приема почты. Необходимо указать имя компьютера, на котором запущен текущий сервер приложений, и, при необходимости, установить флаг удаления входящих сообщений с почтового сервера после импорта их в базу IPS.
Периодичность приема почты задается в минутах. Можно настроить прием только в рабочее время, установив соответствующую галку. Рабочее время в этом случае определяется исходя из указанного календаря.

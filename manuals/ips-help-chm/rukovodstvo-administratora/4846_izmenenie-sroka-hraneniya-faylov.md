# Изменение срока хранения файлов
Для файлов истории и удалённых файлов существует срок хранения. При удалении мусора файлы, срок хранения которых превышает указанный, будут удалены. Срок хранения указывается в днях. Значение «0» – снимает ограничение на срок хранения файлов.
По умолчанию срок хранения удалённых файлов 365 дней, срок хранения файлов истории не ограничен. Для изменения срока хранения выберите свойства **Срок хранения файлов истории, дн.** или **Срок хранения удалённых файлов**.

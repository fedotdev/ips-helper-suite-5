# Настройка процесса автоматической отправки письма
Для автоматической отправки писем пользователями по команде контекстного меню **Канцелярия/Запустить процесс отправки** , необходимо настроить данные: адрес электронной почты и пользователь-отправитель, от имени которого эти письма будут отправляться. Настройка осуществляется в настройках IPS: **Настройка / Параметры IPS** на закладке **Канцелярия/Общие**.
Адрес электронной почты должен быть зарегистрирован в системе, а также назначен пользователю-отправителю (см. п. ). Также здесь можно поменять шаблон, по которому будут создаваться процессы для отправки писем. Для корректной работы процесса отправки письма новый шаблон должен содержать переменные и текст скрипта, такие же, как у действия **Отправка почты** шаблона **Шаблон процесса автоматической отправки почты**.

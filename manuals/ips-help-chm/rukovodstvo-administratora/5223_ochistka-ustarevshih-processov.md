# Очистка устаревших процессов
Настройки этой подгруппы позволяют установить режим очистки устаревших процессов.
Установка флажка в строке **Включить чистку устаревших** **процессов** автоматически предоставляет доступ к настройкам времени устаревания процессов.
Временной промежуток, после которого процессы будут удалены, следует задать в строке **Поле** , где необходимо указать цифру с помощью счетчика и единицу времени с помощью выпадающего списка. А выбор статуса удаляемых процессов следует указать с помощью установки флажка в строке **Выполненные** и/или **Прерванные**.
**Внимание!** Очистка устаревших процессов будет проведена в соответствии с настройками при выполнении задачи **Удаление устаревших данных** планировщика задач. 
**Внимание!** При поиске удаляемых процессов проводится сравнение даты выполнения процессов (атрибут **Выполнено**), а также требуемого статуса (атрибут **Статус действия**) с заданными настройками в параметрах IPS.

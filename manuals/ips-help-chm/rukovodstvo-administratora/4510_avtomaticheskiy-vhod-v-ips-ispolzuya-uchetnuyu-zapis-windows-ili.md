# Автоматический вход в IPS, используя учетную запись Windows или Active Directory
В IPS можно включить режим авторизации, который позволит загружать клиента системы без необходимости ввода пароля. В этом случае авторизация будет производиться по логину пользователя в Windows (если в IPS будет пользователь с соответствующим именем входа в систему) либо по идентификатору пользователя в Active Directory (SID) (если в IPS будет зарегистрирован пользователь с таким SID). 
Для включения режима авторизации по логину следует вписать в секцию **< appSettings>** конфигурационного файла сервера приложений IPS следующую строку:
· **< add key="WindowsLogin" value="1"/>**
Если в базе IPS пользователь с таким именем входа найден не будет, то система предложит ввести имя и пароль в обычном диалоге авторизации IPS. 
Режим входа по логину не безопасен, т.к. при наличии соответствующих прав пользователь может на своей рабочей станции завести локального пользователя с именем входа другого (доменного) пользователя Windows и зайти в IPS с чужим логином. Поэтому более безопасным является режим входа по идентификатору пользователя в службе каталогов Windows. Для включения этого режима следует вписать в секцию **< appSettings>** конфигурационного файла сервера приложений IPS следующую строку:
· **< add key="WindowsLogin" value="domain"/>**
В этом режиме система идентифицирует пользователей не по логину, а по идентификатору пользователя в службе каталогов Active Directory. Для такой идентификации пользователя необходимо наличие у него в IPS атрибута SID, который автоматически заполняется системой при импорте пользователей из службы каталогов Active Directory. Даже если в различных службах каталогов логины пользователей совпадают – их SIDы различаются, поэтому такой способ авторизации гораздо более безопасный. 
Если же система не смогла идентифицировать пользователя по его идентификатору в службе каталогов Active Directory, то система запросит логин пользователя через диалог входа в IPS. 
Также имеется возможность полностью запретить системе запрашивать логин пользователя. Для этого следует вписать в секцию **< appSettings>** конфигурационного файла сервера приложений IPS следующую строку:
· <**add key="WindowsLogin" value="domain_only"/ >**
**Внимание!** Способы авторизации можно обмануть, если пользователь Windows оставил свой незаблокированный компьютер без присмотра.

# Удаление мусора
При удалении мусора из корневого хранилища удаляются все файлы с истёкшим сроком хранения (см. п. ). Для удаления мусора необходимо выбрать корневое хранилище в дереве и нажать кнопку . 
Примечание: если необходимо выполнить удаление мусора во всех корневых хранилищах, созданных службой, необходимо нажать кнопку для корневого элемента дерева хранилищ.

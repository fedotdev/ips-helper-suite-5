# Импорт метаданных
При импорте **Портфеля** с метаданными система сопоставляет метаданные в портфеле и базе-приемнике и отображает результаты сравнения в отдельном окне.
Результаты сравнения имеют следующие разделы:
· **Добавлены** – отображаются метаданные и объекты, которые есть в портфеле, но их нет в базе-приемнике.
· **Изменены** – отображаются метаданные и объекты, которые отличаются в базе-приемнике. В измененные должны попасть метаданные и объекты, у которых различается содержимое в базе-источнике и базе-приемнике.
· **Удалены** – отображаются метаданные и объекты, которые были удалены на базе-источнике (есть в базе-приемнике, но нет в портфеле). 
В интерфейсе результатов сравнения должны отображаться только те параметры, значения которых различаются в **Портфеле** (базе-источнике) и базе-приемнике.
Пользователь имеет возможность добавить некоторые метаданные в исключения. Для объектов в рабочей области и для элементов в дереве **Навигатора** это следующие команды контекстного меню:
· **Исключить из импорта** – команда, которая исключает конкретное метаданное (объект или свойство) из импорта, при этом визуально отмечает исключение цветом. Если команда выполняется в дереве, то все дочерние метаданные исключаются из импорта и отображаются цветом. 
Исключенные метаданные отображается в отдельном окне, где пользователь имеет возможность просмотреть и при необходимости отменить исключение.
Примечание: все исключенные из импорта метаданные хранятся в файле .config, который сохраняется в рабочую папку IPS. 
· **Отменить исключение** – команда, которая отменяет команду исключение из импорта убирает.
Примечание: пользователь имеет возможность добавить в исключения любое свойство до последнего уровня.
Перед импортом портфеля система проводит анализ метаданных на возможность импорта. При обнаружении системой ошибок у пользователя появляется окно с ошибкой или предупреждением. Пользователь имеет возможность исключить из импорта проблемные метаданные по команде **Исключить из импорта**. 
Примечание: если окно с ошибкой и импорт невозможен, то в исключения команда добавляет сам тип объекта, связи или атрибут. 
Примечание: если окно с предупреждением, то в исключения добавляется конкретное проблемное свойство.
Например, если нет возможности изменить тип атрибута (ошибка), то пользователь может добавить этот атрибут в исключения и не импортировать его. После исправления конфликта в метаданных, пользователь имеет возможность убрать атрибут из исключений и выполнить повторный импорт.
Созданные конфигурации списков исключений для импорта метаданных можно сохранить в файл .config в рабочую папку IPS. Для этого следует вызвать команду **Файл\Сохранить изменения**. При запуске импорта портфеля, этот файл автоматически зачитывается и в интерфейсе сравнения метаданных отображаются исключенные свойства или объекты из этого файла.
Для устранения конфликтных ситуация при импорте **Портфеля** создается лог-файл, в котором отображается информация об импортированных метаданных: добавлены, изменены, удалены, а также конфликты импорта, с информацией о причинах конфликта.

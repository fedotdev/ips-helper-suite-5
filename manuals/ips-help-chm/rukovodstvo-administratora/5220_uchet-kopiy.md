# Учёт копий
Данный список представляет собой лист рассылки по умолчанию для документов данного типа. В листе регистрируются абоненты, которым должны быть разосланы копии документа после его регистрации в ОТД (см. ). Этим же абонентам будут рассылаться копии изменённого документа после регистрации изменённой версии в ОТД. Указанный список абонентов используется системой для начальной инициализации листа рассылки документа, после чего в лист рассылки каждого документа можно вносить изменения в соответствие с требованиями данного документа.

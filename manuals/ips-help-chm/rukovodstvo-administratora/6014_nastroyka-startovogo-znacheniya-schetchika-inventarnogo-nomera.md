# Настройка стартового значения счетчика инвентарного номера
В автоматической генерации инвентарного номера ОТД предоставляется возможность задать стартовое значение счетчика инвентарного номера. Для этого следует указать в шаблоне через двоеточие неотрицательное число. Например: {T999:0}, {9999:15}.
**Внимание!** Если администратор задаст стартовое значение счетчику, то старый счетчик сбросится и отсчет начнется от нового заданного значения счетчика. При этом система будет учитывать уже созданные по текущей формуле инвентарные номера. При сбросе стартового значения для типа в {T999:0} если в системе есть объекты соответствующего типа (или наследующего формулу подтипа) с номерами 001 и 002, счетчик автоматически установится в 003.

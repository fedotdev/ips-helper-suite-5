# Фильтрация содержимого файловых шкафов
Файловый шкаф может содержать огромное множество файлов, среди которых непросто сориентироваться и найти необходимые файлы. Система IPS предлагает использовать механизм фильтрации списка файлов, позволяющий отфильтровывать списки, оставляя только те файлы, которые соответствуют заданным условиям. Настройка фильтрации осуществляется в специальном диалоговом окне, которое можно открыть, используя кнопку , расположенную на панели инструментов закладки **Список объектов**.
Диалог позволяет задать следующие условия фильтрации:
· **Имя файла содержит подстроку**. Позволяет ввести символы, содержащиеся в именах искомых файлов. Регистр букв значения не имеет. Следует отметить, что вводить необходимо не шаблон строки, а саму строку. Это значит, что если требуется найти все файлы с расширением DWG, то нужно в поле ввести строку **.dwg** , а не ***.dwg**.
· **Комментарии содержат подстроку**. Позволяет ввести символы, содержащиеся в комментариях к искомым файлам.
· **Фильтр по размеру**. Активизируется с помощью переключателя, расположенного внизу фильтра. Позволяет указать диапазон размеров файлов. В результате применения данного фильтра, в списке останутся только те файлы, размеры которых соответствуют заданному диапазону.
· **Фильтр по датам**. Активизируется с помощью переключателя, расположенного внизу фильтра. Позволяет ввести временной диапазон. В результате применения данного фильтра, в списке останутся только те файлы, дата обновления которых соответствует указанному временному диапазону.
Если к списку был применен фильтр, то на кнопке, вызывающей диалог настройки фильтрации, появится дополнительная надпись, и кнопка будет выглядеть следующим образом: .
Чтобы удалить условия фильтрации, нужно удалить значения из полей ввода или выключить переключатели. Также очистить фильтр можно с помощью кнопки **Очистить** , в результате чего очистятся все поля фильтра.

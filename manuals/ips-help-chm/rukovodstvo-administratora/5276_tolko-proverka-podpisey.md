# Только проверка подписей
Установленный флажок в строке **Только проверка подписей** позволяет включить режим автоматического выполнения без рассылки исполнителям, при котором действие только проверяет набор необходимых подписей. При наличии подписей выполнение процесса будет автоматически продвинуто вперед, при их отсутствии – возвращено назад.
При установленном флажке в строке **Проверять подписи, используя настройки действий…** позволяет унаследовать настройки для проверки подписей из указанных действий.
**Внимание!** Для действий, которые не выполнялись, подписи контролироваться не будут.

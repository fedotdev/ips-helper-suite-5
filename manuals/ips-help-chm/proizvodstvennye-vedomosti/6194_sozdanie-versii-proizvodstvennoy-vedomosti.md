# Создание версии производственной ведомости
Модуль **Модуль для работы с ведомостями Intermech.MRP2** предоставляет возможность создавать версии производственной ведомости. Подробная информация о версии объекта можно прочесть в .
Для создания версии ПВ следует из контекстного меню производственной ведомости выбрать команды **Создать / Версию**.
Для просмотра всех существующих в системе версий производственной ведомости следует воспользоваться кнопкой Версии объекта, которая расположена на панели инструментов или вызвать команду **Дерево версий объекта** из контекстного меню в редакторе производственной ведомости. В открывшемся окне пользователю доступно для просмотра дерево версий производственной ведомости, в котором отображены все имеющиеся версии ведомости.

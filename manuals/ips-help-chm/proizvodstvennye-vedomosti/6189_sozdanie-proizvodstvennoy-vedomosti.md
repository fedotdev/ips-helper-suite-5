# Создание производственной ведомости
Примечание: перед началом создания производственной ведомости, пожалуйста, ознакомьтесь с гл. данного руководства.
Для создания производственной ведомости следует:
1\. В дереве **Навигатора** найти тип объекта **Объекты производственной ведомости** / **Производственная ведомость** и из контекстного меню вызвать команду **Создать**.
2\. Для продолжения создания объекта, в открывшемся окне следует выбрать необходимый классификатор и нажать кнопку .
3\. При корректном выборе классификатора, строка **Обозначение ПВ** заполняется автоматически, в противном случае следует нажать кнопку в строке **Обозначение ПВ** , смотрите на рисунке ниже:
4\. Далее пользователь может заполнить все необходимые поля и строки в соответствие внутренней инструкции предприятия. Подробное описание строк представлено в п. .
5\. При необходимости автоматически открыть создаваемую ведомость в режиме редактирования пользователь может выбрать дополнительные условия в низу диалога создания объекта.
6\. После заполнения карточки производственной ведомости для сохранения изменений следует нажать кнопку .
**Внимание!** Список выходных сборок заполняется в редакторе производственных ведомостей.

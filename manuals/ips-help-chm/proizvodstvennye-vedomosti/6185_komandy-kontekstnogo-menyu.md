# Команды контекстного меню
Описанные выше кнопки, которые расположены на панели инструментов, продублированы в контекстном меню производственной ведомости в виде команд. Контекстное меню дополнено новыми командами, которые необходимы для работы с производственной ведомостью.
Примечание: далее будут описаны по тематическим группам команды, которые отображены в контекстном меню, относящиеся непосредственно к работе с ПВ.

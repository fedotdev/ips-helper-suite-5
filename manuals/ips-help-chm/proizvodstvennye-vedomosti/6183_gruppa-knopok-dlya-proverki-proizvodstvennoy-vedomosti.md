# Группа кнопок для проверки производственной ведомости
 **Пересчитать количества** – кнопка, которая позволяет пересчитать количество при работе с изменениями в объектах. В п. описан пример применения данной кнопки.
 **Запустить проверку ЭС ПВ** – кнопка, которая позволяет запустить механизм проверки электронной структуры производственной ведомости. Данную кнопку следует применять после проведенных изменения ПВ и ее составом. 
 **Запустить процесс для производственных ведомостей** – кнопка, которая позволяет запустить процесс для ПВ. Подробная работа с документооборотом описана в .

# Настройка модуля
**Внимание!** Настройка модуля работы с производственной ведомостью осуществляется пользователем с правами системного администратора.
Для работы с модулем следует настроить ряд параметров, чтобы настроить их все следует перейти открыть команду **Параметры IPS / Система / Подготовка производства (MRP) / Настройки производственных ведомостей**. На рисунке ниже показано окно с параметрами:
1\. В поле **Сценарий для проверки производственной ведомости:** следует нажать кнопку .
2\. В открывшемся окне необходимо выбрать из списка **Сценарий для проверки ЭС ПВ** и нажать кнопку .
Примечание: для расчета количества в ведомости в модуле встроен сценарий, однако пользователь имеет возможность написать новый сценарий, который соответствует внутренним требованиям предприятия. 
3\. В поле **Максимальный номер ведомости:** следует указать максимально допустимый номер, который может быть назначен ведомости. 
4\. В группе параметров **Настройка сравнения атрибутов копий и изделий** следует настроить атрибуты сравнения связанных записей. Это необходимо для корректной работы механизма сравнения атрибутов при сравнении ведомостей. 
В группе **Настройка сравнения атрибутов копий и изделий** пользователю доступны следующие кнопки:
 – кнопка, с помощью которой предоставляется возможность добавить атрибут объекта, как для копии, так и для изделия.
При выборе атрибута название окна со списком атрибутов меняет свое название, тем самым помогает пользователю отследить, в какую именно колонку будет добавлен указанный атрибут. На рисунке ниже показан принцип работы команды **Добавить атрибут объекта** :
Результат:
 – кнопка, с помощью которой предоставляется возможность добавить атрибут связи, как для копии, так и для изделия.
 – кнопка, с помощью которой можно удалить добавленные атрибуты, как для копии, так и для изделия вместе. Удаление атрибутов осуществляется посредствам выделения необходимой строки в таблице.

# Администрирование ЭС ПВ
Система обеспечивает дифференцирование прав доступа к объектам ЭС ПВ на различных этапах конструкторской и технологической подготовкой производства путем перемещения объектов ЭС ПВ по шагам ЖЦ. Схема ЖЦ и свойства отдельных шагов доступны для настройки администратором. В системе должна быть настроена следующая схема ЖЦ для ПВ:
**Разработка** → **Согласование** → **Расцеховка** → **ТПП** → **Производство** → **Хранение** → **Удаление**
При добавлении объекта в состав ПВ, в окне выбора версии для каждого типа изделия, администратор имеет возможность настроить следующие выборки: версии на дату (подбор версии объекта, который перешел на указанный шаг ЖЦ в указанный диапазон дат), все версии, версии по извещению (служебной записке).

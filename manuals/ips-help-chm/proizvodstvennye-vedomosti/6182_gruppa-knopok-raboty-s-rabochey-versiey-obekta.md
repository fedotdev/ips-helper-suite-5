# Группа кнопок работы с рабочей версией объекта
 **Взять на редактирование** – кнопка, которая позволяет взять на редактирование выделенный объект. При нажатии на кнопку объекту назначается статус рабочей копии.
 **Завершить редактирование** – кнопка, которая позволяет сохранить изменения, внесенные в рабочую копию, и вернуть рабочую копию в обычный статус объекта. 
 **Отменить изменения** – кнопка, которая позволяет отменить изменения, внесенные в рабочую копию объекта.
 **Подписать** – кнопка, которая позволяет подписать производственную ведомость с помощью внутренних средств IPS.

 **Версии объекта** – кнопка, которая позволяет просмотреть список со всеми существующими версиями выбранного объекта.

# Создание производственной ведомости по прототипу
Возможности модуля позволяют пользователю создавать производственные ведомости по прототипу. При создании ПВ по прототипу, в новую ведомость копируются значения всех атрибутов конструкторской части ведомости-прототипа. Помимо атрибутов, копируются неуникальные объекты, которые входят в состав ведомости-прототипа на первом уровне. Неуникальные объекты входят в состав новой ведомости со всем своим составом с копированием значений всех атрибутов связей.
Примечание: значения атрибутов могут скопироваться при условии, что в настройках системы значение свойства **Запрет копирования значения у прототипа** отключено.
**Внимание!** Если в составе производственной ведомости-прототипа находятся уникальные объекты, то система копирует их в ПВ, как новые уникальные объекты. 
Для того чтобы создать производственную ведомость по прототипу следует:
1\. Выделить ведомость-прототип и воспользоваться кнопкой , которая находится на панели инструментов. 
2\. В открывшемся окне следует заполнить карточку новой производственной ведомости. 
3\. Для завершения процесса создания ПВ по прототипу необходимо нажать кнопку .

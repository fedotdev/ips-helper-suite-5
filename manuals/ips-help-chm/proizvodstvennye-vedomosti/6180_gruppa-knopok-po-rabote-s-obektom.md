# Группа кнопок по работе с объектом
 **Свойства (Карточка)** – кнопка, которая позволяет открыть карточку выбранного объекта.
 **Развернуть все** – кнопка, которая позволяет развернуть состав выбранного объекта.
 **Свернуть** – кнопка, которая позволяет свернуть состав выбранного объекта.
 **Найти в дереве** – кнопка, которая запускает механизм поиска объекта по заданным условиям. Подробное описание работы команды поиска представлено в .

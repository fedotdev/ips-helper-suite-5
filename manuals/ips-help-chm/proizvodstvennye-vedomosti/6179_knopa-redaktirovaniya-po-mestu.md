# Кнопа редактирования по месту
 **Режим редактирования** – кнопка, которая позволяет осуществить редактирование некоторых атрибутов объекта напрямую из списка дерева состава производственной ведомости.
**Внимание!** Режим редактирования по месту доступен только при условии, что кнопка на панели инструментов нажата. На рисунке ниже показана разница отображения включенного и выключенного режима.
**Внимание!** При изменение значения атрибута непосредственно с помощью ввода данных на клавиатуре или при выборе условия из выпадающего списка, следует подтвердить указанное значение нажатием клавиши **[Enter]**. Во всех остальных случаях подтверждение изменения данных реализуется в диалоговом окне через кнопку .

# Группа кнопок для фильтрации состава
 **Фильтр состава по типам объектов** – кнопка, которая позволяет вызывать список всех имеющихся фильтров. В открывшемся диалоге предоставляется возможность выбрать необходимый фильтр.
 **Настройка фильтров составов по типам объектов** – кнопка, по которой осуществляется вызов диалогового окна **Фильтрация состава по родительским и дочерним типам объектов**. В данном окне предоставляется возможность создать фильтр состава объекта.
Работа с фильтрацией состава подробно описана в 
**Фильтровать документы** – кнопка, которая позволяет в окне выбора параметров объектов скрыть документы (подробное описание представлено в гл. в описании последовательности действий добавления в состав производственной ведомости изделий, узлов или деталей п.п. 3.1), из состава изделия по связи **Документация на изделие** и у которых атрибут **Раздел спецификации** = **Документация**.

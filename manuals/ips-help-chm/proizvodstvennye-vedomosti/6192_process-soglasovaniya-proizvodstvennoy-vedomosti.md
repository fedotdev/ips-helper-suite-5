# Процесс согласования производственной ведомости
Пользователю предоставляется возможность отправить ПВ на согласование по бизнес-процессу. Для этого следует:
1\. Завершить редактирование ПВ.
2\. Вызвать из контекстного меню команду **Запустить процесс для ПВ**.
Для отправки ПВ на согласование по бизнес-процессу можно воспользоваться кнопкой на панели инструментов или на главном меню выбрать **Процессы / Запустить процесс / Выбрать.**
3\. В открывшемся окне **Запуск процесса – Согласование КД** следует выбрать необходимый шаблон процесса и нажать кнопку .
4\. При необходимости можно добавить текст сообщения и выставить приоритет запускаемого процесса.
5\. В следующем окне предоставляется возможность проверить вложения к запускаемому процессу.
6\. Для отправки процесса следует нажать кнопку .

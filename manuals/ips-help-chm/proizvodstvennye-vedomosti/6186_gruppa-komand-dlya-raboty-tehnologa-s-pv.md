# Группа команд для работы технолога с ПВ
 **Добавить** – команда, которая позволяет добавить техпроцесс, заготовку, маршрут обработки и расцеховочный маршрут и т.д..
Подробное описание добавления технологических объектов представлено в .
 **Создать по ПВ-аналагу** – команда, которая позволяет создать расцеховочный маршрут и заготовку по прототипу с ведомости-аналога.
Примечание: при создании расцеховочного маршрута по прототипу с ведомости-аналога в создаваемый расцеховочный маршрут скопируются значения всех атрибутов прототипов.

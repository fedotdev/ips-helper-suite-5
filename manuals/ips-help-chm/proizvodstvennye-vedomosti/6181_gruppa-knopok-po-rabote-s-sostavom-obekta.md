# Группа кнопок по работе с составом объекта
 **Добавить в состав объекты ПВ** – кнопка, с помощью которой предоставляется возможность добавить изделия в состав производственной ведомости, на базе которых будут созданы выходные сборки.
Примечание посредством кнопки можно включить в состав объекты типа **Узлы и детали**. 
**Внимание!** Список возможных для добавления типов объектов настраивается пользователем с правами администратора системы IPS.
Нажатие кнопки **Добавить** **в состав объекты ПВ** позволяет открыть диалоговое окно, в котором предоставляется возможность выбрать версию изделия (детали, стандартного изделия, сборочной единицы, комплекса, комплекта, узлов и деталей).
Примечание: в окне выбора версии изделия для каждого типа изделия администратором системы могут быть настроены следующие возможные выборки: **Версии на дату** (подбор версии объекта, который перешел на указанный шаг ЖЦ в указанный диапазон дат), **Все версии** , **Версии по извещению** (служебной записке).
При выборе изделия (группы изделий) система запрашивает у пользователя метод обработки/поставки изделия. 
При выборе **Входной контроль** , **Консервация** или **Испытания** , система создает входную сборку и автоматически отмечает все объекты состава сборки, как исключенные, а также заполняет атрибут **Метод обработки/поставки**.
Если добавляемое изделие имеет состав и выбран метод – **Изготовление** , то система отображает пользователю окно, в котором предоставляется возможность указать правило подбора версий объектов состава извещения и опции конфигуратора. Для группы изделий система выдает отдельный запрос по каждому изделию правило подбора версий и опций конфигуратора. Для групповых изделий реализованы следующие правила подбора версий: базовые (актуальные) версии, последние версии, версии на дату, серии и даты.
**Внимание!** Панель с настройками подбора по сериям и датам отображается только при условии включенной настройки **Разрешить подбор по сериям и датам**.
**Внимание!** Панель с настройками подбор по сериям и датам отображается только при условии включенной настройки **Разрешен конфигуратор составов**. 
1\. **Подбор базовых версий**
В области подбора базовой версии находятся три кнопки: **Выбрать…** , **Текущее** , **По умолчанию**. 
Кнопка **Выбрать** – кнопка, которая позволяет применить правило из списка существующих в системе правил подбора версий.
Подробное описание по работе с правилами подбора версий представлено в и .
Кнопка **Текущее –** кнопка, которая устанавливает правило, выбранное на данный момент.
Кнопка **По умолчанию –** кнопка, которая позволяет установить правило подбора версий по умолчанию, это то правило, которое настроено в параметрах IPS.
**2\. Выберите контекст редактирования**
При выборе контекста редактирования пользователь может воспользоваться следующими командами:
· **Выбрать** – команда, которая позволяет выбрать извещение или контекст редактирования из списка, существующих в системе. 
· **Текущий** – команда, которая позволяет установить контекст, активный на данный момент.
· **Очистить** – команда, которая позволяет подобрать объекты вне контекста редактирования.
Подробная информация о подборе по контексту редактирования представлена в .
**3\. Выбор контекста, в рамках которого будут отображаться составы:**
Выбранные параметры в списке позволяют указать необходимое отображение состава добавляемого изделия в том контексте, в котором необходимо пользователю.
После подтверждения выбора правила подбора версий система запрашивает изделия для каждой группы допустимых замен в развернутом виде, которые добавлены в состав производственной ведомости. Пользователю предоставляется возможность выбрать для добавления актуальный заменитель, допустимый заменитель или все заменители. 
Примечание: в системе реализована возможность копирования информации о конструкторских допустимых заменах в производственную ведомость. 
 **Добавить объект из состава другой ПВ** – команда, которая позволяет добавить элементы из состава другой производственной ведомости, в текущую ведомость. Система не переносит выбранный элемент из состава одного ПВ в другую, система копирует выбранный элемент.
Примечание: если указанный элемент ПВ неуникальный, то система создает связь с тем же объектом, если же указанный элемент ПВ уникальный – создается новая производственная копия.
Примечание: если в качестве указанного элемента была выбрана производственная копия сборочной единицы, то система преобразует копию в выходную сборку.
 **Заменить объект** – команда, которая позволяет заменить выбранный объект в составе производственной ведомости на другой из списка. 
Примечание: объект, который заменили, автоматически приобретает статус исключенного из состава производственной ведомости.
 **Исключить из состава** – команда, которая позволяет исключить указанный объект из состава производственной ведомости. 
**Внимание!** Для выполнения команды родителький объект должен быть взят на редактирование.
Команда исключает выбранное изделие из состава ПВ. При этом связь исключаемого изделия с родительким объектом получает атрибут **Признак исключения** и заполняется атрибут **Номер версии ПВ**. 
Примечание: в интерфейсе редактора производственной ведомости исключенный объект отображается, как зачеркнутый. Если исключается сборочная единица, комплекс или комплект, то состав удаляется полностью из списка.
Исключенные из состава ПВ объекты можно скрыть из списка в девере, для этого необходимо использовать кнопку на панели или команду **Состав объекта/Скрыть удаленные позиции** из контекстного меню. Описание команд контекстного меню подробно представлено в п. .
 **Указать производственную ведомость** – команда, которая позволяет указать производственную ведомость для производственной копии. 
В открывшемся диалоговом окне, пользователь может выбрать необходимую производственную ведомость. Далее в составе работающей ПВ выбранная копия имеет значение атрибута **Ссылка на ПВ** в соответствии с указанной производственной ведомостью. А значение атрибута **Поставляется отдельно** можно откорректировать, воспользовавшись командой **Состав объекта** **/** **Изменить способ поставки** из контекстного меню производственной копии или воспользоваться кнопкой **Режим редактирования** и скорректировать данные по месту:
**Внимание!** При использовании команды **Изменить способ поставки** на производственную копию**,** объект останется в составе производственной копии. Однако если команду **Изменить способ поставки** применили для объекта с составом, то состав родительского объекта будет исключен ил состава производственной копии и добавлен в состав выбранной ПВ.
После применения команды **Изменить способ поставки** пользователь может скорректировать необходимые данные в карточке объекта, например: изменение количества для объекта из состава ПВ, настроить допустимые замены (подробное описание, как реализуется данное действие представлено в ) и т.д..
Примечание: следует помнить, что при изменении атрибута **Количество** , требуется выполнить пересчет количества по всей производственной ведомости с помощи команды **Пересчитать количества** из контекстного меню ПВ или воспользоваться кнопкой на панели инструментов редактора ПВ.
**Внимание!** После осуществления всех необходимых изменений следует запустить механизм автоматизированного контроля состава производственной ведомости, для этого следует нажать кнопку на панель инструментов или воспользоваться командой **Запустить проверку ЭС ПВ** из контекстного меню ПВ.
 **Создать по прототипу** – кнопка, которая позволяет создать производственную ведомость по прототипу. 
**Внимание!** При использовании кнопки значение всех атрибутов конструкторской части ведомости-прототипа копируются, для которых в настройках системы не установлен запрет для копирования, например: **Обозначение ПВ** , **Обозначение ПЗ** , **Заказ** и т.д.. 
Примечание: настройка **Запрет копирования значения у прототипа** устанавливается системным администратором. 
Неуникальные объекты, входящие в состав ведомости-прототипа, на первом уровне входят в новую ведомость со всем своим составом и со всеми атрибутами связей, значение для которых не меняется при условии, что в настройках системы запрет на копирование значения у прототипа отключен. А уникальные объекты – система копирует в новые уникальные объекты.

# Перечень файлов данных XML
| **Имя файла** | **Содержание** |
| --- | --- |
| MetadataBrief.xml | Краткое описание метаданных (типов объектов, связей, атрибутов/параметров) |
| Objects.xml | Данные об объектах, включая атрибуты/параметры |
| Relations.xml | Данные о связях, включая атрибуты/параметры |
Примечание: имена файлов с данными объектов и связей, могут отличаться от выше приведенных.
В файлах обмена, в качестве дополнительной информации, идентификаторы могут быть указаны в виде глобальных идентификаторов (GUID) и в виде локальных идентификаторов (внутренних) экспортируемой базы.
Глобальные идентификаторы указываются для однозначной идентификации метаданных, объектов и связей при их верификации во время процесса импорта в IPS. Локальные идентификаторы указываются для сохранения взаимосвязей в пределах одной задачи импорта/экспорта, а также для ускорения поисковых процессов при обработке данных на этапе импорта.
Даты и время указываются в виде: yyyy-mm-ddThh:mm:ss, где: yyyy – год, mm-месяц, dd-день, T-разделитель между датой и временем, hh-часы, mm-минуты, ss-секунды, время приведено в UTC (по Гринвичу).

# Структура файлов данных для экспорта / импорта на диске
| **Папка** | **Содержимое** |
| --- | --- |
| \ | Файлы XML |
| \Blob | Импортируемые/экспортируемые двоичные данные, файлы документов |
| \Icon | Файлы иконок соответствующих типов объектов для просмотра данных в автономном режиме |
Примечание: наличие данных в директории **Icon** не обязательное для импорта данных из сторонних систем в IPS.

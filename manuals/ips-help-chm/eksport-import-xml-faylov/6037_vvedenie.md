# Введение
Возможности, описанные в данном документе, доступны в клиенте при условии наличия загруженного модуля **Импорт/Экспорт XML** (Intermech.XmlExchange.Client). На серверной стороне должен быть также загружен серверный модуль **Импорт/Экспорт XML** (Intermech.XmlExchange.Server).
Модуль **Импорт/Экспорт XML** , входящий в состав системы IPS, позволяет осуществить следующие функции:
· Экспорт информации об объектах системы IPS (изделиях, документах, техпроцессах, нормативно-справочной информации и т.д.), их составе и версиях в файлы формата XML для последующей передачи в смежные системы.
· Импорт информации об объектах смежных систем (изделиях, документах, техпроцессах, нормативно-справочной информации и т.д.), их составе и версиях из файлов формата XML в систему IPS.

# Скрипты задачи выгрузки
**Скрипты задачи выгрузки** – в данном разделе настраивается сценарий скрипта экспорта. Данный раздел будет записан в файл xml в элемент **<Script>**. Доступны следующие настройки:
· **Наименование скрипта.** В данной строке записывается наименование скрипта.
· **Текст скрипта.** Содержится сценарий скрипта. Редактирование сценария производится в отдельном окне, открываемого по команде . На рисунке ниже показано окно для редактирования скрипта:

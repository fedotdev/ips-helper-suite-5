# Элемент \< extentions\>
Элемент **< extentions>** cодержит перечень расширений (плагинов) задачи экспорта данных для текущей конфигурации. Расширения позволяют изменить содержимое, а также формат экспортируемых данных.
```text
```
```text
; Cписок расширений (плагинов) задачи экспорта данных
```
```text
  <extentions>
```
```text
   ; Подключение расширения для выгрузки состава контекстов
```
```text
    <extention guid="EE00DA05-D441-4402-B7DE-2CD184251F24" name="Выгрузка составов контекстов" >
```
```text
    </extention>  
```
```text
```
```text
    ....
```
```text
  </extentions>  
```
```text
```
Для создания пользовательского расширения экспорта, требуется реализовать класс, унаследованного от интерфейса **IXmlExchangeExportExtension**.
Для регистрации пользовательского расширения в системе требуется вызвать метод RegisterExtension сервиса **IXmlExchangeService**. 
Перечень зарегистрированных в системе расширений:
− guid="EE00DA05-D441-4402-B7DE-2CD184251F24" – выгрузка составов контекстов. При экспорте объектов контекста (извещений, производственных заказов) экспортирует объекты, входящие в состав контекста.
− guid="EE00DA06-D441-4402-B7DE-2CD184251F24" – Выгрузка признака головного объекта. В атрибут ID =-510 прописывается значение, равное «1» для головных объектов (для которых был вызван экспорт данных).

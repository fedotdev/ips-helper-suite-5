# Элемент \<xmlexportsettings\>
В качестве облегчения настройки импорта данных из XML в базу IPS (для соответствий идентификаторов типов атрибутов/объектов/связей в файле XML и типов в базе IPS), в конфигурацию импорта может быть включена конфигурация экспорта, по которой были ранее экспортированы данные из IPS в формат сторонней системы. При импорте данных система будет искать соответствие идентификаторов типов объектов/связей XML в секциях настроек экспорта. При импорте атрибутов идентификаторы типов сначала производится поиск в секции атрибутов соответствующих типов объектов/связей. Если тип атрибута не найден у объекта/связи, то идентификатор далее осуществляет поиск в общей секции атрибутов настроек импорта.
Примечание: данный элемент **< xmlexportsettings>** не является обязательным к заполнению и может отсутствовать в файле настроек импорта.

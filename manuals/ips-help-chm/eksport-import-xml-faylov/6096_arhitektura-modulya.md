# Архитектура модуля
Внешний вид модуля **Визуализатор XML** показан на рисунке ниже:
 – дерево с отображением загруженных объектов. 
В ветке **Объекты** отображаются объекты, которые были выбраны для просмотра.
В ветке **Прочие объекты** отображаются объекты без состава. Например, пользователи, единицы измерения и т.д..
 – окно с данными, которые соответствуют выбранному объекту в дереве.
При выборе основной ветки **Объекты** , содержимое отображается списком всех входящих в состав объектов.
При выборе конкретного объекта в дереве, пользователю становятся доступны свойства выбранного объекта. На рисунке ниже представлен вид окна с данными выбранного объекта:
 – панель с закладками **Объекты** и **Метаданные**.
По умолчанию пользователь работает с содержимым закладки **Объекты** , однако, для файлов с форматами IPS появляется возможность просмотреть информацию о свойствах объектов, связей и атрибутов на закладке **Метаданные**.

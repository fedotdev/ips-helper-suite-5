# Элемент \<MetadataChangingRules\>
Данная секция в настоящее время не используется, добавлена для будущего развития модуля импорта данных из XML.
Примечание: данный элемент **< MetadataChangingRules >** не является обязательным к заполнению и может отсутствовать в файле настроек импорта.

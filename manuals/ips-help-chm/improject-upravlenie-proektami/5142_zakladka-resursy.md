# Закладка Ресурсы
На этой закладке задаются ресурсы для текущей задачи, а также руководитель (опционально).
По умолчанию руководителем каждой задачи является руководитель вышестоящей задачи. Если таких задач нет, или их руководители явно не назначены, то руководителем будет являться руководитель проекта. Если значение унаследовано, то поле **Руководитель** отображается серым цветом, если задано явно – белым.
Таблица ресурсов позволяет:
· **Добавлять новые ресурсы в список используемых данной задачей**. Для этого нужно перейти на свободную строку и кликнуть по кнопке выбора ресурсов. В появившемся диалоге выбрать необходимые ресурсы.
· **Изменять свойства уже использующихся ресурсов**. Для этого нужно спозиционироваться в нужную ячейку и изменить её значение, выбрав нужный вариант из списка доступных.
· **Удалять ресурсы**. Для этого нужно на нужной строке нажать клавишу **Delete**.
Примечание: при увеличении значения в поле **Единицы** загрузка текущего ресурса будет увеличена, а длительность задачи будет пересчитана пропорционально использованию этого ресурса в задаче.
Примечание: добавление/удаление дополнительных ресурсов также вызывает пересчет длительности задачи.

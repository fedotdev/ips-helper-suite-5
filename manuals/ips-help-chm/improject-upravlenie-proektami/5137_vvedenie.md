# Введение
Модуль ImProject предназначен для решения задач календарного планирования, контроля и координации работ по проекту. Он позволяет разрабатывать и наполнять содержимым проекты, распределять ресурсы по задачам, отслеживать прогресс выполнения и анализировать объёмы работ.

# Настройки модуля
Для корректной работы модуля и возможности использовать полный его функционал, следует настроить параметры, которые находятся по пути **Настройка \ Параметры IPS \ Система \ ImProject**.
Группа **Общие настройки** :
· **Автоматическое завершение проектов при выполнении всех задач**. Включенная настройка позволяет завершать выполнение проекта автоматически, после выполнения всех задач в проекте или вручную из письма, приходящего на почту руководителю проекта, в котором информируется о выполнении всех задач проекта.
Настройка **Автоматическое завершение проектов при выполнении всех задач** работает следующим образом, после выполнения последней задачи в проекте, проверяется значение данной настройки у руководителя проекта.
При условии, что у руководителя проекта выставлено значение **«Да»** для настройки **Автоматическое завершение проектов при выполнении всех задач** – завершается автоматически проект, после выполнения последней задачи в проекте.
При условии, что у руководителя проекта выставлено значение **«Нет»** для настройки **Автоматическое завершение проектов при выполнении всех задач** – руководитель проекта получает письмо на почту о выполнении всех задач в проекте, в данном уведомлении расположена кнопка, с помощью которой руководитель может завершить проект, не выходя из почты.
· **Контролировать процент загрузки ресурсов перед запуском проекта**. Данная настройка позволяет включить режим контроля общего процента загрузки по каждому ресурсу в рамках текущего проекта (при запуске проекта на выполнение, при сохранении изменений в запущенных проектах, при ручном запуске функции проверки проекта).
· **Максимальный общий процент загрузки одного ресурса в рамках текущего проекта.** Настройка, которая позволяет указать максимальный процент загрузки одного ресурса в рамках текущего проекта.
Группа **Специальные команды** :
· **Видимость команды «Обработка проекта по РМ»**.
Группа **Уведомления** :
· **Отправлять ли уведомления о просроченных задачах исполнителям**. Включенная настройка позволяет отправлять уведомление о просроченных задачах исполнителям.
· **Отправлять ли уведомление о просроченных задачах руководителю**. Включенная настройка позволяет отправлять уведомление о просроченных задачах руководителю проекта.
· **Периодичность отправки уведомлений о просроченных задача** х. Данная настройка позволяет задать периодичность отправки уведомлений о просроченных задачах как руководителю проекта, так и исполнителю.

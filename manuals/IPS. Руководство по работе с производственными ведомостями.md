1 Введение
Внимание! Для работы с производственными ведомостями следует убедиться, что в системе загружен
модуль Модуль для работы с ведомостями Intermech.MRP2.
В данном документе описана работа модуля по созданию и редактированию производственных ведомостей
в системе IPS.
Производственная ведомость (ПВ) – это комплект конструкторско-технологических документов, на
основании которых производится заказ-производство изделий/составных частей изделий в цехах завода.
С помощью функционала модуля пользователю предоставляются следующие возможности по работе с
производственными ведомостями:
 автоматизированное формирование ЭС ПВ на основе конструктивной и технологической ЭСИ;
 автоматизированное формирование ЭС ПВ на основе прототипа с автоматической привязкой
технологических ИО (заготовок, расцеховок, ТП) к новому ЭС ПВ;
 разграничение прав доступа к объектам ЭС ПВ на различных этапах КТПП;
 формирование отчетных документов по ЭС ПВ;
 автоматизированное формирование документов типа: Заказной лист, Заявка на материалы,
Заявка на комплектующие на основе данных ЭС ПВ;
 создание и сравнение версий ЭС ПВ.

6 Создание производственной ведомости по прототипу
Возможности модуля позволяют пользователю создавать производственные ведомости по прототипу. При
создании ПВ по прототипу, в новую ведомость копируются значения всех атрибутов конструкторской части
ведомости-прототипа. Помимо атрибутов, копируются неуникальные объекты, которые входят в состав
ведомости-прототипа на первом уровне. Неуникальные объекты входят в состав новой ведомости со всем
своим составом с копированием значений всех атрибутов связей.
Примечание: значения атрибутов могут скопироваться при условии, что в настройках системы значение
свойства Запрет копирования значения у прототипа отключено.
Внимание! Если в составе производственной ведомости-прототипа находятся уникальные объекты, то
система копирует их в ПВ, как новые уникальные объекты.
Для того чтобы создать производственную ведомость по прототипу следует:
1. Выделить ведомость-прототип и воспользоваться кнопкой , которая находится на панели
инструментов.
2. В открывшемся окне следует заполнить карточку новой производственной ведомости.
3. Для завершения процесса создания ПВ по прототипу необходимо нажать кнопку .

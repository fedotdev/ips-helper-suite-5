Программа установки ПО «Интермех»

После установки серверной части в файле Setup.ini можно сделать следующие настройки для установки клиентских мест:  
ADD\_ICO\_ADMIN=Yes \- на клиента не будет устанавливаться Admin.exe (Search Administrator) и TechCFG.exe (Настройка базы данных).

ADD\_ICO\_BLANKS=No \- если ADD\_ICO\_BLANKS=Yes на клиенте будет созданы ярлыки для редактора бланков (BLN) и редактора документов (IMD)

COMMON\_DESKTOP\_S4=Yes- на клиенте будет создан ярлык для Search на рабочем столе;  
COMMON\_DESKTOP\_ALL=No – на клиенте ярлыки будут созданы для пользователя под которым проводили установку;  
INSTALL\_DIR=C:\\IM \- для установки по умолчанию будет предлагаться указанная папка, параметр IM\_Dir из HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Intermech будет игнорироваться;  
SETUP\_SEARCH\_TASKER=Yes – при установке серверной части Search v.13 будет устанавливаться служба SEARCH TASKER.

Для установки клиентов можно создать файл сценария. В этом случае установка происходит без дополнительных запросов. Если файлов сценария несколько, перед установкой запрашивается требуемый файл сценария.  
Список файлов сценариев хранится в файле IMSCR.LIST в подпапке IMSCR. Имена файлов могут быть как на русском, так и английском языке. Например:  
Установка Search.imscr  
Установка Search и Techcard.IMSCR  
Full.imscr

Если в папке IMSCR находится несколько файлов сценария Setup.exe можно запускать с параметром для указания конкретного файла:   
Setup.exe /M=C:\\IM\\IMScr\\имя\_файла.imscr  
Внимание\! В файле “ имя\_файла.imscr” первой строкой должна быть строка:  
FILE\_NAME\_SCR= имя\_файла.imscr

При установке можно запускать дополнительные программ пользователей. Описываются в Setup.ini или файле сценария в секциях \[RUN\_X64\] и \[RUN\_X86\] переменными RUN\_1 – RUN\_5. Например:  
\[RUN\_X64\]  
RUN\_1=c:\\Windows\\System32\\Regsvr32.exe=D:\\IM\\SEARCH\\eDrawViewer.ocx

В файл сценария можно прописать параметр RESTART=No – он отменяет финальный диалог с предложением перезагрузки ПК. 

Если файл IMSCR.LIST не найден, проверяется наличие файлов сценариев в папке  IMSCR. ВНИМАНИЕ\! В этом случае имена файлов сценария должны быть только на английском языке, расширение файлов IMSCR.   
Файлов сценария не может быть больше 10 шт.  
Если в выбранном файле сценария не определены необходимые переменные для автоматической установки сообщение о найденных ошибках пишется на сервере в файл IM\\Common\\COMPUTERNAME.log, где COMPUTERNAME – имя ПК на который производится установка. Если папка IM\\Common не доступна для записи лог не создается.

Структура файла сценария аналогична структуре файла Setup.ini:  
\[INTERMECH\]  
SERIAL\_NO=0000  
TYPESETUP=Client  
ADD\_ICO\_ADMIN=Yes  
// Создавать или нет на клиенте ярлык для Search Admin  
ADD\_ICO\_AUTOSETUP=Yes  
/// Если ADD\_ICO\_AUTOSETUP=No запуск Автообновление программ Интермех //будет прописан в реестр, если Yes – в Автозагрузку.  
COMMON\_DESKTOP\_S4=No  
// Создавать или нет на клиенте ярлык для Search на рабочем столе  
 INSTALL\_DIR=D:\\IM  
// Папка установки клиента по умолчанию  
RESTART=No  
// После установки не будет финального диалога с предложением перезагрузки.  
CLIENT\_SETUP=A  
// Тип установки клиента, A – без копирования на клиента; B – с копированием  
GROUP=Intermech  
// Папка, в которой будут созданы ярлыки для программ  
SYBD=A  
// Используемая СУБВ. A – FireBird (Interbase); B – Oracle; C \- MSSql

// A – Search; B \- Search СПДС; C – Improject; D – AVS; E – ImBase; F – IMH;  
// G – Show; H – Catalog.    
// Заглавная буква – система устанавливается, прописная \- нет  
COMPONENTS\_PDM=abcdefgh  
// A \- Cadmech AutoCAD; B \- Cadmech-T AutoCAD; C – Rotation; D – Spring;  
// E \- IMForging  
COMPONENTS\_2D=abcde  
// A \- Cadmech Inventor; B \- Cadmech ProE; C \- Cadmech Solid Edge;   
// D \- Cadmech SolidWorks; E \- Cadmech Unigraphics; F \- IMShape  
COMPONENTS\_3D=abcdef  
// A – Techcard; B \- АРМ Конструктора оснастки;   
// C \- АРМ Материального нормирования; D \- АРМ нормирования техпроцессов;  
// E \- АРМ Перевода техпроцессов; F \- АРМ Расцеховочных маршрутов;  
// G \- АРМ Расцеховочных маршрутов/Материального нормирования;  
// H \- Модуль экспорта/импорта XML; I \- LCAD  
COMPONENTS\_T=abcdefghi

// Версии устанавливаемых систем. Можно посмотреть в файле Program.list  
CADM\_ACAD\_VER=9  
CADM\_INV\_VER=5  
CADM\_PROE\_VER=2  
CADM\_SW\_VER=8  
CADM\_UG\_VER=7  
CATALOG\_VER=2000  
IMSHAPE\_VER=1  
SEARCH\_VER=11  
PDMBROWSER\_VER=3 10.4.0.1  
IMH\_VER=1  
AVS\_VER=5  
SHOW\_VER=5  
TECHCARD\_VER=8  
LCAD\_VER=4

// R17.1 – AutoCAD 2008; R17.2 – AutoCAD 2009; R18.0 – AutoCAD 2010; R18.1 – AutoCAD 2011;  
AUTOCAD\_VER=R17.1  
// 12 – Inventor 2008; 13 – Inventor 2009; 14 – Inventor 2010; 15 – Inventor 2011;  
INVENTOR\_VER=12  
PROENGINEER\_VER=  
SE\_VER=  
SW\_VER=2009  
UG\_VER=

\[MANAGER\]  
SERVERNAME=A1SERVER  
TCPIP=0

RUN\_1=c:\\Windows\\System32\\Regsvr32.exe=D:\\IM\\SEARCH\\eDrawViewer.ocx

Программа автообновления программных продуктов Intermech – AutoSetup

**Сервер**

На сервере в папке IM находятся:  
AutoSetup – программа, выполняющая автоматическое обновление  
CheckSetup.exe – программа проверки необходимости проведения обновления.  
ServerSetup.INI – ini файл, в котором прописаны установленные программы и дата установки. Например:  
\[PROGRAMS\]  
SYSTEM=15.07.2003  
CADMECH=03.04.2003  
IMBASE=15.07.2003

Для поддержки старой программы автообновления, оставлена возможность написания скрипта обновления. Поддерживается только AutoSetup.ini

**Клиент**

На клиенте при установке в папку IM\\CFG создается файл ClientSetup.ini в котором прописаны установленные программы и дата установки, аналогично как ServerSetup.INI. Программа AutoSetup.exe прописывается в автозагрузку.

При старте Windows на клиентском ПК программа CheckSetup.exe читает файлы ClientSetup.ini и ServerSetup.ini и сравнивает даты для различных приложений. В случае если дата на клиенте, для какого, либо приложения более поздняя, чем на сервере происходит автоматическое обновление исполняемых модулей требуемой программы с помощью программы AutoSetup.exe.  
**\! Регистрации COM серверов и DLL не производится.**  
Если различий не найдено, программа завершается в «тихом» режиме. 

Путь к серверу считывается с HKEY\_LOCAL\_MACHINE\\SOFTWARE\\WOW6432Node\\Intermech из строкового параметра SetupPath.   
Путь установки на клиенте считывается из системной переменной Windows IMTMP

**Структура файла сценария AutoSetup.ini**

// \- символы в начале строки означают что далее идет комментарий  
∙	Копирование файлов описывается в секции \[FILES\]:  
\[FILES\]  
%IM\_SERVER%\\SEARCH\\s4.exe=%IM\_CLIENT%\\SEARCH\\s4.exe,/O  
%IM\_SERVER%\\SYSTEM.DLL\\midas.dll=%SYSTEM\_DIR%\\midas.dll,/A  
%IM\_SERVER%\\CADMECH\\LISP\\\*.\*=%IM\_CLIENT%\\CADMECH\\LISP,/N  
     
Типы перезаписи файла:   
/A \- всегда,   
/O \- если файл на приемнике существует и старый,   
/N \- копирует содержимое папки сподпапками если она существует на приемнике и файлы старые.

Переменные:   
%IM\_SERVER% \- серверный каталог  
%IM\_CLIENT% \- клиентский каталог  
%SYSTEM\_DIR%' \- windows\\system32  
%BDE%' – папка установки BDE на клиенте  
**\! Если файл в папке приемнике имеет атрибут «Только чтение» он не будет заменен в процессе автообновления.**

∙	Запись в реестр описывается в секциях:   
\[HKEY\_CLASSES\_ROOT\]  
***Пример**. Прописывает для вызова файлов с расширением PE программы AVS5.EXE*  
.PE=\\PE\_Auto\_File  
PE\_Auto\_File\\shell\\Open\\Command\\="[\\\\DC-PLM\\IM\\AVS5\\AVS5.EXE](http://\\\\\\\\DC-PLM\\\\IM\\\\AVS5\\\\AVS5.EXE)" "%1"

\[HKEY\_CURRENT\_USER\]  
***Пример**. Прописывает новый тип документа «Перечень элементов» и его настройки для AVS*  
Software\\InterMech\\Avs5\\DOC\\Перечень элементов\\FTYPE=.PE  
Software\\InterMech\\Avs5\\DOC\\Перечень элементов\\INIFILE=%IM\_SERVER%\\CFG\\AVS5\_PE.INI  
Software\\InterMech\\Avs5\\DOC\\Перечень элементов\\KOD=ПЭ3

\[HKEY\_LOCAL\_MACHINE\]  
Software\\Intermech\\Avs5\\.PE=%IM\_SERVER%\\CFG\\ AVS5\_PE.INI

\[HKEY\_LOCAL\_MACHINE\]  
software\\intermech\\search\\ExeName=%IM\_CLIENT%\\SEARCH\\s4.exe

**\! Необходимо иметь ввиду, что выполнение этой операции требует наличие прав у пользователей на клиентах на запись в соответствующие ветки реестра.**

∙	Запуск необходимых программ описывается в секции \[RUN\]  
∙	Внимание\! При включении в данную секцию программы содержащей в пути или имени пробелы брать в кавычки не нужно.  
\[RUN\]  
%SYSTEM\_DIR%\\Regsvr32.exe=%IM\_CLIENT%\\SEARCH\\eDrawViewer.ocx  
%SYSTEM\_DIR%\\reg.exe import=%IM\_CLIENT%\\CFG\\setup\_avs.reg  
%SYSTEM\_DIR%\\Regsvr32.exe=/S %IM\_CLIENT%\\SEARCH\\s4.exe

∙	Добавление иконок на рабочий стол Windows описывается в секции \[COMMON\_DESKTOP\] в формате:  
Имя\_ярлыка=Выполняемый\_файл@Параметры&Рабочий директорий\#Файл\_иконки

\[COMMON\_DESKTOP\]  
Search=%IM\_SERVER%\\SEARCH\\s4.exe@&% IM\_CLIENT %\#% IM\_CLIENT %\\ICO\\S4.ico  
Cadmech="C:\\Program Files\\Autodesk\\AutoCAD 2010\\acad.exe"@/p "\<\<Профиль без имени\>\>"&\#% IM\_CLIENT %\\ICO\\Cadmech.ico  
**\! В этой секции поддерживаются только %IM\_SERVER% \- серверный каталог**  
 **и %IM\_CLIENT% \- клиентский каталог**

**\! Внимание. Секции должны располагаться в следующем порядке:**  
\[FILES\]  
\[HKEY\_CLASSES\_ROOT\]  
\[HKEY\_CURRENT\_USER\]  
\[HKEY\_LOCAL\_MACHINE\]  
\[RUN\]  
\[COMMON\_DESKTOP\]

***Секцию \[COMMON\_DESKTOP\] можно добавлять и в файлы сценариев. Единственное, секция должна быть последней в файле.***

**Как прописать на всех клиентах информацию в реестр, указав директорию, где искать файл avs\_108.ini и отключить автосохранение ini файлов.**

На сервере, например в файл AutoSetup.ini добавляем строки:

\[HKEY\_CURRENT\_USER\]  
Software\\Intermech\\Avs5\\ AutoSaveIni=0  
Software\\Intermech\\Avs5\\Avs5\_Ini\_Filename=%IM\_SERVER%\\CFG\\AVS5\_108.INI  
Software\\InterMech\\Avs5\\DOC\\Спецификация ЕСКД\\INIFILE=%IM\_SERVER%\\CFG\\AVS5\_108.INI

\[HKEY\_LOCAL\_MACHINE\]  
Software\\Intermech\\Avs5\\.SP=%IM\_SERVER%\\CFG\\AVS5\_108.INI

В файле SERVERSETUP.INI для AUTOSETUP устанавливаем текущую дату. При следующем запуске клиента произойдет запись в реестр, если пользователю Windows это разрешено.

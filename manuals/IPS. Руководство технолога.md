1 Введение
Возможности, описанные в данном документе, доступны в клиенте при условии наличия загруженного
модуля редактора технологических процессов (Intermech.TechCard.Client). На серверной стороне должен быть
также загружен серверный модуль Techcard (Intermech.TechCard.Server).
Редактор технологических процессов, входящий в состав модулей IPS позволяет:
 создавать расцеховочные маршруты на изделия по входимости в сборочный узел и заказ;
 назначить и рассчитать параметры заготовки на изделие;
 проектировать технологические процессы обработки детали (в том числе сквозные) в диалоговом
режиме с расчетом параметров операций, переходов и дополнительных приемов, режимов
обработки и нормированием для различных видов производств, используя базы данных, типовые
фрагменты, формулы, таблицы и скрипты экспертной системы;
 создавать новые версии техпроцессов по извещениям;
 создавать групповые/типовые техпроцессы (ГТП/ТТП);
 создавать комплекты технологических документов (КТД);
 формировать комплекты ведомостей (ВТ), в состав которых включать различные ведомости по
материалам, операциям, переходам, оборудованию, оснастке, расцеховочным маршрутам,
технологическим документам и т.д;
 осуществлять поддержку различных видов производств;
 обеспечить взаимосвязь с системой разработки конструкторской документации CADMECH
(разработка ОДО ИНТЕРМЕХ) для проектирования и оформления операционных эскизов и карт
наладок.

3.1 Маршрут обработки
Каждое изделие может иметь один или несколько маршрутов обработки (МО). Каждый маршрут обработки
объединяет информацию по заготовке, расцеховке, входимости МО и одному или нескольким техпроцессам
(ТП).
Ввод дополнительной входимости МО, заготовки или расцеховки на изделие подразумевает создание
дополнительного маршрута обработки. Если в каких-то случаях требуется создание более одного объекта
входимости МО, заготовки или расцеховки в МО, то следует установить запрет на контроль уникальности
данных объектов в МО (см. п. 4.1.2).
Первый МО создается автоматически при указании команды на создание заготовки, расцеховки или
техпроцесса в окне Навигатора либо по команде Добавить - для объектов, в состав которых может быть
включен маршрут обработки.
По умолчанию маршруту обработки присваивается обозначение вида:
 <обозначение изделия> <порядковый номер маршрута обработки> МО
Наименование маршрута обработки совпадает с наименованием изделия.
Руководство технолога 11

3.1.4.10 Работа со сварочными швами

3.4.1.2 Выбор эскизов и многоэскизный режим
Команда меню ТЕХ.ЭСКИЗ/Эскизы/Открыть, и соответствующая кнопка кнопочной панели позволяют
сделать какой-либо эскиз текущим и показать его на экране – в AutoCAD это соответствует включению слоев,
ассоциированных с эскизом. Выбрать эскиз можно как установив курсор на операцию, так и щелкнув мышью
на переключателе рядом с операцией или эскизом. После открытия эскиза в строке состояния AutoCAD
появится название эскиза.
При выборе нескольких эскизов одного техпроцесса редактор эскизов перейдет в многоэскизный режим
работы.
При многоэскизном режиме редактор располагает эскизы в порядке следования операций в диалоге выбора.
Первый эскиз располагается снизу слева. Каждый эскиз располагается в прямоугольной области,
ограниченной соответствующим прямоугольником.
В многоэскизном режиме работы редактор отслеживает все изменения в рисунке и автоматически относит
изменяемый элемент к тому или иному слою в зависимости от того, в границы какого прямоугольника (эскиза)
попал этот элемент. В частности, это означает, что копирование или перенос элемента как средствами
AutoCAD, так и Cadmech приведет к переносу элемента в соответствующий эскиз.
Перед включением многоэскизного режима необходимо установить границы полей рисунков (см. п. 3.4.1.7).
Имя редактируемого эскиза отображается в строке состояния AutoCAD.

3.4.1.7 Работа с границами поля рисунка в бланке
Границы полей рисунков необходимы как для многоэскизного режима работы, так и при выводе на печать
технологической документации. Кнопки, используемые для работы с границами полей рисунков бланков,
находятся на кнопочной панели Граница поля рисунка. Команды, аналогичные этим кнопкам, находятся в

рисунка на все эскизы используется тогда, когда для вывода всех эскизов техпроцесса будет использоваться
один и тот же бланк карты эскизов. Это позволит избежать масштабирования эскиза в бланке, если размеры
границы поля рисунка будут совпадать с размерами поля вывода эскиза в бланке. Для создания границ
используются кнопки Граница поля рисунка на эскиз и Граница поля рисунка на все эскизы. При
нажатии на эти кнопки появляется диалог задания параметров границы.
В поле Базовая точка задается левая нижняя точка бланка. Координаты точки можно как задать вручную,
так и указать на рисунке, нажав кнопку Указание >.
В поле Размеры задается ширина и высота бланка. Размеры, как и базовую точку, можно задать вручную
либо указать на рисунке, нажав кнопку Рамка >. Можно также задать размеры бланка, выбрав их из списка
по кнопке Выбрать. Изменить список размеров можно по команде контекстного меню Изменить список.
Границы бланка можно скрывать и показывать с помощью кнопок Вкл. границу поля рисунка и Выкл.
границу поля рисунка.

элементов доступны только для отображения.

Атрибут – ссылка на IMBASE – заполняется в том случае, если правило автоподбора было создано для

В атрибут Наименование по умолчанию записывается наименование типа объекта, для которого создано

Свойство Режим запуска определяет, когда будет работать данное правило автоподбора:
 Подбирать по команде – правило автоподбора будет работать по команде Автоподбор
контекстного меню, вызываемого по правой кнопке мыши в дереве Навигатора для
технологических объектов.
 Подбирать автоматически для объекта – правило автоподбора будет работать при создании

 Подбирать автоматически для связи – правило автоподбора будет работать в случае включения
уже существующего объекта данного типа в состав других объектов.
Свойства Режим наследования определяет, как будет унаследовано правило автоподбора:
 Собственное – значение, при котором правило автоподбора отрабатывает для текущей папки и для
дочерних, при условии, что у дочерних нет других правил автоподбора.
 Общее – значение, при котором правило автоподбора отрабатывает для текущей папки
справочника и всегда для дочерних подпапок, независимо от наличия в них собственных правил
автоподбора.

миграции из TechCard – значение Общее.
Свойство Сортировка определяет положение правила автоподбора в перечне правил для типа объекта или
элемента справочника. Чем меньше значение данного атрибута, тем выше в перечне правил он располагается.
В свойство Тип объекта записывается тот тип объекта, для которого данное правило автоподбора было
создано.

2. Разместить файл Consulting.SignatureReset.Client.dll в папке клиента и подключить данный плагин
при последующей загрузке.
3. В Параметры IPS \ Система \ Плагины \ Сброс подписи объекта выполнить настройки объектов, для
которых будет осуществляться контроль подписей. В правой части окна настройки дана поясняющая
информация о том, как указать объекты для сброса подписей. Ввод конфигурации производится
вручную. Поэтому следует внимательно относиться к написанию наименования объекта.

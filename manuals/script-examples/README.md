# Примеры скриптов IPS

Коллекция рабочих скриптов для IPS 9.x на C#.

## Бизнес-логика (business/)

Скрипты для бизнес-процессов, автоматизации и обработки данных:

- **Выбор записи из Imbase и создание объекта.cs** — выбор записи из каталога Imbase и создание объекта IPS на её основе
- **Длительность и ресурсы.cs** — работа с длительностью задач и ресурсами
- **Заполнение параметров основного файла.cs** — автоматическое заполнение параметров главного файла объекта
- **Отправка почты.cs** — отправка уведомлений по электронной почте
- **Присвоение номера ведомости.cs** — автоматическое присвоение номеров ведомостям
- **Присвоение поручению даты контроля.cs** — установка контрольных дат для поручений
- **Присвоение фактической даты исполнения.cs** — фиксация фактических дат завершения
- **Проверка указания Нач.КБ.cs** — валидация заполнения поля начальника КБ
- **Сценарий перевода поручения на шаг ЖЦ Поручено.cs** — перевод поручения на следующий шаг жизненного цикла
- **Сценарий проверки ЭС ПВ.cs** — проверка электронной подписи производственной ведомости
- **Формирование аутентичных файлов.cs** — генерация заверенных копий файлов

## Генерация документов (gen-docs/)

Скрипты для автоматической генерации документов и отчётов:

- **Ведомость И.cs** — генерация ведомости изменений
- **Ведомость технологических документов ГОСТ 3.1122-84 форма 3.cs** — формирование технологической ведомости по ГОСТ
- **Заявка на комплектующие.cs** — создание заявки на закупку комплектующих
- **Заявка на материалы.cs** — создание заявки на материалы
- **Отчет по проекту ImProject.cs** — генерация отчёта по проекту
- **Перечень допустимых опций конфигуратора.cs** — список доступных опций конфигуратора изделия
- **Перечень примененных опций в заказе.cs** — список опций, применённых в конкретном заказе

## Использование

Скрипты запускаются через:
- Script Pad (для разработки и тестирования)
- Бизнес-процессы (автоматическое выполнение на шагах ЖЦ)
- Генераторы документов (для создания отчётов и форм)

Все скрипты используют IPS API и выполняются в контексте текущего пользователя с его правами доступа.

## Предупреждения

- Скрипты содержат GUID типов объектов и атрибутов, специфичные для конкретной конфигурации IPS
- Перед использованием проверьте соответствие GUID вашей базе данных
- Скрипты изменяют данные — тестируйте на копии базы
- Права доступа пользователя ограничивают выполнение операций

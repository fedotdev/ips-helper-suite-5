## Быстрый старт

### Claude Code

```bash
/plugin marketplace add ips-helper-suite-5
/plugin install ips-system-helper
/plugin install ips-programmer
/plugin install ips-technologist
```

### Другие платформы

```bash
git clone <repo-url>
```

Скопируйте содержимое `skills/ips-system-helper/SKILL.md`, `skills/ips-programmer/SKILL.md` и `skills/ips-technologist/SKILL.md` в конфигурацию вашей платформы.

## Компоненты

### /ips-system-helper — Помощник по интерфейсу

Для конструкторов и технологов, работающих через интерфейс IPS.

| Сценарий | Пример |
|----------|--------|
| Навигация и поиск | "Где найти мою спецификацию?" |
| Создание документов | "Как создать ТД в IPS?" |
| Ошибки IPS | "Выдаёт ошибку при сохранении" |
| ЕСТД/ЕСКД, ГОСТ | "Как оформить графу штампа по ГОСТ?" |

### /ips-programmer — Программист IPS

Для программистов и администраторов, работающих с кодом и конфигурацией.

| Сценарий | Пример |
|----------|--------|
| Скрипты C# | "Как написать скрипт для массового обновления?" |
| Настройка метаданных | "Как настроить новый тип объекта?" |
| Интеграция с CAD | "Как интегрировать КОМПАС с IPS?" |
| SQL, импорт/экспорт | "Как выгрузить данные из IPS?" |

### /ips-technologist — Технолог IPS

Read-only анализ live-данных ЕТП через IPS-MCP: маршруты, цехозаходы, операции,
ресурсы и нормирование с фиксацией подтверждённых и неизвестных данных.

| Сценарий | Пример |
|----------|--------|
| ЕТП и маршрут | "Что в ЕТП изделия X?" |
| Операции и цеха | "Покажи операции и цехозаходы" |
| Сопоставление раскадровки | "Проверь операции по данным IPS" |

> [!TIP]
> Suite автоматически маршрутизирует запросы. Задайте вопрос о IPS — система направит к нужному компоненту.

## Правила

> [!WARNING]
> Никогда не выдумывайте названия пунктов меню, кнопок или атрибутов. Если название не подтверждено руководством — напишите «точное название проверьте в вашей конфигурации».

- IPS глубоко настраивается под предприятие — не выдавайте поведение конкретной конфигурации за стандарт
- Диагностика ошибок — только по фактам: запросите точный текст ошибки
- При ошибке — признайте и дайте исправленный ответ
- Честность важнее комфорта: если документ не по ГОСТ — скажите прямо

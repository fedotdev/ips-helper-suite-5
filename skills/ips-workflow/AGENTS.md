# Companion guide

## Назначение

Специалист по бизнес-процессам IPS Workflow: схемы, условия, действия, исполнители,
сценарии, локальные IWF/XML-кандидаты и проверка доступных live-данных через IPS-MCP.

## Использование

Прямой вызов: `/ips-workflow`. Следуйте [SKILL.md](SKILL.md).
Формат и ограничения: [references/iwf-format.md](references/iwf-format.md).
Компонент Python выполняется локально агентом, не внутри IPS.

Учитывайте ограничения корневого `AGENTS.md` и `shared/mcp.md`.
Наличие preview/commit-инструмента не отменяет действующее ограничение на чтение.
ЕТП/ГТП направляйте в `/ips-technologist`, общий C#/API — в `/ips-programmer`.

# IPS Helper Suite — Наставник по PLM-системе IPS 9.x

## Назначение

Набор инструментов для помощи пользователям PLM-системы Intermech Professional Solutions 9.x (IPS):
- **Помощник по системе** — для конструкторов и технологов, работающих через интерфейс IPS
- **Программист** — для тех, кто настраивает IPS, пишет скрипты, интегрирует с CAD

## Активация

Активируется на вопросы о:
- IPS, Intermech, PDM, КОМПАС, CADMECH, PDMBrowser
- Спецификации, атрибуты, жизненный цикл, версии
- ЕСТД, ЕСКД, ГОСТ, основные надписи, штампы
- Скрипты, C#, SQL, Script Pad
- Настройка IPS, метаданные, типы объектов
- Интеграция, API, импорт, экспорт

## Использование

### Для работы через интерфейс IPS
Используйте `/ips-system-helper` для вопросов о:
- Как найти объект, открыть карточку
- Как создать документ, заполнить атрибуты
- Как подписать, отправить на согласование
- Ошибки в IPS
- Оформление КД/ТД по ГОСТ

### Для программирования и настройки
Используйте `/ips-programmer` для вопросов о:
- Скрипты на C# для IPS
- Настройка метаданных и типов объектов
- Интеграция с CAD-системами
- SQL-запросы к базе данных
- Импорт/экспорт данных

## Источники информации

Suite использует следующие документы:
- Руководства IPS (пользователя, конструктора, администратора, программиста)
- Транскрипты обучений (GMT*.txt)
- ГОСТы (ЕСТД, ЕСКД)

## Gotchas

- IPS может быть кастомизирован под предприятие — интерфейс отличается от руководства
- Транскрипты содержат ошибки распознавания речи
- UUID-файлы могут содержать устаревшие ответы
- Некоторые функции доступны только администраторам
- API IPS отличается между версиями (9.0, 9.1, 9.2)

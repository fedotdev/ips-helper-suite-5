# IPS Helper Suite — Наставник по PLM-системе IPS 9.x

## Назначение

Набор инструментов для помощи пользователям PLM-системы Intermech Professional Solutions 9.x (IPS):
- **Помощник по системе** — для конструкторов и технологов, работающих через интерфейс IPS
- **Программист** — для тех, кто настраивает IPS, пишет скрипты, интегрирует с CAD
- **Технолог** — для read-only анализа live-данных ЕТП, раскадровки, операций и цехозаходов

## Активация

Активируется на вопросы о:
- IPS, Intermech, PDM, КОМПАС, CADMECH, PDMBrowser
- Спецификации, атрибуты, жизненный цикл, версии
- ЕСТД, ЕСКД, ГОСТ, основные надписи, штампы
- Скрипты, C#, SQL, Script Pad
- Настройка IPS, метаданные, типы объектов
- Интеграция, API, импорт, экспорт
- Live ЕТП, раскадровка, маршруты, операции, цехозаходы

## IPS-MCP: доступ к живой базе IPS

MCP-сервер `ips` подключён в [opencode.json](opencode.json) и даёт read-only доступ к работающей IPS. Общий контекст и инструменты — в [skills/ips-programmer/SKILL.md](skills/ips-programmer/SKILL.md), а точный технологический MCP-контракт — в [skills/ips-technologist/SKILL.md](skills/ips-technologist/SKILL.md).

**Когда использовать:** нужны актуальные данные из базы IPS (объекты, атрибуты, состав изделия, связи, метаданные) вместо догадок по документации.

### Установка

```powershell
python -m pip install -e D:\IPS\IPS-MCP
ips-mcp init
```

`ips-mcp init` пишет `D:\IPS\IPS-MCP\config.json` из переменных окружения, а логин и пароль спрашивает в терминале (пароль вводится скрыто). Существующий файл не перезаписывается без `--force`. Параметры можно менять и руками — сервер перечитывает файл при каждом старте.

Проверка: `opencode mcp list` — сервер `ips` должен быть в статусе connected.

### Ограничения

- Только чтение. Создание/изменение/удаление объектов — скрипты C# в IPS
- Права определяются пользователем, под которым запущен сервер
- Справочник имён (`gloss.db`) привязан к конкретной базе IPS
- Если IPS Web API недоступен — отвечайте по `D:\parsing\IPS-Durdom-5\ips-helper-suite-5\manuals\`, не выдумывая данные
- `/ips-technologist` безусловно работает только на чтение и не выполняет write-операции даже после подтверждения

## Gotchas

- IPS может быть кастомизирован под предприятие — интерфейс отличается от руководства
- Транскрипты содержат ошибки распознавания речи
- UUID-файлы могут содержать устаревшие ответы
- Некоторые функции доступны только администраторам
- API IPS отличается между версиями (9.0, 9.1, 9.2)

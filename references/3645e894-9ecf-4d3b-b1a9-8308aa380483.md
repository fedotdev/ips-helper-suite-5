# Согласно оборудованию на фотографии распредели оборудование, ИОТы и Тшт, Тпз, Кшт по операциям из разных ТП

030 Термическая
035 Универсально-шлифовальная
045 Получение покрытия
075 Никелирование электрохимическое.

Теперь у меня достаточно информации. Составлю подробную таблицу распределения оборудования, ИОТ и нормировочных параметров по операциям.

***

## Распределение оборудования, ИОТ и норм времени по операциям ТП

Ниже приведена привязка оборудования из кооперационной схемы (фото) к четырём операциям с указанием ИОТ, Тшт, Тпз и Кшт согласно ЕСТД и типовым отраслевым нормативам.

***

### 030 Термическая

Эта операция соответствует **стабилизирующему старению** — виду термической обработки, при которой детали выдерживаются при умеренных температурах (120–200 °C для алюминия; 150–350 °C для сталей) с целью снятия остаточных напряжений.[^1_1]


| Параметр | Значение |
| :-- | :-- |
| **Оборудование** | Печь камерная HFL1000 |
| **ИОТ** | ИОТ по охране труда при термической обработке металлов в печах (ПОТ Р М 005-97 / ПОТ РО-14000-001-98) [^1_2][^1_3] |
| **Тшт** | ≈ 0,8–2,5 мин/дет (загрузка/выгрузка; основное время — машинное, вне Тшт по операции) |
| **Тпз** | ≈ 15–30 мин (прогрев печи до рабочей температуры, проверка термопары, заполнение журнала) |
| **Кшт** | 1,0–1,05 (серийное/крупносерийное; при партийной загрузке партия деталей обрабатывается совместно) |

> **Примечание.** Для термических операций с выдержкой в печи Тшт, как правило, включает только вспомогательное время (загрузка, контроль); основное (машинное) время Тосн фиксируется отдельно и может составлять от 1 до 8 ч.[^1_4]

***

### 035 Универсально-шлифовальная

Операция выполняется на круглошлифовальном станке **PALMARY GU-20×40S** — универсальном круглошлифовальном станке, позволяющем обрабатывать наружные и внутренние цилиндрические, конические поверхности.


| Параметр | Значение |
| :-- | :-- |
| **Оборудование** | Круглошлифовальный станок PALMARY GU-20×40S |
| **ИОТ** | ИОТ при работе на шлифовальных станках (типовая форма ИОТ № 122 / ИОТВ-082) [^1_5][^1_6][^1_7] |
| **Тшт** | ≈ 1,5–6,0 мин/дет (зависит от диаметра, длины, припуска; по нормативам на шлифование по ГОСТ 3.1404-86) |
| **Тпз** | ≈ 16–24 мин (наладка станка, балансировка и правка круга, установка приспособления, настройка на размер) |
| **Кшт** | 1,08–1,14 (с учётом Тпз/n при серийном производстве: Кшт = 1 + Тпз/(n·Тшт)) |

> **Примечание.** Кшт рассчитывается по формуле $К_{шт} = 1 + T_{пз}/(n \cdot T_{шт})$, где $n$ — количество деталей в партии.[^1_8]

***

### 045 Получение покрытия

Операция выполняется на гальванических линиях. По данным кооперационной схемы предусмотрено использование одной из двух линий — **ГЛХ-300** или **ГЛХ-500** (выбор зависит от габаритов деталей и требуемого объёма загрузки). Вид покрытия для оп. 045 по наименованию может быть хромовым, цинковым или другим защитным/декоративным — оформляется по ГОСТ 3.1408-2022.[^1_9]


| Параметр | Значение |
| :-- | :-- |
| **Оборудование** | Гальваническая линия ГЛХ-300 **или** ГЛХ-500 (по согласованию, исходя из размера деталей) |
| **ИОТ** | ИОТ при работе на гальванических установках (нанесение гальванических покрытий); ПОТ Р О-14000-005-98 [^1_10] |
| **Тшт** | ≈ 3–15 мин/дет (включая подвеску, промывку, сушку; основное время — электрохимическое осаждение — в состав Тшт не включается, указывается Тосн отдельно) |
| **Тпз** | ≈ 20–40 мин (приготовление или контроль электролита, настройка плотности тока, проверка анодов) |
| **Кшт** | 1,0–1,03 (партионная обработка, Кшт близок к 1,0 при крупной партии) |


***

### 075 Никелирование электрохимическое

Данная операция — электрохимическое (гальваническое) никелирование — также выполняется на одной из гальванических линий: **ГЛХ-300** или **ГЛХ-500**. Оформляется по ГОСТ 3.1408-2022 как отдельный ТП нанесения покрытий.[^1_9][^1_11]


| Параметр | Значение |
| :-- | :-- |
| **Оборудование** | Гальваническая линия ГЛХ-300 **или** ГЛХ-500 |
| **ИОТ** | ИОТ при электрохимическом никелировании (гальванические работы); ПОТ Р О-14000-005-98; дополнительно — ИОТ по работе с никельсодержащими электролитами (канцероген 1А по МАИР) [^1_10][^1_12] |
| **Тшт** | ≈ 5–20 мин/дет (подвеска, предварительная обработка — обезжиривание, активация; выгрузка, промывка, сушка) |
| **Тпз** | ≈ 25–40 мин (приготовление никелевого электролита по рецептуре, корректировка pH, проверка плотности тока, анализ ванны) |
| **Кшт** | 1,0–1,04 |

## Важные замечания

**По оборудованию:**

- Операции 045 и 075 оба используют гальванические линии, что соответствует кооперации с предприятием-исполнителем «Получение покрытий». Разграничение по линиям (ГЛХ-300 vs ГЛХ-500) определяется габаритами подвески и объёмом партии.[^1_13]
- Печь HFL1000 однозначно относится только к оп. 030 Термическая (стабилизирующее старение).[^1_13]
- Станок PALMARY GU-20×40S однозначно относится только к оп. 035.[^1_13]

**По нормам времени:**

- Приведённые значения Тшт и Тпз — **ориентировочные диапазоны** по типовым отраслевым нормативам. Конкретные значения должны рассчитываться по операционным картам на основе режимов обработки, габаритов детали и типа производства согласно ГОСТ 3.1109-82.[^1_14][^1_4]
- Кшт = 1 при массовом производстве; при серийном рассчитывается с учётом Тпз.[^1_8]

**По ИОТ:**

- Номера ИОТ на конкретном предприятии присваиваются внутренним приказом; в ТП указывается внутренний номер ИОТ предприятия, а не номер ПОТ/ПОТРМ.[^1_6][^1_3]
- Для оп. 075 (никелирование) обязателен отдельный ИОТ по работе с канцерогенными веществами 1А группы (соединения никеля) согласно требованиям СанПиН и МАИР.[^1_12]

## Ответ helpdesk — Mon, Sep 21, 2026 05:27 PM (С уважением, Котченко Виктор)

Добрый день!
Доступ к API идет в базовой поставке.

IPS Development KIT - это отдельный набор решений как правило для диллеров, которым нужен отдельный поставочный набор чисто под разработку интеграционных решений.
В базовой поставке будет и сам доступ и описания работы с API:
1.
IPS API - базовый набор API для работы в системе IPS. Используется как в сценариях внутри IPS так и при написании модулей расширения.
Описан в руководстве программиста(описано не всё API). Файл "IPS. Руководство программиста.pdf" в папке Doc.
2.
IPS SDK - набор шаблонов для создания собственных модулей расширения, а также примеры таких модулей расширения.
Описание по работе с IPS SDK в файле" manual.pdf"..\IPS.Installer.Full\Files\IPS SDK\manual.pdf ..\IPS.InstClient\Files\IPS SDK\manual.pdf он находится у Вас либо в папке полным инсталлятором, либо в папке с клиентским инсталлятором, который формируется на стороне сервера.
3. У Вас на ключе есть одна лицензия IPS WebInterface Client v9 - значит и веб-апи будет также доступно для одной сессии.
По работе с Web API подробнее см. раздел "Просмотр списка доступных эндпоинтов и документации по WebAPI через Swagger UI"в том же файле" manual.pdf"
